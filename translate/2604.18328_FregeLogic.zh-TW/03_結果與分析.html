5. 結果與分析

5.1 個別模型表現

Table 5（附錄 D）呈現代表性第一階段內部 fold 中全部 12 組模型-提示組合的結果。準確率在不同配置之間差異不大（79.5–89.0%），但內容效應差異極大（3.49–13.71），驅動了結合分數的大幅差異。最佳提示策略因模型而異：Maverick 偏好 zero-shot 與 few-shot，Qwen 受益於 chain-of-thought。值得注意的是 Simple CoT 在最低平均內容效應（5.24）的同時是最 underspecified 的提示，暗示極簡指令可能讓模型進行內部結構推理，而非錨定於範例內容。Chain-of-thought 並非均勻地降低內容效應；對 Maverick 而言，few-shot CoT 將 CE 從 3.83 提高到 10.11。

5.2 Ensemble 與混合策略

Table 1 比較了跨五個外層 fold 聚合的六種融合策略。純 ensemble 達到 93.4% 準確率但內容效應 3.39。Z3-only 基線準確率低（74.7%），內容效應高（26.28），源於系統性 over-predict invalidity。

Tiebreaker 策略達到最佳結合分數（41.88），將內容效應從 3.39 降到 2.85（降幅 16%），同時準確率提高 0.9 個百分點。這與我們的假設一致：ensemble 意見分歧對應於 Z3 可幫助校正的內容偏誤案例。

Table 2 提供了關鍵策略的子群準確率。Tiebreaker 在四個子群之間達成比純 ensemble 或 Z3 alone 更平衡的準確率。純 ensemble 在 valid 子群（95.9–96.0%）與 invalid 子群（90.2–91.9%）之間存在差距；tiebreaker 縮小了這個差距（93.5–95.6%），其中內容偏誤最強的 invalid-believable 案例增益最大（90.2% → 94.5%）。

其餘策略表現更差：Z3 veto（分數 17.18）覆蓋了正確的高共識預測；加權策略從未翻轉多數決；信心策略（91.7%）在 3–2 與 4–1 split 上都信任 Z3（實質上將差閾值降低到 τ=3），每 fold 覆蓋 ensemble 37–52 個案例，而 tiebreaker 僅為 13–19。因為 Z3 在 valid 三段論上的準確率低（在 3–2 split 案例上僅 48.6%），將 Z3 權限延伸到 ensemble 通常正確的高共識案例會降低整體表現。

5.3 Tiebreaker 行為分析

Table 3 總結了跨五個 fold 聚合的 tiebreaker 機制行為。3–2 投票分裂發生在 7.9% 的案例（960 中的 76 例）。Z3 在所有 76 例上都產出了可用判決，得益於結構化輸出萃取將失敗降到接近零。在 30 個 Z3 覆蓋 ensemble 多數決的案例中，19 次正確翻轉、11 次錯誤翻轉，淨改善 8 個正確預測。

當所有五個 LLM 一致時，邏輯訊號通常足夠強以克服內容偏誤。3–2 split 表明某些模型被內容左右而其他模型沒有；Z3 獨立於語意內容解決這些案例。

聯盟分析顯示 Scout 在 53.9% 的 3–2 split 中出現在少數聯盟（76 中的 41 例），高於機率預期的 40%，暗示其對內容偏誤更敏感。相反地，Maverick+FS 最不常出現在少數聯盟（28.9%，76 中的 22 例），遠低於 40% 的機率基準，代表五個分類器中對內容效應最強的抗性。

5.4 Z3 的 Invalidity 偏誤

Z3-only 基線展現了明顯的 invalidity 偏誤：在 invalid 三段論上達到 97.6% 準確率（IB: 98.0%, IU: 97.2%），但在 valid 上僅有 52.2%（VB: 50.5%, VU: 53.9%）。因為 Z3 求解器本身在給定正確輸入時是確定性正確的，這種不對稱來自萃取步驟。當 LLM 在 valid 三段論中錯誤辨識命題類型或詞項邊界時，產生的 FOL 編碼幾乎總是打破了蘊涵鏈，導致 Z3 正確地回報（現已被破壞的）邏輯結構的不可滿足性。在 invalid 三段論上的萃取錯誤影響較小：三段論本來就不蘊涵，因此不同的結構錯誤不太可能意外產生 valid 推導。這種方向不對稱解釋了 Z3-only 在 valid 案例上的子群崩潰，也解釋了為什麼 tiebreaker 將 Z3 權限限制在低共識案例——糾正內容偏誤 ensemble 錯誤的好處大於萃取引起的 false invalidity 判決風險。

5.5 錯誤分析

三個主要錯誤來源：(1) Z3 萃取錯誤——不正確的結構萃取（如錯誤辨識的命題類型）產生錯誤的 Z3 判決，在所有 fold 中佔了 11 次錯誤翻轉；(2) 一致 ensemble 錯誤——全部五個 LLM 在強內容偏誤的三段論上一致錯誤，阻止了 tiebreaker 介入；(3) 退化前提——互相矛盾的前提觸發一致性檢查，Z3 交由 ensemble 處理（跨所有 fold 僅 1 例）。

萃取失敗分解確認結構化輸出管線內容中立：各合理性子群的失敗率均勻分佈。

全部 11 次錯誤翻轉都在同一方向：Z3 錯誤地拒絕了有效的三段論。其中 8 例涉及 unbelievable 內容，荒謬前提可能加劇了萃取難度。Figure 2 展示了三個代表性案例：(a) 雙重否定（"no ... not"）→ 類型 E 而非 A；(b) "belong to the class of" → 將 "class of birds" 切分為複合詞；(c) "Under no circumstances" → 可能反轉主詞-謂詞或錯失 E 類型。在每個案例中，Z3 求解器根據（不正確的）萃取結構產出了正確判決，確認瓶頸是萃取忠實度而非邏輯編碼。

6. 結論

我們提出了 FregeLogic，一個混合神經符號系統，透過 tiebreaker 機制將 LLM ensemble 與 Z3 形式驗證結合用於三段論有效性預測。我們的結果支持了「ensemble 意見分歧代表內容偏誤預測、形式邏輯可協助校正」的假設。在資料集的嵌套五折交叉驗證（N=960）中，tiebreaker 達到結合分數 41.88，比純 ensemble 提升 2.76 點，驅動力來自 16% 的內容效應下降與 0.9% 的準確率提升。採用結構化輸出 API 進行萃取將 Z3 失敗率從約 22% 降至接近零；包含亞里斯多德存在導入的兩步可滿足性檢查經過任務標註驗證。未來工作包括研究 tiebreaker 機制是否可泛化到其他推理任務，以及探索投票差截止值的自適應閾值。

限制

雖然我們的方法不涉及參數更新，但模型與提示選擇、融合策略選擇、以及 tiebreaker 閾值（τ=1）全部透過提供的資料集進行嵌套交叉驗證調參；沒有使用獨立測試集。此選擇程序增加了不小的設置複雜度：每個 fold 需要在 200 樣本內部子集上對全部 12 組（模型， 提示）組合打分，才能固定 top-5 ensemble，且最優配置在不同 fold 之間存在差異（附錄 D），因此本方法不能簡化為單一現成配方。Z3 管線依賴基於 LLM 的結構萃取，儘管有結構化輸出強制，仍可能產生語意不正確的萃取（如錯誤辨識的命題類型），這解釋了觀察到的 11 次錯誤翻轉。系統每則三段論需要六次 LLM API 呼叫（五次 ensemble 加一次萃取）與一次 Z3 求解，總計約 4300 tokens 與每實例 12.1 秒的序列延遲（平行 ensemble 呼叫時為 2.8 秒）；Z3 求解耗時不到 10ms。完整成本剖析（跨 18,722 次 API 呼叫）見附錄 G。我們未比較大型單一 dense 模型（例如 70B+）；在這個任務上，小規模下的架構多樣性是否優於單一較大模型，仍是未來工作的開放問題。
