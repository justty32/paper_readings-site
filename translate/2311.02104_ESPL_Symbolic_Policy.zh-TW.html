論文／訪談原始來源

利用可微符號表達式進行高效率的符號策略學習（ESPL）

Jiaming Guo、Rui Zhang 等（中科院計算所處理器重點實驗室 / 中科院軟體所 / USTC / Cambricon / 上海處理器創新中心 / UCAS），NeurIPS 2023

摘要

深度強化學習（DRL）在序列決策任務帶來廣泛進展。但神經網路策略的複雜性使其難理解、難在有限計算資源下部署。目前用緊湊符號表達式作為符號策略是獲得簡單可解釋策略的有望策略。先前符號策略法常涉複雜訓練過程與預訓練神經網路策略，低效且限制符號策略應用。本文提出高效梯度學習法 ESPL（Efficient Symbolic Policy Learning），以端到端方式從零學符號策略。引入符號網路作為搜尋空間、用路徑選擇器找緊湊符號策略；如此把策略表為可微符號表達式、以 off-policy 方式訓練進一步提效。此外，不像先前符號策略因複雜只能用於單任務 RL，我們把 ESPL 擴展到 meta-RL、為未見任務生成符號策略。實驗顯示本法生成更高表現的符號策略、大幅提升單任務 RL 資料效率；在 meta-RL，相較神經網路策略，所提符號策略表現更高、更高效、且有可解釋潛力。

1. 引言

DRL 中策略常實作為深度神經網路（龐大參數 + 數千巢狀非線性運算）→ 表示力強但非常複雜，難理解、難預測行為、難在有限計算資源部署。

學界與業界對可解釋簡單 RL 策略興趣高 → 有工作學符號策略（變數/常數/各種數學運算子組成的符號式，簡潔低複雜、更可解釋易部署）。GP 式限簡單任務（需給定/學到的 world model）、比 NN 表現降；DSP（SOTA，用 RNN agent 生符號策略並以 RL 訓 RNN）移除部分限制，但資料效率低（比傳統 RL 多數百倍環境互動）、多維動作空間需預訓練 NN 當錨模型（增複雜、限最終表現）、複雜到難用於 meta-RL。

本文提出 ESPL 以端到端可微方式從零學符號策略。組成：符號網路 + 路徑選擇器。符號網路可視為全套候選符號策略——其激活函數由各種符號運算子構成、參數視為符號式的常數。路徑選擇器自適應遮罩不相關連接，從符號網路選出適當的緊湊符號形式。所有模組設計為可微 → 策略表為可微符號表達式 → 以 off-policy 方式高效訓練、經梯度下降直接更新符號策略（無需額外 agent）。實驗上在數個 benchmark 控制任務，本演算法產出表現良好的符號策略、比 DSP 少數千倍環境互動。

meta-RL 是 RL 應用最重要技術之一（學跨任務共享內部結構以提升對未見任務的泛化）。問：能否利用符號策略 + meta-RL 為未見任務生成符號策略?先前符號策略法太複雜難與 meta-RL 結合，本文把 ESPL 與 context-based meta-RL 結合、開發 CSP（Contextual Symbolic Policy）。context-based meta-RL 強迫策略以「聚合經驗形成的 context 變數」為條件。CSP 中路徑選擇器依 context 變數決定符號形式；並引入參數生成器依 context 變數生成符號策略的常數。訓練建於 context-based meta-RL 法 PEARL 之上。所提 CSP 給少量軌跡即能為未見任務生成符號策略。相較神經網路策略，CSP 產的 contextual 策略泛化更高、更高效、有可解釋潛力。

貢獻：(1) 新梯度式符號策略學習演算法 ESPL（高效從零學）;(2) 用 ESPL 開發 meta-RL 的 contextual 符號策略（為未見任務生符號策略）;(3) 實證 ESPL 在單任務 RL 與 meta-RL 的增益。

方法

（符號網路：運算子當激活、參數當常數；路徑選擇器：自適應遮罩選緊湊式；全可微 → off-policy 梯度訓練。CSP：path selector 依 context 決定符號形式、parameter generator 依 context 生常數、建於 PEARL。）

實驗

  • 8 個連續控制任務：表現與 NN 策略及既有符號策略相當或更高；比 DSP 少數千倍環境 episode（Table 3，回歸法與 DSP 還需預訓練 NN 策略）→ 大幅提升符號策略學習的資料效率。
  • meta-RL（CSP）：比神經網路策略泛化更高、效率更高、有可解釋潛力。

結論

ESPL 是高效梯度式符號策略學習法，端到端從零學符號策略。8 個連續控制任務顯示與 NN 及既有符號策略相當或更高表現，同時大幅提升資料效率。結合 meta-RL 為未見任務生成符號策略——相較 NN 策略，所提符號策略表現更高、更高效、有可解釋潛力。希望 ESPL 啟發 RL/meta-RL 的符號策略未來工作；且因符號策略是白箱，利於理解與部署。
