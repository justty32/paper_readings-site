6. 相關工作

推測解碼首開以 draft model 加速之先。取得推測的方式各異：SpecInfer 用蒸餾／量化／剪枝得到的多個 draft model 共同推測；Medusa、OSD、EAGLE 用訓練得到 draft model／解碼頭；REST 用微調資料集本身作為資料存放區來查找推測；另有工作用 prompt 作參考。與這些不同，Lookahead Decoding 用 LLM 自身的平行生成能力產生推測。取樣方面，本文沿用 SpecInfer 維持輸出分佈的做法，但作用於多個互不重疊的 n-gram。

7. 結論

本文提出 Lookahead Decoding，在不改變輸出分佈下平行化 LLM 的自迴歸解碼；無需 draft model 即獲顯著加速，且能以「每步 FLOPs 的指數投入」換取「解碼步數的線性下降」。
