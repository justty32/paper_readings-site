摘要

大型語言模型（LLM）已被廣泛用於合成資料生成（synthetic data generation），大幅降低標註成本。然而多數既有研究把「合成」視為一組彼此孤立的任務，忽略了一個更根本的問題：模型能否透過累積過去任務的經驗並遷移到未來任務來學會合成？本文提出 StreamSynth——一個合成任務依序（sequentially）到達、且歷史任務的經驗能為未來合成提供有用訊號的新設定。為此，作者提出 SynLearner，一個讓合成模型在任務串流（task stream）上習得可重用合成經驗的通用框架。它不再為每個任務獨立生成資料，而是鼓勵模型探索多樣合成模式、從回饋中學習，並在任務演進時兼顧樣本品質與集合層級多樣性（set-level diversity）。多個基準上的實驗顯示，SynLearner 能有效利用早期任務的經驗提升後續任務的合成表現，展現一致的跨任務可遷移性（cross-task transferability）。

1. 引言

LLM 已廣泛用於指令微調、推理、對齊等場景的合成資料構造，能在擴大任務覆蓋的同時大幅省下人工標註。但多數方法只著眼於單一或孤立任務內提升生成品質，未探究「模型如何學會合成」——即從過去經驗中抽取可遷移的合成策略並泛化到未來任務。

作者將既有合成方法歸為兩種範式（圖 1）：（a）從零合成（synthesis from scratch）：LLM 依任務描述、提示或啟發式規則直接生成；（b）從種子合成（synthesis from seed）：以少量種子範例經改寫、演化或知識增強擴展。兩者都把合成當作靜態、任務專屬的程序，而非可跨任務累積遷移的能力。本文主張第三種範式（圖 1c）——從回饋中學習合成（learning from feedback）：合成模型透過回饋訊號與累積經驗持續精進其生成行為。

StreamSynth 設定：合成任務以串流形式依序到達，目標是訓練一個能獲取、重用、泛化合成經驗的模型；不假設固定或精心設計的任務順序。此設定貼近真實情境——任務隨時間演進、到達順序不可預測、且有效合成應善用先前經驗而非每次從頭來過。

三大挑戰：（1）多數合成管線是「生成後過濾（generate-then-filter）」，資料構造與明確回饋脫鉤，模型無法感知為何某些生成較佳；（2）缺乏在任務串流上累積與組織合成經驗的機制，難以形成穩定、可遷移的能力，尤其當後續任務與早期任務差異大時；（3）既有工作多在單一樣本層級評估，忽略對構造可重用語料至關重要的集合層級多樣性。

貢獻：（i）形式化 StreamSynth 設定，把合成資料生成視為任務串流上的經驗驅動過程；（ii）提出 SynLearner，以回饋（reward）驅動的最佳化跨演進任務串流精修生成行為；（iii）大量實驗證明合成經驗可跨任務、跨順序、跨模型規模、跨額外推理領域遷移。

2. 相關工作

LLM 合成資料生成：代表性工作含種子式指令自舉（Self-Instruct）、指令演化（WizardLM）、精簡合成語料（TinyStories），以及數學推理與對齊的專門方法（概念式問題合成、難度感知生成、多視角改寫等）。這些方法多把合成當作靜態、任務專屬過程，未顯式建模合成經驗如何跨演進任務累積重用。

持續學習與元學習：持續學習（GORP、FAPM、InsCL、SEEKR 等）研究模型在序列分佈偏移下如何保持預測表現；元學習則透過任務分佈或元訓練回合學習快速適應新任務。兩者都利用先前任務經驗，但主要目標是預測保留或快速適應，而非學習可遷移的資料合成行為。

與既有範式的比較（表 1）：作者沿五個維度比較——序列任務建模、合成導向目標、歷史經驗、回饋最佳化、未來任務泛化。靜態合成只做任務專屬生成；多任務合成能利用跨任務共享資訊，但假設任務同時可得而非序列到達；持續學習建模序列存取但目標是預測保留；元學習瞄準未來適應但假設可存取任務分佈。唯有 StreamSynth 同時滿足全部五項。

3. 問題定義

形式化設定：令 T = {T₁, …, T_N} 為合成任務序列。步驟 t 的任務 Tₜ 由提示分佈 Pₜ 與輸出空間 Yₜ 定義：Tₜ = (Pₜ, Yₜ)；提示 p⁽ᵗ⁾ ∼ Pₜ，樣本 x⁽ᵗ⁾ ∼ M(p⁽ᵗ⁾) 且 x⁽ᵗ⁾ ∈ Yₜ。在步驟 t，模型已從 {T₁,…,Tₜ₋₁} 學習並收到當前任務 Tₜ，未來任務不可見，因此必須在無未來資訊下更新合成行為。

學習目標：最大化對未見未來任務的期望合成效用：max_{Mₜ} E_{Tⱼ∈T, j>t}[U(Mₜ, Tⱼ)]，其中效用 U 同時衡量樣本層級品質與集合層級多樣性。

4. SynLearner 框架

SynLearner 含三個功能組件：Diversity-Aware Initialization（DAI，多樣性感知初始化）、Efficient Fine-Tuning（EFT，高效微調）、Hierarchical Reward Optimization（HRO，階層式回饋最佳化）。DAI 提供多樣的任務起始條件；EFT 與 HRO 構成由雙層回饋訊號驅動的統一最佳化管線（圖 2）。

4.1 多樣性感知初始化（DAI）

  • 動態提示（dynamic prompting）：以共享基礎模板 p_base 搭配任務相關的槽位（slot）賦值 vₜ 構造提示 pₜ = p_base(vₜ)，槽值 v_{t,k} ∼ V_k 抽樣，並用一致性約束 Cₜ 過濾語意不連貫的槽位組合——在保留可控多樣性的同時確保語意一致。
  • 演化式擴展（evolutionary expansion）：沿兩維度擴展——**深度導向（depth-oriented）**增加提示內部複雜度；**廣度導向（breadth-oriented）**擴展跨領域、風格、問題形式的覆蓋。所得提示池與 §4.2 的回饋設計對齊。

4.2 雙層評分策略

樣本層級評分：對任務 Tₜ 下合成的樣本 x⁽ᵗ⁾，樣本回饋 RSₜ(x⁽ᵗ⁾) = γ₁·S_struct + γ₂·S_fluent + γ₃·S_rel（γ₁+γ₂+γ₃=1，各分數正規化到 [0,1]）：

  • S_struct（結構有效性）：規則式檢查輸出格式、必要欄位、畸形表達式；
  • S_fluent（流暢自然度）：α·語言模型似然 + (1−α)·風格統計（句長、標點平衡、表層連貫）；
  • S_rel（任務相關性）：θ·任務專屬分類器機率 + (1−θ)·關鍵詞匹配，依當前任務實例化。

集合層級評分：在小批次 Bₜ = {x₁,…,x_m} 內計算局部區辨度（distinctiveness）。對每個樣本，以句向量餘弦相似度與批內其他樣本比較，用正規化的鄰近權重（proximity weights）估計局部密度 Dₜ，再轉為區辨分數 DSₜ(x) = exp(−k·Dₜ(x))。局部密度越高、區辨分數越低，藉此懲罰冗餘樣本、鼓勵多樣但仍與任務相容的生成。

4.3 階層式訓練程序

SynLearner 以「EFT → HRO」兩階段最佳化：

  • 階段一 EFT：對每個到來任務 Tₜ，用動態提示樣本（加可選真實範例）構造 D_sft，做標準監督微調，從上一模型 Mₜ₋₁ 得到 EFT 初始化模型 M̃ₜ；提供基本的任務遵循與結構有效生成能力。
  • 階段二 HRO：從 M̃ₜ 出發，用階層式回饋做強化學習（GRPO 框架）。給定提示 p⁽ᵗ⁾ 生成 x⁽ᵗ⁾，計算 r_sample = RSₜ(x)、r_set = DSₜ(x)，合成總回饋 r_total = λ·r_sample + (1−λ)·r_set（λ 平衡樣本品質與集合多樣性），據此更新 Mₜ ← RL-Update。隨任務序列推進，模型序列 {Mₜ} 逐步累積合成經驗供未來任務使用。（附錄 Algorithm 1/2 給出完整流程。）
