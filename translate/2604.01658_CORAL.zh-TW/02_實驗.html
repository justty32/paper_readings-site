4. 實驗

4.1 設定

  • 任務：6 個數學最佳化（circle packing、Erdős overlap、MMD 等）+ 5 個系統最佳化（EPLB、PRISM、LLM-SQL 等），來自 EvoX 與 TTT-Discover suite。再加兩個壓力測試：Anthropic Kernel Engineering（VLIW SIMD tree-traversal、官方最佳 1,363 cycles）與 Polyominoes packing（Frontier-CS 172 題中最難）。
  • Baseline：OpenEvolve、ShinkaEvolve、EvoX（同種子程式、evaluator、預算）。單 agent 與壓力測試用 Claude Opus 4.6 + Claude Code；多 agent 數學/系統 suite 用開源棧（MiniMax M2.5 + OpenCode）驗證泛化。
  • 預算：3 小時 wall-clock 或 100 迭代（baseline）。CORAL 跑 baseline 中最短時長。壓力測試跑到收斂。4 獨立 trial 平均。

4.2 自主演化勝固定演化搜尋

CORAL 在全部 11 任務取得最佳最終分數，8 個新 SOTA。改善率 3–10× baseline、僅需 5–20 次評估收斂 vs baseline 60–100 次。CORAL 不浪費評估在無產出的候選上——因為 agent 自主分析過往 attempt 與回饋後決定下一步，而非被動遵循固定突變管線。

4.3 多 Agent 演化推展搜尋前沿

四 agent 協同演化在單 agent 已最強的基礎上再推進，特別是壓力測試（單 agent 會早期 plateau）：Kernel Eng. 1,350 → 1,103 cycles（多 agent），Polyominoes 80.2 → 84.2。開源棧上 multi-agent gains 同樣成立。多 agent 勝過獨立 best-of-4。

4.4 分析與消融

為何自主演化有效：

  • 本地驗證：有本地測試的 attempt 改善率較高（如 Kernel Eng. 57% 測試率→47% 改善率 vs 平均 43%）。編譯類任務（Transaction 61%、Kernel Eng. 57%）本地執行常攔截編譯失敗後再提交。
  • 知識累積：進階任務知識創建 10×+（0.55–0.68 vs 0.05/attempt），存取知識的改善率 55%（Kernel Eng.）vs 26%（標準任務）。Kernel Eng. notes 辨識架構瓶頸（如 VALU、WAR dependency）、Polyominoes 有 "what NEVER worked" 目錄避免重訪失敗策略。

為何多 agent 組織有效：

  • 跨 agent 資訊傳遞：Kernel Eng. 36% attempt 用他人 commit 為父代，改善率 17%（全體 9%），66% 新記錄源自跨 agent parent。Polyominoes 87% 輪次引用他 agent 知識。
  • 探索多樣性：每 agent 策略詞彙過半獨特（Jaccard 0.31–0.43）。
  • 貢獻平衡：Kernel Eng. 四 agent 各貢獻 130–165 attempt、10–16 次改善，記錄均分（14/15/10/15）。

消融：拔除 notes/skills → Kernel Eng. -18.6%。Co-evolution vs best-of-4 獨立：協同演化全勝（非僅多算力）。

5. 結論

CORAL 把剛性演化搜尋啟發式換成控制 RETRIEVE / PROPOSE / EVALUATE / UPDATE 的自主 agent，透過共享持久記憶協調，跨任務大幅提升效能。四 agent 發現單一 agent（即便四倍算力）找不到的解。更廣義地，自主 agent 正成為開放式發現的承諾範式。CORAL 可作為系統性探索研究、強 baseline 框架、與可擴展基礎設施，支持未來自主發現系統的發展。

附錄要點

  • Limitations（A）：依賴 frontier 模型難以本地部署、所有 agent 初始同質缺 bootstrap 多樣性、假設有合理 evaluator（對許多開放式問題 evaluator 自身也需協同演化）。
  • Polyominoes SOTA（B.1）：單次 baseline 56.0% 覆蓋率；開 web search 的四 agent CORAL 達 89.4%（超越原 SOTA 87.0%）。
  • 軌跡統計（B.2）：標準任務本地測試率、知識存取率與進階任務對比（見表 4）。
  • 實作細節（C）：完整架構圖與各模組（AgentManager、HeartbeatRunner、GraderInterface、WorkspaceSetup 等）說明。
