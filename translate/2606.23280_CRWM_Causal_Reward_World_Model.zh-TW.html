論文／訪談原始來源

CRWM：為自動化技能生成做零樣本 Reward 設計

摘要

Automated Reward Design（ARD）想用語言驅動的 reward 函數合成取代人手 reward 工程。但現有 LLM 方法本質上相關性驅動，靠對每個任務反覆用環境 feedback 精煉 reward 假設——不僅推理低效，還讓 LLM 易受「語意合理但因果虛假」的 reward 元件影響、導致無效優化。為此我們提出 Causal Reward World Model（CRWM），透過離線多任務互動資料預訓練，顯式建模「候選 reward 元件 ↔ 任務目標物理變數」的因果拓撲關係。基於 coarse-to-fine 預訓練策略，我們引入 Joint Optimization Module，整合 Explicit Mechanism Decoupling 與 Confidence-Aware Soft Fusion，用 micro-level 軌跡精煉粗結構先驗、建出穩健可詮釋的因果骨架。推論時 LLM 把 CRWM 當任務無關的因果先驗約束 reward 生成，達成 zero-shot reward 設計。連續控制 benchmark 上 CRWM 不需 feedback 精煉就生成可執行 reward，大幅降低取得新技能的設計延遲、同時匹敵或勝過 SOTA，並跨未見任務與不同機器人形態強泛化。

I. 引言

賦予機器人自主技能習得能力是 embodied AI 的長期目標，而 RL 的 reward 函數設計一直是難題。LLM 帶起 ARD（給任務描述 → 生成候選 reward 元件 → 環境 feedback 迭代精煉）減輕人手依賴。但這些方法全靠 trial-and-error：LLM 挑「與任務相關」的元件，卻可能虛假相關：

  • ShadowHandLiftUnderarm（雙手舉鍋）：LLM 把 velocity（鍋的瞬時舉升速度）當 reward——語意上跟「lifting」相關，但在連續物理互動中是高頻、因果模糊訊號，引入嚴重梯度噪聲 → Optimization Collapse。
  • ShadowHandScissors：LLM 用 scissors_open 當 reward → agent 鑽漏洞讓剪刀微開不停累積 reward 而不達真目標（reward hacking）。

這些例子顯示：語意合理的 reward 元件若不對齊有效因果拓撲，會遮蔽真任務目標。而 LLM 在因果歸因與反事實推理的弱點，使迭代式方法難一致改善。

IV. 方法

  • A. Structural Prior Extraction via Causal Foundation Models：用因果基礎模型從多任務資料抽粗粒度結構先驗（reward 元件與物理變數的因果拓撲）。
  • B/C. Joint Optimization Module + Causal-ARD：
    • Explicit Mechanism Decoupling（EMD）：顯式解耦各因果機制。
    • Confidence-Aware Soft Fusion：依信心軟融合粗結構先驗與 micro-level 軌跡證據，精煉成穩健因果骨架。
    • Causal-ARD：推論時 LLM 以 CRWM 因果骨架為任務無關先驗，單次生成可執行 reward（ESI=0）。

V. 實驗

  • 設定：所有 LLM 方法（含本文與 baseline）用同一 foundation model DeepSeek-v3 以隔離架構增益。benchmark：Dexterity 套件 + ManiSkill2（跨任務與機器人形態）。
  • Baselines：ZS-LLM（純語意、單次生成 reward，無因果引導/無 feedback）、Eureka（演化式 ARD，LLM 突變精煉、靠密集環境 feedback）、URDP（雙層優化，LLM 結構精煉 + 不確定性感知 Bayesian 優化，比 Eureka 省樣本但缺顯式因果機制解耦）。
  • 指標：Success Rate（SR） + **Evolutionary Search Iterations（ESI）**＝初始生成後的 feedback 精煉輪數（CRWM=0）。

結果：

  • 全部未見任務上，CRWM 以 ESI=0 達到與 SOTA 迭代法相當、避開 Eureka/URDP 的昂貴 trial-and-error;ZS-LLM 在動態/長視界任務明顯較差。
  • 六個未見靈巧操作任務：CRWM 勝多迭代 Eureka（4 ESI）並匹敵 URDP（1–4 ESI 收斂），自己 ESI=0。
  • 消融：CRWM w/o Prior 全面變差（純離線 transition 不足以穩定估結構）；移除 EMD 明顯不穩。
  • 跨形態/跨環境（ManiSkill2）：zero-shot SR PickCube 0.64、OpenCabinetDoor 0.89、TurnFaucet 0.80;Eureka 要多達 6 ESI 才達近似且更不一致 → CRWM 捕捉可遷移因果結構，能在大幅 domain shift 下構造 reward 而不需迭代互動。
  • Sim-to-Real：用 CASBOT W1 移動操作臂 + Offline Trajectory Evaluation——人遙操運動學軌跡餵進生成的 reward 評估對齊，獨立於 RL 優化與 sim-to-real 落差。

VII. 結論

CRWM 把因果世界模型當任務無關先驗約束 LLM 的 reward 生成，達成 zero-shot、可執行、可遷移的 reward 設計，把相關性驅動的迭代式 ARD 轉為因果驅動的單次生成，匹敵或勝過 SOTA 同時大幅降低設計延遲。限制詳見論文 Limitations 章。
