局限

  • 僅涵蓋 Python/Java/SQL，不保證泛化至靜態型別語言、多檔案專案或外部 API 任務。
  • SQL 僅 270 題，統計力有限。
  • 所有模型皆閉源（OpenAI/Google），不含 Llama/Mistral/Qwen 等開源模型。
  • 正確性基於既有測試案例，可能漏掉邊界錯誤。
  • 採樣法增加延遲與成本。
  • 等價法官與生成器可能重疊（同為 Gemini），但執行驗證（附錄 D）與法官消融（附錄 F.2）緩解此疑慮。

完整實驗數據表（AUROC、ECE、Brier Score）、混合方法結果、群集分布圖、執行驗證細節、成本分析、消融實驗（採樣數 m、等價法官敏感度、回應順序）及促發模板詳見論文附錄 A–G。
