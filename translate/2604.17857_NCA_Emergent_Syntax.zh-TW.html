論文／訪談原始來源

論語法經由局部互動而湧現

Zichao Wei

摘要（精譯）

句法處理能否純粹從局部互動自發湧現？本文在一個最小系統上給出具體實例：一個 18,658 參數的二維神經細胞自動機（NCA），僅由 1-bit 邊界訊號監督，訓練於某算術運算式文法的成員判定問題。訓練後，其內部 L×L 網格自發自組織成一個有序、空間延展的表示，我們命名為 Proto-CKY。此表示滿足句法處理的三條操作準則：表達力超越正則語言、結構性泛化超出訓練分布、內部組織與文法結構量化對齊（Pearson r≈0.71）。它在四個上下文無關文法上各自獨立湧現，並在擾動後自發再生。Proto-CKY 在功能上對齊 CKY 演算法，但形式上與之不同：它是一個物理原型，是把數學理想在物理基底上的具體實例，兩者間的系統性距離本身攜帶關於基底的資訊。

1. 核心問題

不靠全域控制器、不靠顯式解析器架構，僅以局部更新規則加上極弱監督（1 bit：運算式是否合法），能否讓最小系統長出能判定字串是否屬於某文法（且該文法超越正則）的內部結構？

2. 方法

  • 基底：18,658 參數的 2D NCA，cell 以局部規則互動。
  • 監督：僅 1-bit 邊界訊號（成員與否）。
  • 任務：算術運算式文法的成員判定（上下文無關語言，表達力超越正則）。
  • 湧現結構 Proto-CKY：訓練後 L×L 網格自組織成有序、空間延展的表示，功能上對齊 CKY 解析演算法（自底向上、以區間填表判定 CFG 成員），但形式上是其「物理原型」而非精確實現。

  nca --> proto["L×L 網格自組織<br/>→ Proto-CKY 有序表示"]
  proto --> out["1-bit 邊界訊號<br/>(是否屬於文法)"]
  proto -.量化對齊 r≈0.71.-> cky["CKY 解析結構（理想）"]

3. 結果

句法處理的三條操作準則同時被滿足：

  1. 表達力：超越正則語言。
  2. 結構性泛化：泛化到超出訓練分布的運算式。
  3. 內部組織對齊文法：Proto-CKY 的空間組織與文法結構量化對齊，Pearson r≈0.71。

此外：在四個上下文無關文法上各自獨立湧現 Proto-CKY；受擾動後自發再生該有序表示。

4. 局限

  • 為最小系統的概念驗證，聚焦算術運算式文法，尚未擴及自然語言或更大文法。
  • Proto-CKY 與 CKY 形式上不同——是近似的物理原型而非精確演算法；其與理想的系統性差距尚待刻畫。
  • 1-bit 監督下湧現機制的細節與可控性仍為開放問題。

5. 意義

本文以一個極小、極弱監督的 NCA，展示句法／解析結構可經局部互動自組織湧現，並提出「物理原型 vs 數學理想」（Proto-CKY vs CKY）這一看待湧現計算的視角：基底（NCA）不只是承載演算法，其物理性質會在與理想的偏差中顯影。
