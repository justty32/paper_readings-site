5. 結論

LLM+ASP 整合 LLM 的自然語言能力與 ASP 的形式推理。近期推理模型能有效把複雜問題翻成 ASP 程式交求解器解，核心強項在求解器結構化回饋驅動的迭代自我修正迴圈。此自修能力（再以精簡 ASP 參考增強）是效能增益主驅動（平均相對提升 52%）。對含預設與例外的非單調推理任務，ASP 的理論基礎提供單調形式體系難複製的固有優勢。

LLM 雖能有效產 ASP，但用參考的增益暗示含更多 ASP 材料的更好 LLM 訓練可帶來大幅提升。願景：LLM 成為通往多種形式推理器的彈性介面，把複雜邏輯任務高效委派以拓展應用範圍。

限制

  • 模型能力依賴：效能強依底層 LLM 推理能力。強模型（Pro）<1 次修正即高準確，非推理型（DS-V3）需 >5 次仍低——自我修正補不了弱底模。
  • 除錯不可滿足程式：Unsat 時求解器回饋極少難定位矛盾；未來可用 unsat-core 萃取或 Spock/Ouroboros。
  • 計算成本：核心實驗 LLM API 約 $3,800 直接費用，含前測/失敗/開發估計 $4,200。
  • 範圍有限：聚焦約束滿足、規劃、非單調推理；對更廣 NLP、更模糊或開放任務的適用性仍待探。

附錄（要點）

  • B Prompts：生成器 prompt 與人類可讀格式化 prompt。
  • C LLM+ASP 範例：完整三輪 trace（Input/Output/Clingo Feedback），示範自我修正迴圈。
  • D–F 擴展分析：參考效果、迭代修正、失敗模式。
  • G 與 Hao et al. (2025) 比較：其方法零樣本化後退化。
  • H 參考生成：精簡參考內容與生成方法。
