論文／訪談原始來源

ARCANA：用於 ARC-AGI-2 的反思式多 Agent 程式合成框架

摘要與問題

ARC 題只給少量 input-output grids，卻要推得能精確執行的組合規則。純文字式思考不保證能同時符合所有示例。ARCANA 因此把一題視為多回合 episode：專門模組看物件、提程式、跑程式、診斷失敗，再把訊息放在共用可微黑板中迭代。

III–IV. 四個 agent

PGA 用 RoPE-2D 的六層 Transformer 編碼格子，再以 16 個 Slot Attention slots 找物件；其重心、框、面積、色彩與物件關係形成 scene graph，跨示例 Transformer 產出 task 表示。HGA 是條件 VAE 加自回歸 decoder，從 task 與上一輪回饋采樣 typed DSL；k-DPP 讓候選兼具程式機率與 latent 距離多樣性。

SEA 的 47 個 DSL primitives 包含幾何、顏色、物件、結構和控制。它在每個 demonstration 執行候選，使用像素精確、cell accuracy、one-hot SSIM 的組合分數，並編碼 execution trace。RRA 將預測與目標的錯誤圖送入 ConvNet；又逐步把 primitive 換成 identity，若移除某步提升驗證分數便增加其 blame。它綜合錯誤、被責怪的操作與 trace，改變下一輪 HGA 的 latent prior。

Meta-controller 用 GRU 讀黑板與目前最佳驗證值，按有限預算選擇哪個 agent 啟動、分多少算力及何時停止；首次全驗證成功、進步太小或剩餘成本不足即終止。另有對 PGA attention 以示例做 50 steps、rank-8 LoRA 的 test-time adaptation。

訓練與實驗

RTO 損失混合 focal grid reconstruction、VAE ELBO、controller 的 REINFORCE 與 contrastive refinement。作者稱遵守 4×L4、12h、offline 條件；main table 在所謂 120-task semi-private set 報 ARCANA 32.5% task accuracy，並以 public set 消融指出 RRA（35.8→25.0）與 TTT LoRA（35.8→28.3）最顯著。這些數字是論文自報。

閱讀結論

系統的工程想法很清楚：感知表徵、程式搜尋、可執行驗證與失敗訊號分工，並讓反思改變下一輪候選分布。不過它同時引入大量可訓練元件、TTT 與成本調度，重現需要完整資料、DSL、訓練與評測細節。更重要的是，本次未驗證其競賽約束、semi-private 結果或「open-source SOTA」聲明，應視為待複現的方案而非已定論。
