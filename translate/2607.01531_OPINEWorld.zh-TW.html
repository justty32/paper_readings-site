論文／訪談原始來源

OPINE-World：ontology-error 優先互動探索

摘要與問題

作者處理 ARC-AGI-3：agent 只能見到 rendered frame，物件詞彙、動作意義、目標都未給，完成關卡的訊號稀疏且動作要計分。深度世界模型彈性大但耗資料；程式合成模型較可檢查，卻通常假定已有物件詞彙。OPINE-World 以線上互動建立物件導向程式模型，並以 ontology error 選擇探測。

2. 設定

作者以 object-oriented MDP 描述遊戲。感知端不給環境原始碼或語義物件，只提供從畫面推得的結構；reward 只在 level advance 出現。世界模型含轉移與 goal predicate，驗證的標準是是否完全重播歷史 transition，不是看起來合理。

3. 方法

模型以 type 分解：每個物件按局部 context 執行自己的 rule，再收集效果。這保留局部性，讓一種物件的錯誤不必推翻整套 dynamics。acting agent 做目標導向的互動與自然語言假說；modeling agent 將假說合成程式，critic 以弱泛化情況挑戰它。兩者共用 replay buffer。

候選程式若不能逐筆重現記錄就拒絕；失配會產生 counterexample，作為下一次修補限制。為防止一次雜訊不停重寫，系統會稍等更多反例；兩輪修補無改善則停止，待新資料才再試。ontology error 根據各 type 的 effect signature 與現有 rules 的相容性估計型別不足，將探測轉向「哪一物件其實不是這個 type」的疑點。

verified model 可做有限前向規劃，但先從已通關的 entry state 離線檢查。live 執行時，每一步都拿實際後繼和預測比對；一有 mismatch 就停止計畫並交回 agent。因此模型不是一次通過後永久可信。

4. 實驗

25 個公開遊戲上，OPINE-World 使用 Claude Opus 4.8，沒有 per-game training 或示範；報告 action-efficiency 78.4，完成 20/25。單 agent coding baseline1（GPT-5.5）為 63.8、14/25。六個 baseline 未解的難遊戲，baseline 在失敗前共花 10,874 動作；OPINE 解完僅 2,578。共同解出的 13 遊戲兩者接近，優勢主要是難遊戲覆蓋與不在難以建模者上浪費動作。

這不隔離 base model、雙 agent、型別診斷和其他工程選擇，作者也未提供逐元件 ablation。Vision 有接觸評測遊戲的離線訓練，不能和 no-training 系統同列；WorldCoder 與幾個 neural latent model 在本文預算下均為零解。

5–7. 關係、限制與結論

相較既有 program-world-model，本文強調 acting/modeling 分工、資料驅動的物件／角色層、exact replay admission，以及每步 live validation。限制是適用於 structured state；原始像素、隨機或部分可觀測環境尚未處理。本文提供的是一個可審計的探索迴路，而非已證明普遍有效的 ontology discovery 定律。
