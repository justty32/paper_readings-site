論文／訪談原始來源

神經符號合規：整合 LLM 與 SMT 求解器於金融法規自動化分析

摘要

本論文提出一個神經符號合規框架（Neuro-Symbolic Compliance Framework），用於自動化、可驗證的金融法規分析。框架結合大型語言模型（LLM）的自然語言理解能力與可滿足性模理論（SMT）求解器（具體使用 Z3）的形式嚴謹性，橋接非結構化法律文本與形式邏輯驗證之間的鴻溝。

與純神經方法——常受邏輯不一致、幻覺與缺乏自我驗證所困——不同，本框架以 LLM 將法規文本與案件事實翻譯為 SMT 表述，再以 SMT 求解器執行形式一致性檢查、以 unsat core 精準定位法規違反，並以 MaxSAT 優化計算恢復合規所需的最小事實修正。

核心技術組成

1. 混合法律 RAG 管線

檢索管線結合多階段策略：(1) BM25 詞彙搜尋與向量搜尋（text-embedding-ada-002），覆蓋 75 部法規、3,753 條條文的資料庫；(2) Cross-Encoder 重排序（bge-reranker-v2-m3）結合 LLM 相關性過濾，自動提取上下文支持的法律條款。此設計確保輸入 SMT 階段的法條既完整又精確，減少不相關條文干擾形式化品質。

2. 形式 SMT 約束合成

法規條文被編碼為不可變更的硬約束（H_law），代表法律強制要求——例如保險法第 143-4 條與第 143-6 條的資本適足門檻。案件事實則編碼為軟約束（H_case），代表可調整的事實狀態——例如淨值比、改善計畫提交狀態。案件中未明確提及的變數保留為自由變數，供求解器在修正階段探索可能的事實調整空間。

3. 驗證與合規恢復

管線執行三階段推理：(1) 法規一致性檢查：驗證法規內部無邏輯矛盾（SAT）；(2) 案件違法性檢查：測試案件事實是否觸發法規違反（預期 UNSAT），並提取 unsat core 隔離具體違法條款與涉案事實；(3) 合規恢復：使用 Z3 的 Optimize() 模組進行 MaxSAT 優化，計算將 UNSAT 不合規狀態轉換為 SAT 合規狀態所需的最小事實變更集合（Δ）。最小干預原則確保修正建議在恢復合規的同時，盡可能保留原始案件事實。

4. 模組化多代理平台

系統由五個專業 AI 代理組成：(1) Rewriter Agent：規劃查詢並檢索前例案件；(2) Execute Agent：調用 SMT 求解器執行形式驗證；(3) Coding Agent：在 SMT 語法或邏輯綁定錯誤時執行自我修復；(4) Analysis Agent：將求解器輸出與 Δ 修正軌跡轉換為人類可讀的合規報告；(5) Instruction Rewriter 與 Modify Constraint 模組：支援人機互動的規則修改。

實驗結果

系統在台灣金融監督管理委員會（FSC）的 87 件真實裁罰案件上進行實證評估：

主要貢獻

  1. 可驗證的法律 AI：以可證明的符號驗證取代啟發式 LLM 推理，提供可審計性與法律可辯護性。
  2. 邏輯驅動優化：計算恢復合規所需的最小必要事實調整（Δ），遵循法律最小干預原則。
  3. 高效自我修復架構：推理速度較純 LLM 快 100–300 倍，並內建自動修復迴路處理形式約束代碼錯誤。
  4. 跨管轄框架：雖以台灣 FSC 案例示範，管線本身與法域無關——替換檢索語料庫與 prompt 模板即可適應普通法系及國際監理框架。
