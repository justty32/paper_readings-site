摘要

仇恨言論偵測通常被框定為直接的二元分類問題，然而仇恨言論實質上是一個複合概念，由多個交互的因子定義，且這些因子隨法律框架、平台政策與標註指南而異。因此，監督式模型常在特定資料集的定義上過擬合，並在領域轉移與標註雜訊下表現出有限的穩健性。

本文提出 xList-Hate——一個診斷框架，將仇恨言論偵測分解為一組基於廣泛共享規範標準的顯式概念層二元檢查問題。每個問題由一個大型語言模型（LLM）獨立回答，產生一個二元診斷表徵來捕捉仇恨內容特徵，而非直接預測最終標籤。這些診斷訊號再交由一個輕量、完全可解釋的決策樹進行聚合，產出透明且可審計的預測。

我們跨多個仇恨言論基準資料集與多個模型家族進行評估，將其與零樣本 LLM 分類以及域內監督微調進行比較。雖然監督方法通常最大化域內效能，我們的方法始終改善跨資料集穩健性與領域轉移下的相對效能。此外，對分歧案例的質性分析提供證據表明，此框架對某些形式的標註不一致性與情境模糊性較不敏感。關鍵的是，此方法透過顯式決策路徑與因子層級分析實現細粒度可解釋性。

我們的結果表明，將仇恨言論偵測重新框定為診斷推理任務而非單體分類問題，為內容審核提供了一個穩健、可解釋且可擴展的替代方案。

1. 引言

仇恨言論已成為線上溝通的核心挑戰。自動偵測對內容審核、法規遵循與弱勢群體保護至關重要，然而仇恨言論缺乏普遍接受的單一定義——法律框架、平台政策與學術分類學在定義與操作化方式上差異重大。仇恨言論並非單體現象，而是一組相關概念因子的集合：鎖定受保護群體、貶損或去人化語言、煽動歧視、呼籲暴力等。這種定義多樣性給資料集標註與模型評估引入了重大模糊性。

LLM 的零樣本/少樣本 prompt 提供了靈活性，但實務上常產生不一致的預測，且決策不透明而難以被正當化。監督微調雖域內效能較強，但跨資料集泛化普遍不佳——模型學到的是特定資料集的標註偏差與詞彙人工製作物，而非穩健的概念學習。

本文的替代方案：不讓模型直接預測是否為仇恨言論，而是將任務分解為十個二元問題，每個問題捕捉一個與仇恨言論相關的獨立概念因子（基於法律定義、平台政策與學術框架）。對每個輸入文本，LLM 獨立回答十個問題，產出一個結構化診斷剖面的二元向量。最終分類交給一個輕量且完全可解釋的模型（決策樹）在這些二元表徵上進行。

此設計刻意將語意判斷與分類決策分離：LLM 的表達能力用於評估定義明確的概念準則，最終決策邏輯保持透明且易於解釋。產出的管線是模組化的、訓練階段低資源的，且本質上可解釋。

2. 相關工作

2.1 仇恨言論定義與標註實踐

  • 定義不穩定性是核心挑戰：法律、機構與學術定義在範圍與執法閾值上差異巨大；歐洲偏重煽動，美國受言論自由傳統限制；大型文獻映射發現哪些身份被視為「受保護」、哪些行為算仇恨存在系統性偏差（種族/宗教多、性別/性傾向/身心障礙少）
  • 這種異質性直接傳播到實證研究：跨資料集評估顯示域外效能大幅下降，許多 SOTA 增益來自資料集特定人工製作物而非穩健概念學習；Transformer 模型過度依賴詞彙「關鍵字」線索
  • 既有工作確立：(i) 定義廣泛多樣；(ii) 資料集繼承此多樣性；(iii) 監督偵測器學到資料集特定捷徑

2.2 監督式仇恨言論分類

  • 主流範式將仇恨言論偵測框定為二元或多類分類，跨語言、模態與架構取得高域內準確率，但代價是穩健性與概念透明度：對標註雜訊、資料集特定定義與詞彙相關性敏感，且需昂貴重訓
  • 可解釋性多用事後歸因（SHAP/LIME），但本質上受限於表層文本特徵，無法揭露去人化、煽動等抽象因子如何交互產出決策

2.3 推論式仇恨言論分類

  • LLM 零樣本/少樣本推論減少了對標註資料的依賴並改善了情境敏感度，但不同 LLM 對相同內容常明顯分歧，表現為系統性偏差、可靠性低於人類
  • 混合方法（LLM 產 rationale → 訓練編碼器分類器）仍是全監督、域內評估、解釋性間接
  • 模組化分類學的文獻顯示零樣本 LLM 效能對定義組件的取捨敏感——定義本身即隱含建模選擇

2.4 可解釋的仇恨言論偵測

  • 既有可解釋性多作事後診斷附加層，token 級歸因和事後 rationale 不暴露抽象因子如何交互產出決策
  • 此缺口促使將可解釋性嵌入模型架構本身的方法
