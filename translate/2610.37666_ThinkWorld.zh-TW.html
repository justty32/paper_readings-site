論文／訪談原始來源

ThinkWorld：以世界想像強化動態鏈推理

第 1–2 節：問題與定位

機器人推理不只要描述目標，也須理解動作如何改變世界。ThinkWorld 在訓練時加入離散動態鏈（Chain-of-Dynamics，CoD），將動作相關運動連到未來視覺狀態，再以預測與觀察的一致性強化推理。它結合人類影片與有動作標註的機器人資料；部署時不生成推理鏈或未來預測。（§1–2）

第 3.1–3.2 節：動態鏈與動作策略

輸入含語言指令、視覺歷史、當前多視角影像，以及可用的本體感覺。VLM 先產生 CoD，再以其條件預測未來觀察的潛在視覺特徵。人類手部與機器人運動使用共同的離散表示，但保留不同原生動作空間。

CoD 用 FAST 風格 tokenizer，把一秒的手腕平移及旋轉增量編成離散序列；單手六維、雙手十二維，不含夾爪。詞彙量 2,048；它不是可直接執行的原生控制指令。輸入歷史最多 16 張、2 Hz，未來目標約一秒後，超過 50 毫秒時間誤差則遮罩監督。

骨幹為 Qwen3-VL-2B-Instruct，目標特徵由凍結 DINOv3 ViT-H/16+ 擷取。64 個未來查詢 token 經投影器預測 196 個 DINO patch；未來影格只當目標，不作輸入。MolmoAct2 式動作專家以 flow matching 學機器人動作，只讀取 VLM 輸入 token 的表示，不直接讀 CoD 或未來查詢。（§3.1–3.2、附錄 A.1–A.2）

第 3.3 節：以影片未來觀察提供強化訊號

先用機器人動作標註與人類手腕軌跡標註建立 CoD 監督，結合未來特徵損失與輔助視覺問答訓練 VLM，再凍結 VLM 訓練動作專家。世界想像 RL 每個輸入取四個 CoD 候選，評分其條件化未來預測與影片真實未來的特徵相似度。

獎勵等權混合全 patch 平均與運動加權平均；權重根據目前至觀察未來的特徵變化估計，減少靜態背景影響。GRPO 使用候選間的相對獎勵，只更新語言模型；未來投影器和動作專家凍結，另加入少量標準 CoD 監督。

此過程不把候選動作送到環境執行，也不需要該影片的動作標註，但需要實際未來影格。獎勵衡量預測一致性，不是實機任務成功或在線環境回饋。（§3.3、附錄 A.4–A.6）

第 4.1 節：資料與部署

人類資料包括 EgoDex、EgoVerse；機器人資料包括 Bimanual YAM、DROID、RoboCOIN、Bridge、RT-1、BC-Z。這不是完全無機器人示範學習。部署時只用受訓後的 VLM 輸入表示與動作專家，既不自迴歸生成 CoD，也不執行未來特徵預測。（§4.1、附錄 A.3–A.4）

第 4.2 節：真機分布外測試

Bimanual YAM 使用雙臂與三台 RGB 相機。顏色配對、掛杯、分類分別收集 60、45、100 段機器人訓練示範，各訓練一個任務專屬策略。ThinkWorld 的完整 rollout 成功次數如下，不是子步驟成功率：

任務 ID OOD
顏色配對 30/30 24/30
掛杯 15/15 15/15
分類 15/15 13/15

ID 共 60/60，OOD 共 52/60；120 次試驗的微平均為 93.3%，六個任務×條件成功率的宏平均為 94.4%。MolmoAct2 對應微平均 60.0%、宏平均 62.2%。分母不同，兩種平均不能互換。（§4.2、附錄 B.3、C.1，表 6）

第 4.3 節：人類影片的技能組合

烤箱設定以 100 段機器人原子技能示範，加 90 段人類完整任務序列共同訓練，包含「開門→關門」與「開門→放左側→關門」等。人類序列只訓練 VLM 的未來特徵預測，不提供動作專家監督。機器人仍有開關門及左右放置的原子技能示範。

作者展示烤箱及抽屜的成功組合軌跡，未報組合任務整體成功率或分母。因此這是定性展示，不能等同零機器人示範或普遍長程技能遷移。（§4.3、附錄 B.3、C.1）

第 4.4 節：模擬泛化結果

2.9B ThinkWorld 僅用標準 LIBERO 訓練集後訓練，直接評估 LIBERO-PRO 的擾動。LIBERO spatial／object／goal／long 成功率為 98.2／98.8／97.8／94.2%，平均 97.3%。

LIBERO-PRO 的物件／位置／語意／任務／環境成功率為 73.3／18.2／93.9／31.9／60.9%，五軸平均 55.6%；每軸先對相關任務套件取平均。整體為表中最佳，但非每軸最佳。相較 VLA-JEPA，任務與環境高 11.1、19.9 個百分點。基線大多取官方儲存庫，† 才標示作者重現結果。（§4.4，表 1、附錄 B.1）

第 4.5 節：累加消融與資料規模

LIBERO-PRO 平均從基本骨幹加動作專家的 40.1%，加視覺歷史後為 40.7%，再加未來預測為 50.4%，再加 CoD 為 54.4%，最後加 RL 為 55.6%。最後一步平均增加 1.2 個百分點，但物件與語意軸略降，並非各軸皆改善。

另一組 SFT 控制固定機器人資料，從 robot-only 的 45.4% 升到 50% 人類資料設定的 47.8%；不能把此值當成完整 RL 系統的主結果。未來特徵與 CoD 打亂／移除的對照，以及注意力視覺化，提供動態表徵的分析；注意力展示本身不構成因果證明。（§4.5，表 2–3、圖 6、附錄 C.2）

附錄 C–D：額外評估、成本與限制

SimplerEnv 整體微平均 46.51%，無基準專屬微調，但預訓練已含 Bridge、RT-1。LIBERO-Plus 平均 71.7%，在所列四方法最高，攝影機改變仍僅 46.9%。（附錄 C.3–C.4）

延遲測試用同一 H100 80GB、batch 1、停用 CUDA graph，暖身五次後計時 50 次。ThinkWorld 中位／p95 為 324.84／333.09 毫秒、記憶體 7.07 GiB；MolmoAct2 為 335.07／467.96 毫秒、12.11 GiB，思考模式為 879.37／1014.47 毫秒。各模型使用原生部署輸入，不是相同輸入的架構消融。真機的 RTX 3090、15 Hz 控制屬另一設定。（附錄 C.5，表 9）

作者明示只有一個訓練 seed；episode 信賴區間只反映評估變異，不能代表獨立訓練 checkpoint 的變異。真機須依試驗次數與任務範圍解讀；延遲取決於硬體和輸入。作者提供初始化、訓練配置、硬體及分母，協助重現。（附錄 D）
