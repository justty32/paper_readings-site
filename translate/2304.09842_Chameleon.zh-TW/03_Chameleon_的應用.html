4. Chameleon 的應用

以第 4.1 節介紹的模組庫為基礎，在 ScienceQA（4.2 節）與 TabMWP（4.3 節）兩項高難度任務上展示 Chameleon 的應用；實驗細節見附錄 A.2。

4.1 模組庫

為因應多樣查詢所需的各種推理能力，系統運用一套豐富的外部工具模組庫（完整列於 Table 2）。各工具定義如下：

  • Knowledge Retrieval（知識檢索）：檢索解題所需的背景知識，對科學、數學等專門領域尤其有用（如稅務表格查詢可生成稅務流程相關知識）。
  • Bing Search（Bing 搜尋）：與知識檢索類似，但更擅長需要多來源、更廣泛或最新資訊的情境；呼叫搜尋引擎 API，回傳結果供後續模組解析、彙整成更豐富的脈絡資訊。
  • Query Generator（查詢生成器）：由於原始問題通常缺乏適合檢索的查詢句，此模組依問題生成搜尋引擎查詢，供 Bing Search 使用；通常宜先接查詢生成器再接 Bing Search，以同時提升檢索的召回率與精確率。
  • Image Captioner（圖像字幕）：為圖片生成字幕，提供查詢所需的補充脈絡，特別適合需要語意理解圖像（如辨識場景中物件與互動）的情境；使用預訓練模型把視覺資料轉譯成語言。
  • Text Detector（文字偵測）：辨識圖片中的文字，適用於問題需要從含圖表、圖示、地圖等視覺元素的圖片中擷取文字資訊的情境。
  • Row Lookup／Column Lookup（列／欄查找）：處理表格脈絡查詢時，鎖定相關儲存格；大表格易造成干擾，此模組僅保留與查詢相關的列／欄，若全部相關則回傳原表格。
  • Table Verbalizer（表格文字化）：把結構化表格轉為文字描述，有助於下游模組（如 Program Generator、Solution Generator）理解表格資訊，對莖葉圖、函數表等小型專門表格尤其有用。
  • Program Generator／Verifier／Executor（程式生成器／驗證器／執行器）：Program Generator 生成 Python 程式以解決需要複雜運算或精細邏輯（如 if-else）的查詢；Program Verifier 檢查生成程式的語法、邏輯錯誤與潛在執行問題，以降低幻覺、提升可靠度；Program Executor 執行程式並產出結果。
  • Solution Generator（解答生成器）：以 CoT 提示方式，運用所有已快取資訊生成詳細解答；若規劃器判斷可獨立解題（尤其是較簡單的問題），可直接使用此模組取代其他功能性模組。
  • Answer Generator（答案生成器）：以規則式方法，從 Program Executor 或 Solution Generator 的結果中擷取並正規化答案；作為 pipeline 最終模組，提供簡潔、特定任務格式的答案（相對 Solution Generator 的詳細多步解答）。

4.2 科學問答（ScienceQA）

ScienceQA 是涵蓋多種科學主題與脈絡格式的多模態問答基準，回答問題需圖像字幕、文字偵測、知識檢索、線上資源搜尋、多線索視覺推理等多種工具與技能。生成程式時把搜尋空間限制在相關工具子集（附錄 Table 6）；若計畫非法（不以「Solution Generator, Answer Generator」結尾）則預設退回此序列，對齊 CoT 提示基線。規劃器提示模板見附錄 Table 8，Knowledge Retrieval、Query Generator、Solution Generator 等 LLM 型模組的提示模板見 Table 10–12。

4.3 表格數學推理（TabMWP）

TabMWP 涉及排程表、價格表、稅務表、圖表、函數關係等多樣表格脈絡的數學推理，要求系統理解各種表格格式並做精確的數值或符號運算。與 ScienceQA 類似，把搜尋空間限制在兩類工具：1）協助 LLM 消化表格資訊者（Row Lookup、Column Lookup、Table Verbalizer）；2）執行可信符號運算者（Program Generator、Verifier、Executor）（見附錄 Table 6）。生成程式須符合限制，如須包含 Answer Generator、且 Program Generator 須排在 Verifier 與 Executor 之前；不合規者退回「Program Generator, Verifier, Executor, Answer Generator」固定序列，對齊加了驗證步驟的 program-of-thought 提示基線。
