論文／訪談原始來源

Towards Neuro-Symbolic Procedural Reasoning for Long-Horizon Vision-Language-Action Manipulation

摘要與問題

VLA 能執行短操作技能，長程程序卻還要持續記住任務進度、遵守相依關係、處理條件分支，並把目前步驟可靠地連到正確物件與目的地。只靠低階政策容易把「怎麼動」和「現在該做哪一步」混在一起，也難把人類或其他 agent 完成的外部事件納入流程。

作者提出神經符號管線：task graph 編碼步驟相依、合法轉移與分支條件；append-only event memory 保存目前步驟、已完成動作、文字脈絡與視覺證據；VLM reasoner 選擇及驗證子目標；微調後的 VLA 以固定相機、腕部相機與機器人狀態執行動作。整體循環是觀察、ground、記憶、選擇、執行、驗證。

任務圖、記憶與協作

task graph 的節點包含指令、執行者角色、可視覺檢查的前置與成敗條件，以及狀態。執行者可為機器人、人類或另一個 embodied agent。相依與前置條件決定哪些節點已 ready；感知確認協作者動作後，系統把它追加成外部事件，更新記憶並解鎖後續機器人節點。

這個分工讓符號層決定什麼步驟合法，VLA 決定如何完成該步，感知則把結果接回圖與記憶。例如機器人先露出標記板，人類完成噴灑，視覺確認後才允許擦拭。固定全域視角適合看任務關係與協作事件，腕部視角支援近距控制。

程序 saliency 的兩種介面

每個受引導子目標只在一條代表性固定相機軌跡上標 pseudo-gaze 點。它不是眼動量測，而是程序上相關的位置。DINOv2 特徵把點轉移到重複示範，再用光流穩定時間軌跡。

第一種介面是 prompt-as-input：在 RGB 上畫空心洋紅圓環，於訓練與推論時直接指出目的地。第二種是 prompt-as-supervision：把 saliency 轉成 token-level 目標分佈，以 KL divergence 約束 action-conditioned attention；推論時輸入乾淨影像，不再顯示圓環。兩者都在現有示範內釐清空間關係，作者沒有宣稱它們能任意指向訓練未見的新座標。

初步實體結果

初步研究聚焦器械處理程序的空間 grounding，尚未測完整長程協作管線。作者自報：政策由 231 條遙操作 episode 微調；兩種受引導版本在分項評估中都完成 25／25 次；拿掉 prompt-trained 模型預期的視覺提示後，模糊容器路由只完成 5／10 次，失敗全是放錯目的地。顯式圓環與 attention regularization 在目前 ceiling 上行為相同，但機制不同：前者部署時保留提示，後者把監督內化並使用乾淨影像。

attention 圖只作質性診斷。作者觀察到 prompt 可改善行為，卻未造成同樣明顯的整體 attention 位移，因此可見的注意對齊與實際效用衡量的是不同性質，不能互相替代。

討論、結論與局限

結果支持結構化程序推理與示範衍生的視覺引導可以互補：task graph 與 memory 管下一步，saliency 幫低階政策把當前子目標落到正確空間位置。固定相機引導在這套多視角政策已足以排除目前的空間歧義，但作者只把這解釋為全域視角提供關係、腕部視角負責近距控制的可能原因。

作者明列的證據邊界很大。初步分數已飽和，尚不能證明反轉來源與目的地、獨立移動物件與容器、未見場景或相機擾動下仍能泛化；也沒有證明 saliency 能幾何轉移到腕部座標。更重要的是，完整管線尚未端到端測量圖上合法順序、人類完成相依項目的辨識、狀態轉移驗證、復原與全任務成功。真正的人類第一人稱 gaze 及跨視角轉移也留待後續工作。
