5 分析

5.1 GA 的設計選擇

Table 4：相對於錦標賽選擇（tournament）與隨機選擇，預設的輪盤法在 SST-5、ASSET 上取得最高平均分（48.17 vs 48.00 / 47.50），驗證此選擇機制的有效性。

5.2 DE 的設計選擇

在 Subj（DE 明顯優於 GA 的理解任務）與 ASSET（兩者表現相近的生成任務）上做消融（Table 5）：

  • 只突變差異部分 vs 突變全部內容：把 Step 1-2 換成「隨機突變 Prompt 1 和 Prompt 2 的全部內容」（denoted "All"），結果在兩個任務上都劣於原設計「只突變差異部分（Diff）」（Subj: 69.87 vs 75.55；ASSET: 45.73 vs 46.21），驗證保留共同部分、只突變差異部分的設計是有益的。
  • Prompt 3 的選取：比較「隨機取樣」（random，Subj 69.82）與「乾脆拿掉 Prompt 3、讓基礎 prompt 直接與突變差異部分交配」（eliminate，Subj 69.07）兩種替代設計，均明顯劣於預設的「取當前族群最佳 prompt 當 Prompt 3」（Subj 75.55）——證明引入 Prompt 3 且選最優者的重要性。

5.3 族群初始化

Table 6（SST-5 上比較 bottom-10、random-10、random-5+var-5、top-10、top-5+var-5 五種初始化策略）顯示：(1) 精心設計初始 prompt 並非必要，隨機挑選即可逼近用最優表現 prompt 初始化的效果；(2) 用最優表現 prompt 初始化時，讓 GPT-3.5 生成變體、引入隨機性能帶來些微提升，但隨機挑選時不需額外引入隨機性；(3) 用最優初始 prompt 時 GA 略優於 DE，但用最差初始 prompt 時 DE 反超 GA——顯示當可用的人工 prompt 品質不佳時，DE 是較佳選擇。

6 結論

本文提出 EvoPrompt，連結 LLM 與演化算法以優化離散 prompt。在 31 個資料集上的廣泛實驗證明其優於人工指令與既有方法，並驗證 LLM 能作為實作 GA、DE 等演化算法的有效、可解釋介面。雖然本研究聚焦 EA，此方法的可擴展性也為 LLM 結合其他傳統算法（如粒子群優化 PSO、蟻群優化 ACO，以及更新的 Quality-Diversity 優化算法）開啟了空間，期望能啟發 LLM 與傳統算法交會的未來研究。

  • 附錄 C.3（成本分析，對 ai_core 讀者尤其關鍵）：評估開銷＝ N × |D| × T（族群大小 × development set 大小 × 迭代輪數）；候選生成開銷主要看 API 呼叫數 T × N；故總 API 請求數＝ N × T × (1 + |D|)，與 APE 同量級。Table 13 在「相同迭代數」與「至收斂」兩種口徑下比較 GA/DE 與 APE 的迭代數、token 用量與分數：相同迭代數下 GA、DE 僅以些微 token 開銷即顯著優於 APE；GA 收斂速度與 APE相近，DE 略慢但天花板更高（此結論在正文摘要中已強調，是 EvoPrompt 「多探索換更高上限」定位的量化證據）。
  • 附錄 C.4（Prompt 分析）：DE 生成的 prompt 平均長度與變異數皆高於 GA，後期迭代 DE 引入更多新詞——顯示 DE 更偏向探索、也更有潛力跳脫局部最優；並釋出理解、簡化、摘要、BBH 各任務上找到的最優 prompt 全文（如 SST-2 上「Examine the movie reviews and classify them as either positive or negative.」以 95.61 勝過人工的 93.68）。
  • 附錄 D（未來工作）：作者列出三個方向——(1) 把框架用於遊戲關卡生成、文字生成圖像、NP-hard 問題（如 TSP）等更多應用；(2) 目前只用最經典的 DE 變體，未來可探索自適應控制參數等更先進 DE 變種，挑戰在於離散語言空間中如何評估 LLM 對連續控制參數的適應能力；(3) 期望本研究能啟發 LLM 與 PSO、ACO、MAP-Elites 等其他傳統演算法的連結，關鍵挑戰是如何把這些演算法的特定元素（如 PSO 的運動方向/速度、ACO 的路徑、MAP-Elites 的特徵維度）轉譯給 LLM 執行。
