摘要

大型語言模型（LLM）在各類任務上表現優異，但仰賴精心設計的 prompt，往往需要大量人力。為自動化此過程，本文提出離散 prompt 優化的新框架 EvoPrompt，借用演化算法（EA）表現好、收斂快的特性。為讓 EA 能作用於離散 prompt——這種需保持連貫、可讀的自然語言表達——我們把 LLM 與 EA 連結起來，同時發揮 LLM 強大的語言處理能力與 EA 高效的優化表現。具體而言，EvoPrompt 完全不使用梯度或參數，從一個 prompt 族群出發，依演化算子由 LLM 迭代生成新 prompt，並依 development set 表現改善族群。我們在 GPT-3.5、Alpaca 等閉源與開源 LLM 上，於涵蓋語言理解、生成任務以及 BIG-Bench Hard（BBH）的 31 個資料集上優化 prompt。EvoPrompt 顯著優於人工設計的 prompt 與既有自動 prompt 生成方法（例如 BBH 上最高勝出 25%）。此外，EvoPrompt 證明連結 LLM 與 EA 能產生綜效，可望啟發 LLM 與傳統演算法結合的後續研究。

1 引言

LLM 在多項 NLP 任務上表現卓越。要讓 LLM 適應下游任務，只需在輸入文字前加上指令（即離散 prompt），即可以幾乎可忽略的算力代價引導模型完成任務，也因此不需存取 LLM 的參數與梯度，適合像 GPT-3、GPT-4 這類黑箱 API。然而 LLM 對特定任務的表現高度受 prompt 影響，因此設計 prompt 已成為一項關鍵技術——prompt engineering。由於不同模型/任務間 prompt 差異極大，設計往往需要大量人力與專業經驗，且指引主觀而有限。

既有方法為減少人力，多依賴 LLM 輸出層的 token 機率（API 未必提供），或走「窮舉候選＋挑最佳」（偏重探索，容易優柔寡斷、浪費資源）或「編輯現有 prompt」（偏重利用，容易陷入局部最優）兩極。傳統無導數優化算法在探索與利用間有良好平衡，其中演化算法（EA）簡單高效、適合離散 prompt 優化——prompt 中的片語序列可視為 EA 中的基因序列，與自然演化過程相容。

本文借用 EA 概念，提出離散 prompt 調優框架 EvoPrompt。EA 中的演化算子通常獨立編輯序列元素生成候選解，卻忽略 token 間的關聯——這對維持 prompt 連貫可讀是致命傷。為此，我們結合 LLM 的 NLP 專長與 EA 卓越的優化能力：LLM 依演化算子生成新候選 prompt，EA 則引導優化過程、保留最優 prompt。

具體來說，基於若干初始 prompt，我們用 LLM 扮演演化算子生成新候選，並保留在 development set 上表現較好者；上述操作反覆迭代以提升族群品質。透過精心設計演化算子與更新策略，EvoPrompt 可實例化為多種 EA。本文在語言理解、生成任務以及高難度 BIG-Bench 任務共 31 個資料集上，為 Alpaca 與 GPT-3.5 兩種 LLM 優化 prompt，結果一致優於人工設計與既有自動生成方法。

主要貢獻：(1) 提出連結 LLM 與 EA 的新型自動離散 prompt 優化框架 EvoPrompt，優點是無需存取 LLM 參數/梯度、能平衡探索與利用、生成的 prompt 人類可讀；(2) 在 31 個資料集上驗證有效性，並釋出情感分類、主題分類、主觀性分類、簡化、摘要、推理等常見任務上找到的最佳 prompt；(3) 證明只要給予適當指令，LLM 能實作多種 EA，期望啟發 LLM 與傳統演算法結合的更多探索。

2 相關工作

LLM 中的 Prompt：連續 prompt（僅調輸入 token 的參數）表現好，但兩個缺點無法忽視——優化需要模型參數（黑箱 API 拿不到）、軟 prompt 缺乏可解釋性。離散 prompt（如加上「It was」，或任務描述式指令）能提供更好可解釋性與互動介面，在各類 NLP 任務上表現良好。

離散 Prompt：既有自動離散 prompt 搜尋/生成方法仍多依賴梯度或輸出層 token 機率。近期一些工作聚焦探索——透過重新採樣枚舉並挑選最佳候選（如 APE）；另一些基於 prompt 編輯的方法（如 Tempera、GrIPS）聚焦利用，容易陷入局部最優。還有方法收集預測錯誤的案例、分析根因來改進現有 prompt（如 APO/ProTeGi、Guo et al. 2023），同樣偏重利用，且僅適用於有標準答案的任務。本文的 EvoPrompt 借助 EA，在不需任何參數或梯度的情況下平衡探索與利用。

LLM 與優化算法：LLM 已展現扮演黑箱優化器的潛力（Zheng et al. 2023），但缺乏可解釋性。也有工作顯示 LLM 能模仿傳統算法的特定操作：透過收集錯誤預測樣本在離散空間執行「梯度下降」（Pryzant et al. 2023；Guo et al. 2023）；模仿遺傳算法（GA）中的突變（Lehman et al. 2022）或交配（Meyerson et al. 2023）算子；Chen et al. (2023) 把 LLM 與 GA 結合用於神經架構搜尋，Lanzi & Loiacono (2023) 用類似方法做遊戲設計。本文更進一步，提出可透過客製演化與選擇過程實例化為多種 EA 的通用框架，望能啟發更廣泛的 LLM 與傳統算法結合應用。
