摘要

透過以自然語言指令為條件，大型語言模型（large language models, LLM）展現出作為通用電腦的驚人能力。然而任務表現高度取決於用來引導模型的 prompt 品質，而最有效的 prompt 幾乎都由人類手工打造。受古典程式合成（program synthesis）與人類做提示工程的方式啟發，我們提出 Automatic Prompt Engineer（APE，自動提示工程師），用於自動生成與選擇指令。方法中我們把指令視為「程式」，藉由在「由 LLM 提出的候選指令池」中搜尋、以最大化選定的分數函式來優化它。為評估所選指令的品質，我們用另一個 LLM 執行該指令並衡量其 zero-shot 表現。大量實驗顯示，我們自動生成的指令大幅超越先前的 LLM 基線，並在 24/24 個 Instruction Induction 任務與 17/21 個精選 BIG-Bench 任務上，達到與人類標註者所寫指令相當或更好的表現。我們也展示 APE 能改善 few-shot 學習、找出更好的 zero-shot chain-of-thought（CoT）提示，並把模型引導向真實性/資訊性。（註：本文將「提示工程」定義為優化 prompt 中的語言以引出最佳表現，不含串接多次 LLM 查詢或給 LLM 外部工具。）

1. 引言

規模與注意力架構的結合，使語言模型具備前所未有的通用性。這些 LLM 在 zero-shot 與 few-shot 設定下展現出常常是超人的能力。伴隨通用性而來的是控制問題：我們如何讓 LLM 做我們想要的事？

近期工作嘗試以 fine-tuning、in-context learning、以及各式 prompt 生成（含可微分的軟提示調校與自然語言的提示工程）來引導 LLM。其中自然語言提示工程特別有意思，因為它提供了人與機器溝通的自然介面，且不只對 LLM 有用，也適用於受提示的影像生成器等其他通用模型。

問題在於：純語言 prompt 不總能產生期望結果，即使用別的指令是能產生的。因此人類使用者必須試遍大量 prompt 才能引出想要的行為，因為他們幾乎不知道某指令與某個特定模型有多相容。我們可以把 LLM 理解為執行「由自然語言指令所指定之程式」的黑箱電腦：它們能執行很廣的自然語言程式，但這些程式被處理的方式對人類未必直觀，而指令的品質只有在下游任務上執行時才能衡量。

為減少人類製作與驗證有效指令的心力，我們提出一套用 LLM 自動生成並選擇指令的演算法。我們稱此問題為自然語言程式合成（natural language program synthesis），並提議把它當作黑箱最佳化問題、用 LLM 生成並搜尋啟發式上可行的候選解。我們以三種方式利用 LLM 的通用能力：(1) 用 LLM 當推論模型，依一小組輸入/輸出示範生成候選指令；(2) 在我們想控制的那個 LLM 下為每個指令算分，引導搜尋；(3) 提出一種迭代式 Monte Carlo 搜尋，讓 LLM 提出語意相近的變體來改良最佳候選。

主要貢獻：把指令生成框定為自然語言程式合成、化為由 LLM 引導的黑箱最佳化問題，並提出樸素法與迭代 Monte Carlo 搜尋法；APE 在 24/24 Instruction Induction 與 17/21 Big-Bench 任務上以模型生成指令達到人類水準；提供大量質性與量化分析，並展示 APE 用於改善 few-shot、找更好的 zero-shot CoT 提示、以及把模型引導向真實/資訊性等應用。

（圖 1）APE 工作流程：對「以輸出示範指定的任務」自動生成指令——先生成數個候選指令（透過直接推論或基於語意相似度的遞迴過程），用目標模型執行它們，再依計算出的評估分數選出最合適的指令。以 24 個 NLP 任務的四分位距平均（IQM）衡量，用 InstructGPT 時 APE 能超越人類表現。

2. 相關工作

大型語言模型：擴大 transformer 語言模型的規模、資料與算力可預期地提升下游表現，並帶出許多湧現能力（few-shot in-context learning、zero-shot 解題、CoT 推理、指令遵循、指令歸納）。本文把 LLM 視為執行自然語言指令程式的黑箱電腦，研究如何用模型生成的指令控制其行為。

提示工程（Prompt Engineering）：提示提供人與通用模型互動的自然介面，但 LLM 需要細心的提示工程（手動或自動），因為模型對 prompt 的理解方式與人類不同。許多成功的提示調校法在連續空間用梯度優化，但隨規模變大、且模型存取轉為 API（未必提供梯度）而不再實用。本文借用離散提示搜尋的組件——提示生成、提示評分、提示改寫（paraphrasing）——直接在自然語言假設空間中搜尋以優化指令。相較於過去對每個組件都用專用模型、且重度依賴人類模板的做法，我們展示整條搜尋可由單一 LLM 完成。

程式合成（Program Synthesis）：程式合成是在「程式空間」中自動搜尋滿足某規格的程式，規格可為輸入/輸出範例或自然語言，可搜尋的空間也從受限的領域專用語言擴展到通用程式語言。不同於需要合適的結構化假設空間與組件庫的既有方法，我們利用 LLM 提供的結構在自然語言程式空間中搜尋；並用 LLM 當近似推論模型（不需訓練、對各任務泛化良好）依少量示範生成候選程式。
