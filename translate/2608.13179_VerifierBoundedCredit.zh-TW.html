論文／訪談原始來源

Teach the Magnitude, Not the Direction: Verifier-Bounded Credit Assignment for Multi-Turn Multi-step LLM Agents

摘要與第 1 節：問題

RLVR（RL with verifiable rewards）是 tool-use agent 訓練的主流，優點是效能上限由 verifier 品質決定（verifier-bounded），但標準目標把整條 trajectory 的單一 reward 廣播給所有 token；在單輪任務裡這只是雜訊，但多輪 session 中各輪結果獨立卻共用一個 reward，credit assignment 變得 ill-posed——作者引用 WildToolBench 數據：沒有模型 session accuracy 超過 15%，且隨輪數增加急遽下降。

On-policy distillation（OPD）讓 teacher 對 student trajectory 的每個 token 評分，天然提供 dense credit，但需要同家族、tokenizer 相同的 teacher，現實中少見。On-policy self-distillation（OPSD）讓 student 自己（給 privileged 資訊如 ground truth）當 teacher，免除外部 teacher，但作者引用先行研究：沒有 per-token KL clip 時，OPSD 約 100 步內因梯度集中到少數 token 而崩潰；且其效能上限受限於 teacher 的 privileged 分布（teacher-bounded）。

CrEST（Hierarchical Credit Assignment via Entropy-Gated Self-Teacher）想同時保留 RL 的 verifier-bounded 上限與 dense token 訊號。

第 3 節：方法

CrEST 的統一目標是標準 policy gradient，但 per-token advantage 拆成兩層：

𝒜ₜ = A[t]^turn（inter-turn：哪一輪，來自 verifier）× φₜ（intra-turn：哪個 token，來自 self-teacher）

Turn 級（3.2）：不用單一 trajectory reward，而是每輪各自算 group-relative advantage（GRPO 式，組內對同一輪的 G 個 rollout 做 z-score）。同一 trajectory 內某輪失敗，該輪 token 就拿到負 advantage，不受其他輪成功與否影響。

Token 級（3.3）：φₜ = 1 + λᵗ_eff·(wₜ−1)，wₜ 由 teacher–student 對數機率差 Δₜ = [log πT(yt) − log πθ(yt)]/τ 經 sign(A_turn)·Δₜ 再 clip 到 [1−ε, 1+ε] 得到。這個 sign 對齊的設計保證方向保持性質 P1：𝒜ₜ 的符號永遠等於 A_turn 的符號，也就是梯度方向完全由 verified reward 決定。

Gating（3.4）：direction gate 在 teacher 與 verifier 方向不一致時把 λᵗ_eff 整段歸零，這是防止效能上限退化成 teacher-bounded 的關鍵機制；entropy gate 用 token surprisal 的 z-score 過 sigmoid，把調幅強度往高不確定性內容 token（如工具名、參數值）集中，壓低低熵格式 token 的權重，範圍 [1−ρ, 1+ρ] 不做到零。兩者相乘再 clip 得複合 λᵗ_eff。作者證明三個性質：P1 方向保持、P2 偏誤有界（‖Bias‖≤λε·‖∇J_GRPO‖，λ=0.3、ε=0.28 時約 8.4%）、P3 符號一致放大（φₜ≥1）。除 λ 外其餘常數（τ=2.0、ε=0.28、ρ=0.5）固定不調。

第 4 節：實驗（作者自報）

benchmark 為 BFCL V3 多輪（100 訓練 ID，400 評測樣本涵蓋 Base/Missing Function/Missing Parameter/Long-Context）與 WildToolBench（128 訓練 session）。base model 為 Qwen3-4B-Instruct 與 Qwen3-8B。baseline 涵蓋 GRPO、MT-GRPO、EnvTuning（RL 系）與 OPD、OPSD（distillation 系）。

主結果：CrEST 在 BFCL V3 平均分達 52.00%（4B）／50.00%（8B），在 14 個 cell 中 13 個拿下最佳或並列最佳；WildToolBench session accuracy 4B 7.03%（+3.90 對比最強 baseline）、8B 9.38%（+4.69）。作者觀察到兩個既有模式：RL 系普遍優於 distillation 系（OPSD 在 4B BFCL 平均只有 38.75%，低於原始 GRPO 的 43.63%，儘管用了 privileged teacher，作者稱這是 teacher-bounded 論點的直接經驗證據）；RL 家族內更細的 credit granularity 有幫助（MT-GRPO、EnvTuning 都優於 trajectory 級的 GRPO）。CrEST 在最吃重 hierarchical credit 的切分上領先最多：BFCL Long-Context 4B +7.0、WildToolBench session accuracy 8B +1.57。

訓練動態（4.3）：CrEST 在約 20 步內達到 0.60 rollout accuracy 並收斂到約 0.70，超越 OPSD 的天花板（約 0.49，之後還下滑）；梯度集中度分析顯示 OPSD 前 1% token 吃掉約 42%、前 5% 約 77% 梯度量，GRPO 前 10% 約 31%，CrEST 前 10% 約 57%，作者稱這是 entropy gate 防止梯度集中崩潰又保留有意義 token 區分度的證據。

Ablation（4.4）：只用 inter-turn（turn 分段）得 47.88%，只用 intra-turn（teacher 調幅）得 48.75%，兩者合併 52.00%——都比單獨任一項更好，證明兩層互補。Gating ablation：拿掉 direction gate 掉到 46.75%（Missing Parameter 掉最多，作者解讀為 teacher 在模糊參數 token 上蓋過 verifier 訊號）；拿掉 entropy gate 掉到 46.25%（Long Context 受創最重，長序列放大格式 token 梯度集中）；兩者都拿掉回落到 43.50%，接近純 GRPO，證明無約束 self-distillation 本身沒有增益。

結論與限制

作者的核心論點：self-teacher 不需要決定梯度方向才有用——把它限制在只調幅度、且由 student 不確定性門控，就能在不犧牲 verifier-bounded 上限的前提下解鎖 dense credit assignment。

局限（第 6 節，作者自陳）：僅在 4B／8B 兩個規模、兩個多輪 tool-use benchmark 上驗證；entropy surprisal 作為 token 重要性代理是有效但仍屬啟發式的近似，未必適用於所有生成情境。評測用單一訓練種子搭配三次低溫解碼，量的是解碼一致性而非訓練變異，不能當獨立訓練重跑看待。
