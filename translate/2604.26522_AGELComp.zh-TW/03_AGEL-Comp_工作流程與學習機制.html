4. AGEL-Comp 工作流程與學習機制

Agent 的操作循環（詳見演算法 1）在兩個階段之間交替：行動與學習。

**行動階段（Perceive And Act）**始於 agent 觀察其環境 St。例如，一枚閃亮的硬幣旁邊有一團劈啪作響的火焰。為了達成目標 G（「取回閃亮的硬幣！」），LLM 核心查詢當前世界模型 Wt。若 Wt 中沒有關於火焰危險的規則，LLM 可能提出直接計劃 At（a1: approach(fire); a2: grab(coin)）。NTP 根據 Wt 驗證此計劃為有效。Agent 執行計劃並收到負面反饋（f1: HP 下降，damage=-50HP）。此經驗被捕捉為情節（episodes），記錄在情節記憶 M 中。

此觀察到的結果構成預測錯誤，因為負面反饋未被當前 Wt 預見。此錯誤觸發學習階段（Learn From Experience）。基礎化函數（G），使用因果歸因與抽象歸納的原則性機制，分析情節以理解錯誤原因並修復 agent 的世界模型。它歸納出一組解釋該事件的 Horn 子句（∆W）：

  • causes_damage(X) :- is_harmful(X).
  • is_harmful(fire).

此規則集隨後整合到世界模型中（Wt+1 ← Wt ∪ ∆W）。此循環使 agent 透過將符號知識建立於直接經驗中，持續精煉其理解。

循環閉合：下一次 agent 規劃時，NTP 將查詢更新後的 Wt+1。涉及 approach(fire) 的計劃現在將由 NTP 評估。NTP 將找到目標 causes_damage(agent) 的證明路徑：is_harmful(fire) 是已知事實，規則 causes_damage(X) :- is_harmful(X) 將其連接到負面結果。由於此證明導致已知的負面結果，NTP 將返回極低的證明成功分數（σ ≈ 0），導致該計劃被拒絕，強制 LLM 生成更安全的替代方案。

AGEL-Comp 的學習是一個混合過程，具有兩種互補形式。首先，新知識透過向世界模型符號性地添加新的 Horn 子句（∆W）來捕捉。隨後，神經推理器適應（neural reasoner adaptation）發生：當 NTP 與符號嵌入矩陣 E 在此更新的知識庫上被定期微調時。此協同作用使 agent 的演繹能力與其不斷演進的、經經驗驗證的符號世界理解保持緊密一致。

5. 實驗

本研究的核心思想是 AGEL-Comp 架構透過促進原位（in-situ）、有基礎的學習，使 agent 能克服 LLM 固有的組合限制。為驗證此觀點，我們設計了在單一連續運行中測量零樣本泛化（zero-shot generalization）的評估協議，不進行任何離線訓練或微調。實驗不僅對比 baseline，也透過嚴格的消融研究解剖每個組件的貢獻。

5.1 實驗假設

  • H1：AGEL-Comp 在具有模糊或隨機事件的環境中，將優於標準 LLM-based agent。
  • H2：缺乏 NTP 驗證器或 ILP 學習器的消融版將表現下降：
    • H2a：w/o NTP agent 相比完整系統性能將下降。
    • H2b：w/o ILP agent 在需要新知識的新型任務上將無法泛化。

5.2 模擬環境 —— Retro Quest

我們開發了 Retro Quest for Compositionality，一款基於 Unity 引擎與 ML-Agents 工具包的 top-down 2D 動作 RPG 遊戲。視覺資產基於 Pixel Frog 的「Tiny Swords」像素藝術包，包含角色、怪物（哥布林）、NPC（農夫）及互動物件（綿羊、南瓜）。Agent 從俯視角感知世界，接收視覺資訊以及附近實體及其狀態的結構化列表。其動作空間包括導航、基本攻擊以及與物件/NPC 的互動（移動、對話、拾取、使用物品）。

5.3 模型與配置

四種 agent 配置使用相同底層多模態 LLM 作為核心認知引擎：

配置 描述
MLLM-Agent（Baseline） 標準 ReAct 風格 agent，無持久世界模型
AGEL-Comp（完整系統） 完整架構：CPG + ILP 學習器 + NTP 驗證器
AGEL-Comp w/o NTP 可學習新規則但無驗證器，計劃僅基於 LLM 判斷
AGEL-Comp w/o ILP 有驗證器但世界模型為靜態，無法從經驗學習

四個 LLM 骨幹：GPT-4o、Gemini Pro 2.5、LLaVA 1.6、DeepSeek-VL。每種配置透過 10 任務課程在單一連續 session 中執行，隨機種子使用三次。後期任務明確納入模糊場景以探測穩健的、有基礎的學習。實驗前已在 OSF 預註冊協議：https://osf.io/a6j4c。

5.4 評估指標

指標 描述
Quest Success Rate (%) 成功完成任務的比例（含崩潰視為失敗）

5.5 結果與分析

實驗結果（見表 3 彙總數據及圖 2-5）為我們的主要假設提供了強力支持。AGEL-Comp 架構（H1）顯著優於 MLLM-Agent baseline，且其核心組件（H2）——ILP 學習器與 NTP 驗證器——皆關鍵且具協同作用。

H1：AGEL-Comp vs. Baseline

整體性能：AGEL-Comp（完整）在四個 LLM 骨幹上皆達 100% 任務成功率。Baseline 表現不僅較低且高度依賴 LLM：GPT-4o 86.67% → Gemini 83.33% → DeepSeek 66.67% → LLaVA-1.6 63.33%。在「困難」（第 4 級）與「非常困難」（第 5 級）任務上，baseline 與 w/o ILP 降至 0%，而 AGEL-Comp 維持 100%。

零樣本泛化：AGEL-Comp 的 First-Try Success 平均為 60.0%，baseline 僅 3.3%（差 18 倍）。AGEL-Comp 的混合推理核心——NTP 驗證 LLM 計劃、ILP 學習新規則——使其能在行動前演繹出正確的新穎計劃。

效率：使用 Gemini-2.5-Pro 時，AGEL 系統平均僅需 23.27 次樣本，而 baseline 需 159.30——樣本效率改善 6.8 倍。Baseline 花費愈來愈多的迭代次數與時間在後續任務上，而 AGEL-Comp 保持高效率。
