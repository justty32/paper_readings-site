5.5 結果與分析（續）

討論：Baseline 的失敗確認了純 LLM agent 缺乏穩健互動所需的有基礎系統性理解。有趣的是，閉源模型（GPT-4o、Gemini-2.5-Pro）的 baseline 表現比開源模型（DeepSeek-VL、LLaVA-1.6）更穩健，但此優勢與 API 依賴、token 成本與延遲掛鉤——加強了我們架構能最大化開源替代方案能力的價值。

H2：消融研究與組件協同

  • H2b：w/o ILP Agent（有驗證器、無學習器）：此 agent 具有 NTP 驗證器但世界模型為靜態，表現幾乎與 baseline 相同（平均任務成功率 76.7%，First-Try 僅 8.3%），在困難任務上完全失敗。關鍵洞見：邏輯驗證器（NTP）在底層世界模型（W）不完整或錯誤時完全無用——agent 只是重複「邏輯上有效」但事實錯誤的計劃。

  • H2a：w/o NTP Agent（有學習器、無驗證器）：此 agent 可透過 ILP 學習，但執行 LLM 提出的任何計劃而不驗證。任務成功率比完整系統低 9%，First-Try 成功率從 60% 驟降至 22.5%。此 agent 以「艱難方式」學習——執行有缺陷的計劃後才歸納新規則。完整系統透過 NTP 在執行前拒絕有缺陷的計劃，避免了此失敗。

討論：消融結果提供了本文最關鍵的洞見——邏輯推理與符號學習是共生（symbiotic）且互為必要的。w/o ILP agent 只能演繹，但其演繹基於錯誤的模型；w/o NTP agent 可以溯因地學習，但無法安全地演繹。AGEL-Comp 是唯一閉合循環的：它演繹健全的計劃（NTP）並在演繹失敗時溯因地修復其模型（ILP），使其能學習世界的「文法」，如 CPG 增長圖所示。非零的規則撤回線進一步顯示系統透過自我修正無效知識的穩健性。

5.6 與最先進神經符號系統的比較

AGEL-Comp 位於三條研究路線的交匯處：(i) 可微邏輯/神經推理，(ii) 符號程式歸納，(iii) LLM-based agent 架構。

首先，神經符號系統通常將神經感知與固定邏輯結構結合，很少在線上擴展可執行的規則庫 [12, 20, 23, 30]。AGEL-Comp 維護動態的 CPG 並從互動中線上學習新規則。其次，相較於程式歸納方法，AGEL-Comp 明確是經驗驅動的——符號規則獲取由具體互動中的預測錯誤觸發，透過 MCS 隔離因果前件，再透過 MIL 泛化為可重用子句。第三，相對於依賴提示/工具使用/非結構化記憶的 LLM-agent 堆疊 [2, 24, 29]，AGEL-Comp 強制執行規劃器-驗證器分離，NTP 根據顯式符號模型檢查 LLM 提議的子目標。

可擴展性考量

雖然單次 NTP 驗證迭代計算更密集，但此開銷與總迭代次數的劇烈減少相比微不足道；baseline 犯下許多錯誤重試，完成速度慢 5 到 10 倍。ILP 歸納的搜尋空間受學習脈絡嚴格限制：僅在 MCS 隔離出單一因果 literal 後才觸發，從一兩個範例中泛化，極大修剪了假設空間。實際部署挑戰包括：驗證/歸納成本預算、雜亂感知下的穩健符號基礎化、CPG 增長與不一致性控制、分佈轉移下的安全適應。

6. 結論

LLM 從根本上難以實現組合泛化。AGEL-Comp 整合 LLM 的生成靈活性與符號推理的形式化嚴謹性，建立在三個支柱上：CPG 作為動態世界模型，ILP 引擎從經驗中為新規則建立基礎，NTP 驗證計劃的邏輯一致性。在 Retro Quest 實驗中，完整系統在所有 LLM 骨幹上實現完美任務成功率，而 baseline 與消融版本在面對新穎場景時遭受災難性崩潰。

最關鍵的洞見：符號學習（ILP）與符號推理（NTP）各自單獨都不足夠——只有驗證器的 agent 無法修正其世界模型；只有學習器的 agent 低效且不安全，First-Try 成功率比完整系統低近 3 倍。正是演繹與溯因的協同循環使成功成為可能。AGEL-Comp 演繹健全計劃並溯因地合成新的可泛化規則，使 agent 能從頭建構一個明確的、可解釋的、具有組合結構的世界理解。
