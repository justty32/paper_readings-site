摘要

基於大型語言模型（LLM）的 agent 在組合泛化（compositional generalization）方面表現出系統性的失敗，限制了它們在互動環境中的穩健性。本文引入了 AGEL-Comp，一種神經符號 AI agent 架構，旨在透過對 agent 行動進行基礎化（grounding）來解決此挑戰。AGEL-Comp 整合了三項核心創新：(1) 一個動態因果程式圖（Causal Program Graph, CPG）作為世界模型，以有向超圖表示程序性與因果性知識；(2) 一個歸納邏輯程式設計（ILP）引擎，從經驗反饋中合成新的 Horn 子句，透過互動為符號知識建立基礎；以及 (3) 一個混合推理核心，其中 LLM 提出一組候選子目標，並由神經定理證明器（NTP）驗證其邏輯一致性。這些組件共同實現了一個演繹-溯因學習循環：使 agent 能夠演繹計劃並溯因地擴展其符號世界模型，同時神經適應階段使其推理引擎與新知識保持一致。我們提出了一個在 Retro Quest 模擬環境中的評估協議，以探測組合泛化場景來評估我們的 AGEL agent。我們的研究結果清楚表明，AGEL 模型相較於純 LLM 模型具有更優的性能。我們的架構為 agent 建構一個明確、可解釋且具有組合結構的世界理解提供了一條原則性路徑。

關鍵詞: 組合泛化、神經符號 AI、基礎化（grounding）、LLM

1. 引言

大型語言模型（LLM）在廣泛的自然語言任務中展現了卓越的能力 [3, 26]。然而，當這些模型被越來越頻繁地部署為互動 agent 的認知核心時，一個根本的限制變得顯而易見：組合泛化的失敗——即從已知基本組件理解和產出新穎組合的能力 [11, 21]。這種「組合性危機」是實現類人智慧的關鍵障礙，因為它揭示了對統計模式匹配的依賴，而非對世界的結構化、系統性理解 [1, 5, 8]。

此脆落性的產生，是因為模型的知識本質上「去身體化」（disembodied）的，脫離了結構化的因果世界。它們的理解缺乏經驗基礎（empirical grounding）——即抽象符號與其現實世界指涉物、互動以及支配概念如何系統性組合的後果之間的連結。目前的模型，包括最先進的 LLM，始終在這些挑戰中掙扎，限制了它們在開放式互動環境中的穩健性與適應性 [7, 9]。

為了解決這一差距，我們提出了 AGEL-Comp（Action-Grounded Experiential Learning for Compositionality），一個專為 LLM 驅動 agent 設計的新型神經符號架構，明確旨在促進組合推理。我們主張，互動環境中真正的泛化無法僅透過神經擴展來實現，而是需要一個能夠學習、表示和推理顯式結構化知識的架構。

AGEL-Comp 透過三個核心組件整合神經模型的靈活性與符號系統的嚴謹性：(1) 一個動態因果程式圖（CPG）作為其世界模型 W，以模組化、階層式結構表示程序性與因果知識 [4, 27, 28]；(2) 一個 ILP 引擎 G，從稀疏的經驗反饋中合成新的 Horn 子句，為透過互動建立符號知識的基礎提供形式化機制 [6, 16]；(3) 一個混合推理核心，其中 LLM 作為高層次規劃器，其提議由 NTP 驗證邏輯一致性 [14, 15, 20]。

透過從有基礎的經驗中建構此模型，agent 可以超越淺層統計模式匹配，轉向系統性、基於規則的推理。雖然先前的工作側重於將 LLM 整合到模擬環境中完成任務，但我們的主要貢獻是設計與評估一個明確針對組合泛化的協同架構。

我們的工作做出以下貢獻：1) AGEL-Comp 架構，一個用於 LLM-based agent 的混合認知架構，強制執行組合推理。2) 混合演繹-溯因學習循環，結合符號世界模型擴展與神經推理器適應。3) 兩階段基礎化機制，透過因果歸因與歸納合成將原始經驗轉化為符號規則。

我們的結果表明，此神經符號方法顯著優於純神經 baseline，為 agent 建構可解釋且具有組合結構的世界理解提供了一條原則性路徑。論文結構：第 2 節回顧三個底層建構模組，第 3 節介紹架構，第 4 節形式化學習循環，第 5 節介紹實驗與結果，第 6 節以限制與部署展望作結。

2. 背景

我們的架構整合了三項關鍵的神經符號技術。

2.1 因果圖形模型

具身 agent 的主要挑戰是超越統計相關性來理解因果關係。因果圖形模型，通常表示為有向無環圖（DAG），是用於此目的的形式化工具 [4, 18, 27, 28]。此結構超越單純的相關性，能實現預測介入結果與思考反事實等更深層推理 [10, 19]。我們從此範式汲取靈感，引入因果程式圖（CPG），專門設計來表示 agent 的程序性與操作性知識。

2.2 歸納邏輯程式設計（ILP）

ILP 是符號 AI 的子領域，在給定背景知識 B 的情況下，歸納出能泛化訓練範例 E 的假設 H（一個邏輯程式）[6, 16]。在標準的「從蘊涵中學習」設定中，正確的假設 H 必須既是完備的（B ∪ H |= E+）又是一致的（B ∪ H ̸|= E-）[22]。ILP 因其資料效率與符號輸出的可解釋性而受到重視 [31]。在神經符號系統中，ILP 提供了一種從雜亂、非結構化資料中進行規則歸納的形式化機制，在強化學習與機器人學中有應用 [13, 22]。與需要大量資料的黑箱神經網路不同，ILP 的強歸納偏誤使其能從極少範例中學習可泛化的規則。此樣本效率對於必須從稀疏且代價高昂的環境反饋中穩健學習的互動 agent 至關重要。

2.3 神經定理證明器（NTP）

NTP 是經典定理證明器所用反向鏈接（backward-chaining）演算法的端到端可微放鬆版本 [20, 14]。它對符號（謂詞與常數）的連續向量表示進行操作，並以嵌入之間的可微相似度函數取代離散統一化 [15]。證明的成功是可微分數，允許整個系統透過梯度最佳化進行訓練。NTP 因其橋接符號推理與神經表示學習的能力而受到重視，提供可解釋性與強大的系統性泛化特性 [25]。雖然計算密集，但其可擴展性是一個活躍的研究領域 [17]。LLM 規劃器容易生成看似合理但邏輯上不健全的步驟。我們使用 NTP 作為形式化驗證器來強制執行組合紀律——這比簡單提示 LLM「檢查自己的工作」更為嚴謹，因為 NTP 提供關於計劃相對於 agent 已學習世界模型有效性的可證明保證。

3. AGEL-Comp 架構

AGEL-Comp 是一個模組化的神經符號架構，設計用來從經驗中學習組合世界模型（見圖 1），由以下互連組件構成。

3.1 知覺（Perception）

在每個時間步 t，此模組感知模擬環境的狀態 St，並將其轉化為結構化知覺 Pt。知覺 Pt 是一組 ground literals，表示 agent 對環境實體及其狀態的當前知識。

3.2 LLM 核心

LLM 核心是中央認知引擎，在目標 G 的脈絡下處理知覺 Pt。它包含世界模型（W）與目標處理及規劃兩個部分。

世界模型（W）：agent 對世界的狀態化表示是一個因果有向超圖 W = (V, E)，將知識表示為結構化、可執行的程式。此結構使程序性依賴關係變得明確。節點（V）是一組 grounded predicates（例如 is_harmful(X)）或概念（例如 fire）。超邊（E）是一組 Horn 子句，作為子程式運作——一個超邊將一組輸入節點（子句 body）連接到單一輸出節點（子句 head），建模邏輯或因果依賴。例如，規則 h ← b1, ..., bn 是從 {b1, ..., bn} ⊂ V 到 h ∈ V 的一條超邊。此模組化結構有助於階層規劃與學習過程中的目標化模型修正。
