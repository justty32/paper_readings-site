論文／訪談原始來源

可擴展的電路學習以詮釋大型語言模型（CircuitLasso）

Yue Yu 等

摘要

機制可解釋性的一條主流方向是在 LLM 組件上學稀疏電路，揭示它們如何共同產生模型行為。然而原始神經元是多義的，使學出的電路難以解讀。稀疏自編碼器（SAE）特徵緩解了這點，但其高維度使既有干預式電路學習法計算上不可行。我們提出 CircuitLasso——一個基於稀疏線性迴歸的可擴展電路學習法。CircuitLasso 在基準資料上回復的電路其結構準確度與最先進干預式方法相當，而計算成本只是其一小部分。在可解釋性上，CircuitLasso 高效揭示 SAE 特徵間的關係，呈現人類可解釋的語意特徵如何在模型中傳播並影響預測。最後，我們以學到電路的洞見在域泛化任務上以大幅更低成本達到相當表現，驗證其實用性。

關鍵詞：機制可解釋性、電路發現、稀疏自編碼器。

1. 引言

MI 的根本挑戰是理解 LLM 行為的「為什麼」。一個關鍵技術是發現電路——驅動特定行為的緊湊子圖（注意力頭、神經元）。但既有電路學習常遇瓶頸：原始神經元多義（一個神經元被多個不相關概念激活並貢獻），使學出的電路稠密、雜訊多、難解讀，破壞了 MI 的初衷。

SAE 的出現提供了更好基礎：SAE 訓練來以高維但稀疏的「特徵」重建 LLM 激活，這些特徵傾向單義（每個特徵一致地對應單一人類可解釋概念，如「與運動有關」「某種情緒」「某種文法結構」）。單義性不僅本身提升可解釋性，也有望產出更稀疏、更乾淨、更忠實的結構圖。但 SAE 特徵維度極高，使干預式方法成本爆炸。

本文引入新方法 CircuitLasso：用 Lasso（ℓ₁ 懲罰線性迴歸） 找出能解釋模型行為的稀疏特徵連接集。稀疏線性迴歸天生適合高維資料——計算高效，且稀疏性直接對應更可解釋的電路。貢獻：(1) 受連續因果發現啟發，提出電路發現的稀疏迴歸代理，並理論分析其相對干預密集法的成本；(2) 可在單義但高維的 SAE 特徵上操作，呈現概念如何在 LLM 中傳播；(3) 跨 LLM（最大 9B）、SAE、資料集的大量實驗顯示「準確度持平下的效率」與下游遷移價值。

2. 相關工作

  • 機制可解釋性：早期以原始／粗粒度組件解釋行為（induction heads 之於 in-context learning;MLP 之於事實回憶），但多義性使洞見難下游應用。SAE / 字典學習辨識出對齊人類概念的稀疏解耦特徵。但既有 MI 仍難擴展到高維 SAE 空間。
  • 電路學習：干預式法（因果中介分析、因果追蹤、activation patching）以反事實干預量化組件影響，但計算密集、難擴展；少數借用因果概念（Conmy 等迭代剪枝，類似 PC 演算法），但更廣的因果發現文獻基本未被用於電路學習。
  • 逐提示 vs 族群層級：多數資料驅動法聚合跨提示得單一族群層級電路；近期也有逐提示歸因圖。CircuitLasso 與後者互補——它聚合觀測式稀疏迴歸係數得到單一族群層級依賴骨架，適合資料集層級的詮釋、模型編輯、域泛化。

3. 方法

  • 3.1 問題表述：抽取 N 個組件（MLP 神經元／注意力頭／SAE 特徵）激活拼成 x ∈ ℝᴺ；目標學以這些組件為節點的 DAG 𝒢。
  • 3.2 稀疏迴歸代理：以 min ‖x − Ax‖²_F + λ‖A‖₁ s.t. 𝒢(A) ∈ 𝔻（無環圖空間） 求解；A 為加權鄰接矩陣，ε 為線性化誤差。繞過無環約束：用簡化假設把問題化簡為標準 Lasso，達成可擴展。
  • 假設討論：這是非線性計算圖的稀疏迴歸代理而非嚴格 SEM；不訴諸需要因果充分性／獨立噪聲／正確線性形式的可識別性定理（三者在 transformer 中僅近似成立）。目標只是高效回復依賴骨架;ℓ₁ 過濾弱依賴得保守地圖。提供非線性擴展（拓撲類似、成本較高）。
  • 3.x 成本分析：對 S 區塊、神經元維度 d、token 長度 n_token 的 transformer，EAP-ig 需額外 O(12·M·S·n_token·d²(2+f)+…)（主成本來自每觀測兩前向一反向），CircuitLasso 為 O(M·L(L−1)d²/2√ε) 且不跑反向傳播，在給定條件下證明更快。
  • 作用於 SAE 特徵：把 h ∈ ℝᵈ 表為稀疏特徵 z ∈ ℝᴰ（D≫d）的線性組合；直接用預訓練 SAE，學特徵間結構依賴 A_{i,y}，成本 O(MD/√ε)；可同時解釋與矯正預測（去除偽相關／偏誤）。

4. 實驗

  • 4.1 神經元上（InterpBench）：86 個已知 ground-truth 電路的半合成 transformer，取 16 主合成案例 + 真實 IOI；以 SHD（結構漢明距離，越低越好）與 runtime 評。對手 EAP、EAP-ig。結果：CircuitLasso-線性 mean SHD 3.16（與 EAP-ig 2.98 統計無別、優於 EAP 3.61），mean runtime 16.3 s（比 EAP-ig 49.1 s 快 3.0×、比 EAP 33.7 s 快 2.1×）。即「準確度持平、成本砍一截」。
  • 4.2.1 SAE 特徵電路（CoLA）：CoLA 前所未用於 MI;CircuitLasso 高效給出 SAE 特徵間人類可解釋的概念傳播關係。
  • 4.2.2 下游域泛化（Bias-in-Bios）：Pythia-70M、Gemma-2-2B/9B；以性別偽相關訓練、平衡測試集評職業預測。對手 original/oracle/cbp/shift/shift-retrain/linear probing。利用學到電路洞見以大幅更低成本達相當甚至略好表現。

5. 結論

CircuitLasso 把電路發現重構為稀疏線性迴歸 / 連續因果發現問題，不跑反向傳播因而能擴展到高維 SAE 單義特徵空間，在準確度持平下大幅省成本，並讓「人類可解釋概念如何在模型中傳播」變得可讀、可用於下游去偏與域泛化。侷限在只回復依賴骨架（非逐邊因果）、族群層級（非逐提示）、依賴 SAE 品質。
