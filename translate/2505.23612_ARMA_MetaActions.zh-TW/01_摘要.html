摘要

由高層語義決策（稱為元動作（meta-actions））引導的可控軌跡生成，對自動駕駛系統至關重要。現有框架的一大限制是依賴固定未來時距上不變的元動作，造成與實際行為軌跡的時間錯位。此錯位使規定的元動作與生成軌跡產生不相關的關聯，破壞任務一致性、限制效能。本文提出自回歸元動作，整合進自回歸軌跡生成框架，為「元動作條件下的軌跡預測」提供統一精確的定義。具體而言，把傳統長時距元動作分解為幀級元動作，使「自回歸元動作預測」與「元動作條件軌跡生成」可序貫交替，確保每段軌跡與其對應元動作嚴格對齊，達成全程一致統一的任務公式並大幅降低複雜度。此外提出分階段預訓練，把基本運動動力學的學習與高層決策控制的整合解耦，提供彈性、穩定性與模組化。實驗證明本框架有效，展現更佳的軌跡適應性與對動態決策場景的回應力。

1. 引言

元動作（車道保持、變道、轉彎等）代表策略性駕駛行為，提供簡化軌跡解釋與控制的抽象語義框架。要學好這些抽象，必須確保每個元動作與其對應軌跡段的精確時間對齊。

傳統可控軌跡生成把單一元動作標籤套在固定、較長的時距上再學軌跡模式。但跨越「不同元動作切換點」的軌跡段被強迫對應到單一元動作 → 語義錯位 → 破壞「全程一致學習決策對齊軌跡」的統一目標，並使決策遵循行為更難建模。近期自回歸模型（把幀級軌跡當離散 token、逐幀預測）成效顯著；有些工作把元動作併入自回歸框架，但仍以固定長時距元動作為條件，保留同樣的語義錯位問題。

本文提出自回歸元動作框架：把高層決策分解成幀級元動作，確保每幀軌跡嚴格對齊其元動作；再把任務重構成「自回歸元動作預測（前向生成元動作）」與「元動作條件軌跡生成（提供可控性）」的序貫交替。先基於歷史軌跡與元動作序列預測下一幀元動作，把每幀定位在當前決策的時間進程中，準確偵測元動作切換；隨後以預測的元動作條件化軌跡生成。

實務上提出分階段微調：(1) 先只用軌跡資料訓練基礎自回歸模型（無元動作監督），學一般運動模式與環境互動；(2) 凍結其參數，加入兩個新模組——元動作預測模組與元動作注入模組，只微調這兩者 → 穩定、模組化地納入決策遵循能力；若要加新決策類型，只需單獨微調元動作相關模組。最後提供從軌跡生成幀級元動作標籤的方法，並開源由 Waymo Motion 衍生、附完整幀級元動作標註的資料集。

2. 預備知識

  • 可控軌跡生成：給定歷史 agent 狀態、環境上下文與高層元動作（取自有限語義動作集），學一函數把歷史與決策映射到未來軌跡（式 1）；常以機率形式表示（式 2）。若系統能不靠外部輸入預測未來元動作，可重構為軌跡與元動作的聯合預測（式 3）。本文採此具預測性元動作的公式。
  • 自回歸框架：把式 3 分解為逐步預測每個未來狀態，同時條件於固定元動作（式 4）。此反映傳統「agent 行為在預測區間保持一致」的假設，但會導致固定決策與實際行為轉變間的時間錯位。

3. 自回歸元動作的統一任務公式

3.1 既有公式的不統一

定義 1（任務統一性）：時序任務的函數 f_t 若在每步滿足 (1) 結構一致（輸入/輸出空間跨步一致）與 (2) 語義一致（同一函數解釋），則稱在時序上統一。

例 1（圖 1）：時距 [t1,t2) 對應元動作 m1、後續對應 m2；若預測時距落在切換點，預測軌跡同時橫跨 m1、m2 兩段，函數企圖把輸入與元動作 m1 映到部分受 m2 支配的軌跡 → 違反語義一致。→ 命題 3.1：式 2 的回歸式任務公式不統一（式 4 自回歸版同樣有此問題）。

幀級元動作的必要性：只要未來時距長於單位時距，總能找到含至少兩個不同元動作的預測軌跡段 → 凸顯需以幀級表示元動作。

3.2 自回歸元動作的任務公式

以單位時距表示元動作，定義幀級元動作 a_t（在 t 時刻引導 s_{t+1} 生成）。任務為自回歸聯合預測未來軌跡與其元動作（式 5a-5c）：式 5b 按時間自回歸分解聯合分布——每步預測 active 元動作與下一幀狀態、再更新歷史；式 5c 進一步分兩階段——先預測下一元動作、再以新預測的元動作條件生成軌跡狀態，符合「高層決策決定運動結果」的因果。外部固定特定步的元動作可直接施加干預或使用者指引。

納入歷史元動作序列：作為輸入幫模型定位當前決策的時間相位。傳統公式（式 3/4）省略此資訊、依賴理想化對齊（例 1 顯示常不準）。顯式納入歷史元動作可免去僅憑軌跡推斷決策邊界，降低建模複雜度、便於學決策轉換（註：因幀級元動作本就與軌跡對齊，移除此條件不破壞語義一致，但為效能仍需納入以減歧義）。

統一性分析：自回歸元動作預測子過程提供「歷史軌跡+環境+先前元動作 → 下一元動作」的一致映射；元動作條件軌跡生成子過程一致地把「歷史+當前元動作 → 對應此元動作的幀級軌跡狀態」。兩子過程語義在每步一致 → 滿足結構與語義一致。→ 命題 3.2：式 5c 的自回歸任務公式統一。

4. 模型架構（圖 2）

模組化架構含三部分：捕捉一般運動與互動的基礎軌跡生成模組、自回歸推斷未來決策的元動作預測模組、整合決策引導軌跡生成的元動作注入模組。基礎模型先獨立訓練；後兩模組在其參數凍結下微調。採 query-centric 設計，統一對待所有 agent（不分本車與周遭）。

4.1 基礎軌跡生成模型

採 Zhao et al.(2024)（KiGRAS）的運動學軌跡表示：相鄰狀態轉移由底層物理控制動作（加速度與偏航率）依運動學模型驅動。自回歸軌跡生成 = 預測自回歸控制動作（式 6）。為建模互動與時序：先在 agent 維做自注意力（agent-agent 互動）→ 地圖 token 自注意力 → agent→map 交叉注意力（agent-map 互動），全配 RoPE（式 7）；再沿時間維做因果自注意力聚合歷史（式 8）；歷史聚合 token 過 MLP 解碼控制動作分布（式 9）。訓練：對離散控制動作用 CE loss（式 10）。

4.2 元動作預測模組

把元動作序列嵌入並做一步時間位移（前置零向量），加到環境互動後的 agent token（式 11-12）。因果條件化：此位移確保 t 步 token 只看得到過去元動作、避免未來洩漏，保自回歸設定。再沿時間做因果自注意力聚合歷史（式 13），解碼成元動作預測（式 14）。

元動作注入的關鍵時機：注入太早（環境互動前）會經注意力跨 agent 洩漏（違反「各 agent 元動作私有、互不可見」）；注入太晚（歷史聚合後）則相關上下文已被壓縮、失效。唯一正確位置 = 環境互動之後、歷史聚合之前，才同時保語義一致與充分性。訓練：凍結基礎模型，對元動作分布最小化 CE loss（式 15）。

4.3 元動作注入模組

把元動作序列嵌入，注入歷史聚合模組（對應式 8 的層），遵循上述關鍵時機。在歷史聚合每層注入元動作嵌入（式 16-17），L 層後再加一額外嵌入後去 token 化（式 18）。注入後 token 送基礎模型的 FFN（式 9）產最終軌跡預測。訓練：凍結基礎模型，只微調元動作嵌入（式 19）。
