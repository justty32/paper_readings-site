6. 從無標籤影片學互動世界的生成模型

2024 初 DeepMind 發布 Genie：110 億參數生成世界模型，自監督訓於大量公開 2D 平台遊戲影片，能由單張種子圖生成無限多種可互動可控的 2D 平台世界。三組件（皆用時空 transformer）：影片 tokeniser（VQ-VAE，幀↔離散 token）、潛在動作模型（VQ-VAE 推斷連續幀間合理動作、限定小型離散動作集、完全自監督無需人標動作）、動態模型（自回歸從過去 token + 動作嵌入預測未來 token）。

推論流程（圖 5）：用戶給類平台遊戲的初始圖 → tokeniser 壓成 token → 玩家輸入動作 → 潛在動作模型轉動作嵌入 → 動態模型依動作與狀態預測下一 token → tokeniser 解碼為可見幀 → 迭代產生可玩序列。

限制：約 1 FPS、有時幻覺不真實的未來、長期世界一致性/穩定性差。但證明「僅靠影片資料學互動世界生成模型」可行，尤其無人標動作就能推出可操作潛在動作空間值得注意。Genie 2（自回歸潛在擴散模型）擴到更難的 3D 互動世界、有物理/物件互動/角色動畫/代理等湧現能力、世界維持約 1 分鐘。

潛在意涵：在最多樣虛擬環境訓測通用適應代理、為機器人（自駕車）模擬無限訓練場景、加速遊戲原型、讓非專家造可控遊戲片段、程序擴充既有遊戲、依玩家模型個人化內容、為醫療/航空訓練模擬環境。未來題目：維持長期一致性穩定、防幻覺、加入音訊、為較少探索的類型（鳥瞰策略）生成機制、找並緩解計算瓶頸以提幀率、更強的動態與潛在動作模型、結合 LLM 與文生圖。

7. 當前技術挑戰：批判性檢視

深度學習落地電玩的挑戰：計算效率/速度、可解釋性與可預測性、模型約束設定、資料需求、泛化、隱私、財務成本；遊戲特有的——整合進傳統開發流程、開發時間、管理玩家對 AI 的期待、維持敘事控制、確保一致性、保留除錯能力。

  • 訓練/運行/蒐資料的可行性：訓 SOTA 模型（LLM、世界生成器）需大量算力與昂貴硬體，對中小工作室是瓶頸；泛化不佳需丟棄或重訓；監督資料難取（且涉玩家行為時有隱私倫理）；即時運行大模型可能拖垮幀率。
  • 黑箱問題：難解釋預測、難預測邊緣情況行為、難保證一致性與除錯。對遊戲的具體障礙：神經網路控制的 NPC 可能出現違背敘事/機制的莫名行為；除錯延長開發；難把可玩性約束硬編進 PCG 生成器。
  • 可能緩解：自監督/合成訓練資料（改善泛化、減標註）、模型蒸餾/網路剪枝（如利用 LLM 中新發現的 super weights）、雲端分散運算卸載、AI 可解釋性與對抗穩健性、品質-多樣性優化（生成兼顧約束與多樣的內容）。

8. 結論

闡明五條途徑：LLM 代理建模、NCA 程序內容生成、深度代理模型加速昂貴模擬、自監督遊戲狀態表示學習、用無標籤影片訓互動世界生成模型。目的是高層概覽、激發更聚焦的深入研究。電玩是尋求通用 AI 最自然重要的前沿之一（提供近乎無限的認知任務與模擬環境）。此方向不僅能增強遊戲品質與沉浸，也能推進整體 AI（如 LLM 代理推進「語言系統能否作通用智能」之辯、互動世界生成器供代理無限訓練環境）。但須正視可解釋性、可預測性、一致性、可除錯性、資料需求、泛化、可重用性、約束設定、財務與計算效率等挑戰——系統性解決這些障礙應是高優先。
