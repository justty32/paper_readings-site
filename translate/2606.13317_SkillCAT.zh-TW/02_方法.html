方法

SkillCAT 把技能自我演化拆成三個階段：對比因果萃取（CCE）、評估增強演化（AAE）、拓撲感知任務執行（TTE）。CCE 與 AAE 在技能學習期間離線運作；TTE 在任務部署期間線上運作。

問題形式化

令 X = {x₁,…,x_N} 為用於技能演化的任務集，Z = {z₁,…,z_K} 為隨機種子集。給定基礎技能 S₀，在種子 z 下對任務 x_i 執行智能體會產生軌跡 τ_{i,z} 與官方評估器給出的二元結果 y_{i,z}∈{0,1}。任務 x_i 的多種子執行結果記為 T_i = {(τ_{i,z}, y_{i,z}): z∈Z}，全部演化軌跡集合記為 T = {T_i}。

技能自我演化以 (S₀, T) 為輸入，輸出演化後技能 S*，以及每個測試時任務所用的路由技能 S_c。目標是提升未見任務上的官方評估器表現，同時限制每個任務注入智能體脈絡的技能內容量。因此問題不只是寫出更長的技能文件：方法必須決定哪些證據可信、哪些修補該進入技能、測試時該載入演化後技能的哪些部分。演算法 1 概括了完整管線：CCE 從多種子軌跡萃取候選經驗記錄，AAE 透過來源任務重播過濾修補並合併成 S*，TTE 把 S* 編譯成可路由拓撲、為每個測試任務組裝任務相關技能 S_c。三個模組分別對應上述三個決策，因此可個別消融或整體評估。

對比因果萃取（CCE）

CCE 從多種子執行中構建同任務成功／失敗配對，並在結果首次出現「有意義分歧」處萃取技能證據。因為配對雙方共享相同輸入、工具與評估器，證據能鎖定最能解釋結果差異的執行選擇。

對比配對構建：對任務 x_i，令 T_i⁺、T_i⁻ 分別為成功與失敗軌跡集合。當兩集合皆非空時，CCE 從各自集合中均勻隨機取樣一條軌跡組成對比配對 (τ_i⁺, τ_i⁻)。這種同任務構建方式，避免把「任務難度或輸入內容的差異」誤認為技能證據。

因果分水嶺辨識與記錄萃取：給定對比配對 (τ_i⁺, τ_i⁻)，CCE 定位因果分水嶺 w_i——成功與失敗軌跡動作序列首次出現分歧的時間點（w_i = min{t: α_t⁺ ≠ α_t⁻}）。萃取器接著圍繞此分歧點寫出候選經驗記錄 r_i = E(τ_i⁺, τ_i⁻, w_i)，包含局部證據、推斷的失敗原因，以及一則可用來編輯技能的教訓。因此 r_i 並非摘要整條軌跡，而是聚焦於結果開始分離的那個行為差異點。

Fallback 機制：若某任務所有 K 條軌跡全成功或全失敗，不存在嚴格的成功／失敗對比配對。若啟用 fallback，CCE 對 T_i 套用單軌萃取器 E₁；否則跳過該任務，以維持「嚴格對比證據」的定義。

演算法 1（SkillCAT 管線）：輸入演化任務 X、種子 Z、基礎技能 S₀、分數閾值 θ、路由預算 k，輸出演化後技能拓撲 (V, S_core)。第一階段（CCE）：對每個任務用所有種子跑出 T_i；若同時存在成功與失敗結果，取一成一敗組成配對、定位分水嶺、萃取記錄加入候選記錄集 R；若結果全同且啟用 fallback，改用單軌萃取器。第二階段（AAE）：把 R 轉成候選修補 {p_j}，對每個修補在來源任務複本上重播並依公式 2 計算評估分數 a_j，選出分數 ≥ θ 的修補集合 P_θ，經公式 4 的分層合併得到 S*。第三階段（TTE，線上執行）：把 S* 編譯成 (S_core, V)；對每個測試任務用其脈絡 c 依公式 5 選出路由節點 V_c、依公式 6 組裝路由技能 S_c，再以 S_c 執行智能體。

評估增強演化（AAE）

AAE 把每個候選修補當作待驗證的假說，而非直接合併的規則。做法是把修補隔離進一個臨時技能，在來源任務複本上重播，並在選擇與合併前，對產生的結果轉移打分。

來源任務重播評估：對候選修補 p_j，令 X_j 為產生該證據的來源任務複本集合。AAE 記錄這些複本上的基線結果，以及套用 p_j 誘導的臨時技能後的重播結果。令 y_j, ŷ_j∈{0,1} 分別為用於評分的基線與重播結果（1 表成功、0 表失敗）。AAE 不估計連續獎勵，而是直接對四種結果轉移排序評分：

a_j = 3.0（若 (y_j, ŷ_j)=(0,1)，失敗→成功）；2.0（(1,1)，成功→成功）；1.0（(0,0)，失敗→失敗）；0.0（(1,0)，成功→失敗）。（公式 2）

此評分把「失敗→成功」視為最強證據，把「成功→成功」視為行為保留，把「失敗→失敗」降權，並拒絕「成功→失敗」。對於源自 CCE 對比配對的修補，配對中成功的一方定義基線狀態：重播成功計為成功→成功，重播失敗計為成功→失敗。此保守規則確保對比修補不會破壞已觀察到成功的來源任務行為。

分數門檻選擇：AAE 只把分數達門檻 θ 的修補送入合併階段：P_θ = {p_j: a_j ≥ θ}（公式 3），本文設定 θ = 2.0。因此保留的修補要嘛修復了一個來源任務失敗、要嘛保留了一個已知成功；讓失敗維持未解決、或把成功變成失敗的修補會被排除在全域技能之外。

階層式分層合併：門檻篩選後，AAE 依分數把保留的修補分層，從低分層合併到高分層。令 ℓ 為合併層索引，L 為層數，P_θ^(ℓ) 為第 ℓ 層被選中的修補，μ 為技能合併運算子：S^(ℓ) = μ(S^(ℓ-1), P_θ^(ℓ))（公式 4），其中 S^(0)=S₀，最終演化後技能為 S*=S^(L)。此順序讓高分修補在後段合併中享有較高優先權，同時仍允許分數較低但已驗證、不衝突的規則參與貢獻。合併運算子複用 Trace2Skill 底層的技能編輯程序；AAE 改變的是哪些修補進入合併、以及合併的順序。

拓撲感知任務執行（TTE）

TTE 把測試時的技能使用視為脈絡選擇問題。它離線把演化後技能 S* 編譯成可路由拓撲，並在線上為每個任務組裝較小的路由技能 S_c，避免載入完整技能的成本與干擾。

拓撲構建：離線編譯器解析 AAE 產生的 S* 的 Markdown 階層。第一層內容組成一律載入的核心技能 S_core，第二層各小節組成可路由節點集合 V。對每個節點 v∈V，TTE 保留原始內容本體 B_v 作為要注入的內容，並抽取標題、關鍵字、摘要與可用依賴關係作為路由用的中繼資料。節點中繼資料組成拓撲摘要 Σ。因此路由只讀取精簡摘要，而技能組裝使用未經修改的節點本體。

LLM 路由與技能組裝：給定任務描述 c 與路由預算 k，LLM router ρ 從拓撲摘要 Σ 中選出至多 k 個相關主節點，此輸出僅為原始選取結果 Ṽ_c。執行期接著驗證節點識別碼、加入確定性的召回與任務意圖錨點、沿依賴邊展開，並納入基礎節點；令 Expand 表示此確定性展開步驟：Ṽ_c = ρ(c, Σ; k)，V_c = Expand(Ṽ_c, Σ)（公式 5）。最終 TTE 把核心技能與最終節點集合 V_c 中節點的原始本體串接，得到任務 c 的路由技能：S_c = S_core ⊕ ⊕_{v∈V_c} B_v（公式 6），⊕ 表示序列字串串接。TTE 不重新生成技能文字，因此保留 AAE 產生的規則；它只改變測試時載入哪些規則，減少每個任務暴露到的無關技能內容。
