論文／訪談原始來源

Neurosymbolic Embodied Agents

摘要與第 1 節：問題

VLM 能生成看似合理的具身計畫，但不保證可執行——輸出可能違反環境動態，或作用在綁定錯誤的物件上。單一自迴歸迴圈裡，agent 必須同時解決遮蔽、容納、物件接地、動作前置條件與長程效果推理，任何一環出錯都會在後續軌跡累積放大；執行回饋能事後暴露錯誤，卻不能阻止模型重複無效選擇或偏離自身動作誘發的狀態。作者提出兩階段架構把這個耦合問題拆開：Phase I 探索（VLM 主動獲取任務相關場景事實）、Phase II 規劃（在 PDDL 轉移模型約束下生成目標導向計畫）。

第 3 節：方法

任務建模為 POMDP,agent 在時刻 t 只收到自我中心 RGB 觀測，完整環境狀態潛藏，物件可能在視野外、被遮蔽或被容器包住。作者不在信念空間求解 POMDP，而是讓 Phase I 降低任務相關狀態的不確定性、收斂到一個點估計，Phase II 再對這個確定性估計求解古典規劃問題、回傳開迴路計畫。

Phase I 探索：探索控制器（harness）依目標、已知事實 F_t、探索紀錄 R_t 構造候選技能集合（Goto、Open、Close、Look、Done 的子集，依狀態動態調整）。VLM 依當前影像、目標與候選技能提出一組候選事實與所選技能。環境執行後回傳新影像與事件（成功/失敗及簡短接地錯誤）。證據更新函式只在動作成功執行後加入其效果，只有經多視角定位或成功 grounded 互動支持的物件-容器綁定才會確立；未經支持或衝突的提議可以觸發再探索，但不會直接寫成關係事實——這不是通用的幻覺偵測器，視覺辨識錯誤仍可能導致 Phase I 失敗。探索在事實齊備、模型選 Done 或互動預算耗盡時終止，回傳符號初始狀態與符號到環境實例的最終綁定。

Phase II 規劃：PDDL 定義動作的前置條件與效果（add/del）。狀態依存的約束解碼在每個 token 邊界，把下一 token 的合法集合限制為能延伸出可行動作字串前綴的 token，不合法 token 機率設為零；每個動作邊界後轉移函式推進狀態，約束隨新狀態重新計算。由此可歸納證明：任何在此分布下生成完的計畫，依構造在轉移模型下皆可執行，只要 PDDL 領域模型本身正確、且 Phase I 的符號綁定準確，這個保證就能轉移到模擬器上。可行不等於能達成目標，作者用 token 層 MCTS 補上——節點結合搜尋回饋值與語言模型先驗（PUCB 公式），完成的計畫用領域無關規劃啟發式（Fast Forward、LM-cut 等加權平均）評分，達成目標給正獎勵，否則依剩餘符號距離與計畫長度懲罰。

第 4–5 節：實驗與結果

在 VirtualHome（200 個問題，四類目標族）與 ALFWorld（134 個未見場景任務，六類目標族）上，用 Qwen3.5 4B/9B/27B 評測，對照直接視覺互動策略、Phase II 消融（無約束貪婪/思考、有約束貪婪、無約束 MCTS）、以及開源具身模型（MiMo-Embodied-7B、Embodied-R1.5-8B、RoboBrain2-32B）與 API 策略 Gemini-3-Flash。

整體成功率：本方法在 VirtualHome 達 94.5–99.5%、ALFWorld 達 90.3–97.8%（作者自報），遠超直接視覺互動與無約束思考模式。4B agent 比 27B 直接 VLM 策略在兩個環境分別高出 32.0 與 63.4 個百分點，也比 27B 無約束思考高出 35.5 與 73.4 個百分點——增加模型容量或自由推理無法取代可執行的動作空間。專精具身模型（MiMo-Embodied 等）在此零樣本、未見模擬器介面設定下遷移效果有限。

成本：配對同模型規模比較，constrained MCTS 比 unconstrained MCTS 少用至多 1.5 倍生成 token、比 extended thinking 少 4.0 倍；約束提前剔除不可行分支，搜尋不再靠反覆生成再拒絕來浪費 token。視覺查詢減少更明顯，比直接互動少至多 5.5 倍模型可見影像（典型 4–6 張 vs 13–34 張）——Phase I 一次性取得緊湊表徵後，Phase II 比對完整候選計畫時不必反覆查詢視覺環境。

失效歸因：把每個失敗任務歸到最早阻斷完成的因果環節。本方法的殘餘錯誤集中在上游——VirtualHome 約 2.3%、ALFWorld 約 4.5% 的任務因表徵獲取不足或錯誤而失敗，ALFWorld 僅 1.0% 是取得可用狀態後仍未達成目標。定性檢視顯示典型視覺失效是小型、低對比物件（如混入桌面的叉子）在非近距離視角下未被辨識，導致初始狀態缺物件。相對地，直接 Qwen 策略在 VirtualHome 有 64.2% 任務未達成目標，在 ALFWorld 有 39.8% 死於動作無法接地、48.8% 未達成目標——ALFWorld 更密的實例與容器語意加重了接地負擔。

消融(Qwen3.5-27B)：VirtualHome 上，約束貪婪解碼把成功率從 61.0% 拉到 98.5%，顯示可行性約束貢獻了大部分收益；無約束 MCTS 達 99.0% 但生成成本更高。ALFWorld 更能區分——單獨約束 32.3%、單獨無約束 MCTS 29.2%，兩者合併達 95.5%，顯示約束與搜尋互補而非可互相替代：約束讓每個被探索的前綴皆可執行，MCTS 則修正局部看似合理但長程無法達成目標的選擇。

第 6 節：結論

作者主張這個分解把「動作可行性」從模型每輪都要重新推斷的行為，轉成生成與搜尋全程維持的不變量，讓 4B–27B 開源模型大幅超越更大的直接視覺策略、無約束推理與專精具身基線，同時用更少生成 token 與視覺觀測。
