摘要

雲端 API 供應商如今提供各種尺寸與配置的大型語言模型（LLM）。這種多樣性提供了廣闊選擇空間，但要有效利用這些選項以最佳化計算成本與效能仍具挑戰。本文提出 AutoMix：依據較小 LM 輸出的近似正確性，策略性地把查詢路由給更大 LM。AutoMix 的兩個核心技術貢獻：其一是 few-shot 自我驗證（self-verification）機制，不需大量訓練即可估計自身輸出的可靠度；其二是鑑於自我驗證有噪音，採用 POMDP（部分可觀察馬可夫決策過程）路由器，依答案信心有效選擇合適尺寸的模型。在五個語言模型、五個高難度資料集上的實驗顯示，AutoMix 一致超越強基線，在同等表現下降低超過 50% 計算成本。程式碼：github.com/automix-llm/automix。

1. 引言

LLM 生態快速演變，各種尺寸、能力與計算需求的模型並存。大模型雖普遍表現更佳，但高昂計算成本使其對許多簡單任務不划算；而真實任務的複雜度變異極大——從簡單（可分資料的二元分類）、複雜（程式碼生成）到可能無解（unsolvable）（某些多步推理）。這使**模型切換（model switching）**技術益發重要：把查詢分派給尺寸與能力不同的模型，更有效配置計算資源。

既有模型切換策略多依賴針對固定任務集訓練的獨立路由模型（FrugalGPT、HybridLLM）；且現代 LLM 常只能透過黑盒 API 存取，無法微調、拿不到權重，還預期有大量任務專屬資料——既有路由方法無法妥善應對。AutoMix 讓使用者在只有黑盒 API 存取下混用各種模型，分三步：1) 解答生成——小模型先產生初始答案；2) 自我驗證——同一個小模型評估答案；3) 選擇性路由——驗證建議升級時才路由到更大模型。此流程呼應人類解題的多步過程：先解、再驗、據驗證結果精煉。

理想路由器須具備：(1) 能從小模型答案的信心評估辨識查詢難度；(2) 能路由到合適尺寸的模型——簡單查詢留給小模型（SLM）、困難查詢給大模型（LLM），且與先前工作不同：無解查詢誰都解不了，不應路由給任何模型，以省成本；(3) 能從少量資料學習；(4) 能泛化到模型數量、成本、能力各異的場景。自我驗證雖是提供信心評估的自然選擇，但先前研究顯示它對推理任務噪音大、校準差——這是必須解決的挑戰。

對此本文提出兩個創新：第一，把自我驗證表述為蘊涵（entailment）問題——評估生成答案與上下文的一致性來估計信心（如上下文講「茶」、答案講「蘋果」即高度不一致）；第二，引入 POMDP 路由器：POMDP 把標準 MDP 擴展到「觀察（自我驗證機率）不可靠、只是狀態（問題難度）的噪音估計」的決策問題，能以原則性方式在模型數量、成本、能力各異的場景學出穩健路由策略，且只需 50 個樣本即可學習。

2. 背景與相關工作

  • 自我驗證：既有方法多依賴 LLM 自身知識，對推理問題有困難；AutoMix 改利用上下文驗證，並引入 POMDP 路由器緩解驗證噪音。先前研究發現自我驗證不足以「修復」模型輸出（self-correction 不可靠），本文則證明它提供的訊號用於路由是有價值的。
  • 混用模型：FrugalGPT、HybridLLM 等透過模型切換降本，但需專門訓練驗證器；AutoMix 用 few-shot 提示免除昂貴的驗證器訓練、不需預先看到全部查詢，50 個樣本訓練的路由器即勝過專門模型。
  • 自適應計算：early-exit 等方法需改架構或取中間表徵；AutoMix 不改架構、只需黑盒 API。AdaptiveConsistency 只優化單一 LLM 內的推理，AutoMix 靈活優化兩個以上模型。
  • POMDP 背景：POMDP 是 MDP 在「狀態觀察不完整或有噪音」下的擴展，定義為元組 ⟨S, A, T, R, Ω, O⟩；代理維護 belief（狀態上的機率分佈），依動作與觀察更新，目標是找出把 belief 映射到動作、最大化期望累積報酬的策略。曾用於機器人、自駕、群眾外包工作流等。AutoMix 以新穎方式用 POMDP 在 LM 間路由：噪音的自我驗證輸出＝觀察，據以評估問題難度並路由，最大化成本與效能的報酬函數。

3. 問題表述

假設可存取 N 個語言模型 LM₁…LM_N（依參數量遞增），各有成本 Cᵢ 與（未知的）單題效能 Pᵢ。目標：在任何總成本下最大化總效能，對每個測試點動態呼叫合適的 LM。實驗以成本—品質曲線及新提出的 IBC 指標評估。任務為上下文錨定推理（context-grounded reasoning）：給定上下文 C（故事、新聞、對話歷史）與問題 q，生成與上下文一致的準確答案。選這類任務的動機：(1) 長查詢計算負擔重，更需要在成本—準確率間權衡；(2) 上下文可供交叉檢核初步答案（自我驗證的基礎）。只假設黑盒 API 存取；訓練路由器只需小型訓練/驗證集 D_train（⟨C, q, ŷ, y_LMᵢ⟩ 三元組）。
