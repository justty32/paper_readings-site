5. 增強方法

5.1 資料中心（優化訓練資料 D）

  • 專家策展：FOLIO 系列（FOL 標註形式驗證，P-FOLIO 延長推理鏈）、LeanDojo（9.8 萬+ 人證定理對）、Symbol-LLM（34 符號任務、20 符號族）。
  • 合成：RuleTaker（行為形式化→範例合成→語言等價生成三階段）、FLD×2（基於符號理論的合成）。
  • LLM 蒸餾：LogiCoT（GPT-4 生成推理鏈擴增）、LogicPro（演算法問題+程式解的變數導引推理）、PODA（前提導向增強生成正/誤選項對比分析，經對比學習分化推理路徑）。

5.2 模型中心（優化參數 θ 與解碼策略）

  • 指令微調（IFT，優化 θ）：多粒度指令；模仿邏輯求解器複製形式演繹；Symbol-LLM 兩階段（Injection 注入符號知識、Infusion 平衡符號與 NL 推理）；對抗過擬合用事實/反事實路徑對比學習；Program-Guided 框架 + 邏輯專屬架構調整；s1（1000 條精製長 CoT + budget-forcing 測試時擴展，使 Qwen2.5-32B 外推超越無干預表現）。
  • 強化學習（RL，優化 θ）：RLHF 後成關鍵；規劃式推理優化；以僅結果監督達過程監督之效。OpenAI o1 的大規模 RL 啟發眾多 o1-style（解決公式化輸出、長推理受限）;CoT 微調 + MCTS 多路徑；MCTS 生程式推理資料供 IFT 與 DPO。DeepSeek-R1 重大突破：R1-Zero 純 RL 無 IFT（推理強但可讀性/語言一致性差）→ R1 加少量長 CoT 冷啟動再 RL，平衡可用性與推理；迭代合成高品質推理資料、突破人工標註限制——邏輯推理優化的潛在範式轉移。
  • 推理時解碼（優化解碼策略 P）：
    • inference-time scaling（不更新參數）：結構化輸出/模組化工作流（GoT 結構推理節點、Chain-of-Logic 法律分解-重組）；激發自主推理迭代精煉（Maieutic Prompting 遞迴消矛盾、Logic-of-Thoughts、DetermLR）。
    • constrained decoding（提升可控/可靠）：NeuroLogic 強制謂詞邏輯約束、Formal-LLM 整合自動機約束計畫生成。

5.3 外部知識利用

LLM 複雜任務常因幻覺出錯，需外部知識輔助。形式化為「神經模型（參數通常不變）+ 知識整合策略 K」的聯合優化。例：抽 Lean 數學證明工具資料助定理證明；LQOT（Logic-Query-of-Thoughts，拆複雜邏輯問題為子問題再接知識圖譜）；閱讀理解中建 supergraph;KnowRA 自主決定是否採納外部知識輔助文件級關係抽取。

5.4 神經符號方法

結合深度學習表示力與符號推理的精確/可解釋。形式上聯合優化神經模型 g_θ（把 NL 輸入映成形式語言內的符號表示）與符號 solver f_φ（對符號表示求解出最終輸出），最大化推理表現。兩方向：改進 g_θ（產出準確且與 f_φ 相容的符號表示）、增強 f_φ（提升 solver 處理能力）。早期管線中 f_φ 常是固定外部邏輯引擎、不被優化；先進實務中 LLM 越來越扮演 f_φ，使多元優化成為可能。

  • 核心模式：用 LLM 把問題翻成符號表示，外部符號 solver 求解。LINC：LLM 把 NL 轉 FOL，再用外部定理證明器做符號演繹。
  • 改進 NL→符號翻譯：一派直接經訓練/解碼策略優化翻譯，另一派靠驗證/修正機制。
  • 把 LLM 全程整合進推理以克服傳統管線限制：Logic Agent（LA）（用規則導引的 LLM 推理鏈取代外部 solver）、LLM-TRes（自足可驗證推理、無外部符號 solver）、SymbCoT（翻譯/規劃/求解/驗證全由 LLM 協調）、Aristotle（三件 LLM 驅動組件：Logical Decomposer、Logical Search Router、Logical Resolver）。

6. 討論

  • 穩健性 vs 泛化：LLM 在結構化推理（演繹、溯因假設生成）表現不一致；FOLIO 微調在受控設定優異，但對抗擾動或語義等價改寫就掙扎——源於依賴表層統計相關而非因果關係 + 有限 OOD 泛化。能否在不犧牲跨域適應下達人類級穩健?當前方法偏重窄任務表現。
  • 可解釋性 vs 效能：核心張力＝神經可擴展性 vs 符號精確性。Logic-LM、Symbol-LLM 嵌形式 solver、以逐步證明提升可解釋，但大知識庫/複雜規則依賴時擴展性瓶頸；資料驅動（LogicBench 指令微調）覆蓋廣但泛化不過語法模式。混合架構有望但帶計算開銷。
  • 評估嚴謹性：LogiQA、ReClor 等多選格式把推理與模式辨識混為一談；NeuLR 用「中性」內容隔離推理與領域知識但缺整體評估範圍；現行指標（accuracy、BLEU）測不出 consistency（對邏輯等價輸入不變）或 soundness（遵循形式證明結構）。benchmark 應優先**系統性測核心原則（傳遞性、逆否）**而非任務特定表現。
  • 未來方向：動態整合神經與符號的混合架構（如可微定理證明器）平衡擴展性與精確；用擾動邏輯陳述（否定前提、互換量詞）壓力測試以隔離推理與記憶；多模態推理（文/圖/碼）；跨學科協作（形式邏輯+認知科學+ML）設計能「與不確定性推理、對不確定性推理」的系統。直到 LLM 能可靠地把邏輯與詞彙解耦，其在高風險領域的部署仍岌岌可危。

7. 結論

本綜述彙整 LLM 邏輯推理的快速進展與持續挑戰。LLM 啟發式推理亮眼，但跨演繹/歸納/溯因/類比的嚴謹邏輯推斷因穩健性、泛化、可解釋性的限制而不一致。分析了增強策略（神經符號整合、資料中心調校、RL、測試時擴展與改進解碼），並標出 FOLIO、LogiQA 等系統評估 benchmark。未來進展取決於統一神經與符號的混合架構、穩健評估框架、跨域與多模態推理的可擴展方法。
