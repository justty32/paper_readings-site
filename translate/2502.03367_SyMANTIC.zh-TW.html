論文／訪談原始來源

SyMANTIC：可解釋簡約模型發現的高效符號迴歸方法

Ohio State University 化工與生物分子工程系 + The Dow Chemical Company

摘要

SR 是發掘簡單可解釋數學式的新興 ML 分支。雖已有多種 SR 法，但常面臨計算成本高、隨輸入維度擴展性差、對噪聲脆弱、無法平衡準確與複雜度等挑戰。本文提出 SyMANTIC 解決這些。SyMANTIC 經獨特組合——互資訊特徵選擇、自適應特徵擴展、遞迴 L0 稀疏迴歸——從海量候選（10⁴ 到 10¹⁰+）高效辨識（可能多個）低維描述子；並用資訊論量度產近似 Pareto 最優方程集（各在給定複雜度下達最佳準確）。開源實作建於 PyTorch（易裝、GPU 加速）。在合成例、科學 benchmark、真實材料性質預測、小資料混沌動態系統辨識上展示有效。廣泛比較顯示 SyMANTIC 以遠低成本發現相近或更準的模型。

關鍵詞：符號迴歸、可解釋 ML、系統辨識。

1. 引言

SR 發掘準確擬合資料的符號式（如從行星質量/距離/重力測量「重新發現」牛頓萬有引力）。簡單數學式不只可能提升預測（更好泛化），也增可解釋、利深入分析 → 適合安全可靠要求嚴格的高風險應用（物理/化學/材料/經濟/醫療/動態控制/太空）。SR 是模型空間全為解析式的監督學習，NP-hard（解析式空間隨輸入指數成長）。

1.1 範圍

聚焦代數模型 y=f(x)+ε（對齊標準監督學習）。也提及動態系統（如 SINDy 假設可取狀態 + 其導數）但非焦點。

1.2 既有方法四類

暴力搜尋（BACON/FAHRENHEIT，靠啟發式、搜尋空間指數成長已不實用）、遺傳程式設計、深度學習、稀疏迴歸。各有彈性/可擴展/可解釋的優勢與限制。

2. SyMANTIC 方法

2.1 問題描述

SR 形式化為函數類 F 上的經驗風險最小化（式 1，損失常取 MSE = 加性 iid 高斯誤差下的 NLL）。SR 與其他迴歸的關鍵差別在 F——應是「可解釋」函數（由基本算術/超越函數/常數/恆等函數經函數組合構成的庫；如 {+,−,×,÷} 含所有二維任意次多項式）。F 隨基元集大小指數成長 → 幾乎不可能精確解。實際目標是泛化 → 依奧坎剃刀聯合最小化期望損失 + 函數複雜度 → 找 Pareto 最優函數（無更簡且更準者）。精確 Pareto 前沿不可行 → 用假設/啟發式建可行近似（取稀疏迴歸/壓縮感知視角的懲罰式 SR）。

2.2 總體演算法

SyMANTIC 核心是 C²-SISSO（Complexity-Constrained Sure Independence Screening with Sparsifying Operator）——建於 SISSO（從海量候選找最優低維描述子的高效壓縮感知法，原為材料性質建模）之上，跑稀疏迴歸前先限制特徵複雜度。C²-SISSO 依賴關鍵超參（生成特徵空間、複雜度約束界），這些難手設且不同複雜度的最佳模型不太可能來自同超參 → SyMANTIC 自動序貫測試多組超參組合，每輪用 C²-SISSO 新結果更新「損失-複雜度」Pareto 前沿估計。因送進 C²-SISSO 的特徵空間由 x 與使用者運算子集遞迴建構、隨運算子/主特徵數指數成長（計算與記憶體很快難承） → SyMANTIC 納入互資訊（MI）篩選處理高維（特徵 >~10–20），對 x↔y 強非線性穩健。

流程（圖 1）：訓練資料 →(Step1) MI 預篩限制送進特徵擴展的主特徵數 →(Step2) 特徵擴展（遞迴 L 層）→(Step3) 擴展特徵 + 複雜度過濾參數送 C²-SISSO 出帶損失/複雜度的新模型集 → 更新 Pareto 前沿近似 →(Step4) 對多組超參自動序貫改善 Pareto。達 RMSE 閾值或試完所有超參組合即停。

MI 預篩：因 x↔y 可高度非線性，用互資訊量測各分量與目標的關係強度（式 2，非負、獨立時為 0），按 MI 值排序選最相關主特徵。

（後續：自適應特徵擴展、C²-SISSO 內部、資訊論複雜度量度、動態系統應用。）

3. 案例研究

合成例、挑戰性科學式、真實化學/材料性質預測、混沌動態系統辨識。對比多個 SOTA SR。

4. 結論

SyMANTIC 克服既有 SR 關鍵挑戰：低計算成本、穩健處理高維輸入與噪聲資料、平衡準確與簡單。不返回單一最準式，而給近似 Pareto 最優方程集。提出計入「唯一輸入/運算子之數量與頻率」的資訊論結構複雜度量度。雖精確 Pareto 前沿一般不可行，SyMANTIC 建於 SISSO 智慧搜尋可能近 Pareto 的有限式集，特別發展複雜度約束變體 C²-SISSO。並含自動超參搜尋逐輪改善近似 Pareto。釋為易用 Python 套件（PyTorch、GPU）。

廣泛測試（合成/挑戰性科學式/真實化學材料性質/混沌動態系統）對比 SOTA：SyMANTIC 一致勝出——回復 >95% benchmark 真值方程（次佳僅略過 50%）、訓練時間最短（高效易平行）。從僅 5 個時間點的狀態導數量測準確學混沌 Lorenz 系統方程，勝廣用 SINDy。在可持續電池材料性質預測上，即使有限資料也學到比現有 SR 與傳統 ML 更準、更可泛化的模型。

未來：更多 benchmark/真實問題找其困難類型；探索更好處理離群/非高斯噪聲的損失；混合稀疏線性迴歸 + GP 搜尋（SyMANTIC 只探到最大深度，GP 可更深但測很多低品質式效率低；SyMANTIC 的針對性搜尋是成功關鍵，混合可結合兩者之長）。
