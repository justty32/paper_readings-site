論文／訪談原始來源

稀疏自編碼器學得有意義的概念階層嗎？

（共同第一作者群）

摘要

稀疏自編碼器（SAE）已成大模型無監督概念發現的重要工具。為讓特徵空間更可解釋、可管理，近期方法開始（顯式或作為訓練約束的隱式效果）施加階層結構，但嚴格比較仍困難：對「有意義的特徵階層該滿足什麼」沒有共識，評估多靠定性插圖與零碎的量化協議。為此，我們借語意網與分類學研究、結合近期 SAE 工作，推導出無監督概念發現中泛化／特殊化階層的一組關鍵需求，並據以導出具體評估協議。把協議用於視覺資料上的現行 SAE 方法，我們發現：特徵空間大致能撐起合理的階層，但建出好的階層結構仍具挑戰。尤其特徵吸收（含眾所周知的「硬」形式與一種連續的「軟」形式）系統性地損害階層品質，指向未來方法必須面對的根本張力。

1. 引言

本文推導泛化／特殊化階層在無監督概念學習下的一組通用需求，借鑑分類學評估與語意網，並結合 SAE 文獻新近的指標。重要地，我們同時涵蓋靜態結構需求（如階層抽象性）與動態共激活需求（如頻繁細化）——後者在無監督概念發現中尤為關鍵。由需求導出一組具體指標，用以評估「在訓練中顯式或隱式施加階層」的現行方法。貢獻：(1) 建立泛化／特殊化階層的通用需求集；(2) 導出對應的可量化指標；(3) 在視覺資料上評估現行 SAE 方法的階層品質；(4) 給未來階層概念抽取器的具體指引。

需求（節選）

  • B1 階層抽象性：邊 (p,c) 中子 c 應比父 p 更具體（tennis 比 tennis racket / tennis serve 更一般）。
  • B2 兄弟相似性：父 p 的多個子應共享 p 所代表的概念，形成連貫的細化集合。
  • 共激活層：把激活當「概念存在的證據強度」，分離散（在/不在）與連續（越大越強）兩種設定。
    • C1 激活蘊含：子 c 是父 p 範圍內的細化，故 c 存在蘊含 p 存在——子激活時父應永遠也激活。這也等於無硬吸收（子激活不壓抑父激活）。

2. 相關工作

SAE 把激活分解成高維稀疏潛特徵，已成語言／視覺-語言模型無監督概念發現的常用框架。多種事後方法探討特徵間結構（解碼器幾何、頂激活輸入、文字描述、共激活樣式）;Wittenmayer 等顯式以加權條件特徵機率建階層 DAG。訓練中施結構的方法：Matryoshka 原則（嵌套稀疏約束 / 嵌套字典）、非嵌套靜態分組、迭代細化重建殘差、高層 SAE + 低層專家 SAE、學多個 SAE 及其關係。標準 SAE 評估聚焦重建品質／稀疏度／特徵解耦，階層結構的評估卻少被關注。本文提供共享框架來評估與比較這些方法引入的階層。

3. 需求與指標

把需求分三級：概念層（孤立概念是否有效可命名，前置條件）、結構層（靜態圖：B1 抽象性、B2 兄弟相似性）、共激活層（逐樣本動態：C1 激活蘊含與頻繁細化等）。每級導出可量化指標。

4. 實驗

  • 研究問題：(1) 視覺概念階層學習的現狀?(2) 視覺編碼器選擇如何影響階層品質?(3) 階層品質隨深度如何變?
  • 圖構造：多數階層 SAE 不產顯式圖、只施隱式約束，故依 Wittenmayer 等由成對條件激活機率建 DAG，再去噪（丟過小組件／過密節點）+ 傳遞約化去冗餘邊。
  • 比較對象：標準 TopK SAE 對多種階層 SAE；評估時統一施 TopK（k=64）對齊稀疏度以利公平。
  • 發現：
    • 現行方法能發現可組成語意有意義但多半淺的階層。
    • 動態激活不一致：跨層級激活行為不一致，常違反 C1。
    • 吸收是核心障礙：除經典硬吸收（子抑父、互斥激活）外，本文新指認軟吸收——父子都激活時，較強子激活仍壓抑父激活，破壞「子蘊含父」的證據強度語意。

5. 結論與侷限

我們導出概念階層的通用需求（概念層前置 + 結構層 + 共激活層）並轉成具體指標。評估顯示現行階層 SAE 能發現可組成語意合理（但多淺）階層的特徵，但激活行為跨層級不一致，且吸收（硬 + 新指認的軟）是中心挑戰。第二個侷限是所有非 H-SAE 方法都依賴 Wittenmayer 的圖構造（只捕捉條件激活機率這一需求，對 MP-SAE 甚至產空圖），顯示需要針對訓練法量身的圖構造；「如何從 SAE 潛表示抽出最佳階層圖」仍是開放問題。
