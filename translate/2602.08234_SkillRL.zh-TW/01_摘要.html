摘要

大型語言模型（LLM）代理在複雜任務中展現了驚人的成果，但它們通常在隔離中運作，無法從過往經驗中學習。現有的基於記憶的方法主要儲存原始軌跡，這些軌跡往往冗餘且充滿雜訊，使代理無法提取對泛化至關重要的高層次、可復用行為模式。本文提出 SkillRL——一個透過自動技能發現與遞迴演化來橋接原始經驗與策略改進之間鴻溝的框架。我們的方法包含三個核心：基於經驗的蒸餾機制，用於建構階層式技能庫 SkillBank；適應性檢索策略，提供通用與任務特定啟發式規則；遞迴演化機制，使技能庫能在強化學習過程中與代理策略共演化。這些創新顯著降低了 token 使用量，同時增強了推理效用。在 ALFWorld、WebShop 與七項搜尋增強任務上的實驗結果表明，SkillRL 達到了最先進效能，超越強基線 15.3%，並在任務複雜度增加時保持穩健。程式碼已開源。

1. 導論

LLM 代理（如 ReAct、Reflexion）已在網頁導航、深度研究等複雜任務中展現了卓越能力，但每次任務執行本質上都是插曲式的——當前的 LLM 代理在隔離中運作，無法從過往的成敗中學習，這嚴重阻礙了它們的演化能力。根本挑戰在於：代理如何有效地從經驗中學習，並將知識遷移至其他任務？

現有的記憶方法主要將原始軌跡直接存入外部資料庫，作為未來類似任務的參考（如 Reflexion、Mem0）。然而這些原始軌跡通常冗長且含有大量冗餘與雜訊（如探索性動作、回溯、冗餘步驟），使模型難以提取關鍵資訊。近期工作（如 MemRL、EvolveR）嘗試壓縮軌跡並透過線上訓練更新記憶庫，但這些方法僅是模仿過往的解決方案，未能蒸餾出核心原則，也未能調整代理的內部策略以利用記憶進行指導式決策。如圖 1(a) 虛線所示，此類方法常在資訊密度與雜訊之間掙扎，導致次優效能甚至退化。

我們的論點是：這些方法忽略了一個關鍵洞察——有效的經驗遷移需要抽象化。人類專家不會記憶每個情境的每個動作，而是發展技能（Anthropic, 2024）：可壓縮、可復用的策略，捕捉完成特定子任務的本質。SkillRL 正是橋接原始經驗與高效策略改進，透過自動技能發現與遞迴技能演化來實現這一目標。

SkillRL 首先引入基於經驗的技能蒸餾機制：收集多樣軌跡，對成功片段保留為示範，對失敗片段合成精簡的失敗教訓以降低上下文雜訊。其次，將這些經驗轉化為階層式技能庫 SkillBank，區分通用技能（跨任務策略指導）與任務特定技能（任務層級啟發式），使代理在決策時適應性檢索相關技能，顯著降低 token 使用量並增強推理效用。最後，SkillRL 在 RL 訓練中引入遞迴技能演化機制，將技能庫視為動態組件而非靜態知識源：每個驗證 epoch 後分析失敗模式，生成新技能或修正既有技能，確保技能庫與策略共演化。

2. 預備知識

LLM 代理形式化：代理在互動環境中運作，每個時間步觀察狀態 o_t、選擇動作 a_t、獲得獎勵 r_t 與下一觀察 o_{t+1}。軌跡 τ 捕捉一個互動回合。任務由自然語言描述 d 指定。以參數 θ 參數化的 LLM 代理實現策略 π_θ(a_t | o_{≤t}, d, c)，其中 c 為額外上下文（如技能、示範）。目標是在上下文長度限制 |c| ≤ L_max 下最大化預期累積回報。

GRPO（群組相對策略優化）：GRPO（Shao et al., 2024）是一種避免訓練評論家的強化學習方法，透過群組內相對獎勵來優化策略。對每個查詢 x，模型取樣 G 個回應並評分，計算歸一化優勢後使用 PPO 風格的裁剪目標進行更新，目標函數包含重要性比率 r_i 的裁剪項與 KL 散度正則化項。其中 r_i = π_θ(y_i|x) / π_old(y_i|x)，歸一化優勢 A_i 由群組內獎勵的標準化計算。

3.1 基於經驗的技能蒸餾

原始軌跡包含探索性動作、回溯與冗餘步驟，掩蓋了導致成功或失敗的關鍵決策。為將經驗轉化為可執行知識，我們使用教師模型 M_T 將軌跡蒸餾為精簡、可復用的技能。

首先部署基礎 LLM 代理 π_base 在目標環境中收集多樣軌跡。與先前僅保留成功片段的方法不同，我們刻意同時保留成功軌跡 T^+ = {τ_i : r(τ_i) = 1} 與失敗軌跡 T^- = {τ_i : r(τ_i) = 0}。失敗軌跡揭示了僅從成功中難以推斷的失敗模式與邊界條件。

我們根據軌跡結果進行差異化處理。對成功軌跡 τ^+，提取導致任務完成的策略模式：教師模型識別關鍵決策點、正確行動背後的推理、以及可泛化的模式。對失敗軌跡 τ^-，直接納入上下文是不可行的（因其長度與雜訊），我們改為合成精簡的失敗教訓，分析：(1) 失敗點、(2) 錯誤推理或行動、(3) 應做之事、(4) 預防類似失敗的通用原則。這將冗長的失敗回合轉化為有價值的反事實經驗。

3.2 階層式技能庫（SkillBank）

遵循 Agent Skills（Anthropic, 2024）的設計原則，我們將蒸餾後的知識組織為階層式技能庫，實現高效的專業知識檢索。

技能組織分為兩個層級：(1) 通用技能 S_g 捕捉跨所有任務類型的通用策略原則，包括探索策略（系統性搜尋模式、優先訪問未探索節點）、狀態管理原則（在行動前驗證前提條件）、目標追蹤啟發式（維護進度計數器、僅在驗證完成後終止）——這些提供可跨任務類別遷移的基礎指導。(2) 任務特定技能 S_k 針對任務類別 k 的專屬知識，捕捉領域特定的動作序列、前提條件與約束、該任務類型獨有的常見失敗模式、以及利用任務結構的優化程序。

完整技能庫為 S_g ∪ ⋃_k S_k。每個技能包含：精簡名稱（如「系統性探索」）、策略描述、適用時機條件。此格式支援高效檢索並提供清晰的應用指導。

技能檢索：在推理時，給定任務描述 d，代理檢索相關技能以增強上下文。通用技能 S_g 始終包含作為基礎指導；任務特定技能透過語義相似度檢索：S_ret = TopK({s ∈ S_k : sim(e_d, e_s) > δ}, K)，其中 e_d、e_s 分別為任務描述與技能的嵌入向量，δ 為相似度閾值，K 控制檢索技能數量。策略隨後基於檢索到的技能進行決策。技能蒸餾相比原始軌跡實現了 10-20 倍的 token 壓縮，同時增強了原始經驗的效用。
