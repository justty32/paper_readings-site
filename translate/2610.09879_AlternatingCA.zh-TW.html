論文／訪談原始來源

簡單規則的重複排列如何構造通用計算

摘要與第 1 節：問題

基本細胞自動機中，Rule 110 的局部規則不具左右鏡像對稱性，並具有已知的圖靈通用性。作者研究另一種來源：每個局部規則本身都左右對稱且行為簡單，但讓不同規則按空間順序週期排列，整體排列就可具有左右方向性。（§1）

第 2 節：模擬 Rule 110

作者將三個二態、最近鄰規則按位置 i mod 3 週期分配：餘數 0 用 Rule 36，1 用 Rule 37，2 用 Rule 5。三者均左右鏡像對稱：（§2，圖 1～2）

  • Rule 36：當且僅當兩側鄰居均與中心格的顏色相反，下一狀態為 1。
  • Rule 37：除 Rule 36 的條件外，三格皆為 0 時也令下一狀態為 1。
  • Rule 5：當且僅當左右兩鄰居均為 0，下一狀態為 1。

將 Rule 110 的邏輯 0 編為三格 [100]、邏輯 1 編為 [000]，並讓編碼區塊與上述規則的三格週期對齊，此混合系統演化三步後，對應 Rule 110 的一步。作者以局部狀態轉移表說明此模擬精確；依既有 Rule 110 的通用計算構造，每邏輯格和每邏輯步分別使用三格和三步，故額外空間與時間倍率都是常數 3。此結論針對上述編碼與同步條件。（§2，圖 2）

三種規則均無法自行區分左右，但 36、37、5 的空間順序及其反向並非平移後同一排列，因而可提供方向性。作者指出，週期為二的兩個對稱規則排列，或週期三中只有兩種規則的排列，反向後可透過平移重合；要在週期三以此方式打破對稱，需三種不同規則。作者另指出兩種規則可在至少週期六形成非鏡像等價排列；這個對稱性觀察本身不證明該兩規則排列能模擬 Rule 110。（§2）

第 3 節：隨機初始條件

作者以週期邊界的有限格點模擬隨機初態，觀察不同區域可能各自模擬 Rule 110，但三步週期相位不同。區域間的 domain wall 可移動；相向的牆碰撞並消失時，系統可能最後鎖定至同一相位。作者也觀察到向左移動的牆可能使一個區域擴張並接管系統，而向右移動、彼此分離的牆可能一直不相遇。（§3，圖 3）

作者報告在測試的格點長度 N≥256 下，約 91～100% 的執行鎖定至 Rule 110 相位；其餘約 0～9% 在模擬中未鎖定，比例依大小而變。已鎖定執行的時間整體約隨 N² 增長；作者註明部分未鎖定者，尤其最大系統，可能只是暫態超過模擬時間。這是有限模擬的觀察，並非所有隨機初態最終都鎖定的證明。（§3，圖 3）

第 4 節：含雜訊的動態

作者讓每個 bit 在每步以機率 ε 隨機翻轉。翻轉可能在數步後被修復，也可能以機率 p 產生一對向相反方向移動的 domain wall。簡化速率模型以每區塊三個 bit 推出牆的產生率 6pε，並以左右各半、相遇時成對消除的近似寫成：

dn/dt = 6pε − 4v(n/2)²，因此穩態 n* = √(6pε/v)。

作者從模擬估得 p≈0.23、左右速度分別約 0.236 與 0.219 區塊／步，取平均 v≈0.2275；觀察到穩態牆密度大致隨 √ε 變化。雜訊較大時牆彼此接近並互相干擾，獨立牆近似失準；實際接近穩態也比簡單速率式慢。（§4，式 1～2、圖 4）

第 5～6 節：討論與範圍

作者提出，以此穩態密度作粗略估算，長度 L 個區塊若滿足 n*L<1，對應雜訊約需 ε < v/(6pL²) ≈ 0.16/L²。這是所用模型下的粗略尺度條件，並非保證一段區域在所有時間都沒有錯誤。（§5）

作者指出，三種簡單規則的排列將方向性放在結構而非局部規則中，但此構造的描述資訊量未少於單一 Rule 110；生物組織與物理系統的聯繫是作者提出的類比和可能研究方向。三格也可視為一個超格，將整體改寫成均勻的八態細胞自動機。（§5～6）

本檔補註，非作者自陳：精確模擬所給的通用性與隨機初態鎖定、含雜訊時的牆密度是不同結論；後兩項模擬不能直接證明含雜訊系統仍可靠地完成任意計算。

重點摘要見 交替規則細胞自動機摘要。
