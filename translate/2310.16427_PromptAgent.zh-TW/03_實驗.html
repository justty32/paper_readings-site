4. 實驗

4.1 實驗設定

任務與資料集：為全面評估專家級提示詞優化在多種應用上的效果，本文從三個互異領域精選 12 個任務：BIG-Bench Hard (BBH)——挑戰性子集中選出 6 個任務，兼顧領域知識（幾何形狀、因果判斷）與複雜推理（企鵝表格、物件計數、認知推理、時間序列）；三個生醫領域專屬任務——疾病命名實體識別 NCBI、生醫句子相似度 Biosses、醫學問答 MedQA；三個知名通用 NLU 任務——兩個文本分類（TREC、Subj）與一個自然語言推理（CB）。

基線：與三類基線比較：(1) 人類提示詞——來自原始資料集的通用水準指令，含 zero-shot 與 few-shot 版本；(2) CoT 提示詞——含 zero-shot（"Let's think step by step"）與 few-shot 版本；(3) 提示詞優化方法，含 GPT Agent（用 GPT-4 搭配 ChatGPT 外掛 AI Agents，以與 PromptAgent 相近的迭代次數取樣模型錯誤並改寫提示詞）與 APE（用蒙地卡羅搜尋迭代提出並選擇提示詞）。

實作細節：基底 LLM 預設 GPT-3.5，優化器 LLM 預設 GPT-4（需要良好的自我反思能力）；基底 LLM 預測時溫度設 0.0，其餘情境溫度 1.0。MCTS 迭代次數設 12，UCT 公式的探索權重 c 設 2.5；expansion 時取樣 expand_width 個批次、每批次生成 num_samples 個新提示詞，每條路徑最大深度為 depth_limit。為簡化超參數調整，探索 Standard、Wide、Lite 三種設定（Standard/Lite 深度較大，Wide 每步生成節點較多），依獎勵挑選最佳設定。

4.2 結果與分析

與各類提示詞基線比較：在 BBH 上，PromptAgent 全面顯著優於所有基線，較人類 zero-shot、CoT、APE 分別有 28.9%、9.5%、11.2% 的相對提升（六題平均：人類 ZS 0.513、CoT 0.707、APE 0.690、PromptAgent 0.802）。值得注意的是 CoT 提示詞在 BBH 上特別有效（呼應 Suzgun et al. 的發現），因為 BBH 任務通常需要格式嚴謹的解法、能被逐步推理的 CoT 順暢誘導出來，這也解釋了 CoT 為何在 Object Counting 上表現極佳。儘管如此，PromptAgent 在除 Object Counting 外的所有任務上仍大幅超越 CoT，顯示優化後的專家級提示詞（即便在零樣本設定下）能帶來比 few-shot CoT 推理更大的提升。在生醫領域專屬與通用 NLP 任務上（Table 2），直白的人類與 CoT 提示詞表現皆不理想，APE 這類自動取樣精煉的優化方法較有希望融入領域知識；PromptAgent 較 APE 平均再提升 7.3%（生醫任務平均 0.655 vs 0.582），顯示其能更有效誘導領域知識、彌合新手與專家提示工程師的落差；通用 NLP 任務上則分別以 +16.9%（vs CoT）與 +9%（vs APE）的幅度勝出（平均 0.868），顯示即便一般任務也存在不容小覷的專家落差。

提示詞泛化性：本文進一步檢驗優化後提示詞能否遷移到其他基底 LLM。這牽涉兩個關鍵事實：(a) 專家提示詞中的領域洞見與細膩引導能否無縫遷移到不同強度的 LLM 上，強化其普適性；(b) 若可行，每個任務只需優化一次，帶來更好的計算效率。需注意 PromptAgent 的首要目標是為最先進 LLM 優化出專家級提示詞，能力較弱、較小的模型（如 GPT-2、LLaMA）未必能妥善掌握這些細膩提示詞的精妙之處，可能導致性能明顯下滑。實驗把用 GPT-3.5 優化出的提示詞直接套到 GPT-4（更強）與 PaLM 2 chat-bison-001（較弱）上：套到 GPT-4，專家提示詞在幾乎所有任務（11/12）上與人類、APE 基線持平或更優（唯一例外 Temporal 已被 GPT-4 解到近乎滿分，屬「已解決任務」）；套到較弱的 PaLM 2，整體表現大幅下滑，但 PromptAgent 仍在 7/12 任務勝過兩個基線，尤其在 NCBI 等生醫領域專屬任務上優勢明顯，佐證領域洞見的實用性。

搜尋策略消融（Table 4）：為系統性檢驗策略規劃的效果，把 MCTS 換成單步隨機的 Monte Carlo (MC)、逐層選最優的貪婪深度優先搜尋 (Greedy)、以及維持多條有希望路徑的 Beam search，其餘動作生成與狀態轉移邏輯保持一致，並在相同探索節點總數下比較（五個代表性任務：Penguins、Biosses、Geometry、Causal、Subj）。結果顯示 Greedy 與 Beam 都比 MC 大幅提升，證實結構化迭代探索的必要性；Beam 與 Greedy 表現相近，但兩者都只能嚴格前向操作、無法前瞻未來結果也無法回溯過去決策；MCTS 的策略規劃則明顯全面勝出（平均 0.754 vs Beam 0.697、Greedy 0.698、MC 0.635），較最佳消融基線再提升 5.6%。

探索效率分析：除表現優異外，PromptAgent 的另一關鍵優勢是能透過策略規劃高效探索提示詞空間——這對控制搜尋的計算成本也至關重要。比較 PromptAgent 與 Greedy Search（Greedy-S 探索 34 個、Greedy-L 探索 72 個提示詞）及 APE（每任務探索 150 個提示詞）發現，PromptAgent 的表現點集中在「準確率高、探索節點少」的左上角象限；增加 Greedy Search 的探索量（Greedy-S → Greedy-L）雖能提升表現，卻要付出更高探索成本且仍不及 PromptAgent；缺乏有原則引導的無方向性搜尋（如 APE）即便探索量更大，效果提升也有限。

收斂分析：以 Epistemic 任務為例，逐樹深度彙總所有節點的訓練（獎勵）與測試表現，觀察到訓練與測試曲線一開始都上升，並在深度 3 之後趨於穩定，顯示學習過程穩健；其他任務的收斂曲線也呈現類似的初期上升趨勢，反映 PromptAgent 迭代精煉提示詞的過程具有穩健的學習動態。

質化分析（Table 5、圖 5，NCBI 疾病實體抽取任務）：從人類手寫的初始提示詞 s₀「Extract the disease or condition from the sentence, if any is mentioned.」（F1 0.521）出發，PromptAgent 經三次狀態轉移逐步注入領域細節——最終狀態 s₃（F1 0.645）不僅要求「排除遺傳模式、基因/基因座、蛋白質、生物路徑等易混淆元素」「不得依進階生物學術語做推論」「同時考慮特定疾病與較廣泛的類別、含常見縮寫」，還規定輸出格式與空結果處理方式，並特別註明「locus 應視為基因體位置而非疾病名」。相較之下，APE 優化出的提示詞（F1 0.576）「If any disease or condition is mentioned in the sentence, extract it.」僅是對人類提示詞的措辭微調，並未注入額外領域知識。整體而言，PromptAgent 的提示詞在術語釐清、解法引導、例外處理等多個面向都比人類與 APE 提示詞更完整詳實；論文也指出未來可探索提示詞壓縮技術以在不犧牲表現下精簡專家提示詞。

5. 結論

本文提出 PromptAgent，一個能自主為給定任務打造專家級提示詞的新型提示詞優化框架。專家級提示詞的特點在於能無縫融入領域洞見、彌合領域專家的知識落差。為達成此目標，PromptAgent 的核心是把提示詞優化視為策略規劃問題，運用 MCTS 規劃的力量策略性、高效地在複雜提示詞空間中穿梭，並以基於 LLM 自我反思能力的試誤方式，把任務的領域專屬知識融入新生成的提示詞。實驗在橫跨三大領域的 12 個多樣任務上測試 PromptAgent，優化後的提示詞一致展現出富含領域細節與引導的專家級特質，顯著超越人類手寫、CoT 提示以及其他優化方法基線。進一步的深入分析顯示，其專家提示詞具備優異的可遷移性、探索效率與品質，為未來提示詞工程解鎖最先進 LLM 的精細任務理解鋪路。
