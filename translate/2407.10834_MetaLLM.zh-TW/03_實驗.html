4. 實驗

4.1 設定

  • LLM 服務：OpenAI 四模型 text-ada-001 / babbage-001 / curie-001 / davinci-002（價格 $0.40 / $0.50 / $2.00 / $20.00 每 1M tokens）；Together AI 四模型 Gemma / Llama / Mistral / Qwen（$0.10 / $0.18 / $0.20 / $0.30 每 1M tokens，跨家族、異質性更高）。OpenAI 用情感二分類 prompt，Together AI 用多選題（只回 A/B/C/D）prompt。
  • 資料集：SST-2（電影評論情感二分類，67,439 訓練 / 872 測試）；MMLU（57 個多選 QA 子任務，14,042 測試 / 99,842 輔助訓練）。
  • 訓練 MetaLLM：以 Sentence-BERT 抽 query 嵌入，線性模型映射到 reward 期望，用式 4 真實 reward 以演算法 1 優化。reward 中成本正規化到最大為 1。對每個預算 b，調 p 使驗證集成本 ≤ b。評估三情境：(i) 只用訓練資料離線優化；(ii) 只在推論時線上更新；(iii) 訓練初始化 + 線上更新。報告每 10,000 個 query 的平均成本。

4.2 OpenAI 模型上的表現（表 3）

成本較高的 LLM 準確率較好，但成本差距懸殊：text-davinci-002 比 curie 貴十倍，準確率卻只高 0.4%，故只查最貴模型並不划算。

設定 方法 測試成本 測試準確率
單一 text-ada-001 0.096 80.50
單一 text-babbage-001 0.120 82.80
單一 text-curie-001 0.480 90.60
單一 text-davinci-002 4.800 91.51
Online MetaLLM（babbage 預算） 0.117 84.06
Online MetaLLM（curie 預算） 0.455 90.94
Online MetaLLM（davinci 預算） 2.046 92.55

MetaLLM 能以更低成本取得更高準確率：同 babbage 預算下比 default babbage 高約 2% 且更省；最關鍵的是——它勝過 default 到最佳模型 text-davinci-002，卻少花約 60%。三情境比較顯示：只用訓練資料優化已能勝過 davinci，但不如加上線上更新；且初始化很重要，只靠線上更新找不到好策略。

4.3 不同 LLM 的異質能力

MetaLLM 能勝過最貴的 OpenAI 模型，意味 LLM 的表現會逐 query 變化、無法只由成本（或模型大小）決定。圖 2 / 圖 3（混淆式矩陣）要旨：位置 (i,j) 是「第 i 個模型答對但第 j 個答錯」的樣本數；可見大量 query 被小模型（ada、babbage）答對、卻被 curie、davinci 答錯。若 MetaLLM 能利用這種「表現與成本的異質關係」，就能顯著超越單一模型。

4.4 帶動態成本的 reward 函數

LLM 成本並非每個輸入固定（零樣本分類下主要取決於 query 長度）。實驗用「每個訓練輸入的實際成本」放入 reward（式 4）並與固定成本比較（圖 3）：動態成本未帶來顯著改善，高預算時甚至準確率更低。推測是動態成本對長 query 施加更大懲罰，逼 MetaLLM 把它們路由到便宜模型，但這些長 query 往往更複雜、便宜模型未必解得好。因此建議用固定成本訓練。

4.5 Together AI 上的表現（表 4，MMLU）

此設定 LLM 更異質（便宜模型在某些 query 上勝過貴的）。

設定 方法 測試成本 測試準確率
單一 Gemma 866.187 64.33
單一 Llama 1559.136 76.69
單一 Mistral 1732.374 66.68
單一 Qwen 2598.561 80.24
Online MetaLLM（Llama 預算） 1540.663 76.87
Online MetaLLM（Qwen 預算） 2304.500 80.90

Default 單一模型時，更貴不保證更好（Mistral 比 Llama 貴卻更差）。以 p=0 訓練 MetaLLM 在 MMLU 上拿到最佳 80.90%。由於輔助訓練集分佈遠離測試集，只做離線優化無法得好策略；而缺少初始化時，拍霸機只會 default 到 Gemma。設正的 p 能大幅降成本、準確率僅略降。MetaLLM 能勝過次佳的 Llama 且成本更低，再次印證其「低成本又高效能」。

4.6 成本縮放參數 p 的分析

圖 4 / 圖 5（直方圖）要旨：只優化表現（p=0）時，MetaLLM 確實能學到「某 LLM 是否能準確作答」——如 §4.3 所述有很多 query 可由便宜的 babbage 答對，MetaLLM 選 babbage 的次數多於 curie 或 davinci。加入小正則 p=0.001 後，MetaLLM 幾乎不選最貴的 davinci，卻仍達 90.98% 準確率（仍優於 default 最貴模型）。

5. 結論

本文研究「從一組 LLM 中為輸入動態選出兼顧表現與成本效益的那一個」，提出多臂拍霸機框架 MetaLLM，能學到「以低價查到正確模型」的 reward。它輕量、適用任意現成 LLM 套件、實務通用。實驗顯示 MetaLLM 把最佳 API 準確率再提升約 1%，同時把零樣本文字分類與多選 QA 的成本大幅降低最多 60%。

6. 局限與社會影響

  • 局限：(1) 只驗證零樣本文字分類（對錯與 reward 好設定），雖足以展示潛力，但推廣到 QA / 文字生成須設計更複雜的 reward，值得獨立研究；(2) MetaLLM 只訓練「以 query 特徵為輸入」的簡單線性模型，忽略更細粒度特徵；(3) reward 只納入表現與成本兩項，尚可加入推論時間、穩健性、emergent ability、訓練分佈資訊等以打造更可靠的 AI 系統。
  • 社會影響：大模型推論成本高、部署昂貴、且高耗電對環境有害。MetaLLM 藉由把輸入路由到「可能答對的較便宜模型」大幅降低查詢成本，甚至能靠多 LLM 組合提升表現，適用於任意現成 LLM，對未來 AI 系統有益。
