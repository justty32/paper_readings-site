ARC Is a Vision Problem!

Runqian Wang、Yeyin Eva Zhu、Jacob Andreas、Kaiming He（MIT）

摘要

抽象與推理語料庫（ARC）旨在推動抽象推理（人類智能的根本面向）研究。本文把 ARC 置於視覺範式中，框定為影像到影像翻譯（image-to-image translation）問題。為注入視覺先驗，我們把輸入表示在一張可像自然影像般處理的「畫布（canvas）」上，於是能很自然地套用標準視覺架構——如原版 Vision Transformer（ViT）——來做影像到影像映射。模型只用 ARC 資料從零訓練，並透過**測試時訓練（TTT）**泛化到未見任務。我們的框架 VARC（Vision ARC） 在 ARC-1 基準達 60.4% 準確率，大幅超越同樣從零訓練的既有方法，與報告的人類平均表現持平。

1. 引言

ARC 基準（Chollet 2019）旨在激勵改進抽象推理能力的機器學習研究。我們把每道謎題框定為影像到影像翻譯問題。核心主張：抽象與推斷可直接從視覺學習中浮現，無須顯式的語言中介。如圖示，三道任務的底層概念可被人類粗略描述為「反射」「對稱」「重力」——這些概念緊密關聯於視覺與物理世界。此視角把 ARC 連到經典影像到影像問題，從低階影像處理到高階影像理解（FCN、U-Net 等）。

為利於學到這些先驗，我們把輸入表示在一張帶彈性幾何變換的「畫布」上，使其能當自然影像處理。畫布上一個 patch 可有指數多種顏色組合，這有助降低過擬合、鼓勵模型學空間先驗而非死記。

VARC（僅 18M 參數的小模型）在 ARC-1 達 54.5%，大幅超越同樣從零訓練的最佳遞迴方法（Hierarchical Reasoning Model、Tiny Recursive 等）。再透過集成（ensembling） VARC 模型，準確率進一步提升到 60.4%，與人類平均表現持平（LeGris 2024）。

2. 相關工作

  • 視覺推理：與一般視覺推理脈絡相連。
  • ARC 的各種路線：既有方法多在離散值 token 空間操作（受語言模型設計啟發）。相關地，ViT-ARC 方法亦嘗試用視覺模型處理 ARC。我們的影像到影像翻譯表述則探索視覺原生的設計。

3. 把 ARC 當視覺問題

3.1 ARC 問題定義

一個任務含一組示範（訓練集，輸入-輸出格子對）與一個測試輸入。我們把每個任務的推理形式化為影像到影像翻譯，框成逐像素分類（類比語意分割 FCN）。

3.2 影像到影像翻譯

不同於既有在離散 token 空間操作的方法，我們在此表述中探索視覺原生設計。

3.3 視覺建模

  • 畫布（Canvas）：預定義且夠大的尺寸（如 64×64）。原始輸入經變換放上畫布；背景設為額外的第 (C+1) 色。此表述自然容納平移與縮放增強，且支援比 token 法大得多的局部 patch 級配置。
  • 平移與縮放不變性：「畫布」讓我們能彈性套用平移、縮放增強（標準視覺模型的關鍵）——
    • 平移增強：把縮放後格子隨機放上固定大小畫布，確保所有像素可見。
    • 縮放增強：對格子隨機縮放。 這些增強逼模型學「對源自視覺世界的幾何變換不變」的底層映射。
  • Vision Transformer：用原版 ViT。
  • 2D 位置嵌入、patchification：標準視覺設計。
  • 替代：卷積網路：亦比較 U-Net 等卷積架構。

3.4 兩階段訓練

  • 離線訓練：只在 ARC 資料上從零訓練。
  • 測試時訓練（TTT）：對目標任務的示範對微調，使模型泛化到未見任務。

3.5 推論

  • 單視圖推論 vs 多視圖（multi-view）推論：多種畫布擺放/變換下做預測再彙整。
  • Pass@2 準確率：每題給兩個猜測，任一全對即算對。

4. 實作細節

涵蓋畫布設定、離線訓練、測試時訓練的具體配置與形狀處理。

5. 實驗結果

  • 5.1 視覺先驗：消融 2D 位置嵌入、patchification、平移/縮放增強——皆對成效關鍵。
  • 5.2 其他消融：ViT 優於 U-Net；離線訓練資料量可擴展；TTT 策略與單視圖 vs 多視圖推論顯著影響準確率。
  • 5.3 系統級比較：單模型 18M 達 54.5%，集成達 60.4%，與人類平均持平，超越從零訓練的遞迴方法。

6. 視覺化與分析

  • 注意力圖：呈現模型關注的空間結構（逐像素、逐層注意力圖）。
  • 任務嵌入 t-SNE：顯示模型學到有意義的任務結構。

7. 結論

把 ARC 重新框定為影像到影像翻譯的視覺問題，配上畫布表示＋幾何增強＋原版 ViT＋測試時訓練，僅用 ARC 資料從零訓練即可達與人類平均持平的 60.4%。這顯示抽象推理可直接從視覺學習浮現，無須語言中介，為 ARC 提供了一條與 LLM/token 路線截然不同的視覺原生路徑。
