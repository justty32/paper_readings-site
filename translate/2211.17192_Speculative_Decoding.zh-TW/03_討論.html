6. 討論

本文提出 speculative sampling，實現高效的隨機推測執行；並透過 speculative decoding 分析其對自迴歸解碼的影響，證明在算力充足時可得實測 2X–3X 加速（相對成熟的 T5X）。

局限：推測執行（含本法）的通性是——以「增加算術運算量」換「靠提高並行度降低延遲」，故在「無額外算力可用」的配置下無益。但在常見的「算力有餘（如記憶體頻寬是瓶頸）」情境，本法帶來加速且有顯著好處：不改架構、不需重訓，最重要的是保證輸出分佈不變；易於實作、可用現成模型加速而無需開發與評估客製方案。

未來方向：與 beam search 的相容性（附錄 A.4）、客製近似模型（客製架構 / 非自迴歸 / 啟發式，或以蒸餾、直接對 α 優化 Mq 來訓練）、分層版演算法（近似模型本身再被更快模型加速）、執行中動態調整近似模型與 γ（§3.5）、不同的機率變換、以及文字以外的模態（如影像）。此外，隨機推測執行與 speculative sampling 也可用在自迴歸解碼之外——例如給定兩個慢函式 f(x)、g(y)，其中 f 產生的分佈作為 g 的輸入，就能用本法讓 f 與 g 平行跑（如物理模擬，或強化學習中 f 是產生動作分佈的大模型、g 是世界模擬）。

附錄要點

  • A.1 正確性證明：對任意 p、q，經 speculative sampling 抽出的 token 與單獨從 p 抽樣分佈相同。關鍵：調整後分佈 p′(x) 的正規化常數為 1−β；P(x=x′) = P（接受） + P（拒絕） = min(p,q) + (p−min(p,q)) = p(x′)。這就是「無損」的形式證明。
  • A.2 vs. 拒絕抽樣：本法的期望接受機率 α 高於（可能高很多）非迭代版拒絕抽樣，故更高效。
  • A.3 理論 vs. 實測：表 4 顯示理論預測大致吻合實測，差異來自實作最佳化差異與 β i.i.d. 假設僅為近似。
  • A.4 beam search：本法可套用（有些效能損失）：用 Mq 以較大 beam width u≥w 跑 γ 步，再用 Mp 平行檢查所有候選（成本 (w+uγ) 次 Mp），當 topw(Mp)⊆topu(Mq) 時可接受，得與單獨用 Mp 的 beam search 相同結果。詳析留未來工作。
  • A.5 寬容度（lenience）：若願意放寬「完全等同」，可引入寬容參數 l∈[0,1]，比較前把 q(x) 乘上 l，仍保證「無 token 被抽到的機率超過 p(x)/l」。Mp=T5-XXL、Mq=T5-small、EnDe 標準抽樣，l=1/0.5/0.3/0.1（意即無 token 被抽機率超過真值 1X/2X/3X/10X）時，α 分別為 0.62/0.71/0.76/0.84、加速 2.5X/3.1X/3.6X/5X（c=0.015）。注意本文除本節外，一律採最嚴格版本、不允許任何寬容。
