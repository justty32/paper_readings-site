摘要

近期 meta-learning 進展已能自動發現以代理目標函數（surrogate objective functions）參數化的新 RL 演算法。要勝過人工設計的演算法，這個學到的目標函數的參數化既要夠表達力以表示新的學習原則（而非僅復現既有原則），又要能泛化到 meta-training 分佈之外的廣泛設定。然而，既有方法所發現的目標函數（如許多廣用 RL 目標函數）不考慮訓練所允許的總步數（「訓練時程，training horizon」）。相對地，人類在習得新能力的過程中會用各式各樣的學習目標——例如學生會依考試臨近程度與自評能力調整讀書法。本文主張：忽略最佳化時程會顯著限制被發現學習演算法的表達潛力。我們對兩種既有目標發現方法提出一個簡單增補，讓被發現的演算法能在 agent 訓練過程中動態更新自己的目標函數，產生具表達力的排程、並在不同訓練時程間提升泛化。過程中我們發現：常用的 meta-gradient 方法無法發現這種自適應目標函數，而演化策略（ES）能發現高度動態的學習規則。我們在廣泛任務上展示有效性，並分析學到的演算法——它們透過在 agent 壽命中改變學習規則的結構來有效平衡探索與利用。

1. 引言

RL 進展歷來來自人工試誤或理論洞見的手工演算法；近期則嘗試自動發現新 RL 演算法。手工 RL 演算法的一個經充分研究的特徵是：更新會適應總步數與剩餘步數。這種對「感知學習時程」的適應，連人類都有（如學生用間隔重複系統、以遞減間隔最大化學習進度）。

本文以 meta-learning 發現「能感知並適應剩餘學習時間」的新 RL 目標函數。我們修改 LPG（Learned Policy Gradient） 與 LPO（Learned Policy Optimization） 兩種近期 meta-learned 目標方法，使其直接以 agent 壽命的時間資訊為條件。我們發現 meta-最佳化方法是成功利用此資訊的關鍵組件，稱此為「壽命條件化（lifetime conditioning）」：用短視代理目標的 meta-gradient 方法（如 LPG）學不到動態更新；改用演化策略（ES）——它以 RL agent 整個壽命結束後的最終回報計算適應度——則能讓兩種方法都發現「在學習過程中動態適應」的目標函數。

在分佈內與分佈外環境（從連續控制到類 Atari 離散設定）、跨多種訓練時程上評估，學到的目標函數顯著勝過其非時間感知版本，並改善對未見時程與環境的泛化。結果凸顯「壽命條件化 + ES」在 meta-learn 時間感知目標函數時的協同效應。

貢獻：(1) 提出 LPG/LPO 的時間感知版 TA-LPG / TA-LPO——增廣其輸入空間以含時間資訊，可直接以總/剩餘訓練時程為條件。(2) 比較 meta-gradient 與演化式 meta-最佳化，發現 meta-gradient 學不到時間感知更新，據此為 TA-LPG 採用 ES 並提出多任務 meta-learning 的簡單適配。(3) meta-train 後在一系列評估環境上測試，時間感知目標函數勝過所有基線、泛化到未見環境與時程。(4) 分析被發現目標函數萃取出的動態排程，發現它們實作了動態策略重要度比率裁剪，外加適應訓練時程的更新與熵退火排程，藉此平衡探索與利用。

2. 相關工作

  • meta-learning 基礎：「學習去學習」旨在端到端發現新學習原則，可分 meta-gradient 與基於記憶（in-context learning）兩類。兩大考量：被 meta-最佳化的媒介該多有彈性（歸納偏置能穩定/提效，但可能阻礙真正新穎的發現）；如何避免過擬合 meta-train 任務分佈與 rollout 時程。本文主張：讓學到的演算法感知 agent 學習時程可同時對付這兩個核心問題。
  • meta-learning 目標函數：一條路線是 meta-最佳化參數化目標函數來表示學習演算法，近期有 MetaGenRL、LPG、LPO、GROOVE；亦有用符號方法取得可解釋 RL 演算法（Alet 2020；Co-Reyes 2021，即 2101.03958）。本文利用 LPG/LPO，證明「讓演算法知道自己在總壽命中的當前位置」可再提升表現。
  • 演化／零階方法做 meta-最佳化：已知 meta-gradient 因記憶體限制與混沌動態只能跑很短的內迴圈展開，導致被發現元件短視（myopia）。替代方案是用演化做黑箱最佳化，繞過高階梯度計算、容許完整演算法 rollout。

3. 背景

3.1 meta 強化學習

發現新 RL 演算法是 meta-RL 的一種。多數 meta-RL 旨在適應少量任務（變動獎勵或環境參數）；本文跟隨「meta-learn 能跨廣泛 RL 環境學習的演算法」這條線。MDP 定義為 ⟨S,A,R,P,γ,d⟩，目標是找最大化期望折扣回報 J(π_θ) 的策略。meta-最佳化在 RL 演算法空間操作，以 meta-參數 ϕ 表示、用來更新策略參數 θ（如 ϕ 參數化損失 L_ϕ，則 θ_{k+1}=θ_k − η∇_θ L_ϕ(θ_k)）。最大化 K 次更新後（或訓練結束時）的期望回報 F(ϕ) = E_{θ0}[J(π_{θK})]。聚焦兩個近期實例：LPG 與 LPO。

3.2 Learned Policy Gradient（LPG）

LPG 推廣 actor-critic：critic 不輸出純量價值估計，而輸出一個 bootstrap 向量，其意義由 LPG meta-learn（可編碼超越價值估計的資訊，如狀態造訪）。LPG 以 LSTM 參數化、逆序迭代 agent 轉移序列，於時刻 t 輸出更新目標 ŷ_t, π̂_t = U_ϕ(x_t | x_{t+1},...,x_T)。輸入向量由轉移建構：x_t = [r_t, d_t, γ, π_θ(a_t|s_t), y_θ(s_t), y_θ(s_{t+1})]（含獎勵、episode 終止旗標、折扣、所選動作機率、當前與下一狀態的 bootstrap 向量）。目標 ŷ、π̂ 分別更新 critic 與策略：Δθ ∝ E_τ[∇_θ log π_θ(a|s)·π̂ − α_y ∇_θ D_KL(y_θ||ŷ)]。LPG 用 meta-gradient 跨多步更新最佳化、最大化訓練結束時策略回報；此計算須對 agent 整個學習過程反向傳播、受記憶體限制，故實務上用截斷反向傳播視窗（只對 k≪K 步最佳化）。

3.3 Learned Policy Optimisation（LPO）

LPO 繼承 Mirror Learning 框架的理論收斂保證。Mirror Learning 中 agent 最大化 E_{a∼π_new}[Q^{π_old}(s,a)] − D^{π_old}(π_new|s)，其中 D 是 drift 函數（把給定狀態下兩策略映到純量）。若 D 滿足特定條件（處處非負且在恆等處為零、其對 π 的梯度在 π=π_k 處為零），Mirror Learning 可證明單調改善並在極限收斂到最優回報。許多既有 RL 演算法是其特例——尤其 PPO（其裁剪目標可重構成 drift 函數）。LPO 以神經網路參數化 D，並刻意設計輸入與架構以保證 drift 條件成立：網路不用 bias 參數，輸入為 x_{p,A} = [(1−p),(1−p)²,(1−p)A,(1−p)²A,log(p),log(p)²,log(p)A,log(p)²A]，其中 p 是當前與原策略的機率比、A 是估計優勢。LPO 用 ES 最佳化 D——ES 從樣本估計平滑化黑箱函數的梯度。
