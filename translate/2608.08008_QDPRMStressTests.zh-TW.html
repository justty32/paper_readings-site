論文／訪談原始來源

PRM 的 QD 壓力測試與 coverage 證書

摘要

PRM 會把錯誤中間推理評得較高。作者以 MAP-Elites 在 behavior space 尋找 correctness-flipping edit，保存每格最嚴重的 attack。有限格的修補可界定已覆蓋部分的風險；coverage fraction 不能界定全域最壞情況。metric cover 加 Lipschitz 假設才可得到連續的 residual bound。

1–3. 形式化

attack 的 gain 是 edit 前後 PRM 分數差，只有原本正確、edit 後不正確且 gain 正才算 strict exploit。descriptor 描述 attack 行為；每 cell 的 elite 是最大 severity。這使 archive 既是搜尋紀錄也是修補樣本，但 descriptor 的選擇決定看得見哪些漏洞。

作者把 occupancy、找到 exploit、可證修補分成三種 coverage。這個區分很關鍵：踩過一個 cell 不代表找過所有攻擊，找過 attack 也不代表修補外溢到鄰格。

4. Quality-diversity discovery

MAP-Elites 每次 mutation／評估後，若候選在其 cell 的 severity 更高便取代 elite。相較只最大化單一分數，此法保留多種 failure mode，可對修補資料避免 mode collapse；但也不能保證未訪問或 descriptor 外區域安全。

5. Repair 與證書

finite-cell theorem 對已修補 cell 提供 tail／平均 residual 的 coverage-indexed 結論，仍允許未覆蓋 cell 有任意大的 worst loss。作者構造反例證明 fraction-only 不能控制 supremum。若 post-repair loss 是 L-Lipschitz，audit set 真正覆蓋 descriptor metric space，則 residual 至多是 archive fitting error 加 L 乘 cover radius。這些是條件式定理，不是對任一實驗 archive 的免費保證。

6. 實驗

controlled field 支持理論形狀。真實部分以 GSM8K 與 Qwen2.5-Math-PRM-7B：mean pooling 找到 44 個 strict padding exploits，最大 gain 0.294；minimum pooling 僅一個。合成控制顯示 padding 本身足夠造成問題，RLHFlow value-head 亦出現較小的同質現象（最大 0.005）。

paired LoRA repair（先前宣告）將 exploit rate 0.148 降至 0.037–0.074，worst gain 0.333 降至 0.177–0.212，ranking AUROC 提升而 best-of-4 未降。fresh unpaired re-audit 44→1；clean-split 最大 0.0092，MATH-500 41→0、clean ranking 40/40。這些是該訓練／評估 protocol 的結果；作者的配對分析認為主因是 adversarial fine-tuning，不是 archive 多樣性。

7. 結論與審計提醒

真實 archive 套入證書時計算的數值僅是 plug-in diagnostics：五項輸入是下界或未驗證假設，spillover 亦無界。coverage 只有在 cell 的語義、搜索完整度、repair 與 metric cover 均可稽核時，才接近可靠性證據。本文最實用的結論是報告「哪一種 coverage、在哪些前提」；不要以一個比例取代安全主張。
