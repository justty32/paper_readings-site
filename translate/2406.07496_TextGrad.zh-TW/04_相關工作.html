4. 相關工作

prompt 優化：實務上 few-shot 選例、in-context learning、CoT、ensemble 都能顯著提升 LLM 表現。自動化方面，白箱數值梯度法可優化 prompt 但需存取模型參數、無法用於閉源模型；亦有多項工作用 LLM 當 prompt 優化器。

與本文哲學最接近的兩項靈感來源：

  • DSPy：開創「把複雜 LLM 系統視為可能多層的程式、以程式化方式建構與優化」的觀點，框架完整、在多種問答/推理/prompt 優化任務上改善表現。本文取不同視角：反向傳播及其延伸可作為優化新一代 AI 系統的通用強力框架，並執行 prompt 優化之外的多種任務——我們不只把指令或示範當變數，也把我們真正在意的實例本身（分子、治療計畫、程式片段等）當變數優化。
  • ProTeGi（Prompt Optimization with Textual Gradients）：在 prompt 優化脈絡下定義了「文本梯度」（梯度＝LLM 針對任務錯誤給出的自然語言反饋）。本文把這個類比從 prompt 優化擴展到更廣的自動微分，並大幅超出 prompt 優化任務。DSPy 與 ProTeGi 都聚焦 prompt 優化，而 TextGrad 的重要進展在於 instance optimization。

更廣義地，有一條「用 LLM 當批評者或優化器」的新興工作線。我們提出單一而通用的框架並在多種應用上成功驗證；在此框架內可推理如何優化 LLM 的鏈或堆疊（傳播自然語言反饋），並把測試時訓練、解答自我精修/自我改進等問題化為幾行程式碼。我們也已從傳統優化文獻搬來 momentum、批次優化、以自然語言表達的約束優化等類比——這開啟了「在同一框架內設計新一代優化算法」的大片空間。

5. 討論

TextGrad 建立於三個關鍵原則：(i) 通用且高效能，不為特定領域手工打造；(ii) 易用，鏡像 PyTorch 抽象以利知識遷移；(iii) 完全開源。透過它我們在程式碼優化與 PhD 級問答上取得 SOTA，優化了 prompt，並在分子設計、治療計畫等科學應用上提供概念驗證。

局限與未來工作：

  • 尚可擴展到更多應用；希望把計算圖運算元擴充到實務 LLM 應用常用的組件，如工具使用與檢索增強生成（RAG） 系統。
  • 自動微分類比開啟龐大算法設計空間：以變異數縮減、adaptive gradient、LLM 自我驗證提升優化穩定性，以及用 meta-learning（甚至用 TextGrad 自身）優化 TextGrad 框架，都是有趣方向。
  • 分子與治療計畫僅為 in silico 驗證的概念驗證，最終仍需實驗與臨床評估（超出本文範圍）。

隨著 AI 範式從「訓練單一模型」轉向「優化涉及多個互動 LLM 組件與工具的複合系統」，我們需要新一代的自動優化器。TextGrad 結合 LLM 的推理能力與反向傳播的可分解效率，構成一個優化 AI 系統的通用框架。
