7. 相關工作

代理框架與其失敗模式。 2024–2025 年 LLM agent 框架快速增生。可靠性代價已有充分文獻：Cemri et al.（2026）識別 14 種失敗模式；Zhu et al.（2026）指出連鎖失敗是主要瓶頸；Gupta（2026）發現 60% pass@1 agent 僅 25% 跨試驗一致性。Dennis et al.（2026a）證明對程序性任務，in-context prompting 超越編排方法，建立了編譯所瞄準的品質天花板。

把代理能力編譯進權重。 以單一訓練模型取代模組化代理管線的想法沿三條線探索：

  1. 摺疊對話管線：SimpleTOD（Hosseini-Asl et al., 2020）把任務導向對話所有子任務（理解、動作決策、回應生成）重鑄為單一序列預測問題，在 MultiWOZ 達 SOTA。AutoTOD（Xu et al., 2024）延伸至自主動作序列，明確識別模組化系統的失敗模式（錯誤累積、泛化差）——正是統一模型可避免的。
  2. 從前沿模型蒸餾代理推理：FireAct（Chen et al., 2023）在 GPT-4 ReAct 軌跡上微調 Llama2-7B，HotpotQA 性能提升 77%。AgentTuning（Zeng et al., 2024）在多元代理互動軌跡上指令微調 Llama 2，產出 70B 模型在未見過的任務上匹配 GPT-3.5-turbo，同時保留通用能力。Agent Lumos（Yin et al., 2024）將代理行為分解為規劃與接地模組，訓練開源模型在多項基準上超越 GPT agent。
  3. 規模化到複雜工作流：WorkflowLLM（Fan et al., 2024）將 106K 工作流樣本（橫跨 1,503 API）的 API 編排知識編譯進 8B 模型。SynTOD（Samarinas et al., 2024）從狀態轉移圖生成合成訓練資料——與本文流程圖引導方法密切相關——證明程序性對話資料無需群眾外包即可合成。Hsiao（2026）將程序知識形式化為階層任務網路，證明結構化分解提升 agent 表現。

這些論文證明了技術可行——且多項達到與前沿模型競爭的品質。但無一項量化編譯相對於編排或 in-context 替代方案的推理成本優勢，無一項量測重新編譯週期，且無一項同時比較同模型編排基準與前沿模型基準來隔離編譯效應（非模型容量效應）。

8. 結論

本文提出三道採納壁壘，並逐一實證回應：

  • 品質：8B 編譯模型達到前沿 in-context 品質的 87–98%，與使用 ∼70 倍大前沿模型的 LangGraph 編排器競爭力相當；受控同模型比較確認編譯本身有助益——在五項指標中四項擊敗以同一基礎模型做編排（p<0.001）。
  • 成本：編譯模型每次對話比 in-context 基準便宜 128–462 倍，優勢在更複雜程序上更大——因編譯模型的 prompt 是常數大小。
  • 靈活性：重新編譯週期在生產級硬體上僅 30–50 分鐘——是 CI/CD 週期，不是漫漫長路的重新訓練。

三道壁壘都比普遍假設的小：品質差距僅 2–13%；成本差距是兩個數量級且在從業者有利方向，且隨程序複雜度擴大；靈活性差距是部署週期，不是典範轉移。

編譯是程序性知識需跨越單次對話上下文持久存在的自然解方：持久結構歸權重，瞬態狀態歸 prompt。

附錄 A：對話範例

附錄提供三個領域的真實評估對話節錄，說明各條件間的典型行為差異。

旅行訂票（地下代理 vs 3B 編排代理）：地下代理在回合 5 即呈現選項、回合 7 確認訂票；編排代理重複詢問日期/偏好問題三次（回合 4、6、8），直到回合 14 才呈現選項——症狀：編排器節點級生成缺乏全域對話意識。

Zoom 技術支援（8B 地下代理 vs Claude 編排代理）：地下代理提供精確的 Zoom 特定指引（關閉 HD Video、檢查 Statistics 面板、調整噪音抑制），12 回合自然解決。LangGraph 編排器單回合塞入四個建議（含錯誤的「original sound for musicians」建議後須收回）。編譯模型的領域特定訓練實現準確的產品知識，其學會的對話節奏產出更清晰、更可操作的排錯步驟。

保險理賠（8B 地下代理 vs Claude 編排代理）：地下代理自然處理 55 節點程序：驗證承保、收集事故細節、授權租車、解釋估價流程、結案——全程流暢對話。編排代理（Claude Sonnet 4.5）產生不適合電話對話的 markdown 格式（粗體標題、項目清單），未能給出差額保險（gap coverage）的確定答案，最終升級給「資深專員」——且無實際系統支援此轉接。節點級生成產出局部合理但全局不連貫的回應。
