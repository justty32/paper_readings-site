論文／訪談原始來源

TRACE: TRajectory Attribution for Automated Context Engineering

摘要與第 1 節：問題

production agent 的 system prompt、知識庫、tool description、skill 任一處有缺漏或過期，都可能造成失敗；人工翻 log 無法隨互動量擴張。TRACE 從歷史完整 execution trajectory 挖出使用者修正、重述、放棄等隱含不滿，而不重訓模型，直接修 context layer。

作者提出四項主張：軌跡 mining、多元 context attribution、先探索再決定 CREATE／UPDATE 的 verification、以及可檢查的 simulation benchmark。作者在 60 條 DSAT trace 報 72.7% root-cause attribution、82% 端到端 fix effectiveness；均為作者的模擬評測結果。

第 2 節：相關方向

TextGrad 將語意批評視為可對 prompt 反傳的 textual gradient；DRIFT 使用隱性不滿作學習；ACE 分 Generator／Reflector／Curator；記憶與 RAG 維護處理 CRUD。TRACE 的定位是把這些概念從單一 prompt 或模型權重，延伸到混合 context source 的診斷與修補。

第 3–4 節：Detector 與訊號

系統包含 Detector、Root Cause、Recommender，最後由人審核建議再套用。Detector 需要完整軌跡，不只是對話：原始問題、agent response、tool call／output 與後續交談。顯式訊號如 thumbs-down、tool error、abandonment；隱式訊號如更正、重述、重複問法、負面語氣、語義跳離。依權重與 confidence 聚合後才升送。

第 5 節：Root Cause attribution

一個 trajectory node 代表受 context 影響的決策，例如選 tool、做 retrieval、生成回應。Root Cause 以「使用者預期與實際輸出的 delta」當 loss signal，反向讀取 response、tool output、thinking、input，找最早引入不一致的節點。它在單次整體呼叫中讀 trace，而非逐 node 迭代；作者稱這較 iterative baseline 少 16 倍呼叫且避免 context truncation。

關鍵限制是此階段採信 agent trace 中提到的 source（例如「依 KB」），並不讀 raw file；所以 attribution 只是後續要檢驗的假說，不能直接執行修補。

第 6 節：Recommender 的探索驗證

Recommender 可 search／read KB、skill、system prompt、tool prompt。收到 root-cause 分析後，依序讀 implicated component、查 authority、交叉比對、擴查相關元件，才輸出含 operation、target path、改動與證據的 CRUD recommendation。作者報未探索時 CREATE／UPDATE 決定正確率 33%，探索後 83%；摘要另報 operation accuracy 96%，兩個數字的評估切面不同，不能當成同一個指標。

第 7 節與附錄 L：benchmark

作者因 proprietary production data 不能公開，改用三層 simulation：context sources → fault definitions → execution traces。六類 fault、2–16 node 的軌跡、root cause 與 correction 都有 ground truth。驗證協定要求：每個 tool output 與 source 字串一致；faulty content 確實存在 source；trace／fault／DSAT evidence 的交叉引用完整；root node 是最早取到錯誤內容者；attribution 約和為 1 且 root 最高。作者稱 75 條 trace 已依此檢查。

結論與使用邊界

本文的可移植思想是 attribution → read → repair 的三段式，而非讓 LLM 用一段軌跡直接改檔。實驗規模小、資料為模擬、context interactions 可能比 taxonomy 複雜；此外 production 未必保存可用 chain-of-thought，且 source 的權威性仍需環境外的治理機制。
