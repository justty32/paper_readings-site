Agent Behavioral Contracts II: Certifying Compositional Reliability Without Assuming Independence

摘要與第 1 節：問題

多 agent pipeline 常被當成 series system 證書：分別界定每個元件的可靠度，相乘，回報乘積。v1 Agent Behavioral Contract（ABC）框架如此做，作者所知的每個 agent 系統的組合可靠度論證也都如此做。這一步由 C5（v1 Definition 3.10）授權——它斷言下游 agent 的合約滿足與上游 agent 的內部執行在給定合規交接下條件獨立。C5 在 v1 中被陳述、但從未被檢驗；作者指出它反思起來並不合理，因為 reviewer agent 檢查 writer agent 時，兩者往往就是同一模型換個 prompt——它們沒有獨立的盲點，而是共享盲點。

本文用一個 preregistered 的驗證性評測量化這件事的嚴重程度：18,000 個 two-agent-handoff 任務、確定性評分、判分過程沒有模型介入；其餘拓撲列為次要工作，在一個 30,820 任務的 campaign 內報告。兩個 mistral-small-24b 實例在其中一個失敗的任務中 90.0% 同時失敗（log OR=6.66，95% CI [6.38,7.00]）。換第二個 agent 為不同模型會顯著降低關聯，在驗證性拓撲與兩個次要拓撲皆然；已換模型後再換供應商則不會。後果對操作者不利：由 Proposition 4.1，組合誤差是有號的——正相依下聯合失敗機率超過獨立乘積，因此冗餘元件共用模型時，可靠度恰好被高估。

第 4 節：獨立性失效時會壞掉什麼

Proposition 4.1（有號的組合誤差）：對 series motif，m=2 時 P(Y_G=1) − p1p2 恰等於 Cov(h1,h2)。對 series 系統本身，正相依下獨立乘積其實是保守的——這是安全方向。但 Corollary 4.1 指出不安全的方向是冗餘：兩條路徑同時失敗的機率 = 獨立乘積 + Cov(F1,F2)，正相依下超過獨立乘積，即冗餘設計（quorum、reviewer–writer）恰好在元件正相依時被高估可靠度——而這正是部署冗餘的目的所在。作者舉例：2-of-3 quorum，每個 worker 以 p=0.61（第 10.2 節測得的 same_model 比率）滿足合約，獨立假設下 quorum 成功機率 0.6623；若聯合分布保有測得的 pairwise 關聯，quorum 失敗機率可能升到約 0.37，相對增加約 9.6%（此為示意用一致聯合分布下的量級，非嚴格下界，嚴格下界見第 6 節）。

丟掉獨立假設呢：得到 Fréchet–Hoeffding 界（Theorem 4.1），但 Corollary 4.2 指出下界在平均元件可靠度 ≤ 1−1/m 時恆為 0——m=4、p=0.75 時下界恰為 0，實務上常見卻無用。

擬合相依模型呢：**Theorem 4.2（覆蓋崩潰）證明：若擬合的相依模型族在真實 moment 上錯誤設定（Δ=R_F(μ)−R>0），任何滿足標準 bootstrap 收斂速率的下界，其覆蓋真實可靠度的機率隨 n→∞ 趨近 0。機制是階數不匹配：識別誤差 Δ 是 O(1)、bootstrap 修正量卻以 O(n^-1/2) 縮小，過了某個有限 n 區間就永遠停在真值上方，資料越多錯得越離譜且無可見徵兆。作者用顯式反例構造出與正確設定的 Gaussian copula 在邊際與 pairwise moment 上完全無法區分、但 all-success 機率相差 0.0617 的聯合分布，證實此陷阱非邊角案例。

第 5–7 節：分層證書

三個選項都不可用之後，作者提出用測得的 co-execution moment 約束聯合分布、在約束集合上做最優化，而非假設相依結構。核心是線性規劃：以 Bonferroni–Clopper–Pearson 信賴盒圈住實測 co-execution moment，對 2^m 個聯合機率格求 all-success 機率極值。Theorem 5.2 證明 sound；Theorem 6.1 證明 sharp；Propositions 6.1–6.2 證明隨 moment 家族擴大單調收緊。四階段真實資料上，moment 從 10 擴到 14，識別區間收窄 85.7%，certified floor 從 0.2455 升到 0.4116。

因為實際部署是持續監控而非固定樣本量停止，第 7 節加入 anytime-valid 的 e-process 版本（Theorem 7.1）：虛無假設只約束條件期望，不需獨立性假設，對本文揭露的失效完全免疫；Proposition 7.1 證明最優下注比例下精確恢復 SPRT。

第 10 節：評測 E1–E6（作者自報）

E1（confirmatory）：H1（same_model 存在正相依）成立，且在每個 arm、每個 motif 都成立；H2（三層排序）整體不成立——same_model 在 6/6 對比中顯著超過兩替代條件，但 same_vendor 不顯著超過 different_vendor，如實報告此 null；組成不變的內部對照 15/15 皆 null。E2：moment 從 10 擴到 14，識別區間收窄 85.7%，floor +16.6pp。E3：錯誤設定下模型型下界覆蓋率隨 n 增大從 0.36 崩潰到 0.01，正確設定對照組維持 0.94–0.96，本文 Tier-1（LP）證書在全部 1600 次重複皆覆蓋。E4：所有允許下注比例下經驗型 I 誤差 ≤α，最差 0.0471，SPRT 被精確恢復。E5（次要、樣本不足）：兩個額外後端同樣觀察到正相依，量級不可跨 arm 比較。E6（ablation）：實測最大 design effect 1.148，讓步至 DEFF=1.5 時 floor 至多移動 2.69pp。

三個存活結論：共用模型產生大而顯著的相依失敗；起作用的變數是模型身分而非供應商；不假設 copula 也能靠豐富 moment 家族把證書收緊。同時明列兩限制：替代操弄把模型身分與能力混淆（ministral-8b 既不同模型也較弱），且各 arm 各自抽自己的任務、非成對比較。

第 11 節：討論、限制與威脅

給實務者的建議：不要對共用模型的元件相乘可靠度；選冗餘看模型身分而非供應商（僅限本實驗一個樣本，不足以支持通用供應商多元化政策）；回報 certified floor 時務必附上 moment 家族（同一筆資料 J=10 與 J=14 下界相差 16.6pp）。

限制：LP 對 m 是指數複雜度（2^m 變數），本文 m≤4 毫秒內求解，五十階段 pipeline 已超出能力範圍；聚合節點（merge/quorum）被假設為確定性程式碼、不帶相依性，若聚合器本身是 LLM 則此分析未涵蓋；drift 動態承襲 v1、本文未重新量測；證書是 per-distribution 的，模型升級即失效，未量化證書隨部署漂移衰減多快。

威脅有效性：模型身分與能力混淆最嚴重，marginal-free 統計量與內部負控制部分緩解；各 arm 任務非成對抽樣；整個 campaign 在約四小時單一時間窗依序執行、非交錯；合約與判分程式碼出自同作者，但不會產生 arm 間差異化共同失敗結構；僅涵蓋零售與金融兩任務域；log OR 是觀察到反轉現象後才選定，作者揭露此研究者自由度而非隱藏它。

第 12 節：本文不主張什麼

不主張共用模型導致相依失敗是本文首次發現；不主張三層 sharing 排序成立（vendor 層未複現）；不主張 v1 drift 動態在本文獲驗證；不主張證書可擴展到大 m；不主張結論適用於前沿模型（僅測中型開源模型）。

第 14 節：結論

多 agent 系統的組合可靠度界透過相乘元件可靠度取得，這一步假設元件獨立失敗。一個 preregistered 的 18,000 任務驗證性評測（campaign 內共 30,820 任務）量出這個假設的代價：兩個同模型 agent 在其中一個失敗的任務中 90.0% 同時失敗。這不是「界稍微鬆一點」的問題——由 Proposition 4.1，誤差是有號的，方向剛好對冗餘設計不利。
