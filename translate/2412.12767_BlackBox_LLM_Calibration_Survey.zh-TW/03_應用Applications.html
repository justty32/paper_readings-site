3. 應用（Applications）

校準流程既能提升 LLM 實務部署的可靠性，也能提升使用者信任。依目標不同分兩類：

風險評估與緩解（Risk Assessment and Mitigation）：黑箱 LLM 在醫療診斷、自動駕駛等高風險領域，因潛在幻覺與過度自信而面臨挑戰，校準流程有助緩解這些風險以利實務部署。例如 Qin et al. 在醫療情境提出「非典型表現再校準（Atypical Presentations Recalibration）」；Savage et al. 展示樣本一致性校準能改善醫療診斷；在生產環境中，Zellinger and Thomson 提出 HCMA（基於不確定性評估的風險管理框架），Shen and Kejriwal 提出校準方法 DwD 處理複合決策風險。

人機信任提升與優化（Human-LLM Trust Enhancement and Optimization）：人機協作中使用者信任至關重要，且高度取決於 LLM 回應品質。除了事實性校準外，研究也聚焦對齊使用者偏好：Steyvers et al. 研究基於人類感知的 LLM 信心校準；Tsai et al. 為黑箱 LLM 開發偏好對齊的決策流程；Do et al. 透過校準過的事實性分數與來源歸因提升使用者-LLM 信任；Spiess et al. 證明校準能在程式生成這類使用者密集型任務中提升效率與準確率。

4. 未來方向（Future Direction）

建立完整的校準基準（Developing Comprehensive Calibration Benchmarks）：校準流程中「正確性」的定義因任務而異，直接影響校準目標——有些任務聚焦事實準確性，有些著重邏輯連貫、主張一致性或人類滿意度。複雜生成任務往往需要更細粒度、多維度的校準方法評估輸出的多個面向。因此，開發能涵蓋多元任務複雜度的多維度、多階段基準，對提升模型校準表現至關重要。

黑箱 LLM 的偏誤偵測與緩解（Bias Detection and Mitigation）：偏誤偵測與緩解在黑箱 LLM 中仍是關鍵挑戰。模型內部不可存取使偏誤難以辨識與處理，對信心估計與校準都構成固有限制，常導致特定群組或任務的校準誤差異常偏高或偏低，損害模型可靠性與公平性。傳統方法在黑箱情境下效果有限，需要量身訂做的解法：提升輸出透明度、整合外部校準機制、利用使用者回饋做動態信心調整。這些策略不僅能處理黑箱情境的獨特障礙，也能提升校準表現與實務效用。

長文本校準（Calibration for Long-form Text）：長文本校準對白箱與黑箱 LLM 都是重大挑戰。隨著 LLM 需求成長，問答與其他生成任務中的長文本常含多項聲明與事實，使校準日趨複雜。當文本只有部分正確時，判斷信心分數是否良好校準格外困難，品質評估本身的主觀性又讓問題更複雜。這需要納入人類感知作為正確性量測指標的有效方法，並針對參數不可存取的黑箱情境開發專用做法。

5. 結論

本綜述完整回顧了黑箱 LLM 校準的現有研究。由於黑箱 LLM 的內部狀態不可存取，可用的校準方法有限；但因黑箱 LLM 卓越性能與廣泛應用，其校準方法近來備受關注。作者先討論校準如何幫助緩解黑箱 LLM 的幻覺與過度自信問題，接著系統性定義校準流程由信心估計與校準（含校準誤差量測方法）兩部分組成，深入探討黑箱情境下各部分面臨的挑戰並介紹最新研究方法，最後探討校準流程在黑箱 LLM 中可發揮效益的應用場景並提出未來研究方向。據作者所知，儘管已有大量研究探討黑箱 LLM 校準，但尚無綜述系統彙整此領域，凸顯本文的先驅性貢獻。

局限（原文自陳）

  • 範疇限制（Scope Limitation）：本綜述雖詳細檢視適用於黑箱 LLM 的校準流程方法，但未廣泛涵蓋白箱 LLM 的方法。由於既有校準研究多聚焦白箱 LLM，本綜述可能未涵蓋該領域一些知名且廣受認可的方法。儘管如此，作者主張專門針對黑箱 LLM 的綜述仍具意義，因黑箱方法往往也適用於白箱情境，可為白箱 LLM 校準流程研究提供新視角。
  • 涵蓋限制（Coverage Limitations）：作者已盡力全面蒐集彙整黑箱 LLM 的校準流程方法，但由於校準流程在許多研究中僅是輔助性的優化或評估工具、而非研究核心，部分重要的相關工作可能因此被遺漏。
