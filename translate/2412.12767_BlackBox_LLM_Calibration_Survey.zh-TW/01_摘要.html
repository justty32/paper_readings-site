摘要

大型語言模型（LLM）在語意理解與生成上表現卓越，但準確評估其輸出可靠性仍是一大挑戰。既有校準技術研究多聚焦於可存取參數的白箱 LLM；相對地，儘管黑箱 LLM性能更優，但因只能透過 API 做輸入輸出互動，對校準技術提出了更高要求。雖然近期研究在黑箱 LLM 校準上已有突破，但至今仍缺乏對這些方法論的系統性綜述。為填補這項空缺，我們提出首篇針對黑箱 LLM 校準技術的完整綜述。我們首先把 LLM 的**校準流程（Calibration Process）**定義為兩個相互關聯的關鍵步驟：信心估計（Confidence Estimation）與校準（Calibration）。接著，我們系統性回顧黑箱情境下的適用方法，並剖析實作這兩個步驟時的獨特挑戰與彼此關聯。此外，我們探討校準流程在黑箱 LLM 中的典型應用，並勾勒未來有前景的研究方向，為提升可靠性與人機對齊提供新視角。GitHub：github.com/LiangruXie/Calibration-Process-in-Black-Box-LLMs。

1. 引言

LLM 在各種應用情境中展現卓越的泛化能力與脈絡理解力，尤其在開放領域問答任務上。然而，面對模糊提示或知識不足時，LLM 常產生幻覺，或對自身回應表現出過度自信。傳統白箱解法（RLHF、模型權重修改、adapter tuning 等參數層級介入）對 Llama、ChatGLM、Vicuna 這類可存取權重的模型有效，但對只允許 API 輸入輸出互動的黑箱模型（GPT、Claude、Gemini）完全無效。鑑於此限制與傳統方法的高運算成本，信心估計與校準方法已成為一種具成本效益、可同時適用於白箱與黑箱模型、且能擴展到大規模部署的替代方案。

信心估計與校準近年常被一併討論：信心估計常受模型/資料不確定性影響，而校準方法能幫助模型認識自身知識邊界，使其信心更準確反映輸出品質。例如：在罕見疾病診斷情境中，LLM 可能對一個錯誤回答給出 95% 信心，而受限於領域知識不足，準確的信心應更接近 40%。校準能辨識這種落差，把模型信心調整到更準確反映回應品質，避免生成回應過度自信。本綜述把「信心估計→校準，以達成良好校準（well-calibrated）信心」這整個流程稱為校準流程。

已有愈來愈多綜述回顧影響 LLM 校準流程的因素——有的整理模型參數/訓練階段/訓練資料如何影響信心與校準，有的探討 RLHF 階段哪種信心表徵更利於校準，也有綜述回顧語言模型（LM）與 LLM 上各種信心估計與校準方法。但既有綜述幾乎都聚焦白箱 LLM，其校準流程方法通常涵蓋 logit-based 校準、額外參數層、指令微調、強化學習技術。

相對地，黑箱 LLM 的校準流程研究儘管發展活躍，卻缺乏系統性分析。黑箱 LLM 近來備受關注，因其在各種實務應用上表現卓越，尤其常被當作評判其他 LLM 輸出品質與整體表現的基準判官模型（judge model），這一角色已被眾多中小企業廣泛用於產品開發。既然黑箱 LLM 扮演關鍵判官角色，強化其對不確定性的敏感度、提升輸出可靠性、培養使用者信任就至關重要——校準流程已展現出滿足這些需求的巨大潛力，也因此驅動了黑箱 LLM 校準流程研究的興趣。

儘管興趣漸增，據作者所知尚無專門針對黑箱 LLM 校準流程的完整研究。本綜述旨在系統性回顧與分析此領域現有研究進展以填補空缺。作者的調查發現，現有黑箱 LLM 校準流程方法可歸為兩大路線：引入第三方代理模型（partially transform black-box models into gray-box models）與只操作輸入輸出資料的後處理技術。黑箱 LLM 校準的複雜度，又因內部邏輯資訊不可存取這一根本挑戰而更加嚴峻。

重要的是，由於黑箱情境下適用的方法通常也能用於白箱情境，研究黑箱 LLM 的校準流程不僅能處理黑箱情境的獨特挑戰，也能為白箱 LLM 校準提供有價值的洞見（見原文 Figure 1）。本綜述涵蓋黑箱情境下的兩個關鍵面向：信心估計與校準（校準內含評估校準誤差的量測方法，因這些量測方法在黑箱與白箱間高度通用，故不深入展開）。第 2 節詳述這些方法論，第 3 節介紹其實務應用，第 4 節以未來研究方向作結（全文組織架構見原文 Figure 2）。
