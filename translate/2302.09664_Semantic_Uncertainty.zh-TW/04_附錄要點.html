附錄要點

  • A.1 語意/句法/詞彙等價辨析：詞彙等價蘊涵句法與語意等價，反之不然；句法等價句子文法結構相同但意思可不同；語意等價句子意思相同但文法或用詞可不同（可差一個同義詞）。等價關係理論上遞移，但因 NLI 分類器並非完美、判斷偏「軟」，實務上聚類結果可能依比對順序略有差異，作者觀察此問題不明顯，但列為未來改進方向。也討論「不對等 token 重要性」——樸素方法如預測熵無法區分關鍵詞與無關緊要 token，監督式方法或本文的語意聚類皆能部分緩解。
  • A.2 Algorithm 1（雙向蘊涵聚類）虛擬碼：初始化 C={{s⁽¹⁾}}；對每個新序列 s⁽ᵐ⁾，與 C 中每一類的代表序列分別做雙向蘊涵判斷（NLI 分類器 ℳ 各判一次「舊→新」「新→舊」），兩方向皆 entailment 才併入該類，否則自成一個新類；回傳最終的 C。
  • A.3 取樣方法對不確定性品質的影響：CoQA 上溫度 0.5 同樣最優，但與 TriviaQA 不同，高溫時長度正規化熵反而優於語意熵。除溫度外，取樣方法／top-p／top-k 等超參數亦有影響：multinomial beam search 取樣得到的不確定性度量（AUROC 0.735，多樣性 0.258）不如一般 multinomial 取樣（AUROC 0.758，多樣性 0.490），因 beam search 過度聚焦高似然區域、樣本多樣性偏低（表 4）。人工檢視 T=1.5 時 100 個分類結果，發現此溫度下模型常生成無意義的詞語組合，語意聚類準確率僅約 61%（低溫時逾 92%，見 B.2），故此溫度下語意等價成為不可靠訊號；低溫、生成通順時語意熵則明顯優於基線。
  • B.1 自動正確性指標與人工評估的吻合度：以 30B 模型人工評估 200 筆答案，Rouge-L(y,y′)>0.3 的自動判準與人工標註的吻合度：CoQA 0.89、TriviaQA 0.96。
  • B.2 雙向蘊涵分類器驗證：人工標註各資料集 300 筆（13B 模型生成）樣本，判斷分類器準確率 TriviaQA 92.7%、CoQA 95.3%。
  • B.3 正確性指標敏感度：更換 Rouge-L 門檻（0.3/0.5）、Rouge-1、exact match，AUROC 幾乎不變（TriviaQA 各指標 AUROC 語意熵約 0.828–0.835），僅 exact match 顯著壓低量測到的模型準確率本身；CoQA 上同樣穩健，唯 exact match 因答案變異度大而過嚴。
  • B.4 準確率隨模型規模的消融：模型規模愈大，兩資料集的生成準確率與語意熵的不確定性表現皆隨之提升；最小模型時準確率與不確定性表現皆下降。
  • B.5 p(True) 提示格式範例：給定問題與一組「腦力激盪」候選答案（含正確答案），要求模型以 (A) True / (B) False 判斷某個候選答案是否正確，取「True」的下一 token 機率當不確定性分數；原作者指出須以 few-shot（而非 zero-shot）方式進行，本文採 10-shot。
  • B.6 Margin-probability 基線：以 beam search 前兩名 y⁽¹⁾、y⁽²⁾ 的似然差作不確定性分數（Lin et al., 2022b），CoQA 上 AUROC 僅 0.54，遠遜於本文方法與基線；分析原因：(1) 只看差值，丟失似然的絕對量級資訊；(2) 未考慮語意不確定性——即使兩個候選只是同一意思的不同措辭，margin 也可能很大，導致無法區分「對措辭猶豫」與「對意思本身猶豫」（表 8 舉例：「Thomas Edison.」vs「Edison.」margin 高達 0.90 而語意熵僅 0.10；「Thomas.」vs「George.」margin 僅 0.36 而語意熵達 0.87，後者才是真正的高不確定性）。若改用 multinomial 取樣（而非 beam search）取得 y⁽¹⁾、y⁽²⁾，第二個問題可略為緩解，但仍明顯遜於本文方法與其他基線。
