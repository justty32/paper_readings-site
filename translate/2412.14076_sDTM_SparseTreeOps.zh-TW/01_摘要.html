摘要

神經網路在組合泛化上持續吃力，缺乏大規模預訓練時更甚。混合式神經符號法雖能展現類人組合泛化，卻陷入符號 AI 的老問題——可擴展性與彈性差，根因是其核心仍是符號計算、把可擴展可彈性的神經計算降格為「參數化符號系統」。本文研究一個統一式神經符號系統：網路中的變換可同時解讀為符號與神經計算。在兩方面擴展 可微樹機（DTM）：(1) 用符號結構的稀疏向量表示大幅提升效率；(2) 從受限的 tree2tree 推廣到更一般的 seq2seq。改進後的模型保留原泛化能力，且因存在一條全神經路徑，避開了「抬高符號計算凌駕神經計算」之神經符號法的陷阱。

1 引言

DL 在語言任務表現亮眼卻難跨出訓練分佈——對新詞、舊詞新語境、更長/更深遞迴的新句構都吃力。資料增強只是降低需泛化的程度，治標不治本。人類靠組合結構（內容單元如詞，嵌入如句法樹的結構中）能解讀從未見過的構造（如「At the airport I smiled myself an upgrade」）。純符號法理論誘人但難普及；純連結派（Transformer）則樣本效率與穩健泛化不足。混合式神經符號法雖兼具組合性與彈性，卻因符號核心而脆弱。本文走不同路：符號操作發生在向量空間——對「向量嵌入的符號結構」做乘加，而非對單個神經元。 貢獻：(1) 稀疏座標樹 SCT 表示樹；(2) 位移操作（Bit-Shift Operating）——SCT 上系統化、平行化的樹操作；(3) sDTM——對 DTM 的架構改進，大降參數與記憶體；(4) 把 DTM 推廣到 seq2seq（序列轉樹）；(5) 大量 baseline 對比，證 sDTM 跨多種任務的強泛化。

2 相關工作

樹結構泛化橫跨 CS/語言學/認知科學；經典 NLP 從文本抽取結構（constituency/dependency parse）。近期分析顯示 seq2seq 模型潛表示含結構資訊，但不證明表示本身是樹狀；受 TPR 與 chart parsing 啟發的分析說明表示如何在訓練中逐漸樹化。顯式樹結構網路（樹 RNN/LSTM/Transformer）常在 OOD 上贏不過非結構版——可能因泛化需同時具備結構化表示與尊重結構的操作。另一線是用神經網路參數化符號系統/模糊邏輯。**VSA（向量符號架構）**在高維空間實作符號演算法但常缺學習元件。本文延伸 Soulos et al.（2023）的 DTM（tree2tree），做出參數更少、記憶體更省的 seq2seq 稀疏版。

3 在稀疏座標樹上的可微樹操作

原 DTM 用 TPR（張量積）表示樹，維度＝embedding 維 × 節點數，而節點數又隨深度指數成長 → 記憶體很快爆炸。

3.1 稀疏座標樹（SCT）

要一個把結構與內容分離到不同子空間的編碼（不同於 RNN/Transformer 的聯合非分解表示），以便獨立操作兩空間——這是組合性的本質。SCT 源自稀疏座標（COO）格式（索引[整數]、值[任意]、尺寸[整數]；未列索引者值為 0）。賦予結構意義：把索引的一個維度定義為「值向量所佔的樹位置」，採 Gorn 位址——索引轉二進位、由右往左讀，0＝左枝、1＝右枝；為區分前導零與左枝，起始位設 1（最高位 1 左邊的 0 皆為未填、非左枝）。空節點直接跳過 → 大省記憶體。SCT ≡ 把 TPR 的角色基底限制為標準基底（見附錄 A.1）。

3.2 可微樹操作

僅需小函式庫三件：left（左子，即 LISP 的 car）、right（右子，cdr）、cons（由左右子樹建新樹）。此三者＋條件分支＋等號檢查即圖靈完備。因值與索引分離，不必像原 DTM 預存/套線性變換，改用索引+位移+加法高效計算：

  • left：取偶索引（最低位為 0，即根左側所有節點）及其值，索引右移一位。
  • right：對稱，取奇索引、並忽略位置 1（移除舊根）。
  • cons：左右子樹索引左移，右子樹索引再 +1，並可給新根節點一個新值。 要可微地學「多步程式」：對 left/right/cons 三操作與候選樹取加權和（操作權重和為 1），結果經 coalesce（合併重複索引：同索引的值相加）。（式 1）

4 稀疏可微樹機（sDTM）

延伸 DTM；計算層級相似但實作大幅省參省記憶體，並能處理 seq2seq。

4.1 總覽

由 agent / interpreter / memory 構成。Interpreter 執行式 1（套 3.2 位移操作並加權），輸出寫入下一可用記憶槽，最後一槽為輸出。Agent 是 Transformer encoder，吃記憶編碼、產出式 1 的輸入（操作權重與兩棵引數樹）；以 <OP>、<ROOT> 兩特殊 token 代表操作與根；每棵寫入記憶的樹會被編成定維 token 餵給 agent；agent 對記憶中諸樹做加權和來軟選引數。注意：agent 用 Transformer 隱式參數化條件分支/控制流 → sDTM 仍可能沾染 Transformer 的泛化弱點（結果顯示部分任務泛化問題仍在）。

4.2 注意力池化（Pooling by attention）

每棵記憶樹需定維編碼。改用 PMA（Pooling by Multi-head Attention）：以 query-key 注意力做加權和取代原 DTM 的線性變換。注意力對 key/value 順序置換不變，但池化須考慮樹位置 → 把位置索引轉二進位向量（為避免全正不對稱，左枝記 −1、右枝記 +1），與該位 token embedding 串接後輸入池化（類似 Shiv & Quirk 的樹位置編碼，但用串接+線性混合而非相加）。query 為獨立可學參數、不依輸入。

4.3 樹剪枝

雖然 SCT 讓填得少的樹省記憶體，但模型混合三操作（尤其 cons 會合併兩樹、增大表示）使樹逐漸變稠密（任何操作機率永不真為 0）。為保稀疏，只留 magnitude 最大的 top-k 節點；k 為可依記憶體調的超參。

4.4 詞彙正則化

為助詞彙泛化，對 token embedding 加標準多元正態雜訊（餵入前每位置每棵樹各採樣）作為正則化（消融見附錄 A.3，證其重要）。

4.5 處理序列輸入輸出

  • seq2tree：把每個輸入 token 當「只有根節點被佔」的樹，記憶初始化為 n 棵樹（每 token 一棵）。因 agent 注意力置換不變，對前 n 個 token 加隨機正弦位置編碼（採遞增整數而非固定位置）以區分同詞異序。因此設定下輸入由下而上處理，限制只用 cons——與 Chomsky 極簡方案的單一操作 merge 理論對齊。
  • seq2seq：把輸出序列轉樹——有 parser 就用 parser；無則用 **LAUD（左對齊均勻深度葉）**嵌入（非終端節點皆同 → 可硬編 cons 的根引數，插 <EOB> 標枝結束，類似 <EOS>）。
