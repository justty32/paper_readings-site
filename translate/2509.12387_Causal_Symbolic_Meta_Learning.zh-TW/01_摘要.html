摘要

現代深度學習擅長模式辨識，但根本上受限於對虛假相關的依賴，導致泛化差、且需海量資料。本文主張：人類般智能的關鍵成分——穩健、樣本高效的學習——源自對因果機制的理解。我們提出 CSML（因果符號元學習），一個學會推斷任務分布之潛在因果結構的新框架。CSML 含三模組：(1) 把原始輸入映成解耦符號表徵的感知模組；(2) 發現支配這些符號之因果圖的可微分因果誘導模組；(3) 利用該圖做預測的基於圖的推理模組。透過跨任務分布元學一個共享因果「世界模型」，CSML 能從少數樣本快速適應新任務，包括需就介入與反事實推理的任務。我們提出新的物理 benchmark CausalWorld。實驗顯示 CSML 在需真因果推理的任務上，大幅勝過 SOTA 元學習與神經符號基線。

1. 引言

深度學習在大型靜態資料集上成功，但常靠統計相關走捷徑，對分布偏移脆弱（Geirhos 2020）。人類卻能從極少樣本學到豐富可泛化的世界模型（Lake 2017）；一個核心假說是人類靠建構並推理直覺式因果模型達成此樣本效率（Pearl 2009）。現有元學習以「學會學習」提升樣本效率（Finn 2017；Snell 2017），但只學高效特徵抽取器或優化策略，不顯式建模資料生成過程的底層機制，故仍敗於違反所學相關的分布外任務。

CSML 的原則：許多相關任務即便表面相異，仍共享一組底層因果律。CSML 不只學共享特徵表徵，而是元學一套「誘導因果結構」的程序。框架（圖 1）三組件：

  1. 感知模組 \(g_\phi\)：神經網路把高維輸入（如影像）轉成低維、解耦的符號潛變數。
  2. 因果誘導模組 \(h_\psi\)：可微模組，吃成批符號變數、輸出表其因果關係的有向無環圖（DAG）。
  3. 推理模組 \(f_\theta\)：GNN，在誘導出的因果圖上訊息傳遞以預測任務結果。

元訓練時 CSML 暴露於任務分布，學會產出一張可當穩健共享 prior 的因果圖；新任務只需學「如何把自身細節接地到既有因果框架」，故能快速適應。貢獻：(a) 統一神經符號、可微因果發現與元學習以誘導因果世界模型的框架 CSML；(b) 把學到圖之正確度正式連到少樣本表現的泛化界；(c) benchmark CausalWorld；(d) 大量實驗證明樣本效率與穩健性勝 SOTA。

2. 相關工作

  • 元學習：優化型（MAML，學易於微調的參數初始化）與度量型（Prototypical Networks，學可用原型距離分類的嵌入空間）。CSML 根本不同——元學的是結構先驗（因果圖），而非參數／度量空間先驗。
  • 神經符號 AI：結合連結主義感知與符號推理（Garcez & Lamb 2019）；多數方法解特定推理任務。CSML 推進處在於自主從資料發現符號規則（以因果圖形式），而非假設規則已給定。
  • 因果發現：經典法多為約束式或評分式（Spirtes 2000）；近期可微分因果發現興起，可與深度學習整合。代表是 NOTEARS（Zheng 2018），把「學 DAG」化為連續優化問題——本文因果誘導模組即建於其上。

3. CSML 框架

元學習設定：任務分布 \(p(\mathcal{T})\)，每任務有 support set 與 query set，目標是學得「給 support 即在 query 上低誤差」的模型。

3.1 架構組件

  • 感知模組 \(g_\phi\)：把高維輸入 \(x\) 映成一組解耦符號潛變數 \(s=\{s_1,...,s_n\}\)。實作用 Vision Transformer（多輸出頭），鼓勵各頭聚焦輸入中不同實體／屬性。
  • 因果誘導模組 \(h_\psi\)：以加權鄰接矩陣 \(A\) 表因果圖（\(A_{ij}\neq0\) 蘊含因果連結 \(s_i\to s_j\)）。為保證為 DAG，採 NOTEARS 的連續優化。給一批符號觀測，解式 (1)：最小化重構/評分項，受 \(h(A)=0\)（\(h\) 為平滑可微、當且僅當 \(A\) 表 DAG 時為零）約束，並加稀疏正則 \(\lambda\)。此模組於元訓練階段被調用，以找跨任務共享的圖。
  • 推理模組 \(f_\theta\)：給因果圖（其鄰接矩陣 \(A\)）與當前符號，用 GCN（Kipf & Welling 2016） 做最終預測；第 \(l\) 層隱表徵更新如式 (2)，\(\hat{A}\) 為由 \(A\) 導出的正規化鄰接矩陣，\(W\) 為可學權重，\(\sigma\) 為激活。GCN 沿因果路徑訊息傳遞，實現結構化推理。

3.2 元訓練（雙層優化）

每個元訓練回合採樣一批任務：

  1. 因果誘導（外層）：把元批所有任務的 support set 過感知模組得大量符號，用以對共享因果圖走一步梯度（如最小化式 1 的評分）。
  2. 任務適應（內層）：對每任務，固定感知模組與因果圖，只對推理模組參數做幾步梯度下降以最小化任務專屬損失。
  3. 元更新（外層）：在各任務 query set 上評估適應後的推理模組，query 損失回傳穿過內層優化過程以更新感知模組 \(g_\phi\)。

此程序逼感知模組產出「因果關係跨任務一致、可被單一強大因果圖捕捉」的符號。

4. 理論分析

定理 1（因果泛化界）：設 \(G^\*\) 為任務分布的真實（未觀測）真值因果圖，\(\hat{G}\) 為 CSML 學到的圖。在對損失函數與模型類的標準假設下，以至少 \(1-\delta\) 機率，新任務的期望 query 誤差被界為（式 3）：

\[\mathbb{E}[\text{query error}] \le \hat{L}_{\text{support}} + C_1\cdot\frac{\mathrm{SHD}(\hat{G},G^\*)}{k} + C_2\cdot(\cdots)\]

其中 \(\hat{L}_{\text{support}}\) 為 support set 經驗誤差、\(\mathrm{SHD}\) 為學到圖與真圖間的結構漢明距離、\(k\) 為 support 樣本數、\(C\) 為常數。

意涵：泛化誤差由兩主項控制——support 上的經驗誤差、與因果圖結構誤差成正比的懲罰項。學到越準的因果模型，直接收緊泛化上界。 證明（附錄 A.1）建於元學習的 PAC-Bayes 框架：prior 由因果圖告知（與真圖一致的函數先驗機率較高），把 KL 散度連到 \(\hat{G}\) 與 \(G^\*\) 間的結構不一致（SHD）。

5. CausalWorld Benchmark

自建 2D 物理環境，含不同形狀、顏色、質量、彈性的物體。任務 = 初始場景配置 + 問題，分三類（圖 2）：

  1. 預測：給初始態預測未來態（如「哪個物體先落地？」）。
  2. 介入：預測對系統屬性做假設性改變後的結果（如「若球質量加倍會怎樣？」）。
  3. 反事實：給定一結果，推理若初始條件不同會如何（如「紅球沒中標，若斜坡更陡會中嗎？」）。

靠所學相關的基線預期在預測表現好，但在需底層物理因果模型的介入與反事實上失敗。

6. 實驗與結果

  • 設定：對比 MAML、Prototypical Networks、與固定全連接圖的標準神經符號基線（NSL）。在 CausalWorld 上評估 5-shot、1-shot、0-shot（介入／反事實）。
  • 結果（表 1，5-shot 準確率 %）：
模型 預測 介入 (0-shot) 反事實 (0-shot)
MAML 81.3 34.5 33.9
ProtoNets 79.8 35.1 34.2
NSL（固定圖） 82.5 40.2 38.7
CSML（本文） 95.4 91.7 90.5

所有模型在預測上尚可，但基線在需因果推理時完全崩潰；CSML 能誘導底層物理的正確因果模型，故跨所有任務型維持高準確，且學得更快（更少 shot 即高準確，圖 3）。

  • 學到圖分析：對「球滾下斜坡撞方塊」場景，學到的圖正確辨識因果依賴：斜坡角度與球質量 → 球速度 → 方塊最終位置（圖 4），證明 CSML 非僅擬合資料、而是學到有意義的世界模型。
