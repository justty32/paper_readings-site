4. 用於 MaxSAT 的邏輯波茲曼機

MaxSAT＝找出最大化已滿足子句數的賦值（式 20）；比 SAT（找任一滿足賦值）更一般，是組合最佳化、NP-hard，常需近似解（平衡準確度與時間）。符號 MaxSAT solver 已能擴展到百萬級變數/子句，應用於軟體分析、硬體驗證、組合最佳化、生資、資料分析。近年興起連結主義 solver（利用平行運算、學習能力與 GPU/TPU 加速器，並促成可解釋分類模型與新型 NeSy）。深度學習式 MaxSAT solver 多需從範例解學實值權重（如 [53]）或訓練 GNN，常被批評需監督且不透明。本文改用 LBM ＋ dual annealing（模擬退火的改良） 搜尋 RBM 能量地形的全域極小（＝MaxSAT 解）。相關 RBMSAT 用 block Gibbs 在加速器上做啟發搜尋；本文則用可解釋的 RBM 層（圖 13，每子句可從二元權重讀出）。

4.1 LBM 搭配 dual annealing

CNF 表示進 RBM 後，Gibbs 取樣在此情境收斂慢；改用模擬退火，具體用 dual annealing（無縫整合全域＋局部搜尋）：先以模擬退火找全域最佳可能所在區域，再以局部搜尋精確定位。

5. 在 LBM 中整合學習與推理

NeSy 的關鍵發展是為既有網路加上「已驗證模組」：一個可證等價於給定邏輯公式的 RBM 即為此種模組，疊在大網路輸出端可約束其輸出滿足特定性質。模組規格可能需比命題邏輯更具表示力的語言——一階邏輯（用謂詞表達量化變數間關係，如 ∀x∃y R(x,y)）。例如數獨可用三元謂詞 In(block,position,value) 更精簡，約束含「存在性」與「唯一性」。

示範把 LBM 當邏輯層疊在深度網路上做語意影像詮釋（預測影像中物件與其部件的關係，需一階邏輯）。知識庫含「某物件類型通常是另一類型的部件」之事實（如 isPartOf(Screen,TV)），及連接兩視覺場景的一階規則（式 23）：「給兩視覺場景及其類型分類，前者是後者的部件 ⟺ 前者類型是後者類型的部件」。實作：Faster-RCNN 抽物件特徵 → 兩個**神經迴歸器（NNR）**實作謂詞 isOfType（輸出謂詞真值）→ 自編碼器實作符號變數間 isPartOf 關係 → 規則轉 SDNF → 以 LBM 當邏輯層疊在這些網路之上（圖 13）。

LBM 的推理可反向傳播回去更新 CNN/迴歸器/自編碼器的權重（最小化一個含 LBM 推理項的損失函數）。例：若網路告知 isOfType(x1,Screen)、isOfType(x2,TV) 且知識含 isPartOf(Screen,TV)，LBM 可推得 partOf(x1,x2) 應為真，此訊號用於更新對應網路參數。

6. 神經符號 AI 的挑戰

與多數 LLM/CoT 路線（推理能力被期待「湧現」、事後用 benchmark 量）不同，本文用邏輯給推理形式定義——有了良定義的語意才能談網路與各種推理形式的對應。我們證明了命題邏輯與 RBM 的等價，催生 LBM。未來聚焦擴展到 SAT 與「資料＋知識」學習（加權子句、加權 SAT 平行化、關係學習）。有了「RBM 可實作某類約束」的證明與演算法，便可想像把 RBM 當可驗證模組疊上網路施加約束（如公平性/安全性需求）。下文討論它對 AI 三大挑戰——資料效率、公平性、安全性、終至信任——開啟的研究方向。

6.1 非單調邏輯

常識推理需「基於不完整資訊跳到結論、得新資訊時收回/修正」，因此用非單調邏輯建模（部分不可判定）。LLM 在常識 benchmark 上勝過邏輯形式化——從資料學常識比邏輯形式化更容易；但理解 LLM 所學極難。理解所學或能反過來幫助釐清「常識邏輯形式化的極限」。隨神經網路用於科學發現，真正理解其過程將要求解釋網路推理的能力。

6.2 規劃

AGI 需朝目標規劃、提問。規劃需把目標拆子目標、在部分資訊下隨時間推理；有目標需「當前狀態與目標狀態的描述」＋「縮小兩者差距（某距離函數）的機制」，機制失效時可改目標或改機制本身。AlphaGo/數獨等封閉環境可用模擬學會最小化距離函數而不需顯式描述；開放情境則難得多——顯式描述須可被符號操作（能問「若做此改動會怎樣」而不真做），且須從少數範例抽象而來。此種「對抽象描述做符號操作」的推理，本質不同於「以相似度/距離做 pattern matching」的推理。

6.3 從錯誤中學習

AGI 應能從錯誤學習、與使用者互動提問、描述其理解、受控地朝目標改進（甚至改目標與改進機制）。在符號描述層受控才能保證安全。呼應 Kahneman《快思慢想》——在 pattern matching 與更抽象兩層皆能推理，系統才能從少數範例適應新奇、檢查理解、多任務與跨任務重用知識，提升資料/能量效率。適應新奇（解長尾與分布外問題）需建立緊湊表示，也需時時改變表示以獲新洞見（如同 spaghetti code 與 beautiful code 之別）。這正是最新 NeSy 研究的核心挑戰：從複雜網路抽取對的抽象層級描述、健全地用多種表示（空間/時間/知識/規範/多模態/非單調）做推理與學習、高效重用與外推。Transformer 本質是「集合映集合」（需位置編碼處理序列），而 NeSy 計算各種邏輯語意也是遞迴地「集合映集合」；多頭注意力類似表示二元關係。某些領域（如蛋白質交互）需表示 n 元關係（如 bond（化合物，鍵型，原子1，原子2），即 Mutagenesis 任務），可用超圖神經網路；而 fibring 神經網路已被證明為 GNN 與 transformer 提供共同表示基礎（對應到帶 self-fibring 的命題模態邏輯）。
