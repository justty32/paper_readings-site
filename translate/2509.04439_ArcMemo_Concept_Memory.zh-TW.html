論文／訪談原始來源

ArcMemo：以終身 LLM 記憶做抽象推理組合

摘要

外部記憶是持久化「模型於推理時得到的發現」的自然方式，近期工作已顯示其對推理密集任務的明顯好處。我們看到機會讓這類記憶更廣泛可重用且可擴展：從實例級記憶條目（精確查詢/回答對，或與原問題脈絡緊耦合的摘要）邁向概念級記憶——從解題軌跡蒸餾、以自然語言儲存的可重用模組化抽象。對未來查詢，選擇性檢索相關概念並整合進 prompt，達成不更新權重的測試時持續學習。我們的設計引入新策略：從 rollout 抽取要點、為新查詢檢索條目，促進重用並讓記憶隨經驗擴展。在 ARC-AGI（壓測組合泛化與抽象推理的基準）上，方法較強無記憶基線取得 7.5% 相對增益，且表現隨推理計算持續擴展。我們發現抽象概念是最一致的記憶設計，在所有測試的推理計算規模下都勝過基線；且測試時動態更新記憶優於固定設定，支持「累積並抽象模式能促成更多解、形成一種自我提升」的假設。

1. 引言

人類解複合推理問題會在先前洞見上累積、抽象模式、在新情境組合。給 LLM 加記憶是保留並在其發現上累積的自然解法。外部增強最初為知識密集任務的事實性而設計（RAG、知識圖譜），近期才轉向推理密集任務——存問題、發現、錯誤而非單純事實。但這些記憶常特定於其衍生的問題/經驗（稱「實例級」概念）。無選擇性檢索時，記憶大小受限、且解題模型還得從所有過往經驗裡挑出相關點子。

我們引入抽象概念級記憶框架支援後續所有查詢的組合推理，含兩個性質：(1) 抽象概念——更一般、脫離原脈絡，對更大的未來問題集有用；(2) 模組化概念——直接促進與其他想法重組、易在新經驗上累積或為目標問題策畫。把解題軌跡（自系統或外部來源）蒸餾成可重用、模組化、自然語言儲存的抽象；推理時選擇相關概念整合進 context，達成不需昂貴權重更新的測試時持續學習。兩大操作：(i) 寫入記憶——格式化概念以利抽象與通用；(ii) 讀取記憶——為當前問題選概念子集。方法命名 ArcMemo（Abstract Reasoning Composition Memory）。

實例級 vs 抽象概念範例：每個 ARC-AGI 謎題須對一組輸入/輸出像素網格推出變換規則。實例級記憶傾向存完整組合的規則（把 A 與 B,C 耦合）；抽象記憶則把 A,B,C,D,E 各自存成獨立模組概念，更易在新脈絡辨識與重組。

評測：在 ARC-AGI 上（簡單像素操作組合成廣大任務空間，解題需組合推理而非死背個別模式，是 ArcMemo 的天然 testbed），方法把官方分數從 55.17 提到 59.33（相對 +7.5%），且是唯一在所有推理規模下都勝過基線的記憶設計。實驗確認評測時持續更新記憶帶來隨推理規模（重試）湧現的分數提升——前一輪 pass 觸發的記憶更新可能讓後一輪 pass 解出新題。此外，為特定問題選記憶子集既提升表現又降 token 成本，顯示選擇操作的價值超出「讓記憶能持續長大」。

2. 相關工作

本方法承襲「給 LLM 加記憶」多條研究線，但在 (1) 目標應用（推理密集 vs 知識密集）、(2) 記憶模態（文字 vs 連續向量/嵌入）、(3) 對抽象與模組化的強調上有別。

  • 測試時推理與概念抽象的記憶：近期轉向以記憶做推理（尤其測試時學習）。Think-in-Memory 把中間推理步驟記成結構化三元組、存進 locality-sensitive 雜湊表供多步重用；Buffer of Thoughts 存問題特定推理模板、以嵌入相似度檢索並對新輸入實例化（把解題嘗試分類摘要成模板化洞見再加入記憶）。
  • 另於附錄討論嵌入空間記憶、無參數測試時學習、agentic 技能獲取的記憶等線。

3. 方法

3.2 記憶格式與組織

概念以自然語言儲存，分兩種格式（OE 與 PS），追求抽象、可重用、模組化。

3.3 記憶寫入：概念抽象

  • OE（Open-Ended）抽象：從解題軌跡抽建議很直接——查詢模型反思軌跡、摘要可重用的一般想法。為此產生後驗推導：從最終解的輸入-輸出構造「觀察與思考/推理步驟」交錯的序列。冗餘與想法整併分別留給選擇與解題階段處理。
  • PS（Program-Synthesis 式）抽象：直接把解轉成 routine 常把低階實作細節錯記成概念；故先把解前處理成偽代碼以優先記錄高階操作，再從偽代碼抽概念、並修訂既有概念的各欄位。為促進抽象/重用/壓縮總記憶長度，此操作會帶壓縮版既有記憶於 context，鼓勵模型藉更新概念描述、參數列表、相關性提示、實作筆記來重用/修訂既有概念。所有寫入操作以 few-shot 示範 + 範例豐富模板 + 完整指示 scaffold。

3.4 記憶讀取：概念選擇

更有效的策略是引入選擇機制，解題時只納入最相關的記憶子集。

  • OE 選擇：OE 格式條目本就為記憶式選擇而設計。關鍵是一個前處理步驟——用模型推理能力把抽象域輸入解析成不同抽象層級的問題描述，以利匹配抽象概念。把空間豐富輸入轉成適合匹配儲存情境的自然語言格式，是輕量的轉換法。
  • PS 選擇：高階概念與具體問題實例的連結因抽象而未必明顯。故提推理導向選擇——用 System-2 式思考刻意探索。相對於 OE 策畫的較直接 playbook，顯式抽象的 PS 概念是一組「拼圖片」，附 relevance cue（辨識某片是否相關）與型別註解（各片如何拼接）。

3.5 持續概念學習

評測時動態更新記憶：前一輪 pass 觸發的記憶更新可能讓後一輪 pass 解出新題，形成跨重試的自我提升。

評測重點

  • ARC-AGI-1：官方分數 55.17 → 59.33（相對 +7.5% vs 強無記憶基線），唯一在所有推理規模下都勝過基線的記憶設計。
  • 抽象概念最一致、在所有推理計算規模下都勝基線；實例級因脈絡耦合而難重用。
  • 持續更新 > 固定：評測時持續更新帶來隨推理規模（重試）湧現的提升。
  • 選擇機制：為問題選子集同時提升表現與降 token 成本，證明選擇操作的獨立價值。
