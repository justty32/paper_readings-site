論文／訪談原始來源

Where the Verifier Fails: A Category-Level Audit of Reward Signals in RLVR

摘要與問題

RLVR 與數學 benchmark 都倚賴自動 verifier，把自由文字答案壓成二元 reward。問題是 verifier 並非數學 oracle，而是一串抽取、正規化、解析與等價比較程式。它拒絕正確答案時，訓練會懲罰該被獎勵的行為；接受錯誤答案時，又會反向鼓勵錯誤。單一 aggregate accuracy 只說「有多少錯」，無法回答錯誤集中在哪種答案形式，也分不出真正的拒絕與程式根本沒有產生 verdict。

作者把 metamorphic testing 的受測對象從模型改成 verifier。對 gold answer 套用依構造保證語意等價的轉換，任何拒絕都可直接判為 certified false negative，不需人工或另一個模型裁決；對語意確定改變的轉換，若被接受則是 certified false positive。

方法

轉換分成三類。certified-equiv 是 verifier 宣告支援範圍內的等價改寫，拒絕即算缺陷；contract-dep 是否應接受取決於介面契約，只呈現差異、不判為 bug；adversarial 明確改變數學意義，用來測 false positive。這個 contract matrix 避免把「功能未宣告支援」誤算成實作錯誤，也讓契約本身可被外界質疑。

研究同時拆開 rejection 與 execution failure。若 verifier 因 parse exception、timeout 或 crash 沒有回傳 verdict，就不該被算成成功拒絕。作者因此同報 all-input rate、只在成功判定樣本上的 judged rate，以及 coverage。這項區分能指出修理方向：字串比較錯誤要改善 normalizer；沒有 verdict 則要修 parser、runtime 或 timeout。

受測者涵蓋同一數學驗證函式庫的兩種 extraction 設定、DeepSeek-Math 系譜的字串 normalizer，以及由 exact string、數值容差與 SymPy 組成的 cascade。測試包含空白與標點、數學模式、集合、分隔符、分數與根式等 strata，也放入 off-by-one 對抗樣本，檢查相對容差是否造成有尺度結構的誤接受。

主要結果（作者自報）

作者自報，整體 audit 產生 307420 個 verdict。在相同輸入上，各 verifier 接受 certified-equivalent variant 的比例從 53.8％ 到 95.2％，顯示 self-validation 不是題目固有屬性，而是 verifier 實作與設定的函數。同一函式庫只換 extraction configuration，也會大量改變個別 pair 的判定。

作者自報，錯誤並未平均散在複雜數學語法中。預設 LaTeX 設定的 in-contract failures 有 93.0％ 來自空白與標點；尾端句點或換行就能主導 error budget。這使問題從「需要重寫 LaTeX grammar」變成更直接的字串 hygiene 與 normalization 工程。

coverage 拆分也揭示外觀相似、病因相反的 verifier。一種 cascade 對能判定的輸入全部答對，但部分輸入根本沒有 verdict；另一種 string verifier 幾乎都能判定，卻會直接拒絕等價表示。off-by-one 測試另發現，relative tolerance 會隨答案尺度跨過固定門檻後，系統性接受錯誤答案。這不是隨機噪音，而是可預測、可能被 RL 利用的 reward channel。

討論與結論

論文的實務主張很明確：benchmark 或 RLVR 報告不能只寫 verifier 名稱。至少還應公開版本、extraction configuration、runtime、coverage，以及按答案類別拆解的 false-negative 與 false-positive 結構。否則兩篇論文即使聲稱使用同一套資料與 verifier family，分數也未必可比。

metamorphic protocol 的價值在於，它把「正確性」嵌進轉換本身，省去人工判讀，並可組合地擴展到大量 golds、transforms 與 verifiers。結論不是所有 rule-based verifier 都不可靠，而是可靠性必須被量成一張按類別、契約與 coverage 分層的圖，不能被一個 aggregate rate 取代。

局限

作者明列五項界線。這是 verifier-level audit，沒有估計任何模型 benchmark 分數會因此變動多少；研究也沒有實際跑 RLVR 訓練，因此不直接量測 downstream policy effect。受測範圍只含開放實作，不能外推到封閉的 frontier systems。資料含 synthetic golds，雖然 corpus-only 檢查保留了主要排序與效應，合成分布仍不是自然模型輸出的替身。最後，哪些 strata 算 in-contract 本身含判斷成分；作者選擇公開矩陣，讓這個假設可以被重算與爭辯。
