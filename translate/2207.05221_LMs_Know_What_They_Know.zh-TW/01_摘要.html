摘要

我們研究語言模型能否評估自己主張的正確性、預測自己能答對哪些問題。首先，我們證明只要問題格式恰當，較大的模型在多樣的多選題與是非題上都有良好校準。因此，對於開放式取樣任務，我們可以讓模型先提出答案，再評估「該答案為真」的機率 P(True) 來做自我評估。我們在多樣任務上觀察到 P(True) 有令人鼓舞的表現、校準與規模效應。當我們允許模型在判斷某個特定可能性之前，先考慮自己的多個樣本，自我評估的表現會進一步提升。接著，我們研究是否能訓練模型預測 P(IK)（不涉及任何特定提議答案，"I know" 這個問題答案的機率）。模型在預測 P(IK) 上表現良好，並能部分跨任務泛化，但在新任務上的 P(IK) 校準較差。當脈絡中出現與問題相關的來源材料，以及數學應用題的解題提示時，預測出的 P(IK) 機率也會適當上升。我們希望這些觀察能為訓練更誠實的模型打下基礎，並有助於探討當模型是在模仿人類寫作以外的目標上訓練時，誠實性如何泛化。

1 引言

我們最終希望訓練出誠實的 AI 系統，這要求系統能準確且忠實地評估自己對知識與推理的信心水準——AI 系統必須能辨認自己知道什麼、不知道什麼，這是前提。本文研究語言模型（LM）具備此能力的程度，以及如何誘發並賦予這種能力。

作為起點，我們檢視校準（calibration）：語言模型的機率預測是否與實際發生頻率吻合？已知語言模型在分布內的 token 機率是校準良好的 [Guo et al., 2017]。我們證明，只要問題格式適當，大型語言模型在多樣的多選題上也校準良好；具體而言，校準隨模型規模與 few-shot 提示而改善。

良好的校準讓我們有機會用模型來評估自己輸出的準確性（「自我評估」）。例如，對任何開放式查詢，我們可以從模型取樣一個答案，再讓模型評估該答案正確的機率 P(True)。我們原本預期自我評估會很有挑戰性，因為模型可能對自己的樣本過度自信（另一個更微妙的問題是：在我們的設定中，模型沒有辦法區分自己寫下的 token 和第三方給它的 token）。然而我們的自我評估流程依然能區分正確與錯誤樣本。此外，隨模型規模與能力提升，模型在自我評估上也隨之進步，暗示在此脈絡下驗證能力進步得比生成能力更快。

我們也證明，如果先給模型看自己的多個樣本，再要求它評估某個特定樣本，自我評估可以進一步改善——也就是「先腦力激盪其他可能性」有助於大模型判斷某個答案選項的有效性。

以上技術處理的是關於世界的問題：「依照世人（人類）公認的事實，某個問題的某個答案是否正確？」在自我評估的情境中，提議的答案雖是模型自己生成的，但其正確與否仍是一項外部事實。

但我們同時關心語言模型能否直接評估自己的知識狀態。為此，我們研究了訓練模型去預測「自己能否正確回答某問題」會發生什麼——這其實是關於模型本身的問題，因為不同模型會知道不同問題的答案。

我們發現語言模型能輕易學會在給定分布上很好地評估 P(IK)（"I Know" 機率，即模型知道問題答案的機率，見圖 3 為例示）。更有趣的是，我們也觀察到一定程度的跨任務泛化（例如從常識問答泛化到故事補全、數學、程式碼），儘管模型在分布外的校準較差。我們也觀察到其他型態的泛化：儘管 P(IK) 只在裸問題上訓練，它仍會在脈絡中出現能回答該問題的來源材料時（針對常識問答）、以及數學應用題出現解題提示時，適當地上升。

1.1 貢獻

校準：多選、None of the Above、True/False

  • 當使用可見字母標籤選項的格式時，大模型在多樣多選題（BIG Bench、MMLU、其他多種評測）上校準非常良好。
  • 校準隨模型規模改善，也隨 zero-shot 過渡到 few-shot 評測而改善。
  • 把某個選項換成「none of the above」明顯降低準確率與校準；但模型在 True/False 判斷上仍校準良好，準確率與校準同樣隨模型能力提升。
  • RLHF policy [Bai et al., 2022] 原生看似校準很差，但簡單的溫度調整就能讓它在多項評測上大致修復校準。

無需微調的模型生成樣本自我評估：在 TriviaQA、Lambada、GSM8K、Codex HumanEval、算術題、自建 Python 函式合成題上，模型能自評自己樣本的真偽，雖然這比評判人類寫的選項更難（模型傾向覺得自己的樣本更可信）。Few-shot 下自評校準良好，zero-shot 則較差；k-shot 中的較大 k 主要透過改善校準、而非改善辨別正確/錯誤的 AUROC 來提升表現。讓模型看過自己多個 T=1 取樣後再判斷某一個是否為真（有點像 self-consistency 提示 [Wang et al., 2022]），能顯著改善表現。

微調以辨識模型能正確回答的問題：訓練帶 value head 的模型預測 P(IK)。發現在 TriviaQA 上訓練的模型，對數學、Lambada、程式碼題有顯著的區分力（見圖 12），但 P(IK) 在這些其他分布上校準較差（圖 13）；泛化在圖 16、17 中最清楚。研究 P(IK) 對來源材料與數學提示的泛化（圖 18、19），發現 P(IK) 會對來源材料、正確提示、錯誤/分心提示做出適當反應。比較兩個能力相近但預訓練資料不同的模型（圖 20），發現模型預測自己的 P(IK) 略優於預測另一個模型的 P(IK)；「交叉」訓練資料的實驗顯示，用「模型自己知道什麼」訓練比用「另一個模型知道什麼」訓練泛化略好。因此我們只觀察到部分泛化。

1.2 模型與評測任務

本研究涵蓋 BIG Bench [Srivastava et al., 2022] 所有多選評測、MMLU [Hendrycks et al., 2021]、TruthfulQA [Lin et al., 2021]、LogiQA [Liu et al., 2020]、QuALITY [Pang et al., 2021]；開放式生成則研究取樣式評測 TriviaQA [Joshi et al., 2017]、Lambada [Paperno et al., 2016]、Codex HumanEval [Chen et al., 2021]、GSM8k [Cobbe et al., 2021]、基礎算術題，以及自建的 Python 函式合成資料集。研究對象是 800M、3B、12B、52B 四種規模的純語言模型，架構與訓練設定與 [Bai et al., 2022] 相同，但預訓練 850B token（該文為 400B）；未研究針對 Python 程式碼微調的模型，但預訓練分布中約 10% 是程式碼。§3.3 簡短研究了以相同基礎模型微調的 helpful-and-harmless RLHF policy，其餘皆研究純語言模型。

1.3 相關工作

一般 ML 預測的校準與改善方法已被研究多年 [Guo et al., 2017 等]。語言模型與問答的校準也有人研究 [Desai and Durrett, 2020; Jiang et al., 2021]，但通常發現要調整預測才能達到好校準；棄答式的 selective prediction 也已被研究 [Varshney et al., 2022]。BIG Bench 的分析顯示語言模型校準隨模型規模改善；Gopher [Rae et al., 2021] 在 MMLU 上初步研究校準並得到正面結果，促成本文嘗試多種多選格式。真實性（truthfulness）議題近來受到關注，包括基準測試 [Lin et al., 2021] 及結合網路搜尋與引註 [Nakano et al., 2021; Menick et al., 2022]；但真實性主要關注「對世界的事實準確度」，而非自我知識或引出潛在知識 [Christiano et al., 2021]。本文用「誠實（honesty）」[Askell et al., 2021] 作為涵蓋真實性、校準、自我知識、可解釋性、非欺騙性的統稱詞。與本文最相近的可能是 [Mielke et al., 2020]（元認知/自我評估改善自然語言校準的有趣應用）與 [Lin et al., 2022]（訓練語言模型用文字表達對算術的校準信心，也研究了類似 P(True) 的訊號）。
