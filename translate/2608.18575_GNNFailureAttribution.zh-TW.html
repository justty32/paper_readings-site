論文／訪談原始來源

Beyond LLM-Based Reasoning: Lightweight GNNs for Agent Failure Attribution

摘要與第 1 節：問題

LLM-based 多 agent 系統常見複雜的失敗模式：一個 agent 的錯誤在後續互動中傳播，最終導致整體任務失敗。Agent Failure Attribution（AFA）任務要求：給定一條失敗的多 agent 互動軌跡，找出哪個 agent 犯了哪種錯誤。既有方法幾乎都把這當生成式推理問題——直接 prompting、在合成失敗資料上微調、或搭建複雜多階段 agentic pipeline——但都有三個問題：長 context 處理與重複推論帶來高計算成本；多階段手工 pipeline 帶來系統複雜度；即使投入這些成本，即使是最先進的推理模型或專有模型，在既有 benchmark 上準確率仍有限，有時甚至輸給隨機 baseline。這促使作者提出一個根本問題：agent failure attribution 真的需要重度 LLM 推理嗎？

第 3 節：方法

對話圖建構（3.1）：把失敗軌跡 T={(a_{i_t}, x_t)} 轉成異質圖，每個 turn 是一個節點。節點特徵分三部分：先把每個 turn 當文件、整條軌跡當語料建 TF-IDF，再用 truncated SVD 降到低維，算出該 turn 相對於對話上下文的「偏離特徵」（deviation features）；加上非語意的統計特徵（如位置編碼）；再加上 sentence-BERT 的密集語意 embedding；三者拼接成節點初始特徵。邊有兩類：相鄰 turn 的雙向時序邊，保留對話的序列性；同一 agent 產出的非相鄰 turn 之間的雙向邊，捕捉跨輪的長程一致性。作者的核心直覺是：故障 agent 的行為往往反映在互動動態的不一致，而不只是單一 turn 的語意內容。

AFANet 架構（3.2）：節點特徵先經線性投影＋ReLU＋LayerNorm 到隱藏維度，再過 L 層 message passing（帶殘差連接，GNN 層可代換 GCN／GAT／GraphSAGE 任一架構）。同一 agent 的所有 turn 表示做「mean-pool 與 max-pool 串接」的雙重 pooling，得到 agent 級表示，再經一個含 bottleneck 投影＋dropout 的多層投影頭，輸出 K+1 類的未正規化分數（class 0 為 clean，1..K 為各錯誤類型）。

訓練目標（3.3）：agent 級目標用 weighted BCE 判斷該 agent 是否故障（正類權重＝clean 數／faulty 數，處理類別不平衡）；錯誤類型目標只對故障 agent 算多類別 CE。總 loss 是兩者加權和。

推論（3.4）：計算每個 agent 的故障機率分數；threshold 解碼用驗證集掃出最佳門檻 τ（先定 agent 級門檻，再定 error-level 門檻 τ_fm）；ranking 解碼直接依分數排序取前幾名 agent。

第 4 節：實驗（作者自報）

主結果：在 AEGIS-Bench（in-domain）與 Who&When（OOD）上，AFANet 對比預訓練 LLM（Qwen2.5-7B/14B、Qwen3-8B）、微調 LLM（SFT，部分再加 GRPO）取得可比或更優的平均表現。作者特別強調 pair-level 指標（同時抓對故障 agent 與錯誤類型，是最難也最有實務意義的指標）：AEGIS-Bench 上 AFANet 拿到 top-1；Who&When OOD 上仍維持高排名，作者將此歸因於「結構性互動動態與一致性模式在不同軌跡間相對穩定，而後訓練方法可能過擬合表層語意模式或資料集特定的失敗分布」。

效率對比（Table 2）：7B SFT 訓練 6 小時、7B SFT+GRPO 訓練超過 26 小時，推論 199 秒（in-domain）／108 秒（OOD）；14B 相應數字更高。AFANet 訓練僅 1.1 小時，推論僅 1.16 秒／0.37 秒，圖建構的前處理時間也僅 80.8 秒，可訓練參數僅 65K（對比 7B/14B）。

Backbone 敏感度（4.3）：GCN／GAT／GraphSAGE 三種 backbone、1–3 層深度下整體表現相對穩定，顯示效果不繫於特定架構或精調層數。

Ablation（4.3）：拿掉全部邊會持續降低表現，證明關係結構重要；只用同 agent 邊或只用時序邊也都比完整圖差，顯示兩種訊號互補。拿掉 deviation/statistical 特徵造成整體性能大幅下降（尤其 pair-level 指標），支持「故障 agent 常表現為互動動態異常與一致性違反」的假設；拿掉 GNN 模組同樣傷害表現。

OOD 泛化與 test-time adaptation（4.3）：作者承認在嚴重分布偏移下泛化仍具挑戰，於是嘗試不需重訓練、不需額外標註的 entropy-minimization test-time adaptation（TTA），比較 agent 級、pair 級、faulty-agent-pair 級三種粒度的熵最小化目標。Table 5 顯示 pair-level TTA 整體增益最大（平均分從 13.96 升到 14.63）。

結論與限制

作者總結：重新檢視 agent failure attribution 後發現，重度生成式推理並非必要；用簡單的 step-level 訊號與 agent 級結構建模的輕量框架，即可以極低計算成本取得可比或更優的表現，顯示結構化建模足以應付有效的歸因任務。附錄 E 列出兩項限制：一是 OOD 泛化在顯著不同的多 agent 設定下仍具挑戰，未來可設計客製化的 message passing 算子；二是推理能力有限，某些失敗仍可能需要更深的語意理解與長程推理，未來方向是把圖建模與 LLM 推理結合而非互斥。
