摘要

AI 社群正透過開發「語言代理（language agents）」探索通往 AGI 的路徑——這類代理是結合 prompt 技術與工具使用的複雜 LLM pipeline。語言代理雖在許多真實任務上展現亮眼能力，但當前研究的根本限制是以模型/工程為中心（model-centric / engineering-centric）：prompt、工具、pipeline 的進展都需人類專家大量手工，而非從資料自動學習。我們認為，從 model-centric 轉向 data-centric（讓語言代理能在環境中自主學習與進化）是其可能達成 AGI 的關鍵。

本文提出 代理符號學習（agent symbolic learning）：一個讓語言代理用符號優化器、以 data-centric 方式自主優化自身的系統化框架。我們把代理視為符號網路，其可學習權重由 prompt、工具，以及它們堆疊的方式定義。代理符號學習藉由模仿連結主義學習的兩個基本演算法——反向傳播與梯度下降——來優化此符號網路；它處理的不是數值權重，而是權重、損失、梯度的自然語言模擬物。我們在標準 benchmark 與複雜真實任務上做概念驗證，顯示此框架能讓語言代理在被建立與部署後仍持續更新自己，造就「自我進化代理」，並全部開源。

1. 引言

開發 AI 代理的常見做法是把複雜任務分解為 LLM pipeline，把 prompt 與工具堆疊起來。語言代理可視為連接連結主義 AI（代理的 LLM 骨幹）與符號主義 AI（prompt 與工具的 pipeline）的系統。但目前語言代理開發受縛於大量工程：研究者須手動把任務分解為子任務（稱為 node）、為各 node 精心設計 prompt 與工具（API、知識庫、記憶等）。這使整個領域呈 model-centric / engineering-centric，幾乎不可能像訓練神經網路那樣在資料集上以 data-centric 方式調校代理，限制了穩健性與通用性。

近期已有自動優化嘗試：DSPy 在 prompt 組件的組合空間中以 bootstrap/隨機搜尋優化 prompt；GPTSwarm 進一步以迭代優化處理組合優化挑戰；Agent-Pro 優化對應代理內部策略的 prompt 組件；AgentOptimizer 以工程化 prompt 優化函式。但這些方法只優化代理系統中的孤立模組（如某 node 的單一 prompt），易陷孤立 prompt/工具/node 的局部最優，損及整體表現。這如同早期分層分別訓練神經網路的做法——如今我們已知整體優化才更好。本文主張代理優化亦然：聯合優化代理內所有符號組件才是關鍵。

我們提出 代理符號學習框架，受連結主義學習程序啟發。核心類比：代理 pipeline ↔ 神經網路計算圖；pipeline 中的 node ↔ 神經網路的層；node 的 prompt 與工具 ↔ 層的權重。如此便能用語言版的損失、梯度、權重實作反向傳播與梯度式更新。對一個訓練樣本：先做「前向傳播」（執行代理）並把每 node 的輸入/輸出/prompt/工具使用存入 trajectory；再用 prompt 式損失函式評估結果得「語言損失」；接著沿 trajectory 從最後一個 node 反向傳播到第一個，產出各 node 內符號組件的文字分析與反思，即「語言梯度」；最後依語言梯度，用另一精心設計的 prompt 更新各 node 的所有符號組件、以及由 node 與其連線構成的計算圖。此法也自然支援多代理系統（把 node 視為不同代理、或讓多代理在一個 node 內行動）。

與既有「分別優化單一 prompt 或工具」的方法不同，本框架聯合優化所有符號組件（prompt、工具、堆疊它們的 pipeline），這種自上而下的方案能「整體地（holistically）」優化、避免各組件的局部最優。又因語言損失函式生成時不需 ground-truth，本框架讓代理能從經驗學習、在被部署到野外後審慎更新所有符號組件——實現「自我進化代理」。

2. 相關工作

  • 語言模型、prompt 與語言代理：LLM（Transformer、autoregressive、大規模語料）展現生成與理解能力；prompt 是釋放其能力的關鍵（in-context learning、CoT、ReAct、self-refine、self-consistency 等）；語言代理進一步讓 LLM 用工具、整合進可執行多步任務的系統。
  • 從自動 prompt engineering 到代理優化：自動 prompt 法分prompt-based（用 prompt 讓 LLM 自我做 prompt engineering）與search-based（用遺傳演算法等搜尋）。代理優化同樣兩類：Agent-Pro / AgentOptimizer 用 prompt 優化某 node 的孤立 prompt 或工具；Sordoni 用變分推論優化堆疊 LLM、DSPy / GPTSwarm 用搜尋。這些法的主要限制：(1) 搜尋法多需可用方程/程式定義的數值指標，但多數真實代理任務（軟體開發、創意寫作）的成功無法以方程定義；(2) 各組件分別更新→陷局部最優；且無法新增 node 或實作新工具。本框架是首個能「整體優化」prompt、工具、node 及其堆疊方式的代理學習法。另有蒐集資料 fine-tune 代理 LLM 骨幹的研究線，與本工作正交、可互補。
