論文／訪談原始來源

MLE-World：在真實執行前預測實驗回饋

第 1–3 節：問題與背景

機器學習研究 agent 寫程式、執行、讀 log 再修正，但每個候選可能需要訓練模型。AIDE 在程式樹上 Draft、Debug、Improve，依實際驗證分數選最後提交。MLE-World 先以模型預測完整程式的終端回饋，讓 agent 比較多個候選，再有選擇地真跑；最終提交仍以真實 validation 選取、隱藏測試評分。（§1、§3、§6）

第 4–5 節：模型、探索與 gate

Qwen3.5-4B 接收程式、套件版本、AIDE 資料概覽和時限，依序輸出例外類別、終端 log、validation metric、提交旗標；使用 497,056 筆歷史執行全參數監督微調（視覺塔凍結），包含成功與失敗。82 個例外類別的首 token 機率重正規化後，p_max 為最可能類別的信心，p_clean 為 null 類機率。留出資料中 p_max 分位越高，各欄位的吻合率也越高；這不是經證明校準的全文正確機率。（§4、§6.3；最後界線為本檔補註）

Best-of-N 按預測分數選，Sequential 依預測錯誤／log 修訂，Pairwise 讓 LLM 比較，Fusion 從候選與預測合成，UCB 在預測分數上加不確定性 bonus；它是經驗探索 proxy，不是正式統計 confidence bound。只在預測正常、有提交且 metric 有限的池內比較分數。Gate 對低信心或缺信心的選中程式真跑；新最佳預測 metric 也必須真跑，以保留可驗證提交；預測 timeout 不跑。（§5、附錄 J）

第 6.1 節：同任務留出程式

主試驗使用 MLE-bench Lite 的 17／22 題，排除五題難有進展者。留出 1,700 程式，每題 100 個、平衡 agent 階段及快慢執行；訓練與測試共享任務。去重排除偵測到的 exact／near duplicates，但機率式 MinHash 搜尋可能漏掉相似項或跨題語意重疊。（§6、附錄 E）

MLE-World 與最強 prompted DeepSeek：terminal judged match 77.9±1.0%／41.1±1.1%，exception exact 86.4±0.8%／57.2±1.2%，crash judged match 76.4±1.3%／48.2±1.5%，validation metric 相對誤差 ≤5% 為 78.1±1.9%／18.6±1.7%。SE 來自 2,000 次 program bootstrap；任務多數與最近程式 corpus controls 的 metric 命中為 55.2%／55.6%。終端 match 是語意判定而非逐字；judge 與獨立 120 例人工標籤的多數決一致 96.7%，成功 log 容許 headline 分數相對差 15%。（表1、附錄 I）

第 6.2–6.3 節：搜尋及真實執行

12h、每設定 17 題 × 三 seeds，提交以真實 validation 選取，無效提交計零，作者報平均測試 leaderboard percentile。未 gate 的 Base AIDE 45.4；Sequential 51.3、Pairwise 47.1、Fusion 47.5、BoN 50.2、UCB 52.1。這些是觀察均值，不等於五種比較皆顯著。（表2）

加 gate 的 Sequential 均值 55.4 對 Base 45.4，約多 10 percentile points；摘要 22.1% 是相對提升，不是 22.1 個百分點。五策略各自 gate 相對 ungated 減少 30.0–39.8% real execution 時間；這不等於總推論 GPU 成本或 wall-clock 減幅。跨封存 cohort 比較屬描述性；主文 §6.3 稱 12 小時 UCB 為 S50/F83，附錄 M 稱表4 UCB 為 S50/F56。（表4、§6.3、附錄 M、附錄 O）

固定狀態診斷從 153 個取樣狀態，扣除三個 Sequential／Fusion 未完成狀態後共同比較 150；Fusion 相同四候選只給程式時 14.0，加預測 log 20.6 percentile，差 6.55±2.87 points。Pairwise 和 Sequential 的預測 log 改善未確立，各方法模型呼叫數不同；真實 log 未顯示額外收益也不證明與預測等效。（表3、附錄 P）

另一個 8h BoN 控制：隨機／confidence gate 各 51 trials、seed 不同，實際執行 5.54／4.49 小時，percentile 47.37／47.21；confidence gate 少約 19% 執行時間，paired task 差 −0.15±2.32 points，未確立品質差異。（附錄 N）

第 7 節與附錄：限制

三個微調排除的任務各測 100 程式，terminal judged match 53.3% 對 DeepSeek 42.1%；樣本以失敗執行為主，成功訓練與 timeout 泛化仍未確立。主實驗同任務、依賴約 50 萬既有執行；Base AIDE 尚未測同 corpus 存取。錯誤預測可誤導搜尋，漏判 timeout 仍會耗完整執行；作者將更廣任務和模型、執行時間預測列為未來研究。（§7、附錄 R）
