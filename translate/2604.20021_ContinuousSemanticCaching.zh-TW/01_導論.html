1. 導論

大型語言模型（LLM）已廣泛部署，ChatGPT 據報達 7 億用戶。然而 LLM 查詢代價高昂：秒級延遲、高能耗與運算成本，且隨查詢量增長而惡化。快取（caching）是自然的解方——對語意相似的查詢直接回傳已快取的回應，免除 LLM 推論。研究發現超過 30% 的 LLM 查詢彼此語意相似。

然而快取設計問題（該快取哪些查詢-回應對？）構成挑戰：快取大小有限，需優先快取高頻率且高成本的查詢，但其成本與到達機率未知且隨機。現有語意快取框架均假設快取候選來自已知的有限離散集合——當 LLM 用戶與查詢多樣化後，此假設根本不可行：真實查詢存在於無限連續嵌入空間中。

本文建立首個連續查詢空間下語意 LLM 回應快取的嚴格理論框架。核心技術：動態 𝜖-net 離散化搭配核嶺回歸（Kernel Ridge Regression, KRR），使系統能正規量化估計不確定性，並將 LLM 查詢成本的部分回饋泛化到連續語意鄰域。

作者提出三種設定下的演算法：(1) 預言機（已知參數）——給出 Reverse Greedy 近似保證；(2) 離線學習——CUCB-SC-Cont，用 KRR 從歷史資料估計成本；(3) 線上自適應——CLCB-SC-LS-Cont，動態建構 𝜖-net 並最小化快取切換成本。理論上證明線上演算法對連續 oracle 達成次線性（sublinear）regret，實驗顯示離線次優性改善最高 73.32%，線上 regret 降低最高 72.41%。

1.1 相關工作

低成本 LLM 服務：量化、推測解碼減少運算開銷，快取則完全消除冗餘計算。曾在 KV-cache 層級、API 請求路由層級做快取，但查詢層級的快取最直接：早期工作基於精確文字匹配（過於嚴格），後發展為語意快取（允許相似查詢共享回應）。然而現有語意快取系統仍為啟發式，假設已知查詢成本或到達分佈，不泛化到連續空間。本文首次處理連續查詢空間下具不確定性的快取。

基於學習的快取最佳化：LFU/LRU 為簡單線上啟發式，成本感知變體如 LEC 估計請求機率與檢索成本指導快取。作者先前工作 [19] 引入語意快取的線上自適應框架，但限於有限離散查詢集。轉向連續域根本改變了問題的數學結構——可建模為一種組合多臂 bandit（CMAB），額外引入"反向回饋"挑戰：從快取提供查詢時，LLM 真實執行成本不可觀測。

1.2 貢獻

(1) 連續語意快取模型（§2）：查詢從連續空間的未知機率分佈中抽取，抵達時比較快取不匹配成本與 LLM 推論成本決定來源。引入覆蓋查詢空間的 𝜖-net，劃分為 Voronoi 區域以離散化快取設計問題。(2) 演算法設計：預言機設定（Reverse Greedy + 離散化保證）、離線設定（CUCB-SC-Cont + KRR 悲觀學習）、線上設定（CLCB-SC-LS-Cont + 低切換自適應）。(3) 理論保證：預言機近似保證、離線次優性 gap 界、最優 𝜖 選擇、線上 regret 上界。(4) 實驗評估：合成與真實資料（NQ+TriviaQA）上顯著改善。

2. 系統模型

2.1 LLM 服務系統

查詢與嵌入：查詢（自然語言提示）從連續空間 X ⊂ ℝᵈᵉ 上的機率密度函數 𝑓 中獨立抽取。X 透過距離函數 𝑑（如嵌入空間中的歐氏距離）繼承度量結構。𝑝 ≤ 𝑑ₑ 為 X 的內在（度量）維度。

服務成本與部分觀測：每個查詢 𝑥 有關聯的未知期望服務成本 𝑐(𝑥) ∈ (0,1]（如延遲或運算成本）。僅當系統實際呼叫 LLM 時才觀測到成本的雜訊實現 𝐶𝑡(𝑥) = 𝑐(𝑥) + 𝜂𝑡(𝑥)，其中雜訊為條件 𝑅-sub-Gaussian。

語意相似度與不匹配成本：快取 M 為最多 𝑘 個查詢-回應對 {(𝑢₁, 𝑎(𝑢₁)), ...}。查詢 𝑥 到快取的距離定義為 𝑑(𝑥, M) = minᵤ∈M 𝑑(𝑥, 𝑢)，最近快取項為 𝑠(𝑥, M)。若以快取回應服務 𝑥，產生期望不匹配成本 𝜙(𝑑(𝑥, 𝑢))，其中 𝜙: ℝ⁺→[0,1] 為非遞減函數（如截斷線性：𝜙(𝑑) = min(𝜁𝑑, 1)）。直接呼叫 LLM 則無不匹配成本。

2.2 語意快取

每回合 𝑡，查詢 𝑥 ∼ 𝑓 到達，系統選擇：快取查找（用 𝑠(𝑥, M) 服務，付出不匹配成本 𝜙(𝑑(𝑥, M))），或 LLM 查詢（呼叫 LLM，觀測並付出成本 𝑐(𝑥)）。最佳決策規則比較兩者成本。

𝜖-Net 離散化與 Voronoi 區域：直接在連續空間 X 上最佳化不可行。以 𝜖-net S = {𝑥₁, ..., 𝑥ₘ} ⊆ X 近似，使得任意 𝑥 ∈ X 都有某 𝑥ᵢ ∈ S 滿足 𝑑(𝑥, 𝑥ᵢ) ≤ 𝜖。S 誘導將空間分割為 𝑚 個 Voronoi 區域 𝑉ᵢ。

定義各區域權重 𝑤ᵢ = ∫𝑉ᵢ 𝑓(𝑥)𝑑𝑥（即該區域的查詢機率質量）。連續空間上的期望損失為：

L(M; 𝑓, 𝑐, 𝑑) = ∫X 𝑓(𝑥) min{𝑐(𝑥), 𝜙(𝑑(𝑥, M))} 𝑑𝑥

離散化損失：L̂(M; S, 𝒘, 𝒄) = Σᵢ₌₁ᵐ 𝑤ᵢ min{𝑐(𝑥ᵢ), 𝜙(𝑑(𝑥ᵢ, M))}

3. 已知參數下的近似解

NP-hardness：連續語意快取問題為 NP-hard（Lemma 3.1），是離散設定的嚴格泛化。若 X 有限且 𝑓 離散，精確還原 [19] 的設定。

連續到離散的近似：在 Lipschitz 連續性假設下，Lemma 3.2 證明連續目標可被離散對應項良好近似，誤差上限為 𝐿𝑔𝜖（隨覆蓋半徑線性縮放）。基於此，問題化約為 S 上的有限最佳化。

Reverse Greedy 演算法：從完整候選集 S 開始，逐次移除對損失貢獻最小的項目，直至剩 𝑘 個。離散化損失函數是超模（supermodular）且非遞增的。Theorem 3.3：Reverse Greedy 的解 M 滿足 L(M) − 𝛼·L(M*) ≤ [L̂(M) − 𝛼·L̂(M*)] + (1+𝛼)𝐿𝑔𝜖，其中 𝛼 為超模曲率決定的近似比。

4. 未知參數下的離線學習

當成本函數 𝑐(𝑥) 與密度 𝑓 未知且須從離線資料集 {(Mₜ, 𝑥ₜ, 𝐶ₜ)}ⁿₜ₌₁ 學習時，面臨兩重挑戰：(i) 在連續域上估計 𝑐(𝑥)；(ii) 將估計不確定性納入快取最佳化。

CUCB-SC-Cont 演算法（Algorithm 2）：

  1. 在觀測嵌入上構建 𝜖-net S。
  2. 以經驗頻率估計各 Voronoi 區域權重 𝒘̂。
  3. 僅使用 LLM 被實際呼叫的查詢子集，以 KRR 擬合成本函數，得到估計值 ĉ(𝑥) 與後驗變異數 𝜎²(𝑥)。
  4. 構造悲觀成本上界 𝑐̄(𝑥) = ĉ(𝑥) + Δ(𝑥)，其中 Δ(𝑥) 為信心半徑（含 KRR 後驗標準差項）。
  5. 以 (S, 𝒘̂, 𝒄̄) 調用 Reverse Greedy 計算近似最優快取。

Theorem 4.1（次優性 Gap 界）：以 ≥1−𝛿 機率，次優性 gap 上界三項分解：(i) 到達估計誤差 O(√(𝑚/𝑛))——與離散 [19] 一致；(ii) 成本估計誤差 O(𝑛^(−1/(2𝑝)))——非參數代價，比離散 O(𝑛^(−1/2)) 慢；(iii) 離散化誤差 O(𝑚^(−1/𝑑ₑ))——連續設定獨有。當查詢空間有限（𝜖=0, 𝑚=|Q|），界退化為離散 CUCB-SC 的 O(𝑛^(−1/2))——本結果是嚴格泛化。

最優半徑 𝜖* = O(𝑛^(−1/(2𝑑ₑ+𝑝))) 平衡離散化與估計誤差。框架可延伸至 Matérn、Laplacian 等核（僅需更換距離-誤差公式）。
