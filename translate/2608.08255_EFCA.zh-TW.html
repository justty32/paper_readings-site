論文／訪談原始來源

EFCA：環境回饋的多時間尺度信用歸因

摘要

長 horizon agent 的成功／失敗常在最後才出現。EFCA 從環境互動直接取得短期本步效果與中期歷史停滯，並重加權既有 stepwise return；不需額外 critic。作者在 ALFWorld、WebShop 報告較強的 success 與 task-quality 表現。

1–2. 問題

只把 terminal reward 折扣回傳，會把成功軌跡的多餘步也獎勵，並處罰失敗軌跡中局部有效的步。既有 learned reward／value model 可補密集訊號，但又需要針對環境訓練，並可能偏離真實動態。本文改用環境本來就回傳的文字、有效性與狀態變化。

3. 方法

原始 step return 是從 t 到終點的折扣獎勵和。EFCA 不替換它。短期 credit 以標準化 feedback 比對 P、N：負 pattern 優先給 -1，正 pattern 給 +1，其餘 0。中期 credit 觀察長 K window：K 步全負則 -1；已滿且沒有正回饋則 -η；否則 0。兩者合成 C=αc_fb+βc_hist。

最後 w=clip(1+λC,wmin,wmax)，將原回報乘以 w。正 process evidence 會加強原訊號，無效／重複行為會壓低它；clipping 防止極端更新。WebShop 的 pattern 需另依搜尋、選品、選項和購買等回饋定義，故它不是不需環境工程的通用演算法。

4. 實驗設定與結果

ALFWorld 有 3,827 個任務、六類家務，WebShop 有逾 110 萬商品與 12k 指令；每環境三 seed。backbone 是 Qwen2.5-1.5B／7B，ReAct action protocol，group size 8。基線包括 PPO、GRPO、GiGPO、GraphGPO、HGPO，部分數字由各基線原論文沿用。

EFCA 在 ALFWorld 取得 95.31（1.5B）與 96.03（7B），兩者為該表最高總分；WebShop Task Score 89.81、89.06 亦最高。GraphGPO 的 WebShop success rate 略高於 EFCA，作者因而主張 EFCA 特別改善「買到符合條件的品項」，不可簡化成所有 success 指標均勝。

消融（1.5B ALFWorld）去 history 為 90.95，去短期 feedback 為 91.40，完整為 95.31。重加權初期平均低於或接近 1，訓練後約 1.4–1.5；reweighted return 方差更大，作者將此解讀為步驟被區分得更開，而非不穩定。這仍是作者解釋，沒有獨立因果檢驗。

5–6. 限制與結論

訊號品質完全取決於環境回饋與 pattern 表；模糊訊息歸零，錯誤表面訊號可能造成錯誤 credit。本文沒有新 grouping optimizer，也不聲稱取代長期 outcome；較恰當的定位是可插入 critic-free stepwise RL 的保守 return 校正。原文 HTML 404，以上根據 arXiv PDF v1 擷取。
