4. 實驗

4.1 實驗設置

三個長時程基準：(1) ALFWorld——文字式具身家居環境，含導航、搜尋、取放、清潔/加熱/冷卻等六類任務，看不見分集 134 題；(2) WebShop——模擬電商網站，代理需導航網頁、篩選屬性、依據購物意圖做購買決策，100 題，回報 SR 與 Score；(3) TextCraft——Minecraft 風文字合成環境，需遞迴建構中間材料後產出目標物品，100 題，測試組合推理與長鏈依賴處理。

對比基線：ReAct、Reflexion、ADaPT、StateAct、ExpeL、WALL-E 2.0、AWM。所有方法使用相同骨幹 gpt-4o-2024-11-20（temperature=0）。需經驗蒸餾的方法在 50 題不相交訓練集上收集軌跡以建立反思或記憶。

消融設置：ALFWorld 134 題全量評估兩模組整體貢獻；另以固定 50 題子集做細粒度設計消融。

4.2 主要結果

本文方法在所有基準上持續超越最強基線：ALFWorld SR 94.78%（AWM 88.81%，+5.97pp）；WebShop SR 51%（Reflexion 35%，+16pp）、Score 0.7132（WALL-E 2.0 0.5998，+0.1134）；TextCraft SR 94%（ExpeL 88%，+6pp）。更重要的是，先前最強基線因領域而異（ALFWorld: AWM，WebShop: Reflexion/Score: WALL-E 2.0，TextCraft: ExpeL），說明既有方法僅處理長時程挑戰的一部分。本文增益在具身操作、網路決策、組合規劃上均穩定，證明聯合建模進展校準與可行性校準能同時改善最終任務完成率與整體決策品質。

4.3 消融實驗

雙記憶互補性（ALFWorld 全量）：

  • 完整模型：SR 94.78%, IAR 11.81%, ATL 14.60
  • 移除 Feasibility Memory：IAR 升至 26.33%（+14.52pp），SR 降至 85.82%——大量失敗來自需執行前修正的局部無效動作
  • 移除 Progress Memory：IAR 僅 12.98%（可控），但 ATL 升至 20.30（+5.70），SR 降 4.48pp——代理可在保持局部有效的同時失去高效階段推進
  • 完整模型三項指標最佳，證明可行性記憶主要防止局部崩壞、進展記憶主要維持全局完成效率，兩者互補而非冗餘

進展記憶的增益來源（50 題子集）：

  • 無記憶：SR=90, ATL=21.22
  • 標準 RAG（任務級全軌跡檢索）：SR=84, ATL=21.64——比無記憶更差，未對齊當前執行階段的檢索會分散注意力
  • 藍圖+任務級檢索：SR=92, ATL=16.42——加入程序藍圖顯著改善長時程控制
  • 藍圖+錨點級檢索：SR=94, ATL=16.18——檢索僅在對齊當前子目標時才有效

結論：進展記憶的增益來自結構化（將經驗組織為階段感知引導）而非單純儲存更多過往經驗；檢索本身僅在條件於該結構時才有用。

可行性機制比較（50 題子集，固定藍圖+錨點檢索）：

  • 無規則：SR=88, IAR=21.63%, ATL=20.90
  • Prompt Rules（純語言提示）：SR=84, IAR=12.11%, ATL=18.16——IAR 大幅降低但 SR 反最低，單一語言提示不適合同時處理語意推進與嚴格可行性
  • Verifier Rules（可執行 Python）：SR=94, IAR=11.00%, ATL=16.18——最佳 SR+ATL 搭配低 IAR
  • Prompt+Verifier：SR=92, IAR=4.66%（最低），但 SR 與 ATL 反不如純 Verifier——更嚴格的提示級過濾並未改善長時程控制

結論：可行性校準應與語言式進展引導解耦，由分離的符號機制處理。最佳可行性機制並非最低 IAR 者，而是能在攔截無效動作的同時保持進展連續性者。

4.4 環境規則統計

ALFWorld：644 正例/159 負例→候選規則 17→零假陽性 15→最終 6 條（手佔用限制、位置可達性條件）；WebShop：190/50→8→8→2（搜尋頁面合法性、點擊目標可見性）；TextCraft：497/219→7→7→3（合成數量匹配、原料充足性）。最終保留規則皆語意可詮釋。

5. 結論

本文透過展示進展校準與可行性校準最好由分離機制處理，回應長時程代理中的雙對齊挑戰。以神經符號雙記憶框架實例化此洞見：神經 Progress Memory 提供階段感知引導，符號 Feasibility Memory 執行可驗證動作攔截。解耦設計在 ALFWorld/WebShop/TextCraft 上持續改善完成率、減少無效動作與冗餘互動，證明穩定的長時程控制受益於以不同機制匹配不同失敗模式。

限制與未來：與目前神經符號代理類似，框架需要一定量的離線軌跡資料進行記憶建構；在極稀疏獎勵或難以詮釋失敗訊號的環境中，此需求難以滿足，是重要未來方向。
