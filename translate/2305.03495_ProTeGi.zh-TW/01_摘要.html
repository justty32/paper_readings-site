摘要

大型語言模型（LLM）作為通用智能體已展現亮眼表現，但其能力高度依賴人工反覆試錯寫成的 prompt。我們提出一個簡單、非參數化的解法——Prompt Optimization with Textual Gradients（ProTeGi），靈感來自數值梯度下降，可在只假設能存取訓練資料與一個 LLM API 的條件下自動改進 prompt。演算法用一批批（minibatch）資料形成自然語言「梯度」，用以批評當前 prompt，如同數值梯度指出誤差上升的方向。這些文本梯度接著被「傳播」進 prompt——把 prompt 往梯度的相反語意方向編輯。這些梯度下降步驟由 beam search 與 bandit 選臂程序引導，大幅提升演算法效率。在三個基準 NLP 任務與一個新提出的 LLM 越獄（jailbreak）偵測任務上的初步結果顯示，Automatic Prompt Optimization 能勝過既有的 prompt 編輯技術，把初始 prompt 的表現最多拉高 31%——靠的是用資料把模糊的任務描述改寫成更精確的標註指示。

1. 引言

以網路規模文本訓練出的 LLM，近來在各式 NLP 任務上展現前所未見的能力。這些 LLM 靠 prompt 輸入來遵循人類指令，而用自然語言撰寫 prompt 仍是需要大量人力與專業知識的手工試錯過程。

因此，我們需要自動或半自動的程序來協助人類寫出更好的 prompt，藉此減少人力、提升任務表現，並產出可解釋的認知決策流程描述。

既有工作多半靠訓練輔助模型或建立 prompt 的可微表示來處理此問題，但這類做法假設能存取 LLM 內部狀態變數，而實務上多數人只能透過 API 與 LLM 溝通。另一類工作以強化學習或 LLM 回饋對 prompt 做離散操作，但這些演算法同樣可能需要低階存取 LLM、產出難以理解的輸出，或依賴無方向性的蒙地卡羅搜尋。

我們提出 ProTeGi，一個連結上述兩類研究、以有方向的方式對 prompt 做離散改進的通用、非參數化自動 prompt 優化演算法。不同於既有工作，我們藉由在文字型 Socratic 對話中模擬梯度下降步驟——用 LLM 回饋取代微分、用 LLM 編輯取代反向傳播——來克服離散優化的障礙。具體而言，我們用一批批訓練資料在自然語言中產生「梯度」，即當前 prompt 相對於這批資料的缺陷描述，再把當前 prompt 往梯度的相反語意方向編輯。這些步驟構成一個更大 beam search 的擴展環節，並把束候選挑選問題視為最佳臂辨識（best arm identification）問題的一個實例，藉此提升演算法效率。

我們在四個 NLP 任務（含新提出的 LLM 越獄偵測問題）上以多種設定評估此框架，結果顯示所提演算法能將初始 prompt 表現最多拉高 31%，平均以 4–8% 的幅度超越最先進的 prompt 學習基線，同時使用更少的 LLM API 呼叫。我們也展示了優化過程的可解釋性，並探討演算法的不足之處。
