論文／訪談原始來源

Mendel Gödel Machine：以比較演化遞迴自我改進的程式 Agent

摘要與動機

能改自身原始碼的 coding agent 已有成果，但慣例是從一條最近的失敗軌跡產生下一次改寫。作者指出：agent archive 其實保存了各版本在多任務上的行為，卻常只被用來抽樣 parent。MGM 要把那些比較訊號帶進「怎麼改」的提示與決策。

方法：三種受控遺傳

clonal mutation 是單一 parent／單一任務軌跡的局部突變。reaction-norm mutation 聚合一個 agent 在多個環境中的成功失敗輪廓，試圖找穩定、基因型層級的問題，而不是把某題失手誤判成通則。cross-lineage hybridization 則選同任務上的另一譜系參考 agent；改寫者比較兩邊軌跡與程式，形成有來源的混合，而非任意拼接。

系統持續擴大 agent、lineage、任務評估與軌跡的 archive。比較資訊用於選 mutation type、參照版本及給 LLM 的修改依據；改完再跑任務，將結果回寫檔案庫。這將單一失敗的局部訊號變成多任務與同題異譜系的反事實線索。

理論與模擬

在加性 fitness landscape 模型裡，作者推導 reaction-norm 與 hybridization 可增加有益訊號、加速收斂，並以受控 surrogate simulation 支持此結論。這個假設很重要：若程式部件高度互相依賴，單項「好基因」未必能安全轉移。

實驗與結論

作者在 SWE-bench 與 Polyglot 比較基線，報告 MGM 在表現、效率與泛化皆有一致改善。論文的核心不是聲稱每次混種一定更好，而是主張擴張中的 archive 應同時是選擇器與診斷器。實作時應把 reference 的版本、資料切分、成本與測試結果一起保存；否則看似比較演化，實際可能是驗證集洩漏或搜尋偏誤。
