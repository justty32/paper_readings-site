論文／訪談原始來源

CoHARL：以強化學習共同演化代理政策與可執行 harness

摘要與第 1–2 節：研究問題

LLM 代理的行為由模型政策和執行 harness 共同決定；後者處理提示、動作解析、工具回饋與 episode 控制。CoHARL 在政策訓練過程中持續修改 harness，並保留多個版本收集軌跡，讓一個共享政策從不同執行介面學習。（摘要與 §1、§2）

第 3 節：共同演化方法

系統維護訓練 harness 池及獨立的歷史 accuracy–cost archive。每次訓練排程器從池中配置版本，針對同一任務與 harness 收集多條 rollout；GRPO 的組內優勢在同一任務–介面組內中心化，只對模型生成 token 計算政策損失，工具觀測作為脈絡。新候選通過檢查後在下一個訓練步驟邊界加入，不改寫已收集的批次。（§3.1–3.2）

獨立 proposer 讀取父版本程式、現行政策的成功與失敗軌跡、歷史取捨及同輪被拒提案，提出 harness 程式修訂。它不得修改訓練框架或政策的動作格式家族。SWE 候選先做契約檢查再進行 pool 試驗；Terminal-Bench 另有 smoke test 和候選驗證。（§3.2）

排程器以任務難度調整的表現、使用次數懲罰及新版本強制試用決定資源分配；其下界式分數是啟發式，不是經校準的信賴區間。Archive 保存歷史非支配的準確率與生成 token 成本組合，供 proposer 參考；它和實際收集訓練軌跡的池不同，舊分數也未必反映現行政策。（§3.2）

作者分析二元回饋下，同組全成功或全失敗會使組內相對優勢為零；提升成功機率可在困難任務上增加差異訊號，但高於一半後該關係反轉。此分析提供直覺，不保證收斂更快；實際 SWE 訓練獎勵含額外過程項與長度懲罰，不能把這個二元公式直接套到所有篩選統計。（§3.3–3.4）

SWE 正式評估要求所有 fail-to-pass 測試通過、pass-to-pass 測試持續通過；訓練更新使用經處理的獎勵，篩選則讀取隨 harness 版本而異的 test_score。三者不應混為同一指標。（§3.4、附錄 C.1）

第 4.1–4.2 節：實驗結果

作者以 Qwen3.5-35B-A3B、rank-32 LoRA 訓練，SWE-rebench 使用 2026 年前任務訓練、110 個較晚任務評估；主結果每題三次嘗試，報平均解題率。作者自報如下：（§4.1–4.2，表 1）

設定 SWE-rebench 解題率
初始政策＋SWE-mini 17.3%
只搜尋 harness（作者重現 Meta-Harness） 21.2%
固定 harness 的 Plain GRPO 20.3%
CoHARL 27.6%

作者將 SWE 訓練出的政策與 harness 不再適應直接測 500 題 SWE-bench Verified、每題一次：CoHARL 為 59.8%，只搜尋 harness 為 52.0%，固定 harness RL 為 49.8%。引用的封閉模型發表數字採不同 harness 與評估設定，不能視為嚴格控制的模型比較。（§4.2，表 2）

Terminal-Bench 2.0 使用另行訓練的終端代理，作者自報 CoHARL 36.8%、harness-only 33.7%。本組結果先按每題已返回的 episode 平均、再跨題平均，無返回則記零；引用的 Flat GRPO 是另一個 89 題 avg@5 協定。這不是 SWE 模型零樣本轉移，也不是所有基線完全同協定。（§4.2，表 3、附錄 C.1）

第 4.3 節：消融與成本

另一組獨立的 30 步 SWE 訓練控制中，各方法用相同訓練預算、110 題每題一次評估。作者報完整 CoHARL 解出 28／110，先搜尋一次再 RL 為 25／110，訓練中交替更新單一 harness 為 21／110。搜尋次數並非各組完全相同，候選驗證及 proposer 成本亦可能不同；這些是本地控制，並非對其他共演化框架的完整重現或總算力等量比較。（§4.3，表 4、附錄 C.1、附錄 F）

150 步 SWE 主實驗的訓練 episode 數與 RL-only 差不到 1%；作者估計 harness 驗證另增約 10% 開銷，proposer 推論另計。相近 episode 數不代表總計算相同，也不能把此估計直接套用到 30 步消融。（附錄 C.1）

隱藏測試與限制

作者在種子 harness 禁止注入隱藏測試，並對試圖恢復存取的提案設稽核門檻。主執行中檢查五個被接納 harness 的程式未發現隱藏測試存取；另一次固定權重搜尋的六個提案均因試圖恢復存取被拒。作者明確指出，這不排除其他資訊通道，也不能將六例視為一般攻擊成功率；訓練仍使用純量任務獎勵。（附錄 B）

作者指出實驗為單一政策模型設定的單次訓練，無信賴區間及完整總算力比較；反覆驗證可能使 harness 選擇過擬合，政策變動也可能令 archive 分數過時。跨資料集評估仍可能受預訓練污染，單一 harness 較差的成因亦未被此實驗證明。（附錄 E）
