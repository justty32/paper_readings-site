論文／訪談原始來源

FluxDisco: Symbolic Regression for Stoichiometric Dynamical Systems via Monte Carlo Graph Search

摘要與第 1 節：問題

動態 symbolic regression 要從有雜訊的 trajectory 找回 governing ODE。一般黑箱模型能預測，卻難解釋；通用 symbolic regression 雖輸出方程式，也可能違反守恆或已知反應結構。對 flux-based system，若已知 stoichiometry S，狀態變化可寫成 dx/dt=S v(x)。與其分別搜尋每條 ODE，FluxDisco 固定 S，聯合搜尋 flux vector v(x)，讓候選式從構造上遵守物理結構並縮小搜尋空間。

作者把方程式發現視為 MDP。state 是一組未完成或完成的 flux expressions，action 是套用 grammar rule，terminal state 是可評估的完整方程組，reward 同時考慮 trajectory fit 與 expression parsimony。因不同 grammar action 可能生成數學上相同的 expression，樹搜尋會重複探索；論文因此改用 Monte Carlo Graph Search，合併等價 state 並在圖上共享統計資訊。

第 2 節：搜尋、評分與物理先驗

每個 episode 從空 expression 開始。若目前 node 尚無 child，演算法先做 conditional expansion 與 warm-start rollouts；selection 依 credible interval、目前最佳 reward 與下游 value 選擇路徑；rollout 補完所有 flux；完成後先做 constant folding，把可加或可乘的重複常數正規化，再以預設 stoichiometry 組成 ODE、用 nonlinear least squares 最佳化常數、數值積分 ODE，最後計算 reward 並沿祖先節點 propagation。

與原始 MCGS 偏好平均 reward 不同，FluxDisco 的 selection 也保留 node 曾觀察到的最大 reward，因 equation discovery 的目標是找到一個最佳 functional form，而不是平均表現良好的分支。作者另以 Beta posterior credible interval 取代過度保守的 BKL bound，使龐大搜尋空間較快分出優先順序。

expression depth 上限促使簡潔解，抵達上限時只允許 terminal grammar rule，避免大量 rollout 因未完成而得到無資訊的零 reward。state ID 先經 recursive constant folding 與 term ordering，讓 transposition table 能合併等價式。使用者也可按 flux 把不合物理知識的 grammar rule 機率設為零。reward 直接比較 integrated ODE trajectory 與 observations，雖比 finite differencing 慢，卻避免差分放大雜訊與 smoothing 扭曲動力學。

第 2～3 節：模擬與結果

**作者自報：**模擬涵蓋 SIR、Lotka-Volterra、Brusselator 與 Fairen-Velarde 四類系統，並分成無雜訊、低雜訊與高雜訊條件。比較對象包括無 stoichiometry 的本法 ablation、SPL、SINDy、PySR、ProGED 與 ODEFormer；評估同時看 NMSE、coupled-expression identification、runtime 與 accuracy／runtime 平衡的 efficiency。

**作者自報：**FluxDisco 在所有受測 system 與 noise level 的最大 trajectory reconstruction error 都低於 2%，且各系統的 error 最低；不施加 stoichiometry 的版本明顯變差，支持已知結構確實約束了搜尋。相較之下，其他方法在部分實驗的 error 超過預測資料平均值所對應的 NMSE=100% baseline。

**作者自報：**symbolic evaluation 中，本法除 Fairen-Velarde 外都有高 coupled-term identification accuracy；Fairen-Velarde 對所有方法都未被正確識別。state merging 與排除不合理 grammar rules 在較低計算 budget 時改善 error 與 efficiency，但 budget 增加後差距縮小。代價是 FluxDisco runtime 比替代方法長數個數量級。

第 4～5 節：討論、結論與局限

FluxDisco 顯示，已知 stoichiometry 不只是事後檢查，而能直接改變 symbolic search 的 state space、候選方程與資訊傳播。它從有雜訊資料恢復可解釋且符合指定物理結構的 dynamics，在數值重建與 coupled term 識別上優於通用 baseline。

作者明列三項主要限制。第一，joint flux estimation 很難擴展到高維、複雜 ODE，因同一 graph node 必須同時抽中所有 flux 的正確形式，flux 數量或複雜度提高會使搜尋空間爆炸。第二，stoichiometry 是硬約束，若指定錯誤就會導致錯誤 flux；可改用 identity matrix 放棄 coupling，或未來設計 soft constraint 同時估計 stoichiometry 與 flux。第三，現有設定假設完整觀測，真實物理系統常有 latent state；作者建議結合 latent trajectory reconstruction 或 time-delay embedding。
