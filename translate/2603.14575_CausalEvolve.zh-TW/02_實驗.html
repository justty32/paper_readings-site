4. 實驗

4.1 實驗設定

在四個開放式科學與演算法發現任務上評估：

  • 程式合成：產生符合規範的 Python 程式
  • 演算法設計：發現高效能排序/搜尋演算法變體
  • 數學猜想：探索數學常數的近似公式
  • 程式優化：優化給定程式的執行效率

基線模型：GPT-4 與 Claude 作為底層 LLM。對比：標準演化（僅分數驅動）、隨機搜尋、人工設計的啟發式突變。所有方法使用相同的評估預算（世代數 × 種群大小）。

4.2 主要結果

  • 跨任務一致性超越：CausalEvolve 在所有四個任務上發現的頂級程式變體的效能分數皆優於標準演化最佳結果，且達到相同分數所需的評估次數更少（更高的樣本效率）。
  • 突破效能高原：標準演化在約 60-70% 的總評估預算處達到效能高原後不再改進；CausalEvolve 則持續突破——在實驗終止時仍在發現更高分數的變體。這直接證明因果暫存器有助於防止停滯。
  • 發現新穎解決方案類別：在某些任務中，CausalEvolve 發現了標準演化完全未探索的解決方案拓撲類別（如不同的演算法範式），顯示因果引導並非僅局部微調，而是有能力促成結構性創新。

4.3 消融實驗

  • 移除溯因模組（−Abduction）：僅保留因素識別，驚喜事件不觸發新假設。結果：效能在早期即飽和，與標準演化幾無差異——證明驚喜驅動的因果更新是核心貢獻。
  • 移除因素識別（−FactorID）：僅在驚喜事件發生時進行溯因，沒有初始因果結構。結果：高層結構創新頻率顯著降低，因果假設的品質下降（更多雜訊假設）——證明初始因果先驗對溯因的引導作用。
  • 移除因果引導突變（−GuidedMutation）：因果暫存器仍在維護但不用於指引突變。結果：因果知識累積了但未被使用，效能與標準演化無異——證明因果知識必須嵌入突變操作才能產生效用。
  • 完整 CausalEvolve 在所有消融對比中顯著勝出。

4.4 分析

  • 因果暫存器的內容演化：隨著世代增加，因果暫存器的條目數趨於穩定（~15-25 條），但條目內容持續精煉（合併操作多於新增）。這顯示 CausalEvolve 有效地從「探索新假設」過渡到「深化既有假設」。
  • 驚喜事件分佈：早期世代驚喜事件密集，後期世代驚喜事件稀疏——符合直覺（演化初期更多未知，後期因果模型更準確）。
  • LLM 品質的影響：使用較弱的 LLM（如 GPT-3.5）時，因果假設的品質下降導致效能退化到接近標準演化，但仍優於標準演化（因為即使不完美的因果引導仍提供有用的偏差）。

5. 討論與結論

5.1 主要發現

CausalEvolve 證明了一個簡單而有效的原理：在演化式 agent 中嵌入結構化的因果推理，能夠顯著改善開放式發現的效率與品質。關鍵洞察是：演化歷史中充滿資訊——效能的不連續性（驚喜）——但這些資訊在標準演化框架中被當作噪音忽略。透過溯因推理將驚喜轉化為因果假設，CausalEvolve 為 agent 提供了探索的「方向感」。

5.2 與 ai_core 的對應

CausalEvolve 的因果暫存器直接對應 §3.6 固化引擎中的「演化作為新抽象發現機制」：

  • 因果暫存器 = 技能庫中的結構化先驗（而非單純的技能條目）
  • 溯因推理 = 從軌跡中提取因果結構的固化操作
  • 因素識別 + 驚喜檢測 = 決定何時觸發固化更新的元認知閘門

這與 HASP（將技能固化為可執行函數）和 SkillCAT（因果分水嶺合併）形成互補——CausalEvolve 的因果假設提供「為什麼固化」的解釋層，補充了其他方法的「如何固化」操作層。

5.3 局限與未來工作

  • LLM 依賴：因果推理的品質受底層 LLM 限制；弱模型可能產生誤導性假設。未來可引入假設驗證迴圈（在演化中測試假設預測）。
  • 驚喜閾值：θ 需手動調整；自適應校準（如基於效能分佈的動態閾值）可進一步提升穩健性。
  • 多 agent 擴展：多個演化 agent 之間的因果知識共享（跨 agent 因果暫存器同步）可加速集體發現。
  • 非程式領域：將因果暫存器應用於化學合成、蛋白質設計、材料科學的開放式發現是自然延伸。

CausalEvolve 為開放式演化建立了一條清晰的路徑：不只演化程式，也演化對程式的因果理解。
