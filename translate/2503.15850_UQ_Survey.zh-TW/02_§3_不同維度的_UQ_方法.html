§3 不同維度的 UQ 方法

3.1 輸入不確定性（Input Uncertainty）

輸入不確定性來自 LLM 的模糊或不完整輸入。現有 UQ 方法專注於擾動輸入提示後觀察回應變化：

  • Input Clarification Ensembles [36]：對給定提示生成多種澄清，用互資訊（mutual information）捕捉不同澄清所引發預測間的分歧，以集成方式量化輸入不確定性。
  • ICL-Sample [68]：在 in-context learning 設定下，使用不同 in-context 樣本量化輸入不確定性。
  • SPUQ [29]：透過改寫（paraphrasing）和啞令牌（dummy tokens）等技術擾動輸入，暴露模型敏感度並捕捉不確定性；以 BERTScore 等相似度量測不同擾動下回應的一致性。

整體而言，專門處理輸入不確定性的論文仍相當少。由於歧義在自然語言中普遍且重要，此方向需要更多投入。

3.2 推理不確定性（Reasoning Uncertainty）

推理是基於可用資訊導出結論的過程。LLM 的推理不確定性研究聚焦於分析內部推理過程與用量化引導搜尋：

從推理結構萃不確定性：

  • TopologyUQ [18]：將 LLM 解釋正式萃出並結構化為圖表徵，以圖編輯距離（graph-edit distance）量化推理不確定性，並透過穩定拓撲度量揭示冗餘。
  • Stable-Explanation Confidence [5]：將每個可能模型及其解釋對視為一個測試時分類器，建構反映整體推理信心的後驗答案分佈。
  • CoT-UQ [132]：將 chain-of-thought 推理整合到回應層級 UQ 框架中，利用 LLM 固有的多步推理能力改進不確定性評估。

用不確定性引導推理搜尋：

  • TouT (Tree of Uncertain Thoughts) [80]：延伸 Tree of Thoughts 框架，以蒙地卡羅 Dropout 量化中間推理步驟的不確定性，為重要決策點賦予不確定性分數。
  • UAG (Uncertainty-Aware Adaptive Guidance) [128]：在每步生成時監控下一個 token 的預測機率，偵測到高不確定性時動態回退到更可靠狀態並融入經認證的推理線索。實驗顯示整合不確定性可提升生成回應的精確度。

3.3 參數不確定性（Parameter Uncertainty）

參數不確定性反映模型因訓練資料或參數限制而缺乏足夠知識，可透過額外訓練或適應技術降低：

貝氏低秩適應：

  • BLoB (Bayesian Low-Rank Adaptation by Backpropagation) [115]：將貝氏模型化注入 LoRA adapter，透過參數分佈而非點估計進行不確定性估計，無需全模型集成。
  • BLoRA (Bayesian Low-Rank Adaptation) [121]：類似方向，以貝氏方法結合 LoRA 的參數效率。但這些方法仍伴隨顯著計算成本。

基於微調的方法（更實用）：

  • Supervised Uncertainty Estimation [69]：訓練輔助模型，基於激活模式和 logit 分佈預測 LLM 輸出的信心。
  • UaIT (Uncertainty-aware Instruction Tuning) [70]：修改微調過程，顯式訓練模型在輸出中表達不確定性。
  • SAPLMA [2]：精煉機率校準技術以動態調整模型不確定性估計，確保對不同下游任務的適應性。
  • LoRA Ensembles [4]：以訓練多個輕量 LoRA 適配變體取代全模型集成，是參數不確定性估計的實用替代方案。

§3.4 預測不確定性（Prediction Uncertainty）

大多數現成 UQ 方法聚焦於預測不確定性，因這是最直接估計不確定性的方式。依生成次數與是否使用外部模型分三類。

3.4.1 單輪生成（Single Round Generation）

多數單輪方法利用生成過程中的 logit 或隱藏狀態，效率高：

  • Perplexity（困惑度）：量測機率語言模型對文本序列的預測優劣度。困惑度 = exp(-(1/N)Sum(ln p(wi)))。困惑度越高表示模型機率分佈越分散，不確定性越高 [77,82,76]。

  • 最大 Token Log-Probability：以句子中最不可能的 token 衡量整句的似然度。Max(p) = max_i(-ln p(wi))。數值越高表示整段生成的不確定性越高 [76]。

  • Entropy（熵）：反映模型對輸入的預測分佈廣度。第 i 個 token 的熵為 H_i = -Sum(p_i(w~) log p_i(w~))，取均值或最大值作為最終不確定性 [49,51]。SAR（Shifting Attention to Relevance）[24] 透過將注意力調整到句子中更相關的 token（以 NLI 模型評估語意相似度 R(wi,s,x) = 1-|g(x U s, x U s{wi})| 作為權重）進一步改進熵的效能。

  • Response Improbability（回應不可能性）[26]：計算句子的機率乘積後從 1 減去。MP(s) = 1 - Pi p_i(wi)。若模型對該句子很確定（token 機率乘積高），MP(s) 就會低。

  • P(True) [49]：讓 LLM 自評生成是否為真。P(True) = 1 - p(y1 = "True")，其中 y1 是詢問 LLM「該生成是否正確」時的第一個 token。需執行 LLM 兩次但無需多次生成，故仍歸類為單輪生成。

3.4.2 多輪生成（Multiple Rounds Generation）

透過生成多個預測並分析其一致性、相似度或變異性來估計不確定性。基本假設：若模型有信心，不同取樣下的輸出應穩定。

  • Token 級 Entropy：為同一輸入生成多次回應，計算 token 機率分佈的熵。Predictive Entropy [49] 應用於多回應設定時，透過多次輸出的變異性展現更好的不確定性品質。SAR [24] 同樣可應用於多回應。另有工作 [75] 擴展蒙地卡羅近似，關注自迴歸生成中機率分佈如何跨 token 演變。

  • Conformal Prediction (CP)：提供形式覆蓋保證（分佈無關，適合黑箱與白箱）：

    • 黑箱 CP：API-only LLM [104] 以頻率取樣結合正規化熵與語意相似度定義非一致性分數；ConU [116] 以自洽性不確定性測度對取樣回應分群並選代表回應，建構帶正確性保證的預測集。
    • 白箱 CP：Conformal Language Modeling [92] 將 CP 與自迴歸文本生成整合，動態校準停止規則以確保生成集中至少一個回應在統計上有效。多選 QA [53] 以模型信心分數校準預測集。Level-adaptive CP [11] 根據輸入難度動態調整覆蓋保證，優化預測集大小的同時維持可靠性。

  • 一致性方法（Consistency-Based Methods）：分析多次生成回應間的共識度。Jaccard 相似度 [66] 量測不同生成間的詞彙重疊，Jaccard 值高暗示不確定性低。但僅靠詞彙相似度不足（不同意義可用不同措辭表達、長推理步驟需要詳盡分析），部分方法導入外部模型評估語意相似度。

3.4.3 多輪生成＋外部模型（Multiple Rounds with External Models）

語意不確定性估計方法納入外部模型（NLI、預訓練語言模型）評估生成回應間的語意關係，超越表面相似度：

  • 分佈型 Entropy 方法：

    • Semantic Entropy (SE) [51]：以 NLI 模型判斷生成回應間的蘊涵關係，將其分為意義保留群集，在群集層級計算熵（而非個別回應層級）。
    • Kernel Language Entropy (KLE) [87]：以正半定核函數將回應嵌入語意空間，計算 von Neumann 熵，提供比 SE 更細緻的不確定性測度，考慮細微語意變異。

  • 成對相似度方法：建構回應間的成對語意相似度矩陣，分析其結構性質以估計不確定性。方法如 [66] 使用 NLI 模型對每對生成輸出評分蘊涵與矛盾，構成加權相似度圖。有信心的模型產出語意一致的強共識（高相似度），不一致或歧義的輸出導致矩陣更分散。圖譜度量用以量化：Eccentricity (Ecc) 捕捉變異擴散、Eigenvalue (Eig) 評估全局結構、Degree (Deg) 評估局部一致性。近期工作延伸為有向圖 [15]、多維度 [8] 表徵語意不對稱性或潛在不確定性因子。
