§4 LLM 不確定性的評估

4.1 基準資料集（Benchmark Datasets，Table 3）

  • 閱讀理解：CoQA（對話式 QA）、RACE（通用閱讀理解）、TriviaQA（事實型問題）、CosmosQA（上下文理解）、SQuAD（段落 QA）、HotpotQA（多跳推理）
  • 推理與數學：StrategyQA（多跳推理）、GSM8K（數學問題）、CalibratedMath（評估信心表達的算術）
  • 事實性：TruthfulQA（常識謬誤）、FEVER（宣稱驗證）、HaluEval（幻覺偵測）、FActScore（長文本事實性）
  • 通用知識：MMLU（多學科）、GPQA（物理科學多選）、HellaSwag（常識推理句完成）
  • 一致性與歧義：ParaRel（328 改寫×38 關係的語意一致性）、AmbigQA 與 AmbigInst（固有歧義問題）

專用 UQ 基準：MAQA 專為評估 LLM 的 epistemic 不確定性設計、LM-Polygraph 被採用為綜合不確定性基準、另有專為 Conformal Prediction 方法開發的基準。

4.2 評估指標

UQ 常透過二進制分類框架評估：高不確定性應對應低期望準確性。以正確性函數為回應賦予二進制標籤，用不確定性估計預測該標籤：

  • AUROC（ROC 曲線下面積）：量測不確定性分數分離正誤回應的有效性，值域 0–1，越高越好 [51,69,72,119]
  • AUPRC（精確率-召回率曲線下面積）：量測不確定性分數分離正誤回應 [68]
  • AUARC（準確性-拒絕曲線下面積）：評估不確定性測度輔助選取準確回應的效能，確定該拒絕哪些不確定的問題 [67]

對 NLG 任務，正確性標籤難以取得：常用啟發式模糊匹配（BLEU/ROUGE 與參考輸出比對），但常無法捕捉語意保真度；LLM-as-a-judge 可捕捉連貫性、風格等細微面向，但自帶偏誤與不一致風險。人工註解成本高且規模有限。

除二進制分類框架外，也有針對特定不確定性處理的評估設計（如 [36] 用 AmbigQA 僅評估 aleatoric 成分；[133] 對長篇不確定性估計對比 FActScore）。

§5 UQ 在 LLM 的應用

  • 機器人學：閉迴路規劃器[141]以不確定性故障檢測器連續評估和調整計畫；非參數 UQ 方法[108]使用高效查詢策略；[84] 將行動可行性檢查納入以對齊 LLM 信心與真實世界約束（成功率約 70%→80%）；[88] 動態調整自適應技能選擇的替代路徑門檻；[62] 以 LLM 自評不確定性提升安全和人機協作。

  • 交通：LLM 推論用於橋接交通號誌控制的 sim-to-real 轉移[16,19]，但兩者皆顯示幻覺風險。少數工作研究了使用 LLM 時的不確定性測度[21]——將 VLM 與深度機率程式設計連結，對多模態交通事故預測進行 UQ。

  • 醫療：LLM 和 VLM 可作為診斷參考，但不確定性是生成可靠治療方案的必要維度。白箱設定下 [9] 量化不確定性，發現以多任務和集成方法可有效降低 EHR 中的模型不確定性。然而 [117] 對不同模型規模的醫學 QA 資料集上基準化 UQ 方法的結果顯示，醫學應用的 UQ 挑戰仍嚴峻。

§6 挑戰與未來方向

  • 效率-效能取捨：多取樣方法對萬億參數 LLM 成本過高（每百萬查詢 $12k），但可靠性增益有限（AUROC 改善 ≤0.02）。混合方法以低成本代理（注意力變異[35]、隱狀態分群[87]）預先標記不確定性「熱點」，僅對高風險輸出（如醫學診斷）觸發目標多取樣，有望以 10% 計算成本達到 90% 最大效能。

  • 可解釋性不足：使用者無法區分不確定性來自模糊輸入、知識缺口或解碼隨機性。模組化架構解耦不確定性估計層[38,100]或對 transformer 注意力路徑進行因果追蹤[113]可澄清不確定性來源。

  • 跨模態不確定性：整合視覺、文本與感測器資料時引入模態間信心不對齊——大型視覺語言模型（LVLM）的視覺不確定性為文本的 2.4 倍[136]，導致多模態 QA 中 63% 的錯誤[134]。需統一不確定性嵌入以調和模態信心尺度和諧化，以及對抗跨模態後門攻擊的訓練。

  • 系統層不確定性（agent 與推理）：LLM 作為自主代理或推理引擎部署時，不確定性在多步中傳播與累積——早期步驟錯誤導致級聯失敗，尤其模型表達錯誤信心時。現有 UQ 方法大多只看單輪，缺乏捕捉多步推理鏈或多行動計畫中的不確定性機制。需發展時序感知的不確定性追蹤、結構化記憶或基於模型的規劃、或以圖表徵追溯與修正不確定步驟。

  • UQ 評估難題：二進制分類指標（AUROC/AUARC）不總是適用（NLG 任務難以簡化為二元正確性、自由形式生成具語意變異和歧義）。LLM-as-a-judge 自帶系統性偏差。此外這些指標無法區分「自信地錯」與「伴隨適度不確定性的錯誤回應」，未能捕捉「有意義的」不確定性。

§7 結論

本綜述提供 LLM 不確定性量化的全面概述。首先介紹 UQ 與 LLM 相關的基本概念，強調高風險應用中可靠性的重要；接著提出詳細的不確定性維度分類法（輸入、推理、參數、預測不確定性）；系統性地以該分類法引入現有 UQ 方法，回顧其在不同不確定性類型上的效能；最後點出 LLM UQ 的持續挑戰，為未來研究提供方向。主要目標是促進 UQ 技術與 LLM 開發的整合，激勵 ML 研究者和實務者參與此快速發展領域。
