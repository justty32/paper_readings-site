§1 引言

大型語言模型（LLM，如 GPT-4）在文本生成、推理和決策方面展現卓越能力，推動其在醫療診斷、法律分析和交通系統等高風險領域的採用。然而可靠性仍是關鍵顧慮：LLM 經常產出看似合理但實際錯誤或不一致的輸出——醫學 QA 任務中超過 30% 的答案含有事實錯誤，可能導致從假資訊到致命誤診的風險。不確定性量化（UQ）成為提升 LLM 可靠性的重要機制，透過顯式建模輸出信心讓使用者識別低信心預測以供人工驗證，並緩解如幻覺過度自信等風險（臨床情境中，不確定性感知的 LLM 可將診斷錯誤降低達 41%）。

傳統 UQ 方法在 LLM 上面臨重大障礙：蒙地卡羅 Dropout 對萬億參數模型和自然語言生成（NLG）任務計算成本過高，集成方法在不同解碼策略間難以維持一致性。更重要的是，LLM 引入了傳統 aleatoric/epistemic 二分法無法捕捉的特有不確定性來源——輸入歧義、推理路徑分歧、解碼隨機性。

本文提出一個新穎的分類法，沿兩軸歸類 UQ 方法：(1) 計算效率（單次推論 vs. 基於取樣）；(2) 不確定性維度（輸入、推理、參數、預測）。此框架處理三個既有研究的缺口：(a) 將 LLM 特有的不確定性來源與傳統 ML 的區分解耦；(b) 從不同回應維度來評估方法；(c) 點出研究不足的領域（如推理不確定性）。既有綜述多聚焦幻覺偵測或將傳統 UQ 分類法硬套到 LLM，忽略了提示驅動的輸入不確定性等 LLM 特有挑戰。

§2 前置概念

2.1 LLM 不確定性來源

2.1.1 Aleatoric vs. Epistemic 不確定性：傳統 ML 中，aleatoric 不確定性來自資料雜訊，epistemic 不確定性來自模型對底層資料分佈的知識不足。LLM 中，aleatoric 不確定性主要源於訓練資料中的不一致、偏誤和矛盾資訊，以及自然語言的歧義性（同一提示的不同解讀可引發多種合理回應）。Epistemic 不確定性表現在 LLM 遇到不熟悉主題時，常以幻覺或過度自信但錯誤的陳述呈現，可透過領域微調或檢索增強生成降低。

2.1.2 四維度不確定性：傳統二分法不足以完整捕捉 LLM 的不確定性複雜度，故定義四個維度（每個維度都可能涉及 aleatoric/epistemic 或兩者混合）：

  • 輸入不確定性（本質 aleatoric）：提示模糊或欠指定，即便「完美模型」也無法產出唯一正確答案。例如「這個國家的首都是哪裡」缺乏上下文。

  • 推理不確定性（混合型）：LLM 透過多步推理或檢索導出答案時，每一步的不確定性累積導致整體含糊或錯誤。問題本身模糊時屬 aleatoric，模型無法提供穩健推理時屬 epistemic。

  • 參數不確定性（本質 epistemic）：訓練資料缺口導致模型從未見過相關資訊或學到錯誤表徵。可透過改進模型知識庫降低。貝氏方法、深度集成、不確定性感知訓練可幫助量化和緩解此類不確定性。

  • 預測不確定性（混合型）：不同取樣運行間生成輸出的變異性。例如對「一款新實驗藥物的副作用是什麼」的回答在多次取樣間大幅變化，反映模型既認識到多種可能答案（aleatoric），也因知識不完整而不確定（epistemic）。

2.2 不確定性與信心

2.2.1 古典信心估計：UQ 與信心估計緊密相關但不同。UQ 是模型預測分佈的性質（不可預測程度），信心是模型對特定預測正確性的信念。在 QA 任務中，自迴歸語言模型的信心為生成序列的聯合機率 C(x,s) = p(s|x) = Pi p(si|s<i, x)，其 log 值有時稱為序列似然度。UQ 估計通常為 U(x)，信心估計通常為 C(x,s)。注意許多 NLG 應用沒有「正確答案」的概念（如摘要），此處的「正確」應理解為該應用的黃金標籤。

2.2.2 信心改進的兩維度：(a) 排序效能（ranking performance）——信心量度對正確性的鑑別力，常用 AUROC/AUARC 衡量；(b) 校準（calibration）——縮小信心分數與條件於該信心分數的期望正確性之間的差距，完美校準為 E[f(s|x)|C(x,s)=c]=c，常用 ECE 變體評估。

2.2.3 LLM 信心估計三大方法家族：

  • UQ 方法與信心估計：黑箱設定下以取樣回覆的相似度矩陣推導各生成回應的信心（圖拉普拉斯特徵值）；白箱設定下從輸出 logits 計算信心（正規化序列長度、注意力加權和、NLI 推斷重要度加權）。
  • LLM-as-a-judge：讓模型自評自由形式生成是否正確，再以分類校準方法校準自評。少數方法將自由形式生成轉為選擇題並加「以上皆非」選項以誘出信心。
  • 可訓練信心估計器：可對基底 LLM 做額外訓練（完全或部分微調，使用不同損失）、使用獨立模型在內部或外部表徵上訓練、或僅用提示誘出口語化信心值。也可組合多種信心估計方法取集成效益。

備註：文獻常混用「不確定性」與「信心」兩詞。一般來說模型對輸出空間不確定性高但仍可能對特定輸出表達高信心；反之模型整體不確定性低但可能對特定預測缺乏信心——後者因 NLG 中輸出是從預測分佈隨機取樣而比分類/迴歸中更常見。
