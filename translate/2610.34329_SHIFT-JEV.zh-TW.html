論文／訪談原始來源

SHIFT-JEV：分布轉移下的可靠決策

第 1–3 節：決策模型與監測

輸入狀態和 K 個候選選項，模型輸出各選項機率；選擇性風險是有回答的輸入中錯誤的比例，coverage 是回答比例。LLM-as-Jev 以編號選項及預填答案前綴，用 prefix-free trie 對選項 suffix 評分；溫度用 ID validation 擬合。樹形 attention mask 打包評分；微調使用樹狀交叉熵、KL anchors 和 LoRA。（§3.1–3.2）

模組 A 記錄熵、最大機率、前二名差距、選項數、合法 identifier 機率質量，以及旋轉選項前後分布／答案一致性；旋轉需額外評分，只在 0.6B 用。state-only embedding 的 k-NN 距離供路由與漂移偵測。串流另用 CUSUM、窗口 KS、預測標籤直方圖卡方測試；無轉移模擬校準目標為最多 5% 誤報。（§3.3）

第 3.4 節：棄權保證的條件

Logistic 風險分數由不確定性、格式及一致性預測錯誤；使用 ID 與兩代理轉移的校準資料。第一半擬合分數並提名門檻，第二半以固定次序 Learn-then-Test 檢驗；Clopper–Pearson 單側上界須低於 α，δ=0.1。從嚴至寬遇首個失敗就停，無通過者則全棄權。已知 regime 有各自門檻；未知或警報後使用 ID 與代理轉移門檻中較嚴者。漂移距離參與路由，不放入風險分數。（§3.4、附錄 A）

若同 regime 校準點和新測試點可交換，且風險模型與候選門檻只依第一半決定，該 regime 的母體選擇性風險以至少 1−δ 的機率不超過 α。未知轉移沒有此保證，只報實測違規；不應把保守 fallback 當成未知分布的證明。（附錄 B；最後一句為本檔補註）

第 3.5–4 節：有標記後適應與實驗

新 regime 的漂移與準確率檢定決定嚴重度；新資料加舊資料重播更新 LoRA。錨定參考前一模型，嚴重度升高時 KL 權重下降、舊決策蒸餾權重上升。半程探測若未驗證轉移且勝數不超敗數即停；否則半程及全程候選各須在 80 個新 regime 留出項的配對 sign test 達 p<0.10，且舊 regime 驗證準確率下降不超過 5 points。選合格者中新舊平均準確率最佳者，無合格則回退；無論回退與否，新 regime 加入參考池並認證門檻。單個無益候選的誤接受上界 0.10，兩候選聯合上界 0.20。（§3.5、附錄 B）

ID 為 AG News、SST-2、BoolQ、ARC-Challenge；SciQ／Emotion 是代理校準，測試轉移包含 domain、類別先驗、新類別與候選集合變化，共十種。移除正確選項後每個回答均錯。Qwen3-0.6B／4B 各三 seeds；Phi-4-mini 為 frozen 第二家族。棄權主比較為九個轉移環境 × 三 seeds＝27 tests，項目跨 seed 共用，違規數只作描述。持續適應依序 Banking77、無轉移對照、Twitter-Fin、CLINC；各階段 300 訓練、80 gate、20 buffer validation、160 認證項。（§4、表6）

第 5.1–5.3 節：校準與棄權

Frozen 0.6B 的 ID、Banking77、Twitter-Fin 準確率為 73.3%、18.4%、27.6%；4B 為 91.1%、55.4%、60.2%。微調加溫度的 B3 將九轉移平均 ECE 從 0.289 降到 0.087（0.6B），從 0.182 降到 0.078（4B）；收益來自底層訓練及溫度，監測棄權層不改預測。（§5.2）

α=0.10，同 pooled LTT 下 learned uncertainty B4 的違規數為 5／3，最大機率分數為 15／5，LAC 為 14／9（0.6B／4B，各 27 tests）；LAC 保證的是預測集合邊際覆蓋而非選擇性風險。B5 的 coverage 33.3%／60.1%、實測風險 5.2%／6.2%、違規 4／6。α=0.05 時 B5 多數 run 沒認證門檻，六個 Qwen run 中五個在 ID 全棄權，零違規因此不能單獨當成果。路由影響小；事後對所有輸入使用 ID／代理中較嚴門檻，0.10 目標下違規降為 3／2，但有 coverage 代價，需另驗。（§5.3）

第 5.4–5.5 節：監測與持續學習

滿嚴重度類別先驗轉移，seed 1 的預測標籤卡方偵測 95%／99%，信心及 embedding 偵測 0–1%；新鮮無轉移串流中卡方誤報 6%／10%，超過 5% 校準目標。警報切嚴門檻多數情況減少違規，但 0.6B CLINC 違規串流 20%→38%，coverage 約 14%→5%。（§5.4）

0.6B 四階段最終平均準確率 70.48±0.88%，高於 LwF 68.10% 與 replay 66.67%，三 seeds 均勝各 baseline。測試項跨 seed 共用，因此項目層檢定先平均每項 correctness；三 seeds 的 seed-level 配對檢定不顯著。移除 replay 降 4.81±2.22 points，移除 gate 降 1.23±2.18 points，僅兩 seeds 較好。4B 拒絕全部 Twitter-Fin 更新；80 項上增益 2.5–7.5 points 未達 p<0.10，最終 79.86±1.10%，較 baseline 低 0.42–1.36 points，item-level 差異不顯著。（§5.5）

再認證後 seed 1 的 CLINC coverage 44.5%／67.0%、風險 4.5%／3.5%（0.6B／4B）；Banking77 全棄權，Twitter-Fin coverage 僅 1.2%／7.3%，風險卻 40%／27.3%；0.6B ID 風險為 11.6%。小型校準集仍可能無法支撐有用且安全的回答。（表15；最後一句為本檔補註）

第 6–7 節：限制

三 seeds 與共享測試項限制統計力；class-prior 和 candidate-set 轉移為合成，模型最多 4B、兩家族，4B checkpoint 與底層論文不同。設計曾根據同一 benchmark 的早期實驗修正，較嚴門檻分析為事後；Phi-4-mini 增加訊號後實測風險升高。作者提出更大留出及認證集、其他模型與自然轉移作未來研究，未在本文完成。（§6.2、§7）
