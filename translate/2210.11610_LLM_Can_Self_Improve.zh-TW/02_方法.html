3. 方法

給定預訓練 LLM M 與只有問題的訓練集 D^train = {x_i}，以及少量 few-shot CoT 範例。對 D^train 中每題以取樣溫度 T>0 做多路徑解碼，生成 m 條推理路徑與答案，再用多數投票（self-consistency）選出最一致、信心最高的答案。保留所有導向該答案的推理路徑，施以混合格式的 prompt 與答案增強，並在這些自產的「推理—答案」資料上微調模型。以下詳述各設計。

3.1 生成與過濾多條推理路徑

Self-consistency 對推理任務帶來大幅改進（如 GSM8K 測試集 56.5%→74.4%），而貪婪解碼與多樣解碼之間的落差，說明可用「自選的高信心推理路徑」當訓練資料進一步提升 M 的推理能力。

對每題 x_i 取樣 m 條 CoT 路徑；由於模型是以 Wei et al. 的 CoT 範例提示，沿用同樣以「The answer is」解析答案的方式取得預測答案。以多數投票選出最一致答案 ỹ_i（不必然是正確答案），並把所有最終答案為 ỹ_i 的推理路徑收進自訓練資料 D^self-consistent = {x_i, r̃_i}。

Table 1（範例）要旨：一題餐廳帳單題（開胃菜 $10、四份主菜各 $20、小費 20%）的三條自產 CoT——輸出 1 與輸出 3 都得到 108（推理過程各異但答案一致），輸出 2 算成 96（錯誤推理路徑）。多數投票保留輸出 1 與 3 作自訓練資料。

Fig. 2（信心校準）要旨：橫軸為多數投票答案的信心（導向 ỹ 的路徑數 ÷ 總路徑數 m），縱軸為該信心下 ỹ 的準確率，圓面積與顏色深淺表示該信心區間的題數。由於我們不用任何真值標註來剔除 ỹ_i ≠ y_i 的情形，關鍵在於自產 CoT 路徑大體可靠、錯誤答案不至於傷害自我改進。圖顯示 self-consistency 的預測信心校準良好：信心高的答案較可能正確；而 ỹ 錯誤時通常只有較少路徑支持，因此帶進訓練樣本的噪音很小。

3.2 以混合格式訓練

為避免語言模型過擬合特定 prompt 或答案風格，我們對每條推理路徑造出四種格式混入自訓練資料（Table 2）：

  • 格式 1：輸入＝[CoT 提示範例] + 問題 + 「A:」；輸出＝過濾後的完整 CoT 推理路徑。
  • 格式 2：輸入＝[標準提示範例（與 CoT 範例同題，但拿掉推理）] + 問題 + 「A:」；輸出＝只有直接答案。
  • 格式 3：不給任何範例，輸入尾端接「A: Let's think step by step.」以引導模型自行產生逐步推理；輸出＝完整推理路徑。
  • 格式 4：不給任何範例，輸入＝問題 + 「A:」；輸出＝只有直接答案。

格式 3、4 不附問答範例，目的是讓模型學會在 in-context zero-shot 的情況下自己思考。混合格式的訓練樣本隨後用於微調預訓練模型 M。

3.3 自產問題與提示

本法需要一組訓練問題與少量人寫 CoT 範例。當訓練問題或 CoT 範例數量有限時，可能產不出足夠的自訓練樣本；而從網路蒐集問題又需人力。為進一步降低人力，我們研究自產訓練問題與範例提示。

問題生成：先前的少樣本資料增強工作多針對分類任務且需要每個少樣本範例的真值標籤。我們採用簡單有效的做法：隨機挑選數個既有問題、以隨機順序串接成輸入 prompt，讓模型續寫出新問題；重複此程序取得大量新問題，再用 self-consistency 只保留具高信心答案者，作為自產訓練問題。

提示生成：在沒有人工 prompt 的零樣本設定下，可由模型自行生成 CoT 路徑——依 Kojima et al. 以「A: Let's think step by step.」開頭讓模型續寫推理路徑，再把這些生成的推理路徑當作 few-shot CoT 提示的範例。

4. 實驗設定

任務與資料集（GSM8K、ARC、OpenBookQA、ANLI 用測試集；DROP 用 dev 集，因其測試集標註未公開）：

  • 算術推理：GSM8K 數學題集；DROP 閱讀理解基準（需數值推理），依 Zhou et al. 把 DROP 切成美式足球相關與非相關兩個子集訓練。
  • 常識推理：OpenBookQA；AI2 Reasoning Challenge（ARC），僅用 Challenge 子集（ARC-c）。兩者皆為選擇題。
  • 自然語言推論：Adversarial NLI 的 ANLI-A2 與 ANLI-A3（比 A1 更具挑戰性），句對關係為蘊涵／中性／矛盾。

模型、訓練設定與超參數：沿用先前研究，在一個 540B 參數的自迴歸 Transformer 語言模型上實驗。每題生成 m=32 條推理路徑；因每條路徑會擴成四種格式，最終訓練樣本量最多達 128×|D^train|。除 DROP 外均使用完整訓練集；為減輕訓練負擔，DROP 的足球／非足球分割各抽 5k 例，ANLI-A2 與 A3 各抽 5k 例。每個資料集微調 10k 步，學習率 5e-5，batch size 32。多路徑解碼在預訓練模型上用 T=0.7（依 Wang et al. 建議），自我改進後的模型（LMSI）用 T=1.2。最大解碼步數一律 256。
