摘要

保證語言模型（LM）輸出的正確性與事實性，是一個尚未解決的重大問題。本文提出共形事實性（conformal factuality）框架，透過連結語言建模與共形預測（conformal prediction），為 LM 提供高機率的正確性保證。我們觀察到：LM 輸出的正確性等價於一個不確定性量化問題，其中不確定性集合被定義為該 LM 輸出的蘊涵集合（entailment set）。利用這個對應關係，我們證明語言模型上的共形預測對應於一種回退演算法（back-off algorithm）——透過逐步讓 LM 輸出變得較不具體（並擴大相應的不確定性集合），提供高機率的正確性保證。此方法適用於任何黑箱 LM，且只需極少量的人工標註樣本。我們在閉卷問答（FActScore、Natural Questions）與推理任務（MATH）上評估此方法，顯示可在保留大部分原始輸出子主張的同時，提供 80-90% 的正確性保證。

1 引言

近年 LLM 已展現卓越進展，並愈來愈廣泛地被用於搜尋引擎、聊天機器人等領域。然而，由於容易產生幻覺與非事實內容，其輸出無法被完全信任。這使得 LLM 的事實性與正確性成為重要且活躍的研究領域，既有一些用知識來源接地（grounding）LLM 的方法，也有一些做棄權與委派（abstention and deferral）的方法。

雖然 LM 的事實性與正確性正在改善，但精確的保證仍不可或缺。在醫療、法律、機器人等領域，安全部署 LM 要求輸出以某個已知、使用者指定的機率為正確；但 LLM 的複雜與不透明使精確的效能保證極難提供。

為了對黑箱 LLM 提供這種高機率正確性保證，本文取徑共形預測——一個能對黑箱機器學習系統做不確定性量化、且不需強分佈或建模假設的框架。對任意輸入，此框架能產生保證有**邊際有效覆蓋率（marginally valid coverage）**的共形集合，意即平均而言，這些集合以任何使用者指定機率包含正確答案。

共形預測雖在迴歸與分類任務上大獲成功，但在 LLM 上成效有限，原因有二：需要為整個輸出空間評分而不可行；以及所得的信賴集合太大而無法使用。雖有少數工作在多選題設定或近似方法下應用共形預測於 LLM，但沒有現存方法能對語言模型開放式輸出提供精確的共形保證。本文提出共形集合與 LLM 輸出之間一個新的自然對應關係——這不只解決了上述主要挑戰，也能直接產生具正確性保證的實用 LLM 系統。

本文的核心洞見是：每個可能的 LM 輸出都定義了一個相應的不確定性集合，此集合被定義為「蘊涵該 LM 輸出的所有陳述」所成的集合。在此定義下，正確性與覆蓋率之間存在直接對應：不確定性集合包含一個正確回應，即意味著相應的 LM 輸出依蘊涵關係也必然正確。以蘊涵關係隱式定義共形集合，讓共形預測在語言模型上變得實用——我們從未真正實例化不可數大的不確定性集合，卻能直接對模型輸出獲得有意義且可解讀的保證。

利用 LM 輸出與其相應不確定性集合之間的對應關係，我們展示共形預測如何為確保 LM 輸出正確性定義出一個回退演算法。此演算法透過產生一連串「越來越不具體」的輸出序列、再依標準共形預測技術選出一個高機率正確的具體程度層級，提供高機率的正確性保證。

雖然本方法對任何黑箱 LM 輸出都能提供保證，我們透過對 GPT-4 輸出提供正確性保證來展示其實用性。方法作法是：取 GPT-4 的輸出，用 GPT-4 提示（prompt）反覆移除輸出中最不確定的子主張。在閉卷問答與推理任務上，共形事實性能達成任意目標正確性，並產生同時具備正確性保證（遠高於基礎模型的正確性）與可用性的系統：FActScore 由 30%→80%，Natural Questions 由 78%→93%，MATH 由 75%→95%，同時保留輸出中大部分子主張。

貢獻：(1) 利用蘊涵定義 LM 輸出相應的不確定性集合，建立共形預測與 LM 之間的自然對應；(2) 提供共形事實性的演算法實例——把 LM 輸出拆解為子主張、評分、再依不確定性移除；(3) 以 GPT-4 實例化的共形事實性，展示能在閉卷問答與推理任務上提供高機率正確性保證，同時保留輸出中大部分子主張（程式碼開源於 github.com/tatsu-lab/conformal-factual-lm）。

2 相關工作

LM 事實性：LM 事實性是重大關切與活躍研究主題，本文引用數篇涵蓋幻覺減少/偵測/評估的綜述。一類工作致力提升 LLM 存取知識的能力（如檢索增強），另一類則透過調整訓練方式、集成或修改解碼器來抑制 LLM 捏造事實的傾向。本文屬於後者，與語意不確定性（semantic uncertainty）等方法相似之處在於同為解碼時方法，但目標不同——本文追求的是精確、機率式的正確性保證。本工作也涉及 LLM 不確定性量化文獻，因為必須能辨識並移除不可靠的子主張；本文對 F_t 的實作方法與 SelfCheckGPT 及「直接提示 LM 給出不確定性估計」的作法密切相關——這些是互補工作，本文貢獻是一個元演算法（meta-algorithm），能運用任何不確定性估計器來回傳具共形事實性保證的 LM 輸出。

共形預測：共形預測是一種在不需強分佈或建模假設下，建構具精確邊際覆蓋保證信賴集合的統計技術，已成功應用於深度神經網路等黑箱模型，但應用於語言模型仍有限。語言模型上共形預測有三大類應用：(a) token 層級方法在個別 token 上建構信賴集合，可套用標準共形預測技術，但 token 上的覆蓋保證無法轉換成序列的正確性保證；(b) 多選題化簡方法在受限領域（如問答）縮小 LM 的預測空間，能提供輸出上的覆蓋保證，但只能用於高度受限的 QA 式領域；(c) 近期工作嘗試直接在序列空間上實例化共形不確定性集合，但所有序列組成的空間過大而必須做近似。最關鍵的是，以上方法都回傳難以解讀、難以據以行動的 token/序列集合。相對地，本文的共形事實性方法回傳單一的自然語言序列（隱式代表一個信賴集合），因此可直接用於改進 LM 輸出。與本文最相近的是 Angelopoulos et al. (2023) 給出的、可套用在具階層標籤分類問題上的共形預測演算法——該法可回傳樹狀結構中的一個中間節點，隱式代表由其子樹所有葉節點組成的信賴集合；本文與其相似之處在於也隱式表示共形集合，差異在於集合的建構方式（透過蘊涵）、層級關係的表示（不需枚舉邊）、應用場域（語言模型）與實際的共形保證內容（輸出的正確性，而非風險控制）。
