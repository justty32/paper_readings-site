論文／訪談原始來源

BRICKS-WM：以介面組合動力學建立可重用結構化世界模型

摘要

Model-based RL（MBRL）靠潛在世界模型在連續控制上成績斐然。但主流做法多依賴單體潛在動力學，把環境動力學糾纏成一個耦合過程，嚴重限制重用性：換 agent 就得整個世界從頭重訓，即使環境不變。為此我們提出 BRICKS-WM（Building Reusability via Interface Composition Kinetics for Structured World Models），一個模組化組裝結構化世界模型的框架。基於「物理世界由獨立實體組成」的洞見，我們認為全域動力學可建模成「透過潛在 interface 互動的不同動力學模組」的組合。作為最小實例，我們把潛在狀態空間 factorize 成 actuated Agent 模組與 external Background 模組，由學習出來的潛在 interface 橋接。實證上，BRICKS-WM 從頭訓練時控制效能匹敵強單體 baseline，並能把凍結的 background 動力學跨 agent 重用。

1. 引言

MBRL 把高維感官壓成緊湊潛在狀態，agent 能想像未來掌握複雜控制。但多數潛在世界模型是單體黑箱，潛在狀態糾纏了「可控實體」與「環境物理」等不同功能成分。後果：場景一變，學到的世界動力學就無法重用，研究者被迫整個世界模型從頭重訓——即使底層子系統相同。

本文採不同視角：不把世界模型當單體預測器，而研究結構化世界模型的模組化組裝。可擴展的世界模型不該是黑箱，而是「可組裝成新環境的、不同可重用動力學模組」的組合（類比實體積木）。關鍵技術挑戰不只是學 factorized 表徵/動力學，而是學出interface 支援重組合而不破壞預測一致性的動力學模組。最接近的 COMET 促進分解，但未直接處理「凍結一部分動力學、只重學必要元件」的跨任務重用。

BRICKS-WM 用一個最小但有意義的實例操作化模組性：把世界 factorize 成 Actuated Agent 模組與 External Background 模組。不同於聚焦視覺分割的 object-centric 法，BRICKS-WM 在轉移動力學上強制功能分離。透過約束 background 動力學只依賴 interface、結構上獨立於 agent 具體狀態，background 變成可重用模組——一個 agent 訓練的 background 可凍結給新 agent 在相關設定重用，把遷移問題化約成 protocol matching。貢獻：(1) 模組動力學組裝框架；(2) object-centric 結構不犧牲控制效能（匹敵 DreamerV3、TD-MPC2，首個純像素無真值狀態在 locomotion 做到）;(3) 首次展示模組動力學重用。

2/3. 背景與設定

  • Compositional Reuse 設定：透過模組組合而非單體建模。source 任務與 target 任務共享相似 background 動力學模組（外部物件與地形），但用不同 agent 模組/任務。
  • RSSM 骨幹：維護確定性 recurrent state h_t 與 stochastic latent s_t；標準 RSSM 學單體 s_t，本文修改內部 factorization 以支援模組重用。

4. 方法

  • 4.2 Composable Dynamics via Action-Conditioned Interface：把潛在狀態切成 Agent 與 Background，中間一條學習潛在 interface z^I。
  • interface 作為 protocol regularizer：約束 background 動力學 p(s^bg_t | s^bg_{t-1}, z^I_{t-1}) 只依賴 interface、結構上不依賴 agent → background agent-agnostic。對 interface 加 information bottleneck（KL 正則 ℛ_I、係數 β_I） 過濾 agent-specific 細節、強制標準化互動 protocol。
  • 4.4 Module Reuse via Compositional Transfer：考慮 source agent A 與 target agent A′ 共用同一凍結 background 模組；A′ 只重學 agent-side 元件並透過 identity-residual interface adapter 對齊。

5. 實驗（DMC，純像素、無真值狀態，500K 步）

  • scratch baseline（Table 4）：BRICKS-WM 控制效能匹敵 DreamerV3、TD-MPC2；首個 object-centric 世界模型在 dynamic locomotion 純像素無真值狀態做到。
  • 5.3 模組重用遷移（Table 2/3）：凍結 source background、新 agent 重學。in-domain（Walker Walk ↔ Walker Run）雙向遷移匹敵或勝單體 baseline、初期收斂快（化約成 protocol 對齊）;Walker Walk→Run final return 746±4、Run→Walk 940±9，AUC 也有一致的樣本效率增益。moderate domain shift（Walker Walk background → 形態不同 Hopper Hop）return 超 baseline;大 domain gap 時遷移落後 → 經驗界定重用邊界。
  • interface 正則消融（Fig 5）：β_I=0 高方差不穩（interface 沒過濾 agent 細節、洩漏破壞解耦）;β_I=1.0 過度限制（interface 容量不足編碼高頻物理量，Cheetah Run/Walker Run 等高動態任務退化）；最佳 β_I=0.01。

6. 結論與未來工作

BRICKS-WM 把全域動力學解耦成「透過學習潛在 interface 互動的可重用模組」的組合。最小實例（Agent + Background，background 對 agent agnostic）下，據作者所知是首個從頭訓練就在 locomotion 匹敵強單體 baseline 的 object-centric 世界模型；且能重用凍結 background、把遷移化約成 protocol matching。限制：目前只驗證兩槽 DMC 設定；更豐富的雙向互動、雜亂多物件場景、非重建目標是重要未來方向。未來將用先進視覺表徵擴展到複雜任務，實現細粒度動力學分解與複雜環境的可擴展組裝。
