NeSyA：神經符號自動機

N. Manginas 等（KU Leuven & Leuven.AI;NCSR "Demokritos";Örebro AASS）

摘要

NeSy AI 是整合神經與符號推理的有望方向，但少有為序列/時序問題量身打造的 NeSy 系統。我們指出 符號自動機（symbolic automata）——結合「自動機的時序推理」與「命題邏輯的靜態推理」——是表達時序領域知識的合適形式。聚焦序列分類與標註，我們證明符號自動機可在機率語意下與神經感知整合，形成端到端可微模型。所提混合模型 NeSyA（Neurosymbolic Automata） 在合成 benchmark 上比前作 NeSy 系統更可擴展或更準確，在真實事件辨識任務上比純神經系統泛化更好。（程式碼 github.com/nmanginas/nesya）

1. 引言

序列分類/標註是 AI 普遍任務。純神經（LSTM、Transformer）處理複雜高維輸入表現好，但在泛化、資料效率、可解釋、遵守領域/常識知識上有缺。NeSy 旨在整合神經學習與符號推理以助緩解。近期有多個時序 NeSy 系統，但語意、推理程序、擴展性差異大。

本文指出符號自動機是複雜時序性質的有吸引力的低階表示：異於經典自動機，它支援狀態間的符號轉移（由命題邏輯定義），故結合時序推理（經自動機）與非時序推理（經邏輯轉移）。我們證明符號自動機可高效整合神經感知、擴展到子符號域（圖 1 核心架構）。

NeSyA 四特性（對比既有系統）：[C1] 聚焦時序域、[C2] 機率語意、[C3] 把靜態邏輯推理整合進時序模式、[C4] 基於矩陣與知識編譯（KC）的高效精確推理。

對比：

  • FuzzyA（最接近，把 LTLf 接神經）：差在 [C2]——基於模糊邏輯（Logic Tensor Networks）。本文證明機率語意在預測準確度上顯著優於模糊。
  • Semantic Loss / DeepProbLog：差在 [C1]——非為時序設計 → 面對含時序成分的問題擴展性差很多。
  • DeepStochLog（統一文法）：差在 [C1] 尤其 [C4] → 慢數量級。
  • 神經 + 經典自動機（Umili 等）：差在 [C3]——經典自動機缺符號轉移與非時序推理。
  • De Smet 等（混合離散連續、表達力強）：基於近似推理 → 差在 [C4]（NeSyA 精確）。

貢獻：(1) 提出結合自動機/邏輯/神經網路的機率 NeSy 系統 NeSyA;(2) 高效推理演算法（矩陣式自動機推理 + KC 邏輯推理）;(3) 合成域上比 FuzzyA 大幅提升、比 DeepStochLog 擴展性好數量級；(4) 真實事件辨識上比純神經更準。

2. 背景

（2.1 命題邏輯與軌跡；2.2 符號自動機 SFA;2.3 用知識編譯算公式機率。SFA 確定性 = 每個狀態對任一解釋恰一條出轉移為真。）

3. 方法

3.1 形式化與推理

NeSyA 是 SFA 的 NeSy 擴展：不假設命題解釋軌跡，而假設子符號觀察序列 o_1..o_T。NeSyA = （SFA over 變數， 神經網路）——神經網路從觀察 o_t 算各變數為真的機率向量（橋接 SFA 離散表示與觀察連續表示）。

圖模型（圖 3，類 HMM 但狀態↔觀察箭頭反轉）：q_t 是 SFA 狀態上的離散隨機變數、o_t 是時刻 t 的觀察。定義 α_t(q)＝看完 o_1..o_t 後處於狀態 q 的機率，動態規劃遞迴算（式 2）。更新各狀態機率須先算 SFA 轉移上的命題公式（給神經網路當前輸出）的機率；不天真枚舉每個公式的所有模型，而用 KC 高效算。狀態更新（類 HMM）可化為矩陣運算 → 可平行、GPU 執行。α 可用大小 |Q| 的向量表示。

running example：給第一個觀察 o_1 與神經網路輸出，定義轉移矩陣 M（每項由傳播該轉移的算術電路算得）；轉移矩陣每列和為 1（SFA 確定性的直接後果）。從 α_0（初始態為 1）遞迴算每時刻。序列分類：只看最終時刻、對接受態聚合得序列接受機率；序列標註：關心每時刻的值。

3.2 學習

序列分類任務：NeSyA 給子符號序列、算接受機率，序列級監督訓練。

4. 結果

問題：[Q1] 擴展性（vs DeepStochLog、FuzzyA 同任務執行時間）;[Q2] 準確（vs FuzzyA）;[Q3] 泛化（vs 純神經）。硬體 AMD Threadripper PRO 3955WX / 128GB / RTX A6000。

4.1 合成駕駛

影像序列依時序模式分類（每影像表一組二元符號，真值用 emoji 表示、加高斯噪聲使影像↔符號映射不平凡）。生 3 個模式（不同 SFA，狀態/符號數遞增）；各 100 正 + 100 負軌跡。神經組件＝CNN，無直接符號監督，序列級弱監督。

  • vs DeepStochLog（圖 4）：NeSyA 平均快 2 個數量級（最複雜任務序列長 N：NeSyA 數秒/batch，DeepStochLog 約數百秒，後者實用性受限）;DeepProbLog 更慢（最簡模式單序列：DeepProbLog 數秒 vs NeSyA 極短）。三系統計算/學習設定等價故準確相同（省略）。
  • vs FuzzyA（Table 1）：NeSyA 用機率介接 SFA 與神經表示，更穩健；FuzzyA 準確顯著較低（序列越長越差），擴展性也落後。 → 肯定回答 [Q1][Q2]。

4.2 事件辨識（CAVIAR）

真實影片，辨識成對行人事件（meeting / moving / no-event；聚焦較頻繁的兩事件 + 第三類）。給每時刻兩個 bounding box（非完整影像，簡化神經組件任務）+ 一個「兩人是否接近」特徵。CNN 須把各 box 接地到低階活動符號。三方法：NeSyA、CNN-LSTM、CNN-Transformer。資料小（8 訓練/3 測試序列），用 macro F1。SFA（圖 6）定義 meeting/moving/no-event 間轉移。

  • [Q3] 泛化（Table 2）：納入「高階事件由低階活動構成」的知識（3 態 SFA + 簡單轉移邏輯）助泛化 → NeSyA train-test 差距小（純神經在低資料 regime 差距大）。Transformer 能與 NeSyA 競爭但需多 2.5M 參數（凸顯 NeSyA 用 3 態 SFA 當背景知識的效率）。CAVIAR 資料小、標準差高（各法都有離群 run），結果需保留看待。 → 肯定回答 [Q3]。

5. 未來工作

  • 子符號 RL 約束：NeSyA 可指定需記憶/狀態的複雜時序約束、且更可擴展（許多 RL 約束系統用 LTL，如 shielding）→ 延伸到子符號 RL 域；reward machines（用自動機指定 RL 任務/獎勵）及其 NeSy 擴展可加邏輯轉移。
  • 受約束自迴歸/LLM：Ahmed 等的 pseudo-semantic loss、Zhang 等的 LLM 約束皆假設扁平詞彙；NeSyA 對「輸出結構含多特徵（生成結構化 trace 而非自然語言）」的受約束自迴歸有益。
  • 高階 NeSy 時序語言：自動機低階、難手寫 → 定義人本介面，以 NeSyA 為編譯目標。

6. 結論

NeSyA 在乾淨機率語意下整合神經網路與符號自動機。DeepStochLog、DeepProbLog、FuzzyA 在時序域難達可擴展且準確；NeSyA 則擴展性顯著更好、準確更高。
