3. R-CCAM 架構：橋接專家系統與神經推理

3.1 核心挑戰：從脆斷到適應性

專家系統提供了結構化知識推理框架，但兩項弱點致其衰落：脆斷性（規則集要嘛完全匹配，要嘛徹底失敗，無法優雅處理新案例）與知識工程瓶頸（構建與維護規則庫需要昂貴的人工編碼）。LLM 提供前所未有的生成與推理能力，但部署為自主智能體時面臨自身的脆弱性——推理與執行糾纏、記憶揮發、跨步驟不一致。

SCL 旨在調和這兩種傳統：透過將核心智能體功能模組化為循環，恢復專家系統的結構優勢，同時納入機率推理與動態知識整合。關鍵在於：這一恢復不依賴單一模組作為包攬一切的執行者——Regulation 形塑 Cognition 的可提案範圍，結構上獨立的 Control 模組約束執行過程，Retrieval 提供證據基礎，Memory 跨週期持久化驗證後的結論。

3.2 R-CCAM 迴圈：逐模組對應

3.2.1 Retrieval：從靜態知識庫到動態證據層

專家系統的知識庫是靜態的、事先策劃的、易過時的。SCL 重構為一個動態整合外部來源（API、資料庫、語料庫）的 Retrieval 模組。克服脆斷：每次迴圈迭代刷新證據，使系統適應變化條件與不完整輸入。減少知識工程瓶頸：知識獲取從人工規則編碼轉向管線驅動的攝取與索引，LLM 輔助解析異構資料。與 CLARION 的對比：CLARION 假設相對穩定的知識庫，SCL 強調每輪推理週期中動態、上下文敏感的檢索。

3.2.2 Cognition：從確定性規則到機率推理

專家系統推理引擎以確定性規則鏈推理，SCL 的 Cognition 模組利用 LLM 進行不確定性下的機率推理。克服脆斷：當無規則適用時，系統生成不確定性下的候選推理路徑，探索替代方案並基於約束修正。減少知識工程瓶頸：人類設計者無需預見所有可能條件，只需透過 Metaprompt 定義高層指令，LLM 以機率方式補充推理鏈。與 ACT-R 的對比：ACT-R 提供心理上合理的推理，但未利用 LLM 規模的機率推理；SCL 優先自適應不確定性處理而非人類認知逼真度。

3.2.3 Control：確定性執行治理

SCL 中的 Control 模組透過對回合執行狀態施加的確定性程式碼級規則來約束執行——此角色與 Regulation 不同，Regulation 在 Control 檢查之前已透過軟符號控制形塑 Cognition 的提案。Control 不重新檢查提案是否符合 Regulation 政策；它檢查 Regulation 根本看不到的東西——本回合已執行的調用歷史、累積錯誤數、循環深度。

三項核心功能：(1) 重複與循環控制：記錄每個工具-參數組合；重複執行已執行過的關鍵/條件行動則阻斷提案並終止迴圈；安全的唯讀調用若重複則從緩存返回結果 (2) 錯誤累積控制：跨回合計數行動失敗；單次失敗回饋至下一循環使 Cognition 調整重試；連續失敗超過閾值則終止迴圈 (3) 終止判定：當目標達成、Cognition 返回最終回應且無進一步工具提案、或達到結構化循環邊界時判定終止。與 Soar 的對比：Soar 聚焦於規則調度，而 SCL 的 Control 模組執行更窄、更機械化的功能——作為機率提案者的調度器與斷路器，而非其規則的解釋器。

3.2.4 Memory：從會話綁定狀態到持久審計軌跡

專家系統依賴脆弱的工作記憶存儲推理過程中的短暫事實，常在不同會話間重置，不適合多步驟任務。SCL 將其擴展為結構化外部 Memory，記錄中間狀態、決策軌跡與失敗嘗試。克服脆斷：記憶跨週期持久化事實，實現一致的多步驟推理並減少重複失敗。減少知識工程瓶頸：系統可從累積軌跡中歸納約束與模式。實作結構：Memory 典型為狀態-行動-理由三元組的結構化日誌，Metaprompt 指令確保 Cognition 在每循環中一致查閱這些日誌。與記憶增強方法的對比：TME、A-MEM 外部化存儲但缺少與控制迴圈的緊密整合；SCL 獨特地將 Memory 嵌入式嵌入至循環治理週期中，使持久性與監督不可分割。

3.2.5 Action：分離且可問責的執行

專家系統中推理引擎通常直接觸發輸出，冒著不透明或非預期效果的風險。SCL 明確將行動與推理解耦：Cognition 提案，Control 授權，然後 Action 模組才執行。克服脆斷：推理不確定時執行不崩潰；只有驗證後的行動才被執行。減少知識工程瓶頸：系統構建者無需腳本化每個回應；他們定義安全的執行政策，迴圈確保可追溯性與錯誤時的回滾。與專家系統的對比：專家系統常將推理與輸出緊密耦合，SCL 強制嚴格分離，符合高風險領域對安全與可審計性的現代需求。

3.3 完整 R-CCAM 循環

SCL 可理解為專家系統與神經推理之間的現代橋梁。每個模組對應經典組件但具關鍵調適：Retrieval 將靜態知識庫轉化為動態證據層；Cognition 以機率推理取代確定性規則鏈；Control 提供確定性執行紀律；Action 強制分離與問責；Memory 將工作記憶外部化為可審計日誌。專家系統脆斷且工程成本高昂，SCL 透過模組化設計與循環達致適應性與透明性。其結構復興了專家系統的可治理性與可解釋性，同時拋棄了硬編碼規則的僵化，並繼承了 LLM 跨多樣上下文泛化與靈活應對不完整資訊的能力。
