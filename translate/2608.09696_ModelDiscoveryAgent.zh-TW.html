論文／訪談原始來源

Model Discovery Agent：LLM 輔助的 Bayesian 實驗設計與機制世界模型發現

摘要與 1：問題

要回答介入式「如果做了未曾做過的動作」問題，需機制／因果模型而非曲線擬合；但被動觀測不足以識別機制，實驗又昂貴。MDA 將 LLM 放在提案者位置，Bayesian machinery 負責定量比較、參數識別與實驗選擇，避免由 LLM 單獨相信一個看似合理的公式。

2–3：MDA

每輪 LLM 依現有資料和殘差提出候選結構，系統將其轉成可模擬世界模型。SMC 追蹤候選模型及參數的 posterior；可計算 likelihood 時直接使用，否則以 SBI、particle filter 或 summary statistic 的 synthetic likelihood。候選模型的 predictive inadequacy 會在 posterior predictive check 中顯現，觸發 M-open 的 hypothesis expansion，而非假設真相必在初始模型集。

下一個介入由 value of information 選擇，目標是讓不同機制的預測最可區分，而非只最大化預期反應。新資料同時使某些參數／結構可識別，也讓更好的機制預測剩餘殘差，形成發現與設計互相強化的迴圈。

4：三個 benchmark

ForceBench 由軌跡辨識力律；Yukawa 例子說明短距離資料無法區分近似冪律，VoI 會選長距離 launch。ChemBench 在七維連續條件下發現酵素速率律；VoI 對模型判別，與只選 posterior-mean 最高反應的 exploitation baseline 不同。作者稱在 36 題、兩 seed 中，MDA 約八個實驗到 symbolic accuracy 56%，而先前 LLM-AutoSciLab 到 60 次僅約 42%。

NeuronBench 建六個含新離子機制的 Hodgkin–Huxley mystery neurons；agent 可選 9 種刺激與 3 種 blocker。truth 未被提出時保留 residual 再開池。stochastic extension 的 nested particle methods 很慢，作者學習 1D-CNN summary 以加速，但此處是近似性與計算成本的主要風險。

5：相關工作後即止

原稿於 Related Work 後結束，沒有可翻的獨立結論。從已呈現證據可得的保守讀法是：LLM 適合提出可讀機制，Bayesian posterior 與設計把它們暴露給反駁性實驗；它不是對自由形式科學發現成功率的保證，且所有結果受 proposal、simulation 與 benchmark 介面限制。
