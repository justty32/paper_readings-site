論文／訪談原始來源

Finite Automata Extraction

摘要與導論：問題

可遊玩的神經世界模型通常把環境動態藏在大型網路裡。對遊戲開發者而言，這種表示難以解釋、移植或直接修改，也需要大量資料與運算。本文提出 Finite Automata Extraction，簡稱 FAE，從 gameplay video 學出神經符號世界模型：先把畫面轉成 sprite grid，再以程式合成搜尋每種 sprite 的行為，輸出可讀、可編輯的 Retro Coder 程式。

作者把 FAE 定位在兩類方法之間。相較影片生成式世界模型，它明確表示遊戲規則；相較既有純符號 Game Engine Learning，它利用神經表徵從像素抽取 sprite，又以較小的程式搜尋空間追求更一般的規則。評估使用 Pac-Man 與 River Raid，並以 GameGAN 和 Game Engine Learning 為基準。

系統概觀與表徵抽取

管線先把 gameplay video 切成 RGB 影格，以修改過的 Marionette 自監督模型學習有限 sprite dictionary。每一影格再被編碼為符號 grid，每個 cell 指向一個學到的 sprite；離散 grid 讓碰撞可用鄰接關係處理。

作者為固定背景遊戲加入 background subtraction，使 reconstruction loss 聚焦於動態 sprite，並提高重建項目的權重。作者自報，該權重設為 10。模型訓練後，以 latent grid 的 softmax 權重決定每個 cell 出現哪個 sprite，得到供後續程式搜尋使用的符號序列。

這一步同時是方法的主要風險：若神經 sprite extractor 把同一物體拆成多個 cell、漏掉小物件，或無法穩定表示大小與旋轉，後端程式合成只會忠實擬合錯誤符號，不可能恢復原始畫面的真實規則。

Retro Coder 與 FAE

Retro Coder 是針對二維 sprite 行為設計的 domain-specific language。每個 sprite 各有一份模組化程式，由 condition 與 action 組成。條件可檢查某類實體是否存在、是否與目前實體相鄰，或兩類實體是否相鄰；動作可追蹤某實體、朝固定方向移動、轉成另一 sprite，或移向指定位置。grid 中的鄰接被當成碰撞。

FAE 對人工選定的可學 sprite 逐一搜尋，避免同時合成整個遊戲而使搜尋空間爆炸。對某 sprite 出現的影格，演算法以目前程式預測下一個 grid，計算同真實下一格的 absolute error，再做局部鄰域搜尋：候選程式可以增加或移除 if–then 規則，只在一批連續案例上降低誤差時才接受。作者自報，搜尋批次大小設為 3。最終輸出是每種 sprite 的短規則集合。

評估設計

評估分成前端世界模型與後端程式兩部分。世界模型使用 FID、FVD 與自訂 prediction error 衡量生成序列；程式則以長度與 condition 數量近似一般化程度，規則越少，能套用的狀態通常越廣。

作者測兩種 rollout。Approach 1 每一步都用真實當前影格預測下一格，主要測一步動態；Approach 2 只在起點使用真實影格，之後把模型輸出遞迴餵回，測誤差累積。Pac-Man 使用簡化地圖與單一 ghost，River Raid 則裁掉不參與玩法的背景區域。

主要結果（作者自報）

在 Pac-Man 的一步設定，作者自報 FAE 的 test FID 為 0.28，GameGAN 為 10.46，Game Engine Learning 為 0.39。FAE 學到 Blinky 追逐玩家、吃到 power pellet 後變形，以及 pellet 被吃掉等規則；但無法正確表示 ghost 與 eyes 的隨機行為。小型普通 pellet 也因 sprite extractor 的解析限制而沒有被學到。

在 River Raid 的遞迴設定，作者自報 FAE 的 test FID 為 0.13，GameGAN 為 58.81，Game Engine Learning 為 0.14。FAE 能學到 projectile 向上移動及部分碰撞消失規則，但稀有 boat 沒有足夠樣本；fuel sprite 跨越不同數量的 grid cell，也讓運動規則無法穩定學得。

程式緊湊度是 FAE 最清楚的優勢。作者自報，Pac-Man 中 FAE 平均只有 1.75 個 condition，Game Engine Learning 為 73；River Raid 則是 2.00 對 125.42。另一方面，FAE 包含神經表徵訓練與程式搜尋，耗時遠高於未收斂的符號 baseline。結果因此不是全面勝出：低資料下 GameGAN 未學到非隨機模型，Game Engine Learning 常退化成複製前一影格，FAE 的分數較好或相近，但仍只正確學到部分 sprite 行為。

局限與結論

grid 表徵會在 sprite 位於 cell 邊界時重複幻覺，也不處理旋轉或不同尺寸，會誘發假的 condition。Retro Coder 為每個 sprite 獨立建模，不能產生全域 GameManager 來控制 spawn；DSL 沒有時間概念，也不能表示週期或隨機行為。稀有 sprite 因畫面暴露不足更難學習。

FAE 證明從少量 gameplay video 抽出可讀程式是可行方向，但目前更像受限二維遊戲的原型，而非一般遊戲引擎逆向工具。它的價值是把預測錯誤拆成表徵與規則兩層，並讓部分學得的行為可以被人直接閱讀和修改；要擴展到更複雜世界，必須先改善物件表徵，再擴充能表達全域、時間與隨機機制的 DSL。
