論文／訪談原始來源

FindingDory: A Benchmark to Evaluate Memory in Embodied Agents

摘要與問題（第 1 節）

具身 agent 的長期記憶不能只考「能否從很長的影片找到某一格」。真正的任務還要求模型把跨時段的觀察、物體移動與互動順序整合起來，選定目標後再實際導航。既有長影片問答常可靠關鍵影格或多選猜測過關；既有具身 benchmark 又可能把探索、感知與記憶混在一起，使分數無法指出 agent 究竟忘了什麼。

FindingDory 在 Habitat 的擬真室內場景中，專門測量「回想過往互動並據此行動」。作者自報，benchmark 有六十種可程序化延伸的任務模板，涵蓋空間、互動、屬性、時間、持續時間與多目標記憶。問題可以是回到昨天碰過的物體、找出某物之後立刻互動的下一個物體，或依指定順序重訪多個地點。

Benchmark 設計（第 3 節）

每個 episode 分成經驗收集與互動評估兩階段。前一階段由能讀取模擬器真值的 scripted oracle 在場景內導航、拾取並重新放置物體，建立含影像、姿態與動作的歷史，也讓環境狀態真正改變。後一階段換成受測 agent；它可讀取完整歷史，但必須依自然語言指令找出正確目標並完成導航。這個切分固定了先前經驗，避免把「沒探索到」誤判成「記不得」。

任務模板分別檢查物體與容器、是否互動、互動先後、視覺屬性、房間造訪、相對距離及多目標順序。場景實體由模擬器真值取樣，完成條件用 PDDL predicate 自動驗證，不需人工挑關鍵影格或撰寫主觀答案。難度可藉由增加歷史中的互動與狀態變化程序化擴張。

基線與評估（第 4 節）

基線採階層式架構。高階 agent 讀完整互動影片與指令，挑出一個可作為目標的歷史影格；比較的模型包含 Gemini、GPT、Qwen 與 Gemma，也包含先把影片分塊轉成文字摘要的 memory agent，以及以正確目標影格監督微調的版本。低階 agent 再用 image-goal navigation 或顯式地圖回到該位置。

指標不只看是否到達。高階成功率衡量目標影格是否正確，高階 SPL 同時懲罰沒有選最近的有效目標；低階版本再把導航是否真正到達及路徑效率算進去。另有只檢查距離或語意覆蓋的寬鬆指標，用來區分「認得物體但定位不準」與「根本找錯語意目標」。

主要結果（第 5 節，作者自報）

凍結的前沿 VLM 整體表現偏低。GPT-4o 的成功率最高但只有百分之二十七點三，Gemini-2.0-Flash 為百分之二十五點七，Qwen2.5-VL 與 Gemma-3 落在百分之十三至十六；純文字記憶最差，說明摘要會丟失辨識視覺目標所需的細節。

多目標任務尤其困難。多數 VLM 幾乎無法完成，監督訓練的 Qwen 接近百分之二十，仍遠低於可解上界的百分之九十九。模型常連目標數量都答錯。單目標也不等於容易：VLM 可能找到正確類別，卻無法判斷哪一個有效實體離當前位置最近；放寬距離條件後，大型容器的語意成功率明顯上升，小物體則改善有限。

增加輸入影格並未讓凍結 VLM 穩定變好，密集而未篩選的長脈絡反而可能降低表現；監督微調模型才會從較長影片得到一致收益。階層分解也造成額外落差：高階選中的影格分布與低階導航策略的訓練目標不同，常只看到牆面或容器局部，顯式地圖雖較穩，仍不能消除高階語意目標與低階可達性之間的斷層。

結論與局限（第 6 節、附錄 A）

FindingDory 的價值不在宣稱某個 memory 方法已解題，而是把長期回想、空間定位與實際控制放在同一條可診斷的評估鏈上。結果顯示，長 context 容量本身不是有效記憶；模型還需要事件選擇、跨片段推理，以及能把回想結果交給控制器的介面。

作者明列四項限制。低階控制器的路徑效率會遮蔽真正的記憶能力；收集經驗時的 Magic Grasp 會瞬間搬移物體，動作不自然且視覺變化短暫；互動物體通常比 distractor 更常、更近地出現在畫面，曝光不平衡仍可能提供捷徑；目前評估階段全是導航任務，尚未納入必須依長期記憶完成的操作任務。
