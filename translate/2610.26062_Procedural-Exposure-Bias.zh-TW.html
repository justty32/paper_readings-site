論文／訪談原始來源

技能增強 agent 的程序暴露偏差

第 1–2 節：重複程序與當前適用性

技能描述可重用流程，但整體任務相關不代表每個動作都適合當前狀態。程序暴露偏差（PEB）是指：狀態及動作相關性不變時，模型因技能中相關程序訊號反覆出現而更偏好該動作。本文以受控暴露量測此現象，再比較文字與視覺呈現。（§1–2）

作者自報從成功 ALFWorld 軌跡重建 165 個中間狀態，移除原技能提示。固定歷史、參考動作及候選集合，另添與任務相關、卻不在當前可執行集合的干擾動作。暴露以物件相關名詞的 whole-word 次數操作，設為 0、1、2、4、8；固定插槽用含 target 或不含 target 的等字數程序片語填入。總字數相同不保證模型 token 數相同。（作者自報，§2.1、附錄 A.1.1–A.1.2）

固定候選以 teacher forcing 取得長度正規化 token log-probability，再於集合內 softmax；所得偏好不是自由生成的動作概率。圖1(b)端點差另使用總 token log-probability。target替換降低偏好，一般頻率匹配詞替換影響較小；後者只有128個合格狀態，原始及target替換為165個，彙整值非完全配對。（作者自報，§2.2、附錄 A.1.3–A.1.4）

第 3 節：文字與視覺的證據路徑

文字重複在語言上下文增加相關 token 位置；注意力聚合可讓多個位置共同貢獻，不必每次出現的權重都提高。Visual 將相同文字轉圖，經影像 patch 與原生視覺編碼器再進語言模型，改變重複訊號進入動作預測的路徑。此描述動機不等於已定位全部內部因果機制。（§3；末句為本檔補註，非作者自陳）

第 4–5.1 節：完整 agent 評估

比較 No Skill、Text Skill、Visual Skill。後兩者共用 Qwen3.8-Max 依任務與技能 metadata 所排的技能及程序內容，僅呈現不同。三環境為 ALFWorld、ScienceWorld、WebShop；macro success 對三環境等權平均。WebShop score 與完成任務成功率不同，不能混用；步數要在成功率可比時解讀。（§4–5.1、附錄 A.3）

作者自報 Text→Visual 的 macro success：Qwen3.5-9B 40.70→44.06%、27B 53.06→53.94%、Gemma-4-31B-it 57.24→58.21%、Kimi-K2.5 56.34→58.64%。四者整體較好，不代表所有環境／子任務都較好；例如 Qwen27B WebShop 成功率 23.00→21.50%。作者明說未證實 PEB 降低足以完全解釋整體優勢。（作者自報，§5.1，表1、附錄 A.4）

第 5.2 節：編碼、可及性與動作選擇

為隔離排版，另將文字原字原序轉成簡單等寬 Rasterized 圖，再與 Structural Visual 技能卡比較。作者自報9B的暴露敏感度斜率，Text／Rasterized／Structural Visual 為0.741／0.467／0.552；Gemma為2.657／1.283／1.361。plain圖已減弱效應，支持主要差異來自視覺編碼，不需要結構卡布局；也不是圖片完全免疫PEB。（作者自報，§5.2、附錄 A.5.1）

直接讀詞探針改問最常出現物件，固定回答位置的 target詞序列概率在兩種呈現下均隨暴露上升。因此重複訊號仍可讀出，不能只以資訊全部丟失解釋減弱；但這不是 exact-match accuracy，也未證明相同可及性，不能排除部分訊號退化。（§5.2、附錄 A.5.2）

可執行動作實驗另取64條成功軌跡的185個狀態，競爭動作來自當前 admissible set、與參考不同，以 greedy 自由生成量選擇率。作者自報彙整斜率 Text 0.0091、Visual 0.0026；配對差0.0065，bootstrap 95% CI [0.0011,0.0120]。此趨勢不表示每個狀態都隨暴露單調切換，也不能把競爭動作一概稱為不可執行錯誤。（作者自報，附錄 A.5.3）

第 5.2 節：層讀出與元件介入

各中間層的隱藏表示經最終 norm與head讀出，在中後層暴露相關干擾支持較明顯，Text強於Visual。這是teacher-forced讀出，非各層獨立生成；早層弱不代表資訊不存在，也不直接指出造成差異的計算。（§5.2、附錄 A.5.5）

介入在零暴露run的動作位置，用高暴露run快取的對應元件輸出替換，再測干擾score變化。Qwen兩個規模的MLP patch產生與原暴露效應相反的變化；Gemma則部分同方向恢復。回復比例是平均介入變化除平均原效應，可超出0–100%。結果只描述指定activation transplant的效果，不能歸因為所有架構同一個MLP機制，亦不能把Visual的減弱定位到單一元件。（§5.2、附錄 A.5.6）

第 6–7 節：相關研究與結論

本文承接技能生命週期、上下文重複／統計偏差、跨模態呈現及機制分析，聚焦已供應技能如何變成狀態相關決策。結論是技能表示影響重複程序訊號被當作動作證據的強度，並可延伸至生成及完整互動；不是只要檢索到相關技能便能保證正確使用。（§6–7）

附錄 A.1–A.6：補充口徑及paired rollouts

技能暴露只計供應文件，非全歷史；名詞用whole-word計數，非token數。主Visual為結構卡，原始Text–Visual同時改變編碼及呈現，須以Rasterized控制拆解。附錄另給任務類別成功率／步數、排名prompt及ALFWorld/WebShop卡片示例。（附錄 A.1–A.4、A.6）

paired rollout從同狀態分兩支，強制先執行參考或可執行競爭動作，再在相同呈現及暴露條件下自由greedy續跑。成功、動作不可解析或耗盡狀態預算即停止。步差只算雙支都成功的配對，不描述失敗率。作者自報跨暴露等級彙整的雙成功配對中，Text 86對、競爭支多2.31步（95% CI [1.61,3.21]），Visual 98對、多2.43步（[1.26,3.90]）；這是初始動作後果比較，不能單獨估計暴露對完整agent成績的效果。（作者自報，附錄 A.5.4，表7–8）

控制偏好、直接讀詞、可執行生成及paired續跑各答不同問題，不能將其指標互換，或把相關的整體成績差當成完整中介因果證明（本檔補註，非作者自陳；依據§5.1–5.2、附錄 A.5）。
