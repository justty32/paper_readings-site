5. 評估

評估面向是 agent behaviour、consistency、capabilities（error detection/adaptability）與 safety。每個 backend 在 original dataset 跑 10 次，另在 20 個 systematic perturbations 各跑一次。

5.1 Clean workflow

Metric Llama 2 7B Llama 3.1 8B Qwen2.5 7B
Task success 0.80（8/10） 0.90（9/10） 0.80（8/10）
Baseline RMSE 0.8853 0.8853 0.8853
Mean RMSE 0.8856 0.8839 0.8671
Mean workflow uncertainty（原表標籤） 0.7345 0.5506 0.6012

三者 predictive RMSE 接近 baseline，Qwen 平均稍好。相同 prompts 下，Llama 2 較容易 approve；Llama 3.1 與 Qwen 比較常留下 critical notes。

5.2 Perturbed datasets

20 種測試涵蓋 low/high missing values、刪除 rows、刪除 columns、增加 data、增加 columns、feature noise、label noise、distribution shift、fairness 與 counterfactual cases。

Metric Llama 2 7B Llama 3.1 8B Qwen2.5 7B
Error detection 0.45（9/20） 0.65（13/20） 0.90（18/20）
Mean RMSE 1.0655 1.0728 1.0157
Mean workflow uncertainty（原表標籤） 0.7342 0.5573 0.5833

Qwen 最常偵測問題，也更常 retrain 或改策略。Llama models 常漏 severe issues，較少 adaptation。System 對 population/distribution shifts 較敏感，missingness 與 sparsity 不一定被抓到。

然而 clean 與 perturbed 的平均 workflow score 差異很小：Llama 2 為 0.7345／0.7342、Llama 3.1 為 0.5506／0.5573、Qwen 為 0.6012／0.5833。Qwen 的 18/20 error detection 很高，但論文沒有消融證明偵測來自 BN score，而不是 Reviewing Agent 直接檢查資料與模型輸出。

Appendix 定義 severity indicators：relative row／column change、missingness change、standardized target-mean shift、zero-or-missing sparsity、population stability index，以及 correlation matrices 差的 L2 norm。Target 是 number of claims。

5.3 證據分母與資料缺口

Task-success 分母只有每 backend 10 runs，error-detection 分母為 20 perturbations。論文沒有命名 original actuarial dataset，也未報 rows、features、train/test split 或 calibration-validation split；因此讀者可知道 perturbation 類型與結果分母，卻無法僅由論文重建 base data 或 f_cal。

6. 結論與限制

作者把 BN 定位為 runtime uncertainty-propagation monitor，不是 correctness proof。Framework 能重現單一 actuarial baseline RMSE，也顯示相同 agent topology 在不同 small open models 上有不同 error detection、adaptation 與 confidence behaviour。

作者明列的結構限制是：BN 為 DAG，沒有 sequence、priority、revision loops 或 temporal behaviour；intrinsic/extrinsic uncertainty 尚未充分分解，未來可加入 symptom layers 與 dynamic BN。

另有幾項由報告證據直接可見的限制。Calibration 關鍵細節缺失；DAG/CPT 是設計假設而非由 outcomes 學出；原表的 uncertainty 數值在正文也被稱 certainty/confidence，方向不一致；clean／perturbed 平均 score 幾乎重疊，且沒有消融把 BN monitor 的偵測貢獻和 Reviewer 分開；單一 actuarial prototype、三個 7B/8B models、10 clean runs 與 20 perturbations 無法支持跨領域部署；monitor 未定義 action thresholds、false alarms、selective risk 或 human-review workload。它目前較像可解釋的 uncertainty dashboard，而非已完成校準與閉迴路控制的 production safety mechanism。
