摘要

本文研究 LLM multi-agent systems 如何支援 actuarial risk modelling，焦點是不確定性量化。保險是高風險 decision-support setting；不可靠輸出可能導致錯誤風險估計、不公平定價與法規違反。

作者提出由 Central Hub 協調資料準備、建模、審查與解釋 agents 的 framework，並結合 token-level log probabilities 與 Bayesian network，傳播 agents 之間的依賴不確定性。Logprob 不直接當 correctness 或 task-success probability；先做 length-normalised summary，再轉成 calibrated task-level confidence，才作 BN evidence。實驗顯示 framework 能重現 actuarial baseline performance，並提供 workflow stability 與 runtime uncertainty propagation 的資訊。

1. 引言

保險公司依預測未來 claims 決定 premiums、profitability 與 solvency。Actuarial workflow 包括 data preparation、model development、validation、interpretation，仍需大量人工。

LLM agents 可協助自動化，卻引入 hallucination、run-to-run variability 與 black-box 問題。錯誤若由一個 agent 傳入後續 stage，可能造成難以察覺的錯估與偏誤。既有 evaluation 常看單一 task accuracy 或 tool usage，較少表示 multi-step dependencies 如何累積風險。

本文的 runtime monitor 同時使用 explainability／fairness guardrails，與以 logprobs + BN 建立的 workflow-level uncertainty graph。目標是指出不安全 state 與可能需要人工複核的位置，而非只替每個 agent 各自打一個分數。

2. 背景

2.1 Multi-agent systems

MAS 將複雜任務拆給 specialised agents，可能改善能力與 robustness；但 LLM 並非天生為 collaboration 訓練，prompt sensitivity、hallucination 與不一致仍會跨 agent 存在。動態互動也使單一 task metric 無法完整描述 behaviour、capability、reliability、safety 與 alignment。

2.2 Uncertainty quantification

Autoregressive model 的 predictive distribution 可提供 token-level logprob。這是 model-internal confidence-related signal，不是 correctness probability。Multi-agent workflow 還需區分：

  • Intrinsic uncertainty：某一個 step 自己的 uncertainty。
  • Extrinsic uncertainty：由 earlier decisions 沿 dependency 傳入的 uncertainty。

Monte Carlo 多次生成 reasoning trajectories 可以估傳播，成本高且較難解釋。BN 以 nodes 與 directed edges 顯式表示 variables 和 conditional dependencies，是較結構化的替代方案。
