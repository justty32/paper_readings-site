3. Multi-agent system 設計

Framework 是 centralized star topology。Central Hub 以 message passing 協調四個 agents，沒有 direct agent-to-agent communication：

  • Data Preparation：ingestion、cleaning、encoding。
  • Modelling：建立 predictive models。
  • Reviewing：評估 data preparation、model outputs、performance、consistency 與 modelling decisions。
  • Explanation：internal beliefs、concept alignment 與 fairness guardrails。

Shared memory 保存前序 outputs 與 metadata。Reviewer 發現問題時，Hub 可要求 revision 或終止。每個 agent task 再拆成 planning、code generation、evaluation、explanation 等 layers，減少單一 prompt 複雜度。

Explanation Agent 使用 TCAV 做 concept alignment，並比較 age、population density 等敏感群組的 predicted／observed outcomes。Backends 是可在 local machine 快速執行的 Llama 2 7B、Llama 3.1 8B、Qwen2.5 7B。

4. 不確定性量化

4.1 從 token logprob 到 task confidence

輸出序列 y=(z_1,...,z_L) 的機率分解為：

p_θ(y|x) = Π_t p_θ(z_t | z_<t, x)

取 log 後變成各 token logprob 的總和。因長輸出天然累積更多負 logprob，作者使用平均值：

s_i = (1/L_i) Σ_t log p_θ(z_t | z_<t, x)

並轉成 bounded feature：

q_i = exp(s_i)

這只是模型對已生成 token sequence 的平均 likelihood。流暢卻錯誤的文字仍可有高 q_i，所以不能寫成 P(correct)=q_i。

論文另定義 calibration：

P(X_i=success | q_i) = f_cal(q_i)

X_i 表示 agent i 是否成功完成 task，f_cal 應由 validation runs 估計，產生的 calibrated value 再成為 BN probabilistic evidence。

原文未交代 f_cal 的形式、validation sample count、資料切分、success labels，也沒有 Brier score、ECE 或 reliability curve。故下文所稱 task confidence 是 framework 中的估計量，不是已被論文充分驗證的 empirical correctness probability。

4.2 Bayesian networks

每個 BN node X_i 是 workflow task success/failure，edge 是 direct conditional dependency。Joint distribution 分解為：

P(X_1,...,X_n) = Π_i P(X_i | Pa(X_i))

沒有 parents 的 nodes 使用 calibrated confidence 作初始 prior；dependent nodes 的 confidence 參與 CPT。論文例子中，WorkflowOK 的三個 parents 採 AND gate：只有全部為 true 時，WorkflowOK=true 才取 0.99 prior 或 evidence 更新後 posterior。

這是 execution trace 的抽象，不是完整 agent control logic。BN 不表示 direct parents 之外的 temporal ordering、task priority、repeated execution、feedback loops 或 iterative revisions。若 agent 要求 revision，只把 final accepted stage output 當 evidence，使 graph 保持 acyclic、易解釋。作者將 dynamic BN 與 influence diagram 留給未來工作。

4.3 Inference 與 runtime monitor

Agents 把 uncertainty measurements 寫入 metadata，Hub 抽取後更新 BN evidence 與 posteriors。Graph 可顯示 individual nodes 及 overall workflow 的 confidence，找出高 uncertainty 或強烈影響 downstream 的 node。

溫度 scenarios 的 P(WorkflowOK) 是：全部 agents T=0.2 時 87.1%；data/model 0.2、review/explanation 0.7 時 69.0%；全部 0.7 時 59.2%；其中一個 agent 提高至 1.2 時 42.8%。例圖中多數 stage 約 80%，組合後 final workflow 約 55%。

這些數字顯示 BN 依預設 dependency 與 evidence 做概率傳播。它們尚不能直接解讀為「重複 100 次會有 55 次正確」，因論文沒有展示 task-level calibration validity。

Monitor 可以協助 Reviewer／Hub revision、termination 或 human review，也可把新 run 與 clean-run distribution 比較，將 large deviation 作 warning。作者只把 conformal prediction 描述為可採用的後續方法；未定義 posterior threshold、automatic action、review budget 或 false-alarm cost。
