摘要

大型語言模型（LLM）在語言理解與互動式決策任務上表現亮眼，但其推理（如 chain-of-thought prompting）與行動（如行動計畫生成）能力此前主要被當成獨立課題研究。本文探索用 LLM 以交錯（interleaved）方式同時生成推理軌跡（reasoning traces）與任務特定行動，使兩者產生更大協同：推理軌跡幫助模型歸納、追蹤、更新行動計畫並處理例外；行動則讓模型得以介接知識庫或環境等外部來源、蒐集額外資訊。我們把此方法命名為 ReAct，應用於多樣的語言與決策任務並展示其超越最先進基線的效果，同時提升人類可解釋性與可信度。具體而言：在問答（HotpotQA）與事實查核（Fever）上，ReAct 透過與一個簡單的 Wikipedia API 互動，克服了 chain-of-thought 推理中普遍的幻覺（hallucination）與錯誤傳播問題，生成比無推理軌跡基線更可解釋的類人任務解決軌跡；在兩個互動式決策 benchmark（ALFWorld 與 WebShop）上，ReAct 僅憑一到兩個 in-context 範例，就以絕對 34% 與 10% 的成功率優勢勝過模仿學習與強化學習方法。

1 引言

人類智能的獨特之處在於能將任務導向的行動與語言推理（verbal reasoning，或稱內在語言 inner speech）無縫結合——這被認為在自我調節、策略制定與維持工作記憶中扮演要角。以下廚為例：任兩個具體行動之間，我們會用語言推理來追蹤進度（「都切好了，該燒水了」）、處理例外或依情境調整計畫（「沒鹽，改用醬油和胡椒」）、意識到需要外部資訊（「麵團怎麼揉？上網查」）；也會採取行動（翻食譜、開冰箱、查食材）來支撐推理、回答問題。這種「行動」與「推理」的緊密協同讓人類能快速學習新任務，在未見情境或資訊不確定下仍能穩健決策。

近期成果暗示了在自主系統中結合語言推理與互動決策的可能。一方面，適當 prompt 的 LLM 展現出逐步推理求解算術、常識、符號推理問題的湧現能力（CoT；Wei et al., 2022）；但這種「chain-of-thought」推理是靜態黑箱——模型只用自身內部表徵生成思路、不與外部世界接地（not grounded in the external world），限制了反應式推理與知識更新的能力，導致事實幻覺與推理過程中的錯誤傳播。另一方面，已有工作用預訓練 LM 在互動環境中做規劃與行動（SayCan、WebGPT 等），重點是藉語言先驗預測行動，但它們不用 LM 對高階目標做抽象推理、也不維護支撐行動的工作記憶。在簡單具身任務之外，尚無研究探討推理與行動如何協同地結合用於一般任務求解、以及這種結合相比單用推理或單用行動是否帶來系統性增益。

本文提出 ReAct——一個以語言模型結合推理與行動、求解多樣語言推理與決策任務的通用範式：prompt LLM 以交錯方式生成與任務相關的語言推理軌跡和行動，讓模型動態地建立、維持、調整行動的高階計畫（reason to act），同時與外部環境（如 Wikipedia）互動、把新資訊納入推理（act to reason）。

在四個 benchmark 上實證評估：問答（HotpotQA）、事實查核（Fever）、文字遊戲（ALFWorld）、網頁導航（WebShop）。在 HotpotQA 與 Fever 上，可存取 Wikipedia API 的 ReAct 勝過純行動生成模型、與 CoT 相當；整體最佳的是 ReAct 與 CoT 的組合，同時利用內部知識與外部取得的資訊。在 ALFWorld 與 WebShop 上，一到二-shot 的 ReAct prompting 勝過用 10^3–10^5 個任務實例訓練的模仿/強化學習方法，成功率絕對提升 34% 與 10%。除通用性與效能外，推理與行動的結合也提升可解釋性、可信度與可診斷性——人類可輕易區分資訊來自模型內部知識還是外部環境，並檢視推理軌跡以理解行動的決策依據。

主要貢獻：(1) 提出 ReAct，一個基於 prompt 的新範式，在語言模型中協同推理與行動以求解一般任務；(2) 在多樣 benchmark 上做大量實驗，展示 few-shot 設定下 ReAct 對「孤立做推理」或「孤立生成行動」既有方法的優勢；(3) 系統性消融與分析，理解「行動之於推理任務」與「推理之於互動任務」的重要性；(4) 分析 prompting 設定下 ReAct 的局限，並做初步微調實驗，顯示 ReAct 能隨額外訓練資料改進。

2 ReAct：推理 + 行動的協同

考慮代理與環境互動求解任務的一般設定：時刻 t，代理收到觀察 o_t ∈ O，依策略 π(a_t|c_t) 採取行動 a_t ∈ A，其中 c_t = (o_1, a_1, …, o_{t−1}, a_{t−1}, o_t) 為代理的脈絡（context）。當 c_t ↦ a_t 的映射高度隱含、需要大量計算時，學習策略非常困難——如圖 1(1c) 的代理無法生成正確的最終行動完成 QA 任務，因為那需要對整條軌跡脈絡做複雜推理；圖 1(2a) 的代理無法從脈絡理解 sinkbasin 1 沒有 peppershaker 1，於是不斷產生幻覺行動。

ReAct 的想法很簡單：把代理的行動空間擴充為 Â = A ∪ L，其中 L 為語言空間。語言空間中的行動 â_t ∈ L——我們稱之為 thought（思考）或推理軌跡——不影響外部環境、因此沒有觀察回饋；它的作用是對當前脈絡 c_t 推理、組合出有用資訊，並更新脈絡 c_{t+1} = (c_t, â_t) 以支撐後續推理或行動。有用的 thought 型態多樣：分解任務目標並建立行動計畫、注入與任務相關的常識知識、從觀察中抽取重要部分、追蹤進度並轉換行動計畫、處理例外並調整計畫等。

但語言空間 L 無限，在此擴充行動空間中學習很難、需要強語言先驗。本文主要聚焦這一設定：以凍結的 PaLM-540B（附錄 A.1 另有 GPT-3 結果且表現更佳）配 few-shot in-context 範例 prompt，生成領域特定行動與自由形式的語言 thought。每個 in-context 範例是一條人類的行動-思考-環境觀察軌跡。推理為主的任務（圖 1(1)）採 thought 與 action 交替生成，軌跡由多個 thought-action-observation 步組成（密集 thought）；可能涉及大量行動的決策任務（圖 1(2)）則讓語言模型自行決定 thought 與 action 的非同步出現位置（稀疏 thought，只在最相關處出現）。

ReAct 具備幾項獨特性質：A) 直覺易設計——標註者只需在所採行動之上用語言寫下思考，無需特設格式、思考設計或範例挑選；B) 通用且彈性——彈性的 thought 空間與 thought-action 出現格式使其適用於行動空間與推理需求迥異的任務（QA、事實查核、文字遊戲、網頁導航）；C) 高效能且穩健——僅從一到六個範例學習就能對新任務實例強泛化，跨領域一致勝過只推理或只行動的基線，微調後另有額外增益，且效能對 prompt 選擇穩健；D) 與人類對齊、可控——決策與推理過程可解釋，人類能檢視推理與事實正確性，甚至可即時編輯 thought 來控制或矯正代理行為（§4、圖 5）。
