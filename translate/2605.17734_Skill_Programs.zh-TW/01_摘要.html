摘要

賦予 LLM 智能體從過去經驗中提煉出的可複用技能，已成為處理複雜、長程任務的熱門且有效做法。然而這類經驗教訓通常被編碼成文字形式的指引，本質上仍屬建議性質，缺乏明確機制去指定何時、如何介入智能體迴圈。為彌合這道落差，我們提出 HASP（Harnessing LLM Agents with Skill Programs），一個把技能升級成可執行 Program Functions（PF）的新框架。PF 不再只是被動提供建議，而是作為可執行的 guardrail，在容易失敗的狀態下啟動，修改下一步動作或注入修正性脈絡。HASP 高度模組化：可在推論時直接插入智能體迴圈做介入、可在後訓練時提供結構化監督、也可透過演化通過驗證與教師審查的 PF 來自我改進。實證上，HASP 在網頁搜尋、數學推理與程式撰寫任務上，相較訓練無關與訓練相關方法都帶來顯著提升——例如在網頁搜尋推理上，僅靠推論期 PF 就比（multi-loop）ReAct Agent 平均高 25%，後訓練加上受控演化則比 Search-R1 高 30.4%。為更深入理解 HASP，我們的機制分析揭示了 PF 如何觸發與介入、技能如何被內化，以及穩定技能庫演化所需的條件。

1 引言

近期 LLM 進展催生了愈來愈強的智能體，能規劃、與環境互動、有效解決複雜任務。但隨任務分布漂移、回饋跨情節累積，許多智能體失敗會以可辨識的形式反覆出現：多步智能體可能在驗證前就終止、對脆弱的中間結論過早定案、或重複無效動作。核心挑戰是讓智能體能辨識反覆出現的失敗模式、把它們抽象成可複用知識或技能，並據此調整未來行為。

既有系統多半把經驗複用做成文字形式（Reflexion、SKILL0、ExpeL 等）：塞進 prompt、當檢索建議、或間接透過後訓練影響獎勵。這讓技能保有彈性，卻也高度建議性：文字技能能原則上表達該做什麼，卻無法精確表達何時該在策略迴圈中生效、如何具體改變下一步決策，實務上也常被模型忽略。因此，用語言表達的可複用經驗，與能可靠、明確控制智能體行為的可複用經驗之間，仍有落差。

為彌合這道落差，本文提出 HASP，把技能重新框架為可執行的 Program Function（PF）。PF 是一個可複用的「狀態—動作介入函式」：給定當前智能體狀態與候選下一步動作，它決定是否需要介入、若需要則明確修改或增補策略。技能不再是模型可選擇遵守與否的被動指引，而是一個可按需觸發、能直接介入智能體迴圈的可執行物件。HASP 作為外部智能體 harness運作——包在基礎智能體外的一層控制層：每一步，基礎策略提出動作，harness 檢索相關 PF、評估其啟動判準、執行合法的介入，再把修改後的動作或注入的脈絡送回迴圈。

我們從訓練池中的失敗案例初始化 PF，賦予明確的啟動與介入介面，並且只有通過語法、介面與 mock-execution 驗證後才允許進入活躍庫。同一套「狀態—動作介入」介面讓 HASP 高度模組化：推論時可直接插入既有智能體迴圈修正動作或注入脈絡、無需更新模型；有後訓練資源時，每次 PF 執行都提供一筆結構化紀錄（原始動作、PF 修復、觸發的技能、觀察到的效果），HASP 用結構化的 PF 衍生準則替這些事件打分，再用 PF 修正後的軌跡以 SFT、rejection sampling 或 on-policy distillation 訓練學生基礎策略；啟用自我改進時，HASP 會在當前 checkpoint 下重新檢視失敗、把反覆出現的失敗—修復模式摘要成候選 PF、經可執行驗證與教師審查過濾後更新外部技能庫，形成執行、學習、庫成長三者的閉環。

貢獻三項：(1) 把技能表達為可執行的狀態—動作介入函式；(2) 提出 HASP，一個支援可控 PF 觸發與介入、在推論、後訓練、自我演化三種範式下均有效的高度模組化智能體 harness；(3) 在網頁搜尋、數學推理、程式撰寫上均取得對強基線的大幅提升。

2 相關工作

智能體推理與工具使用的後訓練：Search-R1、ReSearch、ZeroSearch、StepSearch、VerlTool 等訓練模型與搜尋/工具環境互動；SimpleRL-reason、Open-Reasoner-Zero、General-Reasoner、ToRL、AceCoder、GRPO-based code training 等用獎勵導向或任務層級目標優化策略。HASP 不預設單一訓練範式，同時支援 SFT、rejection sampling 與 on-policy distillation。

技能增強與自我改進智能體：智能體透過交錯思考與動作（ReAct）、使用外部工具（Toolformer）、擴展成更豐富的多智能體工作流（AutoGen、AgentFlow）解決複雜任務。複用過去經驗或技能已成為改善智能體行為的顯著策略：Reflexion、ExpeL、Voyager 儲存言語教訓、記憶或程序；近期自我改進系統則研究記憶/技能演化，如 MemSkill、SkillRL、EvolveR、SAGE。多數既有方法把經驗複用為 prompt 文字或任務專屬程序。相對地，HASP 把技能表達成在智能體迴圈內觸發的可執行狀態—動作介入函式，提供直接的執行期控制。論文表 1 用「技能/記憶形式、執行期控制、學習訊號、策略訓練、技能演化」五維比較 HASP 與 ExpeL、MemSkill、SKILL0、SkillRL、SAGE、AgentFlow、Search-R1/ReSearch、P-GRPO 等——HASP 是表中唯一在全部五維都拿到「✓（明確支援）」的方法。
