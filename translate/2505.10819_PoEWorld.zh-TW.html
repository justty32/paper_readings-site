論文／訪談原始來源

PoE-World: Compositional World Modeling with Products of Programmatic Experts

第 1 節：問題

神經網路世界模型（如 Dreamer）靈活但需龐大訓練資料；WorldCoder 這類符號世界模型改用 LLM 生成單一 Python 程式描述世界動態，資料效率高，但因對描述一切的大程式做離散組合搜尋，難以擴展到格子世界以外。作者借鏡「心智是互動專家社群」的哲學與認知科學觀點，把學世界模型改成習得數百個各司其職的小程式，機率式聚合預測未來，而非搜尋單一巨型程式，稱為 PoE-World（Product of programmatic Experts）。PoE-World 只模擬像素級物件運動，不模擬像素外觀，假設觀測已由物件偵測器轉成符號形式，專注忠實從示範學世界模型，不做高效探索，也不解規劃本身的計算難題。

第 2 節：背景

序列決策問題可寫成觀測、動作空間、環境動態、獎勵函式的元組，「完整歷史」表述數學上等價於 POMDP。世界建模是經驗風險最小化問題，負對數概似為損失。既有深度學習世界模型樣本效率差、泛化弱（如 Diamond 訓練近 100 小時後仍想像玩家穿牆、瞬移）；既有 LLM 程式碼世界模型效率較高，但尚未在文字與格子世界以外成功。

第 3 節：方法

表示：世界模型定義成 P(o|h) ∝ exp(Σ w_i log P_i(o|h)) 的指數加權乘積，o 是下一觀測、h 是完整歷史，每個 P_i 由一支程式定義、w_i 是其權重，各專家只對世界某個面向表態（如「碰骷髏就死」或「平台上按 LEFT 則 x 速度變 -2」），彼此互不重疊。假設物件為中心的狀態，每個物件的邊界框、速度各存成特徵且條件獨立，才能分別算正規化常數讓乘積可行計算。用完整歷史而非 POMDP 潛狀態，是因為全域潛變數會把所有專家綁在一起，新增一個就要對所有程式做聯合更新；歷史表述讓獨立機制可獨立學習。Atari 複雜到任何可學程式都無法完美模擬，機率模型因此傾向過度近似（如落地物理只給「大致往下」），作者另學一組硬性限制做修正，用析取而非合取組合，因遊戲物理常有不寫實情況（如沿梯子下爬時身體與平台重疊），真實世界則合取較合適。

學習：從示範軌跡循環：合成程式專家、用梯度法做最大概似估計擬合權重、剔除權重低於閾值的專家，軌跡更新就重跑。合成時把小批轉場輸入 LLM prompt，一次只顯示單一物件類型的變化以強制模組化，多個 LLM 模組平行跑，各自處理被動移動、互動效應、生成/刪除等面向。程式解讀成分布時假設屬性條件獨立，程式設定的值轉成單峰分布（加雜訊避免零機率），未設定屬性維持均勻分布。作者發現讓 LLM 寫確定性程式、而非直接寫機率程式效果好得多，推測因一般 Python 在訓練語料中遠比機率程式常見。權重用 L-BFGS 做最大概似估計，因資料與參數量小而優於 Adam、SGD；之後剔除權重過低的程式與只能解釋極少數觀測的限制式。

用途：世界模型可當模擬器加速 RL（模型內預訓練後仍續真環境訓練），也可做前瞻規劃，搜尋最優動作序列。作者結合分層規劃（PoE-World + Planner）：先用低階規劃器（MCTS 變體或貪婪搜尋）對每對「物件接觸」定義的抽象狀態跑通路建出抽象圖，BFS 找最短路徑當高階計畫，低階 agent 依序完成子目標、邊執行邊視情況重規劃。

第 4 節：實驗（作者自報數字）

場景與基線：在 Atari Pong 與 MR 上用 OCAtari（手動修補後）解析畫面成物件清單。每遊戲示範少於 1000 幀且非成功流程（MR 示範從未拿到正分）。另建構不提供示範的 Pong-Alt（3 球、3 對手）與 MR-Alt（更多敵人與梯子，地圖改編自 Kangaroo）測試組合式外推。基線含 PPO（100k、20M 步兩種預算）、ReAct（LLM 直接當策略）、WorldCoder+Planner（單一整體程式世界模型，套用同一套分層規劃器比較）。示範初始化世界模型後，agent 最多訓練 3k 步再評估。

Agent 結果：低資料量下 PoE-World+Planner 四個環境全面勝出。持續加碼訓練 PPO，要超過一百萬步才追上；PPO 練到 2000 萬步在 MR 上仍從未拿過正分。PoE-World+Planner 是唯一在 MR 基礎版與 Alt 版都拿到正分的方法。把 PPO 先在世界模型裡預訓練、再到真環境微調可明顯加速學習：原版 PPO 要 100 萬步才贏過隨機基準，預訓練後只需 20 萬步。

下一觀測預測與硬性限制：PoE-World 多數設定優於 WorldCoder，唯獨 Pong 隨機幀測試集上兩者相近，因隨機 agent 很少真正打到球。PoE-World 只在 MR 上啟用硬性限制，因 Pong 多數場景本來就物理合理。拿掉限制會讓 MR、MR-Alt 規劃成功率下降，但對預測準確率無顯著影響——硬性限制做的是損害控制，把預測修到剛好撐起長程規劃，而非把爛預測變好。

與 WorldCoder 的質性差異：PoE-World 為 MR 合成的世界模型有 4000 行以上程式碼，WorldCoder 不到 100 行。PoE-World 正確表示玩家相對平台、梯子的移動限制；WorldCoder 則預測玩家可「亂飛」不受約束，還幻想出不存在的開火能力，作者認為這與 WorldCoder 無細粒度機制降低問題片段的權重有關，PoE-World 靠剔除低權重專家做到了這件事。

第 5-6 節：相關工作與討論（節錄）

WorldCoder、CodeWorldModels 同樣用 LLM 寫 Python 轉移函式，但學單一整體程式，擴展性受限；本文模型需多一個數量級程式碼才能建模複雜環境，並額外處理部分可觀測性與非確定性。可組合性是本文精神：把知識拆成小專家，預測可組合外推到物件更多、重新排列的新場景。組合式拆解與是否用符號程式碼正交——程式可整體（如 WorldCoder），神經網路也可分解——但組合性是能否可擴展學到底層符號程式的關鍵：合成單一整體程式不只對真實世界不可行，對 Atari 也不可行。限制方面，符號程式需要符號輸入，不從像素直接學；不處理探索、決策、獎勵函式學習，但作者推測程式結構世界模型能為探索開新路，因它給出可解讀的信念描述介面，探索類似於測試一段編碼了世界模型的程式。
