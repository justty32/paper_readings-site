論文／訪談原始來源

RENEW：以偏好學習世界模型並修復模型 exploitation

摘要與動機

離線世界模型在資料稀薄區會產生錯 dynamics，規劃器會刻意尋找並利用這些錯誤。保守法是避開不確定區，卻限制泛化；補 demonstrations 又可能昂貴或危險。本文提出從人對 imagined rollout 的物理合理性偏好，直接修世界模型，而非只修 reward 或避開未知。

DLHF：偏好監督 dynamics

對 segment σ，模型以每一步 transition log probability 的和作為軌跡 likelihood。兩條軌跡的偏好機率由其 likelihood 差的 logistic 函數給出，並以 Bradley–Terry cross-entropy 更新 dynamics parameters。也就是同一套 pairwise preference machinery，RLHF 通常學 reward；DLHF 則直接學 transition。

問題文字很重要：應問哪段「較真實」，不問哪段「任務做得較好」。迷宮模型若准許穿牆，較短的穿牆軌跡可能獲得 task-success preference；但合理性偏好應選可穿行的那段，才能反向修正 exploitation。

RENEW 的主動修復

naive DLHF 若均勻抽 imagined rollout，很多標註花在模型已經正確的地方。RENEW 每輪計算 epistemic uncertainty，對 high-uncertainty 起點與 segment 以較高機率取樣，產生候選 pair、收集同一輪的 preference、最小化 DLHF loss，然後以更新後模型重算不確定度。作者使用 ensemble disagreement，但表示方法不綁定該 estimator。

它不以舊 offline corpus 作 finetune 資料，只從其有效起始 state pool 發射 rollout；作者認為這適合無法取得、過大或受隱私限制的 pretraining data。這不表示不需要任何有效 state source。

實驗

在 Jumanji 的小型離散世界，synthetic oracle 依相對 ground-truth transition 的 L1 error 標偏好。從零開始的 DLHF 到 1M labels 才接近 1K supervised transitions，顯示 binary preference 對高維 transition 的資訊效率很低。

同樣 100K labels、相同 checkpoint 與 optimizer 下，RENEW 在 Sliding Tile 3×3 的 L1 error 0.207，naive 0.419；5×5 為 1.689 對 1.819。Sokoban 也出現關鍵負結果：naive 的 0.0428 比預訓練 0.0377 更差，RENEW 則為 0.0257，與避免 catastrophic forgetting 的解釋一致。

修復實驗預訓練 Maze model，只有 1,600 preferences。RENEW 四個 maze size 的 transition accuracy 為 96.5%、97.2%、94.4%、94.9%，naive 為 89.7%、93.2%、92.3%、93.2%。作者以 error 與 uncertainty 均下降作為 exploitation-repair 證據；並未直接評估一個 learner 是否再也無法利用模型。

結論與限制

偏好可直接監督 dynamics，但從零學十分昂貴；主動把人力給 uncertainty 高區使修復較實際。限制是標註者其實是 synthetic oracle、環境小而簡單，尚未面對噪聲真人、影像觀測或真實 offline RL。降低 prediction error 也還不是形式化的安全或不可利用保證。
