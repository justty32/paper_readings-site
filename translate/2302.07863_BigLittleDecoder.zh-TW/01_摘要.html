摘要

基於 Transformer 的大型語言模型（LLM）帶來 NLP 的巨大進展，但其推論延遲很長，限制部署並使即時應用成本高昂。自回歸生成任務更放大此問題——模型必須循序、逐一生成 token，無法利用 token 級平行化。為此，作者提出 Big Little Decoder（BiLD）：一個能改善各種文字生成應用之推論效率與延遲的框架。BiLD 含兩個不同大小、協同生成文字的模型：小模型自回歸地以低成本生成大部分文字，大模型只偶爾被叫來以非自回歸方式修正小模型的不準確預測。為協調兩者，BiLD 引入兩條簡單有效的策略：(1) fallback policy（決定何時把控制權交給大模型）；(2) rollback policy（決定大模型何時需修正小模型的錯誤預測）。在 IWSLT 2017 De-En、WMT 2014 De-En 翻譯與 XSUM、CNN/DailyMail 摘要上，於 NVIDIA T4 GPU 達成最高 2.12× 加速且生成品質幾乎不掉。框架完全 plug-and-play，無需修改訓練流程或模型架構。程式碼開源（github.com/kssteven418/BigLittleDecoder）。

1. 引言

Transformer 已成 NLP 的事實標準架構，並由參數達千億級的 LLM 進一步強化。但高效推論因模型巨大與執行複雜而困難，限制了需即時回應的應用。這些低效在自回歸生成任務（機器翻譯、摘要、語言建模）尤為突出：每個 token 依賴先前 token，模型須反覆執行，每次生成都要載入權重矩陣與先前 token 的 KV cache，無法跨多 token 平行化，使自回歸生成在推論時記憶體頻寬受限、硬體利用率低、延遲高。相對地，文字分類等非自回歸任務可一次載入權重並平行處理整個輸入。因此提升自回歸解碼的延遲與效率至關重要。

既有的非自回歸解碼（平行解碼）雖能同時生成多個 token 以降延遲，卻因假設輸出 token 間條件獨立而有品質問題；要追平自回歸品質，通常需複雜且任務相依的訓練策略、引導解碼的輔助提示資訊、以及知識蒸餾。

本文提出 BiLD，可套用於各種文字生成情境以降延遲，無需額外訓練迭代、也不改既有訓練管線或模型架構。BiLD 由一大一小兩個 decoder 協同生成：只有小模型自回歸執行、生成大多數文字（善用其低開銷），大模型只偶爾介入、以非自回歸方式修正小模型的不準確預測。這種「小模型自回歸、大模型非自回歸」的方案，相較常規自回歸帶來最高約 2× 的端到端加速，同時維持相近或更好的品質。其可行性也由觀察支持：小、大模型的預測只有輕微分歧，故小模型只需極少量修正即可追平大模型。

主要貢獻：(1) 提出協調大小模型、讓大模型只偶爾且以非自回歸方式高效介入的通用框架 BiLD；(2) 提出 fallback 策略（小模型不夠自信時交棒）與 rollback 策略（大模型審查並修正小模型錯誤預測）；(3) 提出對齊小、大模型預測的簡單技術（prediction alignment）以進一步提升效能；(4) 在 4 個生成情境（IWSLT／WMT 翻譯、XSUM／CNN-DM 摘要）上，相較全自回歸，品質不掉時最高 1.85× 加速、容許約 1 分下降時最高 2.12× 加速（T4 GPU）。

2. 相關工作

2.1 高效 Transformer 解碼推論

提速方向包含高效架構設計、量化、剪枝、神經架構搜尋等。與本工作最相近的一條線是非自回歸解碼（平行解碼），最早由 Gu 等 [16] 提出以平行產生多 token 避免循序生成；後續工作以輔助／提示資訊或多輪迭代精修來提升品質，但普遍需複雜、任務相依的訓練策略與輔助資訊。相對地，本文追求免複雜訓練管線的 plug-and-play 方案。

另一相關方向是「讓 decoder 變淺」：Kasai 等 [29] 指出加深 encoder、減淺 decoder 可降延遲而保品質；CALM [51] 引入 early exiting，對每個 token 動態調整 decoder 深度、在中間層終止。BiLD 目標相同（加速解碼）但走提升解碼平行度而非跳過計算的路線，並對 CALM 有幾點優勢：(1) 純黑箱、不改模型結構（CALM 需對跳過層做狀態傳遞）；(2) 不改訓練管線（CALM 需跨所有層平均損失以確保層一致性）；(3) 可完全免訓練套用（在許多訓練不可行或極貴的 LLM 情境下關鍵）。§4.4 也顯示 early exit 可被納入 BiLD 框架並得到顯著更好的品質。

2.2 多模型的運用

知識蒸餾讓小模型模仿大模型行為以提升效能（蒸餾 logits／隱狀態／注意力圖）；但它只在訓練時利用大模型知識，本文則是執行時的方案，更能適應執行期行為且不增訓練複雜度。集成學習獨立訓練多模型再合併預測，對 Transformer 推論有前景，但執行時須跑多模型並合併、計算貴且未針對延遲最佳化；本文則同時最佳化效能與執行延遲。

與本工作同時且獨立地，Leviathan 等 [38] 與 Chen 等 [4] 也提出以較強模型對較弱模型的預測評分並推測式取樣以加速生成的演算法。相較 [38, 4] 提供匹配較強模型機率分布的無偏估計，本文的實證顯示 BiLD 因採用非隨機的 rollback（拒絕）策略與動態 fallback 窗口大小，能提供更佳的延遲—效能取捨（詳見 §4.2 與附錄 7.3）。
