摘要

幻覺（hallucination）是大型語言模型（LLM）長期存在的問題。隨著這些模型愈來愈多地用於醫療、金融等高風險領域，有效的幻覺偵測至關重要。為此，我們提出一個實務者可套用於真實案例的閉卷（closed-book）幻覺偵測通用框架。作法是：改寫多種既有的不確定性量化（uncertainty quantification, UQ）技術——包含黑盒 UQ、白盒 UQ 與 LLM-as-a-Judge——在必要時加以轉換，統一為介於 0 到 1 的標準化 response-level 信心分數。為增加彈性，我們提出一個可調（tunable）的集成方法，可納入任意組合的個別信心分數，讓實務者針對特定場景最佳化集成以提升效能。為簡化實作，全套評分器隨論文以 Python 工具包 uqlm 開源。我們用多個 LLM 問答 benchmark 進行大量實驗評估各評分器，發現可調集成通常勝過其個別組件，也優於既有幻覺偵測方法。結果證明客製化的幻覺偵測策略能提升 LLM 的準確率與可靠性。

1. 引言

LLM 正被大量用於生產級應用，且常在醫療、金融等高風險領域，因此監控輸出的準確性與事實正確性的需求日增；在這些敏感場景中，即使小錯也可能造成安全風險、財務損失與商譽傷害。幻覺——輸出聽來合理卻與事實不符——是特別令人擔憂的風險；即便是 OpenAI GPT-4.5 這類新模型，在某些 benchmark 上幻覺率仍高達 37.1%。

幻覺偵測法通常是：比對 ground truth 文本與生成內容、比對來源內容與生成內容、或量化不確定性。比對 ground truth 的作法多在部署前進行以量化風險，不適合對已上線系統做即時評估；相對地，比對來源內容或量化不確定性的作法可在生成時算出 response-level 分數，適合即時監控。

UQ 技術可在閉卷環境下做幻覺偵測——不需來源內容資料庫、標準答案或網路。這類方法通常分三種：黑盒 UQ利用 LLM 的隨機性、測量同一 prompt 多個回應的語意一致性；白盒 UQ利用輸出 token 的機率算不確定性；LLM-as-a-Judge用一或多個 LLM 評估「問答串接」的事實正確性。

本文提出一個生成時、閉卷的通用幻覺偵測框架：改寫上述三類方法、必要時做轉換，得到 0 到 1 的標準化信心分數（作者強調是用 UQ 風格訊號來產生 response-level 信心以偵測幻覺，而非把不確定性量化本身當目的，也不區分 aleatoric 與 epistemic 不確定性）。為增進客製化，提出可調集成——輸出是各組件的簡單加權平均，權重可用使用者提供的一組已評分回應調出。集成可擴充，未來新方法可持續納入。作者在四個 LLM、多個問答 benchmark 上評估全套評分器，主要發現：可調集成大多勝過個別組件；但單一分數排名隨資料集大幅變動；黑盒中 entailment 類（NLI）表現最佳；採樣更多回應的增益隨數量遞減；模型在某資料集自身的準確率，正相關於它當該資料集評審的能力。論文並附開源套件 uqlm（github.com/cvs-health/uqlm）。

2. 相關工作

黑盒 UQ：Cole et al. 提出用 exact match 類指標比對原始回應與候選回應（repetition＝與原始回應相符的比例；diversity＝懲罰候選中唯一回應過多），缺點是會懲罰同義但措辭不同者。文本相似度指標較寬鬆：SelfCheckGPT 用 n-gram；亦有 ROUGE、BLEU、METEOR（對 token 順序敏感、常抓不到語意等價）；句向量餘弦相似度（用 Sentence-BERT）可跨措辭抓語意；BERTScore 用情境化詞向量的最大餘弦相似度。NLI（Natural Language Inference）模型是另一主流：把一對文本分類為 entailment／contradiction／neutral，用 1−P(contradiction) 或 P(entailment) 量化不確定性；LUQ 則跨句平均並排除 P(neutral)。另有用 NLI 分群算 semantic entropy 者，以及在語意空間估密度者。

白盒 UQ：SelfCheckGPT 考慮平均負對數機率與最大負對數機率（有效但無界、難解讀、宜排序而非單看）；也有人用 perplexity（平均負對數機率取指數，同樣無界）與 response improbability（全 token 聯合機率的補數，有界易解讀但懲罰較長序列）。另一主流是 entropy（考慮詞表所有 token 機率）；Malinin & Gales 亦考慮 token 機率的幾何平均（有界、易解讀）。

LLM-as-a-Judge：多研究把問答對串接、要 LLM 評分或分類正確性。Chen et al. 的 self-reflection certainty 用同一 LLM 判 incorrect／uncertain／correct，對應 0／0.5／1；Kadavath et al. 要 LLM 給出 P(Correct)；Xiong et al. 探索多種自評提示變體；更複雜的還有多選題生成、多 LLM 互動、追問等。

集成方法：Chen et al. 的 BSDetector 是雙組件集成——observed consistency（exact match 與 NLI 矛盾機率兩比對分數的加權平均）＋ self-reflection certainty，兩者加權平均得信心分數。Verga et al. 提出 PoLL（Panel of LLM evaluators）：用一組較小 LLM 組成評審團而非單一大模型，發現 PoLL 勝過大模型評審、模型內偏誤更少。
