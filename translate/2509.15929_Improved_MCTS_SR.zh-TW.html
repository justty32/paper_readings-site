改進符號迴歸的蒙特卡羅樹搜尋

PKU-CMEGroup（程式碼 github.com/PKU-CMEGroup/MCTS-4-SR）

摘要

SR 旨在發掘簡潔可解釋、滿足目標（如擬合資料）的數學表達式，是高度組合的優化問題。GP 長期主流，近期探索 RL 提升搜尋效率。MCTS 經引導搜尋平衡探索-利用，成為符號表達式發現的有望技術。但其傳統 bandit 策略與逐符號建構常限制表現。本文提出改進 MCTS 框架，經兩大創新解決：(1) 為辨識全域最優表達式量身的極值老虎機分配策略，多項式獎勵衰減假設下有有限時間表現保證；(2) 演化啟發的狀態跳躍動作（如變異、交叉），使非局部轉移到搜尋空間有望區。這些狀態跳躍動作也在搜尋中重塑獎勵地形，提升穩健與效率。我們做徹底數值研究並在多種資料集（ground-truth + 黑箱）上對比既有 SR 方法。本法回復率與 SOTA 庫相當，在準確 vs 模型複雜度的 Pareto 前沿佔有利位置。

1. 引言

SR 不假設預設形式、發掘可解釋簡潔解析式；同時搜尋函數形式與參數（組合空間），產人讀式利於科學發現（金融/材料/氣候/醫療/即時控制）。SR 是 NP-hard 組合優化（搜尋樹結構 + 參數）。GP 最主流（演化候選式經變異/交叉/選擇）但常產過複雜公式、對超參敏感。學習法利用結構規律（對稱/可分離/組合性）；深度網路可直接生候選式但常只擅長資料擬合、難泛化出訓練分布。另一途徑把 SR 當序列決策用 RL（受 Go 啟發，policy-gradient/RNN 逐 token 建式；MCTS 導航符號程式空間）。

SR 與傳統 RL 兩處不同：(1) 目標是找全域最優狀態（最高獎勵）而非最大化期望累積獎勵；(2) 動作空間非固定、可設計成彈性狀態跳躍繞過逐步轉移。貢獻：(1) 制定類比 UCB 的極值老虎機分配策略並推導某些獎勵假設下的最優性保證；(2) 引入演化啟發狀態跳躍動作（變異、交叉） 把 MCTS 獎勵分布移向更高值；(3) 精煉 MCTS 框架達 SOTA 競爭力 + 對「RL 用於組合優化」新洞見。

1.1 相關工作

  • MCTS for SR：受 AlphaGo 啟發。早期用預訓練 actor-critic 當價值函數於 UCB；後有 module transplantation（手動加高獎勵狀態的子式）、transformer 引導動作機率、GA+MCTS 混合（MCTS 初始化 GP、GP 訓練 MCTS 內 double Q-learning）。共通：強調利用高獎勵動作（ε-greedy 或把 UCB 平均換最大）。
  • Bandit 分配：UCB 平衡探索-利用，但 UCB 最小化平均 regret，SR 求單一最佳 → 研究 extreme-bandit 設定。本文提有最優保證的 extreme-bandit 分配規則嵌進 MCTS。
  • 混合法：GP（有限狀態馬可夫過程、收斂靠遍歷性，但須仔細平衡探索-利用、對超參敏感）+ RL（MCTS/policy gradient，逐符號建式平衡較好但逐步建構低效）。近期混合 RL+GP 交替。本文把生物啟發的狀態跳躍（變異/交叉）嵌進 MCTS。

2. 背景

（2.1 SR：表達式表為二元樹/符號序列；2.2 MCTS 四步選擇/擴展/模擬/反向傳播 + UCB。）

3. 方法

（3.1 極值老虎機分配策略 UCB-extreme + 多項式獎勵衰減下的最優性保證；3.2 狀態跳躍動作變異/交叉。）

4. 實驗與結果

基本 benchmark（ground-truth 已知閉式）：Nguyen、Nguyen C、Jin、Livermore（至多兩變數）。SRBench 黑箱：Feynman、Strogatz、Black-box（122 任務，46 真實觀測 + 76 合成）。含常數時各表達式評估用 BFGS 優化常數。

演算法分析（Nguyen）：

  • 先視覺化獎勵分布（高機率回復的重要指標）。多數 Nguyen 案例尾衰減率約在某區間（圖 2 Nguyen-4）。
  • 只配 UCB-extreme：尾衰減率估計高於某值時可達最優回復；但對尾衰減率參數敏感、需仔細調，複雜目標式（如 Nguyen-4）常掙扎。
  • 加狀態跳躍動作：劇烈重塑獎勵地形。加入前 Nguyen-4 的尾衰減（Beta 分布 β 參數）在某區間，加入後降到 <2；其餘 Nguyen 案例 β 從原區間移到 [2,4]。實務上降 β → 更快更穩收斂。後續比較固定此設定。

比較研究（Table 1，200 萬評估、100 次平均回復率%）：

  • Nguyen：Ours 93.25 / NGGP 92.33 / GEGL 86 / DSR 83.58 / PySR 74.41
  • Nguyen C：Ours/DSR/GEGL/NGGP 皆 100、PySR 65.40
  • Jin：Ours 100 / NGGP 100 / GEGL 95.67 / DSR 70.33 / PySR 72.17
  • Livermore：Ours 71.41 / NGGP 71.09 / GEGL 56.36 / DSR 30.41 / PySR 46.14
  • → 與 SOTA（DSR/GEGL/NGGP/PySR）相當或更優。

SRBench（對比 21 基線）（圖 3）：本法在準確-複雜度間取得有利平衡——測試準確排第 2（僅次 Operon），但模型簡單得多；在 Pareto 前沿位列頂尖（與 Operon、GP-COMEA、DSR 並列）。
