5. 實驗

任務：L2 ScaleUp（生產 RankMixer backbone，搜 token_cnt/token_dim/層數等耦合結構超參，模型大小保持在生產基線 ±10%）;L3 Literature-to-Production（測能否把 TokenMixer-Large 移植進同 backbone，改 token 互動模組同時保特徵管線、張量形狀、訓練穩定、推論相容）。

指標：LPR（本地通過率）、EPR（有效通過率）、SFR（靜默失敗率：能跑但無效）。Baseline：人類專家迴圈、AutoML、通用 coding agent（含標準 ReAct 單代理）。

主結果：L3 上 NOVA 達 86.7% LPR、60.0% EPR，大幅勝 coding-agent baseline、EPR 超過人類專家迴圈兩倍；L2 ScaleUp EPR 54.5%。降低靜默失敗。一個 L3 週期人工時間縮短逾 13 倍（節省集中在工程師時間、非 GPU 吞吐）。

消融：移除論文復現、方案設計、多候選生成、品質評估、架構梯度回饋各會掉效。

線上 A/B：選中 L3 候選三個 pCVR 目標 GMV +1.25%/+1.70%/+2.02%、pCVR 偏差降 58.8%/66.7%/37.3%。

6. 結論與未來

NOVA 是工業推薦架構演進的驗證感知分級智能體 harness，以架構梯度聚合多源回饋引導搜尋、以靜默失敗感知驗證級聯把失敗轉成禁區方向、以 L1–L4 + AutoRun/Copilot 對齊自動化與風險。生產部署與線上 A/B 證明其有效與商業價值。
