6. 結果與討論

6.1 顯著特性與創新

NeuSymMS 最顯著的特徵是其混合神經符號架構：LLM 僅用於其增值之處（自然語言理解），CLIPS 處理確定性任務——產生零成本、低延遲、附帶基於規則的明確理由（reason 欄位）的決策。系統實現了自動化真值維護（新資訊撤回過時事實）、否定感知萃取（正確處理喪失、停止或變化的陳述）、基於存取的晉升（無需額外模型的有機重要性訊號），以及三層作用域隔離（防止多 Agent 場景中的跨實體污染）。人機協作管理透過 UI 增強信任與合規。

6.2 可靠性與成本

設計優先考慮優雅降級：LLM 萃取失敗→記憶不更新；CLIPS 錯誤→降級存為短期；記憶載入失敗→Agent 無上下文繼續（而非拒絕請求）。成本最小化：使用低成本 LLM、本機運行 CLIPS、避免嵌入檢索或額外評分模型——上下文注入為所選事實的字串拼接，無需昂貴的向量搜尋。

7. 結論與未來工作

我們提出了 NeuSymMS——一個實用的混合神經符號記憶系統，結合神經事實萃取與 CLIPS 專家系統，實現確定性、可審計的記憶管理。透過以三元組表示知識、強加作用域生命週期並利用基於存取的晉升機制，NeuSymMS 為 Agent 提供了對其使用者的持久、演化中的知識，同時控制成本並確保可靠性。

未來工作包含：更豐富的時序推理（區間與事件）、改進的否定與不確定性處理、自動化規則學習或規則建議機制以適應分類與生命週期策略到新領域。計畫在有無 NeuSymMS 的情境中評估使用者體驗與下游任務效能，以量化結構化記憶對真實世界 Agent 部署的影響。

7.1 評估路線圖

完整量化的評估留待未來工作，但作者概述了計畫中的協定：在 LoCoMo、LongMemEval、AMA-Bench 與 MEMORYARENA 等長期記憶基準上評估，以固定 LLM 主幹隔離記憶層的效果。基線包括 Mem0、MemGPT/AMEM、LiCoMemory、TELEMEM、GraphRAG/Semantic Anchoring、AMAC 等，允許對矛盾處理、檢索品質與運營成本進行直接比較。將報告的指標包含 Agent 中心指標（任務成功率、檢索準確性、多會話一致性）與系統指標（讀取/寫入延遲、token/計算成本、多租戶負載下的吞吐量）。
