5. 討論、局限與未來展望

在真實場景使用 LLM 的高昂成本是其普及的一大障礙。本文列出並討論降低 LLM API 推論成本的實用策略，並以 FrugalGPT 示範其中之一（LLM cascade）。實證顯示 FrugalGPT 可在保留頂尖 LLM 表現的同時最多降低 98% 成本。

局限：

  • 訓練 FrugalGPT 的級聯策略需要有標註樣本，且為使級聯運作良好，訓練樣本應與測試樣本同分佈或相似分佈。
  • 學習級聯本身需要資源；作者視其為一次性前置成本——當最終查詢資料集大於用來訓練級聯的資料時才划算。
  • 尚有其他省本方向（如加速 attention 計算本身）未在此討論；鑑於 LLM 快速發展，本文不求窮盡或提供定案，目標是為此重要研究議程奠基、並證明「即使簡單級聯也已能達到可觀節省」。

未來方向：FrugalGPT 專注於平衡表現與成本，但真實應用還需評估 latency、fairness、privacy、環境影響等關鍵因素；在風險關鍵應用中須謹慎量化 LLM 生成輸出的不確定性；處理訓練與部署 LLM 的環境衝擊需 LLM 使用者與 API 供應商共同努力。
