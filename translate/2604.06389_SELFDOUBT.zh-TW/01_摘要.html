摘要

推理語言模型的不確定性估計在實務中難以部署：採樣式方法計算昂貴，而常見的單次代理指標（如口語化信心或軌跡長度）跨模型時常不一致。對不揭露 logits 或中間 token 機率的商用推理 API，此問題更為嚴峻——實務人士在推論時無可靠不確定性信號可用。我們提出 SELFDOUBT，一套單次不確定性框架，透過直接從推理軌跡萃取行為信號來解決此僵局。核心信號 **Hedge-to-Verify Ratio（HVR）**偵測推理軌跡是否含不確定性標記，以及是否有明確的自我檢查行為予以抵消。不同於需多次採樣軌跡或模型內部存取的方法，SELFDOUBT 僅需單一觀測推理軌跡，適合延遲與成本受限的商用 API 部署。我們在七個模型、三項多步推理基準（BBH、GPQA-Diamond、MMLU-Pro）上評估 SELFDOUBT。最值得注意的是，不含任何 hedge 標記的軌跡在 96% 的情況中正確，揭示了零額外成本的高精度信心閘。其餘案例中，完整 SELFDOUBT score 以 10 倍低推論成本顯著優於採樣式語義熵。結合兩階段的部署級聯達成 90% 準確度、71% 覆蓋率，無需任何任務特定標註。這些結果確立了 SELFDOUBT 作為商用推理模型可擴展、可生產的不確定性估計基礎。程式碼公開於 https://github.com/satwik2711/SelfDoubt。

1. 引言

推理語言模型的不確定性量化仍困於兩個不討好的極端之間。採樣式方法——包括語義熵（SE; Kuhn et al., 2023; Farquhar et al., 2024）、P(True) 自我評估（Kadavath et al., 2022）、語義幾何方法（Li et al., 2025; Phillips et al., 2025）——需 N 次獨立前向傳播，而單次推理本身已耗費數千 token，此成本令人望之卻步。單次替代方案存在，但各有取捨：口語化信心（Tian et al., 2023; Yoon et al., 2025）在困難任務與弱模型上失校準；軌跡長度（Devic et al., 2025）僅在中難度基準上與不確定性相關；探針式方法（Kossen et al., 2024）需隱藏狀態存取。更進一步的約束：商用推理 API 不揭露推理 token 的 log-probabilities，使依賴 token 層級機率的方法（Moslonka et al., 2026; Zhang & Zhang, 2025）在最需要 UQ 的場景中架構上不可行。

我們提出 SELFDOUBT，一套從推理軌跡直接萃取行為信號的單次不確定性框架。其核心信號 **Hedge-to-Verify Ratio（HVR）**為單一純量：hedge 標記數除以 verify 標記數加一。直觀地說，hedging 表達懷疑（"maybe"、"perhaps"、"not sure"），verification 則對其採取行動（"let me check"、"verify"、"substitute back"）。因此 HVR 捕捉了所表達的懷疑是被解決、還是被擱置。HVR 與口語化信心的 z-score 融合產出完整 SELFDOUBT score，無需訓練、無需模型內部、僅需每模型 90 條無標註校準軌跡。

四項貢獻：(1) HVR = 0 gate——僅需 regex 匹配的零成本正確性過濾器，七模型三資料集上零 hedge 語言軌跡正確率 96.1%（25.4% 覆蓋率，標註雜訊校正後真正錯誤率 0.58%）;(2) SELFDOUBT——O(1) 不確定性分數，顯著優於語義熵的鑑別力（p=0.001），選擇性預測品質持平、推論成本十分之一；(3) 無監督標記發現——從 90 條無標註軌跡建構模型特定詞典的無監督管線，無需正確性標籤、無需人工策劃、切換模型無需重新訓練；(4) 生產級推遲級聯——Tier 1（HVR = 0 gate）+ Tier 2（校準 z-sum 閾值），71% 覆蓋率 89.7% 準確度、+9.2 百分點提升，僅需每模型 4 個儲存純量。

2. 相關工作

方法全景：表 1 沿計算成本與方法需求兩軸組織 UQ 方法。O(1) 方法含口語化信心（Tian et al., 2023; Yoon et al., 2025）、軌跡長度（Devic et al., 2025）、TL+VB、詞彙提示（Vanhoyweghen et al., 2025）、CoT-UQ（Zhang & Zhang, 2025，需 token logits）、EPR/WEPR（Moslonka et al., 2026，需 Top-K logprobs）、SEP（Kossen et al., 2024，需隱藏狀態）、Latent CoE（Wang et al., 2025，需隱藏狀態）。O(N) 方法含 P(True) 自評、語義熵、語義體積、幾何不確定性；O(N²) 方法為 Topo-UQ（Da et al., 2025）。SELFDOUBT 的定位：O(1) 成本、僅需軌跡文字與提示修改——無需訓練組件或模型內部。

採樣式 UQ：語義熵（Kuhn et al., 2023; Farquhar et al., 2024）將 N 個採樣輸出依語義聚類；語義體積（Li et al., 2025）與幾何不確定性（Phillips et al., 2025）量測嵌入散佈；Topo-UQ（Da et al., 2025）以 O(N²) 計算圖編輯距離。這些方法對推理模型尤其受限——單次推理已數千 token，10–20 倍成本為禁制級。

軌跡式 O(1) 方法：Devic et al. (2025) 顯示軌跡長度為湧現不確定性信號，TL+VB 優於任一單獨成分。Yoon et al. (2025) 發現推理模型口語化信心更校準。最接近的同期工作是 Vanhoyweghen et al. (2025)，顯示 CoT 軌跡中 hedge 詞彙使準確度最高相對下降 40%。Podolak & Verma (2025) 進一步指出推理軌跡暴露出直接答案生成中不存在的自我信心信號。

探針式與隱藏狀態方法：需隱藏狀態或 token 機率，商用 API 不可用。缺失的是一個從純文字捕獲審議結構的 O(1) 方法——無訓練、無模型內部。
