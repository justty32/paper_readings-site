摘要

我們提出語意熵探針（SEP），一種便宜且可靠的大型語言模型（LLM）不確定性量化方法。幻覺——聽起來合理但事實錯誤、任意生成的模型內容——是 LLM 實務採用的一大挑戰。Farquhar et al. (2024) 提出的語意熵（SE），可透過對一組模型生成估計其語意空間中的不確定性來偵測幻覺。然而，計算 SE 需要 5 到 10 倍的算力增加，阻礙了實務採用。為解決此問題，我們提出 SEP，直接從單次生成的隱藏狀態逼近 SE。SEP 訓練簡單，測試時不需取樣多個模型生成，把語意不確定性量化的額外開銷降到近乎為零。我們證明 SEP 在幻覺偵測上保有高效能，且比先前直接預測模型準確度的探針方法更能泛化到分布外資料。我們跨模型、跨任務的結果顯示，模型隱藏狀態確實捕捉了 SE，消融研究則進一步揭示了哪些 token 位置與模型層具有此特性。

1. 引言

LLM 已在各式自然語言處理任務展現出色能力，並愈來愈常被部署在醫療、新聞、法律服務等高風險領域，因此我們必須能信任其輸出。不幸的是，LLM 有幻覺傾向——原本定義為「與原始來源不符或無意義的內容」，如今泛指模型生成的非事實、任意內容。即使是 GPT-4 這樣能力強的模型，被要求生成人物傳記時也常常完全捏造事實。這類幻覺在低風險場景或許可接受，但在事實性至關重要的場合可能造成重大傷害。

一個有效的幻覺偵測策略是：對同一提示取樣多個回應，檢查不同樣本是否表達相同含義。核心想法是：若模型「知道」答案，會持續給出相同答案；若在幻覺，回應會因取樣而變動。例如問「法國首都是哪裡？」，「知道」答案的 LLM 會持續輸出（巴黎、巴黎、巴黎），「不知道」的則可能輸出（那不勒斯、羅馬、柏林），顯示幻覺。

這現象的一種解釋是 LLM 具有校準過的不確定性，即「語言模型（大致上）知道自己知道什麼」：確定時持續給出正確回應，不確定時則生成任意答案。但我們無法直接用 token 層級機率估計不確定性，因為不同的 token 序列可能表達相同含義（例如「巴黎」「就是巴黎」「法國的首都是巴黎」意思相同）。為此，Farquhar et al. 提出語意熵（SE）：把生成結果聚類成語意等價的集合，再於語意空間估計不確定性。

SE 及其他取樣式方法的一大限制，是每個輸入查詢都需要多次（通常 5–10 次）模型生成，導致成本比不用 SE 的樸素生成高出 5–10 倍，是實務採用的重大阻礙。我們需要計算上更便宜、同樣可靠的幻覺偵測方法。

LLM 的隱藏狀態是理解、預測、操控 LLM 行為的一個有前景的方向。近期一類工作學習在 LLM 隱藏狀態上訓練簡單的線性探針，來預測模型回應的真實性；線性探針訓練與推論都計算高效。然而既有方法通常是監督式的，需要為陳述句或模型生成標註準確度的標籤資料集；雖存在無監督方法，但其有效性已受到質疑。本文主張：用 SE 而非準確度標籤來監督探針，對穩健地預測真實性更有利。

我們提出語意熵探針（SEP）：從 LLM 隱藏狀態捕捉語意不確定性的線性探針，是一種划算且可靠的幻覺偵測方法。SEP 結合了探針法與取樣式幻覺偵測法的優點：與其他探針法一樣，SEP 訓練容易、部署便宜，且可用於單次模型生成的隱藏狀態；與取樣式幻覺偵測法一樣，SEP 捕捉模型的語意不確定性。它同時修正了先前方法的部分缺陷：相對於取樣式偵測，SEP 直接作用於單一模型隱藏狀態，測試時不需生成多個樣本；相對於先前的探針法，SEP 訓練目標是預測語意熵而非模型準確度，不需要取得可能昂貴的真值準確度標籤。

我們發現 SEP 預測是真實性的有效代理指標。事實上，SEP 比直接訓練預測準確度的探針更能泛化到新任務，為划算的幻覺偵測樹立新的 state-of-the-art。我們的結果也提供了對 LLM 內部運作的洞見，強烈顯示模型隱藏狀態直接捕捉了模型對語意含義的不確定性；消融研究顯示這在多種模型、任務、層與 token 位置上皆成立。

核心貢獻：(1) 提出 SEP，在 LLM 隱藏狀態上訓練以捕捉語意熵的線性探針（第 4 節）；(2) 證明語意熵確實編碼在單次模型生成的隱藏狀態中，可用探針成功萃取（第 6 節）；(3) 跨模型、任務、層、token 位置的消融研究，強烈顯示內部模型狀態（即使在生成任何 token 之前）即隱含捕捉語意不確定性（第 6 節）；(4) 證明 SEP 可用於預測幻覺，且比先前直接以準確度訓練的探針更能泛化，樹立划算幻覺偵測的新 SOTA（第 7 節，圖 1）。

2. 相關工作

LLM 幻覺：早期工作多指摘要任務中模型生成「與原始來源不符」的內容；隨後研究顯示 LLM 本身可儲存並檢索事實知識，帶出目前流行的「封閉書」設定（不提供額外上下文查詢 LLM）。此後大量工作聚焦於一般自然語言生成任務中的幻覺偵測，大致分兩類：取樣式與檢索式方法。

取樣式幻覺偵測：對同一查詢取樣多個模型回應、量化生成間的語意差異，Farquhar et al. 的語意熵（本文用其監督隱藏狀態探針）尤其相關。另一路線不直接重新取樣答案，而是用追問來揭露原答案的不一致；也有工作把整段生成拆解成單一事實或句子，分別驗證各自的不確定性。

檢索式方法：依賴外部知識庫（如網路搜尋）驗證模型回應的事實性，優點是不依賴良好的模型不確定性、可直接修正生成中的錯誤，但會增加成本與延遲，且對推理這類任務效果較弱（LLM 在推理上也容易產生不忠實、誤導性生成）。檢索式與不確定性式方法是正交的，可結合使用。

取樣與微調策略：另有工作透過調整取樣方案、以事實性為目標的偏好最佳化、或微調使 LLM 的「口語」不確定性與模型準確度對齊，來減少（而非偵測）幻覺數量。

理解隱藏狀態：近期工作顯示，對 LLM 隱藏狀態的簡單操作即可質變模型行為、操縱知識、或揭露欺騙意圖；探針是理解神經網路內部表徵的有用工具，且先前已證明隱藏狀態探針能高準確度地預測未來一到多個 token。與本文最相關的是「潛在空間中存在一個能預測陳述與生成正確性的『真實性』方向」這一路線的工作；本文延伸此路線——同樣關心預測模型是否在幻覺非事實回應，但主張捕捉語意熵，而非直接用準確度標籤監督探針，才是泛化效能的關鍵。
