附錄要點

  • 附錄 A（額外結果）：報告各模型在四個資料集上的任務準確度（Table 3，例如 Llama-3-70B 長答：BioASQ 67.2%、TriviaQA 88.5%、NQ Open 61.2%、SQuAD 46.0%；Llama-2-7B 短答準確度普遍較低，如 SQuAD 僅 23.5%）。額外圖表顯示 SEP 與準確度探針在 SLT/TBG 兩種位置的同分布表現相近；探測「隱藏狀態」持續優於探測殘差流（residual stream）或 MLP 輸出（圖 A.11）；「最佳切分」二值化略優於「均分」二值化，但 SEP 對二值化方式不算敏感（圖 A.12）；曾嘗試以 sigmoid 轉換語意熵為「軟標籤」訓練，早期結果未見效能提升。
  • 附錄 B（實驗細節）：
    • 提示模板：長答用「Answer the following question in a single brief but complete sentence.」；短答額外附 5 個示範例；反事實情境實驗則在問題前加一段 Context。
    • 語意熵計算：N=10 次生成，溫度 T=1.0，top-p=0.9、top-K=50；短答用 DeBERTa-Large 判蘊含、SQuAD F1 評準確度；長答用 GPT-3.5 判蘊含（自訂蘊含/矛盾/中立提示），用 GPT-4 或 GPT-4o（因兩者成本差異，Llama-3-70B 實驗改用 GPT-4o）判斷模型答案是否與真值同義。
    • SEP 細節（Table 4）：各模型層數、隱藏維度、SEP 與準確度探針所選代表層區間，如 Llama-2-7B（32 層、4096 維）SEP 選第 28–32 層、準確度探針選第 18–22 層；聚合結果均取一組相鄰層串接、依同分布區間內平均 AUROC 最高者決定。長答訓練時過濾語意熵落在 55–80 百分位區間的樣本以提供更清晰訊號（對準確度探針無益，故不套用；Llama-3-70B 實驗發現此過濾非必要）。短答訓練集 2000 筆、長答 1000 筆，SEP 與準確度探針訓練集大小一致。
    • 基線細節：p(True) 用含 10 個範例的 few-shot 提示（每例含問題、多個「腦力激盪」候選答案、一個待判斷答案、正確與否的標籤），以提示結尾處 token「A」的機率作為真實性機率。
    • 評估：泛化設定採留一法——每個探針只在單一資料集上訓練，於其餘資料集上測 AUROC，最後對每個被評估資料集取所有（未曾用其訓練的）探針的平均表現。
  • 附錄 C（計算資源）：使用內部叢集的 24 張 Nvidia A100 80GB GPU，並透過 OpenAI API 呼叫 GPT-3.5/4/4o。70B 模型的推論與隱藏狀態計算需 2 張 A100；較小模型僅需一張 A100 的一部分算力；一旦訓練資料（隱藏狀態–語意熵配對）產生完畢，僅需 CPU 即可擬合邏輯迴歸模型。依已完成的實驗紀錄估算，全文結果約耗用 300 GPU 小時 + 310 CPU 小時。
