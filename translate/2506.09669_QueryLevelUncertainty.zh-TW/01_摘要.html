摘要

大型語言模型（LLM）應察覺自身知識的邊界，把「能有信心回答的查詢」與「超出能力範圍的查詢」區分開來。這種察覺能力讓模型得以進行自適應推理（adaptive inference）——例如觸發檢索增強生成（RAG）、進入緩慢而深入的思考，或在適當時拒答（abstain）。這些機制是打造高效且可信 AI 的關鍵。本文提出以 Query-Level Uncertainty（查詢層級不確定性）偵測知識邊界的方法，它在生成任何 token 之前就估計模型能否回答某查詢，從而避免生成成本。為此我們提出一個新穎、**免訓練（training-free）**的方法 Internal Confidence（內部信心），它利用跨層、跨 token 的自我評估，提供可靠的不確定性信號。在事實問答與數學推理任務上的實證顯示，Internal Confidence 在信心品質上勝過多個基線，且計算更便宜。此外，我們展示其在自適應推理中的效益：在 RAG 與模型級聯（model cascading）情境下，它能在維持整體表現的同時降低推理成本。程式碼見 github.com/tigerchen52/query_level_uncertainty。

1. 引言

LLM 有其知識邊界（knowledge boundary）——存在某些問題是它無法給出正確答案的。讓 LLM 自我察覺自身極限、即「知道自己知道什麼、也知道自己不知道什麼」，至關重要。

清楚察覺知識邊界對「提升 AI 的效率與可信度」都很核心。LLM 與 agent 用量攀升帶來可觀的算力與金錢成本——例如 agentic 工作流每次查詢的花費可能是單純 LLM prompt 的 5×–25×（Anthropic, 2025）。就效率而言，若 LLM 能分辨「可答 vs 不可答」「簡單 vs 困難」的查詢，就能聰明地做自適應推理、在算力成本與輸出品質間權衡：對超出參數知識的查詢，主動觸發 RAG 取得外部知識或呼叫工具；面對難題則進入慢（深）思考（即 test-time scaling）；或把複雜問題透過模型級聯交給更大的模型。就可信度而言，面對高度不確定的查詢，模型可採取拒答策略，避免給出誤導性回應，這在醫療等高風險領域尤其重要。

本文引入 Query-Level Uncertainty 概念來估計模型對某查詢的知識掌握。核心研究問題是：給定一個查詢，我們能否在生成任何 token 之前，就判定模型能否處理它？ 多數既有工作聚焦 answer-level uncertainty（答案層級不確定性），衡量的是某個具體答案的不確定性、用來評估輸出可靠度；本文相反，把重心從「生成後（post-generation）」移到「生成前（pre-generation）」——在答案生成之前就衡量模型解此查詢的信心（見圖 2），從而避開生成（可能很長的）答案的算力成本。

既有不確定性估計策略大致兩類：一是訓練一個內部狀態的 probe 去預測查詢不確定性；二是以微調教 LLM 在回應中明說「我不知道」。它們共同的問題是都需要微調與訓練樣本，增加開銷、也可能限制跨模型/跨領域的通用性。為填補此缺口，本文提出免訓練的查詢層級不確定性估計法，簡單而有效。

我們的免訓練、免生成方法稱為 Internal Confidence，利用跨內部層、跨 token 的自我評估。它基於一個簡單假設：LLM 能在僅對查詢做一次 forward pass、不生成明確答案的情況下，內部自評其知識邊界。受不確定性量測 P(True)（Kadavath et al., 2022）啟發，我們用一個 yes–no 問題提示 LLM 自評「能否回答此查詢」，並把賦予 token YES 的機率定義為信心水準 P(Yes)。為充分挖掘 LLM 內部潛在知識，我們改良版的 Internal Confidence 在每一層、每一個 token 位置都算這種 P(Yes)，再彙整成整體信心分數——此彙整受「跨層邏輯一致性可改善輸出」等先前工作啟發：具體是跨層與跨 token 做加權和，權重由**衰減編碼（attenuated encoding）**導出，可細緻控制相鄰單元的影響。

在涵蓋事實 QA 與數學推理的三個資料集上，我們把既有 answer-level 方法改寫到查詢層級以做公平比較。結果顯示 Internal Confidence 比一系列基線更準地分辨可答／不可答查詢，且遠快於 answer-level 方法（圖 1a）。應用上，它能支援高效 RAG 與模型級聯：一方面幫使用者衡量「呼叫額外服務時 cost↔quality 的取捨」，另一方面揭示一個「最佳點」——在不損表現下降低推理開銷（圖 1b）。

2. 相關工作

2.1 不確定性估計與 LLM

既有 LLM 不確定性方法主要估計「LLM 生成回應」的不確定性，給查詢–答案對打一個反映可靠度的分數；這些方法常倚賴內部狀態或文字回應，並用校準技術緩解過度自信與偏差。值得注意的是，它們都在評估生成後（post-generation）的可靠度，即針對某個已產出答案的不確定性。相對地，「在 token 生成前量化模型解某查詢之能力」的研究極少。例如 Gottesman & Geva (2024) 訓練一個輕量 probe 估計模型對特定實體的知識；Semantic Entropy Probes（Kossen et al., 2024）指出內部狀態能隱含地編碼語意不確定性，甚至在任何輸出生成之前。據作者所知，本文是首個正式定義查詢層級不確定性並系統性研究它的工作。

2.2 知識邊界偵測

LLM 應能忠實評估自己回答某查詢的信心程度。Kadavath et al. (2022) 的開創性研究探討能否訓練語言模型預測自己何時「知道」答案，提出「I Know（IK）」預測概念。後續工作以微調策略讓 LLM 明確察覺知識極限：Cohen et al. (2024) 在詞表引入特殊 [IDK]（我不知道）token 讓模型直接表達不確定；R-Tuning（Zhang et al., 2024a）則調校 LLM 使其對超出參數知識的問題拒答。這些基於拒答的方法雖有助於緩解幻覺，卻多需額外微調、增加開銷並可能限制通用性。本文改提免訓練方法來辨識 LLM 的知識邊界，是可跨模型、跨任務套用的更高效替代方案。
