摘要

提出全新的網路剪枝元學習框架。它是通用框架，理論上可應用於幾乎所有類型的網路與各種剪枝方式，具備強大的通用性與遷移性。實驗顯示其在眾多熱門且具代表性的剪枝任務（含 CNN 與 Transformer）上有出色成果。不同於既有作品——要嘛靠固定手工準則粗糙地剪、要嘛用 learning to prune（每次剪枝都要專門訓練且缺通用性）——本框架能透過一個神經網路（元網路）自動學習複雜的剪枝規則，且通用到不需任何專門訓練即可剪枝。具體而言，首次把元學習的元網路概念引入剪枝：元網路是「以另一個網路為輸入、輸出一個被修改後網路」的網路。我們先在神經網路與圖之間建立雙射對應，再用 GNN 當元網路，訓練它自動學習剪枝策略、把難剪網路轉成易剪網路。元網路訓練好後，剪枝只需「一次前饋 + 標準微調」即達 SOTA。程式碼：github.com/Yewei-Liu/MetaPruning。

圖 1：對一個剪枝準則，我們用元網路把「難剪網路」改成「易剪網路」以利更好剪枝。

1. 引言

深度學習進步帶來參數與 FLOPs 暴增 → 簡化網路同時保性能的需求成長。剪枝（選擇性移除網路部分）是有效途徑。大量先前剪枝核心思路是移除不重要的組件，因此發明各種衡量組件重要性的準則：基於 norm／magnitude、基於移除後性能變化、或更複雜的 saliency／sensitivity。

有了準則就能判斷模型「易剪／難剪」：若能剪掉相當大一部分而準確率只小幅下降＝易剪；反之＝難剪。先前改進剪枝有兩路：(1)精煉準則（被廣泛研究）;(2)把模型變得更好剪（較少人做，但稀疏正則化法等取得不錯成果）。本框架繼承第二路：對任一準則，訓練一個能把難剪網路轉成易剪網路的元網路。

貢獻：（1）首次把元學習的元網路引入剪枝；（2）提出理論上可用於幾乎所有網路與各種剪枝的通用框架；（3）給出具體實作並在多任務達 SOTA；（4）進一步研究框架的彈性與通用性。

2. 相關工作

  • 2.1 元網路：用神經網路處理其他神經網路。元網路定義＝以另一網路為輸入、輸出其資訊或被修改網路。兩種視角：權重空間視角（直接對權重套設計過的 MLP，保對稱性）與圖視角（把網路轉成圖再套 GNN）。本文採圖視角，利用圖節點與層內神經元的自然對應及其對稱性。
  • 2.2 圖神經網路：採 message passing 框架，骨幹用 PNA（Principal Neighborhood Aggregation）。
  • 2.3 稀疏正則化剪枝：本質上是「鼓勵網路變稀疏以利剪枝」，本文某種程度繼承此原則（元網路＝把原網路改寫成更稀疏版本）。
  • 2.4 Learning to Prune & Meta Pruning：先前用 NN／RL 自動學剪枝策略；少數把元學習用於剪枝。本文也取元學習思想，但學習方式與所有先前作品完全不同。

3. 通用元學習框架

一句話（圖 1）：對一個剪枝準則，用元網路把難剪網路改成易剪網路以利更好剪枝。

  • 剪枝準則：衡量特定組件重要性（典型如權重向量的 norm）。剪枝時對各可剪組件算重要性分數，由低到高移除。
  • 易剪／難剪：固定準則下逐步剪，準確率快掉＝難剪；慢掉＝易剪。
  • 元網路：輸入與輸出皆為神經網路的特殊網路（一般網路輸入是影像／句子／圖）。

4. 基於圖元網路的具體實作

三大技術挑戰：（1）如何建元網路?（2）如何訓練?（3）如何設計剪枝準則?

4.1 元網路設計

  • 網路↔圖轉換（以 ResNet 為例，繼承 NGGNN／GMN 思路但實作不同）：
    • 節點＝FC 層神經元或卷積層通道。
    • 邊＝原網路中有直接連接（FC／卷積／殘差）的兩節點之間。
    • 節點特徵＝神經元相關參數，此處用 BatchNorm 的 weight/bias/running mean/var（含前一相鄰層與前一 skip 連接的 BN，若存在）。
    • 邊特徵＝連接權重；線性與殘差視為 kernel size=1 的卷積特例；兩通道間卷積攤平成定維邊特徵向量。
    • 邊特徵須等維：（1）把所有卷積核補零到同尺寸 或 （2）攤平後用學到的線性變換投影到同尺寸。
    • 池化等其他組件直接忽略（實驗顯示忽略已有出色結果）；不用位置編碼。此轉換可逆（圖可轉回等價網路）。
  • 元網路架構（基於 message passing + PNA，詳見附錄 B.1）：節點／邊特徵先編碼到同隱藏維 → 多層訊息傳遞（更新節點與邊特徵）→ 解碼回原維度 → 乘上很小的殘差係數加回原輸入（讓元網路只學 delta 權重而非完全重寫）。
    • EdgeInvertor：讓邊特徵前半維學「交換 i,j 不變」的無向特徵、後半維學「隨反轉等變」的有向資訊；經驗上最有效。

4.2 元訓練

  • 資料準備：(1)data models＝一組待剪網路當原始網路（數量可極小如 1/2/8，因實作對其不敏感）；（2）傳統訓練集（如 CIFAR-10）算準確度損失。
  • 一次迭代：選一 data model 當原始網路→轉圖→過元網路→新圖→轉回新網路→在新網路上算兩種損失→反傳更新元網路。
  • 兩種損失：(1)準確度損失＝把訓練集（注意不用測試集）餵新網路算交叉熵，確保元網路不過度破壞原網路有效部分；(2)稀疏度損失＝新網路上的正則項，促稀疏好剪（與剪枝準則設計相關）。

4.3 剪枝準則

有效準則含兩件：(1)重要性分數函數（算各可剪組件分數、由低到高剪）;(2)稀疏度損失（在參數上算的損失，優化它使網路好剪）。

  • 預設用結構化剪枝，少量做非結構化與 N:M 稀疏（後二者直接用樸素 norm 當分數函數與稀疏損失）。
  • 結構化剪枝參考 DepGraph，用 group norm（在剪枝群組層級算，比孤立看節點／邊更有效）當重要性分數；稀疏損失＝group norm 分數乘係數。準則高度彈性（見 §6.1）。

4.4 整體視角

網路過元網路前饋時，每個參數從鄰近參數與架構蒐集資訊，元網路自動學會據此改寫權重以利剪枝（圖 4）。重要性質：

  • 通用性：元網路是相對極小的 GNN，每參數只看有限局部；GNN 本質使任何位置的參數都以同方式處理鄰域資訊 → 必須學通用策略 → 解釋了為何「剪枝模型與訓練 data model 完全不同卻一樣好」「對 data model 數量不敏感」「無過擬合」（單一 data model 可視為大量資料點）。
  • 自然遷移性：如 GNN 可用於不同大小的圖，元網路可直接用於不同規模網路。
  • 通用適用性：理論上可用於幾乎所有網路與各種剪枝（幾乎所有網路可轉圖，GNN 與準則設計也廣泛相容）。
