論文／訪談原始來源

ESAA：LLM 軟體工程自主 Agent 的事件溯源架構

摘要與 1–2. 問題背景

長程 coding agent 缺少原生 state，context 會退化，且 probabilistic generation 不符合 deterministic execution 的需求。ESAA 以 Event Sourcing／CQRS 分離 agent intention 與 project mutation。Agent 只提出 validated JSON，orchestrator 才能產生 effects、events 與 read model。

現有 ReAct／multi-agent framework 強在協調，但常依賴 in-memory state 或 snapshot，缺少 immutable audit trail 與 deterministic replay。ESAA 的 source of truth 是 events，不是 repository 當下 snapshot。

3. 架構

Canonical artifacts 包括 boundary contract、activity.jsonl 與 roadmap.json。每筆 agent output 必須有 schema version、correlation／task／attempt ID、actor、action、idempotency key 與 payload。Agent 不直接寫檔；patch 經 path、authority、schema 與 idempotency validation 後由 orchestrator 套用。

Materialized view 是 event stream 的 pure projection。Canonicalization 排序 keys、正規化字串，排除序列化差異；SHA-256 projection_hash 比較 replay 結果與保存 view。

Multi-agent 以 task claim 與 phase gate 避免重複工作。Append-only store 提供 total order 與 actor attribution，agent 不需把整個歷史放進 prompt，只收到 roadmap 與相關 facts 的 purified view。

4. 方法

架構介入固定 pipeline：驗證 output、拒絕違規、由 orchestrator 寫 effect、append event、重投影 roadmap、replay 並 hash verify。公開 repo 以只含 run.init 的 clean state 供重跑。

5. 案例

Landing page 有 9 個循序 tasks、49 events，包含 specs、HTML/CSS/JS 與 QA，最後 verify_status=ok。

Clinical dashboard 有 50 tasks、15 phases、7 components 與 critical path；四 agent 分工 specification、UI/test、implementation、security/docs。15 小時產生 86 events，其中 30 claims、30 completions、17 promotions、8 phase completions、1 init。同一分鐘出現六個 claims，證明並行活動能被 log 序列化。

但分析時只完成 31/50 tasks、8/15 phases。Table 2 明確標 verify_status=ok (partial)；這是進行中 project 的可重播狀態，不是完整交付成功。

6. 結果與討論

兩案 output.rejected=0，顯示受測模型遵守 contract，但沒有 baseline 可估 failure reduction。Replay 可重建 view 並偵測 divergence。事件序列可看 agent specialization 與 phase progression。

Purified view 避免把 raw long history 放入 prompt。Boundary denial 降低 compromised agent 的 write blast radius。成本估計為每 call 200–500 tokens、每 event 低於一秒、86-event log 約 15KB。

7. 有效性威脅

兩個 controlled cases、temperature 0，不能外推 enterprise repository。Landing page／clinical POC 不涵蓋 CI、migration、monorepo。verify_status 與 output.rejected 測 compliance／reproducibility，不測 design quality、business value、coverage 或 maintainability。n=2 不支援統計結論。

8. 結論

ESAA 證明「LLM 提意圖、deterministic reducer 執行」可形成可稽核 vertical slice。未來工作包括 CLI、remote repo、concurrent file conflict、time-travel diff、SWE-bench 與 model checking。
