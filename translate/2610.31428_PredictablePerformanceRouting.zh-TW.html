論文／訪談原始來源

可預測表現的額外價值，受模型改善空間所限

第 1–2 節：與 self-confidence 比較

performance predictor 預測模型在題目上能否答對，供 routing 或 cascade 決定是否換模型。本文問其相對 self-confidence 的額外價值來自何處。self-confidence 指模型賦予自己所選答案的機率；如果它不可取得，另外的 predictor 僅重建這個訊號也可能有用。本文研究超過此基準的增益，未主張所有 routing 都無用。（§1–2、§5）

第 3.1–3.2 節：正確性預測可等量轉成答案 log loss 改善

固定題目、答案的分布，模型 f 選最大機率答案，Z 表示其正確與否。答案 loss L_Y 是 gold answer 的負對數機率期望；正確性 loss L_Z 是二元正確標記的 log loss。predictor 可讀模型輸出，須具 full support；額外可預測性為 E = L_Z(f) - L_Z(g,f)。（§3.1）

重新校準把所選答案質量改成 g(1|x)，剩餘質量按原有其他答案比例分配。在有限答案 loss、其他答案原總質量非零等條件下，命題1給出 L_Y(C_g(f)) = L_Y(f) - E。證明將答案 loss 分成正確性 loss 與答錯時的 alternative loss；後者不變，相減即得恆等式。這是 log loss 的精確轉移，不是 accuracy 必然同量提升。（§3.2、附錄 A.1；末句為本檔補註，非作者自陳）

第 3.3 節：次佳差距與新增容量

假設固定任務上每個參數預算 P 都有可達最佳答案 loss L_Y*(P)。模型類允許模型與 predictor 合成；參數含凍結權重，共享只計一次，固定算術不增參數，因此重新校準至多使用 P+Q。令 delta_P(f) = L_Y(f) - L_Y*(P)，定理1為：

E <= delta_P(f) + L_Y*(P) - L_Y*(P+Q)。

因此額外預測優勢可來自模型未達自身容量最佳值，也可來自 predictor 帶來的容量。只有超過後一容量增益，才證明自身預算下的次佳性；新增參數為零而 E 為正是其特例。（§3.3、附錄 A.1）

附錄 A.2–A.4：上界的含義

命題2把任意模型的答案 loss 也分成是否答對原模型答案、以及原模型答錯時哪個替代答案正確；若比重新校準模型更好，至少一個成分必須改善。推論1另假設 loss floor 凸，將容量增益限制為 2Q/P 乘從 P/2 到 P 的 floor 降幅；小 predictor 在此假設下的容量修正較小。（附錄 A.2–A.3）

命題3顯示次佳差距不決定最大 E：保持所選答案與 confidence，只把替代答案分布和均勻分布混合，在指定 alternative loss 條件下可降低答案 loss，卻保持各 predictor 預算下的最大 E。二元答案只有一個替代，此分離來源不存在。（附錄 A.4）

第 3.4 節：實驗設計

作者自報八家族16個 base／instruction-tuned release，規模7–12B，在 WinoGrande、CommonsenseQA、GSM8K、MMLU-Pro 評估。前兩任務以選項 likelihood 正規化，後兩者以每題128個抽樣解答估答案分布，再選最高機率答案。loss 單位為 nats。（作者自報，§3.4.1、附錄 B.1–B.2）

task-specific LoRA 用 gold answer 或 Qwen3.5-122B-A10B 的正確教師推理軌跡訓練。只保留 development accuracy 微調後提高的模型對，依任務16／16／14／13對，共59對；未用 test labels 篩選，但排除微調不改善的結果。empirical suboptimality 是相對留存群組最佳觀察答案 loss 的差，並非理論上已知的 loss floor。（作者自報，§3.4.1、附錄 B.3）

每個模型、任務、階段另訓 Qwen3-Embedding-4B predictor。輸入含題目、答案、答案分布，生成題另有一條以多數答案結尾的抽樣推理軌跡，不含 gold answer。以 Platt map 初始化 confidence logit 校正，再訓 LoRA 與 head。（作者自報，附錄 B.4）

作者自報四任務的 empirical suboptimality 與 E Pearson 相關依序0.98／0.98／0.93／0.65。微調後59對的答案 loss 均降，E 在55對下降；Llama-3.1-8B 的 CommonsenseQA 軌跡中由0.107降到0.004 nats。這些是觀察關係，上界不保證每個模型皆如此。（作者自報，§3.4.2，圖1–3）

第 4.1–4.2 節及附錄 A.5–A.7：cascade 上界

弱模型先回答，router 升級分數最高的 rho 比例給強模型；confidence routing 則升級 confidence 最低者，兩者升級率相同。令決策差為 u，完整 accuracy 增益等於額外捕捉弱錯誤減額外遇到強錯誤。多抓弱錯誤、避開強錯誤都可能有用。（§4.1）

引理1沿 u 校正弱模型 error logit，以二元 log loss 曲率上界證明：多抓弱錯誤就能選校正強度使 correctness loss 改善。定理2再結合容量 floor 與同升級率的決策差範圍，得到額外弱錯誤捕捉上界：

sqrt(min(rho,1-rho) * [delta_P1(f1) + L_Y*(P1) - L_Y*(P1+Q+2)])。

合成新增容量包含 router 的 Q 及升級率、校正強度兩個參數。推論2只有在額外強錯誤項非負時，才把同一上界套到完整 cascade 優勢。（§4.2、附錄 A.5–A.7）

第 4.3 節及附錄 B.5、C：排序與實際增益

正斜率 Platt 校準可降 correctness loss 但不改排序，故固定升級率下不改 routing。實驗用4B predictor 與 confidence 比較，強模型為 Qwen3.5-122B-A10B，前兩任務微調，後兩任務用 released 版。報告的 100D 是同升級率 accuracy 差跨所有升級率積分，單位百分點，不是某固定預算的成績。（作者自報，§4.3、附錄 B.5）

作者自報微調後 routing 優勢在53／59對下降；四任務平均由1.38→0.18、1.09→0.18、0.52→0.20、0.94→0.07百分點。118個留存版本中91個的強錯誤項跨升級率平均後非負，不代表每一升級率均非負。（作者自報，附錄 C.5，表8）

附錄 C 另分 released／微調群、比較 predictor 容量及完整 cascade 曲線。作者自報0.6B predictor 超過校準的價值小，部分跨模型相關為負；4B、8B通常捕捉更多。相關檢定假設獨立觀察，未調整多重比較。（作者自報，附錄 C.1–C.4）

第 5 節：結論與局限

作者認為改善底層模型可減少額外 predictor 的需求，但理論是上界，不保證每次答案 loss 改善皆縮小預測優勢；完整 routing 優勢還需考慮強模型錯誤。當 self-confidence 不可取得，恢復它仍有價值。（§5）

（本檔補註，非作者自陳）生成題 confidence 需大量樣本、predictor 也讀模型作答後資訊，不能把本實驗直接當作未執行模型前的零成本 query-only routing；留存規則亦限制微調結論的適用範圍。（依據§3.4.1、附錄 B.2–B.4）
