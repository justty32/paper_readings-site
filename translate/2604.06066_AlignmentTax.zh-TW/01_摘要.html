摘要

大型語言模型（LLM）的內在自我修正在開放式推理任務中經常失敗，原因在於「幻覺雪崩」——模型在自由文本反思中會遞迴地為早期錯誤編造辯護。雖然結構化反饋可以緩解此問題，但現有方法多依賴外部訓練的批判者或符號工具，降低了 agent 的自主性。本研究探討能否純粹透過 Outlines 約束解碼來強制結構化反思、在不增加訓練的前提下打斷錯誤傳播。在 Qwen3-8B（80 億參數）上的實驗顯示：僅施加結構約束並未改善自我修正效能，反而觸發了一種新的失效模式——「結構雪崩」（structure snowballing）。滿足嚴格格式規則所需的認知負荷，將模型推入格式陷阱：agent 實現了近乎完美的表層語法對齊，卻完全無法偵測或解決深層語意錯誤。這些發現揭露了約束解碼內在的**「對齊稅」（alignment tax）**，凸顯自主工作流中結構粒度與模型內在能力之間的張力。

1. 引言

Reflexion 框架奠定了「語言強化學習」的基礎：agent 在任務失敗後生成自然語言反思、存入情節記憶、並在後續嘗試中調整行為，在具有明確外部接地的環境（如程式碼生成）中成效良好。然而研究人員發現內在自我修正有顯著局限：缺乏外部驗證訊號時，LLM 常無法可靠修正推理錯誤，甚至自我修正後整體效能反而下降。Zhang et al.（2023）指出關鍵機制是幻覺雪崩——在自由文本反思中，模型傾向為早期錯誤生成自洽但虛假的解釋，將原始錯誤固化進推理鏈而非解決它。

結構化反饋是潛在解法。REFINER 框架用外部訓練的批判者提供型別化、格式化反饋，顯著改善推理效能。但這些方法高度依賴外部工具、獨立訓練的批判模組或符號求解器，削弱了 LLM 內在自我修正的自主性。一個關鍵缺口是：能否純粹在生成時透過文法約束解碼來強制結構化反饋格式，完全不依賴外部訓練或工具？

為此本研究探討三個問題：(1) 用文法約束解碼強制結構化反思，能否獨立打斷幻覺雪崩並提升開放推理任務的自我修正成功率？(2) 在嚴格結構約束下進行內在反思時，錯誤傳播機制如何改變？(3) 自我修正過程中，模型內在能力與結構約束粒度之間是否存在張力？

答案出乎預期：僅引入結構約束不提升效能，反而引入新弱點——結構雪崩。約束解碼雖成功抑制了發散的語意幻覺，卻迫使模型陷入格式陷阱與死亡迴圈。Qwen3-8B 這類小模型耗費大量認知努力來滿足嚴格的分類與語法規則，結果表面語法對齊完美，深層語意錯誤卻全部被忽略。

本文三項貢獻：(1) 實證顯示，在無外部訓練下部署內在結構化自我修正，會引入對齊稅；(2) 將結構雪崩定義為幻覺雪崩的理論對偶，揭示受約束自我推理的新失效模式；(3) 探索在小型開源模型上部署複雜 agent 邏輯的實務邊界。

2. 相關工作

2.1 自我修正

Reflexion 引入語言強化學習，Self-Refine 用迭代反饋循環改進初始輸出。但研究指出內在自我修正的根本瓶頸在於錯誤偵測而非錯誤修正：模型幾乎找不到自己推理鏈中的錯誤。將自我修正分解為錯誤偵測、定位、修正三步後，證據顯示未引導的模型難以準確定位推理過程哪裡出了問題，凸顯反思階段需要明確引導。

2.2 推理中的結構化反饋

為模型提供結構化、具體的反饋，能解決通用自然語言反思的不足。REFINER 證明半結構化反饋（明確標示錯誤類型與位置）比自由文本或標量獎勵更顯著改善中間推理步驟。ROSCOE 提供逐步推理評估的分類法，定義了邏輯不一致、缺失步驟、幻覺等具體錯誤型別。然而目前生成結構化反饋的方法計算成本高昂：REFINER 需要用標註資料集訓練獨立批判模型。這留下一個研究缺口：如何在推論期生成可靠的結構化反饋，而不需要監督微調或外部模型依賴的成本。

2.3 約束解碼

約束解碼提供了無需額外訓練即可強制結構化輸出的工程解方。Outlines 基於有限狀態機（FSM）引導文本生成：對詞彙表建構索引，保證輸出嚴格符合預定義的正則表達式或上下文無關文法。此方法與模型無關，且對 token 生成過程增加的計算開銷極小。透過 Outlines 施加硬約束，開發者可將格式要求從訓練層移到解碼層，據稱可減輕小模型的認知負荷——強制模型將錯誤診斷歸入特定類別，填補了結構化推理反饋需求與訓練專用批判模型高成本之間的缺口。

3. 方法

3.1 多跳推理錯誤的 4+1 分類法

為系統評估與修正多跳推理中的失敗，作者提出 4+1 錯誤分類法。前四類代表認知與推理失敗，最後一類處理格式對齊：

  1. RETRIEVAL_FOCUS：模型最初找錯了段落或句子。
  2. BRIDGE_FAILURE：模型找到了正確的初始資訊，但未能提取必要的橋接實體以過渡到下一個推理步驟。
  3. HALLUCINATION：模型生成了給定上下文中不存在的事實或細節。
  4. INFERENCE_ERROR：模型成功定位資訊，但犯了邏輯推導或算術計算錯誤。
  5. FORMATTING_MISMATCH：模型推導出正確結論，但未能以要求的格式約束輸出。

這些類別對應一個資訊流漏斗：處理資訊→連結實體→尊重知識邊界→執行邏輯推導→格式化回應。此流程確保錯誤類別互斥且窮盡。分類法限制為五類是刻意的設計選擇，在診斷粒度與模型能力間取得平衡——ROSCOE 定義了多達十種細粒度錯誤，但在有限上下文長度下，同時呈現大量錯誤類型會加重模型負擔、降低反饋品質。

3.2 上游優先歸因策略

LLM 的推理失敗很少孤立發生。早期生成階段的初始錯誤常觸發一連串後續錯誤。為此作者實作了上游優先歸因策略：當推理軌跡失敗時，反射器只需識別並分類序列中第一個致命錯誤。這呼應 Zhang et al.（2023）打斷幻覺雪崩的策略——模型天生傾向固守早期選擇，若早期犯錯，模型常會過度堅持、並為初始錯誤生成後續幻覺或缺陷邏輯來辯護。修正下游邏輯錯誤而不處理上游檢索失敗，是無效的。此策略也直接對齊 BIG-Bench Mistake 資料集的標註原則：每條生成軌跡標註第一個邏輯錯誤，後續錯誤因依賴於原始錯誤而被忽略。

3.3 透過約束解碼的邏輯引導反思

作者建構了一個三元架構：Actor（演員，生成推理軌跡）、Evaluator（評估者，對照標準答案給出二元獎勵訊號）、Reflector（反射器，基於失敗軌跡與儲存先前修正規則的情節記憶 M 診斷錯誤根因）。

傳統自我修正要嘛依賴自由文本反思，要嘛需訓練昂貴的專用批判模型。為在無微調成本下達成高品質結構化反饋，作者以約束解碼實作邏輯引導反思：不使用 prompt engineering 強制格式，而是用 Outlines 將預定義的 Pydantic schema（5 類錯誤型別＋字串 Correction_Rule）轉譯為有限狀態機。從機器學習機制看，此 FSM 在自迴歸解碼過程中直接作用於 logits 層：每個時間步計算未歸一化的條件分佈時，施加一個動態布林遮罩，將原始下一個 token 分佈的支持域限制為僅允許的 token——嚴格將違反 JSON 語法或超出預定義分類枚舉的任何 token 機率歸零。因此數學上保證 100% schema 遵循與格式合規，讓現成的 8B 模型可靠執行目標化、結構化的錯誤歸因，媲美微調過的批判模型。反射器成功生成有效結構化輸出後，該 JSON 字串被追加到情節記憶中，作為 Actor 下一次嘗試的診斷上下文，封閉迴路、防止重複已識別的邏輯失誤。
