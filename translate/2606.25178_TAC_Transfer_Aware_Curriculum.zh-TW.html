論文／訪談原始來源

TAC：多領域 RLVR 的自動課程

摘要

RLVR（可驗證 reward 的 RL）已從單領域擴到橫跨數學、程式、科學的多領域推理套件。但訓練課程（每個領域多常被取樣）通常固定或手調，儘管推理技能跨領域遷移不均。本文提出 Transfer-Aware Curriculum（TAC），一個 bandit 式線上課程，優先取樣「更新能廣泛嘉惠其餘訓練套件」的領域。TAC 重用 RL 訓練已產出的訊號：per-domain advantage 抓局部 learnability、投影梯度（取自正在算的 GRPO step）用梯度幾何對齊估跨領域 transferability，成本可忽略（<1% wall-clock）。在六領域推理套件上，TAC 於 Qwen3-1.7B 與 Llama3.2-3B 都拿最佳 macro 平均準確率，勝過 proportional random sampling、手設計排程與 learnability-only bandit，比最後者最多改善 2.8 分（相對 10%）。消融顯示移除 transferability 項表現急遽下降，且 TAC 在不平衡訓練混合上仍穩健（learnability-only 課程會過度投注主導領域）。我們的發現把跨領域 transferability 確立為多領域 RLVR 課程設計的關鍵訊號。

1. 引言

RLVR 在「正確性可自動檢查」的 benchmark 上帶來大幅推理增益，並從單領域擴到多領域套件。但建強多領域推理者不只是「把各領域資料池在一起」：推理訓練跨領域遷移不均。我們在自己的設定也觀察到（Fig 1a）：在不同單領域 RL 訓練，對其餘領域的 transfer profile 差異顯著——同樣預算下，table → simulation +14.6 個百分點，但 math → simulation 只 +5.0。

既有方法多在 optimization/loss 層介入（per-domain 梯度對齊、per-task loss reweighting），對「每一步該取樣哪個領域、且該如何依跨領域 transferability 決定」關注極少。既有 RL 課程優先取「on-policy advantage 或 reward variance 高」的領域——告訴你 policy 現在能從哪個領域學，卻不問「在該領域走一步是否也嘉惠其餘訓練領域」。一個高 learnability 的領域可能範圍狹窄、增益不遷移；一個不那麼明顯可學的領域可能更新方向廣泛改善 policy。對跨領域遷移盲目的課程會過度投注於局部豐富但全域狹窄的領域，把可達的跨領域改善留在桌上。

TAC 把跨領域 transferability 當領域選擇的一等訊號。Fig 1a 預示：均勻取樣（Random）已勝任何單 source 課程，TAC 在六領域全面再拉開。兩訊號在實務上分道揚鑣：最可學的領域常不是最可遷移的;math（RLVR 最倚賴）在本套件中最不可遷移之一，TAC 正確下調其權重。

2. 背景

  • 多領域 RL for reasoning;GRPO（Group Relative Policy Optimization）;課程作為 multi-armed bandit——把領域選擇當 bandit arm。

3. 方法

  • 3.2 Gradient-Based Transferability：用正在計算的 GRPO step 的投影梯度，透過梯度幾何（cosine）對齊估「某領域的更新是否與其他領域的更新方向一致」。
  • pairwise transferability：用領域對之間的梯度 cosine 刻畫遷移結構。
  • 3.3 課程訊號與演算法：每個 arm（領域）分數 = learnability（per-domain advantage）+ β · transferability（梯度 cosine），單一係數 β 混合。優先取分數高（更新廣泛嘉惠他者）的領域。所有訊號重用 GRPO 已算出的量，額外開銷 <1% wall-clock。

4. 實驗

  • baseline：proportional random sampling、手設計排程、learnability-only bandit。模型 Qwen3-1.7B、Llama3.2-3B。
  • 主結果：TAC 兩模型都拿最佳 macro 平均準確率，比 learnability-only 最多 +2.8 分（相對 10%）。
  • 課程動態：TAC 適應、SEC 錨定——TAC 隨訓練調整取樣；SEC（對照）錨定不動。
  • learnability 與 transferability 偏好不同領域：最可學 ≠ 最可遷移；math 被 TAC 正確下調。
  • 消融：移除 transferability 項表現急遽下降 → 是關鍵；TAC 在不平衡訓練混合上穩健，learnability-only 會過度投注主導領域。

6. 結論

TAC 引入跨領域 transferability 作為多領域 RLVR 課程的一等訊號，重用既有 RL 訓練訊號、近零成本地優先取樣「廣泛嘉惠他領域」的領域，在兩個小模型上拿最佳 macro 準確率。限制（Limitations 章）：六領域、兩個小模型上驗證，更大規模待驗；transferability 用一階梯度 cosine 近似局部幾何對齊；β 需設定。
