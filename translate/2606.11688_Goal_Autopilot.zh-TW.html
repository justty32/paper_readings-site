Goal-Autopilot：無人長程 Agent 的可驗證防捏造防火牆

依官方 arXiv TeX 原文作精要逐節翻譯，保留定理假設、完整 verdict 分布及作者承認的負結果。

摘要

長程 agent 會在 context 漂移、tool failure 或 restart 後，回報從未驗證的成功。本文把 honesty 定義為限制 agent 在 termination 時可宣稱之事，提出 Goal-Autopilot：先把 goal 編譯成有可執行 gates 的 state machine，再由 stateless ticks 執行。只有實際執行且為 true 的 gate 能前往 DONE；最壞情況是 honest stall。

3,150-cell paired corpus 上，Autopilot fabrication 0.95%，Reflexion 8.10%，StateFlow 25.05%。SWE-bench Lite 上，StateFlow 33.73% 降至 Autopilot 0.67%。這個 firewall 以 coverage 換 honesty；stall 可恢復，捏造成功則會污染下游。

1. 導論

checkpoint、workflow graph、reflection 或 model confidence 都不能保證 terminal success claim 為真。Autopilot 將工作分解為 states，每個 state 有 falsifiable executable predicate；agent 的信心不進入成功判定。

貢獻包括：條件式 no-false-success theorem；framework-neutral reference implementation；測 fabrication、honest stall 與 verified completion 的 paired benchmark。

2. 相關工作

過往 long-horizon 方法著重記憶、恢復、反思、狀態化控制與 context efficiency。selective prediction 讓低信心模型 abstain，但仍信任 confidence calibration。Autopilot 不問模型有多確定，而要求 external check 真正執行。它針對的是 termination-time false success，不等同解決一般 hallucination、規劃錯誤或 tool misuse。

3. 方法

S=(goal, states, cursor, phase, async, attempts, history, definition-of-done) 是整次 run 的 durable memory。每 state 含 gate、known fixes 與 retry bound；graph 的唯一 success sink 是 DONE。每次變動都 atomic write 並 commit 到 version control。

每個 stateless tick：讀 S；處理 async job 或 cursor state；做一單位工作；實際執行 gate 並記錄 literal result；true 才 advance，否則做可逆、資訊量高的修復並重試；最後持久化。fresh session 只 rehydrate S，因此 per-tick context 對 horizon T 為常數 O(|S|)，總成本 O(|S|T)，相較攜帶完整 trajectory 的 O(T²)。

goal compiler 只呼叫一次 LLM，把 goal 分解成 dependency-ordered states 與 gates，並自查 gate 是否 executable、DONE 是否 reachable、transition target 是否存在。compiler 的自查是 A3 的建構來源，但不能保證語義完整。

4. No-False-Success 形式化

A1：check_s()=true ⇒ g_s；允許 false negative。A2：只有實際執行並通過 gate 的 path 能設 DONE。A3：accepting path 的所有 g_s 合取蘊含真正 goal G。若 A1∧A2∧A3，則 DONE 必然蘊含 G：A2 給出所有通過 checks，A1 推得 predicates，A3 推得 goal。

gate 不完整只會讓已完成工作被判 stall，不能產生 false success。這是保守錯誤方向。保證的信任不在 model confidence，而在 gate soundness 與 plan coverage；A2 是 tick code invariant。

5. 系統

reference stack 使用 generic process supervisor、任意 headless agent CLI、git 下的 JSON state；具體用了 pm2，但設計不綁框架。scheduler 定時 spawn fresh worker，crash/reboot 後重啟；長操作放 background，後續 ticks poll。

作者稱 atomic state write 與 externalized state 使 tick idempotent/crash-safe。不過這項敘述主要覆蓋 S 本身；外部工具 action 是否可重複、是否有 side effects，仍需 gate、tool protocol 或 idempotency 個別處理。

6. 初步實證評估

corpus 含 20 trap + 50 SWE-bench Lite tasks，11 repositories；Autopilot、Reflexion、StateFlow × 三個 models × 五 seeds，共 3,150 cells、1,050 paired triples。每 cell 600 秒，ensemble auditor 先 static、再 LLM judge，bootstrap 5,000 次。

總體 verdict：Autopilot 85 true、10 fabrication、928 stall、32 undetermined，fab 0.95% [0.38,1.62]；Reflexion 92/85/674/199，8.10%；StateFlow 293/263/488/6，25.05%。Autopilot 相對 StateFlow −24.10 pp，相對 Reflexion −7.14 pp。

trap 300 paired units 上差異不顯著：1.67%、2.67%、3.33%。SWE-bench Lite 750 units 上則是 0.67%、10.27%、33.73%，Autopilot–StateFlow 為 −33.07 pp。但 Autopilot 在 SWE-bench 的 true success 是 0%；750 cases 成為 745 honest stalls 與 5 fabrications。

按模型看，最強 F2 在 Autopilot/Reflexion/StateFlow 為 2.86%/22.29%/64.57%；M1 為 0/1.14/4.00%；M2 為 0/0.86/6.57%。所有 10 個 Autopilot fab 都來自 F2。928 stalls 中，866 在任何 action 前因 failed-A3-audit，43 timeout，19 harness artifacts。

首輪 baseline 曾因 driver 不接受 flag 且無 output，被 oracle 全判 fabrication，得到不合理 100%；作者移除 flag、加入 explicit abstain，重跑全部 2,100 baseline cells。正式數字為重跑後結果。

7. 限制

定理是條件式：A1/A2 可測 code path，但 A1 的 predicate-grounding 與 A3 的語義 coverage 仍是 trust points。auditor 主要檢查 goal-text requirement tokens，不能證明語義等價；誤導性 goal 可能讓 tokens 都出現而 plan 仍錯。

trap regime 的 CI 穿過零，不能宣稱普遍改善。35-cell pilot 中 auditor 7 次 over-fire，擋住原可通過 oracle 的 artifact。scaled SWE-bench 上 0% true success，顯示保守政策犧牲所有有效 coverage。模型使用 tier 名稱而非公開型號，也限制外部比較。

8. 結論與可重現性

Autopilot 將 success claim 變成由 executed verification gates 控制的能力，而不是模型可自由生成的文字。在其 corpus 上 fabrication 從 StateFlow 25.05% 降至 0.95%。最嚴謹的解讀是：在 gate soundness、floor enforcement、plan coverage 成立時，可排除 false DONE；現有 auditor 大幅降低但沒有消除 A3 risk。部署時應把大量 STALL 視為需要明確排隊與升級的正常結果。
