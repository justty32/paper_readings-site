論文／訪談原始來源

The LLM Proposes, the Executive Disposes

摘要與第 1 節：問題

長 horizon agent 的 self-report 本身不可信，傳統 drift 分數又把不同失效混在一起。作者設計的不是事後 verifier，而是 verification 成為 agent 的底層：belief 要靠預先承諾的 prediction 與環境觀測比對才取得。本文明說 task efficacy 為零；貢獻限於驗證方法與它可量出的 drift 分解。

作者區分 binding drift：目標與 referent 都存在但連結掉失；以及 commitment drift：目標後來根本不在 context。兩者應有不同修復。

第 2 節：驗證架構

LLM 的 Observer、Surveyor、Actuator 只可送出 closed-vocabulary 的 typed proposals。deterministic Executive 擁有所有狀態變更與 belief。referent 的提升由機器檢查：名稱文字不夠，須先由 raw observation 的 salience-blind extraction 錨定，再有 action receipt，最後要被經測試規則引用。append-only log 使身分與後果可重播。

join J 將 active goal 與 canonical referent 固定位置預先接合；agenda A 是程式執行的外部 commitment store。兩者各由一個環境旗標關閉，其餘 scaffold 相同。

第 3 節：驗證量測

任一 organ 的 typed rejection ratio 過高、render 超 token 上限、或各 prompt zone 的 salted-canary echo 低於門檻，run 即自行失效且不納入 attribution。作者稱最初八個架構 run 有四個被此機制剔除。

在 A 被刪除時，已無 live plan，原本無法計算 drift。因此 shadow path 對相同 store 純讀編譯「完整系統本會提交」的 plan，不 render、也不執行；byte-identity test 確認它不影響行為。每個 reference beat 依計畫動作與目標，分類為 bind、aligned 或 abandon。

第 4 節：作者報告的 dissociation

在一個遊戲的三 seed/cell protocol 中，關掉 agenda 將 abandonment 由 0.00 推到 1.00，binding score 維持 0.00；但 A0 有一個 seed 沒有可用 feedstock，drift 為 undefined，不能算成零。FULL 與僅關 J 仍是 0.00 abandonment。作者將其解讀為 commitment 的單變量效果。

J 的消融沒有顯現 binding score，因 aimed action 的落點、containment 與 receipt attribution 已由 Executive 程式決定；作者稱這是 binding failure 被結構吸收，而不是修復無效。雙重關閉時 hypothesis formation 下降，故某些 drift 值是 undefined，不應寫成零。

第 5 節：效能負結果

**所有 52 個 gated ARC-AGI-3 run，包含 baseline，均為零完成、零分。**作者預先將約零勝場設成效能主張的 defeater；因此機制指標不構成解題效能。小型 backbone 可在 worked examples 後滿足 typed contract，但這只說明迴路能跑，不代表能解關卡。

第 6–8 節：邊界與結論

作者把 grounding 限為相對形式 micro-world 的 causal-informational grounding。限制包括：commitment 結果只在一遊戲、完整多遊戲多 seed protocol 未完成；雙消融的 drift 無定義；closed vocabulary 可能不足；可被鑽的 milestone 與高 run variance。結論是先辨別 drift 的機械來源，才談修復。
