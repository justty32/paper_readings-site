論文／訪談原始來源

Plan Right, Then Plan Tight: Symbolic RL for Efficient Embodied Reasoning

摘要與第 1 節：問題

具身任務規劃要把自然語言指令和場景狀態轉成可執行動作序列。LLM 規劃器雖能寫出流暢步驟，常沒有便宜而確定的世界內有效性檢查；高擬真模擬器可驗證，卻太慢，無法當 RL 內迴圈訊號。作者要在不靠字串比對或完整模擬下，得到可驗證的資料、評估和密集獎勵，並防止過早壓縮損害正確性。

SymPlan 將 BDDL 作為共用介面。BDDL 記錄帶型別物件、初始述詞及目標述詞，比自由文字可檢查，又比低階軌跡抽象。本文定位於高階規劃腦；低階 VLA 或技能控制器仍負責把短子目標變成馬達動作。

第 3.1 節：資料建構與動作發現

策展好的 BDDL 可直接用；若只有影片和任務描述，parser 先找出任務物件與關鍵影格，推得初始和目標述詞，再由 LLM verifier 檢查語法、物件一致性、述詞可行性及目標可執行性。通過者會正規化成 extended BDDL，加入場景干擾物，並改寫成含場景、機器人身體、短澄清對話、目標步驟和可執行程式碼的規劃樣本。

若新目標述詞不在動作集合裡，automatic action builder 會提出並編譯缺少的可呼叫動作。冷啟動 SFT 以 Gemma-4-31B-IT 為教師，對每個 prompt 採樣多個回答，只保留 Strict-Pass 的最短軌跡，沒有通過者就排除，得到 RL 的 D-SFT 初始化。資料、動作庫和訓練目標因此同受 BDDL 約束。

第 3.2 節：符號驗證引擎

引擎依 BDDL 初始狀態逐步執行生成計畫。每步先查前置條件；成立才套用預定效果，違反則記錄錯誤但繼續，以取得完整診斷。它回傳目標完成率 GCR、錯誤集合、Engine-Pass 與 Strict-Pass。前者只要求所有目標達成，即使過程有非法動作；後者還要求零錯誤。於是「最後碰巧達目標」和真正可執行的計畫不會混在一起。引擎以毫秒級延遲取代昂貴模擬作為訓練內迴圈回饋。

第 3.3、3.4 節：符號 RL 與壓縮

D-SFT 是 RL 唯一初始化。作者以 DAPO 將格式、答案、長度獎勵相加；答案獎勵同看連續 GCR、前置條件錯誤懲罰與 Engine-Pass 獎勵，區分部分完成、非法但目標完成、嚴格成功三種回答。

壓縮只在正確性穩定後才開啟：非 Strict-Pass，或本批通過率低於歷史最佳率減容忍值時，長度獎勵為零。GroupAdapt 再取同批 group pass rate 當零成本難度訊號，困難題先獲較寬的長度容忍，通過率變好後自動收緊。作者自報預設為 group size 8、閾值 0.5，容易題容忍 200 tokens、困難題 400 tokens；每題長度參考只由 Strict-Pass 回答線上更新。

第 4 節：實驗（作者自報）

**設定。**作者自報在 B-100 與 B-1000 評估。B-100 有 100 個任務和 200 個單臂／雙臂配對 episode；B-1000 保留 97 個任務、194 個 episode 作測試與 RL 驗證，訓練池經擾動擴增為 2117 個 episode。主指標為 Strict-Pass，另報 Engine-Pass、GCR、輸出長度；RL 結果以 3 個解碼種子平均，baseline 為單次抽樣。

**主結果。**作者自報 B-1000 的 Strict-Pass：原始 Qwen3-8B 為 77.3，D-SFT 為 92.3，D-SFT 加 DAPO 為 96.2，完整 Short-RL 加 GroupAdapt 為 97.3；完整配置的 Engine-Pass 為 97.3、GCR 為 99.39、錯誤率為 0.2。B-100 上完整配置為 94.0，低於 Short-RL 的 95.2，故 GroupAdapt 並非每個資料集都必然提高最終精度。

**長度消融。**作者自報未做長度調適的 DAPO 在 B-1000／B-100 輸出 999／1253 tokens；Short-RL 為 194／242 tokens，Strict-Pass 為 96.9／95.2。預設 GroupAdapt 閾值 0.5 為 207／251 tokens，Strict-Pass 為 97.3／94.0；閾值 0.75 為 217／255 tokens，Strict-Pass 為 97.6／95.5。較高閾值使更多尚不穩定題目暫留寬預算；作者仍採 0.5，理由是訓練軌跡較平衡。

第 5 節：結論與局限

同一 verifier 同時建資料、執行計畫、過濾 SFT 軌跡、供給 RL 獎勵和延後壓縮，是 SymPlan 的核心。作者自報完整 8B 在 B-1000 達 97.3 Strict-Pass，相對 Qwen3-8B 的 77.3 提升 25.9％，且輸出壓至 207 tokens，較 baseline 少 79％；這些只是在固定 prompt、符號引擎和本研究協定下的結果。

模型仍只做抽象規劃，不學低階操控技能；真實部署需要由多視角感知即時、穩健建出場景 BDDL；主實驗固定使用 Guided prompt，其他 prompt 對較強模型可能更好。因此結果不能直接當作機器人控制成功率，也未排除 prompt 選擇的影響。
