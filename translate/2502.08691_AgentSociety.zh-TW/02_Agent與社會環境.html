3. LLM 驅動的社會生成式 Agent

3.1 概觀

每個 agent 有相對穩定的 profile，以及持續變動的 status。profile 包含人口資料與人格；status 包含心理狀態、經濟狀況與社會關係。心理過程分為情緒、需求與認知。行為則明確建模移動、社交、工作與消費，睡眠等簡單行為交由 LLM 處理。所有行為都由 profile、status 與心理狀態共同決定。

3.2 情緒、需求與認知

情緒是最即時的反應。agent 選一個描述當前狀態的關鍵字、生成相關想法，再對悲傷、喜悅、恐懼、厭惡、憤怒、驚訝六種情緒給 0–10 強度。互動與環境事件會更新情緒，情緒也會影響後續語氣、動機與判斷。

需求依 Maslow 式階層排列，從生存到成長。需求優先級受主動行為、被動外部事件與心理狀態更新。依計畫行為理論，agent 針對高優先需求形成計畫，使短暫情緒不致完全打斷較長期目標。

認知涵蓋推理、規劃與決策。agent 以句子描述行動與情境，再更新對特定議題的態度及情緒；態度用 0–10 表示支持或反對。三個模組形成循環：需求引出社交計畫，情緒改變訊息語氣，互動結果再更新情緒、態度與需求。

3.3 移動

移動採「需求 → 計畫 → 行為序列」。系統先抽取移動意圖，再選 POI 類型，依年齡、體力、天氣與交通決定半徑，最後用重力模型按地點吸引力與距離衰減抽樣。LLM 決定目的，數學模型負責空間選擇，降低計算成本並保留人類常見的近距離偏好。

3.4 社交

社交模組包含關係與訊息行為。關係分家人、朋友、同事，強度為 0–100；關係類型、強度與歷史紀錄影響對象、頻率與語氣。agent 依需求選互動者，也會參考對方專長。訊息內容由意圖、信念和情緒決定；收到訊息後，關係、歷史與當前情緒共同決定回應。現版主要模擬線上訊息，離線互動仍是後續工作。

3.5 經濟

經濟行為集中於工作與消費。工作傾向決定工時及月收入，消費傾向決定預算，agent 再選擇地點與商品。上月消費、價格、稅率等會改變決策。勞動市場中的換職、失業、債務與投資尚未完整納入。

3.6 記憶與工作流

記憶分三部分。Profile 存固定屬性；Status 以 key-value 存需求、滿意度、財務等動態狀態；Stream Memory 沿時間保存 Event Flow 與 Perception Flow。每個節點含時間、地點與描述。Event Flow 記主動行為、外部事件及環境變化；Perception Flow 記 agent 對一或多個事件的想法、態度與情緒。

每輪先依 status 決定行動，再接收環境回饋；事件與感知寫入兩條記憶流；情緒及認知模組分析結果並更新狀態。被動事件也走同一流程。這套顯式循環讓過去經驗、當前需求與外部限制共同影響下一步。

4. 真實世界社會環境

作者不讓 LLM 自行幻想物理與經濟規律，而把專家知識固化成程式環境。環境分城市、社交、經濟三個空間，提供狀態、成本與行為回饋。

城市空間以 OpenStreetMap 路網、AOI 與 SafeGraph POI 建立靜態層；動態層以離散時間模擬位置、速度與加速度。開車使用 IDM 加速與 MOBIL 換道，行人遵守號誌，公車依時刻表，計程車由全域系統派最近空車。API 可初始化位置、下達行程、重設模擬並查詢即時狀態。

社交空間保存可變的關係網路，支援線上訊息與依空間鄰近發生的離線互動。supervisor 在送出前檢查訊息，可依規則過濾內容、封鎖使用者或切斷連結，用於研究平台治理。

經濟空間包含 agent、公司、政府、銀行與統計局。公司用勞動生產商品、支付薪資，依供需調整工資與價格；政府課所得稅；銀行依 Taylor rule 調整利率並支付存款利息；統計局彙整 GDP、工時與人均消費。商品競爭、完整供需衝擊、失業與勞資談判仍被簡化。
