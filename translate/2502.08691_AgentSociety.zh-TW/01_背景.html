摘要

生成式社會科學以由下而上的模擬，取代成本高、執行困難的部分傳統社會實驗。本文提出 AgentSociety，整合 LLM 社會 agent、較真實的社會環境與大規模模擬引擎。作者為超過 10,000 個 agent 生成社會生活，模擬約 500 萬次 agent-agent 與 agent-environment 互動，並研究極化、煽動訊息傳播、全民基本收入、颶風外部衝擊與都市永續。模擬結果與若干真實實驗方向一致，顯示它作為社會科學測試台的潛力。

1. 引言

計算社會科學常分成解釋與預測。生成式社會科學再加上一個要求：若能由個體規則與互動生成觀察到的群體現象，才算理解機制。傳統 agent-based modeling 多用規則、方程式或小型模型，難以產生自然語言、複雜決策與社會互動。LLM 能推理、學習、決策，也能推測他人意圖，因此成為更像人的 agent 核心。

個體能力仍不足以形成社會人。自我、規範與集體現象要在 agent 間及 agent 與環境的長期互動中形成；規模也會改變湧現結果。AgentSociety 因此同時設計心理與行為、城市／社交／經濟環境，以及分散式互動引擎。論文報告的規模為 10,000 agent，每人每天平均約 500 次互動。

2. 設計概觀與相關工作

作者以三個維度比較社會模擬器。第一是 agent 是否有角色 profile、心理狀態與社會智慧，以及移動、經濟、社交和自由行為。第二是心理狀態如何驅動行為，以及環境能否提供客觀回饋。第三是引擎支援的 agent 規模及是否能進行訪談、問卷與干預。

既有平台或偏向任務協作，或只模擬社會生活的一個面向；環境可能只是靜態資料、LLM 文字世界或簡化遊戲。AgentSociety 的主張是把多領域心理與行為理論、三種客觀環境、萬級 agent 引擎與社會實驗工具放入同一系統。
