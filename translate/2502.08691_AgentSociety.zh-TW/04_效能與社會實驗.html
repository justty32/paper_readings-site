6. 效能評估

實驗使用 Huawei Cloud 64-core 機器與 DeepSeek-V3 API，安排在服務離峰時段，以減少外部限流。

城市環境以 1,000、10,000、100,000、1,000,000 個模擬個體測試。每步平均耗時分別為 0.008578、0.009129、0.01800、0.1680 秒。這只評估環境模擬器，不代表同規模 LLM agent 已完成推理。

訊息測試設 100,000 agent，每人傳 10 則 100-byte 訊息。MQTT 最佳為 44,702.1±111.3 msg/s，Redis Pub/Sub 為 81,216.2±333.6，RabbitMQ 為 23,667.3±1,777.7。Kafka 五分鐘內未完成初始化。作者選 MQTT 不是因為最快，而是效能超過估算需求，且附管理 GUI。

完整 agent 測試使用 1,000 與 10,000 agent。10,000 agent 下，8、16、32 groups 每輪平均為 5681.18、1422.48、458.82 秒；環境呼叫僅約 30–34 ms，LLM API 是主要瓶頸。平行數增加也會遭遇外部 API 負載波動，因此更大規模可能需要昂貴但可控的私有推論服務。

7. 社會實驗

7.1 一日生活

24 小時案例展示需求如何形成計畫，再產生通勤、工作、消費、社交、休閒與睡眠。每個 agent 每日平均有 491.68 次互動：城市讀取 465.67、城市寫入 4.27、經濟讀取 9.26、經濟寫入 3.30、社交訊息 9.08。

7.2 極化

控制組自由討論槍枝管制，39% 變更極化、33% 變溫和。同溫層只接收相同立場說服訊息，52% 更極化；異質組只接收相反立場，89% 變溫和、11% 被說服轉向。作者據此認為異質接觸可緩解極化。

7.3 煽動訊息

以徐州鐵鏈女事件建立數百 agent 的訊息擴散實驗。煽動內容比普通內容觸及更多人並引起更強情緒。平台以 LLM 判斷煽動內容；node intervention 封鎖反覆散播者，edge intervention 永久切斷傳播連結。前者對傳播與情緒的抑制都較強。訪談顯示，同情、擔憂、社會責任與提高公共關注是 agent 自述的分享動機。

7.4 全民基本收入

作者依德州實施 UBI 城市的人口分布建模，處理組每人每月無條件得到 1,000 美元。政策在第 96 step 加入，之後比較 24 steps。處理組消費增加、CES-D 憂鬱分數降低，方向與德州實驗相似；訪談常提到利率、長期利益、儲蓄與生活必需品。

7.5 颶風外部衝擊

以 2019 Hurricane Dorian 與 Columbia, South Carolina 為例，從 SafeGraph 與人口普查資料建立 1,000 agent。颶風前各區活動率為 70%–90%，登陸時降到約 30%，之後恢復。九天行程趨勢與真實資料相近，但高峰時期的反應幅度與速度仍有差異。

7.6 都市永續

北京 GIS 環境中有 200 個依 2024 人口資料抽樣的 agent。六組研究團隊在預算 100,000 內，以限量直接溝通、每處 1,000 的海報、每次 10,000 的全市廣播設計環保規範；第二天停止干預，測問卷態度、運具與碳排。六組都提高環保規範分數並降低移動碳排；個人道德義務與環保身份比單純「應該如此」的命令式規範更有效。

8. 討論、結論與限制

作者把社會模擬器分為社會孿生、政策反事實實驗、虛實共存三層，並主張 AgentSociety 朝第三層前進。它也被描述成計算社會科學的第四種典範：以可選擇、可觀察、可干預的高擬真人類 agent，補足資料分析、預測模型與傳統規則式 ABM。

實際證據較適合支持「研究原型」，而非高精度社會孿生。心理變數由 LLM 自評與生成，尚未建立測量效度；五項實驗多比對方向而非完整效應量；prompt、模型、隨機性與人口合成方式的敏感度分析不足。引擎也缺少動態負載平衡、故障恢復、訊息重複語意與跨 agent 錯誤管理。AgentSociety 展示了一個可檢查、可干預的大型實驗架構，但政策預測能力仍需嚴格外部驗證。
