論文／訪談原始來源

從分數到診斷：符號迴歸的搜尋獨立後診斷

第 1–2 節：把回饋從搜尋策略分離

不同符號迴歸求解器有互補的搜尋方式，但 MSE 等純量分數只提供候選排序，難以描述錯在哪裡。PostDiag 接收求解器提出的候選骨架與觀測資料，產生風險位置、局部證據與修訂式，再透過 adapter 回到原求解器；診斷不需搜尋軌跡、族群狀態或運算子歷史。（§1、§3）

第 3 節：局部指紋、風險平面與介入

每個候選表示為骨架 \(s\) 加數值係數。資料隨機分為擬合集和 audit 集；前者擬係數，後者診斷。輸入各維正規化後，以最遠點取樣的錨點與 k 近鄰建立可重疊的 audit 區塊。每塊指紋有三項：level 為均值；trend 為對正規化輸入的最小平方斜率向量；roughness 為相對局部仿射近似的均方根殘差。比較觀測與候選指紋，可定位局部行為差異。（§3.1–3.2）

表達風險 Bias 是各區塊三種特徵差異的加權平均；穩定風險 Var 固定骨架，對擬合集 bootstrap 重擬係數，再衡量相同 audit 區塊的指紋變動。兩軸以閾值區分：低 Bias／低 Var 為 Settled，保留或小修；高 Bias／低 Var 為 Underfit，局部修補；低 Bias／高 Var 為 Overfit，簡化；兩者皆高為 Mismatched，可重寫。局部證據表保留各特徵差異與不穩定度。（§3.3）

NMSE gate 排除誤差極低和極高者，將中間候選送診斷。LLM 根據狀態與證據提議式子，數值程序在擬合集重擬係數，僅 audit 誤差降低時接受修訂。GP 求解器可將修訂式加入族群；LLM 求解器可接收診斷紀錄和修訂。實際 adapter 依 solver 不同：例如 LaSR 在概念抽象階段加入診斷，SR-Scientist 提供診斷工具，PySR 注入個體。（§3.4、附錄 F）

第 4 節：設定與結果

實驗用 LLM-SRBench 的 LSR-Synth，129 題分布於物理、材料、化學、生物；每題 5,000 點中 4,000 訓練、500 ID 測試、500 OOD 測試。OOD 為時間或溫度較大的點，測試資料不參與搜尋、診斷或修訂接受。PostDiag 的訓練資料 75%／25% 分擬合與 audit；預設 64 個區塊、各 64 近鄰，三特徵權重 0.4／0.4／0.2，3 次 bootstrap 重擬，風險閾值 Bias 0.25、Var 0.15，閾值取自少量保留任務的初步實驗。（§4.1、附錄 A）

主實驗使用五種 LLM 及兩種 GP 求解器，在低原生搜尋預算下各自與增強版配對，固定基礎預算和 seeds，彙整三 seeds。PostDiag 額外診斷與 LLM 呼叫不扣基礎預算，但納入實際端到端時間；因此比較不是總計算量相同。主表使用 Qwen3.5-27B，GP 增強版的編輯器也用該模型。（§4.1、附錄 C–D）

作者自報 ID 整體 \(Acc_{0.01}\)：LLM-SR 22.0%→31.0%，SR-Scientist 25.6%→35.7%，PySR 23.8%→28.7%；每題平均秒數依序 167.5→191.7、648.0→702.2、8.8→10.5。該指標要求測試點最大相對誤差 ≤1%。這些配對顯示品質改善與額外時間成本並存。（表1）

OOD 整體 \(Acc_{0.01}\) 在同一 27B 設定下，LLM-SR 21.2%→28.9%、SR-Scientist 24.8%→33.6%，gplearn 及其增強版皆 0%。符號等價檢查先去除擬合參數與常數，再讓模型獨立判斷十次，非一致案例由人工處理；Direct LLM 27B 為 1.55%→1.55%，gplearn 為 0%→0%。（附錄 E、表2、附錄 G、表4）

第 4.3–5 節：診斷驗證與局限

人工構造的四種骨架—資料配對大致落在預期風險區，但 Underfit 與 Mismatched 在穩定性邊界有重疊。四求解器消融比較純 NMSE、NMSE 加風險平面、僅證據及完整 PostDiag，作者報完整版本最佳。當前實驗限於 LLM 與 GP 求解器；缺少接受修訂介面的其他搜尋方法可能需要更大調整，診斷與介入效率仍可改進。（§4.3–4.4、§5）
