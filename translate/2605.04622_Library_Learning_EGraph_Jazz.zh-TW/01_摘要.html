摘要

人類能對音樂模式形成高度結構化的直覺理解，但這些模式往往需多次反覆聆聽與反思才能內化。為刻畫此內化過程，我們提出一個基於庫學習（library learning）的爵士和聲模式學習計算模型。給定一批和聲進行語料，模型在「由 primitive 和聲關係組成的程式空間」中搜尋，以發現對語料的簡潔生成式解釋。模型先為每首曲子枚舉可能的程式，再聯合學習一套和聲模式庫與重構後的程式。為高效導航「程式 × 庫」的龐大聯合空間，我們把演繹式 parsing 與 e-graph 上的庫學習整合。我們透過評估程式與庫的直覺性、以及與人類所寫和聲推導的相似度，檢視模型捕捉人類音樂模式學習的程度。

關鍵字：庫學習、e-graph、演繹式 parsing、音樂重複、爵士和聲。

1. 引言

模式（動機、schema、終止式、和聲進行、節奏細胞）是音樂創作、感知、分析的核心，提供可重用的描述單位。本文聚焦音樂模式發現（MPD）：直接從資料辨識反覆出現的音樂規律。核心挑戰是模式要 (1) 夠抽象以涵蓋非精確重複、(2) 夠有分析意義以支持解釋——兩者常衝突：越抽象越易產生瑣碎的假陽性，越具體越脆弱、抓不到變奏的家族相似結構。

我們主張：好模式不該只用計數或表面相似度定義，而該連結到「抽象在建構緊湊、可重用的音樂結構解釋中所扮演的角色」。

1.1 我們的觀點與方法

人類對音樂模式的理解很少一次聆聽就完成，而是透過「假設—修正」的反覆循環。我們採用計算認知科學的觀點：把理解建模為建構能解釋觀察的結構化程式（Tenenbaum、Lake 等）。這些程式是生成式、組合式的：能由少量零件產生許多表面形式。於是「好模式 = 在許多解釋中有用的抽象」——它因可重用、能降低語料整體描述長度而獲得在模型中的地位；模式不由頻率定義，而由「對壓縮與解釋的效用」定義。

核心計算問題：僅給觀察到的音樂表面（和弦進行），能否聯合推得 (1) 每首曲子的緊湊生成式程式（推導）與 (2) 一組跨曲可重用的共享抽象？傳統上前者屬 parsing（假設固定文法、求最佳推導）、後者屬 library learning（從程式語料抽共用子程序壓縮）。但在我們的設定中這個分離是人為的：推導空間取決於可用抽象，而抽象的有用程度取決於它如何參與各曲推導——兩者互相依賴。

天真做法是循序：先窮舉每首曲子所有 parse 樹當候選程式，再對此語料做庫學習。但這在計算上不可行：二元分支歧義 CFG 對長度 k 的串有 Catalan 數 C_{k-1} 個 parse，n 首曲子的程式語料空間達 C_{k-1}^N，先窮舉再抽象會導致執行時間爆炸。

本研究改用整合演繹式 parsing 與 e-graph 庫學習的非監督方法。E-graph 是緊湊資料結構，透過非破壞性的 term rewriting 表示與操作大量等價程式族；在共享表示中維護眾多候選推導，讓抽象與 parsing 決策能互動而無須顯式枚舉整個搜尋空間。我們從兩面評估：量化上量壓縮率，質化上檢視學出模式的音樂合理性。

2. 和弦進行上的庫學習

2.1 問題設定

目標：從和弦進行語料推得 (1) 每首的結構化推導（程式）與 (2) 一組讓推導更經濟的共享和聲抽象。兩目標互相依賴。第一階段是 parsing：把和聲分析建模為 DSL 程式（由 primitive 和聲關係遞迴組合生成和弦序列），但保留歧義、用 e-graph 對推導族推理而非過早承諾單一推導。第二階段是為整個語料找緊湊碼庫：把跨曲反覆出現的子結構抽出為可重用抽象，類比於重構程式碼庫（把重複片段抽成具名函式）。

2.2 和聲關係作為 DSL primitive

採既有爵士和聲文法為 DSL，但把產生規則重新詮釋為和聲關係：不把和聲分析當和弦符號的樹，而當和聲關係的組合。例如 V-I（Descending5th）不只是改寫符號，而是斷言兩和弦實例滿足音程與性質約束（一根音高五度、一和弦具屬功能）。每個 primitive 以 egglog 邏輯規則編碼。

2.3 整合演繹式 parsing 與 e-graph 庫學習

每首和弦進行編碼為邏輯事實（公理），用 egglog 內的 CYK 式演繹程序 parse；所得 e-graph 緊湊表示所有曲子的所有推導，把相同子推導合併為等價類。候選模式由 e-class 間的 anti-unification 產生（求兩子推導的最小一般化，得到捕捉共享結構的參數化模板）。候選加進 e-graph 當改寫規則，做 equality saturation 直到不再產生新等價式，得到飽和圖 G'。再以**成本集分析（cost set）**評估候選庫：每 e-node 配 (cost(L), cost(D|L))，前者量引入抽象的複雜度、後者量用這些抽象編碼語料的成本，兩者實例化 MDL 目標：

L* = argmin_{L⊆P} ( cost(L) + cost(D|L) )

最後用最優庫 L* 重構原始 e-graph G。模型輸出即一個緊湊碼庫：學到的和聲模式庫 + 以該庫表達的壓縮推導。

3. 在 egglog 中的實作

實作建於 egglog（egg equality saturation 框架的宣告式擴展，整合 Datalog 式由下而上邏輯編程於 e-graph）。

  • Parsing 階段：以兩條推論規則跑到飽和，在 e-graph 內實例化 CYK 動態規劃，並顯式建構與合併推導程式；對每個 IsPhrase 事實，把產生同一樂句的所有推導程式視為等價於一個標準項 Der。飽和後 e-graph 類似 Shared Packed Parse Forest（歧義文法下可指數大）。再以「root-connectedness」由上而下傳播，濾掉不參與任何完整 parse 的局部片段。
  • Anti-unification 階段：把經典樹 anti-unification（Plotkin 1970，求最小一般化）擴展到 babble 式「在 e-class 之間」計算；交錯計算 e-node 與 e-class 的 anti-unifier（e-node 的依賴其子 e-class 的已定稿值；e-class 的依賴收齊其構成 e-node 的所有候選）以避免重複傳播；base case 處理 primitive（相同→自身、相異→恆等 Id），inductive case 處理組合模板；CanCoOccur 確保只在能共同參與完整 parse 的推導間抽象。
  • 壓縮（refactor）階段：用模板飽和 G 並在 G' 上改寫。例如模式 f(X+Y)×g(Y) 把 f(3+42)×g(42) 改寫為 (λx y. f(x+y)×g(y)) 3 42；在 Template 語言寫作 ×[f[+],g]（方括號表結構組合、尖括號路由引數）。重構即「以模板改寫 e-graph」，把重複結構換成高階組合子。
  • 成本集分析：每項配一組 (L, c) 對（候選庫子集與使用成本）；primitive 為 (∅,1)；合成項由下而上組合子項成本集（交叉乘積 + 父建構子局部貢獻），e-class 取其 e-node 成本集聯集；以 beam search 在傳播時剪枝、保留 MDL 下最有希望者。egglog 的關聯引擎自然支援所需 join 與 union。
