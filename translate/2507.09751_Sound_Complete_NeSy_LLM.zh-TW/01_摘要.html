摘要

大型語言模型（LLM）在自然語言理解與生成上展現亮眼能力，但其輸出存在邏輯一致性問題。儘管 LLM 不一致，我們如何在形式推理中駕馭其廣覆蓋的參數知識？本文提出一種方法，把 LLM 直接整合進一種超協調邏輯（paraconsistent logic）之形式語意的解釋函數中。我們以短答事實性基準 GPQA 與 SimpleQA 衍生的資料集做實證評估，顯示雙邊事實性評估在兩個基準上把 macro-F1 較單邊基線提升約 6 個百分點（代價是覆蓋率降低，因為在不一致或不確定情形會觸發棄權）。我們進一步描述一個實作該方法的概念驗證 tableau 推理器，並應用於一個用藥安全知識庫（228 條斷言 + 712 條推論）：系統偵測到 92 個 gluts，對應醫療上顯著的錯誤（如鴉片類被推論為非成癮、β-阻斷劑被推論為氣喘患者安全），同時系統仍保持可滿足，證明矛盾被局部化而非導致邏輯爆炸。

1. 引言（Introduction）

本文處理根本問題：LLM 編碼大量知識卻不一致、不完整，作為知識庫並不可靠。作者提出透過超協調邏輯的「LLM 接地解釋（LLM-grounded interpretations）」把 LLM 直接整合進形式邏輯語意。不用 prompting、也不用外部 solver，而是把一個 LLM 評審（judge）嵌入作為解釋函數本身。關鍵創新是使用廣義真值（驗證/反駁評估的成對值）取代二元判斷，植根於「Belnap 電腦」——處理不完整/不一致資訊的理論建構。

2. 相關工作（Related Work）

  • 2.1 LLM 的邏輯推理：當前取向分三類——(a) prompt 式（LLM 用自然語言推理）、(b) solver 式（LLM 產形式語句交外部推理器）、(c) 預訓練/微調（LLM 從證明範例學習）。作者提出新穎的 (d) 解釋式取向：「LLM 評審可為 𝐀𝐂 提供一個保持推理健全與完整的解釋」。
  • 2.2 用 LLM 評審做事實性評估：近期工作用 LLM 評審擴展事實性評估，提示模型賦予真值。作者以廣義真值延伸——同時捕捉驗證與反駁的可能，提供比二元判斷更豐富的知識論資訊。
  • 2.3 超協調推理的多值邏輯：本文建立於 Belnap 四值語意與超協調描述邏輯。選用 Angell 的分析包含邏輯（logic of analytic containment, 𝐀𝐂），因為它同時處理超協調性（容忍矛盾不爆炸）與超完備性（拒絕排中律），適合模糊/不完整資訊。

3. 原子公式的雙邊事實性評估

方法把**雙邊論（bilateralism）**操作化——理解一個命題需同時掌握其斷言與否認條件的哲學原則。

流程：

  1. 把原子公式 φ 語句化為自然語言；
  2. 對 LLM 提示兩次：一次驗證（「你能驗證這個嗎？」），一次反駁（「你能反駁這個嗎？」）;
  3. 把回應映到 weak Kleene 真值：𝔱（真）、𝔢（未定義）、𝔣（假）;
  4. 組合為有序對 ⟨u,v⟩ ∈ 𝒱₃ × 𝒱₃。

關鍵定義：

  • Def 3.1 語句化函數：δ:𝒫(ℒ)→Σ* 是把公式集映到 token 序列的全函數；可為模板式或 LLM 生成。
  • Def 3.2 驗證函數：P⁺:Σ*→Σ* 提示 LLM「取原子公式 φ 的語句化、生成陳述 φ 已被驗證或無法驗證的 token 序列 σ⁺」。
  • Def 3.3 反駁函數：P⁻:Σ*→Σ* 類似地提示反駁陳述。
  • Def 3.4 雙邊事實性評估：ζ:ℒ_AT→𝒱₃×𝒱₃ 產生 ⟨u,v⟩——若輸出含 "VERIFIED" 則 u=𝔱，含 "CANNOT VERIFY" 則 u=𝔣，否則 u=𝔢;v 以反駁 token 類推。
  • Def 3.5 快取函數：ζ_c 確保穩定性——一旦某原子公式被評估，重複呼叫回傳快取值，這對需要跨推導維持穩定賦值的 tableau 推理至關重要。

例（Figure 3）：查詢「America was discovered in 1492」產生驗證陳述：「在歐洲探索脈絡下準確但不完整」→ 無法驗證（u=𝔣）；反駁：「從歐洲視角看不矛盾」→ 無法反駁（v=𝔣）。結果 ⟨𝔣,𝔣⟩，表示知識不完整。

4. LLM 接地的解釋（LLM-Grounded Interpretations）

本節建立形式保證：LLM 評審可取代標準解釋函數而保持健全與完整。

  • Def 4.1 LLM 接地的 𝐀𝐂 解釋：ℐ=⟨𝐂^ℐ,𝐑^ℐ⟩ 是一個 𝐀𝐂 解釋，使得對每個函數 R^ℐ∈𝐑^ℐ：R^ℐ(c₁^ℐ,…,cₙ^ℐ)=ζ_c(R(c₁,…,cₙ))。雙邊評估函數直接計算謂詞真值。
  • Lemma 4.2 穩定性：對任一 LLM 接地解釋，ℐ(φ) 良定義且首次計算後恆定（證明依賴 Def 3.5 的快取）。
  • Lemma 4.4 LLM 接地 → 標準的映射：對任一 LLM 接地 𝐀𝐂 解釋 ℐ，存在一個標準 𝐀𝐂 解釋 ℐ′ 在所有公式上保持 ℐ 的語意行為（透過固定快取的賦值建構出同定義域與關係的 ℐ′）。
  • Lemma 4.6 標準 → LLM 接地的映射：反之，任一標準解釋可透過以標準解釋的真值預填快取，轉成 LLM 接地形式。
  • Theorem 4.8 保持健全性：若 Γ⊢_ACrQ φ，則對所有 LLM 接地 𝐀𝐂 解釋 ℐ，Γ⊧_ℐ φ 有效。證明：由 Ferguson (2021b)，語法推導蘊涵標準語意有效；因 LLM 接地解釋與標準解釋等價，有效性轉移。
  • Theorem 4.10 保持完整性：若對所有 LLM 接地 𝐀𝐂 解釋 ℐ 皆有 Γ⊧_ℐ φ，則 Γ⊢_ACrQ φ。證明：Lemma 4.4 把任一 LLM 接地反例轉成標準形式；ACrQ tableau 系統的完整性即可導出結論。

含意：以 LLM 評審作為解釋函數的推理，維持底層形式系統的邏輯保證。

5. 評估（Evaluation）

  • 5.1 資料與指標：由短答事實性基準 GPQA 與 SimpleQA 構造兩個資料集（各 N=400）。問答對近似原子公式的語句化。指標：Macro F1（在不棄權時）、Coverage（評審給出非棄權賦值的比例）、執行時間與 token 用量。
  • 5.2 LLM 評審：測六個模型——三旗艦（Llama 4 Maverick、GPT-4o、Claude 3.5 Sonnet）與三蒸餾（Llama 4 Scout、GPT-4o Mini、Claude 3.5 Haiku）；三種 prompt 變體（direct、zero-shot CoT、few-shot CoT）；基線為單邊評估（僅 𝔱 或 𝔣）。標準誤以 bootstrap 重抽樣估計（1000 子樣本，N=100）。

5.3 結果

關鍵發現：

  1. 雙邊評估 macro F1 勝單邊（p<0.01），代價是較低覆蓋率（平均差 +0.062 F1、−0.456 覆蓋率）。
  2. 旗艦明顯勝蒸餾（雙邊差 0.091–0.112，單邊差 0.074–0.087）。
  3. 雙邊評估約耗 2× 執行時間與 token（旗艦 GPQA：36.7s/4782 tokens vs 12.4s/2213 tokens）。
  4. 「不一致顯著比不完整更常見」（p<0.05）——⟨𝔱,𝔱⟩（矛盾）約 30% vs ⟨𝔣,𝔣⟩（不完整）11%。

5.4 局限

計算複雜度取決於需評估的原子公式數，最壞情形可能呈指數。每個原子需 2k 次 LLM API 呼叫（k-sample 多數投票）。快取與 tableau 優化預期有助益，但尚未驗證。本文缺乏完整端到端推理器實作——僅實作了解釋函數（原子公式評估）。提議的未來方向：把 𝐀𝐂 翻譯成古典描述邏輯（如 SROIQ），以透過 Pellet 等既有工具整合推理器。
