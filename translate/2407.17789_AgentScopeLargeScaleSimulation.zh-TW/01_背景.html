摘要

LLM 為超大規模多 agent 模擬開啟新方向，但既有平台仍受限於擴展性、效率、agent 多樣性與繁重的管理。本文擴充 AgentScope：以 actor 式分散機制支援 agent 級平行、工作流自動分散部署，以及 agent 彼此和環境間的互動；加入人口配置工具與自動背景生成管線；再提供網頁介面，統一監控跨裝置的 agent。作者以大型模擬展示這些元件，並公開程式碼。

1. 引言

傳統模擬仰賴預先寫好的規則與專家設計。LLM agent 有機會讓模擬更互動、可調適，也減少人工工作。不過 agent 數量變大後有三個障礙。

第一是擴展性與效率。小規模樣本可能無法呈現真實世界的複雜性，但大量 agent 又需要依依賴關係正確排程，並承受高頻的 agent-agent 與 agent-environment 存取。第二是人口分布與多樣性。只有簡單背景會產生大量同質角色；年齡、教育、職業等人口分布也需要控制。第三是管理。跨裝置 agent 的建立、運行、停止、資源與互動監控，很快就超過人工能處理的範圍。

本文在 AgentScope 上加入 actor 式分散執行、彈性環境、異質人口生成與 Agent-Manager。既有集中式工作流只需在初始化加入 to_dist，即可轉為分散式版本。作者再以「猜平均數的 2/3」遊戲測試到 100 萬 agent，分析模型、prompt 與背景如何影響群體及個體行為。

2. 相關工作

既有 LLM agent 平台可分為單 agent 工具與多 agent 協作框架。AutoGPT、LangChain 等偏向個別任務；MetaGPT、AutoGen、CAMEL 等以協作解決軟體、資料科學、遊戲與社會模擬問題。IoA 已能跨裝置部署，但重點是解題而非大規模模擬。作者認為這些平台的 agent 規模與運行效率仍有限。

既有 agent 模擬涵蓋教育、經濟、社會、交通與醫療，也有 Vidur、SOTOPIA 等專用環境，但多半侷限於特定領域。本文的目標是提供可自訂環境與管理工具，讓同一平台承載不同類型的大型模擬。
