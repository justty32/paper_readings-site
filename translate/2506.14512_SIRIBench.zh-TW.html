論文／訪談原始來源

SIRI-Bench: Challenging VLMs’ Spatial Intelligence through Complex Reasoning Tasks

摘要與第 1 節：問題

現有 VLM 評測多半測辨識、描述、距離估計，或把數學推理放在文字與平面圖中。這些任務很少要求模型先從真實感影像取得空間條件，再完成多步推理。可是機器人、擴增實境與具身系統恰好需要這種能力。作者因而提出 SIRI-Bench，把立體幾何題轉成影片問答，刻意將幾何類型、尺寸與頂點關係藏在場景裡。模型不能只讀題幹，必須先看懂空間，再計算答案。

作者把空間智慧界定為感知大小與形狀、理解幾何變換、擷取空間知識並據此推理的綜合能力。SIRI-Bench 的目的不是再測一次抽象數學，而是拆出一個更具體的問題：當語言模型會算題時，視覺介面是否能把解題所需的三維條件可靠地交給推理過程？

第 3 節：資料與自動場景建立

資料源是公開的立體幾何題。作者先人工排除低品質與難以驗證的證明題，再把選擇、填空等格式統一成開放式數值問答。每題被拆成示意圖、幾何體類別、主要條件、輔助條件與最終問題。場景保留必須從視覺取得的條件，文字則保留無法由畫面自然表達的輔助資訊，避免模型繞過空間理解。

Automatic Scene Creation Engine 以多個專職 LLM agent 串成工作流。數學 agent 先解出幾何體類型與具體尺寸，程式 agent 再生成 Blender Python 腳本。其後把字母頂點改成顏色索引、刪除可由場景推得的題目條件，並依縮放後的幾何重新計算答案。最後，相機繞主體拍攝，影片才成為被測模型的視覺輸入。這個流程的重點不是寫實裝飾，而是讓畫面、文字與數值答案仍忠於原題。

SIRI-Bench 最終由影片、問題與數值答案組成。題目跨不同幾何體、題型與難度，但目前規模仍屬中等；作者將引擎的可擴充性視為日後擴大資料集的基礎。

第 4 節：主要實驗（數字均為作者自報）

評估以預測值相對於真值的絕對相對誤差衡量，同時承接空間估計與數學計算造成的錯誤。作者測試多種開源、閉源、一般與長推理 VLM，另加入只讀完整文字條件的同系列 LLM 作對照。

作者自報，資料集共有 891 個樣本。最佳影片輸入模型 Doubao-1.5-pro 仍有 50％ 的預測誤差超過 100％；這顯示失敗不是少數極端題造成，而是普遍存在。參數規模也未呈現穩定優勢，InternVL 的不同尺寸得到近似的誤差分布。

關鍵對照是把空間條件由影片改成文字。作者自報，三組同系列模型在誤差低於 20％ 的比例，分別由影片輸入的 12.4％、8.3％、7.4％，升到文字輸入的 49.5％、18.4％、27.4％。Doubao 的文字版本約有一半預測落在最低誤差區間。這支持作者的診斷：模型已有一部分高階解題能力，主要瓶頸在於從影片擷取可靠的三維條件。

小型人類比較也呈現同樣方向。作者自報，受試者在允許 60％ 誤差時可解出約 70％ 的題目，明顯高於受測 VLM。不過作者只隨機抽取少量題目，人類結果不宜視為完整基準。錯誤案例顯示 GPT-4o 會把實際為矩形的截面簡化為三角形，還會在沒有視覺證據時假設單位邊長；問題因此同時涉及空間辨識、條件擷取與後續推理。

第 5 節：結論與局限

SIRI-Bench 的價值在於把「會不會推理」改寫成「能否從三維視覺取得條件，再完成推理」。實驗顯示，文字條件一旦明示，模型表現大幅改善；用影片承載相同資訊時，現有 VLM 卻常以錯誤假設補洞。

（本檔補註，非作者自陳）原文無作者自陳的 Limitations 小節，以下為本檔判斷。資料來自立體幾何題，仍不等同開放世界中的物理互動；場景與相機採固定設定，可能低估視角、遮擋與光照變化；答案只收數值，無法完整分離感知錯誤與推理錯誤。資料規模中等，人類對照樣本又少，因此這套基準較適合暴露問題，尚不足以概括所有空間智慧。
