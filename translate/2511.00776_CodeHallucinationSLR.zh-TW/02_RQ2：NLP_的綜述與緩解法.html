5. RQ2：NLP 的綜述與緩解法

回顧 NLP 幻覺綜述，分四主題：LLM 基礎技術概覽、醫療/臨床應用、幻覺的辨識/評測/緩解、跨域整合。代表如 Tonmoy 等 [124]（綜述 30+ 緩解技術，依資料用法/任務/回饋/檢索器分類）、Ji 等 [51]、Huang 等 [46]（幻覺分類法）。多項研究指出幻覺定義跨域不一致、呼籲統一術語。NLP 緩解法：模型層訓練、推理層、知識增強、agent 互動、後編輯/解碼約束（RAG、指令微調、自洽解碼等）。 RQ2 小結：(1) NLP 幻覺緩解研究廣泛且多綜述；(2) 關鍵策略含模型層訓練、推理層、知識增強、agent 互動、後編輯/解碼約束；(3) 這些有潛力遷移到程式碼生成，但需因應程式碼的結構與語意特性調整。

6. RQ3：緩解程式碼專屬問題

程式碼有獨特語法結構與功能特性，但多數現有法仍照搬 NLP。實證研究：Agarwal 等 [2] 提程式碼幻覺定義+分類法+首個資料集 CodeMirage；Liu 等 [78] 定義五類幻覺、提 HALLUCODE benchmark（顯示現有模型難偵測/減幻覺）。緩解法：語法感知解碼、靜態分析、執行回饋、測試案例驗證、編譯器驗證、約束引導生成、結構化提示、依賴挖掘+約束解碼（顯著減少幻覺）。 RQ3 小結：(1) 多數仍靠 RAG、微調、後編輯（類似 NLP）；(2) 多忽略程式碼獨特的結構/語意特性；(3) 針對變數誤用、API 幻覺、結構不一致的程式碼專屬解法仍稀缺，是開放方向。

7. RQ4：任務、資料集、模型與指標

任務（表 6）：補全、生成、程式合成、測試案例生成、摘要、修復、bug 偵測等。Benchmark/資料集：CodeHaluEval [123]（8,883 樣本、699 任務）、HALLUCODE [78]、CodeMirage [2] 等；多數只覆蓋 Python/Java。指標：語法有效性、功能正確性（pass@k＝k 次取樣至少一次通過全測試的機率）、精確匹配、幻覺專屬分數（MiHN、HR）。 RQ4 小結：(1) 多數資料集只聚焦少數語言（Python/Java），廣用性受限；(2) 適用指標含語法有效性、功能正確性、精確匹配、幻覺專屬分數（MiHN、Pass@K、HR）。

8. 挑戰與機會

8.1 挑戰

  • 幻覺 vs 一般錯誤：錯誤（mistake）是語法/邏輯/事實回憶的失誤（如 pritn 打錯）；幻覺是流暢、語法合理卻無據（如自信產出不存在的 calculateSquareRoot() API）。幻覺常以高信心產出，更難偵測、更具誤導性。
  • 信心 vs 幻覺：高信心不總代表正確，過度自信使幻覺更難察覺。
  • 幻覺 vs 泛化（表對比）：泛化＝對未見輸入產正確輸出，是正向能力；幻覺＝產貌似合理但無據輸出，須最小化。泛化在控制良好時可與低幻覺共存，但外推超出訓練資料即增幻覺風險。
  • 合成資料的事實性：以含幻覺/錯誤資訊的合成資料訓練的模型難泛化到真實場景，須嚴格資料驗證與偏差緩解。
  • 私有/敏感資料：工業程式碼與開源分布偏移大、隱私限制排除商用方案；模型可能記憶並重現不當片段/API/內部識別符，私有程式庫場景幻覺更易發生且難偵測。

8.2 機會

  • 統一評測 benchmark：現有多聚焦 Python/Java，缺 Rust/DSL；應動態更新以防資料洩漏、納入私有庫與標準化指標。
  • 可解釋幻覺偵測：多數把幻覺當分類問題；應發展可解釋模型（如反事實解釋：修改/移除提示片段觀察幻覺變化）。
  • 經模型編輯做歸因：不重訓而修改特定行為，定位並隔離幻覺表示、追溯對錯誤/過時知識的依賴。
  • 統一多階段緩解管線：結合上游知識增強檢索（補資訊缺口）、中游約束解碼（緩解結構幻覺）、下游符號執行驗證（驗證輸出）——模組化組合提升強健性與可解釋性。
  • 持續學習/終身適應：程式庫與 API 演化、過時知識是幻覺主源；增量適應演化的軟體生態而不全重訓。
  • 多模態 UI 程式碼生成的幻覺緩解、模型合併（融合通用 LLM 與小型程式碼專用 LLM 以平衡流暢與結構正確）。

9. 效度威脅

搜尋字串/資料庫範圍、納入準則主觀性、arXiv 預印本品質等（作者自陳並以 Kappa、人工複審緩解）。

10. 結論

本文從四視角全面審視 code LLM 幻覺，比對 NLP 綜述與軟工論文，人工定義並刻畫程式碼幻覺、辨識主因（資料噪聲、曝光偏差、語意接地不足），總結緩解策略（知識增強解碼、約束生成、一致性訓練，多源於 NLP），凸顯加劇幻覺的程式碼特性（語法剛性、強型別、外部庫依賴），並討論程式分析、符號執行、單元測試如何用於偵測/緩解。最後強調需發展超越一般正確性的統一、幻覺感知 benchmark，並列出開放挑戰：平衡泛化與事實可靠性、私有程式庫的幻覺偵測。
