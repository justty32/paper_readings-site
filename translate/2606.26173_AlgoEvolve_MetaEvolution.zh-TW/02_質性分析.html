6. 質性分析

  • 內迴圈基線：Phase 1（Gen 1-4）快速啟發式收斂（發現 RSI/CMO 動量濾波、SMA 趨勢確認，但邏輯淺、固定門檻）；Phase 2（Gen 5-12）「零交易」停滯陷阱——連 8 代終端報酬 0.0%，靠 Threshold Fragility（隨機調參而非結構創新）試圖復原，證實靜態提示下 LLM 突變運算子易陷局部最優，需元演化層突變搜尋指令本身。
  • 元演化動態：Era 1（MG1-2）「精煉範式」——以「提小變體」收斂 DNA 高效於穩定 regime，發現 Confluence Filter（RSI+布林）與 Hierarchical VWAP Filter（所有進場邏輯經 VWAP 把關、防逆主趨勢），累積 +1.79%。Era 2（MG3-4）「韌性轉向」——MG3 regime 轉變致冠軍虧 -1.59%（族群均值 -2.90%），Meta-LLM 在 MG4 執行「策略多樣性注入」（演化的 θ_focus 基因轉向「提出結構多樣原型、探索非線性指標組合與反波動訊號繞過零交易停滯」），復原捕捉 2.53% alpha——實證系統能自主偵測啟發式失敗並結構轉向。Era 3（MG5-6）「複雜度天花板」——元指令趨向高密度邏輯，末代遇首個語法邊界；穩健性濾波成功隔離錯誤候選（賦 −∞ 適應度），冠軍世系仍無效碼、捕 +2.50% alpha，示範安全的持續發現（優先執行完整性勝過投機複雜度）。

7. 結論與展望

AlgoEvolve 證明 LLM 式語意演化是噪聲、非可微、高維環境中持續程式合成的可行途徑——bi-level 架構讓系統自主放棄人設先驗、發現 regime 自適應邏輯，外迴圈元演化提示基因組緩解零交易等失效模式。設計時演化符號策略、部署時零推論延遲與本質可解釋，是相對 runtime LLM agent 的關鍵優勢。
