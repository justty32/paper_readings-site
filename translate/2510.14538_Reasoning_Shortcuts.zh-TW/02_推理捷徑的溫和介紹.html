3. 推理捷徑的溫和介紹

何時 NeSy 預測器會錯誤接地?直覺上會以為「只要訓練資料充足無噪、知識完整正確，最小化訓練損失就會像監督學習一樣學對概念」——但並非如此，因為 RS。

定義 3.1（RS，非正式）：RS 是「NeSy 預測器透過錯誤地接地概念，達到符合先驗知識的、準確的標籤預測」的情形。

例 3.2（MNIST-Add 的 RS）：訓練集僅兩例。理想接地是學到正確的圖→概念映射；但也可錯誤接地成另一套不直觀映射，同樣滿足約束、達高準確率。 例 3.3（BDD-OIA 的 RS）：正確接地紅綠燈與行人的預測器準確；但系統性把行人與紅燈搞混的預測器準確率相同（真值表中兩概念可互換，任一觸發都推出同一正確動作）。

這些例子顯示：正確與有缺陷的 NeSy 預測器無法僅靠標籤準確率區分，故訓練時沒有理由偏好其一；RS 即使知識正確完整、資料無噪也會發生；甚至訓練資料窮舉（含所有紅綠燈/行人組合）RS 仍持續（正確與錯誤模型在所有例子上給相同預測）。

3.1 成因、頻率與影響

  • 為何出現? 兩個相關問題之結合：(a) 先驗知識允許從不當接地的概念向量推出正確標籤；(b) 概念抽取器表示力夠強（夠多層）足以習得任何此種錯誤映射。兩者結合在學習問題中引入歧義，模型可自由學錯概念映射又保持高準確。
  • 實務中會發生嗎? 知識不夠「嚴格」時 RS 可能發生（非必然）。但文獻中標準條件下訓練的 NeSy 預測器屢屢落入 RS，顯示 RS 在 NeSy benchmark 中自然出現。
  • RS 讓 NeSy 不可用嗎? 否。只求準確（B1）與有效（B2）時 RS 不成問題（RS 不改標籤準確率，有效性是內建的）。但無法僅靠監看標籤預測偵測。
  • 有何後果? 嚴重損害可重用（B3）與可解釋（B4）：壞接地概念無法在其他設定運作（例：把救護車知識「緊急時可闖紅燈」配上「行人↔紅燈混淆」的預測器 → 緊急時遇行人反而開過去）；持續學習中也卡關（微調新任務時把 stop sign 與紅燈劃等號）;NeSy 驗證失效；解釋誤導（畫面是行人卻解釋成「因為有紅燈」）。

4. 推理捷徑的理論

兩種主流形式化。§4.2 可識別性：無限樣本下，達高概似的模型何時能真學到正確概念。§4.3 統計學習：有限資料下學正確概念的保證（經驗風險最小化）。

4.1 設定與假設

資料生成過程：區分真值概念 g*（underlying）與學到概念 c。訓練樣本取自真值聯合分布 = 真值概念抽取器（input→概念分布）與真值推理函數（概念分布→標籤分布）之合成。

  • 假設 4.1（完整性）：真值概念抽取器是「從 input 推真值標籤」的充分統計量（保留所有必要資訊）；標籤在給定真值概念下與 input 獨立，且所有 (x,y) 都與知識相容。（排除「概念空間相對標籤空間過於受限」的情形。）
  • 假設 4.2（可外推性）：真值概念抽取為確定性 one-hot 函數（可由 input 唯一取回真值概念）。
  • 假設 4.3（確定性）：真值推理層把每個概念向量映到單一標籤（one-hot）。
  • MNIST-Add、BDD-OIA 都滿足 4.2/4.3。

4.2 視角：可識別性

問：標準監督方式訓練的 NeSy 預測器，是否保證學到真值概念抽取器?即真值概念抽取器是否為訓練資料概似的唯一最大值?——這是可識別性理論的範疇。

  • 模型類（4.2.1）：NeSy 預測器＝（概念抽取器 ∈ F, 推理層）。多數理論在非參數設定（F 含所有 input→概念分布的函數）；且假設推理層在 one-hot 上等同真值推理層（Eq.11）。
  • 概念抽取器不可識別（4.2.2）;概念重映射分布 α（4.2.3）：α 描述「真值概念向量如何被映成學到概念向量」；確定性 α 對每個真值向量輸出 one-hot；任意 α 可表為確定性重映射的凸組合。真值對應的 α 是恆等映射 id（在假設 4.2 下）。
  • RS＝非預期的最優概念重映射（4.2.4）：

    定義 4.7（RS，正式）：若可學概念重映射分布 α 能滿足推理層且存在對應概念抽取器，但 α ≠ id（至少在一個真值概念上不同），則 α 是該推理層的 RS。

    • α≠id 有兩因：要嘛是有缺陷預測器（分布內就接地錯），要嘛雖分布內正確但在支撐集外（OOD）行為異於 id（組合泛化失敗）。
    • 此定義把焦點從概念抽取器（子符號層）移到概念重映射（符號層）。確定性 RS 對所有推理層都是 RS（因 Eq.11 在 one-hot 上輸出相同）。
  • 確定性 RS 的刻畫（4.2.5）：

    Theorem 4.10（數 RS）：在假設 4.1/4.2/4.3 下，確定性 RS 的數目有顯式公式；此數與 F 的具體選擇無關 → 所有 NeSy 架構有相同的確定性 RS（因所有整合知識的推理層都滿足 Eq.11）。

    • 若一個標籤可由 k 個不同概念向量推得，RS 數就乘 k! → 隨「多對一」程度迅速爆炸。
    • 例 4.11（XOR）：兩二元概念經 XOR 生標籤；窮舉支撐下有確定性 RS（如翻轉位元仍給正確標籤）。

4.3 視角：統計學習

學 NeSy 模型＝學概念抽取器使（配上推理層後）達高標籤概似 ＝ 找最小經驗標籤風險的模型。問：何時最小化標籤風險會帶動概念風險下降?

  • 知識複雜度（Def 4.15）：依訓練觀察到的標籤分布，衡量「有多少概念與知識不相容」;少數概念才能推出某標籤 → 複雜度高（知識更明確）；多概念映同標籤 → 複雜度低。（BDD-OIA 三概念：8 個向量中僅 1 個推 go、7 個推 stop。）
  • Theorem 4.16（RS 風險無界，不可能性結果）：若知識複雜度不夠高（被概念空間大小上界界住），則存在概念抽取器使標籤風險→0 但概念風險→∞（RS 風險趨於無限）。兩主因：知識複雜度不滿（每標籤對多概念向量）、F 無限制（可表達任意條件概念分布）→ 皆為緩解目標（加更專門的約束提高知識複雜度；或限制抽取器架構縮小 F）。
  • 分解式概念抽取器的 PAC 可學性（4.3.3–4）：許多任務 input 可分解成獨立單元（MNIST-Add 各數字），用同一函數獨立處理各單元（即「架構解耦」）。在 PAC 框架下研究，連到弱監督模型的可學性。
  • k-unambiguous 推理層的 PAC 可學性（4.3.5）：

    定義 4.17（k-unambiguity）：對任意兩概念向量 (z,c)、(z,c')（c≠c'），推理層都給出不同標籤（即在這些對上單射）。MNIST-Add 滿足此條件。

    • Lemma 4.18：在 k-unambiguity 下，概念風險可被標籤風險上界 → 任務 PAC 可學。

4.4 兩理論的關係

可識別性（無限樣本、唯一最大概似）與統計學習（有限樣本、風險上界）互補；知識複雜度/k-unambiguity 與「數 RS」彼此呼應——都指向「知識的多對一程度」是 RS 的根源。
