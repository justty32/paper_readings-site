4. HORMA

4.1 記憶增強的 agent policy

HORMA 引入外部記憶狀態 F_t，以 memory-augmented MDP 表示。Workspace 由 structured files 與 directories 組成，隨互動由 transition operator 更新：

F_(t+1) = T_F(F_t, a_t, o_t)

Manager M_m 負責實現這個 transition。Retriever M_r 從 workspace 選出 C_t ⊆ F_t，再交給主 agent：

π(a_t | o_t, F_t, q) = M_r(C_t | F_t, q) · M_θ(a_t | o_t, C_t, q)

長對話也用同一分解：不再把全部 user/assistant turns 交給模型，而是先由外部記憶取回小型、相關 context。

4.2 有根據的階層 workspace

每一次互動或對話 turn 都先封存到 timestamped directory。Manager 再依任務相關性，合成 entity logs、event summaries、state trackers 等 notes。每份 note 同時保存時間 metadata 與底層 raw trajectory reference。

這個設計的重點是 provenance 與 recoverability：快速路徑讀摘要，需要細節時才展開原始軌跡。Manager 和 retriever 都只透過 Bash／file operations 操作共享 workspace，記憶改動因而可見、可稽核。

4.3 以技能演化管理記憶

Manager 起初只有 domain-agnostic principles，例如 entity tracking、event abstraction、relation grouping。作者不以 long-horizon RL 直接訓練它，而是比較 raw history H 與 managed history H'：

  • D_exo：H 成功但 H' 失敗，指出 construction 遺漏重要資訊。
  • D_end：H' 成功但 H 失敗，指出結構化記憶成功濾掉噪音或減少 hallucination／lost-in-the-middle。

LLM 逐案比較兩條軌跡產生 feedback，再把多個 feedback 彙整為新 memory-management skills，加入下一輪 prompt。作者將其視為 textual gradient descent。技能庫逐輪增長，模型參數不變。

4.4 以強化學習導航檢索

Retriever 不用 flat nearest-neighbor search，而是利用 directory hierarchy、時間順序與 provenance。它可執行 ls、grep、cd、cat，另有兩個終端動作：select 把選定內容加入 C_t，done 在證據足夠時停止。

Retriever 以 GRPO 訓練。Evidence-grounded reward 是 retrieved context C_t 與 ground-truth evidence E 的 Jaccard overlap：

J(C_t, E) = |C_t ∩ E| / |C_t ∪ E|

它同時獎勵 coverage 與 precision，因此 agent 會學到階層探索、command failure recovery，以及停止拿取冗餘 context。
