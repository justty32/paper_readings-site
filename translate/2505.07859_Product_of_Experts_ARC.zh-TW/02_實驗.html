5. 實驗

5.1 資料建模（Tokenization）

須最小化 token 數（context 有限、長 context 降效）且避開 tokenization 失敗模式（標準分詞會把數字併成「分組數字 token」，徒增謎題複雜度）。故精簡 token 集（從 >10 萬減到約 64 個，見表 5）：每格用一 token（不壓縮）、盡量不加多餘分隔符；移除嵌入層多數列以縮小模型、杜絕 token 合併。任務開頭加少量額外 pre-prompt token（大小寫字母 A…Za…z），意外略升效能——推測微調時模型學會用這些當計算緩衝影響後續 token。

5.2 訓練

選 Mistral-NeMo-Minitron-8B-Base 表現最強。用 LoRA + 4-bit 量化 + 梯度檢查點（unsloth），LoRA 套用所有層含輸入輸出嵌入。只對輸出格算梯度（不令模型預測輸入格；且無範例無法預測第一個輸出）。訓練於增強資料（所有對稱 + 顏色置換 + 範例重排）。

  • 初始微調：LoRA rank 256，單 H100;只用 RE-ARC——避「概念洩漏」（某類題出現在訓練資料會不當降低評估難度）。98 H100-時。
  • 測試時訓練：限時、僅針對評估集，LoRA rank 32、64 步、batch 1；單獨 TTT 即顯著提升；平均 51 秒/任務（4090）。

5.3 解推論

DFS 採樣產候選集。增強含 16 個函數/任務（各對稱用兩次但配不同隨機顏色置換與範例重排）。表 3 比較 DFS / beam / 多項式 / 貪婪：DFS 快、省 VRAM、誤報率低。DFS T=9% 雖比 4× 隨機採樣找到的正解少（76% vs 77.3%），但選擇分數更好（誤報只約一半）、僅 1/4 推論時間（9:32 vs 39:47）。

  • 對比 beam search：4-beam 可達 DFS T=9% 同準確度（71.6%），但需約 2 倍 VRAM（14GB vs 7.3GB）、4 倍時間；DFS 只需記單一路徑、靠低機率路徑早剪而快。對第一個之後的增強，先把目前最佳候選當初始猜測單次前向處理再回溯，更快。
  • 閾值 T 為超參（無法預知正解採樣機率）;T 約 1%–9% 在時間與正解數間取平衡；模型越確定 DFS 越快。T 越低候選集愈含正解（單調增）但選擇愈難；最終結果用 T=9%（推論時間約等於貪婪採樣）。

5.4 選擇策略

用增強集算 PoE 集成；取 PoE 機率最高與次高者為兩次猜測。圖 5：正解原非 rank 1 時，此程序多能改善其 rank。表 3 證實乘積（PoE）一致勝過取平均（averaging）;DFS 推論下 PoE 比平均高（71.6% vs 較低）。

5.5 ConceptARC

為驗不過擬合原 ARC，於 ConceptARC（按概念分類的 ARC 樣資料集）測：同 DFS T=9% 超參達 73.3% 兩次猜測準確度，顯示良好泛化到同難度 ARC 樣資料。

5.6 Sudoku

換域驗證（Sudoku 3M）。規則跨題一致故不用 TTT；以 ARC 預訓 Llama-3B 再於 Sudoku 微調。無歧義故報 top-1。用 DFS T=1%，達 53%（SOTA LLM <3%）。且若採到正解幾乎必選中——Sudoku 正確性易驗，增強更能識錯、大減誤報。圖 6：PoE 較單純取最高採樣機率大幅提升。

6. 討論

核心：單一微調 LLM 兩角色——生成器（為各增強提解）+ 評分器（跨所有增強取似然乘積/幾何平均重評）。好處雙重：(1) 候選須在每個有效變換下皆合理才排前，難靠單表示的偽相關取巧；(2) log-linear pooling 天然是集成法。儘管 ARC 號稱複雜，此「先生成再重評」兩階段於開源模型達 SOTA；唯一更高的閉源解每題 17 美元，而本法全開源、可重現、每題僅約 2 美分。

更廣原則：處理結構化/抽象推理時，關鍵是善用保語意變換、逼模型在同問題多視角下保持一致，從而把單模型當專家集成。此視角可望推廣到能定義此類變換的更複雜符號推理。

6.1 未來工作

(1) 探索把單 LLM 當 PoE 推廣到 ARC 專屬變換之外的增強（如文字改寫、風格變體）以擴及更廣自然語言推理；(2) 評估 DFS 候選生成於 ARC 樣謎題之外（邏輯推理、程式合成、數學）的適用性。

附錄（要點）

  • A. DFS 演算法：機率引導的 DFS 採樣偽碼（用負對數機率避數值問題）；實作因 unsloth 不支援動態快取須自行剪 KV-cache，並用「最佳已知序列含 prompt+預測的同時初始前向」等優化。
  • B. 訓練參數：初始 LoRA rank 256 / TTT rank 32;rank-stabilized LoRA on;cosine LR;adamw_8bit;4-bit;bfloat16；只訓輸出 token；初始 RE-ARC、TTT 單任務範例。
  • C. PoE 證明：定理 4.1 的完整推導（KL 分解 + 幾何平均 ≤ 算術平均得 log Z ≤ 0）。
