10. Organic Failures

30 個 temperature 0.9 非注入 episodes 有 11 failures：7 silent aborts、3 fabricated counts、1 ungrounded blend。既有 monitor 只抓 1/3 fabrications，整體 AUROC 0.31–0.42，healthy false alarm 36%。簡單 completion check 抓 7/7 aborts、0 false positive。

預註冊 55 episodes replication 只出現 2 個 candidate hallucinations，低於預定最低 10，因此作者不宣稱統計 monitor 能抓 fabrication。這類錯誤改由 numeric-grounding verifier 處理：回答中每個金額都必須可追溯至收到的 tool result 或其算術組合。

11. Deterministic Verification

total_consistency 重算 total，required_coverage 檢查必要 calls，tool_contract 檢查 result shape。它們不讀任務的 hidden world，只讀該 run 真正收到的結果，無需健康 null、threshold 或 false-alarm budget。

Served-temperature 同批資料中，checks 為 60% recall，加 coverage 96%，0/63 false positives；monitor 為 54%、11/63。高溫時 checks 65%／96%、0/38，monitor 40%、6/38。

checks 是看 serving failures 後寫的，所以作者另收 120 個 disjoint-seed episodes，凍結規則再測：total 抓 54%，加 coverage 93%，算術錯誤 36/36，0/64 false positives。llama3.1:8b 同 seeds、無調整，抓 110/110 failures、0/10 false positives。Tool contract 對 1,825 healthy 為零誤報，抓 46% context corruption、44% looping；215/218 在 onset 一步內。

12. Repair

flagged run 回滾到共同 checkpoint，之後全部重新呼叫模型。55 個錯誤案例三次重複下，單純 resample recover 16%；只提供失敗 check 名稱的 located 為 45%，p=0.0005；generic 與包含正確值的 specific 都是 36%；calculator 28%，adaptive 21%。五重比較 Bonferroni 後只有 located 顯著。

Located 在 120 episodes 將成功率 52% 提至 73%，修復 25 failures，因 checks 沒有誤報而未破壞任何正確 run。工具層持續壞掉時 retry 沒用；loop trap 可把 30-step loop 在第 10 步切斷，剩餘案例需 escalation。

13. 限制與結論

統計 monitor 只適合其健康 null 對應的 serving distribution；slow drift、omission 與 plausible corruption 各有結構性盲點。Deterministic checks 精度高，但需要可寫成規格，且是根據先前 failure 設計。文章開頭稱 2,823 episodes 中 770 使用 real tools，實證段又稱整個 corpus 都是 live agents against real tools，資料範圍文字不完全一致。

可靠的 runtime 不該押注單一 detector。低成本序列 monitor 負責行為變化，確定性規格負責可證明的內容與覆蓋，LLM judge 處理剩餘語意案例；修復只在可重建 checkpoint 且故障類型允許時執行，否則安全終止。
