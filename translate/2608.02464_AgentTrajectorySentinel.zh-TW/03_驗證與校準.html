5. 真實生態驗證

九個 real corpora 中，looping detection 為 0.48–1.00；tool cascade 0.17–1.00；abrupt goal drift 在四個命中的 corpus 為 0.66–0.86；wrong document 0.00–0.20、malformed JSON 0.05–0.50，是明顯內容盲點。

跨模型 transfer 失敗。qwen2.5:7b null 直接套 llama3.1:8b，AUROC 0.527、healthy false alarm 75%；llama 自身重校為 0.885。ESN 相對 Mahalanobis 的 detection 優勢會隨 onset 後可觀察步數增加：≤3、4–8、≥9 steps 分別 +0.09、+0.14、+0.40。短 episode 沒時間累積，memoryless distance 反而具競爭力。

llama 重校後 AUROC 0.885，Gemini 125 episodes 為 0.794。Gemini detection 較低主要因 onset 後中位只有 4 steps，qwen 為 8；配對 horizon 後兩者為 0.53 與 0.56。拿掉 token surprisal，四個 corpus 的 ESN AUROC 變化為 0，顯示 structured tool results 比 logprobs 更重要。

Gemini judge 在 161 prompts 的實測 detection 0.548、false positive 0.052。原本模擬假設 0.90／0.02，導致 escalation 宣稱可保留 82% detection；換成實測後只剩 43%，五 seeds 全不支持原假設。judge 對 goal drift 完美，對 context corruption 只有 0.18；monitor 剛好相反，因此 judge 適合作互補 escalation。

6. 外部 Corpus

AFTraj-2K 過濾後 1,882 trajectories，ESN AUROC 0.745、最佳 hybrid 0.760，但 5% budget 下 detection 只有 4.8%。61% failure 在 onset 後三步內結束，只有 6.9% 有九步以上；長 horizon 時 ESN detection 50.9%，短 horizon 則幾乎無法報警。

ATBench 過濾後 604 trajectories，ESN AUROC 0.779、unsafe detection 31.1%。Over-privileged action 與 unvalidated tool output detection 為 50.8%、47.3%，inaccurate information 只有 3.8%。做了什麼較易從 telemetry 看出，說錯什麼較難。

7. 控制研究

模擬器直接建構 detector 輸入，不經 LLM 或真實 adapter，因此只用來解釋機制。五 seeds 中 ESN 平均 detect 0.707±0.068、realized FA 4.4%、AUROC 0.872±0.015、平均提前 4.6 steps；它不能作 deployment 證據。

8. Calibrated Hybrid

1,002 injected episodes 中，273 只被 ESN 抓到、57 只被 Mahalanobis 抓到、372 兩者都抓到、300 皆未抓。Cross-fit logistic fusion 的權重會依 horizon 改變；grand-mean AUROC 0.826，高於 ESN 0.802、Mahalanobis 0.807。但逐 dataset 與當地較佳 parent 比，AUROC 八個中七個不較高，detection 八個全較低。Hybrid 適合事前不知道 regime 的穩健選擇，不代表支配兩個 parent。

9. 補內容盲點

加入 9 維 grounding channel 後，874 injected episodes 中 content gate 把 content detection 由 0.27 提至 0.58，behavioral detection 由 0.74 提至 0.79。若工具結果根本沒進 telemetry、內容太短，或錯誤數值格式合理，仍無法檢測。
