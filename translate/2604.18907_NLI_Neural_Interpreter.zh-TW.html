論文／訪談原始來源

以神經詮釋語言進行梯度式程式合成（NLI）

摘要

本文提出 Neural Language Interpreter（NLI）——一個架起符號與神經程式合成之間鴻溝的新架構。透過學一個離散、類符號的語言與一個可微的解釋器，NLI 結合符號系統的組合強度與神經網路的靈活性。我們證明 NLI 在具挑戰性的組合泛化（compositional generalisation）任務上勝過既有神經法、並與符號法 competitive；消融確認離散、序列的潛在程式是此成功的關鍵。

1. 引言 / 2. 問題陳述

神經程式合成靈活但組合泛化差；符號法泛化強卻不靈活、難端到端可微。NLI 旨在兼得兩者之長。問題設定為 programming-by-example：模型只看輸入輸出對，須做到系統性泛化。

3. 離散序列推論

3.1 訓練目標

  • 重建損失 L_rec：解釋器執行所推得的程式須重現目標輸出。
  • 編碼器正則化損失：約束編碼器（inductor）的程式表徵。

3.2 Inductor：離散程式表徵學習

把輸入輸出對編碼成離散 token 序列（類符號程式）；離散性透過 Gumbel-Softmax 等機制實現（§4.3 專門分析）。

3.3 Interpreter：遞迴神經程式執行

一個可微解釋器逐步執行 token 程式：每層（執行步）條件於恰好一個 token，採嚴格遞迴/序列流。此遞迴設計正是長度泛化能力的來源（致謝 François Chollet 早期關於「神經程式應透過遞迴 by design 處理長度泛化」的啟發對話）。

3.4 搜尋神經程式

三種推論策略：Base Inference（直接取編碼器輸出）、Prior Search（從編碼器抽樣）、以及主力 Gradient Search（在潛在空間以梯度優化程式）。test-time 梯度搜尋是泛化的關鍵啟用者。

4. 實驗

benchmark：自訂組合泛化套件 + DeepCoder benchmark 的組合版（Shi et al., 2023）。自訂套件用固定長度序列（20），含三 split：Shift-L（訓練於小位移、測試於更大未見位移＝長度泛化）、Shift-P（反向：訓練於大位移、測試於小位移＝原語抽取）、Comp-I（訓練於單一原語、測試時須組合它們）。

基線：In-Context Learning（ICL）、Test-Time Training（TTT）、Latent Program Network（LPN）及其離散變體（D-LPN）。NLI 評估三種推論：Base、Prior Search、Gradient Search。所有模型三隨機種子、報平均。

4.1 神經模型的組合泛化

所有模型訓練 100k batch（size 512），於 in/out-of-distribution 測試 split 評估。因 NLI 與基線推論成本差異，為公平也對基線做「增加 decoder 層的匹配算力」訓練——但這反而降 ID 效能且無泛化，故 Table 1 報告較佳的低推論 2 層 decoder 結果。

所有模型在 ID 測試近完美（皆能解類訓練分布的任務）。但在更難的 OOD split：所有基線與 NLI 的非搜尋變體無法泛化——ICL 與 LPN/D-LPN 在 Shift-L、Shift-P 上 OOD 近 0%，搜尋型 LPN 在 Comp-I 僅微幅進步仍未解出。相對地，NLI + Gradient Search 跨三 benchmark 展現強組合泛化：Shift-L 達 99%（從小位移外推到更大未見位移）、Comp-I 達 91%（合成如複合程式）、Shift-P 達完美 100%（只訓練於複雜程式後「反編譯」出原語）。這確認 NLI 達成系統性泛化，由梯度式搜尋啟用；base encoder 與 prior search 變體則與 ICL/TTT/LPN 基線一樣無泛化。

4.1.1 學到的程式表徵：學到的 code 展現原語的系統性重用——模型一致以 token 231 表示單次左移、token 476 表示兩步移，較大程式由這兩塊積木組合；OOD 的八次位移也（經梯度搜尋）表示為這些原語的混合，凸顯泛化來自重用而非記憶（圖 2）。

4.2 NLI 泛化能力的來源（消融）

base 模型 OOD 準確率近完美；逐一移除組件：移除遞迴執行、或移除 inductor/interpreter 任一的離散性，OOD 準確率崩到近 0%——顯示離散 inductor 程式、離散解釋器、遞迴動態三者皆為泛化所必需。移除 skip token 降至中等（模型能自學 skip，但專用 token 利更快更穩訓練）。編碼器損失的益處視組合類型而定：對 Shift-P（需表徵原語以組更短程式）有用，對長度泛化（把已見原語組成更長程式）則無影響。

4.3 Gumbel-Softmax / 4.4 擴展 test-time 程式搜尋 / 4.5 DeepCoder

進一步分析離散化機制、test-time 搜尋規模、以及在擴大原語數與程式複雜度的 DeepCoder 組合版上的表現。

6. 結論

本文提出 Neural Language Interpreter，架起符號與神經程式合成之間的鴻溝：透過學一個離散、類符號的語言與一個可微解釋器，NLI 結合符號系統的組合強度與神經網路的靈活性。NLI 勝過既有神經法、與符號法 competitive；消融確認離散、序列的潛在程式是成功關鍵。

局限與未來：主要瓶頸是 test-time 潛在搜尋的計算成本（雖對過擬合異常穩健、受限預算下仍 robust）；擴展到更難問題需更高效推論（演化/局部搜尋為有望方向）。問題變難時程式長度與詞彙增大，可能引發梯度消失/爆炸（實驗未見但大規模或需架構改動）。當前解釋器表達力受限：每層只條件於一個 token（無法做帶參原語如 add(k)），執行嚴格序列、無條件分支。
