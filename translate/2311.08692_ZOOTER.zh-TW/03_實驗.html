4 實驗

4.1 實驗設置

候選 LLM：選六個同為 13B 的 LLaMA 系模型作路由候選：(a) WizardLM——用 EvolInstruct 增強查詢與回覆對齊；(b) WizardCoder——用相同技術對齊的程式專家；(c) WizardMath——以查詢增強、ChatGPT 獎勵與 PPO 優化對齊的數學專家；(d) Vicuna——對齊自使用者與商用聊天機器人的大量對話；(e) OpenChat——用篩選過的 ShareGPT 資料加額外訓練策略對齊；(f) Llama-2-Chat——先做監督微調再多輪拒絕抽樣對齊。基線與 Zooter 均以這六個候選實驗評估。

訓練資料集：從開源資料建立一個多樣混合指令資料集，以最大化 Zooter 的泛化能力。先用本地標註器對 13 個開源資料集打標籤，並對含有與下方評測集 6-gram 重疊查詢的樣本做去污染，避免資料洩漏。接著對每個獨特標籤隨機取 10 筆樣本，組成 DivInstruct：共 47,986 筆指令、涵蓋 6,270 個不同標籤。

評測集：涵蓋四組評測。先納入三個廣泛使用、以 GPT-4 當裁判的對齊評測——AlpacaEval（koala、vicuna 等 5 個子集，共 805 筆）、FLASK（10 個細粒度對齊技能領域）、MT-Bench（涵蓋數學與程式共 8 個面向的多輪評測，訓練與路由僅用首輪查詢，但按原始流程做多輪評估）。由於 GPT-4 裁判可能帶偏見且與人類判斷有顯著分歧，另納入 MMLU、GSM8K、HumanEval 一組。

指標：因各評測分數尺度不同，除各評測分數外，另定義 MTR（mean task rank，平均任務排名）——某模型在所有基線中的平均排名（越低越好），可跨不同分數尺度的評測比較；並提出 %Uplift（拿下最佳表現的子集比率，越高越好）。共在四組評測、26 個子集上報告這兩指標。

基線：與既有 reward model 排序（RMR）方法比較，用當時最新的 reward model 組成基線——OAssistRM、Auto-J、UltraRM、QwenRM，及一個 Oracle 排序作參照；也把 LLM-Blender 的 pairwise ranking 視為 RMR 方法之一；並報告 GPT-3.5-turbo、GPT-4 兩個商用模型的表現作參考。

配置：路由函數以 mdeberta-v3-base 為骨幹訓練；用 QwenRM 對訓練查詢產生獎勵作監督，因其在 4.2 節所述的 RMR 表現中，以相對小得多的參數量取得最佳效果；全部訓練與推論在 8 張 A100 GPU 上完成；MMLU、GSM8K、HumanEval 使用貪婪解碼。

4.2 結果

主結果如表 1（26 個子集）。六個路由候選中，「單一平均最佳模型」（BMA）是 Llama-2-Chat。Zooter 以 \(\beta=0.3\) 的標籤增強設定為主結果。

互補潛力：以五個不同現成 reward model 做 RMR 評估。UltraRM 的 RMR 在整體 MTR（1.53）與 %Uplift（72%）上最佳；QwenRM 的 RMR 次佳，效果接近 UltraRM 但參數量小得多；接著依序為 Auto-J、LLM-Blender、OAssistRM。QwenRM、UltraRM、Auto-J 三者的 RMR 都優於 BMA，證明 RMR 的有效性。用 Oracle 排序（理論上限）的 RMR 一致優於全部候選，甚至在 AlpacaEval 與 FLASK 上超越 GPT-4，為 LLM 互補潛力假設提供有力證據，也支持 Zooter「用現成 reward model 的獎勵當路由函數銀標籤監督」的核心動機。但 RMR 在 MMLU、GSM8K、HumanEval 上表現不佳，顯示現成 reward model 精準判斷知識、數學、程式問題仍具挑戰。

Zooter 表現：Zooter 在 AlpacaEval、MT-Bench、Benchmarks 上勝過 BMA，FLASK 上表現相近，MT-Bench 上提升最明顯（平均分高出 BMA 0.39）。整體而言 Zooter 在 44% 子任務拿下第一，BMA 僅 31%。以上證據顯示，Zooter 只需一個 86M 參數的路由器的計算開銷，即能更一致地利用 LLM 間互補潛力取得最佳表現；Zooter 也以顯著更少的計算開銷勝過 OAssistRM、LLM-Blender、Auto-J 三個 RMR 基線。但 Zooter 雖在 AlpacaEval 勝過 QwenRM 的 RMR，整體上 Zooter 與 QwenRM 的 RMR 之間仍有明顯落差。

4.3 分析

RM 不確定性：既有研究指出 RM 的純量獎勵存在不確定性，會在把 RM 分數當銀標籤監督時引入雜訊。作者先展示此不確定性的存在，以說明基於標籤的標籤增強（緩解此不確定性的方法）的動機：對 MT-Bench 每個樣本，計算 QwenRM 在全部候選 LLM 間給出獎勵的熵，並與用 QwenRM 做偏好排序所得的 MT-Bench 分數對照（圖 3）。結果顯示獎勵熵越低的樣本，MT-Bench 分數往往越高，即獎勵熵越高代表該獎勵的不確定性越大。因此提出基於標籤的標籤增強，用標籤先驗調整獎勵熵。

標籤增強：\(\beta\) 代表細粒度樣本級獎勵與粗粒度標籤級獎勵間的權衡。實驗調整此超參數並分析不同粒度獎勵如何影響路由函數訓練（表 2）：Zooter 在 \(\beta=0.3\) 時整體 MTR 最佳（1.97），證明樣本級與標籤級獎勵的組合有利於獎勵蒸餾，也證明標籤增強的必要性。此外，純標籤級蒸餾（\(\beta=0\)，MTR 2.06）明顯優於純樣本級蒸餾（\(\beta=1\)，MTR 2.34），支持「樣本級獎勵中來自 RM 不確定性的雜訊會傷害獎勵蒸餾」的分析。

5 結論

本文重新檢視開源 LLM 的互補潛力，以及多個現成 reward model 的排序，為 LLM 集成的有效性提供證據。作者提出 Zooter，一個高效的 reward 引導路由方法，用於集成現成 LLM。綜合評估顯示 Zooter 能以顯著更少的計算開銷，勝過單一平均最佳模型，甚至勝過以 reward model 排序做集成的方法。有價值的未來工作包括深入探究各 LLM 潛在專長的可解釋性。
