3 方法

3.1 LLM 的互補潛力

給定一組 LLM \(\mathcal{M}=\{m_i\}\) 與一組下游查詢 \(\mathcal{Q}=\{q_i\}\)，作者假設對 \(\mathcal{M}\) 中每個 LLM \(m_i\)，存在一個非空查詢子集 \(\mathcal{Q}_{m_i}\)，使得對其中任一查詢 \(q_j\)，\(m_i\) 的表現都一致優於 \(\mathcal{M}\) 中其他 LLM，即 \(m_i=\operatorname{argmax}_{m\in\mathcal{M}} P(q_j, m(q_j))\)，\(P\) 可為任何偏好或效能評估指標。本文進一步強化此假設，主張 LLM 間的互補性揭露了它們在不同領域與任務上的專長，因而能對查詢分類、為每一類挑出最佳 LLM。

Reward Model 排序（RMR）：利用互補潛力集成 LLM 並取得超越表現。RMR 試圖找到一個獎勵函數 \(\hat{P}\) 來估計 oracle 偏好 \(P\)，藉此為每個查詢取得最佳模型。然而 RMR 必須讓所有候選模型都做推論以取得輸出，再用獎勵函數排序，帶來很大的計算開銷。

查詢路由（Query Routing）：相對 RMR 更能緩解 LLM 集成中的效率問題。一般而言，查詢路由試圖找到一個路由函數 \(\mathcal{Z}(q,m_i)\)，使 \(m_i=\operatorname{argmax}_{m\in\mathcal{M}}\mathcal{Z}(q_j,m)\)。路由函數僅依查詢本身分配查詢，不需生成輸出。若 LLM 的互補潛力假設成立，路由函數即在預測一個查詢 \(q\) 屬於某 LLM 專長集合 \(Q_m\) 的機率。

3.2 Zooter

本節提出 Zooter，一個 reward 引導的查詢路由方法，用於高效集成大型語言模型。Zooter 從 reward model 排序中學習，以詮釋各模型的潛在專長：先讓全部候選 LLM 在一個涵蓋多樣查詢的訓練集上推論、產生回覆（圖 2 藍色虛線標示）；接著全部回覆由現成 reward model 給出純量獎勵；獎勵先經過基於標籤的先驗做平滑去噪；再把正規化後的獎勵分佈當作路由函數知識蒸餾訓練的監督（圖 2 綠色虛線標示）。推論時，路由函數把輸入查詢分類到在此查詢上專長潛力最強的 LLM，由該 LLM 生成專家回覆。透過訓練這樣一個路由函數，Zooter 只需推論一個專家 LLM，加上路由函數的少量計算開銷，達成更高效的集成。

獎勵蒸餾（Reward Distillation）：如 3.1 節所述，查詢路由旨在找到一個路由函數，預測查詢 \(q\) 屬於 LLM \(m\) 的專長集合 \(Q_m\) 的機率，其中 \(Q_m\) 是 LLM \(m\) 在所有候選中一致取得最高偏好的查詢集合。回顧 reward model 排序，估計偏好 \(\hat{P}(q,m_i(q))\)（即獎勵）可解讀為某 LLM \(m_i\) 相對其他候選在查詢 \(q\) 上的相對優勢。因此，正規化後的獎勵可作為路由函數的銀標籤監督：\(\mathcal{Z}(q)_i = P(q\in Q_{m_i}) := \exp(\hat{P}(q,m_i(q))) / \sum_{m_i\in\mathcal{M}}\exp(\hat{P}(q,m_i(q)))\)，因為更高的優勢本質上代表某 LLM 相對其對手在該查詢上的專長。

為估計各模型的專長並訓練路由函數，需在多樣訓練集 \(\hat{Q}\) 上做獎勵偏好排序：先讓全部候選模型對每個查詢 \(\hat{q}\) 推論，再由現成 reward model 給出每題每模型的純量獎勵 \(\mathbf{r}_i=\{\hat{P}(\hat{q}_i,m_j(\hat{q}_i))\}_{j=1}^{|\mathcal{M}|}\)。接著以 KL 散度作為損失函數，用知識蒸餾在訓練集上訓練路由函數 \(\mathcal{Z}\)：\(\mathcal{L}(q_i,\mathbf{r}_i)=\mathrm{KL}(\mathcal{Z}(q_i),\mathrm{softmax}(\mathbf{r}_i))\)。Zooter 是資料高效、低資源的方法，因訓練集 \(\hat{Q}\) 只需查詢、不需回覆標註；但訓練集中的查詢須盡量多樣，以最大化路由函數的泛化能力。蒸餾過程幫助 Zooter 學到各模型的潛在專長，如此一來，推論時只需用路由函數判斷查詢屬於哪個專長集合，即可降低計算成本。

基於標籤的標籤增強：獎勵蒸餾雖提供路由函數利用 RMR 銀標籤監督的可行途徑，但語言 reward model 給出的獎勵帶有不確定性，會引入一定雜訊。作者先在 4.3 節實證此不確定性：現成 reward model 都或多或少涉及此類不確定性雜訊（見論文圖 3）。因此，作者利用指令標籤來進一步增強訓練查詢上的獎勵。此標籤增強方法類似廣泛使用的標籤平滑技術，並已被證明對知識蒸餾有效。具體而言，先用一個本地標註器 \(\mathcal{T}(\cdot)\) 為每個訓練查詢 \(\hat{q}_i\) 標上一組標籤 \(\mathcal{T}(q_i)\)；接著把帶相同標籤的查詢的獎勵聚合成標籤級獎勵 \(\mathbf{r}_t=\frac{1}{|Q_t|}\sum_{i\in Q_t}\mathbf{r}_i\)（\(Q_t=\{q_i \mid t\in\mathcal{T}(q_i)\}\)）；然後以線性組合增強每個查詢的獎勵：\(\mathbf{r}_i^*=\beta\mathbf{r}_i+(1-\beta)\mathbf{r}_t\)，\(\beta\) 是細粒度樣本級獎勵與粗粒度標籤級獎勵間權衡的超參數。訓練時以增強後的獎勵 \(\mathbf{r}^*\) 取代原獎勵，加入 KL 散度損失。
