摘要

大型語言模型（LLM）的「互補潛力」假設現成 LLM 在廣泛領域與任務上具有異質專長，因此 LLM 集成能持續取得比單一模型更好的表現。既有 LLM 集成方法主要聚焦於用 reward model 對輸出排序，導致顯著的計算開銷。為解決此問題，我們重新檢視 LLM 的互補潛力，並進一步用現成 reward model 挖掘潛在專長來闡述它。我們提出 Zooter，一個 reward 引導的路由方法，把訓練查詢上的獎勵蒸餾出來以訓練一個路由函數，能精準地把每個查詢分配給對它有專長的 LLM。我們也整合了基於標籤的標籤增強，以緩解把獎勵當作銀標籤監督時帶來的不確定性雜訊。Zooter 相較 reward model 排序方法只引入路由函數這一項很小的計算開銷，展現推論期的計算效率。我們在涵蓋不同領域與任務、共 26 個子集的綜合評測集合上評估 Zooter。Zooter 平均勝過單一最佳模型，並在 44% 的任務上排名第一，甚至超越多個 reward model 排序方法。

1 引言

隨人類偏好對齊的 LLM 快速湧現、幾乎每天都有新模型發布，這些現成 LLM 進一步被微調或對齊成通才或特定領域的專才，以解決各種下游任務。值得注意的是，LLM 用各異的資料做預訓練與對齊，導致它們在各種下游任務上呈現多樣的優劣勢。因此，LLM 集成能利用它們之間的互補潛力，達到比單一「平均最佳」模型更好的跨任務表現。

LLM 集成的關鍵挑戰之一是計算效率，因現有 LLM 參數量龐大。既有研究提供了合併多個 LLM 生成輸出的可靠方法，但這類方法需要極高的推論成本，在低資源情境下不具擴展性、也難與「單一平均最佳模型」競爭。為了高效集成現成 LLM，作者先深入檢視一個看似直觀卻仍研究不足的假設：即便是被對齊成「通才」的現成 LLM，也在廣泛領域與主題上具有異質專長。然而分析 LLM 的專長很困難，因為 LLM 的潛在專長與預訓練及對齊資料高度相關，而這些資料即便對熱門開源 LLM（如 Llama-2-Chat、WizardLM）而言也十分模糊且不可得。

若此假設成立，現成 LLM 便能透過「把查詢分配給擅長它的模型」來高效集成，而不必對每個模型都額外付出推論成本。這種高效路由策略對每個查詢只需單一模型的推論成本，加上一個小得多的查詢路由器的開銷。然而，探測現成 LLM 的細部專長、並為訓練路由器產生監督訊號，同樣需要標註，開發資料高效的路由訓練方法目前仍研究不足。

為解決此問題，作者提出 Zooter，一個 reward 引導的查詢路由方法，用於高效集成現成 LLM。Zooter 從既有 reward model（RM）取得並增強銀標籤監督，以訓練查詢路由器，並事先把查詢分配到對應的「專長」。如圖 1 所示，獎勵分佈隱含了 oracle 判斷、揭露了 LLM 間潛在的專長差異。Zooter 從獎勵分佈中捕捉這種專長，並在推論時提供查詢分配。具體而言，作者先進行一項涵蓋四組、超過 26 個子集、跨多領域與任務的綜合研究，探討六個廣泛使用的開源 LLM，並透過 reward model 排序聚合它們，展示這類廣泛下游任務的互補潛力。接著收集一組多樣的訓練查詢集，把模型專長的獎勵蒸餾出來當作訓練 LLM 路由器的間接監督，並開發基於標籤的標籤增強，進一步克服此類來自 reward model 的銀標籤不足的問題。

三項貢獻：(1) 重新檢視開源 LLM 的互補潛力，證明 LLM 集成的有效性，並展示現成 RM 的獎勵可作為模型專長的銀標籤監督；(2) 提出 Zooter，一個高效的 reward 引導路由方法，從現成 reward model 蒸餾獎勵以探測模型專長，並開發基於標籤的標籤增強來緩解 reward model 不確定性帶來的雜訊；(3) 在四組共 26 個子集的評測上綜合評估集成方法（含 reward model 排序與 Zooter），評估顯示 Zooter 能有效集成 LLM，甚至以顯著更少的計算開銷超越 reward model 排序方法。

2 相關工作

指令微調與對齊：指令微調幫助 LLM 遵循多樣指令，被廣泛用於把 LLM 對齊人類偏好。本文聚焦集成已對齊的 LLM（如 Llama-2-Chat、WizardLM、Vicuna 等），並在廣泛的對齊評測任務上評估它們。

大型語言模型集成：LLM 集成因開源 LLM 的爆炸性成長而成為新興主題，目標是合併現成 LLM 以在多樣下游任務上取得持續更好的表現。少數工作探討了 LLM 的互補潛力假設及如何據此集成。Jiang et al. (2023, LLM-Blender) 提出一個由 pair ranker 與生成融合器組成的集成框架；Chen et al. (2023, FrugalGPT) 依序推論現成 LLM，直到回覆滿足足夠品質才停止；Wang et al. (2023b) 提出「專家融合」問題，把具互補知識的專家模型輸出融合、形式化為監督學習；Shnitzer et al. (2023) 展示了從各種評測資料集學習模型路由器的效用與侷限。這些工作雖都聚焦獎勵排序或路由策略來集成 LLM，Zooter 在兩方面與這些同期工作不同：其一，這些同期工作需要對所有候選都做輸出生成或前向過程來取得查詢表示，帶來顯著計算開銷，而 Zooter 透過在預先定義的訓練查詢集上蒸餾獎勵來推斷模型專長，避免此類推論開銷；其二，這些工作多在一組固定評測集上開發與評估，而 Zooter 只需查詢、不需黃金回覆即可開發，且瞄準更多樣的對齊任務。因此 Zooter 在資料與計算上都更高效，作者也在更多樣的對齊任務上評估 Zooter，以全面檢視 LLM 的互補潛力。

Reward Model 引導生成：LLM 情境下的 reward model 常被用於透過強化學習或偏好學習改善對齊表現；reward model 也能在生成階段改善表現，例如用 reward model 對多條推理路徑排序以改善數學推理能力，或用 reward model 做 reward-guided decoding。受這些 reward model 在對齊上的成功應用啟發，Zooter 同樣利用現成 reward model 來探究 LLM 的潛在專長。
