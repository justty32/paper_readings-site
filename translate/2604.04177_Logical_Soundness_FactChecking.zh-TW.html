論文／訪談原始來源

立場：邏輯健全性不是用 LLM 做神經符號事實查核的可靠判準

University of Sheffield 計算機科學學院

摘要

隨著 LLM 日益融入事實查核管線，形式邏輯常被提議為緩解模型輸出之偏誤、錯誤、幻覺的嚴謹手段。例如某些神經符號系統用 LLM 把自然語言翻成邏輯公式，再檢查所提宣稱是否邏輯健全（即能否從已驗證為真的前提有效推導）。我們主張這類做法結構性地無法偵測誤導性宣稱，因為「邏輯健全的結論」與「人類通常做出並接受的推論」之間存在系統性分歧。借鑑認知科學與語用學研究，我們給出一套類型學：在這些情形下，邏輯健全的結論會系統性地引發人類做出前提不支持的推論。因此我們主張一條互補進路：把 LLM 的類人推論傾向當作特徵而非 bug，用這些模型來驗證神經符號系統中形式組件的輸出是否可能誤導人。

1 引言

LLM 推進了自動事實查核與宣稱驗證，但其輸出仍易幻覺、偏誤、邏輯不一致。為此，越來越多工作提出神經符號進路，用形式邏輯約束或驗證 LLM 輸出：LLM 充當語意剖析器，把自然語言陳述翻成如一階邏輯（FOL）公式，再對已驗證知識庫或外部來源評估。共同假設是：若一宣稱邏輯健全（在形式推論規則下可從真前提有效推導），則該宣稱即被支持、可接受。

我們主張這有致命盲點：邏輯健全不是偵測誤導資訊的可靠判準，因為人類推論常偏離形式邏輯運算，使邏輯健全的結論可系統性地誤導人。由此得三蘊含：(a) 相較於用形式邏輯驗證 LLM 輸出，LLM 反而有潛力建模人類推論、偵測形式系統認不出的誤導；(b) LLM 推理研究應把類人傾向不只當 bug（模型犯人類式錯誤與偏誤），也當 feature（模型預測人會接受卻形式無效的推論）；(c) 若 LLM 要有效建模人類推理，不該被訓練 / 優化成嚴格遵循形式邏輯。

2 誤導資訊與基於邏輯的事實查核

查核不只要識別明確錯誤，也要識別字面為真卻誤導的陳述。「誤導」＝事實正確、卻傳達為假或無依據之隱含意義的內容；「隱含意義」包含人類讀者通常會做出或接受的推論。例：「John 和 Marilyn 大吵一架，決定和她分手」——讀者依 conjunction buttressing 通常讀成 (i) 時序（先吵後決定）、(ii) 因果（吵架促成決定）。若 John 早在吵架前已決定分手，此句雖與事實字面相容，仍應視為誤導。

既有研究把 LLM 與顯式邏輯驗證結合：用 LLM 把複雜宣稱拆成 FOL 謂詞公式逐一驗真；或用自然邏輯 + 定理證明器判斷宣稱是否被證據蘊含；亦延伸到知識圖譜法、程式法。共同假設：能從可信前提以邏輯有效方式推導者，即視為被支持、被驗證。

3 人類推理與形式邏輯的分歧

認知科學顯示人類接受並做出的推論常偏離形式系統的有效性。例：對析取「A 或 B」，依心智模型論，人把它表徵為一組預設成立的可能性合取，故聽到「A 或 B」會把「可能 A」「可能 B」當直覺正確，儘管在標準模態邏輯中二者皆無效。

示例：知識庫僅有一條已驗證真前提

  • S1：法國關稅將漲 10%。 驗證宣稱
  • S2：法國關稅將漲 10% 或 100%。 把 S1 記為 A，由析取引入規則可有效推得 S2，故 S2 對 S1 為邏輯健全。但人類通常接受「可能 B」，即
  • S2-I：有可能關稅漲 100%。 而 S2-I 完全不被 S1 支持。故 S2 應視為誤導：它隱含一個 S1 無依據的宣稱。

表 1（對同一前提 S1 套用合法運算的誤導例）：

  • 析取引入 → S2「漲 10% 或 100%」→ 人推「可能漲 100%」（依「析取＝預設可能性合取」）。
  • 合取引入 → S3「漲 10%，且漲 10%」→ 人推「連續兩次漲 10%」（Gricean 量準則 + conjunction buttressing 時序）。
  • 實質蘊含（正悖論）→ S4「若利率不降則漲 10%」→ 人推 S4-I「若利率降則不漲」（conditional perfection：把條件句讀成雙條件）。
  • 實質蘊含（空真）→ S5 同上。
  • 模態 B、T 公理 → S6「可能漲 10%」→ 人推「可能不漲 10%」（從可能推出不確定，Gricean 質準則）。

結論：邏輯健全不是查核誤導資訊的可靠判準。

4 蘊含

當前「以形式邏輯約束 / 驗證 LLM 輸出」的範式只捕捉了查核可靠性所需的一部分。未來工作應探索 LLM 評估形式上有效的結論是否可能誤導人類讀者的潛力。此方向可行，因為既有研究顯示 LLM 已展現多種類人推論傾向——但多數文獻把這些傾向只當錯誤型態處理（人自己也會在被糾正後承認的錯）。我們強調不同目標：形式無效、卻被人視為直覺且可接受的推論。把類人傾向當 feature（而非只 bug）研究，對評估 LLM 能否充當人類推論的有用模型至關重要。同理，若 LLM 要藉建模人類推論來補足形式驗證，其訓練目標不應強制 / 鼓勵遵循形式邏輯（獎勵形式一致或偏置訓練資料趨向合邏輯型態，會壓抑偵測「邏輯健全卻誤導」輸出所需的語用敏感度）。

5 替代觀點

  • 「在邏輯健全外再加輔助判準 X」：要求宣稱同時邏輯健全 + 滿足 X，會系統性產生誤殺——因可接受的人類推論常邏輯無效；但「僅當邏輯不健全且不滿足 X 才拒」同樣有問題（會漏掉表 1 那類誤導）。
  • 「不必管含連接詞的複合句，惡意者不用」：LLM 能大規模產生散布錯誤資訊；即使人類偏好直接斷言，自動系統可學會生成規避邏輯過濾器、卻仍誘發誤導推論的合法複合宣稱。
  • 「把推導 trace 攤給用戶自行判斷」：假設用戶會一致檢視形式 trace、且能可靠地從中察覺語用誤導性，實務上多數用戶做不到；委派給 LLM 解讀又繞回原問題。trace 透明有助問責，但不消除核心可靠性問題。

6 結論

我們主張：在事實查核與錯誤資訊偵測脈絡中，邏輯健全不是評估宣稱的可靠判準，因它系統性漏掉某些因「人類推理與形式邏輯分歧」而誤導的陳述。我們列舉邏輯健全卻誤導的結論例（會引發人類無依據推論，如各認知科學 / 語言學研究所預測）。據此提出對現行範式的替代：呼籲未來工作探索並最大化 LLM 偵測「在嚴格形式系統中本會被許可、卻誤導人」之陳述的潛力。
