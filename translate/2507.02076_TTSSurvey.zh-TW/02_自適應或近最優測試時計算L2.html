5. 自適應或近最優測試時計算（L2）

5.1 順序

Prompting：CCoT（要求簡潔）在弱模型數學題有準確率損失；SoT 用三種認知啟發（概念鏈／區塊符號化／專家詞彙）省 token 到 15-30%，搭配輕量路由模型依題型動態選擇策略；MetaReasoner 用 contextual bandit 動態選擇重啟／回溯／簡化等提示策略；TIP 發現 o1-like 模型有 underthinking──傾向過早放棄有潛力的推理路線（頻繁 "Alternatively"），提出解碼層面的抑制方法。SFT：Munkhbat 等人發現 prompting 效率法在小型任務特定模型上會降低準確率，改以自我訓練（BoN 選最短正確軌跡＋few-shot 範例）學習簡潔推理；TOPS 讓 LLM 生成低/中/高三種 effort CoT 後微調以獲得可控長度；TALE（兩種變體──TALE-EP 用模型自評 token 預算後給 budget-aware prompt，TALE-PT 直接微調於最優預算的 QA 對）；Pangu Embedded/C3oT 訓練長短 CoT 混合並以特殊標記觸發；DualFormer 用隨機丟棄推理軌跡讓模型學會自主決定何時快/慢推理。蒸餾路線：將 System 2 輸出（篩選後）蒸餾到 System 1；Retro Search 用 MCTS-like 搜索發現更短但仍正確的軌跡後蒸餾；Z1 提出 Shifted Thinking Window──去除思考分隔符、設定答案長度上限，超出時中斷並追加提示。連續潛在空間：COCONUT 以課程學習將離散 CoT token 逐漸替換為連續表徵（省 token 但不需語言通順成本）；SoftCoT 用輔助小模型生成潛在空間思考再投射到主模型（避免完整微調與災難性遺忘）；CODI 用自蒸餾讓單一模型同時擔任 teacher/student 壓縮 CoT；Heima 將 CoT 壓縮為「思維 token」並支援可選解碼重建。LightThinker 訓練模型動態壓縮中間思考為內部隱狀態以節省峰值記憶體。ITT 用 residual thinking connection＋adaptive token routing 讓同一層內多次迭代精煉 token 表徵。RL：長度懲罰獎勵是主流（Kimi k1.5 用漸進式長度懲罰升溫、Arora & Zanette 省 token 22-77%、O1-Pruner 用 pre-sampled baseline 修剪冗餘、DAST 用 Token Length Budget 引導對比 RL、IBPO 將推理框架為約束最佳化、MRT 用分段 regret 取代二元正確獎勵、CPO 捕捉偏好對齊的推理路徑、Dr.GRPO 控制長度爆炸）。AdaReasoner 以 multi-armed bandit 配置推論參數但未加長度懲罰。AdaCtrl/ARM 支援使用 [Easy]/[Hard] 標記觸發不同推理策略。模型合併：Wu 等人探索合併快思維與慢思維模型，基於激活的合併法在 1.5B/7B 模型上省 50-55% token，但在 14B/32B 上效果令人失望。

5.2 並行

Prompting：Adaptive-Consistency 用 Beta 信心停止準則避免多餘取樣；DSC 先依估計難度分組再分配取樣數；ESC 對當前多數答案做假設檢定決定是否提前終止；Path-Consistency 用已生成的最佳推理前綴引導下一批取樣（迭代延長前綴直到滿足停止準則）；ST-BoN 在早期分歧點截斷劣勢路徑；Certaindex 以語義熵指標動態分配集群資源。SFT：RASC 從 CoT 抽取啟發式特徵訓練評分函數做加權多數投票；Ada-BoK 在 BoN 取樣數與 LLM 路由間做預算分配；IBPO 無需外部驗證器學習查詢難度並分配預算。RL：Pan 等人訓練 LLM 動態 spawn() 子進程並行探索不同推理路徑後 join() 聚合，在 Countdown 遊戲上展示 token 效率。

6. 討論

Prompting vs Fine-Tuning：訓練預算有限時，prompting 法最易入手（self-consistency/BoN 控制取樣數＋CCoT/s1 壓縮 token 長度）。能負擔訓練時，SFT（強化自訓練、TOPS）與 RL（LCPO、Kimi k1.5 等）可將效率內化為模型習慣。

混合快慢 LLM：大型推理模型在數學/科學等可驗證任務上成功，GPT-4o/DeepSeek-v3 等快速模型在創意寫作/翻譯/文本檢索仍具競爭力。未來方向：設計同時融入直覺（快）與複雜（慢）推理能力的混合模型；擴散模型架構可能提供更好的多模態推理框架。

多模態 TTS 效率：極少工作──Vision-R1 用漸進式思考抑制訓練；LLaVA-CoT 用階段級 beam search；FAST 用問題難度+圖像複雜度指標動態調整推理長度；Skywork R1V 用自適應長度 CoT 蒸餾；VLM-R1 對開放詞彙物體檢測用預測長度懲罰因子。

應用：企業常部署多模型大小服務延遲敏感與計算密集型場景，L1 可控方法為「一模型通吃」提供可能。互動式 AI 代理（如 Deep Research）在嚴格延遲下需維持高品質。多模態領域（自動駕駛、機器人、醫療）目前效率努力集中於模型壓縮（量化/蒸餾/剪枝），未來應探索推理層級最佳化（如控制 CoT 長度、減少冗餘推理步驟）。

7. 結論

本綜述提出 L1 可控／L2 自適應的二層 TTC 效率分類學，透過廣泛基準測試識別了當前推理模型的關鍵低效問題。未來最有前景的方向為：能根據任務複雜度靈活分配推理努力的混合快慢思維 LLM；以及將自適應計算擴展至視覺語言與具身 AI 等領域──統一跨模態的可控與自適應推理可能通向下一代高效、可擴展、情境感知的 AI。
