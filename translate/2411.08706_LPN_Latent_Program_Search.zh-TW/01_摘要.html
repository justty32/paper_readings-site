摘要

通用智能需要能高效習得新技能並泛化出訓練分布的系統。程式合成法泛化力強，但因組合空間巨大而難擴展，需人造 DSL 或預訓練先驗來縮窄搜尋；深度學習成功但缺結構化測試時適應、依賴重度隨機取樣或昂貴梯度微調。本文提出 LPN (Latent Program Network)——把測試時搜尋直接內建進神經模型的新架構。LPN 學一個「隱式程式」（神經式地映射輸入到輸出）的潛在空間，並在測試時用梯度於其中搜尋。LPN 結合符號法的適應力與神經法的可擴展性，在緊湊潛在空間搜尋、繞過預定義 DSL。在一系列「以範例編程」任務上，LPN 達到或超越上下文學習與測試時訓練法。在 ARC-AGI 上，開啟測試時搜尋使 OOD 任務表現翻倍。

1. 引言

AI 系統難以泛化出訓練分布或適應新奇。Chollet (2019)《On the Measure of Intelligence》主張：只測技能的傳統基準會被「無限先驗知識」或「海量訓練資料」鑽空子 (gamed)，掩蓋真正泛化力；應改測技能習得效率（用最少經驗學新任務的能力），並在控制先驗與資料下評估泛化。ARC-AGI 即測技能習得效率而非純技能——few-shot 設定、極少資料適應新任務、且對齊人類表現。

當前 ARC-AGI／程式合成法分兩類：(1) 歸納式（Parisotto、Devlin、CodeIt 等）用 DSL 生成顯式程式 → 手工問題特定 DSL 不可擴展、且仰賴「總有人造 DSL」的不實假設，AI 生 DSL（DreamCoder）進展有限；(2) 上下文學習/傳導式（Devlin、Kolev、Li 等）訓神經模型條件於少量範例、為新輸入產出，於模型激活內隱式推程式 → 擺脫 DSL 更可擴展，但難維持一致性 (consistency)（無法映射規格自身的輸入到輸出）。測試時微調可解一致性但對大模型極昂貴且易過擬合；transformer 上下文學習受自注意力二次複雜度所限，阻礙規格長度擴展。

LPN 取兩者之長：以連續潛在空間表示隱式程式、允許高效測試時程式搜尋；只反傳一小部分參數故比測試時微調省；在潛在空間做程式聚合與重組、移除注意力的二次成本。貢獻：(1) 新架構 LPN，內建測試時適應（學程式潛在空間並為新資料搜尋最佳潛在表示）;(2) 證明「訓練時的梯度式潛在搜尋」會優化潛在空間以利測試時適應；(3) 證明 LPN 能泛化到訓練未見的規格長度（甚至提升），不像上下文學習在大規格下不微調就失效。

2. 相關工作

早期演繹法（定理證明造可證明正確程式）→ 因難獲形式規格而轉向歸納法（從 I/O 範例推程式）。三範式縮窄指數搜尋空間：(1) 可微程式語言（整合符號推理與連續優化）;(2) 神經網路當先驗約束搜尋空間（DeepCoder、RobustFill、CodeIt 用預訓練 CodeT5）;(3) 上下文/傳導法繞過中間程式表示（直接學 I/O 映射，神經網路即完全可微的程式表示、權重編碼程式結構；LLM 也可做 in-context 傳導推理；hendel/yang 發現 LLM 激活內湧現「任務向量」）。LPN 顯式學習並解耦程式空間（與其他激活資訊分離），帶來更佳程式表示與更高效探索。神經法雖免 DSL 但犧牲可解釋性與系統化推論搜尋能力，且難維持與規格一致。

測試時訓練 (TTT)：測試時微調模型參數以解一致性問題（把網路參數當程式、微調=參數空間搜尋；神經網路是萬能逼近器故目標程式很可能存在於參數空間）。MAML 在全參數空間做 few-shot 梯度更新；LEO（與本文相近）引入瓶頸，內迴圈優化在潛在空間進行、解碼器為條件於潛在生成原始參數的 hypernetwork——LPN 移除 hypernetwork 之需，重用 transformer 上下文學習能力直接條件於潛在變數生成。

潛在空間條件/優化已用於分子生成、組合優化 (TSP)、黑箱優化、符號數學（潛在優化平衡方程複雜度與準確）;LEAPS 用 RL 搜尋 Karel 程式的潛在空間。LPN 可從半攤銷變分推論 (SVI) 視角理解：先用編碼器做攤銷變分推論，再對每資料點額外更新以縮小攤銷間隙（對數似然與 ELBO 之差）;LPN 的對應更新即測試時在潛在空間做梯度下降。

3. 背景

程式合成：在目標語言生成確定性程式，使輸入產出的輸出與給定規格一致。任務由規格集定義，每個規格是一組 I/O 範例。程式解任務須對規格每個輸入複現輸出。

程式合成泛化：把學到的程式套到新輸入（而非僅解釋規格）。給定某程式（不必限於 DSL）生成的 I/O 範例 + 額外輸入 x'，目標是泛化並預測 x' 的輸出（可經歸納或傳導）。若不限程式的 Kolmogorov 複雜度，總能為任何規格找到「一個」解釋（未必是真正底層程式）。評估泛化不只測「解釋規格」，更測「能否推得底層程式的一般性並套到新輸入」。近 few-shot learning，但只有一個任務。ARC-AGI 屬此形式化：每任務的 I/O 對是最多 30×30、每格 10 色的 2D 網格。
