3. 實驗

3.1 實驗設定

基礎模型：Llama 2 70B（Touvron et al., 2023）。

3.1.1 種子訓練資料

IFT 種子資料：使用 Open Assistant（Köpf et al., 2023）的人工撰寫範例。依 Li et al. (2024)，只取英文、首輪對話、且人工標註排名最高（rank 0）的高品質樣本，共 3,200 筆。僅用此資料以 SFT 微調基礎模型者，作為我們的 SFT baseline。

EFT 種子資料：Open Assistant 每個提示附有多個人工排序的回應，可用來建構評估微調資料。切成訓練與評估集，依圖 2 的輸入格式構造 LLM-as-a-Judge 資料。由於資料本身沒有現成的思維鏈理由與 5 分制分數，改由 SFT baseline 產生評估輸出，只有當其分數排序與資料中的人類排序一致時才收進訓練集。又因觀察到許多樣本被評為 4 分，故對最常見分數做部分丟棄重取樣以避免分佈過度偏斜。最終得 1,630 筆訓練、541 筆評估樣本（與 IFT 資料不重疊）。

3.1.2 評估指標

指令遵循：以 GPT-4 為評審，在 256 題 IFT 測試提示上做模型兩兩對戰勝率；成對提示的兩種順序都試，若 GPT-4 兩次判斷不一致則計為平手。另做作者親自參與的人類評估。此外報告 AlpacaEval 2.0 排行榜格式（805 題，對基線 GPT-4 Turbo 的勝率，由 GPT-4 評判）、MT-Bench（多輪、多類別的困難題，GPT-4 以 10 分制評分），以及 9 項 NLP 基準：ARC-Easy、ARC-Challenge、HellaSwag、SIQA、PIQA、GSM8K、MMLU、OBQA、NQ。

獎勵建模：在自 Open Assistant 導出的評估集上量測與人類排序的相關性（每個指令平均 2.85 個附排序的回應）。指標包含成對準確率（任一對回應的排序是否與人類一致）、完全匹配率（整體排序完全一致的比例）、Spearman 相關、Kendall τ，以及模型給 5 分滿分的回應被人類評為最高名次的頻率（5-best %）。

3.1.3 訓練細節

SFT 用學習率 5.5e−6（cosine 衰減至 1.1e−6）、batch size 16、dropout 0.1，只在目標 token 上算損失。DPO 用學習率 1e−6（衰減至 1e−7）、batch size 16、dropout 0.1、β = 0.1。每 200 步存檔並用 Claude 2 在 253 筆驗證樣本上以 AlpacaEval 提示格式與前一步的生成做成對比較，據此早停。

自我指令創建：新提示由固定模型 Llama 2-Chat 70B 以 8-shot 提示生成（6 個示範取自 IFT 資料、2 個取自模型生成資料，T=0.6、p=0.9），並套用 Self-Instruct 的非分類任務模板與過濾（ROUGE-L 相似度檢查、關鍵字過濾、長度過濾）。除提示生成外，其餘（生成回應、評估回應）都由正在訓練中的自我獎勵模型執行。候選回應取 N=4（T=0.7、p=0.9）。因評分有變異，評估時同樣用抽樣解碼、重複產生 3 次取平均。最終加入 3,964 個偏好對構成 AIFT(M₁)（用來訓 M₂），6,942 個偏好對構成 AIFT(M₂)（用來訓 M₃）。

3.2 結果

3.2.1 指令遵循能力

EFT+IFT 與純 IFT 表現相當：加入 EFT 任務並未損害指令遵循表現（對戰 30.5% vs 30.9%）。這是好消息——自我獎勵能力的增強不影響其他技能，因此可用 IFT+EFT 訓練當作第 1 輪（M₁），再往下迭代。

第 2 輪勝過第 1 輪與 SFT baseline：M₂ vs M₁ 為 55.5% : 11.7%；M₂ vs SFT baseline 為 49.2% : 14.5%。使用第 1 輪獎勵模型所提供的 AIFT(M₁) 偏好資料，帶來明顯的效能躍升。

第 3 輪再勝過第 2 輪：M₃ vs M₂ 為 47.7% : 12.5%；M₃ vs SFT baseline 提高到 62.5% : 9.8%（勝率高於 M₂ 當時的表現）。

AlpacaEval 2 排行榜（對 GPT-4 Turbo 勝率）：第 1 輪 9.94% → 第 2 輪 15.38% → 第 3 輪 20.44%。M₃ 勝過榜上多個模型，包括 Claude 2（17.19%）、Gemini Pro（16.85%）、GPT-4 0613（15.76%）、GPT-3.5 Turbo 0613（14.13%）、LLaMA2 Chat 70B（13.87%）、Vicuna 33B v1.3（12.71%）；GPT-4 0314（22.07%）與 Mistral Medium（21.86%）仍在其上。值得注意的是，許多競爭模型使用專有對齊資料（動輒逾百萬筆標註）或從更強模型蒸餾的目標，而本方法僅從 Open Assistant 的少量種子資料出發，其後的目標與獎勵全由模型自己產生。

細分析（以 GPT-4 把 AlpacaEval 測試集依指令類別、指令複雜度、期望回應長度分群；圖 4）：(i) 多數類別的勝率都顯著提升，但數學與邏輯推理類沒有改善，顯示目前的訓練方式主要是讓模型更善於運用既有知識；(ii) 各種複雜度的任務勝率幾乎都上升，尤其是稍難的（10 分制中的 5、6、7 分）；(iii) 各種期望回應長度的任務勝率也穩定上升。

資料分佈分析：對 IFT、EFT、AIFT(M₁) 做 t-SNE 視覺化，發現 IFT 與 AIFT(M₁) 重疊良好（符合預期），而 EFT 落在嵌入空間的不同區域，這可解釋為何 EFT 不影響 IFT 表現。此外，AlpacaEval 上 M₁ 生成的平均長度為 1092、M₂ 為 1552、M₃ 為 2552——模型學會產生更長的回應，作者指出這可能是相對表現的一項因素。

人類評估：從 IFT 測試集隨機抽 50 題，每題三組配對（baseline vs M₁/M₂/M₃），各交三位標註者（作者盲測）成對判斷後多數決。結果與 GPT-4 判斷一致：越後面的迭代對 SFT baseline 的優勢越大。

MT-Bench（10 分制）：SFT baseline 總分 6.85（數學/程式/推理 3.93、人文等 8.60）；M₁ 6.78（3.83 / 8.55）、M₂ 7.01（4.05 / 8.79）、M₃ 7.25（4.17 / 9.10）。人文、STEM、角色扮演、寫作、抽取類增益較大，數學／程式／推理增益較小——作者認為是 Open Assistant 種子提示偏少推理任務所致。此外本法只構造單輪提示，MT-Bench 卻是多輪評測。

NLP 基準未見能力流失（表 3）：Llama 2 / SFT baseline / M₁ / M₂ / M₃ 依序為 ARC-challenge 57.40 / 55.97 / 57.51 / 54.51 / 53.13；HellaSwag 85.30 / 85.17 / 84.99 / 84.27 / 83.29；GSM8K 56.80 / 50.72 / 60.27 / 59.29 / 57.70；MMLU 68.90 / 69.76 / 69.34 / 69.31 / 69.37；NQ 25.30 / 34.35 / 35.48 / 33.07 / 31.86。大致與基線相當。作者推測因訓練資料（種子與合成）都基於 Open Assistant 提示，與這些任務所需技能關聯不大，故表現持平甚至略降；並引 InstructGPT 所稱的「對齊稅（alignment tax）」。未來方向是把自我獎勵範式擴及更多樣的種子提示來源。

3.2.2 獎勵建模能力

EFT 擴增優於 SFT baseline：加入 EFT 資料（示範如何當 LLM-as-a-Judge）自然優於只用 IFT。IFT 涵蓋廣泛任務，本身已賦予 SFT baseline 一定的評估能力，但 EFT 提供更多此特定任務的範例。五項指標全面提升，例如與人類的成對準確率由 65.1% 升至 78.7%。

獎勵建模能力隨自我訓練提升（表 4，SFT baseline / M₁ / M₂ / M₃）：成對準確率 65.1% → 78.7% → 80.4% → 81.7%；5-best % 39.6 → 41.5 → 44.3 → 43.2；完全匹配率 10.1 → 13.1 → 14.3 → 14.3；Spearman 0.253 → 0.279 → 0.331 → 0.349；Kendall τ 0.233 → 0.253 → 0.315 → 0.324。M₂ 是用 M₁ 的獎勵模型訓練出來的，卻在全部五項指標上勝過 M₁；M₃ 又在多項指標上勝過 M₂。且過程中沒有再提供任何新的 EFT 資料，自我指令創建迴圈產生的樣本看起來也不像 LLM-as-a-Judge 訓練樣本——作者推測是因為模型的一般指令遵循能力變好，連帶讓 LLM-as-a-Judge 任務也做得更好。

LLM-as-a-Judge 提示的重要性：前期實驗嘗試過多種提示。例如 Li et al. (2024) 提出的另一種 5 分制，把選項描述成「品質分桶的多選題」；本文則把分數描述為加法式、涵蓋品質的多個面向。兩者在 SFT baseline 上差距極大：本文提示為 65.1% 成對準確率，對方僅 26.6%。
