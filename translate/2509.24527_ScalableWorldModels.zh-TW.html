論文／訪談原始來源

Training Agents Inside of Scalable World Models

摘要與第 1 節：問題

世界模型可以從影片學一般知識，再讓 agent 在想像軌跡中訓練，避開昂貴或危險的真實互動。既有 Dreamer 類模型在窄任務上快速可靠，卻難以擬合複雜視覺分佈；大型可控影片模型雖能生成多樣場景，又常無法精確保持物件互動與遊戲規則，推論成本也太高，不適合大量 imagination training。

Dreamer 4 試圖把兩邊接起來：用可擴展影片模型學 Minecraft 的像素動態，以低階滑鼠和鍵盤動作控制，再完全在模型內做強化學習。作者選擇離線挖鑽石作為長視野測試，因為它需要依序蒐集材料、製作工具並操作遊戲介面，且不能讓訓練中 agent 接觸真實環境。

第 2 節與第 3 節概觀：從 flow model 到 agent

模型以 flow matching 為基礎，並結合 shortcut model 與 diffusion forcing。shortcut model 額外接收步長，學習用少量網路 forward pass 跳過多個去噪步驟；diffusion forcing 則讓序列中不同時間點具有不同噪聲程度，使每個位置同時是去噪目標與後續時間的歷史條件。

整體訓練分三階段。先以影片預訓練 causal tokenizer 與 dynamics model；再插入 task token，微調 policy 與 reward head；最後從資料集 context 啟動 world-model rollout，只更新 policy 與 value head，在想像中做強化學習。tokenizer 和 dynamics 共用 block-causal transformer 設計，時間上因果、同一時間內可互相注意。

第 3.1 節：Causal Tokenizer

tokenizer 把原始影片壓成連續 latent sequence，包含 encoder、低維 bottleneck 與 decoder。時間因果結構讓它利用過去做壓縮，同時仍可逐影格解碼，符合互動推論需求。訓練目標結合 pixel MSE 與 LPIPS，並以 masked autoencoding 隨機遮蔽 image patch。作者觀察這能改善 dynamics 生成影片的空間一致性。

多模態注意力經刻意限制：latent token 可讀取各輸入 modality，但每個 modality 只在自身內部注意；解碼時，各 modality 可讀 latent，latent 本身則不反向混入輸出 token。這使影像、動作與其他訊號能整合，又保留清楚的資訊流。

第 3.2 節：Interactive Dynamics

dynamics model 讀取交錯的 action 與 frozen tokenizer representation。滑鼠、鍵盤等 action component 分別編碼；無 action label 的影片只使用 learned embedding，因此大部分視覺知識可從未標註影片學得，再用較少量對齊資料學 action conditioning。

核心的 shortcut forcing 不是預測高頻 velocity，而是直接預測 clean representation。作者認為逐影格生成時，velocity prediction 的細小誤差會長期累積，x-prediction 較能維持任意長 rollout。訓練另用隨 signal level 線性上升的 loss weight，把容量集中在資訊較多的樣本；推論時逐影格自回歸，並輕微擾動歷史 latent，使模型對自身生成誤差更穩健。

第 3.3 至 3.4 節：Imagination Training 與效率

agent token 接收 task embedding，輸出 policy 與 reward；其他 modality 不能注意 agent token，避免 world model 的未來預測被任務本身直接影響而產生 causal confusion。第一階段 agent finetuning 以 behavior cloning 與 reward modeling 學資料中的行為，第二階段則從資料 context 展開想像軌跡，以 reward head 標註回饋、value head 預測長期 return，再用 PMPO 更新 policy。behavioral prior 約束 policy 留在合理行為分佈附近。

為降低影片 transformer 的運算與 KV cache 成本，架構將空間與時間 attention 分開，只間歇使用 temporal attention，並在 dynamics 採 group-query attention。訓練交替使用大量短 batch 與少量長 batch，最後再以長 batch 微調，避免模型把每段 context 開頭誤認為永遠存在的起始影格。

第 4.1 節：Offline Diamond Challenge（作者自報）

主要資料是 VPT contractor dataset。作者自報，該資料含 2541 小時、低階滑鼠與鍵盤 action 對齊的 Minecraft 影片。評估 episode 從隨機世界與空 inventory 開始，每局六十分鐘；success rate 以一千局計算。Dreamer 4 不在訓練時接觸環境，只在最後評估執行 policy。

比較包含 VPT、從頭訓練的 behavior cloning、以 Gemma 3 初始化的 VLA、使用世界模型表徵的 WM＋BC，以及完整 imagination RL。作者自報，VPT 的離線 policy 使用約多一百倍的資料，卻只穩定進展到 stick；VLA 製作 iron pickaxe 的成功率為 11％。Dreamer 4 在 stone pickaxe 以前的 milestone 超過 90％，iron pickaxe 為 29％，最終在 0.7％ episode 中取得 diamond。雖然絕對鑽石成功率仍低，它是本文設定下第一個只靠離線資料取得鑽石的 agent。

消融比較顯示，world-model representation 用於 behavior cloning 優於從頭訓練與 Gemma 3 表徵；在此基礎上做 imagination training，里程碑越難，成功率改善越明顯，也更快到達目標。這支持影片預測學到的動態資訊能轉移到決策，而模型內強化學習可超越資料直接示範的 policy。

第 4.2 節：人類互動測試（作者自報）

人類玩家直接以滑鼠與鍵盤在 world model 裡完成挖坑、築牆、砍樹、放置與駕船、轉頭後再找物件，以及使用工作台和熔爐等任務。作者將 Dreamer 4 與 Oasis、Lucid-v1、MineWorld 比較，質性結果主張 Dreamer 4 較能保持物件、持有物與玩家建造的結構，其他模型較常視覺退化或幻覺未建造物件。

可用 raw 在比較表剛開始時中止，沒有保留完整量化 human-interaction 表，因此本檔不列勝率或模型規模對照，也不把質性圖例擴張成精確領先幅度。

範圍局限與結論

原文素材沒有獨立限制與結論節。由可見設計可確定的範圍限制是：主要控制證據集中在 Minecraft 與單一離線資料來源；鑽石成功率仍低；reward 來自既有 event annotation，task sequence 也由人工設計；人類互動比較以選定任務和質性生成為主。模型內 RL 的可靠性仰賴 dynamics 與 reward head 在 policy 造訪的想像狀態上仍準確，本文可見段落沒有提供跨遊戲或實體機器人的驗證。

在這個範圍內，Dreamer 4 的結論是可觀察的：高容量影片模型若同時做到快速 action-conditioned rollout、因果 tokenizer 與可訓練的 policy／reward／value 介面，就能把離線影片轉成 agent 的想像訓練場。它展示的是一條可擴展配方，而不是離線長視野控制已經解決。
