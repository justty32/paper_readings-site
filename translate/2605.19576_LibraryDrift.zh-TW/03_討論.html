7. 討論

作為通用故障模式的庫漂移：雖然在技能庫中展示漂移，但定義（式 1）與診斷均不限於技能。基於規則的系統（Zhang et al., 2026b）、工作流記憶（Wang et al., 2024）與情節性儲存均持久化 LLM 編寫的跨任務 artifacts，面對同樣的「累積而無退休」故障。本文主張庫漂移應被認可為與工具使用錯誤、規劃失敗並列的一級故障類別。

診斷先於修復：追蹤級診斷在終端指標下降前就已檢測到漂移。在 A4 中，庫在第 30 輪即崩塌至 2 個 active 技能，但 pass@1 僅顯示緩慢下降——因為 Router 適應性地更頻繁選擇 NONE。沒有逐技能診斷，漂移會顯示為「隨機任務難度變化」，不可見亦無從修復。關鍵地，這些診斷不僅是描述性的，更使反事實干預成為可能：操作員觀察到 Router 參與率跌破 50% 即可在漂移到達終端指標前停止合成並調查。此診斷配方（逐 artifact 貢獻分數、歸因判決、參與指標）可推廣至任何 LLM 代理跨情節累積持久 artifacts 的系統。

治理旋鈕的規模依賴性：Default 是廣泛安全的——除 A4 外每個條件都顯著超越無技能基準，且非發散保證（Prop. 1）不受任務分布影響。然而，具體旋鈕設定是規模依賴的。在 100 任務套件上，meta-skill 單獨提供足夠風格一致性使正則化（A5）與 cover-guard（A6）非必要；在具有數百個候選模式的更大套件上，顯式去重預期將變為 load-bearing。類似地，有界 cap（C=50）可安全加倍（A7 達到可比較均值增益），但以顯著更高方差為代價——每種子增益範圍從 +0.172 到 +0.440——確認放寬 cap 使迴圈暴露於「合成順序運氣」。原則性做法：以 Default 為安全起點，在操作員觀察到 meta-skill 足夠後、循診斷訊號放寬治理旋鈕。

預期與非預期結果：八組消融中三組產生意外。A4 跌破無技能基準——我們預期嚴苛退休會表現不佳，但未預期到會主動傷害，確認證據地板即使在原則上也是 load-bearing。A5/A6 略優於 Default，反駁了我們認為顯式去重有幫助的設計假設——meta-skill 已強制足夠同質性。A8 儘管增加 55% 壁鐘時間僅產生邊際增益，挑戰了「陳舊 meta-skill 限制合成品質」的直覺。給予從業者教訓：治理機制可能適得其反；診斷配方（§4）是使故障可見、安全干預成為可能的關鍵。

限制：(i) 單一基準（MBPP+ hard-100）；推廣至更廣泛領域（多步驟代理、SWE-Bench）留待未來工作。(ii) 單一模型（Claude Opus 4.7）；跨模型穩定性尚未確立。(iii) 診斷閾值（何時干預）為經驗選擇；原則性校準留待未來。(iv) 假設漂移訊號在多步驟代理中更敏感——逐步驟判決可隔離陳舊技能傷害了哪個步驟；經驗驗證留待未來。

8. 結論

自我演化技能庫的瓶頸不是作者，而是圖書管理員。庫漂移——以無生命週期管理的無界累積——是一種沉默的系統性故障模式：同一個在無治理下停滯於 +0.002 的 frozen LLM，一旦加入退休、有界 cap 與寫作先驗，即達成 +0.328。

本文提供：(1) 從兩端框定此故障的可複現觸發器（A1: 無注入地板；A4: 治理誘導傷害）；(2) 在終端指標惡化前檢測漂移的追蹤級診斷；(3) 記錄哪些機制是 load-bearing（退休、meta-skill）與哪些可安全移除（顯式去重）的八組消融實驗。三個意外（A4 有害、A5/A6 超越 Default、A8 成本高但邊際）證明天真治理可能比無治理更糟，使診斷配方對安全干預至關重要。此操作手冊（逐 artifact 貢獻分數、歸因判決、參與指標）同樣可遷移至任何跨情節持久化 LLM 編寫 artifacts 的系統。

附錄 A：系統架構

Ratchet 每輪執行五階段迴圈：(1) Eval：在 held-out 任務上路由 active 技能；(2) Train：在訓練分割上執行相同管線，產生失敗基質；(3) Critic：逐失敗歸因判決（LLM 呼叫）；(4) Synthesizer：按正則模式叢集失敗，為 ≥3 個成員的叢集編寫新技能；(5) Curator：計算貢獻分數、退休表現不佳者、強制 cap。Router 通過兩階段檢索（tf-idf + embedding, K=10 each）後接 LLM 閘，為每任務選取一個技能或 NONE。

附錄 B：超參數

Default 設定：active-cap C=50, Nmin=100, τ=0.10, 正則閾值 0.85, cover 閾值 0.85, 技能 YAML 字元上限 1500, 合成回顧窗口 6 輪， 最小叢集大小 3, 每輪最大技能數 2, Router cutoff=20, 檢索 K=10, rollback τ_rb=0.10, rollback 持久 5 輪， 每 run 100 輪， 每條件 3 組種子（42, 7, 13）。

附錄 D：非發散證明草稿

Proposition 1：令 |S_t| ≤ C，假設 Curator 在 n(s) ≥ Nmin 且 ĉ(s) ≤ −τ 時退休技能 s。在 Hoeffding 界容忍度 ϵ 與逐技能失敗機率 δ 下：以 ≥ 1 − Cδ 的機率（C 個技能的 union bound），每個倖存技能有 c(s) ≥ −τ − ϵ。路由至倖存技能的任務有期望通過機率 ≥ p₀(x) − τ − ϵ；路由至 NONE 的任務實現 p₀(x)。取期望：E[pass@1] ≥ E[p₀] − (τ + ϵ) − Cδ。Default 值（τ=0.10, Nmin=100, C=50, δ=10⁻³）：ϵ ≈ 0.20，地板 = E[p₀] − 0.35。該界在本文規模下偏鬆（系統獲得 +0.328 而非損失 0.35），但排除了無界退化。
