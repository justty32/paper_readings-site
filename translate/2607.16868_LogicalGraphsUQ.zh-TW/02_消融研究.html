4. 相關工作

Token 與語意層級 UQ。早期 UQ 方法從 token 機率推導序列級信心（如平均 log-prob、困惑度、token 熵），這類方法在詞彙層次操作，將表面變化與真正的不確定性混為一談。token 層級校準在 RLHF 微調後已知會退化。語意層級方法透過聚類應對詞彙敏感性：SE 在 NLI 衍生的等價類上計算熵，大幅超越 token 層級基線；KLE 以核捕捉簇間的漸進相似度，代價是額外超參。另有方法納入 logit 評分或自我評估提示——後者往往過度自信且在不確定性對齊上不如 token 方法。與所有這些方法不同，LGU 明確地對生成答案間的藴含與互斥關係建模，從平坦語意聚類走向結構化的邏輯假設空間。

圖結構化表示與長文本 UQ。結構化關係表示廣泛用於因果推理、可靠性工程、圖熵與網絡分析。在 LLM UQ 中，近期工作走向明確的關係結構：有人建構回應-聲明二部圖並經由中心性度量（度、PageRank）估計不確定性；有人則在有向語意依賴圖上定義結構熵。這些方法與我們共享圖基礎直覺，但都沒有如 LGU 般對真值條件的藴含或假設間的相互互斥建模。LUQ 在抽樣回應間聚合聲明層級的藴含一致性；LoGU 進一步區分有支撐、無支撐與受矛盾的聲明，以產生更細粒度的不確定性訊號。

5. 討論

本工作處理了當前 LLM 不確定性量化方法的基礎限制：無法捕捉模型回應底層的邏輯結構。我們提出一個以兩個互補量為核心的邏輯圖框架：Implication Graph Entropy (IGE)，沿 Implication Graph (ImG) 中的邏輯藴含鏈匯聚機率質量；以及 Logical Graph Uncertainty (LGU)，進一步經由 InG 懲罰 ImG 根之間密集的互斥模式。跨多基準與模型家族，LGU 在辨識不可靠產出上提供實質改進——尤其在正確答案邏輯豐富而非僅是平凡重複的開放式設定中——將邏輯連貫性提升為 UQ 景觀中與語意等價平起平坐的一階角色。

限制：第一，框架僅支援藴含與成對互斥，缺乏對更豐富邏輯關係（如因果、時序、可廢推理）的建模。第二，LGU 受限於底層 NLI 模型的固有缺陷——其判斷錯誤會傳播到邏輯圖與不確定性分數。第三，對長文本與多步推理而言，建構邏輯圖的計算成本高昂，需要層次化或近似推理解決方案。最後，評估僅限於短 QA；尚須驗證對話、程式碼生成等其他領域。

廣泛影響聲明：本文提出一種用於估計 LLM 產出不確定性的量化方法，主要目標是促進機器學習研究社群對模型不確定性之理解與評估。
