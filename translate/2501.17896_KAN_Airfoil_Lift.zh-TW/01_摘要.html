摘要

資料科學已成為科學探索的第四範式（與實驗、解析、計算並列）。然而許多 ML 模型像黑箱運作，對其預測推理提供的洞見有限；這種不透明是「從資料生成新知識」的障礙之一。近期提出的 Kolmogorov-Arnold Network（KAN） 是一個內嵌可解釋 AI 的替代模型。本研究展示 KAN 用於新科學探索的潛力：把 KAN 與另外五個熱門監督式 ML 模型，套用到航太工程著名的翼型升力預測問題。使用某早期研究對 2900 個不同翼型 產生的標準資料。KAN 表現最佳，測試資料 R²=96.17%，勝過基線模型與多層感知器（MLP）。透過對模型剪枝與符號化展示 KAN 的可解釋性——得到一條「升力係數對輸入變數」的方程。從 KAN 擷取的可解釋資訊與已知的翼型升力生成物理一致，從而展示其輔助科學探索的潛力。

I. 引言

近年資料科學興起，被視為科學探索的第四範式。藉 ML 已驅動若干新科學發現，但許多模型是黑箱，洞見有限——這是從資料生成新知識的障礙。為此，可解釋 AI（XAI） 興起：方法從 LIME（Local Interpretable Model-Agnostic Explanations） 到較新的 SHAP（Shapley Additive explanations）。但這些方法多聚焦解釋個別預測而非整個模型，限制了追溯模型每階段學習因果的能力。

近期 KAN 被提為內嵌 XAI 的替代模型。這得益於 Kolmogorov-Arnold 表示定理：任何多變數複雜函數可分解為較簡單函數之和。KAN 結構似 MLP，但有可學習的激活函數（B-spline 曲線）在邊與節點上，節點只做求和。這類激活函數比 MLP 更靈活，故 KAN 可更準確且可解釋，可望辨識驅動模型的重要特徵、發現符號公式。

本研究的翼型幾何用 Kulfan 等人提出的 CST（class shape transformation，類形變換） 參數法表示（航太常用），以 Bernstein 多項式 的形狀函數描述翼型；僅 8 個 CST 係數 即可有效涵蓋對稱、非對稱、有彎度、反曲等各種翼型輪廓。

本研究建立 KAN 模型，展示其解釋與詮釋能力，並與其他傳統 ML 模型（含 MLP）比較；以「預測翼型升力係數 C_L」這一著名問題為應用，再用 KAN 的可詮釋性理解升力、形狀與攻角之間的關係，並在已知翼型空氣動力學物理脈絡下討論結果。

II. 方法

翼型表示

以 CST 參數（Bernstein 多項式）表示幾何，8 個 CST 係數涵蓋多種翼型。

資料

取自 Agarwal 等人的研究：對約 2900 個翼型（取自著名的 UIUC 翼型資料庫與 Airfoil Tools 資料庫）估計並發布 8 個 CST 係數；並對每個翼型在低雷諾數（10⁵）、攻角 −4°～+8° 下估計升力係數 C_L 與阻力係數 C_D。本研究以 8 個 CST 係數（c1–c8）+ 攻角 為特徵預測 C_L。資料 33,705 筆、10 特徵、無缺值；但 9 個關注變數（8 CST + C_L）中有 3,266 筆重複值，去重後 30,439 筆，按 75%:25% 切分為訓練 22,829 / 測試 7,610。

機器學習模型

為預測 C_L，開發六個模型：(1) 多元線性迴歸 LR、(2) 決策樹 DTR、(3) 隨機森林 RFR（以線性迴歸為基估計器）、(4) AdaBoost ABR（以線性迴歸為基估計器）、(5) MLP、(6) KAN。

KAN 由 Liu 等人提出，建於 Kolmogorov-Arnold 表示定理、結構似 MLP，但三大差異：

  1. MLP 激活在節點、權重在邊；KAN 激活（B-spline 曲線）在邊上，節點只求和。
  2. MLP 激活固定（sigmoid/ReLU）只學權重；KAN 學激活函數（B-spline）的參數，更靈活。
  3. 因此 KAN 可解釋，兼作 XAI 工具。

KAN 開發步驟：(1) 選網路架構——隱藏層數、各層寬度 w、grid size g、樣條多項式階數 k（皆為可調超參）;(2) 稀疏化與剪枝——依節點/邊重要度分數保留重要者，辨識最主導關係；(3) 符號化（symbolification）——把每條邊上經驗擬合的激活函數，換成 KAN 套件函數庫中擬合 R² 最佳的已知數學函數；(4) 得到連接輸入與輸出的封閉形式方程。

每個模型以兩指標評估：MSE 與 R² 分數；並與 Agarwal 等人提出的基線 ANN 比較。除 LR 與 KAN 外，超參用五折交叉驗證調整。LR 中凡兩變數高相關（>50%）只留其一（故排除 c2、c5、c8 以避免多重共線性）;KAN 則試多組 (w, g, k) 後選定。

超參（Table I 摘要）：MLP＝全連接 [9,9,6,3,2,1]、LeakyReLU、Adam(lr=0.001)、HuberLoss;KAN＝width=[9,9,1]、grid=6、k=2、seed=2024、base_fun='silu'；基線 ANN＝[9,12,6,2] 含 BatchNorm1d、ReLU、HuberLoss。

剪枝細節：調好的全連接 KAN 有 19 節點、90 邊；剪枝保留重要度 > 75 百分位者（node_score>0.2537、edge_score>0.0426）。即使只留全網 25%，測試 R² 仍達 95.60%，接近基線 ANN。剪枝後網路為 11 節點、10 邊。完整 KAN 與最終剪枝符號化 KAN 見 Figure 1（輸入層在底、輸出層在頂，邊粗細表重要度）。

III. 結果與討論

效能（Table II，測試 R²）：

模型 訓練 % 測試 %
KAN 96.14 96.17
MLP 95.88 96.00
ANN（基線） 95.60 95.66
ABR 95.11 95.35
RFR 96.04 95.07
LR 93.83 94.13
DTR 96.26 93.91

KAN 測試 R²=96.17% 最佳，勝基線與 MLP;MLP 次佳（96.00%）；其餘皆遜。令人意外的是 LR 雖簡單卻勝 DTR。

可解釋性：由物理知，翼型幾何（8 CST 係數）與攻角對升力生成的空氣動力學很重要；且不論形狀，攻角顯著影響 C_L。這些被特徵重要度分數（Figure 3） 良好捕捉，清楚展示 KAN 的可解釋性——可揭示最重要變數，引導正確方向的科學探究。

符號化：對剪枝模型每個激活函數選最佳擬合數學函數，得式 1（C_L 對 CST 係數與攻角的方程，Figure 2）。方程呈現複雜非線性關係，與先驗知識一致：翼型即使單一截面形狀改變也影響整個流場與 C_L；此非線性也由 Figure 1 網路圖中「一條連結所有輸入變數與 C_L 的中間邊」呈現。可驗證該方程斜率符合理論預期、與資料一致。

封閉方程的價值：可對任一或所有主導輸入變數求導以估敏感度——對許多科學工程探索極有用，也能建立「輸出不確定性源於輸入不確定性」的關係；對翼型而言可用於求最佳形狀。剪枝與符號化清楚帶出 KAN 內嵌的可解釋性，可輔助科學發現。

IV. 結論

本研究示範以「內嵌可詮釋性」的模型驅動資料科學的科學探索，並在航太工程應用上展示。五個傳統 ML 模型與內嵌可解釋性的 KAN，套用於預測翼型升力係數。KAN 測試 R²=96.17% 最佳，勝基線 ANN 與 MLP。剪枝與符號化以網路圖帶出內嵌可解釋性，最終得一條連結升力、CST 係數與攻角的封閉形式方程。KAN 的可詮釋性被用來導出翼型空氣動力學的有意義資訊，其預測與解釋皆與已知升力物理一致。結論：KAN 具輔助科學探索的潛力。

局限：僅建模 C_L，C_D、C_L/C_D 比有待探索；資料僅低雷諾數（10⁵），其他雷諾數範圍的模型表現亦可探。
