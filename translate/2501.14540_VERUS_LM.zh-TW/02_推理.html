5. 推理

KB 建好後，逐問題：偵測推理任務 → 抽相關資訊 → 交引擎 → 輸出格式化回自然語言。

5.1 偵測推理任務

分為 8 種推理：①模型生成/擴展（生 n 個 T 的模型，部分符號解釋可已給）;②可滿足性;③最優化（找使某項 t 最小/最大的模型）;④傳播（定哪些原子在 T 所有模型中恆真/假）;⑤解釋（為何某原子在所有模型恆真/假，或解釋不一致）;⑥定值域（某函數項可能值的集合）;⑦相關性（哪些符號改值會使模型不再成立）;⑧邏輯蘊涵（T ⊨ φ 否）。1–7 IDP-Z3 直接提供、8 易實作 → 印證 IDP-Z3 的多功能性。

  • 用 BERT 句子分類器（自製 1000+ 問題 + 對應推理任務訓練）偵測。
  • multi-step 模式：把巢狀複雜問題（需一序列推理步）先拆成多步，各步當獨立推理任務，再合併結果（類 CoT）。

5.2 資訊抽取

多數推理任務除 theory T 外還需額外資訊。兩種情況：

  • 抽資料與目標偵測：問題常給部分符號解釋（「Ann 16、Brit 32，誰符合?」→ age 結構）；最優化需知道要最小/最大化哪個項。因此時已知詞彙，可用語言模型文法（如 llama.cpp GNBF grammar）強制輸出符合自動生成的 KB 專屬文法，確保只生正確型別的解釋 → 此剪枝使小語言模型（SLM）達到大 LLM 同等表現，可在筆電跑、省成本又增資料安全（免把敏感資訊傳外部）。
  • 構造複雜公式：如蘊涵任務需在推理時構造 φ，複雜度同 KB 建立 → SLM 不適、須用大 LLM（亦可能新增符號）。目前不自動偵測問題是否含複雜公式（可依應用決定：不在乎成本就always用 LLM、或依偵測到的任務、或訓專屬分類器決定）。

6. 實驗

6.1 驗證

驗證 (1) 引入推理引擎是否確比單獨 LLM 好、(2) 管線能否從 NL 正確辨識 8 種推理任務。因現有資料集多只涵蓋一兩種任務，自製 DivLR（115 問、涵蓋全部 8 任務、6 領域：投資策略/COVID 限制/灌溉/雜工/兩個 BMI 變體）。B* 域用虛構的 BMI 公式與區間（測記憶污染，類似既有實驗）。SLM＝Phi 3.5 mini（3.8B，推理成本約比 GPT-4 低 1 萬倍），LLM＝Gemini 1.5 Pro；在 Mac M2 Pro 32GB 跑。

  • Table 1：V-SLM/V-LLM 一致勝過單獨 SLM/LLM（平均 80.3/91.8 vs 39.5/66.7）。V-SLM 在兩個 BMI 域明顯較差——深入分析：SLM 不肯只抽引擎所需資訊、反而自己算 BMI（訓練資料含 BMI 範例）。LLM 在 B vs B* 掉分（66.7→50，記死真 BMI 定義、無法用顯式給的新定義推理）→ 暗示 LLM 學到過時事實難用 prompt 糾正、需重訓；此效應在 V-LLM 仍可見（88.9→83.3）但推理引擎管線大幅削弱。
  • Table 2：BERT 分類器平均 92.6% 正確辨識推理任務（Propagation 略低）。資訊抽取上多數任務 V-LLM≈V-SLM；最大差在 Entailment（唯一需推理時構造複雜公式者，V-SLM 僅 29.6%）。

結論：(1) 引入引擎確比純 LLM 好；(2) 簡單 BERT 分類器即可辨任務；(3) 只要不需構造複雜公式，SLM 即可抽足夠資訊（但對訓練資料常見概念較不穩）。後續 benchmark：不需構造複雜公式者用 V-SLM、否則 V-LLM。

6.2 與 SOTA 比較

benchmark（Table 3）：PrOntoQA（可滿足性，500）、ProofWriter（傳播，600）、FOLIO（蘊涵，204）、LogicalDeduction（可滿足性，300）、AR-LSAT（多種推理，231）。對手：GPT-4 直答、GPT-4 CoT、LINC、Logic-LM、SymbCoT。

  • Table 4：前四 benchmark 各系統相近（VERUS-LM 至多比最佳低 5%，且不用資料集專屬 prompt）;AR-LSAT：VERUS-LM 68.36 顯著勝所有方法，比次佳（SymbCoT 43.91）高約 25%。平均 85.02（最高）、標準差 11.49（最低，最穩）。歸功：(1) 通用性（不用任務專屬 in-context 範例）;(2) FO(·) 表達力（如聚合「至少 3 張 CD 特價」#{c∈CD:on_sale(c)}≥3）;(3) 支援多推理任務（AR-LSAT 中偵測並執行了 4 種，Table 5）。

6.3 自我精煉效果

Table 6：語法精煉平均 +11.2% 執行率（執行準確度大致不變 → 被修正的 KB 與本就正確的 KB 一樣可靠）；再加語意精煉再 +10% 執行率（處理原本不可滿足的 KB，如矛盾公式或型別錯；這類錯多源於 NL 難懂、故也較難正確修，使執行準確度略降，但 total accuracy 仍顯著升）。

7. 局限

  • 無形式正確性驗證（NeSy 此類通病：NL 有歧義、LLM 會錯）→ 擬引入無邏輯經驗的領域專家 in-the-loop 驗證。
  • FO(·) 表達力有限（不適高階邏輯/真 OWA，模擬 OWA 僅近似）；語意精煉非總適用（如假新聞推理可預期不可滿足）；繼承 solver 局限（超大域 SAT）；通用 prompt 在完全不同邏輯範式的準確度仍不確定。

8. 結論

VERUS-LM 整合語言模型與符號推理：兩階段把 KB 建立與推理分離，同 KB 可做多種推理任務 → 同域多問可複用 KB 高效作答；並把 SOTA 的語法精煉擴展出基於可滿足性的語意精煉（實驗證有效）。VERUS-LM 在困難多樣的 AR-LSAT 上顯著勝 SOTA，於較簡單 benchmark 上保持競爭力。
