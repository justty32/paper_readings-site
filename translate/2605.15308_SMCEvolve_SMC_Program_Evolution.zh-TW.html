論文／訪談原始來源

SMCEvolve：以序貫蒙地卡羅演化做有原則的科學發現

美國（俄亥俄州立大學）

摘要

LLM 驅動的程式演化（AlphaEvolve、ShinkaEvolve）缺原則性基礎與收斂保證：組件手工設計、無法判斷收斂或停滯、資源低效。本文把程式搜尋重構為對獎勵傾斜目標分布取樣的序貫蒙地卡羅（SMC）問題，用單一溫度參數統一導出父代選擇/突變/停止，並給出首個有限樣本收斂保證。

1. 引言

中心問題：能否把 LLM 程式演化奠基於嚴謹機率框架？指出既有系統三大缺陷（孤立組件設計、無收斂保證、低效）。

2. 方法

  • 獎勵傾斜形式化：p*(x|q) ∝ p₀(x|q)·exp(βR(x))。
  • 機制 1 自適應父代重採樣：重要性權重 Wₜ⁽ⁿ⁾ = exp((βₜ−βₜ₋₁)R(xₜ₋₁⁽ⁿ⁾)) / Σ_m exp((βₜ−βₜ₋₁)R(xₜ₋₁⁽ᵐ⁾))；早期近均勻（探索）、後期集中高獎勵（利用）。
  • 機制 2 帶接受的突變混合：四核 M¹⁻⁴（局部/全重寫 × 有無同儕啟發）；MH 接受 αₜ(x,x')=min{1, exp(βₜ(R(x')−R(x)))}；Thompson 採樣依近期成功率挑核；每步 K 次提案助混合。
  • 機制 3 自動收斂控制：以 ESS 二分排程溫度（找 λₜ 使 ESS(λ)=κN），λₜ=1 自動終止，免預設總迭代 T。

3. 收斂分析

定理 3.1（有限樣本複雜度界）：ℬ = Õ((ε⁻²∨κ⁻¹)/(1−ρ)·β·ΔR)，ℬ=NTK=總 LLM 呼叫、ε 誤差容差、κ 橋接規則性、ρ 突變核混合率、β·ΔR 獎勵強度。表示以高機率（≥3/4）逼近目標分布所需預算，由問題難度與核性質明確參數化。

4. 實驗

  • 數學發現（10 題）：Circle Packing N=21 達 0.9993（vs ShinkaEvolve 0.9514），192 次呼叫（基線 200）。
  • 演算法效率（8 題）：convolve2d_full_fill 11.6×（vs 1.27×）、fft_cmplx_scipy 9.23×（vs 1.1×）；288–480 次（基線 500）。
  • 符號迴歸（16 題）：跨生物物理/化學反應/材料科學，普遍持平或更佳；256–384 次（基線 400）。
  • AutoResearch（TinyStories GPT 預訓練）：最高最終 reward，遠少呼叫即自動終止。
  • 消融（Circle Packing）：均勻 0.9514 / 貪婪 0.9760 / 自適應混合 0.9993；單核上限 0.9929 / Thompson 混合 0.9993；N=8,K=2（0.9993）勝 N=4,K=4 與 N=16,K=1（皆 0.9379）。效能提升伴隨算力降低。

5. 結論

SMCEvolve 把父代選擇、突變、停止統一在單一溫度 βₜ 的探索-利用連續譜下，源自 SMC 理論，兼得理論保證與實證提升。

局限：橋接規則性假設的正式刻畫仍開放；黑箱 LLM 僅能用獎勵代理 MH 比值；複雜度界可再緊；聚焦單目標，多目標/無獎勵未探索。
