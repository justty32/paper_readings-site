論文／訪談原始來源

複雜網路上的符號基礎迴歸器（SFR）

摘要

科學中我們不只關心預測，也關心預測如何做出——具體說底層可解釋模型長什麼樣。資料驅動 ML 能大幅簡化「發現科學定律」這個複雜耗時的傳統手工過程。本文提出預訓練符號基礎迴歸器，能有效壓縮含眾多交互變數的複雜資料、同時產出可解釋的物理表示。模型在非網路 SR、複雜網路 SR、跨領域（物理/生化/生態/流行病）的網路動力學推斷上嚴格測試。結果顯示方程推斷效率顯著提升——比 baseline 有效 3 倍、同時保持準確預測。並應用於從全球疫情爆發資料揭示更直觀的交互傳播律、達最佳擬合。此模型把預訓練 SR 模型的應用邊界擴展到複雜網路。

引言

AI 能加速科學定律發現。資料驅動挖符號科學律可溯至 1950s 遺傳演算法（Eureqa、GPLearn、PySR 等已用於聲子晶體設計、黑洞質量標度、重離子碰撞噴流背景減除）。LLM（ChatGPT、DeepSeek）達新階段（蛋白質設計、自然演化模擬），因建於大量資料知識而通用。但複雜現象常源於眾多相互關聯變數的協同演化——全球疫情傳播涉 200+ 國家地區的自由變數，若細到個人則上億自由變數。

本文提出複雜網路上的符號基礎迴歸器，處理「大量相關變數」的時空資料、高效重建支配方程。造 ~20 億條網路數學表達式預訓練基礎模型，學「資料空間→表達式空間」的統一映射。網路動力學場景中 1.2 分鐘重建方程（比搜尋/學習法快 >3 倍），真實全球傳染病爆發新律 <0.5 分鐘。這是首個專為複雜網路設計的基礎符號迴歸模型，把預訓練模型擴展到「大量變數的複雜現象」。

結果

科學律發現可建模為 D→L（D 觀測資料、L 科學律）。人類科學家把複雜現象的時空觀測歸納為可解釋物理表示（壓縮）；之後查詢（預測/調控/分析）時只用表示而非原始資料回應（解壓縮）。本文聚焦用 ML 模仿人類學習的壓縮部分（比數值法直接解的解壓縮更難）。

複雜網路 SR 的普遍性

複雜網路 SR：y_i = f(x_i, {x_j : j∈N(i)})——輸入含節點自身狀態 + 鄰居狀態；傳統 SR 是特例（單獨節點無鄰居）。節點鄰居數不一（依拓撲）、狀態可多維。拓撲多樣 + 高維變數的彈性方程組合 → 預訓練模型須準確表示巨大拓撲與方程空間，極具挑戰。

經局部取樣解耦拓撲：表示大拓撲結構空間（各種尺度/類型/度分布/生成參數）看似不可能。繞道：引入取樣策略收集「獨立於全域拓撲特徵」的局部觀測。因「節點與其鄰居」是拓撲基本積木 → 把觀測樣本建模為三元組（中央節點 x_i + 直連鄰居 {x_j} + 輸出 y_i）；取樣不同中央節點 → 解耦觀測與拓撲尺度/類型，聚焦局部區域（利於現實常見的不完整觀測、增建模彈性如異質傳播方程）。

經物理先驗簡化方程：面對複雜高維方程，逐一加長測試可能耗時超過宇宙年齡。用物理先驗——網路狀態受自身 + 鄰居狀態影響 → 把方程分解為 self 部分 f_self(x_i) + interaction 部分 Σ_j A_ij·f_int(x_i,x_j)（A 是鄰接矩陣；f_self 描述個別節點演化、f_int 描述鄰居交互）。故 f 由兩函數構成。此分解可行性/普遍性已被確認（適配廣譜真實資訊傳播機制）。關鍵：學固定的 1 元 f_self + 2 元 f_int，而非直接推可變的 n 元 f → 達降維。局部取樣 + 物理先驗的普遍性奠定模型基礎。

SFR 整體流程（三步）

  1. 造方程語料 + 合成觀測資料：不像 NLP 可用大量真實資料，真實網路觀測完整資料 + 標註方程稀缺 → 造夠豐富的方程語料、從中取樣。隨機生成表達式樹（葉＝常數/變數、非葉＝運算子；規則：避免巢狀三角/指數、interaction 至少一項）→ ~20 億條有效網路方程。取樣多種拓撲（grid/random/power-law/small-world/community）；從域空間（標準常態）取輸入模擬輸出 → 訓練樣本。
  2. set-to-sequence 雙分支模型：因輸入是集合 → 集合到序列的翻譯問題。提出雙分支 set-to-sequence 模型：資料表示模型（基於 Set Transformer，把觀測集映到表示空間） + self 分支 + interaction 分支（兩個 transformer 解碼器同步自迴歸生 f_self 與 f_int 的前綴表達式序列）。用 cross-entropy 充分預訓練。
  3. 下游應用：單次前向傳播出目標方程。因訓練資料採自已知分布、真實分布常未知且不同 → 輸入前做 scaling 變換轉成模型期望分布；模型出方程後用 BFGS 優化常數增精度、再 unscaling。constrained beam search 可納入專家/LLM 領域知識（與既有 LLM 整合的介面、增彈性）。

驗證

  • 非網路 SR（圖 2）：對比 PySR（搜尋）、SINDy（學習）、NeSymRes/E2E（預訓練），SFR 在 R² 與準確度（預測與真實相對誤差 <閾值的資料點百分比）上顯著勝，尤嚴格指標。
  • 所需資料點少（圖 3c）：正常方程 40+ 個（節點數×時間步）即可、複雜方程 60+ → 適合稀疏難取資料的現實。
  • 網路動力學（6 場景）：Gene 基因調控/Heat 熱擴散/Epi 疫情/Bio 生化/LV Lotka-Volterra/Mutu 互利。對比 GNN+GP（搜尋）與 TPSINDy（學習），SFR 全指標最佳（不論拓撲/線性非線性）;1.2 分鐘重建最準控制方程（圖 4b）。LV 動力學於 community 結構：GNN+GP 與 SFR 擬合都遠勝 TPSINDy，但 SFR 預測誤差最小、輸出方程最接近真實。
  • 真實全球疫情：揭示更直觀的交互傳播律、最佳擬合，<0.5 分鐘。

結論

SFR 是首個為複雜網路設計的基礎 SR 模型，把預訓練 SR 擴展到「大量變數的複雜現象」。可作為加速科學律發現、增強 SR 工具實用性的基礎，是邁向「AI 科學家」長期目標的重要一步。
