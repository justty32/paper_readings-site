論文／訪談原始來源

EMMA：有歸屬的多agent episodic memory

第1–3節：記憶是外部配置

Controller、sub-agents與reflector共用同backbone，weights固定；training只更新外部文字配置。三層為controller routing memory、agent prompts、procedural skills。Controller讀index自行選load，非similarity retrieval，可不載；specialists執行時繼承generalist的當前prompt，自己的prompt只放specialization；skills按step派發全文。（§2–3.1）

Controller一次dispatch一step，讀結果後續做／改剩餘plan／終止，executor只見curated prior-output summary。Context／round overflow用partial trace拆成existing agents可做的較小steps，splice回同位置、保完成工作並記overflow證據。不是固定整條plan或無限新增agents。（§3.1.2）

第3.2節、附錄A–B／E：LLM診斷與guards

Reflector讀plan、每round code、evaluator digest、prior revisions、prompts、skills及overflow，必要時inspect logs；依localize→classify→generalize→minimize提出一action。歸屬為：一次execution slip只本task revise_plan／no_change；一般behavior改prompt；procedure改／建skill；missing capability優先skill、必要才agent；routing改controller memory／plan，有overflow才可建agent。

通用behavior寫generalist、role-specific寫specialization。附錄E允許failing specialist繼承generalist時，後者未直接參與仍可修通用prompt，不能把participant-only概述絕對化。（表1、附錄E）

每failed revision只一entry／level。Guards核scope–action、strategy change、leakage、prompt preservation及bounded growth：保≥60%原prompt lines、prompt≤6000chars；agents≤10含seed、skills≤40且各≤3000chars；specialization≥150chars。檢reference answer、15-word verbatim task spans及dataset/run paths；這不證語意洩漏或錯誤lesson全被識別。

同level不可連續超過兩failed cycles；同step連兩次overflow須改工作split。拒絕理由回reflector、最多3次後no_change；新／改skill-agent要在rerun plan實際exercise。LLM仍負責scope診斷與泛化，guards保acceptance envelope，不保edit語意正確。（§3.2、附錄B；語意界線為本檔補註，非作者自陳）

第3.3節：training與test邊界

每task fresh environment，最多5revisions／6executions，success即停、最後failure不再留未測edit。Accepted edits即使rerun仍失敗也持久。每chain後另做至多2條controller update（pass或fail），不是每task只一條memory。固定order一pass後freeze，每benchmark-backbone一artifact、無checkpoint selection。

Heldout仍可select memory／replan／overflow decomposition，不呼叫reflector或寫persistent memory。Controller最多load15entries／12000chars，plan15steps、每agent-step30rounds。Gate：Krama Opus4.5 judge、AppWorld tests、BBEH exact match；weights固定不等沒LLM成本。（§3.3、算法A、表6）

第5.1節、附錄C–D：實驗分母與baselines

五backbones為Opus5、Sonnet5、GLM-5、DeepSeekv3.2、Kimi-K2.5。各method同disjoint split：Krama28train／76eval、六domains macro accuracy；AppWorld90train／168normal／417challenge、TGC／SGC（同scenario所有variants需pass）；challenge用training未見app。BBEH-mini23類各4train／16eval，共92／368，equal-size使macro=micro。（§5.1、附錄C）

ACE學playbook並best-validation選；GEPA prompt evolution＋training-split validation Pareto；EvoMAS三steps演化whole配置、oracle metric減cost；ADAS code search、budget matched GEPA，AppWorld DS／Kimi未勝seed時報hand-written seed。ACE AppWorld只見pass/fail與trace。皆train學artifact再freeze，但selection／feedback／objectives不同，非等tokens／wall-time或只差guard。（附錄D；公平性界線為本檔補註，非作者自陳）

第6節：限制

Accepted edits即使chain未解仍保留，可能有無效／有害entry；mini-batch cross-verification、多epochs及強reflector配弱executors均是future work。Backbone-independent只指guards的規約，diagnosis／generalization品質仍依model，不能當語意正確或無interference保證。（§6；最後保證界線為本檔補註，非作者自陳）
