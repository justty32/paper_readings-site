論文／訪談原始來源

AXIOM：以信任優先的神經符號執行架構實現可驗證數學推理

逐節精要翻譯（非逐字）。原文 arXiv:2606.00671v1（獨立研究者 Alessio Bruno）。

摘要

我們提出 AXIOM，一個面向自然語言數學推理的信任優先神經符號執行架構。在 AXIOM 中，語言模型嚴格充當正規化器（canonicalizer）：把非正式題目文字改寫成一個狹窄 schema，供確定性的電腦代數系統（CAS）管線消費，由後者推導並驗證答案，或以棄答（abstain）作為一等公民輸出。路由遵循 1:1:1 對齊——題型 regex ↔ schema 專屬 prompt ↔ 封閉式 CAS handler，已上線 3,100+ 條路由，跨 250+ 次連續 ship commit 零 lost_correct 回歸。我們在 4 個 MATH 類別上報告累計正確率 94.36%（2,592/2,747），且在可解析題上達 100% 信任（零自信而錯）。

1 引言

  • 不可驗證的 LLM 數學問題：純 LLM 會「自信地答錯」，且對錯只能事後靠 benchmark 判定，無法在 API 邊界給可信保證。
  • 信任優先 vs 準確率優先：問題若能很高信任即便準確率不高也值得——AXIOM 寧可明確棄答也不產出「自信但錯」。
  • 自底向上的架構承諾：覆蓋率靠逐條增加路由建立。
  • 可重現性：報告完整流程與指標。

2 架構

  • 2.1 1:1:1 任務路由對齊：每條路由把「題型 regex」「schema 專屬 prompt」「封閉式 CAS handler」一一對齊。
  • 2.2 棄答為一等輸出：謂詞無法識別/題型未涵蓋即棄答，而非硬猜。
  • 2.3 組合任務鏈框架：多任務可串成鏈。
  • 2.4 純規則架構特例：完全不需 LLM 的特例。

3 實證評估

  • 3.1 各領域 MATH 覆蓋：4 類別累計 94.36%（2,592/2,747），可解析題 100% 信任。
  • 3.2 lm-eval 算術（結構正確性）：2 萬筆基準，覆蓋約 88% 算術記錄；可解析子集結構正確性達 100%。
  • 3.3 真實生產分布：
    • 各推理路徑的延遲；
    • API 邊界零「自信而錯」事件;
    • 「無任務池（no-task pool）」成為發現新領域的架構通道；
    • 撰稿期間 registry 仍持續擴張。
  • 3.4 與純 LLM CoT 對比：兩種架構哲學而非單純競賽；AXIOM 的優勢在更難領域上呈凸性放大（越難差距越大）。
  • 3.5 任務局部化 prompting 的 token 效率：靠局部化降低 token 用量。

4 討論

  • 4.1 運維原則形式化：
    • 原則 1：math-template 分桶；
    • 原則 2：LOST_CORRECT 掃描當回歸 oracle;
    • 原則 3：predicate-not-recognized 必須棄答；
    • 原則 4：新領域以「可解析優先」上線。
  • 4.2 線性回報組合：任務鏈組合呈線性回報。
  • 4.3 局限：視覺鎖定記錄；NLP 不可化約的應用題；Intermediate Algebra 天花板；自底向上承諾（需持續人工擴張路由）。

5 相關工作

LLM 數學推理 benchmark;LLM 副駕的定理證明；符號與神經符號系統；信任與可驗證性框架。

6 結論：今天的棄答，明天的正確

AXIOM 以「LLM 僅正規化 ＋ CAS 確定性推導驗證 ＋ 棄答為一等公民 ＋ 1:1:1 路由」實現可信賴的數學推理；每一次棄答都標記出可被未來路由補上的缺口——今天棄答，明天即可轉為正確。
