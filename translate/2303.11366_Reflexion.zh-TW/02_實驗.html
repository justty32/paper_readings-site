4. 實驗

在決策、推理、程式三類任務評估：HotPotQA（搜尋式問答）、AlfWorld（家務多步任務）、HumanEval/MBPP/LeetcodeHard（程式撰寫）。最顯著結果：AlfWorld +22%、HotPotQA +20%、HumanEval +11%。

4.1 序列決策：ALFWorld

AlfWorld 是基於 TextWorld 的文字互動環境，含 134 個環境、六類任務（找隱藏物、搬移物件、以物操物）。用 ReAct 當動作生成器。因環境只在任務完成時給訊號，需自我評估，故實作兩種：LLM 自然語言分類，與手寫啟發式（若同一動作同一回應重複超過 3 個循環、或當前環境動作數超過 30，即判定規劃低效並觸發自我反思）。基線觸發時直接重置重試（跳過反思）；Reflexion 則用反思找錯、更新記憶、再重試。記憶截斷為最近 3 條反思。

結果：ReAct+Reflexion 用簡單啟發式偵測幻覺與低效規劃，解出 130/134 題，並在 12 次連續試驗中持續學會更多題；ReAct-only 在第 6–7 試就停止進步。分析：基線常見錯誤是智能體「以為拿到某物件卻其實沒拿到」，之後在長軌跡中無法回溯找錯。Reflexion 用反思把長而失敗的軌跡蒸餾成可當「自我提示」的經驗，幾乎消除此類錯誤。長期記憶在兩種情形幫上忙：(1) 長軌跡中的早期錯誤易被辨識，可換動作或換長期計畫；(2) 待查表面/容器太多時，能跨試驗累積經驗徹底搜尋房間。ReAct-only 收斂在 22% 幻覺率且無長期恢復跡象。

4.2 推理：HotpotQA

HotPotQA 為維基百科式、11.3 萬題的多跳問答。為隔離「純推理」能力，實作 Reflexion+CoT，做 Q→A 與 Q,C_gt→A（C_gt＝真值脈絡）；為測「整體問答」（需推理＋動作選擇），實作 Reflexion+ReAct（用維基 API 檢索脈絡）。試驗間用 exact-match 給二元成功訊號，再由自我反思迴圈放大，記憶大小 3。

結果：Reflexion 大幅超越所有基線。ReAct-only、CoT-only、CoT(GT)-only 在溫度 0.7 下無法在後續試驗解出首試失敗的題目。CoT(GT) 因有真值脈絡故準確率較高，但仍有 39% 題答錯；Reflexion 在無真值答案下幫智能體修正、準確率提升 14%。分析（消融）：以 CoT(GT) 為基線，先加「情節記憶（EPM，納入最近軌跡）」，再加標準自我反思步驟。結果顯示自我反思較「僅情節記憶」再帶來 +8% 絕對增益，支持「refinement-only 不如 reflection-guided refinement」。

4.3 程式

在 MBPP、HumanEval、LeetcodeHardGym 上評估 Python 與 Rust 程式撰寫。用 MultiPL-E 編譯器把 HumanEval/MBPP 子集翻成 Rust（示範 Reflexion 對直譯與編譯語言皆語言無關）。LeetcodeHardGym 含 40 題 hard、發布於 GPT-4 預訓練截止（2022-10-08）之後。程式任務可用更接地的自我評估（自生單元測試套件），故符合 pass@1 資格：用 CoT 生成多樣測試、以能否建構有效 AST 過濾語法、取樣最多 6 條組成測試套件 T。程式智能體記憶上限設 1 條經驗。

結果（表 1，pass@1）：HumanEval PY 91.0（前 SOTA GPT-4 80.1）；HumanEval RS 68.0（GPT-4 60.0）；MBPP PY 77.1（GPT-4 80.1，唯一落後）；MBPP RS 75.4（GPT-4 70.9）；Leetcode Hard PY 15.0（GPT-4 7.5）。

分析：自我反思程式智能體受限於「能否寫出多樣、完整的測試」。若測試套件不穩，可能出現：偽陽性（所有測試在錯誤解上通過→過早回報無效提交）或偽陰性（測試在正確解上失敗）。Reflexion 下偽陰性優於偽陽性——智能體可藉反思辨識出錯誤測試、保留原本正確的實作。表 2 顯示 MBPP Python 的偽陽性率 16.3%，遠高於 HumanEval Python 的 1.4%，正是 MBPP PY 落後的主因。

消融研究（表 3，HumanEval Rust 最難 50 題，GPT-4 為底）：(a) 拿掉內部測試生成與執行 → 52% vs 60%（基線），代表沒有單元測試時智能體無法判斷當前實作是否正確、被迫每輪都改動、做出有害編輯；(b) 拿掉失敗後的自然語言反思步驟 → 不優於基線，代表僅靠「測試生成＋編譯」能抓語法/邏輯錯，但修正並未反映這些指示。此結果顯示：近期若干「盲目試錯除錯、無自我反思」的方法，在較難任務（如寫複雜 Rust 程式）上是無效的。

5. 局限

Reflexion 本質是用自然語言做策略最佳化——策略最佳化雖能藉經驗改進動作選擇，仍可能陷入非最優的局部極小。本研究把長期記憶限制為有最大容量的滑動窗口，鼓勵未來以向量嵌入資料庫或傳統 SQL 資料庫等更進階結構擴充。就程式而言，TDD 在指定精確輸入輸出映射時有諸多實務限制：非確定性生成函式、與 API 互動的不純函式、隨硬體規格變動輸出的函式、以及難以預測的並行/並發行為。

6. 更廣泛影響

LLM 愈來愈常與外部環境（網際網路、軟體、機器人）及人類互動。本工作有潛力賦能這些智能體提升自動化與效率，但也放大濫用風險，需在安全與倫理上投入更多。另一方面，RL 長期受困於黑箱策略、可解釋性與對齊困難；「言語」強化學習或能讓自主智能體更可解釋、可診斷——例如工具使用太複雜難懂時，可監看自我反思以確保使用工具前意圖正當。

7. 結論

本文提出 Reflexion，利用言語強化教智能體從過去錯誤中學習，實證顯著超越目前廣泛使用的決策方法。未來可把傳統 RL 中深入研究的技術（自然語言中的 value learning、off-policy 探索）引入。

8. 可重現性

強烈建議在隔離的執行環境中進行自主寫碼實驗，因生成程式碼在執行前未經驗證。
