摘要

LLM 越來越多被用來演化程式與多智能體系統，但多數現有方法依賴覆寫式突變，每次只維持一個候選——丟棄有用變體、受破壞性編輯所苦、探索一個易結構失敗的脆弱空間。我們提出 EvoLattice：把整個候選程式/智能體行為的族群表徵在單一有向無環圖中。每個節點存多個持久的替代方案（alternatives），圖中每條合法路徑定義一個不同的可執行候選，於是在不複製結構下得到龐大組合搜尋空間。EvoLattice 對「每個替代方案出現的所有路徑」逐一評分，做細粒度的替代方案層級評估，產生「局部設計選擇如何影響全域效能」的統計。這些統計為 LLM 引導的突變、重組、剪枝提供密集、資料驅動的回饋訊號，同時保留成功組件。結構正確性由確定性自我修復機制保證（強制無環與依賴一致，獨立於 LLM）。EvoLattice 自然延伸到智能體演化——把替代方案詮釋為 prompt 片段或子智能體行為。橫跨程式合成（代理與優化器元學習），EvoLattice 比既有 LLM 引導法產生更穩定的演化、更強的表達力、更強的改善軌跡。其動態類似品質-多樣性（QD）優化，但是從 EvoLattice 內部多選項表徵中隱式湧現，而非靠外部 archive。

1. 引言

LLM 已不只是程式碼生成器，而是演算法發現、程式精煉、智能體設計的主動參與者（FunSearch、AlphaEvolve、DAG-based 智能體演化框架）。但這些系統共享一個設計選擇：演化物件——函數/程式/智能體 prompt——在每次迭代被表徵為單一龐然候選；突變覆寫結構，取代而非累積先前變體。即使祖先版本被歸檔在演化樹中，它們不再參與計算、無法與未來改進重組。演化是一連串覆寫的時間序列，而非累積擴張的搜尋空間。

此表徵選擇使這些方法無法保留多個競爭策略、同時探索它們、或把部分成功融合進單一活躍結構；多樣性只存在於「多個程式/智能體之間」，不存在於任一個體內部。diff-based 突變高效卻結構脆弱（破壞命名/依賴順序/型別；智能體 DAG diff 可能破壞無環性或產生不可達節點），正確性全靠 LLM 維護它無法可靠維護的約束。修復存在但是外部、粗粒度的。

即使維護族群或譜系樹，每個候選的表徵仍是內部單路徑。系統無法保留同一子程式的多個可行變體、無法跨個體重組高效組件、無法累積可重用微算子庫。LLM 從未看到「過去替代方案表現如何」的結構化量化表徵——無法分辨哪些子程式一致提升效能、哪些在特定情境有潛力、哪些組合有協同效應；沒有 per-operator 貢獻、無路徑層級分解。此資訊瓶頸迫使 LLM 在有限脈絡下盲目突變。

本文提出 EvoLattice：一個讓 LLM 驅動演化「在單一物件內部操作結構化族群」的表徵轉變。每個節點存多個替代方案（各代表不同微算子/子程式/智能體行為），除非被結構性剪除否則全部保持活躍，所有跨圖的替代方案組合都是可執行路徑——在單一緊湊表徵內創造指數級豐富的候選地景。所得動態類似 MAP-Elites 等 QD 法（靠保留並精煉多樣部分解而非優化族群均值），但在現有 LLM 系統中此行為僅隱式、短暫地出現。

核心特色：替代方案層級效能統計。 每個節點每個替代方案，跨「所有含它的合法路徑」評估（用快取保證效率），產生對全域效能貢獻的 per-alternative 估計（均值效應、變異、最佳情形影響），與結構圖一同呈給 LLM。LLM 因此能明確就 QD 推理，依經驗訊號而非啟發式猜測做有針對性的突變/重組/特化/剪枝。每次突變後，確定性自我修復管線還原無環性、移除懸空依賴、剪除空節點、保證可達性——把結構正確性的責任移離 LLM，讓模型專注高層推理。

貢獻：(1) EvoLattice 表徵——DAG，每節點存替代實作，緊湊編碼一個族群於單一演化物件；(2) 替代方案層級評估與量化統計（均值/變異/最佳/年齡）；(3) 把 QD 直接嵌入表徵；(4) 獨立於 LLM 可靠度的自我修復演化；(5) 程式與智能體演化的統一框架；(6) 可解釋演化地景與自動假設生成。

評估於 NAS-Bench-Suite-Zero（大規模免訓練架構排序 benchmark）：在相同評估條件下，EvoLattice 一致勝過 SOTA 零樣本代理與 LLM 單路徑演化法，獲得更高 rank correlation、更低變異、更快穩定；另在免訓練優化器更新規則發現上驗證泛化。

2. 相關工作

多數 LLM 驅動演算法發現/程式合成/智能體設計遵循外部族群、龐然演化範式：把完整程式/智能體當不可分單元演化，缺持久內部多樣性、細粒度效能歸因、結構穩健性。QD 演算法（MAP-Elites、novelty search、repertoire-based）顯式保留行為空間中多樣高效解，但依賴大型外部 archive、顯式行為描述子、手工相似度量度，且不整合 LLM；EvoLattice 把 QD 隱式、內部地實現——每節點替代方案構成局部 niche，跨多組合情境評估，per-alternative 統計即嵌入表徵的緊湊資料驅動 QD map。模組化 GP、階層神經演化、CPPN 強調可重用子組件，通常靠顯式模組壓力或特化重組算子；EvoLattice 則因構造而模組化（節點＝組合單元，替代方案＝微算子，組合式路徑評估自然重組部分解）。LLM 合成從一次性生成/修復走向迭代精煉與執行驅動回饋；FunSearch、AlphaEvolve、ShinkaEvolve 對整個程式做 LLM 突變/交配，Darwin Gödel Machine 演化自我改寫智能體——共享同一表徵瓶頸：個體龐然、突變破壞性、多樣性只在族群間。信用分配是演化合成的長期挑戰；前人靠譜系或 ablation，無顯式子組件統計，EvoLattice 直接靠「跨所有路徑聚合每個替代方案的效能統計」填補。
