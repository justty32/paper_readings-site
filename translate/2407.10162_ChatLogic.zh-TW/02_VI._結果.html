VI. 結果

  • PARARULE-Plus（Table II，總準確）：GPT-3.5 Base 0.344 / Zero-shot CoT 0.388 / ChatLogic 0.528;GPT-4 0.555 / 0.690 / 0.730（GPT-4+ChatLogic 在深度 4、5 高複雜度表現尤佳）;Llama 2-7B 0.048 / 0.105 / 0.183（弱基線各深度全面提升 → 框架對不同模型的多功能性）。
  • CONCEPTRULES V1/V2（Table III）：GPT-4 已強到天花板——Zero-shot CoT 多數情況與 ChatLogic 持平或略勝（尤其 V2 full）。GPT-4 與 ChatLogic 差距比 PARARULE-Plus 微妙；ChatLogic 主要對小參數模型有效（提供適當引導）。凸顯未來需更精巧資料集挑戰先進 LLM 上限。
  • ChatLogic 顯著提升 LLM 表現、多數場景準確度遠勝基線；保留完整自然語言資訊、防遺漏與誤差累積、增透明與可追溯。

VII. 消融研究

兩模組從語意與語法角度改善程式執行。程式可執行率（Table IV，Base / SE / SE+SYN）：兩模組逐步提升執行率（如 PARARULE-Plus GPT-3.5 0.26→0.5→0.62、GPT-4 0.54→0.64→0.70）。SYN 對預訓練 code 文字較少的 Llama 2 提升有限但仍精煉品質。GPT-4 因部分子任務能力極強，似已達現有資料集的「表現天花板」。

VIII. 局限與未來工作

ChatLogic+LLM 勝原生 LLM。但：PARARULE-Plus 基於 CWA;CONCEPTRULES V1/V2 亦人工構造、缺自然語言表達，未必充分代表真實複雜度；面對開放世界假設下更複雜句子、導入整合推理「以不同方式表達的外部知識」仍是挑戰。優化模組與精心設計的 prompt 範例目前僅適用特定資料集、非通用模板；未來應發展可適配的優化組件以應對更廣場景與資料源。
