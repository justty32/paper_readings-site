4. 實驗

實驗圍繞四項歸因要求組織。全部使用 gpt-5.2-2025-12-11 作 auditor 與 agent，溫度 0.0。

4.1 實驗設置

基準：WTQ（表格 QA，137 軌跡，119 條人工步級標註）、GAIA（多跳推理，117 軌跡，83 條標註，來自 TRAIL）、BBM（連鎖思考驗證，150 軌跡，邊界壓力測試）、SWE-bench（軟體工程，31 軌跡，30 條標註，來自 TRAIL）。每基準使用對應 agent 實作。

驗證信號：主實驗假定有預期答案 y*，驗證化約為任務特定的答案匹配（WTQ/GAIA 字串比對、BBM 任務特異萃取、SWE-bench 測試套件）。Proxy 設定完全移除此假定。

基線：比較八個基線跨越四範式——(i) prompt 式（AAO 全量同時、SBS 逐步、BS 二分搜尋）；(ii) 修正式（ICS、Reflexion ± GT）；(iii) 評分/約束（AgentRx、ThinkPRM）；(iv) 修正驗證（DoVer+GT）。

4.2 指標

定位準確率（主要）：Exact Match（EM，預測步 ∈ 人類標註錯誤步集合）、Off-by-1（預測步距任何標註步 ≤1）、Mean Distance。解釋品質：LLM 法官語義相似度（0–1），僅在預測步匹配人類標註步時評分（步條件化）。另報覆蓋感知指標 Sim_cov = Sim × (n_matched / n_total)。

4.3 RQ1：純修正或純法官方法能忠實定位嗎？（表 3）

REFLECT 在全部四個基準上達到同 auditor 方法中最高的 EM：WTQ 76.3%、GAIA 39.0%、BBM 34.5%、SWE-bench 70.0%。最大增益在 WTQ 與 SWE-bench，修正後重定位提供強對比證據。換用 Claude Opus 4.6 作 auditor 無法在 tool-use 基準上彌平差距（WTQ 70.8%、SWE-bench 19.4%），但在 BBM 上 Opus 超越 REFLECT（60.1% vs. 34.5%），符合 BBM 邊界壓力測試角色。

4.4 RQ2：修正是否耦合於定位？（表 4）

關鍵發現是耦合間隙 ∆：REFLECT 在修正成功 vs. 失敗軌跡之間顯示大幅解釋品質差異（∆ = +0.25～+0.29），而 ICS（∆ ≤ +0.03）與 Reflexion（∆ ≤ +0.05）僅顯示微弱間隙——儘管它們修正率不低。對 REFLECT 而言，成功修正伴隨顯著更好的解釋（Sim_c = 0.48–0.61 vs. Sim_f = 0.23–0.32），驗證了修正後重定位設計（§3.4）。此耦合是前綴保留重播（R2）的直接後果：原始與修正軌跡共享前綴但在假設錯誤步處分岔，提供結構上受約束的對比證據。

4.5 RQ3：干預信號是否忠實？（表 5，119 WTQ 例，3 樣本/條件，溫度 0.2）

正確修補提示比無提示高 +42.0pp 修正準確率、比安慰劑高 +32.0pp，確認 agent 對干預的語義內容有反應。效果在改寫、位置匹配變體間穩定（全在 6pp 內）。在故意錯誤步上干預（平均距離 2.6）將準確率降至 46.2%，確認定位目標——非干預行為本身——驅動修正。當修補計畫正確識別錯誤區域（步距 ≤3）且 agent 遵循時，修正率達 88%（相比計畫良好但未被遵循時 75%，+13pp）。

4.6 RQ4：無 oracle 驗證時什麼留存？（表 3 末行、表 6）

REFLECT (proxy) 以計畫錨定步級審計取代 oracle 驗證器，保留大部分 oracle 準確率：WTQ 62.2%、SWE-bench 66.1%、GAIA 33.3%。Oracle 到 proxy 的差距反映驗證器品質：AUROC 在 SWE-bench 達 0.97，在 BBM 僅 0.56（純 CoT 軌跡缺乏工具結構）。

4.7 消融（表 7，WTQ）

七個消融配置：(1) bare 基線；(2) +Diagnostician；(3) +Hard Gate；(4) +Multi-rollback (K=3)；(5) D+G；(6) D+M；(7) 完整 pipeline 無重定位。

Diagnostician 對修正貢獻最大（∆Corr: +27.8pp）。Multi-rollback 驅動定位（∆EM: +2.2pp）。Hard gate 保衛干預特異性（R3）。Post-correction re-localization（表 7 末行）提供 +10.6pp EM 增益（65.7% → 76.3%），確認歸因回饋迴路——非僅修正——是 REFLECT 與 correction-only 方法的分野。

4.8 驗證 vs. 退路定位（表 8）

驗證過案例（intervention succeeded）的定位大幅優於退路案例（correction failed）：GAIA 47.1% vs. 25.8% EM、BBM 35.8% vs. 14.3%，確認干預支撐歸因強於純模式匹配。WTQ 退路僅 10 例且恰好都被正確定位，因 WTQ 是最簡單基準。

5. 結論

REFLECT 透過診斷候選錯誤步、目標化重播測試、用驗證結果翻轉作為對比證據精煉最終定位，閉合了修正→歸因的迴路。在四個基準上達到最高同 auditor 定位準確率，展示所有基線皆缺乏的強修正-定位耦合。方法增益在結構化 tool-use 軌跡最大，在純連鎖思考推理上較小（干預信號較弱）。未來工作應針對更強的無 oracle 驗證與非結構化軌跡的重播機制。
