7. 可重現性聲明

管線簡單易實作、可重現，所有實驗細節記於正文與附錄。因 prompt 過長無法全文附上，但於附錄 L 提供各類 prompt 範例。完整實作（prompt 腳本、外部評分器訓練碼、評估碼等）公開於 https://github.com/MurongYue/LLM_MoT_cascade 。

附錄要點（節選）

附錄 A（級聯的成本分析）：假設每個示範例（不論表徵）消耗 N_tok 個 token。以 CoT-1D-Vote 對 CoT-2D-Vote 為例，前者弱模型成本為 (M·C^w_i + K·C^w_o)·N_tok，後者為 (2M·C^w_i + (K₁+K₂)·C^w_o)·N_tok（C^w_i、C^w_o 為弱模型 input／output 每 token 成本）。設 K₁=K₂=K_2D/2，為使兩者成本一致，令 K_2D = K_1D − M·(C^w_i / C^w_o)；類似可得 MoT 的總樣本數 K_MoT。此分析指導各法配置為「成本可比」。注意不改變示範數 M，因 LLM 對此極敏感。
