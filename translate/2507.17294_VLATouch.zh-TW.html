論文／訪談原始來源

VLA-Touch: Enhancing Vision-Language-Action Models with Dual-Level Tactile Feedback

摘要與第 1 節：問題

視覺難以判斷硬度、粗糙度、摩擦與接觸是否發生，偏偏這些資訊決定抓取、擦拭、削皮等接觸密集任務能否成功。現有 VLA 多以視覺、語言與本體感覺訓練，既沒有觸覺輸入介面，也缺少足夠的大型視覺－語言－動作－觸覺資料可重訓。

VLA-Touch 採模組化路線，不微調 base VLA，而在兩個層次補入 touch。高階規劃需要把局部觸覺變成 planner 可理解的物性描述；低階控制則要用即時接觸訊號修正 VLA action chunks。這種鬆耦合設計也讓作者能分別測量 touch 對選擇下一步與精細執行的貢獻。

第 3 節：雙層觸覺回饋

高階迴圈由 GPT-4o planner、RDT policy 與預訓練 tactile-language model Octopi 組成。Planner 根據任務目標、場景圖與先前回饋，產生一次只操作一個物件的 primitive instruction。RDT 執行後，Octopi 讀取 GelSight 的短觸覺序列，輸出粗糙度、硬度等文字描述，再讓 planner 依新資訊改寫下一步。力的估計因不在 Octopi 的預訓練能力內，另由 marker tracking 結果與參考向量提供給 planner。

低階部分以 BRIDGeR interpolant controller 修正 RDT 動作。它不像一般 diffusion 從高斯雜訊出發，而以 VLA 已產生的 action distribution 作 informative source，再條件化於 RGB、本體感覺與觸覺力訊號。GelSight marker 位移被彙整成力向量與大小，控制器輸出 refined action sequence。推論時以 sliding windows 逐段修正與執行，執行失敗則回到高階重規劃。

訓練資料把專家示範狀態與同一狀態下的 VLA 動作配對，使控制器學會把 base policy 的提案拉向 expert actions。這不是把 touch 注入 VLA 內部表徵，而是外掛一個觸覺條件化的修正器。

第 4 節：真實機器人實驗（數字均為作者自報）

實驗使用單臂機器人、夾爪、GelSight 與兩部 RGB 相機，測三種任務。Cup 要靠觸覺判斷杯中是否有水再放到對應位置；Wipe 要選較平滑的海綿擦掉墨水；Peel 要辨認芒果軟硬並維持削皮接觸。規劃比較無觸覺、直接給 raw tactile images，以及由 Octopi 轉成文字；控制比較原始 RDT、RNN residual controller 與 interpolant controller。

作者自報，規劃端只看場景時接近猜測；直接給 tactile images 對粗糙度有效，卻不擅長力與硬度。Octopi 文字回饋使力判斷成功率達 90％、硬度達 75％，相應 raw image 條件為 50％、60％。結果支持「先把 touch 轉成模型熟悉的語言」比要求通用 VLM 自行解讀感測器影像可靠。

控制端每個子項以多次真實試驗評估。作者自報，interpolant controller 在 Wipe 的完整擦拭為 12／20，原始 RDT 為 5／20；Peel 完整成功為 10／20，原始 RDT 為 6／20。它也比 residual controller 更能維持多模態示範中的不同有效軌跡，減少平均化後提早離開表面的情況。

雙層消融顯示兩者互補。作者自報，完整 VLA-Touch 在 Cup、Wipe、Peel 的整體成功分別為 9／20、12／20、7／20；只在控制端用 touch 時為 5／20、5／20、6／20，只在規劃端用 touch 時為 6／20、5／20、4／20。視覺消融與觸覺消融則顯示，視覺主要負責空間定位，touch 對接觸維持、壓力調節與釋放時機尤其重要。

第 5、6 節：結論與局限

VLA-Touch 說明，無需重訓大型 VLA，也能用語言橋接高階觸覺推理，再以動作修正器處理低階接觸。兩層分工貼近現有模型的能力邊界，也便於替換 planner、tactile model 或 base policy。

局限首先來自感測域差異：實驗夾爪與 Octopi 預訓練設定不同，硬度解讀因此受影響。實驗只用單臂，且 RDT 原先為雙臂預訓練；目前證據主要是物件位置與樣本變化，不是跨任務泛化。控制器的頻率也低於觸覺感測器可提供的更新率。（本檔補註，非作者自陳）三項任務與有限試次仍屬概念驗證，模組間重複推論帶來的延遲也尚未完整量化。
