神經符號 AI：邁向提升大型語言模型的推理能力

南京大學 LAMDA；GitHub 資源庫：Awesome-LLM-Reasoning-with-NeSy

摘要

LLM 在各任務展現亮眼成果，但推理能力仍是根本挑戰。建構具強推理能力的 AI 被視為通往 AGI 的關鍵里程碑。各種技術被探索以提升 LLM 推理，其中神經符號（NeSy）方法尤其有前景。本文全面回顧 NeSy 補強 LLM 推理的近期進展：先形式化推理任務並簡介 NeSy 學習範式，再從三視角討論——Symbolic LLM、LLM Symbolic、LLM⊗Symbolic，最後討論關鍵挑戰與未來方向。並釋出 GitHub 資源庫。

1. 引言

AI 發展歷經不同範式：1990 年代前以符號 AI（操作符號、邏輯、規則、知識）為主，但在可擴展性與面對含噪原始感官輸入的彈性上遇困；連結主義 AI（神經網路）則在資料驅動學習上大獲成功。近期 LLM（基於 transformer）在多任務表現亮眼，但許多研究指出 LLM 難以處理複雜推理——它們只是複製訓練資料中的推理步驟、無法真正推理。

現有提升 LLM 推理的研究依模型建構階段分三類：資料建構（自動生成/擴增/標註/選擇含推理路徑的資料）、微調（監督式與強化式微調）、推論（從 CoT 到 test-time scaling）。各種大型推理模型亦相繼釋出（OpenAI O1、Qwen-QwQ、DeepSeek-R1 等）。

其中 NeSy 方法表現優越：結合擅長複雜推理的符號 AI 與擅長大數據學習的神經網路。NeSy 對齊認知科學的雙系統理論——System 1（快速、直覺、無意識：神經網路）與 System 2（慢速、審慎、有意識、聚焦邏輯推理：符號推理）。故 NeSy 自然是提升 LLM 推理的有力路徑。

2. 何謂推理？

推理任務刻畫為遞迴過程：給定輸入問題與背景知識，目標是得到滿足某關係的答案；其間有由一連串中間步驟構成的推理路徑，每步建立在前序步驟之上。問題、知識、步驟可用自然語言或符號形式表示。

3. 何謂神經符號 AI？

NeSy 整合符號 AI（擅複雜推理）與神經網路（擅大數據學習）。本文以三種交互模式組織：

  • 3.1 Neuro 助 Symbolic：神經補符號；
  • 3.2 Symbolic 助 Neuro：符號補神經；
  • 3.3 混合神經符號架構：兩者深度耦合。

4. Symbolic→LLM：解決推理資料稀缺

  • 4.1 符號生成、LLM 模仿：用符號引擎/求解器自動生成高品質、帶正確推理路徑的訓練資料，LLM 透過模仿學習吸收。
  • 4.2 LLM 形式化、符號擴增：LLM 先把自然語言問題形式化為符號，再以符號方法擴增/驗證資料。

5. LLM→Symbolic：解決推理函數錯誤

把 LLM 不可靠的推理步驟外包給可靠符號元件：

  • 5.1 符號求解器輔助：交給邏輯/數學求解器；
  • 5.2 程式輔助（Program-Aided）：生成程式碼由直譯器執行；
  • 5.3 工具輔助（Tool-Aided）：呼叫外部工具；
  • 5.4 搜尋增強（Search Augmented）：用搜尋（如樹搜尋）強化推理。

6. LLM⊗Symbolic：端到端推理

  • 6.1 符號格式化推理：以符號格式組織推理過程；
  • 6.2 可微符號模組：把符號運算嵌入可微管線，端到端訓練；
  • 6.3 符號回授：用符號驗證結果回授修正 LLM。

7. 挑戰與開放研究方向

  • 多模態推理：跨視覺/語言等模態的符號推理；
  • 進階混合架構：更深度的神經-符號耦合；
  • 理論理解：對 NeSy 為何/何時有效缺乏理論。

8. 結論

提升 AI 推理是通往 AGI 的關鍵里程碑。本文從 Symbolic LLM、LLM Symbolic、LLM⊗Symbolic 三視角，探討符號方法如何解決 LLM 推理的關鍵挑戰（推理資料稀缺、推理函數錯誤、表徵錯誤等）。因領域發展快、論文眾多，難以完全覆蓋，本文聚焦關鍵想法與技術路徑，盼提供最新進展摘要並啟發符號 AI 與 LLM 整合的新洞見。
