論文／訪談原始來源

以 LLM 溯因推理與邏輯驗證做神經符號臨床試驗配對

University of Leicester / University of Edinburgh / University of Sheffield

摘要

LLM 為自動化臨床試驗配對（CTM）提供了途徑，但對複雜資格條件所需的確定性驗證仍力不從心；反之，純符號法雖嚴謹，卻在面對不完整病歷與雜訊臨床證據時崩潰。為彌合此鴻溝，本文研究結合 LLM 與邏輯驗證的混合框架，並提出溯因式神經符號 CTM（αNeSy-CTM）：利用 LLM 的語言與世界知識，對含噪、欠定的臨床文字進行推理。大量評估顯示 αNeSy-CTM 大幅勝過純 LLM baseline，相對 zero-shot 最高 +30%；且溯因推理確實提升準確率、特異度與穩健性。αNeSy-CTM 與思維鏈（CoT）高度互補，暗示可走混合路由策略。本文展示神經符號法對自動化 CTM 的潛力，邁向可審計、LLM 驅動的下一代臨床應用。

1. 引言

臨床試驗是生醫發現通往救命療法的橋樑，但常卡在招募瓶頸。隨試驗協議愈趨龐雜，人工把病歷比對資格條件已不可持續且易錯。LLM 因能處理臨床敘述的語言變體，成為自動化 CTM 的途徑。

然而自然語言與形式資格邏輯間的表徵鴻溝仍是關鍵障礙：CTM 本質需確定性驗證嚴格數值門檻、時間窗、巢狀邏輯依賴;LLM 在此高風險場景極不可靠、缺可驗證推理軌跡，無法安全部署。反之符號/規則系統邏輯嚴謹，但面對病歷的片段化、不完整就脆斷。

本文把試驗–病人配對框成約束滿足問題：用 LLM 自動形式化病人檔與資格條件成符號約束，交 Z3（SMT 求解器）當確定性邏輯引擎評估。為應對語言噪聲與欠定證據，提出 αNeSy-CTM：用 LLM 做溯因，從隱含的臨床/語言線索生成明確、最小的證據集，確保資格與病人資訊充分指定以利穩健形式化。

在 TREC 2021–2023 上實驗：αNeSy-CTM 隨條件複雜度上升而帶來一致的多面向改善。TREC 2023 達 75.71% 平均準確率，超越 58.17% zero-shot；受控證據擾動下只掉 2%（非溯因版掉 8.5%）；且與 CoT 互補（αNeSy-CTM 救回 CoT 失敗的 18%，CoT 救回其失敗的 12%）。

2. 方法

給定病人描述 P 與試驗報告 T（皆自然語言），CTM 判定資格 y∈{0,1}。難在臨床文字非結構化、條件含嚴格形式約束、病人證據常欠定。

2.1 問題形式化

對病人–試驗對定義變數空間 V={v₁,…,v_k}（年齡、既往治療、診斷、時間指標）。醫療約束需型別域（整數/實數/布林），在背景理論 𝒯（如線性算術）下評估。資格條件 L=φ(T)（V 上符號約束集）；病人事實 F=ψ(P)（賦值子集）。

資格轉成 SMT 問題：y=1 ⟺ 觀測事實與資格約束的聯合理論在 𝒯 下至少有一個有效模型（可滿足）；若有矛盾則 y=0。即 y=1 ⟺ F∪L ⊭_𝒯 ⊥。

2.2 神經符號 CTM（NeSy-CTM）

標準神經符號法三階段：

  1. 自動形式化：LLM 把資格條件譯成 SMT-LIB 約束（assert (>= Age 18)），從病人檔抽事實賦值（assert (= Age 20)）。
  2. 符號驗證：用 Z3 把 F 對 L 檢查，回確定性 sat（合格）/unsat（不合格）。
  3. 自我修正迴圈：Z3 報語法/型別錯 → LLM 收錯誤回饋迭代修正（工具增強推理）。

例：試驗要 Age≥18、病歷說 52 歲 → 形式化為 (assert (= Age 52)) (assert (>= Age 18)) (check-sat) → Z3 回 sat（整數算術下無矛盾）。

2.3 CTM 的溯因推理（αNeSy-CTM）

標準法在病人檔與條件完全指定且對齊時有效。但現實中語言噪聲（詞彙變體）與隱含臨床假設會妨礙穩健驗證。若 L 的變數與 F 不完全匹配 → 整個形式化欠定 → Z3 可能高估資格。αNeSy-CTM 加一道溯因階段，讓 LLM 補知識與詞彙缺口：

  1. 溯因推理：給病人檔與條件，LLM 生成一組保守的、文本支持但未明說的推斷事實 I（匹配縮寫、治療史、疾病狀態指標）。例「能獨立行走」「日常無限制」可指示低 ECOG 狀態，但不過度賦具體值除非文本明確支持。
  2. 增強驗證：把溯因輸出與觀測事實、約束合併成 F∪I∪L，再交 Z3 檢查 𝒯-可滿足性。

例：病歷「63 歲男、能獨立行走、能採買、生活無需協助」；試驗要 ECOG≥3（意指僅能有限自理、過半清醒時間臥床/坐椅）。溯因階段可推斷低 ECOG（=0 或 1）加入理論 → 這些溯因事實是判定不合格的關鍵；標準法下 ECOG 可能仍未指定，使 Z3 無法可靠識別矛盾。

3. 實證評估

3.1 設定

資料集：TREC 臨床試驗 Track 2021–2023，二元資格預測（合格 vs 不合格）。

  • TREC 2021：75 個合成病例對 ClinicalTrials.gov 試驗描述。
  • TREC 2022：50 題，偏重數值顯著證據（列表式檢驗值、門檻比較、治療史約束）。
  • TREC 2023：病人表徵轉向半結構化問卷，碎片化/欠定證據更核心，凸顯缺失資訊下的推理。

模型：αNeSy-CTM 對比非溯因 NeSy-CTM（三階段自動形式化-驗證-修正）、純 LLM baseline（Zero-shot、CoT、QuaSAR——步進式自然語言推理 + 符號形式化）。三個 LLM 骨幹（T=0.1）：gpt-oss-120b、olmo-3-32b-think、qwen3-vl-32b-instruct；符號引擎 Z3 v4.12.2。

3.2 結果（要點）

  • 神經符號法把敏感-特異度權衡推向平衡準確：純 LLM（Zero-shot/CoT）高敏感（Sens 85–96）卻低特異（Spec 25–56）;NeSy-CTM 把 Spec 拉到 82–90，達更平衡的準確。
  • 更嚴的邏輯邊界大幅降假陽性。
  • 形式驗證在最難、欠定資料集（TREC 2023）增益最大：αNeSy-CTM 平均準確率 75.71% vs Zero-shot 58.17%。
  • 平衡分類成為更可靠的人機協作篩選過濾器。

3.3–3.6 消融、互補、穩健性、複雜度（要點）

  • 消融確認溯因階段對準確、特異、穩健皆有貢獻。
  • 互補性分析：αNeSy-CTM 與 CoT 各自救回對方失敗案例（18% / 12%），支持混合路由。
  • 溯因穩健性：受控證據擾動下 αNeSy-CTM 僅掉 2%，非溯因 NeSy-CTM 掉 8.5%。
  • 複雜度分析評估多階段管線的執行時間成本。

4. 相關工作

LLM 自動化 CTM、自然語言到形式邏輯的自動形式化、LLM + 符號求解器（SMT/Z3）的神經符號推理。

5. 結論

本文展示 LLM 驅動的溯因式神經符號推理對自動化 CTM 的潛力。透過把配對框成 SMT 問題、用 LLM 自動形式化、Z3 確定性驗證、並以溯因補不完整證據，αNeSy-CTM 在三年 TREC benchmark 上一致勝過純 LLM baseline，並與 CoT 互補。為可審計、LLM 驅動的下一代臨床 AI 應用鋪路。
