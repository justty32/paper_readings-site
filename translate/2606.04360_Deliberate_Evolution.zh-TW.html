論文／訪談原始來源

Deliberate Evolution：以代理式推理達成樣本高效的 LLM 符號迴歸

清華大學 + 香港浸會大學 + Lenovo Research（ICML 2026）

摘要

SR 從資料發現緊湊數學式，但近期 LLM 演化式方法仍樣本低效，因為主要倚賴純量回饋（如 MSE）。我們辨識核心限制：既有方法把候選提議與搜尋引導混為一談，要 LLM 從單一分數同時推斷「如何演化式子、診斷其錯誤、重用過去經驗」。為解此，我們提出 Deliberate Evolution（DE）——一個把符號生成與搜尋控制解耦的代理式框架：以自適應運算子給搜尋方向、分析工具做結構診斷、反思記憶累積軌跡級經驗。在 LLM-SRBench 上，DE 跨多個科學領域一致勝過代表性 LLM-SR 基線，且只用標準取樣預算的 40%。程式碼：github.com/Xinyu-Pang/Deliberate-Evolution。

1. 引言

SR 尋求解釋觀測資料的緊湊數學式，是可解釋科學發現的關鍵工具。近期 LLM 方法把 SR 構為演化迴圈：LLM 提議符號候選，數值最佳化器擬合常數，外部評估給完成式打分。此範式結合 LLM 的數學先驗與可驗證的數值回饋，但實用性受限於樣本低效——既有系統每題常需 10³ 個評估候選。

我們把此低效歸因於根本設計問題：當前方法把候選提議與搜尋引導混為一談。只給親代式 + 一個 MSE 純量，卻要 LLM 一次推斷三件事——該如何改、為何現在失敗、過去嘗試的教訓如何指引下一步。此純量驅動迴圈缺三關鍵訊號：

  • 方向（Direction）：純量分數不指明該做哪種符號移動。模型得瞎猜該精修有望結構、引入更大突變、重組有用子式、還是放棄當前區域重啟。
  • 診斷（Diagnosis）：MSE 量「離資料多遠」，卻不揭示「為何失敗」——無法分辨誤差來自缺週期性、變數交互錯、量綱無效、漸近錯、或其他局部結構缺陷。
  • 記憶（Memory）：每次提議多被當近乎獨立的試驗。搜尋缺顯式機制記住哪些編輯反覆失敗、哪些符號母題在好候選間反覆出現、哪些變換帶來大改善。

缺方向則搜尋在無效編輯間漂移；缺診斷則無法瞄準誤差的結構源頭；缺記憶則反覆重蹈失敗。於是大量評估浪費在「貌似合理卻無資訊」的候選上（重複的局部變體、結構無效的突變、或只擬合觀測卻沒回復底層定律的代理式）。

核心洞察：把「提議什麼式子」與「搜尋如何演進」分開。純量演化把發現當弱引導的試誤；深思演化則讓搜尋軌跡顯式化——方向引導決定符號移動、診斷引導從資料與殘差局部化結構證據、歷史引導重用前次教訓。此分離把 SR 從純量驅動生成轉為引導式科學搜尋。

我們在 LLM-SRBench（涵蓋 LSR-Transform 與 LSR-Synth，橫跨物理/材料/化學/生物）以 Llama3.1-8B-Instruct 與 Qwen3-4B-Instruct 評估。DE 一致勝過 LLMDirect、LLM-SR、LASR、SGA。如圖 2：只用標準取樣預算的 40%，平均 NMSE 在 Llama3.1-8B 降 55%、Qwen3-4B 降 37%。進一步在域外泛化、噪聲觀測、真實應力-應變量測與消融上，證明深思引導改善擬合準確度、穩健性、樣本效率。

2. 預備知識

問題形式化：給未知目標 f⋆:ℝᵈ→ℝ 與資料 D={(xᵢ,yᵢ)}，SR 在可容許表達式空間 F 搜尋擬合觀測的式子，損失 ℓ(f) 通常為 MSE。目標不只最小化經驗誤差，還要式子緊湊、能泛化到未見輸入。

LLM 演化式 SR 的標準工作流：LASR、LLM-SR、SGA 等多採演化最佳化——維護候選族群 Pₜ（有時分多島嶼以保多樣、緩解早熟收斂），每輪以「選擇-變異-評估」更新。選擇階段依適應度相依分佈 psel 抽親代 fp。

3. 方法

DE 是讓 LLM 搜尋更「深思」的演化框架，關鍵原則是解耦候選提議與搜尋引導：LLM 提議符號骨架，顯式引導決定搜尋如何進行。具體：

  • Adaptive operators（自適應運算子）：依當前搜尋狀態與停滯行為，顯式選擇是 refine（精修簡化）/ mutate（功能變異）/ crossover（重用有望子式）/ regenerate（更廣探索）（圖 3 示四運算子由親代式產生新式）。
  • Tool-augmented proposal（工具增強提議）：藉分析資料統計、殘差樣式、量綱一致性診斷當前失配，把純量誤差轉成給 LLM 的局部化結構回饋。
  • Reflective memory（反思記憶）：彙總成功母題、失敗編輯、停滯軌跡，助未來提議重用有望結構、避免冗餘探索。

三機制合力解耦符號生成與搜尋控制，使每次提議都由「顯式意圖 + 局部證據 + 累積經驗」告知。

4. 實驗（精要）

在 LLM-SRBench（LSR-Transform、LSR-Synth）以 Llama3.1-8B 與 Qwen3-4B 為骨幹：DE 一致勝 LLMDirect、LLM-SR、LASR、SGA;只用 40% 取樣預算，NMSE 降 55%（8B）/37%（4B）；在更少評估下達更低誤差，樣本效率顯著。另測域外泛化、噪聲、真實應力-應變資料與消融，皆支持「深思引導」的價值。

5. 結論

DE 把「提議」與「引導」解耦，以方向（自適應運算子）、診斷（殘差/量綱工具）、記憶（反思）三訊號，治本地解 LLM-SR 的樣本低效，把符號發現從弱引導試誤轉為引導式科學搜尋。
