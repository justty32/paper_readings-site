論文／訪談原始來源

邁向可解釋臨床決策評分的符號迴歸

Federal University of ABC（巴西）、UPenn 病理與生物醫學資訊、Boston Children's / Harvard Medical School

摘要

醫療決策常用「結合風險方程與規則」的演算法，提供清晰標準化的治療路徑。符號迴歸（SR）傳統上把搜尋空間限於連續函數形式與參數，難建模這種決策。但 SR 能導出資料驅動、可解釋的模型，對發展資料驅動臨床風險評分有潛力。為此提出 Brush——結合決策樹式分支（split）演算法與非線性常數優化的 SR 演算法，讓規則式邏輯無縫融入 SR 與分類模型。Brush 在 SRBench 達 Pareto 最優，並應用於復現兩個廣用臨床評分系統，達高準確與可解釋模型。相較決策樹、隨機森林、其他 SR，Brush 達相當或更優的預測表現、同時產更簡單模型。

關鍵詞：符號迴歸、遺傳程式設計、srbench、臨床決策支援。

1. 引言

SR 旨在從資料發掘數學式及其參數。應用於物理、醫療資訊、航太、材料等。主要吸引力是本質可解釋（科學發現、或預測模型須證成推薦時關鍵，如美國 FDA 臨床決策支援軟體指引）。

但純數學式需數學素養 → 臨床上不如決策樹受青睞。美國廣用 triage 評分系統（如 CART）基於生理參數、可快速評估預測患者急性惡化；評分系統需可解釋（簡單決策規則）、關聯更好的住院結果、傳統手工開發 → 可用大數據與 AI（尤 EHR）探索。

當代 SR 靠局部參數優化，但無法納入 split 操作（split 參數難用現有優化法優化）。提出 Brush——橋接符號預測模型與 split 操作 + 非線性參數優化；解多目標優化（同時最大化效能、最小化複雜度）;在表達式任一點學 split 操作、與非線性優化相容（即使有不連續）。

實驗兩部分：(1) 在 SRBench 真實/合成物理問題驗證，Brush 達 Pareto 最優、表達式顯著更小、過半 run 達高 R² 即使高噪聲；(2) 在 MIMIC-IV EHR 上學 triage 評分（CART、MEWS）的迴歸與分類，產競爭力結果且模型小得多、用簡單 split 規則標記高風險患者。

2. 相關工作

混合決策樹與線性迴歸葉子早有探索；近期整合 SR 與決策樹：PS-Tree（決策樹結構 + SR 葉子，競爭力但模型過大、無參數優化靠隨機常數）；另一法生決策樹 + 符號葉子；SREDT（用 SR 導出的 split，勝傳統決策樹但也無參數優化）。優化自由參數仍難（隨機常數阻收斂、純演化收斂慢）→ 近期 SR 用 Levenberg-Marquardt（LM） 調參有效。La Cava 等改 FEAT 做邏輯比較、用於高血壓可計算表型；其他醫療 SR 應用含特徵工程、CT 評分。

3. Brush：混合 split 函數與參數優化

Brush 能學含 split 操作的表達式、不受決策樹結構約束；其 split 與非線性參數優化相容（現有演算法缺）。

  • split 節點（受經典決策樹啟發）：一個謂詞依布林輸出決定評估左或右分支。學習時窮舉測試特徵 j 與閾值組合，選最小化結果分區目標值總變異數者。
  • 三分支：實值條件子樹 + true/false 子樹（各為 Brush 樹）；條件與可學權重/閾值比較；最優閾值最小化兩側目標變異數和（一維聚類，式 1–4）。此運算遮罩資料集 → 下游運算只作用於子集（子樹更精確、優化更快）。
  • 初始族群可選只含 split 節點，經 GP 在效能改善時漸換成數學式。每節點有可切換的內在權重（初始只開終端權重，擴展 Operon 機制）。
  • 優化（LM，式 5）：因任一子樹是有效 Brush 樹 → 可隔離優化到子樹。含 split 的三步啟發式：先優化條件子樹 → 找最小變異數閾值 → 固定條件與閾值擬合其餘（只傳符合條件的資料子集給對應分支）。兩型：greedy split（單特徵 + 閾值如決策樹）、flexible split（演化生子表達式、只優化閾值）。
  • GP：適應度向量（MSE + 線性複雜度，並行優先簡單）;ε-lexicase 選擇 + NSGA-II 存活；後處理不精確簡化（比對預測向量、用近似等價的較簡子樹替換大子樹，壓縮保效能）。變異算子（toggle weight/subtree/point/delete/insert）+ 子樹交叉。
  • 分類模式：表達式樹根固定一個 logistic regression 節點 + 強制 offset 參數（用同套非線性優化）。

4. SRBench 表現

Brush 達 Pareto 最優、表達式顯著更小、過半 run 達高 R² 即使高噪聲。

5. 方法（臨床實驗）

基於 MIMIC-IV-ED v2.2（Beth Israel Deaconess 去識別 EHR）。提取 MAP（平均動脈壓）、CART（心臟驟停風險 triage）、簡化 MEWS（改良早期預警）。原為序數評估，用閾值轉二元分類（高風險災難性惡化）。各評分訓練原始迴歸 + 二元分類。對手：PS-Tree、FEAT、決策樹（DT）、L2-logistic（LR L2）、隨機森林（RF）（聚焦 PS-Tree 因結構類似、FEAT 因臨床成功應用）。特徵集含 triage 生命徵象、過去 ED 訪次、主訴、Charlson 共病指數等多變數（刻意全保以挑戰特徵選擇）；類別不平衡 → 用 AUPRC。

6. 結果

  • 評分（迴歸，Table 3）：報各方法平均 R² 與模型大小；Brush 競爭力 + 模型小。
  • 分類（Table 4，AUPRC + 大小）：Brush 競爭力相當或更優、模型小得多。
  • split 節點消融：迴歸問題上停用 split 無顯著影響；但分類顯著降 AUPRC（CART/MEWS deterioration，p<1e-4）→ split 益處不只可解釋、也含分類效能。
  • 可解釋範例模型：過濾低 AUPRC 與平衡準確 0.5（隨機）的模型後選最小者——CART deterioration 模型是巢狀 if 規則（resprate≥21→1.0；否則 dbp≥50→heartrate≥140→0.39…），人讀可解釋。

7–8. 討論與結論

Brush 與 SOTA SR 競爭力相當、同時納入 split 方程，能產反映 ground-truth 系統特徵與邏輯的模型支援決策。兼為第一性原理建模工具與可解釋分類模型學習法，擴展 SR 實用應用。
