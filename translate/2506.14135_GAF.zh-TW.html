論文／訪談原始來源

GAF: Gaussian Action Field as a Dynamic World Model for Robotic Manipulation

摘要與問題（第 1 節）

從 RGB 直接預測動作的 V-A 方法缺少顯式三維幾何；先建點雲或 voxel 再預測動作的 V-3D-A 方法雖看見空間結構，仍把時間演化留在隱式特徵裡。操作場景一旦有遮蔽、接觸或複雜空間關係，靜態表徵很難說清楚物體與末端執行器接下來會怎麼移動。

GAF 提出 V-4D-A：先以帶 motion attribute 的 Gaussian Action Field 同時表示現在幾何與未來位移，再從這個動態場估計機器人動作。世界模型不只生成未來畫面，而把場景運動本身當成 action reasoning 的中介表徵。

Gaussian Action Field（第 3.1、3.2 節）

每個 Gaussian primitive 除了位置、顏色、不透明度、旋轉與尺度，還帶有預測位移。GAF 支援三種 query。current query 取出當前 Gaussian，從新視角重建場景；future query 把位移加到中心位置，渲染未來狀態；action query 讀取與夾爪相關的 motion attribute，從當前與未來點雲求初始動作。

模型從兩張無外部相機姿態的 RGB 影像及其內參開始。共享 ViT 以跨視角 attention 取特徵，再由 Gaussian center、其他外觀參數與 motion prediction 等 head 產生動態 Gaussian。當前與未來渲染都用影像重建 loss 監督，使同一表徵同時學到現在的幾何忠實度與下一狀態的時間一致性。

從動態場到可執行動作（第 3.3 節）

action query 擷取夾爪在當前與預測未來的 Gaussian，以 ICP 求剛體轉換 T in SE(3)，再插值得到初始動作序列。但部分觀察、遮蔽與接觸會讓 motion field 含雜訊，幾何上看似合理的軌跡也可能穿透物體或碰錯位置。

因此 GAF 再用 diffusion refinement。系統把初始夾爪軌跡依相機參數投影回多視角影像，形成 Actionable RGB Guidance，並與初始動作及 gripper state 一起引導去噪。精修後動作直接執行，取得新觀察，再重建、預測與精修，形成閉迴路。

主要實驗（第 4 節，作者自報）

作者從 RLBench 選九項操作任務，每項只收二十條訓練示範，並以隨機初始化物體的一百個 episode 評估。比較方法包含二維動作策略 ACT、Diffusion Policy、R&D-AI，以及三維基線 ManiGaussian；所有方法使用相同相機、動作空間與任務變化。

在當前場景重建上，GAF 相較 ManiGaussian 平均提高十一點五三八五 dB PSNR 與零點三八六四 SSIM，LPIPS 降低零點五五七四；未來狀態預測也呈現同方向的大幅改善。定性結果則保留較清楚的夾爪關節與物體表面，讓末端執行器點雲更適合估計動作。

操作成功率方面，完整 GAF 相較當時最強的 R&D-AI，九項任務平均提高十點三三個百分點；遮蔽明顯的 Close Microwave 提高十三個百分點。消融顯示，拿掉 GAF、只從兩張影像用 diffusion 直接預測動作會退化；只用 Gaussian motion 得到的初始動作則常在接觸階段出錯，精修模組能以實際互動資料修正錯位與穿透。

結論與局限（第 5 節）

GAF 把場景重建、未來預測與動作估計收進同一個可查詢的四維 Gaussian world model。這個設計讓視覺理解與控制共享同一份運動表徵，也能以 feed-forward 方式在單張 GPU 上即時執行。

作者明示的限制是模型聚焦幾何與 motion prediction，缺少 semantic 或 task-level understanding。後續方向是加入語言模型提供高階語意先驗，從 V-4D-A 延伸到 Vision-Language-4D-to-Action，使同一套動態幾何推理能處理更依賴情境的操作。
