arXiv：2608.04761

論文／訪談原始來源

InsightEmb：用於 Agent 洞見檢索的行動意圖嵌入

1–2：問題

自我改進 agent 累積規則後，關鍵在每一步取回現在有用的 insight，而非主題相近的段落。例如尚未找到物件時，先取「搜尋」而不是「加熱」規則。具體 state 與抽象規則字面差很大，相關性又取決於下一個必須解開的程序瓶頸，故一般 semantic embedding 容易過早取回看似相關的技能。

3：兩階段幾何

第一階段以數學題、partial chain-of-thought 和抽象 heuristic 進行 situation-to-insight contrastive matching，讓具體狀態能對齊規則。第二階段的 situation-to-experience matching 對齊外表不同、卻有相同進展結構的推理軌跡。兩階段均使用公開數學資料；在 agent 環境不再訓練，僅將當前 observation、goal、history 編碼後，在 insight corpus 檢索。

4–6：評估與分析

作者以 ALFWorld、WebShop、ScienceWorld 的動態任務和 SRA-Bench 靜態 skill retrieval 評估，報告相對 reasoning-oriented embedders 的全面改善。分析聲稱檢索能隨步數由尋物轉到驗證與狀態變換，減少 loop 與零分回合；不同 insight generator、action model 亦有穩健性。SRA-Bench 的 MedCalcBench 是明顯例外：語彙檢索瓶頸使純 dense 模型不足，BM25 hybrid 可恢復部分 recall。

7：結論與版本註記

核心主張是「進展結構」可從數學轉移到具身與網頁 agent。這不代表所有技能庫都能直接泛化，因規則品質、狀態表示和 reranker 都可能成為瓶頸。本檔依現行 v2 原文，但保留 v1 的批次日期；不可用本檔替代逐版本的數字差異核對。
