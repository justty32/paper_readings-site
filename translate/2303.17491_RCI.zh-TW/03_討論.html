5. 討論

本文屬於「LLM 或許就足以應付困難決策問題」這條研究線。相較模仿學習與 RL，LLM 能以零樣本或少樣本方式解決新任務，不需要任務相關的專家資料或獎勵函數；隨著 LLM 與基礎模型能力提升，本方法也會自然變好。不過作者也承認：目前 LLM 的能力在某些電腦任務上仍不如任務專屬的 SL+RL；而且 RCI 比只從 LLM 採樣一次的方法昂貴。

未來方向包括：改用多模態基礎模型，讓 agent 依文字、影像、音訊、影片行動（而非僅 HTML）；以及用「針對電腦任務微調過的 LLM」取代純預訓練模型。

作者特別指出，目前 LLM 在如井字棋這類需要「預先思考」的推理任務上表現不佳，因為它們不會向前推演；RCI 雖改善推理能力，但要完成需要前瞻的困難認知任務，LLM 的推理能力仍有大量工作要做。

最後，RCI 可以視為「用 LLM 的輸出寫進外部記憶、稍後再取回以選擇動作」。既有結果顯示具備記憶的 LLM 在計算上是通用的（computationally universal），亦即原則上只要有正確的 prompt 就能執行任意程式。RCI 只是這個強大框架的基本版本，作者預期未來會出現更進階的 RCI 變體：例如以多個不同 LLM 模擬組織中團隊成員間的資訊交換，融合多元觀點來處理複雜問題（並可引入賽局理論與多智能體系統研究）；也可以用強化學習（透過人類回饋或給定獎勵函數）去搜尋有效的迴圈與 prompt 結構，探索可能的迴圈／prompt 結構空間，找出效果最好的組合並據此微調模型。

附錄要點

  • A 廣泛影響：讓 LLM 在電腦上執行任務可大幅提升生產力，但也帶來自動化網路攻擊、資訊操弄、就業衝擊、以及在虛擬機上執行 LLM 的安全風險（如 prompt injection）；最令人憂心的是未來 LLM 在電腦上行動可能導致連鎖失控事件。作者呼籲研究界討論必要時如何協調放慢高度顛覆性技術的開發速度。
  • B 相關工作：MiniWoB／MiniWoB++ 的 RL 與模仿學習路線需要極大量專家資料（6,300 小時）；WebN-T5-3B 等 LLM 路線仍需大量示範做微調；WebGPT、WebShop 靠少數自訂命令（Search、Next Page）自動化網頁任務，範圍受限。在「LLM 加上動作」這一線，Huang 等人以嵌入比對把動作接地到可受理清單（但未考慮狀態接地）、SayCan 以價值函數加權動作機率、Inner Monologue 加入狀態接地的回饋迴圈但仍需預訓練的語言條件機器人策略。本文不依賴 LLM 之外的額外模型元件，而是用 RCI 讓 LLM 自主更新動作以達成接地。在推理架構方面，與 ReAct（交錯推理與行動）、Reflexion（擴充 ReAct、納入先前試誤經驗，但需要多輪任務專屬的成功回饋，因此擴展性不如本文）、Corrective Re-prompting（需任務專屬前置條件）、以及最相近的 Self-Refine（用局部化、面向式回饋迭代精修）相比，作者主張本文是**首個證明「僅憑隱式回饋（例如『找出這份計畫的問題』）的自我批評能力就能提升推理能力」**的工作。
  • C 實驗設定：MiniWoB++ 任務子集選自 WebN-T5-3B 的評估集合，排除 book-flight、choose-date（-easy/-medium）、click-pie 等 HTML 超出脈絡長度的任務，另納入 CC-Net 表現不佳的困難任務（terminal、simple-algebra）。消融用的任務依本方法（gpt-3.5-turbo）的成功率分為 easy（click-shape 0.98、click-widget 0.98、enter-date 0.96）、medium（click-checkboxes-soft 0.72、click-collapsible-2 0.62、click-tab-2 0.74）、hard（click-tab-2-hard 0.56、count-shape 0.40、guess-number 0.20）。部分任務為配合脈絡長度做了修改（social-media 系列的媒體元件數限制在 3～6；email-inbox 系列的隨機信件數限制在 3～6）。
  • D 提示詞：MiniWoB++ 的初始 prompt 以正規表示式描述 agent 可受理的指令集（type、press、clickxpath、clickoption、movemouse 等），並要求打字前需先以點擊定位游標。
  • E 跨接地改進實例：狀態接地不僅做狀態接地——它會刪掉計畫中多餘的打字指令（表 10），也會補回任務接地動作漏掉的標點（表 11，Vel id at → Vel id at.）。
  • F 失敗模式：click-dialog-2 中狀態接地反而把動作改成與任務無關（因此該任務停用狀態接地）；click-menu、count-shape 需視覺渲染資訊；guess-number 需長程決策；login-user-popup 的突發彈窗有時關不掉；tic-tac-toe 不會防守、也不考慮攻擊被擋；use-autocomplete 無法算出方向鍵要按幾次。
