論文／訪談原始來源

Emergent Models: Intelligence from Tiny Substrates

摘要與第 1 節：動機

Emergent Models（EM）不學封閉形式的輸入輸出映射，而是讓固定局部規則在 latent space 迭代不定步數，經 interface 接外部輸入輸出，訓練用演化搜尋。作者假設某些 EM 偏向 global generalization：捕捉生成資料的規則本身而非只擬合訓練範圍內的值，故能外推。核心論點是 expressivity（模型族在完整定義域上能精確或任意精度逼近的函數類 G_φ）決定搜尋能找到什麼，目標行為不在此範圍內則任何算力都到不了。FFNN 的 universal approximation 只在緊緻定義域成立，無法全域表示 sin(x)、e^x。作者主張擴大 expressivity 的關鍵是「每輸入多次迭代」而非單次前向：ACT、推理型 LLM、HRM／TRM、Neural GPU、NCA 等近年工作都以少 10^3-10^5 倍參數量達到可觀效能，最強 expressivity 概念即 Turing completeness。CA 結合局部規則與無界介質，GoL、Rule 110 已知 Turing complete。既有 CA 用法不把初始條件當可學習物件，EM 則直接訓練初始狀態扮演「program」。理想形式 latent universality（Theorem 1）：規則固定，只換初始狀態即可表示任意可計算函數；實驗僅做更簡單的 setting，模型規模僅 20-300 參數。

第 2 節：形式化

2.1-2.3 模型定義。 示意 x→E(x)→s0 --f^T--> s_T→D(s_T)→y：固定更新規則 f 在 latent 狀態 s 上迭代 T(s0) 步（可變，依初始條件而定）。Emergent Model 是六元組 M=(S,f,H,E,D,⊕)：program p 與編碼輸入 E(x) 經 ⊕ 合併成 s0=p⊕E(x)，推論即初始化→迭代 f 至 halting→解碼，得部分函數 Φ(x)=D(f^{T(p,x)}(p⊕E(x)))。「模型計算函數 g」（Def.1）要求定義域上處處精確相符（離散）或任意精度逼近（連續），強於一般深度學習的「緊緻域局部擬合」。可訓參數分兩類：soft parameters 屬 program p，推論期可能因 retention 改變；hard parameters 屬 f/H/interface，訓練後固定不變。

2.4 Latent Universality。 若 (S,f,H,E,D,⊕) 全固定、僅改 program p 即可實現任意 partial computable function，稱該 EM latent-universal（Theorem 1）。這是把 UTM「固定轉移函數＋固定編碼即可跑任意程式」重述為機器學習語言：encoder E 只作用於輸入 x、不含 p 或目標函數資訊，故可獨立搜尋 program 而不動輸入編碼。Theorem 1：在可數無界節點集、有限離散取值（含 quiescent 符號）、program 與 encoded input 皆有限支撐的強通用性設定下，對任意 partial computable function g，存在有限支撐 program p 使 Φ_p 計算 g；Appendix 擴展到 Game of Life（Rendell 構造）。

2.5-2.7 序列操作、擴展、訓練。 序列任務引入 retention operator R：S→S，把終止狀態轉成下一 macrostep 合法的 program，p_{i+1}=R(s_{T_i,i})（直接沿用終止狀態通常無效，因已滿足 halting）。作者推測：reward 併入輸入時，latent-universal EM 或可內部同時實現「預測」與「用 reward 修改 program 子區塊」兩子程序，構成 meta-learning 雛形，但屬推測。框架可延伸到連續時間／PDE 型場，或放寬為固定計算時間預算 T（允許 identity retention R(s)=s）。EM 動態高度遞迴、非凸、常離散，梯度法不可行，訓練採族群演化演算法，適應度只取決於解碼輸出。Searchability Lemma：program 皆有限支撐字串時，對任意 partial computable g 存在有限字串可實現，枚舉／隨機取樣理論上終能命中，僅保證漸近存在性。

第 3 節：實驗（以下數字均為作者自報）

3.1-3.3 算術任務。 EM43：1D、4 值、radius-1 CA，program 區長 Lp＋60 條 LUT，2 bits/參數。訓練域 x∈[0,30]，外推測試域 [30,1000]；x+1、2x、x mod 4、round(x/3)（Lp=10，70 參數＝140 bits）與 x·(1+x mod 2) 全部 100% 訓練／100% 測試準確率；雙輸入 a·b（Lp=50，110 參數）未收斂，訓練/測試皆差，原因無法歸因於算力、超參、interface 或表達力。成功案例呈現「geometric grokking」：泛化以規則可讀的幾何圖案呈現（x mod 4 學到「標記左移 4、下移 4 直到藍色成多數」），跨尺度穩定。GoL-EM 固定規則、只訓 glider 位置：x-2/x-1/x+1/x+2/x+5（18 格、2 glider、4 萬次評估）全部 100%/100%；條件式任務（偶數 x+1、奇數 x-1；26 格、3 glider、100 萬次評估）僅 60%/50%，隨機搜尋與 GA 效果相近，地景弱結構化。

3.4-3.7 控制任務。 CartPole 隨機基線約 20-25，滿分 500 或 800。GoL-EM CartPole（無 retention）代表性 run：T=300、族群 100、10 世代，族群平均 return 171.36，最佳訓練 return 417.20，20 個新 episode 評測 316.90±121.52，非 halting 率 54.5%；策略偏重角度、忽略位置。CEM1D：連續值 1D 格（L=19），局部規則含三次阻尼項（γ=0.03 固定），僅訓 a_l,a_c,a_r 三係數，內部 T=30 microstep，具跨 macrostep retention。70 世代、族群 120：訓練 return 737.32±104.63，1000 個新 rollout 評測 734.93±107.00（滿分 800），遠超基線，但長 rollout 中 cart 仍常漂出邊界。

3.8-3.10 Meta-Life。 2D 環面世界，agent 靠三道 lidar 感測，輸出轉向與速度；Meta-Life-Food 單純覓食（reward+1），Meta-Life-Adapt 中資源在 food/poison 間隨機時長切換但視覺相同，agent 須靠碰觸後 reward 線上推斷並切換策略。CEM2D：8×8 格雙通道，T 可訓練（[2,10]），hard params 35、soft params 128。mRNN baseline：d=6，每 macrostep 更新一次（T=1），hard params 117、soft params 12。Meta-Life-Food：CEM2D 訓練/評測 return 155/133，mRNN 150/146。Meta-Life-Adapt（族群 300；CEM2D 訓 510 世代、mRNN 260 世代）：CEM2D meta-score 0.714（reaction 0.780、after-reaction 0.699），mRNN 0.822（0.913、0.796，約高 15%），皆遠高於基線 0，皆能線上調適，CEM2D 收斂較慢。latent 狀態出現與 food/poison 相關的可解釋 cell，調節「追逐 vs 原地旋轉」；消融記憶場 m 短期影響小但長 rollout 退化。兩模型皆有「原地旋轉」失效，mRNN 另有「碰毒後永久靜止」的 freezing 失效。

第 4 節：結論

EM 被定位為對 CA／NCA／Neural GPU／RNN／計算理論既有想法的整合，主張學習相關的計算不必駐留在預先規定的架構中，可直接從物理式基質及其初始條件湧現。latent universality 把 Turing completeness 加上「固定、與任務無關的 interface」，使「模擬任意機器」變成「把任意函數當黑盒計算」；固定成分只定義通訊語法，program 決定語意。實驗刻意極簡（數十到數百參數，遠小於同類系統常見的 10^5+ 參數），目的是把路線可行性與規模效果分開檢驗，成熟度類比「深度學習二十年前」。作者提出猜想性指標 q=N_params/T̄：低 q 迫使搜尋收斂到壓縮、規則式解，高 q 給予容量直接記憶資料，大型 FFNN 是高 q 極限；低 q 泛化優勢或需付出可訓練性代價，latent-universal EM 原則上可兼具兩者。論文承認 GoL 對初始條件高度敏感是最大障礙，CartPole 與 Meta-Life 環境可能被近線性策略解掉，不足以充分檢驗 EM 優劣。後續方向：先跨任務聯合訓練共用規則，再凍結規則只搜各任務 program，並為此類地景設計專門最佳化演算法。
