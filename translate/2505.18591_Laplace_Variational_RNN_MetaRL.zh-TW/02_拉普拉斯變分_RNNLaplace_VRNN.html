4. 拉普拉斯變分 RNN（Laplace VRNN）

對變分任務後驗 \(q(z)\) 做相對簡單的拉普拉斯近似，用於式 (2)/(4) 的下界。核心：用此把點估計法（base RNN）擴展成在訓練任一時點可用分布。

  • 把預測的分布參數當 helper 變數，視映射為學到的摘要統計（MAP 估計）；\(\mu\) 由 RNN 自迴歸計算。
  • 對 \(q\) 做均場假設（式 5），得欲近似的目標函數；對在 \(\mu\) 處線性化的對數後驗做二階 Taylor 展開、指數化、再正規化；假設 \(\mu\) 為 MAP，得拉普拉斯近似（式 6），其中協方差由對數後驗 Hessian 給出。
  • 時序聚合：對每步後驗的期望，假設高斯密度卷積 → 結果仍為高斯、參數相加（式 7/8，Bromiley 2003）。即：RNN 把最近幾步隱狀態與協方差相加得輸出高斯；實務用較小窗口控成本。
  • MAP 假設之風險：假設 \(\mu\) 為 MAP（即式 3 攤銷取等）相當嚴格；函數類不足時會在變分對數後驗的 Taylor 展開引入一階誤差、近似變差。且多數 RNN 不對預測模型求和隱狀態，與本式失配。下節以實驗探究這些技術假設。

特例（便宜關鍵）

取 \(q\) 為標準高斯 + \(z\) 無資訊先驗時，對數後驗 Hessian 化為 RNN 狀態 Jacobian 對 \(\mu\) 的外積和，給出逆協方差（式 9），可用 **forward accumulation（JAX）**廉價計算。

後驗預測

若策略對 \(z\) 線性，全模型退回一種高斯過程；本文改用另一神經網路建此項以增表達力。策略由後驗預測定義，以 Monte-Carlo 採樣計算（式 10）→ 誘導出有限混合策略（對應 posterior sampling，Osband 2013）。\(\mu\)、策略參數端到端聯合訓練。訓練時發現當樣本數 \(>1\) 時輸出聚合更穩——故訓練時對 logits（或連續情形對參數分布的均值/方差）做樣本平均。

5. 實驗驗證

對 RNN-based 記憶式元 RL agent 套用本法（不改架構）需若干簡化（僅非平穩對數後驗假設需省去式 7 的均值聚合；平穩因式分解不需）。三個研究問題：(1) 效用：能否給非貝葉斯基線有用的後驗統計？(2) 敏感度：哪些模型假設經驗上有效？(3) 效能：當作 VI 替代品時是否至少與既有法持平？

基線：點估計 RNN（LSTM）；VRNN（Chung 2015，以 RNN 輸出變換預測高斯均值與協方差）。RNN/VRNN 假設平穩因式分解後驗（式 1 的簡化、最貼近真生成過程）。間歇對 RNN 做快照、在參數網格上微調出 Laplace VRNN 與 VRNN。所有實驗跨多 seed 重複，報 95% 雙側信賴區間。

5.1 監督式學習

在無噪 1D 迴歸任務（Fourier 展開採樣參數生成資料集）測試；訓練最小化監督下界（KL 權重）；測試算與真生成分布的預測交叉熵（CE），每步以 Monte-Carlo 估後驗預測。

變體：Laplace VRNN 用**平穩假設（Stationary，紅）**與 Markovian 假設（Sum，綠）；前者對 \(D\) 中每點在每步算協方差，後者對每對相鄰步求和協方差。測對角與滿協方差。

結果（圖 1）：預測 CE 起初下降，當資料集超過訓練所見長度後略升。stationary Laplace VRNN 非從頭使用（紅）會嚴重退化（尤其滿協方差）——可能後驗過寬、點估計過尖，導致樣本對預測模型而言離分布。反之 Markovian（綠）在所有情況至少與基線持平，且訓練後仍提供 RNN 的貝葉斯後驗。圖 2 顯示：對累加協方差的綠線做 post-hoc Laplace（最右列），後驗越來越自信卻不收斂到穩定分布。

5.2 強化學習

在隨機 5-臂 bandit 與稀疏獎勵確定性 gridworld 上測（用 recurrent PPO 近似式 4）。bandit 從 Dirichlet 先驗採獎勵機率、策略只條件於採樣模型假設（如 Thompson sampling）、考驗對模型採樣噪聲的穩健性；gridworld（Zintgraf 2021）隨機生成起點/終點、agent 把任務建模為 Bayes-adaptive MDP（策略條件於模型樣本 + 當前狀態）。

變體：windowed stationary Laplace（紅，截斷歷史以改善否則 \(O(t^2)\) 的協方差計算）；兩個 Markovian 變體（\(O(t)\)）——**proper-Markovian（藍）**求和每個 state-action 的均值與協方差，另一只求和協方差（綠）。

結果：

  • 後驗統計演化（圖 2）：貝葉斯法的後驗熵可靠下降、相鄰後驗 KL 近零（理想行為）。微調時相似（除 stationary 紅）。最關鍵：累加協方差的綠變體做 post-hoc 後驗時，熵穩定下降、但相鄰後驗 KL 越來越大；反之 post-hoc VRNN（灰）與 stationary（紅）保持恆定、無資訊。這顯示確定性 RNN 未收斂到穩定隱狀態：學到的估計子越來越自信卻不一致（延伸 Xiong 2021）。
  • 訓練回報（圖 3）：確定性法（黑）效能強、噪聲最低、訓練最快；Laplace VRNN 勝過 baseline VRNN。proper-Markovian（藍）在 bandit 早期學更快但 gridworld 退化。bandit 上所有貝葉斯法噪聲顯著、僅達次線性累積後悔；gridworld 上各法皆達次線性後悔。
  • 總結：所有貝葉斯變體在確定性預訓練後 post-hoc 套用皆不退化；Laplace VRNN 回報通常與 VRNN 持平；唯 **Markovian + 累加協方差（綠）**能產出有洞見的後驗統計。三個研究問題均獲確認。

6. 結論

描述了如何在 zero-shot 元 RL 脈絡把拉普拉斯近似套到 RNN 模型——一個把既有循環網路廉價轉成貝葉斯模型的方法，讓訓練好的 agent 更準地建模任務不確定性。在監督與 RL 任務上驗證效用、模型假設依賴性、與 VI/點估計基線的對比（不退化效能）：可在訓練任一時點、不改模型或訓練程序，把非貝葉斯模型可靠地轉成貝葉斯後驗；反觀 VI 需改架構與訓練設置卻僅持平或更差。

局限：需算 Jacobian、受高斯限制；RNN agent 需多種機率模型簡化（某些配置），其引入偏差待究；本法只能觀察、不能修正非貝葉斯 agent 的過度自信。未來：朝統計上嚴謹的表徵學習、或透過分布偏移偵測改善元 RL 探索。
