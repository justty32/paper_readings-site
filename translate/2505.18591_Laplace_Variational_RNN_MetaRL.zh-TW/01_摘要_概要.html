摘要 / 概要

元 RL 在任務分布上訓練單一 RL agent，使其測試時能快速泛化到訓練集外的新任務。從貝葉斯視角，這可詮釋為對訓練任務後驗做攤銷變分推理。眾多元 RL 法中常見做法是用 RNN 以點估計表示此分布。本文展示如何透過拉普拉斯近似——在學習開始、進行中或之後——把點估計擴增為完整分布，且不改基礎模型架構。藉此近似，我們能估計非貝葉斯 agent 的分布統計（如熵），並觀察到點估計法產生過度自信的估計子、不滿足一致性。再者，與完整分布式學任務後驗的方法相比，本法在參數遠少之下表現與變分基線相當。

四點貢獻

  1. 構造一個機率圖模型以匹配記憶式元 RL agent 的實務設計，從而透過拉普拉斯近似做不確定性量化，無需重訓或改架構（擴展 Chung 2015 的 VRNN、Abdolmaleki 2018 的 MPO，採 Levine 2018 的 control-as-inference）。
  2. 研究對 MDP 後驗模型的不同假設如何與 RNN 的表徵學習、不確定性量化交互（對非貝葉斯 agent 套貝葉斯近似，仍存在一定程度的模型誤設）。
  3. 當作 baseline VRNN 的替代品時，本法持平或更佳——用更少可學參數、無需改架構即提供變分線上學習的替代近似。
  4. 結果顯示非貝葉斯元 RL agent 學到的 RNN 表徵（跨多種圖模型假設判斷）產生過度自信的估計子——延伸 Xiong 2021「記憶式元 RL 學到不一致估計子」的洞見。

1. 引言

元 RL 中 agent 在環境的先驗分布上訓練，使其能就一段新軌跡推斷潛在環境參數並線上適應行動策略（zero-shot／few-shot 適應）。準確的**任務後驗（給資料下潛變數分布）**對量化 agent 不確定性有用：可偵測分布偏移、以新奇訊號引導探索；部署時分布偏移偵測對及時人為介入或重訓至關重要。

常見做法用 RNN 隱狀態做點估計任務後驗，但拿不到分布統計、且過度自信（除非真後驗尖峰於該點，這是不切實際的強假設）→ 已知會過擬合訓練分布、下游脆弱（Xiong 2021；Greenberg 2023）。顯式參數化完整分布（如高斯 VRNN）更準，但訓練更慢、回報常還輸給點估計法（後者採樣噪聲低、數值易表示、模型容量不被「學複雜後驗」佔用）。

本文提出 Laplace VRNN：用拉普拉斯近似擴展 RNN-based 元 RL，不改架構、不改損失、不重訓即可對非貝葉斯 agent 做不確定性量化；可在訓練任一時點套用，訓練後套用即 post-hoc 後驗（Daxberger 2021），讓我們既享確定性預訓練之利、又得貝葉斯之益。拉普拉斯近似只需在局部極大處的對數似然曲率；對均場高斯假設，只需 RNN 輸出對隱狀態的 Jacobian，得中心在 RNN 隱狀態、逆協方差等於 Jacobian 外積和的高斯——比對高維網路參數做 Laplace 便宜得多。

2. 相關工作

  • 元 RL：從 context、潛變數模型、攤銷推理、「學會學習」等多視角描述。與本文相關的是 Garnelo 2018 的神經過程（用元學習推斷生成分布的全域潛變數）；本文在 RL 上測試，故模型可視為非平穩隨機過程／序列神經過程。與 PlaNet（Hafner 2019）類似，但不把循環模型條件於任務後驗的採樣，以求解析解（代價是降低模型非線性）。
  • 貝葉斯 RL：學「條件於任務後驗」的最優控制策略 ≈ 逼近 Bayes-adaptive 最優策略（Duff 2002）——agent 條件於當前狀態與觀測歷史、產生潛變數信念分布、在信念上最大化期望回報。本文聚焦 Bayes-adaptive 框架。
  • 拉普拉斯近似：曾用於 MAML（Finn 2017/2018）做更準推理、或持續學習（Kirkpatrick 2017）當權重更新正則。主障礙是逆 Hessian 計算（參數量的平方記憶體），故 BNN 常用 block-diagonal 分解（Martens & Grosse 2015）。本法繞開此問題——只對全參數的小子集（隱狀態）建分布；相較對最後一層做貝葉斯線性迴歸，本法能表達多峰分布。

3. 預備

把序列決策形式化為回合制 MDP：狀態、動作、獎勵為隨機變數；折扣因子吸收進轉移作為全域終止機率（Levine 2018）。目標是找最大化期望回報的策略 \(\pi\)。

3.1 元 RL 中的推理

與單任務 RL 不同，元 RL 要對環境分布找最優策略；agent 通常不知身處哪個環境，需據線上回饋自適應切換策略，且可跨多回合適應（zero/few-shot）。以全域潛變數 \(z\) 形式化：固定 \(\phi\) 下，每條採樣軌跡依賴採樣的 \(z\)（可詮釋為當前環境的唯一識別碼），agent 不直接觀測 \(z\) 但其影響環境的獎勵與轉移。式 (1) 定義生成過程，含環境採樣分布與給目前所有觀測資料下潛變數的後驗（後驗在每步 inter-episodically 更新）。此模型完全一般化，反映多數記憶式元 RL 的因式分解與推理能力；一般化既是優點（捕捉廣泛環境）也是缺點（搭函數逼近時模糊了 agent 學到什麼、後驗不確定性如何表示）。

攤銷推理：式 (1) 後驗通常不可解 → 用變分推理，以較簡模型類的分布 \(q\) 表後驗、最大化資料邊際的下界（式 2）。為免每步重解泛函優化，用攤銷：訓練一神經網路把過去觀測直接映到分布參數（Gershman & Goodman 2014）。式 (3) 給出攤銷學習目標的不等式——具足夠函數類與最優參數時取等，且可用標準 SGD 訓練（需能從 \(q\) 採樣、且對參數端到端可微）。

從推理到控制：用 control-as-inference（Levine 2018）擴展式 (1)。引入二元最優性變數 \(\mathcal{O}\)，其給定軌跡的似然 = 獎勵和的指數；由貝氏規則推出期望策略。對 \(\mathcal{O}\) 的對數似然定變分下界（用變分策略），給定本文的 outcome likelihood 即得正則化 RL 目標（式 4）——是 MPO（Abdolmaleki 2018）目標的擴展，納入潛變數後驗及其 KL 項。實務常加三項設計選擇：(1) 用前一步變分後驗替代真後驗（只在 \(t=0\)、episode 0 用真先驗）；(2) 策略迭代更新到變分最優；(3) KL 罰項以 \(\beta\) 縮放。當用點估計（Dirac 後驗）+ 忽略 KL 時，攤銷後的式 (4) 退回典型記憶式元 RL 目標（Duan 2016）。
