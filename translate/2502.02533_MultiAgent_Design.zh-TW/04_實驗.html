4. 實驗

模型與評估資料：除了自動化 MAS 常用的基準外，作者在廣泛的任務集合上實驗：1）Hendryck's MATH 與 DROP 用於推理；2）HotpotQA、MuSiQue、2WikiMultiHopQA（取自 LongBench）用於長上下文理解；3）MBPP、HumanEval、LiveCodeBench（LCB）「test output prediction」子任務用於程式生成。主要實驗以兩種 Gemini 1.5 模型規模（gemini-1.5-{pro,flash}-002）進行，並在附錄以 Claude 3.5 Sonnet 與 Mistral Nemo 進一步驗證關鍵發現。

基線：CoT（零樣本 chain-of-thought）；CoT-SC（@9 agents 的 self-consistency）；Self-Refine（2 agents @5 輪，含 Reflexion 風格）；Multi-Agent Debate（3 agents @3 輪 + 1 位裁判）；ADAS（LLM-based meta-agent 迭代提出新 agent）；AFlow（在預定義算子集合上用 MCTS 自動設計 workflow）。所有基線在相當的每查詢推理成本、最多 10 個 agent 的限制下公平比較。

主結果（Table 1）：MASS 相對於不優化 prompt、只擴大規模的常見 MAS 形式（self-consistency、self-refine、multi-agent debate）帶來實質增益：在 Gemini 1.5 Pro 與 Flash 上分別平均達到 78.8% 與 74.3%，在 Claude 3.5 Sonnet 與 Mistral Nemo 上也觀察到一致的改善。與 SOTA 自動 agent 設計基線 ADAS、AFlow 比較：ADAS 即使其 meta-agent 生成已以常見 agent 形式為條件，仍只帶來細微增益——meta-agent 持續提出複雜拓撲，卻沒有優化 prompt 設計；AFlow 則展現與 MASS 相當的競爭力，尤其在 2WikiMQA 與 HumanEval 上。作者將 AFlow 的表現歸因於：1）其「擴展」階段根據對照真值與預測的錯誤日誌生成新節點，提供隱含的文本梯度以反思任何格式錯誤；2）在一組預定義算子內更精煉的搜尋空間。儘管 AFlow 與 MASS 同樣重視搜尋空間設計的重要性，它仍缺乏優化其預定義算子的 prompt 優化階段，導致在 MATH 與 MuSiQue 上表現不足。相較這些基線，MASS 帶來的一致改善凸顯了同時搜尋 prompt 與拓撲設計空間的重要性。

逐階段消融：從 block-level 到 workflow-level 優化，並與單一 agent APO 基線（MIPROv2）比較：block-level 優化與單一 agent APO 之間存在平均 6% 的顯著差距，顯示 MAS 從「讓其 agent 在建構區塊內被優化」中獲益甚多，顯著優於單靠 APO；從 Stage 1 到 Stage 2，透過組成有影響力的拓撲並搜尋最佳配置，可再獲得約 3% 增益（消融顯示：若省略事前的 prompt 優化、或省略搜尋空間剪枝，Stage 2 效果都明顯較差，兩者對有效搜尋空間探索都是關鍵）；最後 MASS 透過對最佳拓撲做 workflow-level prompt 優化再獲得約 2% 增益，顯示針對 agent 相互依賴建模的 prompt 優化在 MAS 中有其效益。

成本效益：MASS 的優化軌跡呈現穩定趨勢，透過交錯搜尋更好的 prompt 與拓撲逐步改善驗證表現。相較之下，沒有明確 prompt 優化階段的自動設計基線：AFlow 因 MCTS 本質而暴露較大變異；ADAS 則陷入發現過度複雜、卻不如 prompt 設計空間有效的拓撲。整體而言，MASS 的優化軌跡凸顯了在有效設計空間中優化的重要性，交錯優化在相同訓練成本下進一步以更多連續獎勵化解了複雜度。此外，MASS 也展現了推論 token 效益上的優勢與可比擬的訓練成本。

最佳 MAS 架構與設計原則：作者進一步檢視在 MATH 上優化 prompt 的例子與 MASS 發現更有效拓撲的軌跡（Fig. 7）：優化從零樣本 CoT agent 起步，Stage 1 很快識別出以 debate 為高表現拓撲、搭配其優化過的 prompt；然而 Stage 2 發現，用更多並行 agent 做聚合，實際上優於多 agent 辯論；workflow-level prompt 優化接著找出最佳的聚合預測者 prompt。整體優化流程揭示了建構有效 MAS 的指引：1）在組成 MAS 前妥善優化個別 agent 很重要；2）透過組成有影響力的拓撲可建構更有效的 MAS；3）為 agent 間的相互依賴建模是有益的，可透過 workflow-level 聯合優化達成。

5. 相關工作

LLM-based agentic 系統的形式：最簡單的 LLM-based agentic 系統形式涉及單一能動態與環境互動、回應的 agent。近期進展賦予 agent 多元角色與工具，協調多個 agent 彼此合作。agent 合作的標準形式（即拓撲）常涉及並行與串行的資訊流：並行形式通常在多個 agent 間多元化探索，self-consistency 是其代表；串行形式旨在透過一連串 agent 推進任務的利用，LLM 可作為反思型 agent 來自我論證與精修先前的預測；之後，多個 agent 的意見可由聚合 agent 摘要以取得最一致的答案。此外，多 agent 辯論涉及更複雜的資訊流，近期研究顯示辯論可引出更真實的預測。近期 agent 拓撲擴展超越上述連接方式，MASS 能在上述空間中自動搜尋最佳拓撲。

MAS 的自動優化：近期研究開始透過把 agent 功能解讀為可學習的策略、並為 agent 微調合成軌跡，自動化 agent 設計。從單一 agent 更進一步，自動多 agent 優化面臨更高層次的複雜度，因此需要更精緻的搜尋空間與演算法設計。在近期多 agent 優化的進展中，優化空間已涵蓋 prompt、工具、workflow、思考策略。更接近本文拓撲搜尋空間的是：DyLAN 動態啟用 agent 的組合；Archon 把 MAS 形式化為超參數優化問題——兩者皆未考慮重要的 prompt 空間，本文已在第 3 節證明其重要性。此外，GPTSwarm 用 policy gradient 演算法優化 agentic 節點之間的連接。SOTA 自動 agent 設計方法 ADAS 與 AFlow 也嘗試用進階搜尋演算法與以 LLM 作為優化器來優化 agentic workflow。與本文同期的 MaAS 為查詢相依的 MAS 優化一個 agentic supernet。然而，作者觀察到 prompt 設計的重要性在這些先前工作中相對地未被充分研究。

6. 結論

作者以先對龐大設計空間做徹底分析為起點來設計有效 MAS，揭示 prompt 的關鍵角色，並識別出 MAS 搜尋空間設計中的冗餘。基於這些發現，作者引入 MASS——一個在經剪枝的設計空間內搜尋、交錯 prompt 與拓撲優化的新式多階段優化框架，能有效率地產生高表現的 MAS。MASS 對客製化的 prompt optimizer 與拓撲設計空間皆保持無關（agnostic）。實驗證明 MASS 優化的 MAS 在廣泛的任務集合上顯著優於現有的手工與自動化方法。最後，基於 MASS 發現的優化系統，作者萃取出寶貴的設計原則以指引未來 MAS 的發展，並期待未來的 prompt 與拓撲設計方法整合進 MASS，朝建構更高效有效的 LLM-based agent 邁進。
