摘要

大型語言模型作為互動協作的多個智能體，已在解決複雜任務上表現出色。這些智能體以宣告其功能的 prompt 編程，並搭配協調智能體間互動的拓撲。為多智能體系統（MAS）設計 prompt 與拓撲本質上很複雜。為了自動化整個設計流程，我們首先對設計空間做深入分析，理解建構有效 MAS 背後的關鍵因素，發現 prompt 與拓撲兩者皆對啟用更有效的 MAS 設計扮演關鍵角色。基於這些洞見，我們提出 Multi-Agent System Search（MASS），一個透過交錯（interleave）其優化階段——從局部到全局、從 prompt 到拓撲——有效率地利用複雜 MAS 設計空間的優化框架，共分三階段：1）block-level（局部）prompt 優化；2）workflow 拓撲優化；3）workflow-level（全局）prompt 優化，每個階段都以前一階段迭代優化出的 prompt／拓撲為條件。我們證明 MASS 優化出的多智能體系統以顯著優勢勝過一系列既有替代方案。基於 MASS 找到的系統，我們最後提出建構有效多智能體系統背後的設計原則。

1. 引言

LLM 已展現出理解、推理、根據使用者 prompt 生成連貫回應的非凡能力，革新了廣泛的應用。LLM-based agent 透過自主處理跨領域的複雜任務來提升可用性，包括程式生成與除錯、檢索增強生成（RAG）、資料分析、互動式決策。這些 agent 通常以 prompt 編程，強化其與環境互動、利用可用工具、跨多輪逼近目標的能力。除了個別 agent 之外，LLM 還可以在複雜拓撲中被協調，把多個 agent 朝共同目標編排。這類多智能體系統（MAS）通常靠涉及更多元的 agentic 視角或角色分工（例如 agent 當驗證者、多 agent 辯論）而勝過單一 agent 的對應版本。

然而，為新領域設計有效的 MAS 常常很有挑戰性。首先，單一 agent 可能受prompt 敏感性所苦——prompt 的簡單修改就可能造成顯著但難以預期的性能退化。在 MAS 中，當敏感的 agent 被串接起來，因 prompt 敏感性造成的複合效應可能被放大。除了 prompt 設計，打造有效的拓撲可能需要大量基於試誤的人工實驗。問題複雜度又因整體組合式搜尋空間而加劇——不只是無邊界的 prompt 設計空間，還有「該把哪些 agent 整合進拓撲」的設計決策。

雖然近期研究已探索自動化 agentic 設計的各個面向，但對「究竟什麼因素對提升 MAS 表現最重要」仍缺乏理解。例如 DSPy 自動化了設計範例以改進 prompt programming 的流程；Li et al.（2024a）提出透過擴大多數投票中的 agent 數量來優化 MAS；ADAS 透過 LLM-based meta-agent 以程式碼編程新拓撲；AFlow 在一組預定義算子內用蒙地卡羅樹搜尋（MCTS）搜尋更好的拓撲。然而，包括 prompt 與拓撲在內的多個設計空間之間的相互作用，仍不清楚。

本文中，我們首先對 MAS 中常見的設計空間做深入分析，檢視優化 prompt、擴大 agent 數量、涉及不同類型拓撲等面向的影響。我們的分析顯示：prompt 經常構成能產出強力表現 MAS 的有影響力設計組件，而有影響力的拓撲只佔完整搜尋空間的一小部分。基於這些洞見，我們旨在把有影響力的 MAS 組件精煉進一個經剪枝的搜尋空間，藉此降低整體搜尋流程的複雜度。我們提出 Multi-Agent System Search（MASS），一個自動化 MAS 優化的新式多階段優化框架，作用於一個高效率的搜尋空間之上。MASS 整合了即插即用的 prompt optimizer 與 workflow optimizer，作用於一個可配置的拓撲空間。它透過交錯優化階段——從局部到全局、從 prompt 到拓撲——克服 MAS 上聯合優化的複雜度，共三階段：1）針對每個拓撲區塊的 block-level（局部）prompt「暖身」；2）在一個經剪枝的拓撲空間集合中做 workflow 拓撲優化；3）在最佳拓撲的條件下做 workflow-level（全局）prompt 優化。

透過在已識別出的有影響力組件上優化，MASS 產出達到 SOTA 表現的優化 MAS，在涵蓋推理、多跳理解、程式生成的廣泛任務選集上，以顯著優勢勝過現有手工打造的 MAS 基線與自動生成的替代方案。基於 MASS 找到的最強 MAS，我們進一步提供建構有效 MAS 背後的洞見與指引。整體貢獻：1）對影響 LLM-based MAS 表現的設計因素做深入分析，凸顯 prompt 的重要性並識別出有影響力的拓撲；2）提出 MASS，一個透過在有影響力的搜尋空間內交錯優化 prompt 與拓撲，自動化 MAS 設計的新式多階段優化器；3）MASS 在多個評估基準上展現顯著性能提升，為未來建構有效多智能體系統提供指引。
