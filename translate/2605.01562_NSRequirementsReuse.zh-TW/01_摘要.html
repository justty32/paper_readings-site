摘要

物件導向需求編寫與管理方法（OOMRAM）是一個需求重用框架，依賴精確識別碼匹配與僵化模板，限制了其在不同脈絡中調適規格的能力。雖然大型語言模型（LLM）提供了克服此瓶頸的彈性，卻引入了產生結構無效或不一致需求組合的風險。為處理此張力，我們提出一個神經符號多代理系統，將需求重用重新概念化為模型驅動的引出（Model-Driven Elicitation）流程。在此範式中，LLM 作為非確定性啟發式（heuristic），在由形式化 OOMRAM 需求晶格（lattice）表示的確定性領域模型中進行遍歷。一個確定性的符號驗證器在代理迴圈內強制執行所有結構約束，實際上以構造性方式消除了幻覺需求組合。在兩個應用家族上的自主基準測試中，我們的系統達到 100% 需求覆蓋率，約束違規率僅 0.2%。雖然對照單一金標準的 F1 分數僅中等（0.47–0.51），但每一份產生的規格皆結構有效且滿足所有必要領域需求。與模型無關的實作可透過子圖導航擴展至更大晶格，並提供透明的審計軌跡以滿足法規遵循。

一、引言

由於需求工程（RE）成本高且易出錯，從軟體產品線重用已驗證的需求已成為降低開發工作量與提升需求品質的有效策略。OOMRAM 將一個應用家族建模為需求物件的形式化晶格，其中的變異性透過判別式（discriminants）——限制子需求（更具體或替代性的需求）如何被選取的決策點——來表達。雖然 OOMRAM 提供了嚴謹的基礎，其原始檢索機制卻要求使用者指定精確需求識別碼。這道「精確匹配瓶頸」使分析師無法以自然語言專案描述自動生成規格。

LLM 能解讀自由文本的 stakeholder 願景並建議相關需求。然而，LLM 天生傾向產生幻覺：捏造不存在的識別碼、忽略必要約束、或組合互斥選項。近期的 RE 工具雖利用了 LLM，卻缺乏形式化正確性保證，使它們易受邏輯不一致所困。

為釋放 OOMRAM 形式主義在現代需求工程中的實用潛力，我們提出一個神經符號多代理架構，實現模型驅動的引出流程。我們的方法將 LLM 視為能解讀模糊 stakeholder 意圖的非確定性啟發式，而 OOMRAM 晶格則提供保證最終規格架構合理且無邏輯不一致所需的確定性領域模型。系統以 LangGraph 構建，部署四個專門代理：Navigator、Interpreter、Validator 與 Scribe，它們共享一個具型別狀態。關鍵是，Validator 不含任何 LLM 組件；它是一個演算法方法，對照 JSON 編碼的晶格綱要檢查每個被提議的需求選取。這一設計徹底阻斷了幻覺需求組合。

我們以自主模擬模式在十個專案願景上評估系統，這些願景來自兩個應用家族：原始的 eRecordKeeping 晶格（約 60 個需求）與合成的 SmartHome 晶格（約 20 個需求）。三個代表性願景結果顯示：(1) 全部 100% 完成且結構有效；(2) 對照人工金標準的 F1 分數 0.47–0.81（這是大量合法可選與替代選項的結果，非效能失敗）；(3) 約束違規率僅 0.2%（1 次違規，在 Validator 拒絕後修正）。其餘七個願景全部成功完成且零約束違規，確認了穩健性。

主要貢獻：(1) 引入神經符號架構，以 LLM 驅動的自然語言遍歷取代精確 ID 選擇，首次將 OOMRAM 操作化於 LLM 時代；(2) 呈現完全確定性的 Validator 作為執行期護欄，徹底消除非法需求組合，從而移除不受約束 LLM 固有的幻覺問題；(3) 提供可重現的自主基準，展示可靠遍歷、近零約束違規與產出規格的完全結構有效性；(4) 交付基於 LangGraph 與本地 Ollama 的開源、模型無關實作，設計上可擴展至更大的工業晶格。

二、背景與研究缺口

大型語言模型如今支援越來越多的 RE 活動，從初始引出到精煉與品質評估。多數工作依賴提示工程或微調，並對照人類編寫的參考來評估結果。這些方法雖能減少手動工作，但評估資料集仍小且常限定於特定領域。更重要的是，產生的需求鮮少對照機器可讀的約束進行檢查；正確性被視為可能或經驗上可信，而非形式化保證。

非確定性輸出使可追溯性成為 LLM 產出物件的長期困擾。一個有希望的方向是一開始就將可追溯性視為首要關注——將其嵌入結構化提示、以元資料感知微調、並使用檢索增強驗證來保持輸出可審計且與上游需求連結。Graph-RAG 與進階提示改善了需求與法規的對齊，但在輸入不完整或含雜訊時仍缺乏形式化保證。形式化方法可提供強保證，卻仍與 LLM 驅動的 RE 管線脫節。

幻覺在安全關鍵 RE 中尤其危險。即使檢索增強系統在檢索不完整時也會產生幻覺。RAG、迭代紮根、多層框架等緩解法減少若干錯誤，但它們提供的是啟發式緩解而非確定性強制。現有 LLM 或代理框架未在生成迴圈中嵌入確定性約束檢查器。

代理式編排在 RE 中指的是使用多個自主代理各自處理工作流的不同部分，而非執行單一的直通管線。其他多代理 RE 應用包括辯論策略以改善需求品質，以及以 LLM 代理進行協作隱私威脅建模。然而，簡單的非代理式管線有時在特定基準上優於多代理方法，同時更可預測、更易維護。且此類多代理設置即使能實現動態推理與迭代精煉，通常也缺乏內建的強制正確性機制。

本工作彌補了這一缺口：在代理迴圈中整合形式化的、基於晶格的約束檢查器，透過演算法強制而非啟發式過濾，確保無幻覺規格。
