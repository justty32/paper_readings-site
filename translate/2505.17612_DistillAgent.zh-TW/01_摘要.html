摘要

大型語言模型（LLM）在複雜推理任務上表現卓越，但計算成本極高，限制了實際部署。近期研究聚焦於使用 teacher LLM 的思維鏈（Chain-of-Thought, CoT）推理軌跡，將推理能力蒸餾（distill）到小語言模型（sLM）中。然而，這種進路在需要稀有事實知識或精確計算的場景下遇到瓶頸——sLM 因能力有限，經常幻覺（hallucinate）。

本工作提出 Agent Distillation，一種不僅轉移推理能力、更將基於 LLM 的 agent 之完整任務解決行為轉移到配備檢索與程式碼工具的 sLM 的框架。我們沿兩個互補軸改進 agent 蒸餾：

  1. 提出 first-thought prefix（FTP）提示方法，提升 teacher 生成軌跡的品質；
  2. 提出 self-consistent action generation（SAG），改進小 agent 在測試時的穩健性。

我們在八個推理任務上評估——涵蓋事實領域與數學領域、in-domain 與 out-of-domain 泛化——結果顯示：小至 0.5B、1.5B、3B 的 sLM 可達到與下一級（1.5B、3B、7B）使用 CoT 蒸餾微調之模型相當的效能，展示 agent 蒸餾在建構實用、能使用工具的小 agent 上的潛力。

程式碼：https://github.com/Nardien/agent-distillation

1. 導論

LLM 在複雜真實世界任務中已超越平均人類準確率，但推論成本日益沉重。雖然 sLM（小型語言模型）備受關注，要保留大模型能力仍極具挑戰。核心問題：如何在遠更小的模型中保留 LLM 級的問題解決能力？

近期推理蒸餾（reasoning distillation）讓 sLM 模仿 teacher LLM 的 CoT 推理軌跡——但蒸餾後的小模型易幻覺、常無法準確計算。例如，「2010 年投 $100 買 Apple，2020 年值多少？」——CoT 蒸餾的學生只是背下 AAPL 的 split 歷史，遇到 Nvidia（NVDA）就不會了。

Agent Distillation 的兩個關鍵優勢：

  1. sLM 專注學習如何使用工具解決問題，而非死記知識與計算；
  2. 對需要前所未見事實或計算的新查詢泛化更強。

核心挑戰：這種複雜 agent 行為能否從 >30B 的 teacher 蒸餾進 0.5–3B 的 student？

貢獻

  • 提出 Agent Distillation 框架，訓練 sLM 模仿 LLM agent 軌跡，賦予 agentic 行為。
  • First-Thought Prefix：改善 teacher 軌跡品質（僅用於 teacher，student 推論不需要）。
  • Self-Consistent Action Generation：test-time 提升穩健性。
  • 在八個事實與數學推理基準上驗證，跨規模（0.5B–7B）一致超越 CoT 蒸餾。
  • 0.5B/1.5B/3B 蒸餾 agent 可達到下一級更大 CoT 蒸餾模型的平均效能。

2. 相關工作

2.1 語言模型的推理蒸餾

LLM 以 CoT 提示在複雜推理上表現強。CoT 蒸餾方法訓練 sLM 複現 teacher LLM 的逐步推理軌跡——尤其在數學推理上有效。近期工作引入外部工具（檢索、程式碼執行）來改善泛化，但大多數仍依賴靜態示範，缺乏與環境的互動。對比之下，本工作蒸餾 agentic 行為——模型在與環境互動中學習推理和工具使用。

2.2 語言 Agent 與 Agentic 推理

Agent 泛指自主觀察世界、採取行動以追求目標的實體。早期工作如 ReAct 引入「語言 agent」——觀察世界、用自然語言思考、採取行動。因 LLM 原生並非為此類互動訓練，先前工作依賴精心設計的 prompt（few-shot 範例），或從更強模型生成軌跡進行微調（FireAct）。此前研究聚焦於微調 ≥7B 的 LLM——而本工作旨在將 LLM 的 agentic 能力蒸餾進 ≤3B 的 sLM。

3. 預備知識

知識蒸餾（Knowledge Distillation）

知識蒸餾將大 teacher \(p_T\) 的能力轉移到小 student \(p_S\)：

\[\min_\theta \mathbb{E}_{(x,y)\sim D_{train}} \frac{1}{L_y}\sum_{n=1}^{L_y} D\left(p_T(\cdot|y_{<n},x) \| p_S(\cdot|y_{<n},x;\theta)\right)\]

推理蒸餾（Reasoning Distillation）

在推理任務中，\(y\) 可以是逐步解題的 rationale。teacher 用 CoT 提示生成 rationales，student 模仿：

\[\min_\theta -\mathbb{E}_{x\sim D_{train},\, y\sim p_T(\cdot|x,I_{CoT})} \sum_{n=1}^{L_y} \log p_S(y_n|x,y_{<n};\theta)\]

其中 \(I_{CoT}\) 是 CoT 風格提示（如「Let's think step by step」）。

4. Agent Distillation

推理蒸餾不賦予模型與外部環境互動的能力。Agent 軌跡由反覆的「思考（thought,\(r\)）、行動（action,\(a\)）、觀察（observation,\(o\)）」循環組成：

\[\tau = ((r_1,a_1,o_1),\ldots,(r_{L_\tau},a_{L_\tau},o_{L_\tau})) \sim p_T(\cdot|x,I_{agent})\]

\(I_{agent}\) 是 agent 指令，如「你必須以一系列 Thought→Code→Observation 步驟解決任務」。每個 observation \(o\) 由環境回應（非模型生成）。蒸餾目標（排除 observations）：

\[\min_\theta -\mathbb{E}_{x\sim D_{train},\,\tau\sim\pi_T(\cdot|x,I_{agent})} \sum_{t=1}^{L_\tau} \log p_S(r_t,a_t|x,\tau_{<t};\theta)\]

蒸餾後，sLM 可作為互動式 agent 運作：思考要產生什麼程式碼、生成行動（API 呼叫、迴圈）、根據執行回饋修正——如 interpreter 報錯則修正程式碼；輸出有效但不夠（搜尋結果次優）則改寫查詢。

兩個關鍵挑戰

  1. agentic 行為往往在 pretraining/instruction-tuning 分佈之外，蒸餾可能損害已在 CoT 風格推理上優化良好的領域。
  2. sLM 產出功能性程式碼的能力較弱，常見錯誤格式、錯誤使用函式庫。

First-Thought Prefix（FTP）

觀察：instruction-tuned LLM 作為 agent 時，在 MATH500 難題上的表現不如用 CoT 提示（分佈偏移）。假設是 agent 指令覆蓋/衝突了既有 CoT 推理模式。初始推理步驟至關重要（首步偏差使整條鏈偏離）。

解法：借鑒 LLM jailbreak 的 prefix-attack，先用 CoT prompt 生成第一步推理 \(y_1\)，再將 \(y_1\) 作為 prefix 餵入 agent prompt 繼續生成完整軌跡：

\[y_1 \sim p_T(\cdot|x,I_{CoT})\]
\[\tau \sim p_T(\cdot|x,y_1,I_{agent})\]

**FTP 僅用於 teacher 生成軌跡，student 推論時不需要。**這使 teacher 生成的軌跡含 CoT 式初始化，兼顧 agentic 靈活性。

Self-Consistent Action Generation（SAG）

小蒸餾 agent 常產出無效行動（CodeAct 中 = 無法執行或報錯的程式碼）。

SAG 機制：每步不只用 greedy decoding，而用 nucleus sampling（高溫 T=0.4）採樣 \(N=8\) 條 thought-action 序列，以輕量 interpreter 過濾 parse/execution error。全失敗則保留一個隨機失敗 action，以其錯誤訊息作為 observation 供下一步修正。進一步以多數投票在產生的 observations 上取最一致者作為最終 action——若三條成功、兩條輸出相同，則選其一。

5. 實驗設置

任務與資料集：兩類推理——事實型（in-domain: HotPotQA；out-of-domain: Bamboogle/2-hop, MuSiQue/3-hop, 2WikiMultiHopQA/2-hop）與數學型（in-domain: MATH；out-of-domain: GSM-Hard/大數運算， AIME/奧賽級， OlymMATH/奧賽級）。訓練用 HotPotQA 1000 + MATH 2000 題。每測試集上限 500 題。評估指標：數學用 exact match，事實型用 GPT-4o-mini 作 judge。

模型：Teacher = Qwen2.5-32B-Instruct。Student = Qwen2.5-Instruct (0.5B/1.5B/3B/7B)。

基準線：(1) CoT 蒸餾——模仿靜態 CoT 推理鏈；(2) CoT 蒸餾 + RAG——加入檢索增強，公平對比外部知識；(3) 本工作 Agent Distillation（基於 CodeAct/smolagents 框架，含 FTP 與 SAG）。

訓練細節：Wikipedia 2018 作 KB（非搜尋引擎），e5-base-v2 embedding。每題採樣 teacher 軌跡一條，過濾錯誤軌跡得約 2000 條。LoRA rank=64 全線性層，batch=8，lr=2e-4，2 epochs，4x A100 80GB。推論用 greedy decoding，agent 上限 5 steps，SAG 設 N=8、T=0.4。
