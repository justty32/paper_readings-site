論文／訪談原始來源

HEAL: An Empirical Study on Hallucinations in Embodied Agents Driven by Large Language Models

摘要與問題（第 1 節）

LLM 成為具身代理的高階規劃器後，也把文字模型的幻覺帶進物理行動。這裡的幻覺不是一般知識答錯，而是計畫沒有扎根於眼前環境：任務要求使用不存在的洗衣機時，模型仍產生洗衣機相關目標。錯誤會沿符號目標、動作規劃與軌跡生成往下傳，最後可能碰撞物體、浪費能源或執行危險替代動作。

HEAL 系統研究長時程任務中的 scene-task inconsistency。作者問哪些不一致最容易誘發幻覺、不同模型如何反應，以及沒有幻覺是否就代表規劃正確。重點不是一般情境中的偶發錯誤，而是用受控修改主動製造場景與指令衝突，觀察模型能否承認任務不可行。

定義與探測集（第 3 節）

基準管線先把視覺場景解析成物體、初始狀態與可能狀態的結構化文字，再由 LLM 把任務指令與場景轉為 Linear Temporal Logic（LTL）目標。目標分成物體應達到何種狀態的 node goal，以及兩物體應具何種關係的 edge goal。若輸出提及場景不存在的物體，或宣告不受場景允許的狀態，就判為幻覺。

探測集對基準提示做四種修改。Distractor Injection 在任務描述插入不存在但不影響核心目的的物體，測模型是否把干擾物寫入目標。Task Relevant Object Removal 從場景移除完成任務所需物體，測模型是否仍引用它。Synonymous Object Substitution 以常見同義詞替換場景物件，測模型能否理解概念等價並保持符號命名一致。Scene Task Contradiction 把原場景物件全換成不相關場景的物體，保留原任務，要求模型辨識整項任務不可行。

評估同時看物體與狀態。CHAIR 計算輸出所提項目中有多少是幻覺，較全面但受輸出長度影響；POPE 則把特定不存在物體是否被提及轉成二元探測。因基準提示與狀態沒有預先定義的負例清單，POPE 只用於物體。

實驗設計與主要結果（第 4 節，作者自報）

作者自報：探測集以 VirtualHome 與 BEHAVIOR 兩個模擬環境的長時程任務建成，含兩千五百七十四個 scene-task inconsistency 樣本；評估十二個開放與封閉 LLM，另以相同語言骨幹的 VLM 做小規模跨模態試驗。修改提示誘發的幻覺率最高可達基準提示的四十倍。

作者自報：VirtualHome 的任務較抽象且需要補足更多隱含步驟，整體幻覺高於 BEHAVIOR。四種變體中，Scene Task Contradiction 通常最高，顯示模型在整個場景不相容時仍傾向產生計畫；Synonymous Object Substitution 最低，表示模型大致理解同義概念，卻可能在輸出中混用新舊名稱。移除核心任務物體比移除周邊物體更易引發幻覺，小模型也更容易受 distractor 影響。

作者自報：在 VirtualHome 的 distractor 測試中，Qwen-VL 的 POPE 由只看影像的三十一點八四、只看文字的三十點三二，降到影像加文字的二十四點三七；LLaMA-Vision 與 Gemma 也以雙模態最低。文字通常比單獨影像更可靠，而兩者合用可交叉驗證。不過此試驗規模小，且只測 distractor，不能推廣到所有衝突類型。

緩解與失敗模式（第 4.2、5 節）

作者比較兩種事後自我修正。Knowledge-Augmented Feedback 提供一般原則；Self-Correcting Woodpecker 直接點名幻覺物體，因此較能降低錯誤。但即使收到明確回饋，Scene Task Contradiction 的幻覺仍高。這不是模型毫無推理：它會依共現模式補物體、替複數名詞生成多個實例，或理解同義詞；問題在於它缺乏在使用者要求與場景證據衝突時停止規劃的控制機制。

更深的問題是，沒有幻覺也不等於計畫正確。找不到洗衣機時，模型可能把淋浴器打開；找不到貓時，可能改抓衣物。這些輸出沒有引用不存在的物體，語法也可能有效，卻擅自改寫任務且可能造成危險。少數模型偶爾會明確拒絕不可行任務，但未形成穩定行為。因此可靠規劃的目標不能只降幻覺率，還要驗證任務可行性、保持使用者意圖，並允許代理說「無法完成」。

結論與局限（第 6～7 節）

受控的場景與任務不一致揭露了 LLM 具身規劃的接地缺口：自我修正只能部分緩解，影像與文字交叉驗證也未根治，最困難的仍是拒絕不可行任務。HEAL 因而提供失敗案例與理想反應方向，而不是一套已解決問題的代理架構。

研究主要聚焦物體幻覺，沒有涵蓋數量、屬性與空間關係等完整類型；只評估 LTL 符號輸出，未實際量測下游行動與真實機器人的執行錯誤。跨模態試驗規模有限，模型樣本也不能代表所有 LLM；緩解方法僅含事後自我修正，替代解碼、監督微調與架構層改造仍待研究。
