2 經驗壓縮光譜

我們形式化一條四層光譜，刻畫互動經驗如何被逐步壓縮成愈來愈抽象、可重用的知識。

2.1 形式化框架

定義 2.1（互動軌跡 Interaction Trace）：軌跡 𝒯={(s_t, a_t, o_t, f_t)}，是代理執行中蒐集的狀態、動作、觀察、回饋訊號序列。

定義 2.2（經驗壓縮函數）：C_L: 𝒯→𝒦_L，把軌跡映射到壓縮層 L∈{0,1,2,3} 的知識產物。

四層：

  • L0 原始軌跡：未壓縮互動記錄（完整日誌、執行軌跡）。壓縮率 1:1。可重用性極低，完全綁定 context。
  • L1 情節記憶（Episodic Memory）：結構化抽取「發生了什麼」，保留關鍵脈絡細節、丟棄冗餘互動機制。格式：鍵值對、時間戳事件摘要（例：「[2026-03-15] 使用者以 SQL 請求 Q3 營收分析，偏好表格格式」）。壓縮率 5–20×。可重用性低到中，綁定特定情節。
  • L2 程序技能（Procedural Skill）：抽取「某類情境該怎麼做」，跨實例抽象成可重用行為模式。格式：結構化 routine、程式片段、工作流模板（例：「資料分析：(1) 確認來源 (2) 選工具 (3) 以偏好格式呈現 (4) 驗證」）。壓縮率 50–500×。可重用性高，可跨相似情境遷移。
  • L3 宣告式規則（Declarative Rule）：抽取「什麼原則支配決策」，領域不變知識。格式：自然語言原則、約束、政策（例：「呈現前務必以來源資料核對計算結果」）。壓縮率 1,000×+。可重用性最高，領域通用但可能缺乏可操作的具體性。

2.2 光譜的性質

四層沿三個維度呈現系統性 trade-off，各具直接的效率意涵：

  • 泛化性 vs 具體性：壓縮增加（L0→L3）時知識更廣泛適用但更不 context-specific。
  • 壓縮率 vs 資訊保留：更高層透過語義抽象（辨識哪些模式可泛化、哪些屬偶然）丟棄更多脈絡細節。實例：Mem0 把多會話對話史（約 26,000 tokens）壓成檢索記憶條目（約 1,800 tokens），L1 約 15×；Trace2Skill 用 128 個並行子代理把 200 任務的軌跡蒸餾成緊湊技能目錄，L2 約 100–500×。
  • 取得成本 vs 維護成本：L1 記憶取得便宜（單軌跡）但規模化維護昂貴——只有 L1 的系統每天累積上千條，數週內就耗盡檢索預算；L3 規則需多條軌跡誘導但形成緊湊、低維護集合。這使向上壓縮對規模化長程部署不僅是「想要」而是「必須」。量化：只有 L1 的代理存 1,000 個情節、每個約 500 tokens ＝約 50 萬 token 知識庫，每次決策都要索引與搜尋；壓成 L2 技能降至約 5K tokens，壓成 L3 規則降至約 500 tokens——儲存與檢索開銷 100–1,000× 下降，並在每天上千決策上複利放大。

關鍵：這些不是循序的流水線階段。系統可從 L0 直接壓到 L3，或同時在多層維護知識。光譜描述的是輸出空間，不是固定處理順序。

2.3 映射既有系統

選入標準：(a) 從互動軌跡學習（排除預先寫定的規則）、(b) 產生持久知識產物、(c) 2023 年後發表。映射 20+ 系統（圖 1、表 2），揭露每個都運作在固定預設壓縮層。（選樣非窮盡；如 LightMem 等更多 L1 系統進一步印證聚集模式。）

  • L1 情節記憶：10 個系統聚此，機制多樣（LLM 驅動抽取、agentic 索引、階層儲存、RL 優化記憶操作、meta-learned 記憶架構、多代理協調、含時間衰減的治理）但都收斂到同一輸出——結構化情節記錄。
  • L2 程序技能：8 個系統聚此。Voyager 開創範式；CASCADE 把累積式技能創建與自主演化串起。一個新興共識強化本框架：把軌跡蒸餾成抽象技能，一致優於把它們存進檢索記憶庫（表 1）。SkillRL 在 ALFWorld 上較 L1 軌跡檢索 +68.5pp；Trace2Skill 在 SpreadsheetBench 上勝人寫技能 +21.5pp。SkillsBench 進一步發現 curated 技能有幫助（+16.2pp）而 LLM 自生技能毫無助益（+0.0pp）：光有壓縮層不夠，壓縮過程的保真度才決定產物是有用還是只是緊湊的雜訊。
  • 跨層（L1↔L2）：ExpeL 與 AutoAgent 同時運作於兩層，但都用預設層、無自適應選擇——是「兩速系統」，非連續光譜。
  • L3 宣告式規則：明顯稀疏。無任何被調查系統能自動化「從代理經驗抽取規則」。Constitutional AI 用預寫規則；獎勵設計方法（PBRS、process rewards、rule-based rewards）編碼 L3 型知識但由人設計、非學習而來。權重層規則（經 RLHF）訓練後靜態、不可檢視、不重訓就無法更新；scaffold 層規則則可檢視、可編輯、無需梯度更新即可部署。自動化 L3 抽取的障礙屬技術性：(i) 區分因果規律與偶然相關比抽取情節更難；(ii) 無 L2 接地的規則有過度抽象之險；(iii) 無評估規則品質的方法學（meta-evaluation 無限回歸）；(iv) LLM-as-Judge 給人「評估已解決」的假象。但近期實證提供初步 L3 證據：RuleShaping 研究 25,000+ 條編碼代理的自然語言規則，發現負向約束（護欄）改善 7–14pp 而正向指令反傷，暗示 L3 壓縮須保留 shaping 訊號而非規定性指令；SEVerA 為自演化代理加形式驗證（與壓縮層正交但對正確性關鍵）；閉合 L3 迴路方面，**帶顯式洞見治理的口語強化學習（Cui et al.）**把規則抽取配上持久證據日誌與 curation 政策，顯示同一批累積經驗，依治理迴路存在與否，會低於 zero-shot 基線或反而提升表現。

2.4 缺失的對角線（The Missing Diagonal）

映射揭露一個醒目模式：系統聚在 L1 或 L2、跨層工作極少、L3 幾乎空白。我們稱此為「missing diagonal」——缺少能做到以下三件事的系統：

  1. 為給定軌跡 𝒯 自適應選擇適當壓縮層 L。
  2. 證據充分累積時向上升層（C_{L→L'}, L'>L；多記憶→一技能→一規則）。
  3. 規則對特定 context 過抽象時向下降層（C_{L→L'}, L'<L）。

此缺口反映的是問題框定的侷限（每個社群先驗地定死自己的輸出格式），而非缺乏工程努力。自適應選層是一個meta-learning 問題：學「該抽取哪種知識」，而不只是「抽取哪些知識」。它也是可擴展性瓶頸：只有 L1 的系統面臨儲存與檢索成本線性成長，終將因無關條目稀釋有用知識而退化。向上壓縮（L1→L2→L3）是自然解方：把反覆出現的模式鞏固成緊湊技能或規則，使其隨經驗量次線性成長。
