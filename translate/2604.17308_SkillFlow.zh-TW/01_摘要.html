摘要

隨著自主智能體能力前緣持續擴張，它們愈來愈能透過「隨插即用」的外部技能完成專門任務。然而現有 benchmark 多半只測模型能否使用已提供的技能，卻沒有回答模型能否從經驗中發現技能、在失敗後修復它、並隨時間維持一個連貫的技能庫。本文提出 SkillFlow：一個涵蓋 20 個家族、166 個任務的 benchmark，每個家族內的任務建構都遵循一個「領域無關執行流程（Domain-Agnostic Execution Flow, DAEF）」所定義的智能體工作流框架，使同家族任務共享一致的工作流結構。智能體在「智能體式終身學習（Agentic Lifelong Learning）」協定下被評測：從無技能起步，依序解同家族內的任務，透過軌跡與 rubric 驅動的技能補丁把教訓外化，並把更新後的技能庫帶到下一題。實驗揭露顯著的能力落差：對 Claude Opus 4.6 而言，終身技能演化把任務成功率從 62.65% 提升到 71.08%（+8.43 點）；然而高使用率不代表高效益——Kimi K2.5 儘管技能使用率達 66.87%，收益卻僅 +0.60 點；Qwen-Coder-Next 完成率僅 44.58%，相對 vanilla 設定甚至倒退。SkillFlow 提供了這個方向的結構化測試平台，以及對技能發現、修補、遷移及其在終身評測下失敗模式的深入實證分析。

1 引言

前緣 LLM 系統愈來愈常被部署為在終端環境中解決真實多步任務的自主命令列智能體，Claude Code、Gemini CLI、Codex CLI、Qwen-Coder 都是代表案例。Agent skills（智能體技能）近期成為擴充模型能力的外部程序性知識包，能編碼使用情境、核心指引與可重用的程式碼／文件資產，許多廠商已開始為其 agent 版本原生支援技能。

SkillsBench 初步證明技能能大幅協助模型解題，但也指出當前模型在自主生成技能上仍有限；SkillWeaver、SkillRL、MemSkill 等系統顯示經驗萃取的技能能提升下游表現，卻沒回答核心問題：自主智能體能否從自身解題過程萃取可重用技能、應用到未來同類任務、在失敗後修復它、並在一連串任務中維持演化中的技能庫？為回答此問題，本文提出 SkillFlow——涵蓋 20 個任務家族、166 個可執行任務的 benchmark。

建構過程中，作者先分析既有 agent 迴圈，發現成熟 agent（如 Claude Code 等）通常依賴穩定的 AI 工作流，讓它們能以一致方式解決同類任務。據此定義 DAEF：一個保留操作拓撲、抽掉領域專屬實體的工作流框架，作為 benchmark 建構的骨架，用以支持家族內的可控難度遞進。具體做法：從 GDPval 與 SkillsBench 挑選真實任務作種子，為每個種子抽取 DAEF，再透過雙代理迭代管線（一方構造任務資產、另一方複審並回饋）以原任務為參照具象化每個 DAEF，每個 DAEF 產出 8–9 個 Harbor 格式任務，合組成一個任務家族；人工驗證後，最終 benchmark 含 20 個任務家族、166 個任務。評測則遵循 Agentic Lifelong Learning 協定：智能體從無技能起步，依序解同家族任務，從軌跡與 rubric 回饋摘要教訓，並在每題後以顯式技能補丁更新技能庫。

實驗揭露顯著能力落差：在 Claude Opus 4.6 上，終身技能演化把任務成功率從 62.65% 提升到 71.08%（+8.43 點）；然而高使用率不代表高效益——Kimi K2.5 儘管技能使用率 66.87%，收益僅 +0.60 點；Qwen-Coder-Next 完成率僅 44.58%，相對 vanilla 仍倒退。作者發現多數當前模型無法透過迭代技能更新實現穩定的自我演化：較強模型傾向把先前經驗固化成穩定工作流並持續精煉，帶來持續的能力增益；較弱模型則難以把多次經驗整合成連貫程序，導致後續任務出現認知過載。

貢獻：(1) 提出 SkillFlow，涵蓋 166 個可執行任務、20 個任務家族，用於評測自主智能體的終身技能發現與演化；(2) 以 DAEF 為基礎設計共享智能體工作流框架的任務家族，支持跨任務技能遷移學習的系統性評測；(3) 定義 Agentic Lifelong Learning 協定——智能體從無技能起步，透過軌跡與 rubric 驅動的技能補丁演化外部技能庫，並在家族內固定任務順序下漸進學習、被評測；(4) 辨識並深入分析技能演化中常見的失敗模式，包括碎片化的技能成長、錯誤邏輯的強化、以及「寫技能」與「可靠修復技能」之間的落差，揭示當前模型在產出精簡、可遷移程序性技能上的局限。
