§4 實驗設定

§4.1 資料集

MAB FactConsolidation（選擇性遺忘能力下的衝突解決任務）。兩子任務（單跳/多跳）× 四上下文長度（6K/32K/64K/262K）。MAB 報告 6K 僅在推理模型驗證（表 5），非主系統比較；我們使用全部四長度。共 8 子任務列 × 100 題 = 800 測試實例/管線。FactConsolidation 由 MQUAKE 反事實改寫建構：原事實與反事實串接，反事實以較高序號出現；多對疊加達目標長度。

§4.2 骨幹模型

  • gpt-4o-mini（gpt-4o-mini-2024-07-18）：主要骨幹
  • gpt-4o（gpt-4o-2024-08-06）：僅 Ablation C
  • o4-mini：推理模型骨幹（多跳/單跳診斷 sweep，§5.6，非主表）

所有 MAB 基線使用 gpt-4o-mini 骨幹（per MAB §4.1），比較為 apples-to-apples。

§4.3 評測管線

標籤 描述 切片 新鮮度邏輯 骨幹
Headline SH-conflict §3.1 fact-level Python max(serial) gpt-4o-mini
LLM-judgment BM25+MAB prompt fact-level LLM 判斷 gpt-4o-mini
Ablation A SH-conflict chunk-4096 chunk-4096 Python max(serial) gpt-4o-mini
Ablation B CAR §3.2 fact-level Python max(serial)/hop gpt-4o-mini
Ablation C SH-conflict §3.1 fact-level Python max(serial) gpt-4o

LLM-judgment 基線使用 MAB 發表的 BM25 答案 prompt（T=0.7），Headline 使用結構化候選提取後確定性 max(serial)（T=0.0）。兩者使用相同事實級檢索與 TOP_K，但 prompt 格式/輸出格式/溫度/resolver 不同。

§4.4 超參數

TOP_K=10（匹配 MAB）。溫度：確定性管線 0.0、LLM-judgment 基線 0.7（匹配 MAB BM25 預設）。切片策略：fact-level（regex 解析每條事實獨立索引，500–18,000 chunks）；chunk-4096（滑動視窗，~6 chunks@6K、~250 chunks@262K）。BM25：rank_bm25.BM25Okapi（k1=1.5, b=0.75），tokenizer 為 [A-Za-z0-9]+ 小寫。

§4.5 指標

SubEM（子字串精確匹配），與 MAB 相同。預測答案 y* 與 ground truth 列表 Y，若 Y 中任元素作為子字串（大小寫不敏感）出現於 y* 即正確。對我們管線非問題（輸出為短實體），但膨脹長上下文 oracle 基線。

§4.6 計算與可重現性

總 LLM 評測：4400 次（44 格×100 題）。API 成本 ~$3（4 格 gpt-4o ~$2；gpt-4o-mini ~$0.3）。每格 ~5–10 分鐘，20 格主表平行 ~15 分鐘。完整程式碼/prompts/per-question 輸出/Langfuse 追蹤 metadata 於專案倉庫。Headline 實驗單指令：python scripts/13_paper_experiment.py --source factconsolidation_sh_<L>。

§4.7 基線

比較 MAB v3 表 3 的 22 個系統（不重新執行以避免實作差異）。系統跨越四家族：long-context FIFO、簡單 RAG（BM25）、嵌入 RAG（Contriever/Text-Embed-3/Qwen3-Embedding）、結構增強 RAG（RAPTOR/GraphRAG/MemoRAG/HippoRAG-v2/Mem0/Cognee/Zep）、agentic 記憶（Self-RAG/MemGPT/MIRIX）。

§5.3 匹配設定管線比較（gpt-4o-mini，fact-level）

LLM-judgment vs Headline：AVG +10.8pp，McNemar χ²=14.6, p<0.001。差距在長上下文擴大（6K +8pp→262K +21pp）。chunk-4096 匹配比較：確定性 80.8% vs LLM-judgment 61.0%（+19.8pp），大於 fact-level +10.8。

切片策略比較：fact-level vs chunk-4096 平均平手（78.0 vs 80.8，CIs 重疊），但曲線相反——chunk-4096 短上下文勝、fact-level 長上下文勝（262K 82 vs 73）。

§5.4 上下文長度穩健性

LLM-judgment 基線在 262K 急劇退化（61%，從 64K 75% 下降 14 點）。確定性管線不退化：gpt-4o-mini 71–82%、gpt-4o 92–99%。退化非因檢索——條件化在反事實可證明被檢索到的題目上，基線仍從 78%（64K）降至 66%（262K）。基線 14 點降幅中約 10 點是可檢索事實的誤判。

§5.5 檢索上界與方法互補性

LLM-judgment ∪ Headline 聯集準確率（n=400 pooled）：88.5%。即 88.5% 題目至少一管線可解——給出固定 TOP_K 管線的軟天花板 ~88–95%。方法互補：56.8% 兩者正確、21.3% Python-only、10.5% LLM-only、11.5% 皆錯。Headline +10.8pp 淨差距來自 +21pp Python 獨贏 -10.5pp LLM 獨贏。McNemar χ²=(85-42)²/(85+42)=14.6, p<0.001。

§5.6 FC-MH 結果與失敗模式分析

CAR FC-MH 27–34% 跨四長度。骨幹擴展：gpt-4o-mini 30.2%、o4-mini 43.2%、gpt-4o 51.5%。gpt-4o+CAR (51.5) > o4-mini+CAR (43.2)——剛性逐跳管線未利用 o4-mini 推理能力。交叉現象：6K CAR 傷害 o4-mini（52 vs plain 80——模型已端到端解決，分解僅增加 hop-1 失敗面），但 32K CAR 挽救它（42 vs plain 14 已崩潰）。平均每題 2.56 hops，86% hops 成功執行。

失敗模式定性（262K 約 30 題錯誤抽查）：主語混淆 ~25%、謂語語意間隙 ~25%、保守空提取 ~10%、反事實不在 TOP_K ~10%、真實先驗多數勝 ~10%、序號平手 ~5%、其他 ~15%。最常見 CAR 失敗模式：hop-1 幻覺（LLM 偶爾提取不匹配問題意圖的實體，鏈中斷）。

§5.7 跨基準泛化（LongMemEval 知識更新）

在 LongMemEval 知識更新題型（對話記憶，真實時間戳，n=45，gpt-4o-mini）：

管線 正確 準確率 95% CI
Baseline (BM25+LLM-freshness) 29/45 64.4% [49.8, 76.8]
Ours (extract+max(timestamp)) 26/45 57.8% [43.3, 71.0]
Δ -3 -6.6pp CIs 重疊，統計平手

確定性管線未擊敗 LLM 基線——但失敗非新鮮度錯誤：3 題 Yes/No（提取器回傳逐字事實而正確答案需 "Yes" 前綴）、1 題歷史/相對（「之前的狀態」→max(timestamp) 取當前而非前一狀態）、1 題聚合/過濾（需按事件時間過濾而非最新提及）。這強化論點：max() 是當前值衝突的正確算子，需與題型感知處理組合。
