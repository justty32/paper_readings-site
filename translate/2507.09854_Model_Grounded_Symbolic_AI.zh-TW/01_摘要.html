摘要

NeSy AI 結合神經網路與經典符號機制，兼取「大規模可泛化學習」與「穩健可驗證推理」之長。眾多 NeSy 分類顯示兩者可有多種整合方式。本文提出把指令微調的 LLM 重新詮釋為「模型接地（model-grounded）的符號 AI 系統」——自然語言充當符號層，接地透過模型內部表示空間達成。在此框架下，我們探討並發展「保留與傳統學習推理範式結構相似性」的新學習與推理方法。在不同複雜度的公理化演繹推理程序上的初步評估，提供了本法在學習效率與推理可靠性上的洞見。

關鍵詞：神經符號 AI、大型語言模型、符號接地。

1. 引言

NeSy 旨在結合神經網路的泛化學習與符號系統的顯式可驗證推理。LLM 在複雜推理上有限制（邏輯一致性、抽象、適應訓練分布外的新概念）→ 整合符號知識被視為提升 LLM 的有望途徑。NeSy 的核心挑戰在於統一符號接地的數學框架——橋接「接地於離散顯式知識表示的符號」與「接地於隱式連續抽象向量空間的符號」。後者本文稱 model grounding（模型接地）。

傳統符號接地問題（Harnad）＝把符號連到真實世界指涉（常經知識圖譜顯式表示）。有證據說 LLM 缺此能力（尤真實世界脈絡）；但近期亦有相反觀點：符號接地問題可能不適用於 LLM（接地於語用規範/抽象向量空間就足以得穩健解）；指令微調（如 RLHF）的 LLM 經向量空間接地賦予符號內在意義。

本文把指令微調 LLM 重新詮釋為符號系統——符號是「在模型內部表示中 model-grounded 的自然語言指令」，並提出新學習機制：

模型接地的符號學習視角：能否把 LLM 的任務學習概念化為「透過訓練資料集的迭代學習過程，其中符號化的自然語言互動刻畫每次訓練、影響模型行為」?

不把學習僅看成梯度下降的參數更新，而是精煉 LLM 的「任務功能狀態」——prompt + 批判的結構化記憶。這些迭代精煉來自反覆的訓練資料互動 + 一個識別 prompt 錯誤（梯度）的外部 judge。此機制下有傳統學習的直接類比：train-val-test 切分、跑資料的次數（epoch）、梯度累積（何時觸發 prompt 修訂）、模型儲存（存互動史、prompt 修訂、最終 prompt）、推理時載入（載同歷史、測試前暖機幾個樣本）。在不同複雜度的公理化演繹推理上測試。

主要貢獻：(1) 模型接地符號框架（把指令微調 LLM 當符號系統，自然語言為接地於模型內部表示的符號）;(2) 迭代 prompt 精煉（經迭代 prompt 修訂與批判驅動更新「學習」，橋接符號推理與梯度優化）;(3) 實證驗證（公理化演繹推理上改善推理可靠性、適應性、樣本效率）。

2. 模型接地的符號 AI 系統

2.1 自然語言作為原生符號系統

關鍵觀察：自然語言本就是符號表示。詞/句是受文法支配、有意義（人類約定與使用）的離散符號；不像像素/音波，文字是高層、人造的資訊編碼。LLM 的成功顯示語言中潛藏多少知識與推理模式。每個詞可視為符號、句子為符號結構。故 LLM 是有趣案例：處理符號輸入（text token）的神經網路，已部分活在符號域——非形式邏輯，而是語言這個非正式符號系統。故 LLM 某種意義上本身就是 model-grounded 符號 AI（用內部模型計算操作詞等符號）。LLM 經適當 prompt 可做類邏輯推斷的 CoT、模擬規則推理（把應用題翻成方程再解）、整合外部計算器/資料庫。但**自然符號（詞）vs 人造符號（形式邏輯謂詞/程式變數）**仍有別——LLM 很懂人語符號，但未必原生懂形式符號（除非經文字教）。Model-grounded 法須思考如何用 LLM 對語言符號的強項去納入更形式/精確的符號知識：可把形式知識用自然語言表達（用英文寫邏輯規則）讓 LLM 消化；或讓 LLM 經介面產生/批判形式符號（LLM 生 code/邏輯子句交符號引擎執行，即「LLM+Python」「LLM+logic」）。自然語言可當 model-grounded 系統中學習與推理組件的通用符號介面。

2.2 向量空間中的自然語言符號接地

經典符號 AI 中，符號靠指向符號系統外的東西（感測讀數/人給的解釋）接地；model-grounded 系統則把符號接地在模型學到的向量空間。LLM 處理「apple」時活化其內部向量空間的一部分（apple 的 embedding 與相關脈絡活化）——「apple」對模型的意義編碼在那些模式中（知道蘋果是水果、圓的、可吃，因這些關聯反映在向量相對位置：apple 近 banana、遠 office desk）。符號接地變成「把符號表示對齊到抽象向量空間的區域/方向」：符號「接地」⟺ 模型對該符號的使用與其學到空間中對應人類意圖意義的一致性質相關。例：規則「除企鵝外所有鳥會飛」——「bird」對應向量空間的一個子空間、「penguin」編碼為該子空間的離群（或屬性向量否定飛行）。不需顯式 boolean flag「can_fly」，而是「can fly」是 embedding 空間的一個方向、多數鳥對齊它而企鵝不對齊。AI 的世界模型（訓練塑造的內部表示空間）隱式含符號意義，符號陳述可依此空間解釋。這連到 prompt 式指令：用 LLM 自己的語言介面定義新符號或繫住意義（用自然語言給定義即成該詞的接地）。若接受向量空間接地，符號只是流形上可辨識的方向/區域，學習＝重塑向量空間使其尊重符號結構；不再要求離散符號表 + 直接物理指涉，只要需要時能從連續空間抽出類符號行為/事實即可（如 King−Man+Woman≈Queen）。符號視角即：在自然語言符號引導下操作這些向量以達期望智能行為；符號指令成為對連續表示的約束。

3. 模型接地符號 AI 的任務學習

3.1 示意例

文字冒險遊戲中的 LLM 代理：策略由 LLM 給，另維護「已發現事實的符號記憶」（自然語言描述的地圖/道具）與顯式目標/規則（「不可傷害無辜」）。代理行動時，外部 prompt 式 probe/judge（另一 LLM）對照規則與已知事實檢查其動作；若違規或與知識邏輯不一致，評估者介入——給自然語言回饋（「你記得傷害無辜違反守則」）或調整代理狀態（在 context 插提醒）。代理（LLM）因而收到改變後續處理的符號互動。不直接調權重，而是迭代程序：每次互動產生 trace，用以微調模型狀態（當前 prompt、互動史、prompt 修訂、judge 批判）。久之模型內化規則、不再需介入。把符號學習重構為「在含符號內容（規則/知識查詢的自然語言描述）的任務世界經驗資料集上訓練」，學習演算法的任務是使模型行為對齊任務目標。

3.2 任務學習演算法

提出鏡像梯度優化、但用自然語言符號回饋與介入更新模型的迭代範式。四步：① 模型初始化（預訓練 LLM）;② 外部 judge 評估（測錯誤/不一致）;③ 生成符號修正（自然語言：精煉 prompt / 補範例 / 邏輯解釋）;④ 迭代精煉（context 更新）。重複至收斂（Algorithm 3.2）。

  • Judge.evaluate＝符號評估器（如更先進/專門 LLM 比對輸出與期望/約束，輸出分數或文字批判）。
  • generate_corrections＝符號介入：judge 給自然語言回饋（「推理有誤因假設 X 與已知事實 Y 矛盾」），演算法轉成修正後的推理 trace 或在 context 提醒 Y 的 prompt → 訓練中依模型錯誤修訂 prompt。
  • 更新機制在有效模型行為（給更好 prompt 或加先前修正的記憶）——如累積指令的持久 prompt（prompt tuning / 閉迴路）。可詮釋為監督訓練迴圈，judge 當 oracle 提供目標/損失。
