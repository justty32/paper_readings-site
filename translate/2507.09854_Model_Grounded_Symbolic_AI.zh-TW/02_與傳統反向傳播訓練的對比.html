4. 與傳統反向傳播訓練的對比

  • 可微性：backprop 需端到端可微；本法用不可微回饋（judge 可為不可微黑箱程序，當外部 oracle，經範例式 prompt 調整更新模型狀態）→ 大優勢：納入任意符號規則不需把符號邏輯做成可微。
  • 資料效率與課程：傳統用固定資料集，模型犯錯除非資料分布涵蓋否則持續犯；本法迭代迴圈本質是 curriculum/active learning——模型錯誤即時驅動修正、聚焦最相關處 → 更省資料（少量聚焦範例可糾正否則需大量隱式範例才修的行為；self-correction 顯示單一好範例/指令可大幅扭轉某些任務）。
  • 局限與收斂：無梯度下降的收斂保證或良定義優化目標（較啟發式）；最終品質取決於 judge 與修正品質（judge 不完美如有錯/偏差會帶歪、植入錯規則）；傳統訓練有清楚損失與資料較易分析；prompt 修正若沒「黏」進長期記憶可能震盪/不收斂。

5. 實驗與討論

在 MATH-500（100 題，難度 level 1–5）評估 metatuning 對 LLM 的影響。先評零樣本表現（無微調直接生成），生成回應 + ground-truth 交 LLM judge 評估。train-test 切分：對訓練集中 LLM 初答錯的題，構造注入正解與解法的對話歷史，測試時提供此豐富 context；比較零樣本 vs metatuning 後準確。

  • 小模型（LLaMA 3.2 1B via Ollama）基線太低不適用；judge 必須用 SOTA（評估失真則整個 metatuning 不可靠）。本研究只用 SOTA 非推理模型；candidate＝GPT-4o / Gemini-1.5-Flash（明確 prompt 要求給推理過程 + 最終解）、judge＝Gemini-2.0-Flash。

5.1 基準結果

Train Context Size x＝x 題做 metatuning、其餘 100−x 題測試。

  • GPT-4o（Table 1）：context 5 +2.11%、context 10 +5.56%、context 20 0%、context 30 −2.86%、context 40 0%。
  • Gemini 1.5 Flash（Table 2）：context 5 −1.05%、+6.67% / +6.25% / …+5.00%（多數 context 一致提升）。

5.2 分析

metatuning 多數情況提升兩模型準確。GPT-4o 小 context 顯著受益（context 10 +5.56%）但大 context 無提升；Gemini 1.5 Flash 跨 context 一致改善（唯 context 5 略降 −1.05%，最大提升 context 10 +6.67%）。顯示 metatuning 有益，但依 context 大小與模型架構可能遞減報酬甚至輕微倒退。
