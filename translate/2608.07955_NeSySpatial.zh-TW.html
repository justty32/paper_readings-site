論文／訪談原始來源

NeSy-Spatial：用於工具增強空間推理的自我演化神經符號技能

摘要與背景

視覺語言模型處理細緻空間題時，常同時需要感知、幾何運算和中間驗證。現有方法不是每題臨時規劃工具，可能先跑 Python 卻尚未取得物件座標；就是手刻完整管線，連簡單題也冗餘。本文主張把經驗累積成可執行、可組合的技能。

3. 表示與推論

原子指令具名稱、型別簽章、輸入輸出、依賴、執行器及 verifier；高階 skill 是由原子構成的有向依賴結構。Tool-Use Skills 組織偵測、深度、重建等工具的正確順序；Geometry Skills 將工具輸出化成座標、距離、轉換與一致性檢查。每個 episode 從 library 取回相符技能、填參數、執行並讀中間結果，因此既非固定 pipeline，也不必每次白紙規劃。

演化

系統緩衝成功與失敗軌跡，抽取每一步的操作、參數、產物、變數及局部結果。分析器跨軌跡聚合 recurring dependency，輸出原子更新和受支持／失效的 skill fragment；fusion 將它們與既有 library 對照後做新增、替換、刪除依賴或子圖替換。pruner 對已充分使用的項目以錯誤率判斷，亦刪除過久未用者；較資深項得到有限保留，避免少量雜訊立即刪除。刪除後要修復或棄置依賴該原子的 skill。

4. 實驗與結論

在 MMSI、MindCube、OmniSpatial，作者比較動態工具 agent、固定技能 LAST、AWM、ASI 等，兩個 API backbone 共六組。作者稱 NeSy-Spatial 五組 Overall accuracy 最高：GPT-5.4 的 MMSI 49.50、MindCube 71.50，OmniSpatial 60.27 略低於 61.00；Gemini 2.5 Pro 三題均最高。工具鏈的 first-pass 成功與 Python 成功率也提升。此結果支持「把依賴與可驗證幾何外顯」的方向，但沒有證明抽到的 skills 對新工具或新分布必然正確。
