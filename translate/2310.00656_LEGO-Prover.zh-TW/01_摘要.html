摘要

儘管大型語言模型（LLM）已取得顯著成功，定理證明仍是最困難的推理任務之一，遠未被完全解決。先前以語言模型為基礎的方法雖有進展，卻仍難以證明中學程度的定理。這些方法的一個共同限制是假設定理庫在整個證明過程中固定不變。然而，創造新的有用定理乃至新理論，不僅有幫助，對推進數學發展與證明更難更深層的結果更是必要且關鍵。本文提出 LEGO-Prover，採用一個包含已驗證引理作為「技能」的成長型技能庫，以增強 LLM 的定理證明能力。藉由模組化構建證明，LEGO-Prover 讓 LLM 既能從技能庫檢索既有技能，也能在證明過程中創造新技能。這些技能進一步透過 LLM 提示詞進行演化，從另一尺度豐富技能庫。模組化且可重用的技能不斷被加入庫中，使系統得以應對日益複雜的數學問題。此外，所學的技能庫透過讓填補缺失的證明步更為容易，進一步橋接了人類非正式證明與形式證明之間的差距。LEGO-Prover 將 miniF2F-valid 的 pass rate 從 48.0% 提升至 57.0%，miniF2F-test 從 45.5% 提升至 50.0%。在證明過程中，LEGO-Prover 生成了超過 20,000 個技能（定理／引理）並加入技能庫。消融實驗顯示這些新加入的技能確實有助於定理證明，將成功率從 47.1% 提升至 50.4%。

1. 導論

形式推理任務的自動化——如定理證明和數學證明形式化——是人工智慧領域中極具挑戰性且活躍的研究方向。形式化數學證明的程序通常依賴人類專家將複雜的數學概念轉寫成結構化的形式語言，再由交互式定理證明器（如 Lean 或 Isabelle）進行驗證。此程序雖穩健，卻高度勞力密集且要求極高的事業知識。

近年來，LLM 成為一個有前景的途徑。神經定理證明中主要有兩種典範被廣泛探索。其一是逐步證明生成，由微調模型提供單步證明動作，搭配搜尋演算法尋找完整證明（GPT-f、PACT、HTPS、Thor 等）。其二是利用 LLM 的程式碼能力，在單次解碼中構建整個證明（Draft-Sketch-Prove、Subgoal-Learning 等）。這些方法統稱為純證明器（plain prover），共同策略是循序合成證明、每一步依賴前一步，並將所有證明碼堆入一個大證明區塊。

然而純證明器有若干短板。一方面，它們嘗試用靜態 LLM 獨立證明定理，但不同問題之間常可互為洞察——不同問題可能共享相同的引理，純證明器卻無法重複利用已證明的引理。另一方面，即使有 ChatGPT 或 GPT-4 的輔助能生成短鏈證明，面對長鏈證明時仍因推理難度而頻繁失敗。

為克服這些短板，並受樂高積木模組化的啟發，我們提出 LEGO-Prover：一種以積木方式證明定理、由成長型技能庫支撐的新方法。系統包含證明器與演化器兩個核心組件，由成長型技能庫橋接。證明器以問題的形式陳述為輸入，檢索相關技能來提示 LLM 生成模組化證明，生成的引理累積入庫。然而證明器創造的引理常為問題特定，可重用性低，因此引入演化器，將庫中技能轉化為更具一般性、可重用性與複雜度的形式，經驗證後再回注入庫。
