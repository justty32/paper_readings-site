3. 實驗

3.1 設定

使用 OpenAI 的 gpt-4-0314、gpt-3.5-turbo-0301 做文字補全，text-embedding-ada-002 做文字 embedding。除自動課程用溫度 0.1 以鼓勵任務多樣外，其餘溫度皆設 0。模擬環境建於 MineDojo 之上、以 Mineflayer 的 JavaScript API 做馬達控制。

3.2 基線

因無現成適用 Minecraft 的 LLM 智能體，選代表性演算法並改寫使其能在 MineDojo 執行：

  • ReAct：以 CoT 生成推理軌跡與行動計畫，餵入環境回饋與智能體狀態作觀察。
  • Reflexion：建於 ReAct 之上加自我反思，餵入執行錯誤與我們的自我驗證模組。
  • AutoGPT：把高階目標分解為多個子目標、以 ReAct 式迴圈執行；以 GPT-4 做任務分解，餵入狀態、環境回饋、執行錯誤。相比 VOYAGER，AutoGPT 缺技能庫（累積知識）、缺自我驗證（評估成功）、缺自動課程（開放式探索）。

不直接與「吃像素、出底層控制」的方法比較，因非同類比較——本工作聚焦把 GPT-4 推向終身具身學習的極限，而非解 3D 感知或感測運動控制；VOYAGER 與 VPT 等梯度式方法正交、只要控制器提供程式 API 即可結合。

3.3 評估結果

  • 探索顯著更佳（圖 1）：160 次提示迭代內發現 63 個獨特物品，為對照的 3.3×；AutoGPT 遠遠落後，ReAct/Reflexion 幾無進展（缺合適課程時開放式探索目標太抽象、難執行）。
  • 一致的科技樹掌握（表 1）：科技樹（木器→石器→鐵器→鑽石）測試分層工具的製作與使用。相比基線，VOYAGER 解鎖木器級快 15.3×、石器級快 8.5×、鐵器級快 6.4×，且是唯一能解鎖鑽石級者（3 次中成功 1 次、平均 102 次迭代）。凸顯自動課程能持續給出合適複雜度的挑戰。
  • 廣泛地圖橫越（圖 7）：橫越 2.3× 更長距離、穿越多樣地形，基線常困在局部區域，嚴重妨礙其發現新知識。
  • 高效零樣本泛化（表 2、圖 8）：清空庫存、重置到新實例化世界、以未見任務測試。對 VOYAGER 與 AutoGPT 都用 GPT-4 把任務拆為子目標。VOYAGER 在 50 次迭代內一致解出全部任務（鑽石鎬、金劍、熔岩桶、指南針），基線一題都解不出。值得注意：由終身學習構建的技能庫不僅提升 VOYAGER，接給 AutoGPT 也帶來增益——顯示技能庫是可被其他方法直接採用的即插即用（plug-and-play）資產。

3.4 消融研究

消融 6 個設計（自動課程、技能庫、環境回饋、執行錯誤、自我驗證、以 GPT-4 生成程式碼），關鍵發現：

  • 自動課程至關重要：換成隨機課程，發現物品數暴跌 93%（某些任務若不按序嘗試會太難）；人工設計的課程需大量 Minecraft 專門知識、又不顧智能體實時處境，實驗結果不如自動課程。
  • 技能庫：無技能庫的 VOYAGER 在後期傾向停滯（plateau）——技能庫讓新技能建於舊技能之上、穩步推進能力邊界。
  • 自我驗證是所有回饋類型中最重要者：移除它使發現物品數大跌 −73%；它是決定「何時換新任務或重試舊任務」的關鍵機制。
  • GPT-4 遠勝 GPT-3.5：以 GPT-4 生成程式碼多得 5.7× 獨特物品，因 GPT-4 在編碼能力上有質的飛躍。

3.5 來自人類的多模態回饋

當時 GPT-4 API 僅文字，故 VOYAGER 尚不支援視覺感知，但有潛力以多模態感知模型增強。實證：在人類回饋下，VOYAGER 能蓋出複雜 3D 結構（如地獄門、房屋）。整合人類回饋有兩途：(1) 人類作為 critic（等同自我驗證模組）：提供視覺批評讓 VOYAGER 修改上一輪程式，修正它無法直接感知的空間細節；(2) 人類作為課程（等同自動課程模組）：把複雜建造任務拆成小步、引導 VOYAGER 漸進完成。

4. 局限與未來工作

  • 成本：GPT-4 API 比 GPT-3.5 貴 15×；但 VOYAGER 需要 GPT-4 在程式碼生成品質上的質變，GPT-3.5 與開源 LLM 無法提供。
  • 不準確：即使有迭代提示，仍有卡關造不出正確技能的情形（自動課程可日後重試該任務）；自我驗證偶爾失誤，如未把「蜘蛛絲」認作打敗蜘蛛的成功訊號。
  • 幻覺：自動課程偶爾提出遊戲中不存在的任務（如造「銅劍」「銅胸甲」）；程式生成也會幻覺（如把圓石當燃料——實為無效燃料，或呼叫控制原語 API 中不存在的函式而致執行錯誤）。作者相信未來 GPT API 改進與開源 LLM 微調新技術能克服這些限制。

5. 相關工作（摘要）

  • Minecraft 決策智能體：分底層控制器（多用階層式 RL 從人類示範學習；MineDojo/VPT 用 YouTube 影片大規模預訓練；DreamerV3 學世界模型採鑽石）與高階規劃器（用 LLM 把高階任務按 Minecraft 配方拆為子目標，但缺完整探索彈性）。VOYAGER 也以 LLM 為高階規劃器、以 Mineflayer 為底層控制器，但採自下而上、好奇心驅動的自動課程，實現開放式探索。
  • LLM 用於智能體規劃：分機器人學習（Code as Policies、ProgPrompt 直接用 LLM 生成可執行機器人策略；Inner Monologue 納入環境回饋）與文字智能體（ReAct、Reflexion、AutoGPT、DERA、Generative Agents、SPRING）。這些工作皆缺技能庫來發展更複雜行為——而技能庫是 VOYAGER 終身學習成功的關鍵。
  • 含執行的程式碼生成：執行導引式合成、多數投票、LEVER 訓練驗證器、CLAIRIFY 規則式驗證器等。VOYAGER 的不同在於把環境回饋、執行錯誤與自我驗證整合進迭代提示機制做具身控制。

6. 結論

VOYAGER 是第一個 LLM 驅動的具身終身學習智能體，用 GPT-4 持續探索世界、發展愈趨精巧的技能、無人類介入地一致做出新發現；在發現新物品、解鎖科技樹、橫越多樣地形、把學到的技能庫應用於新世界的未見任務上都表現卓越。它是「不調模型參數就打造強大通用智能體」的一個起點。

（廣泛影響：研究在 Minecraft 這個安全無害的 3D 遊戲環境中進行；若應用於實體機器人，需額外注意並由人類施加安全約束。）
