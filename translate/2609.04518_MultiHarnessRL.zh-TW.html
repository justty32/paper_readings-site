論文／訪談原始來源

What Does Multi-Harness RL Learn? Credit Assignment and Portability in Coding Agents

摘要與問題

多 harness 強化學習其實混合了兩件不同的事：讓同一策略接觸多種執行介面，以及把不同介面的報酬放進同一個相對優勢群組比較。既有系統往往連同資料、訓練規模與評估方式一起更動，因此無法判斷收益來自多樣經驗，還是來自跨 harness 的 credit assignment。

作者把這兩項干預拆開。在 repository-level coding 任務中，所有訓練分支共用同一批凍結軌跡、報酬、token、loss mask、更新預算與初始 SFT checkpoint，只改變 GRPO 的分組邊界。研究問題不是「多 harness 訓練有沒有用」，而是更窄的一問：當 exposure 固定時，跨 harness 比較報酬是否會學到可攜能力，而非只適應產生資料的配置。

方法：固定經驗，只改 credit 邊界

Within 以 task–harness pair 為群組，優勢值在各 harness 內分別標準化；Cross 則把同一任務在不同 harness 下的軌跡合併，再共同標準化。兩者重播完全相同的經驗，因此差異只在「哪些軌跡彼此競爭 credit」。作者另設 coverage-matched、residualized 與半程重新 on-policy 收集資料的分支，檢查結果是否只是凍結資料或 harness 成功率偏移造成。

評估採單一 sealed oracle，在訓練所見的 Aider、OpenHands、Qwen Code、SWE-agent 上量來源配置收益，另用訓練未見的 minimal harness 量 portability。這個切分很關鍵：來源 harness 上的提升同時含有模型能力與配置適應；只有換到未見介面仍保留的提升，才是此設計下的可攜成分。

作者也直接檢查 credit signal。分類器只看 advantage，嘗試辨識軌跡來自哪個 harness；若 Cross 把介面本身的成功率混進 credit，分類器應能恢復 harness 身分。最後，研究比較同一 checkpoint 在不同 harness 下，以及不同 checkpoint 在同一 harness 下的 action distribution，判斷行為主要由介面還是訓練規則決定。

主要實驗結果（作者自報）

作者自報，評估 harness 對平均 solve rate 的影響達 4.3 倍，而不同訓練 recipe 的影響只有 1.16 倍。也就是說，跑模型的介面比訓練它的這項 recipe 選擇更能左右分數。

在未見 harness 上，Cross 與 Within 沒有可檢出的差異；提高嘗試次數、合併多個訓練 seed，或將後半訓練資料改為 on-policy 重收，都沒有改變這個結論。兩種規則在來源 harness 上的最大增益也落在同一介面，較符合 configuration adaptation，而不是跨介面能力內化。

作者自報，credit signal 的診斷顯示，Cross 的 advantage 可讓分類器比 shuffled-label baseline 高 4.48 個百分點，Within 幾乎不攜帶這項資訊。這證明跨 harness pooling 的確把 harness 身分寫進 credit；但污染沒有轉化成可觀察的 held-out 得分差異，兩種規則在各 harness 內的 action distribution 也近乎相同。行為工具譜主要由執行 harness 決定，不由 credit 分組規則決定。

討論與結論

這篇論文把「看過多種 harness」與「讓多種 harness 的結果彼此競爭」分成兩個因果問題。實驗支持前者可帶來來源配置上的收益，卻沒有證據顯示後者額外產生可攜能力。Cross 改變了梯度由哪些軌跡承擔，也把介面身分帶進 advantage；但換介面後，分數與行為都沒有因此改善。

作者因此建議，多 harness RL 報告至少交代經驗由哪些 harness 產生、advantage normalization 是否跨越 harness 邊界、各來源 harness 的增益，以及至少一個未見 harness 上的差異。只報原介面的分數，無法區分模型學會了能力，還是學會配合那套 scaffold。

局限

作者明列的限制包括：除主要 held-out level 外，多數估計只來自單一 checkpoint；來源 harness 的每題嘗試預算有限，絕對 solve rate 偏低，終點又是二元結果；訓練只涵蓋單一模型家族、單一預算、單輪 on-policy 重收與 Python 任務。第二模型家族只做未訓練 checkpoint 的 harness 比較，不能代替完整的跨模型訓練重現。研究能解析的是約一個百分點以上的差異，更細小的效果仍可能存在；預先固定的 held-out contrasts 也未做外部註冊。
