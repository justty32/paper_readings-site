論文／訪談原始來源

Learning Hierarchical Skill Policies with Offline Quality-Diversity Reinforcement Learning

問題

Offline-to-online RL 常用兩階段策略：先從離線資料集抽取多樣 skill 當 low-level policy（通常靠 trajectory VAE，如 OPAL、SPiRL），再訓練 high-level policy 解特定任務。SUPE 進一步把離線資料重用於 online replay buffer（pseudo-labeling 推論 skill 並給 optimistic reward），能明顯加速探索。但這類方法有個共同弱點：標準 trajectory VAE 對資料集裡所有片段一視同仁地做重建，若資料混雜好動作、失敗嘗試與雜訊，模型會把容量浪費在重建雜訊上，得到一個「雜亂」的 skill space——不同 latent code 對應到難以區分或無用的行為，讓 high-level policy 收到不一致的訊號。純多樣性驅動的方法（最大化互資訊）能區分不同行為但無法區分「不同的有用行為」與「不同的無用行為」；純獎勵驅動或行為克隆方法則容易崩塌成單一模式，缺乏下游探索所需的多樣性。作者提出 QDOS（Quality-Diversity Offline Skill learning），用 advantage 加權同時解決「過濾雜訊」與「保留多樣高品質 skill」。

方法

問題形式化：標準 MDP，只有一個靜態離線資料集 D = {τ_i}，軌跡含 reward 但沒有 skill 分段或標籤，好壞動作混在一起。目標分兩層：(1) skill discovery——學一個 latent-conditioned low-level policy π_θ(a|s,z) 與 prior p(z)，捕捉多樣、有用的行為同時過濾雜訊；(2) hierarchical adaptation——學 high-level policy π_ψ(z|s) 在 online 互動時選 skill 最大化期望回報。SUPE 的侷限在於它隱含假設抽出的 skill 都是有意義的，標準 VAE 對所有片段一視同仁地重建，雜訊資料集會讓 VAE 也重建雜訊，得到雜亂的 skill 庫，進而導致不可靠的 pseudo-labeling。

Advantage 估計（IQL）：把離線軌跡切成固定長度 H=20 的片段 τ_[H]，用 Implicit Q-Learning 訓練 value function V_ψ(s)（expectile regression，τ∈(0.5,1) 逼近回報分布上 expectile，不查詢分布外動作），估計每個片段起始狀態的 advantage A(τ_[H])。權重 w ∝ exp(A/λ)，λ 是溫度參數；高 advantage 片段權重顯著更高。

Advantage-weighted VAE 目標：encoder f_θ(z|τ_[H]) 把片段映射到 latent z，decoder（即 low-level policy）π_θ(a|s,z) 重建動作，另學一個 state-dependent prior p_θ(z|s_0)。目標函數 = β·KL(posterior‖prior) − 期望的「加權對數概似」，其中對數概似項乘上片段權重 w(τ_[H])，讓模型優先重建高價值行為。

互資訊最大化（多樣性項）：為防止 mode collapse、確保 skill 間有區分度，用變分下界近似互資訊 I(z;τ)。具體做法：從 prior 均勻抽 z_rand，用當前 π_θ 生成短的輔助 rollout，再編碼回 latent 比對重建誤差（最小化 MSE：||ẑ_rand − z_rand||²）。關鍵設計：這個多樣性損失同樣乘上該軌跡的 advantage 權重 w，確保「鼓勵多樣性」只發生在高品質行為之間，而不是鼓勵多樣的失敗模式。總預訓練目標 = advantage-weighted VAE 損失 + α_loss × 互資訊損失。

Online 探索：預訓練完成後凍結 low-level policy π_θ，訓練 high-level policy π_ψ(z|s)，每 H 步選一次新 skill。沿用 SUPE 的雙重資料重用策略：對每個離線片段，用預訓練 encoder 推論 skill 標籤 ẑ，並用 RND 給學到的 reward model 加探索獎金算出 optimistic reward r̂，把 (s_0, ẑ, r̂, s_H) 加入 online replay buffer，讓 high-level agent 從一開始就能對離線資料做 off-policy 學習，高品質 skill 加樂觀探索獎金一起把 agent 導向有希望的狀態空間區域。

實作細節：PyTorch，VAE 訓練用 Adam，學習率 3e-4；H=20；IQL expectile τ=0.9；溫度 λ 依環境調（約 [0.3,1.0]）；互資訊權重 α_loss ∈ {0.1,0.2,0.3}。Online 高階策略用 SAC，replay buffer 先用 pseudo-labeled 離線資料初始化，訓練時維持離線/線上各半取樣比例，全部實驗跑 5 個隨機種子平均。

實驗與結果（皆為作者自報數字）

四個稀疏獎勵、長視界任務：antmaze-large（四足蟻導航大迷宮）、kitchen-mixed/partial（機械臂依序操作微波爐、水壺、開關等多個物體）、humanoidmaze-medium（人形機器人導航，比 antmaze 難得多）、antsoccer-arena（蟻需推足球到目標，兼具運動與操控）。基準包括 SUPE（主要對照，沒有 advantage 加權的 trajectory skill）、ExPLORe（探索獎金但非階層式）、標準 trajectory skill（無 advantage 加權或多樣性最大化）、IQL、以及 Diffusion BC + Jump-Start RL。

主結果（Table I，SUPE 與 QDOS 皆 3 seed 平均）：QDOS（α=0.3）在 antmaze-large 達 96.0±6.0（SUPE 83.0±21.0，IQL 64±10，BC 41±7）；antsoccer-arena 達 80.0±10.0（SUPE 僅 27.0±31.0）——作者特別強調這是差距最大的任務，推論精細操控球的成功時刻正是 advantage-weighting 聚焦所在；humanoidmaze-medium 達 100.0±0.0（SUPE 97.0±6.0）；kitchen-mixed 上 α=0.2 版本拿滿分 100.00±0.00（SUPE 85±13.25，作者稱這代表能把片段化子任務正確拼接起來）；kitchen-partial 與 scene-task1 上 QDOS 與 SUPE 同屬最佳統計組。

目標發現效率（Table II，到達目標所需環境步數）：QDOS 一致比 SUPE 更快找到目標——scene 任務以最短可能步數 5001±0 達標（SUPE 5834±1443）；humanoidmaze 減少約 4000 步（19168±8036 vs. 23334±6292）；antmaze-large 也更少（11668±9465 vs. 13334±5774，但兩者標準差都很大）。作者歸因於「更乾淨的 skill space」讓 high-level policy 不用把時間浪費在雜訊或無效 skill 上。

超參數敏感度：動態複雜任務（antsoccer）偏好較高多樣性權重 α_loss=0.3（解空間大，鼓勵多樣互動增加找到成功策略的機率）；結構化操控任務（kitchen）偏好中等權重 0.2（最優行為較受限，過度多樣反而學到無關變異干擾策略）。

失敗案例（作者主動報告的限制）：在僅需 pick-and-place 的高品質資料集 cube-single/double 上，降低互資訊權重 α_loss 反而讓效能趨近 SUPE 水準，說明對高品質、結構化的示範資料而言，用互資訊強制多樣性的必要性降低。

Latent space 視覺化：t-SNE 顯示 QDOS 的 latent 分布比 SUPE 更廣、更分散，暗示更充分利用 latent space 表達多樣 skill；行為視覺化顯示 kitchen 中特定 latent code 穩定對應「開微波爐」等語意明確的互動，antmaze 中連續內插 latent z 能得到平滑的行為過渡。

結論與局限

QDOS 把 advantage 加權整合進 skill 預訓練目標，同時抑制對雜訊/失敗片段的重建與多樣性鼓勵，蒸餾出穩健、與任務對齊的 skill，克服標準無監督 skill discovery 在混合品質資料下的弱點；結合雙重資料重用策略後，在 antsoccer、kitchen、humanoidmaze 等困難領域上，漸進回報、樣本效率與探索速度都優於 SUPE 等強基線。作者也指出局限：目前互資訊權重 α_loss 需依任務手動調整（cube 資料集上的失敗案例即為一例），未來方向包括自動調節 quality-diversity trade-off，以及讓 low-level skill 在 online 互動期間也能微調以適應新情境。
