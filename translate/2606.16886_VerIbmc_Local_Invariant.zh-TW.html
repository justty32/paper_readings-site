論文／訪談原始來源

神經符號軟體驗證：VerIbmc

引言

本文處理迴圈不變量合成——形式軟體驗證的關鍵瓶頸。近期 LLM 工具雖有前景，卻依賴專有雲端 API，帶來隱私、可復現與成本顧慮。作者提出 VerIbmc：把符號推理與本地可部署開源權重模型（7B–120B）及 ESBMC 驗證器配對，實現「隱私保護、能源高效」的驗證，無需外部服務。

VerIbmc 管線架構

遵循「只在必要時升級」原則，三階段：

  • Phase 0：ESBMC 驗未標註程式，若 trivially safe/unsafe 則退出。
  • Phase 1：符號列舉透過變數兩兩比較產生候選不變量原子，無 LLM 呼叫。
  • Phase 2：由結構化 ESBMC 回饋驅動的迭代 LLM 精修。

系統維護三庫，追蹤可證（𝒫）、可否證（𝒟）、未知（𝒰）原子，作為後續 prompt 的先驗知識。

符號不變量合成（Phase 1）

確定性列舉形如 vi⋈vj 或 vi⋈c（⋈∈{<,≤,=,≠,≥,>}）的原子候選。對 |V| 活變數、|C| 常數的迴圈，最多產 6(|V|²+|V|·|C|) 個候選。ESBMC 分類每個原子的歸納性。光是符號合取就解 75 題（有效 499 題的 15%）零 LLM 呼叫。

LLM 精修迴圈（Phase 2）

Phase 0 回 unknown 時，Phase 2 反覆：

  1. 以迴圈原始碼、當前原子庫、few-shot 範例提示 LLM。
  2. 用 ESBMC 驗提議的不變量。
  3. 把失敗候選拆成子公式、濾出歸納原子進 𝒫。
  4. 測合取 ⋀𝒫 是否整程式驗過。

解析錯誤觸發續跑不罰。每題迴圈最多跑 N 輪。

Prompt 策略

CoT vs ToT 設計軸：

  • 驗證器回饋：Basic 策略用 Phase 1 符號先驗；LLM-Only 跳過 Phase 1。
  • 推理結構：CoT 用單一範例集；ToT 探四種推導風格。

四種範例風格：歸納（含/不含解釋——逐步證明或精簡格式）、Hoare 邏輯推導（顯式 {I∧B}S{I} 三元組）、Horn 子句推導（約束 Horn 子句編碼）。

ToT 兩階段：Stage 1 用 score(s)=(0.6|𝒫ₛ|−0.3|𝒟ₛ|+0.1|𝒰ₛ|)/|𝒫ₛ∪𝒟ₛ∪𝒰ₛ| 為四風格評分，Stage 2 精修 top-2 至 R=10 輪、每 6 輪重排。

實驗評估

5 模型：GPT-OSS-120B、GPT-OSS-20B、Qwen2.5-32B-Instruct、Qwen2.5-7B-Instruct、Llama-3.1-8B。

基準（520 題；去 21 不可避溢位後 499 有效）：C2I 133（Code2Inv）、L4I-SVC 99（LaM4Inv-SVCOMP24）、L4I-SY 84（LaM4Inv-SyGuS19）、SVC 154（SV-COMP 全集未過濾）、NL 50（非線性 Clause2Inv）。

硬體：4× NVIDIA RTX A6000（48GB）、ESBMC v8.2、每題 600s timeout。

關鍵結果

RQ1 有效性：最佳單組態 GPT-OSS-120B（Basic）431/499（86.4%）。各模型（Basic）：120B 431、20B 424、Qwen-32B 382、Llama-8B 342、Qwen-7B 352。Basic 全面勝 LLM-Only，弱模型優勢最大（Llama 307→342，+35）。

RQ2 對比 SOTA：完勝 Class I 傳統符號（CPA-Checker 282、2ls 194、ESBMC-Kind 145）與 Class II 神經（Code2Inv 210）。四共享套件（C2I/L4I-SVC/L4I-SY/NL）：VerIbmc 346–348（四單 LLM 策略聯集）、LaM4Inv（GPT-4o-mini）338、Clause2Inv（GPT-4o）356、LORIS（GPT-4.1）351。可比 SV-COMP 子集（43 程式）：LORIS 39/43、VerIbmc（本地）36/43、Clause2Inv/LaM4Inv 各 30/43。

RQ3 ToT 影響：ToT 達 49 個 CoT 未解的 （模型，題） 對，但聚合多為負：

模型 CoT(Basic) ToT(Basic) Δ
GPT-OSS-120B 431 421 −10
GPT-OSS-20B 424 411 −13
Llama-3.1-8B 342 285 −57
Qwen2.5-32B 382 349 −33
Qwen2.5-7B 352 341 −11

ToT 開銷至多 1.40× wall-clock。

RQ4 各階段貢獻：Phase 0 114（22.8%）、Phase 1 符號 75（15.0%）、Phase 2 需 LLM 248（49.7%）、永遠未解 62（12.4%）。Phase 1 對弱模型確定性增益：Llama +36 淨題、Qwen-7B +22；GPT-OSS-120B +0（自己就能導同樣原子）。

收斂分析

強烈前載：65.1% 的 LLM 解在第 1 輪、85.1% 在 5 輪內、88% 在 10 輪內；最多觀測 171 輪。

獨特解與穩健性

20 組 （模型，策略） 的 Jaccard 中位數 0.73（可解前緣「高度一致」）；模型身份對變異的貢獻是策略選擇的 3–7×。

相關工作與定位

對比 ESBMC、CPAchecker、2ls（Class I 符號）；Code2Inv（Class II 神經）；Clause2Inv、LaM4Inv、LORIS（Class III LLM 增強）。VerIbmc 獨特處：擴展到完整 C 語法、同時保持本地且無專有模型。

局限與效度威脅

  • 實數算術語意：在 ℤ 上推理而非 C 定寬整數（排除 21 不可避溢位題）。
  • 非確定性：用 best-of-three / pass@k 協定。
  • 基準代表性：限迴圈密集程式；架構雖語言無關但無其他語言實證。
  • 前端限制：與 Clause2Inv/LaM4Inv 比較受其單迴圈純量整數解析限制。

結論

VerIbmc 證明「本地部署的開源權重模型在與形式驗證器整合時，能有效支援迴圈不變量生成」。神經符號法在 499 基準上達 86.4%（單組態）到 87.6%（聯集），無雲端 API、能源高效、與昂貴 frontier 模型系統有競爭力甚至超越。75 個 Phase 1 符號解建立了一條獨立於 LLM 品質的確定性、隱私保護基線。
