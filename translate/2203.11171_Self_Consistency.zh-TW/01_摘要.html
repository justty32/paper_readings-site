摘要

思維鏈提示（chain-of-thought prompting）結合預訓練大型語言模型，已在複雜推理任務上取得令人鼓舞的結果。本文提出一種新的解碼策略——自我一致性（self-consistency）——取代思維鏈提示中天真的貪婪解碼。它先取樣出一組多樣的推理路徑，而非只取貪婪的那一條，再藉由把取樣到的推理路徑邊際化（marginalize out），選出最一致的答案。自我一致性利用的直覺是：複雜推理問題通常允許多種不同的思考方式，而它們都通往同一個唯一的正確答案。廣泛的實證評估顯示，自我一致性在多個熱門的算術與常識推理基準上以驚人幅度提升思維鏈提示的表現，包括 GSM8K（+17.9%）、SVAMP（+11.0%）、AQuA（+12.2%）、StrategyQA（+6.4%）與 ARC-challenge（+3.9%）。

1. 引言

語言模型在許多 NLP 任務上成功，但推理能力常被視為其限制，且無法單靠擴大模型規模克服。Wei et al.（2022）提出思維鏈提示：引導模型生成一連串模仿人類解題過程的短句。例如面對「停車場有 3 輛車，又來了 2 輛，現在有幾輛？」，模型不是直接回「5」，而是被提示產出完整推理鏈：「停車場已有 3 輛車，又來 2 輛，現在是 3 + 2 = 5 輛。答案是 5。」

本文引入一種新解碼策略自我一致性，取代思維鏈提示所用的貪婪解碼。其直覺是：複雜推理任務通常存在多條都能抵達正確答案的推理路徑；問題越需要慎思與分析，能回復出答案的推理路徑就越多樣。

方法分三步（圖 1）：先以思維鏈提示模型；接著不做貪婪解碼，而採「取樣—邊際化（sample-and-marginalize）」程序，從解碼器取樣出一組多樣的推理路徑；每條路徑可能導向不同的最終答案，於是把推理路徑邊際化掉，在最終答案集合中找出最一致的答案。這類比人類經驗：若多種不同思路都得到同一答案，人對該答案的信心就更高。相較其他解碼法，自我一致性避開了貪婪解碼的重複性與局部最優問題，同時緩解單次取樣的隨機性。

自我一致性遠比先前做法簡單：不像 Cobbe et al.（2021）要另外訓練一個驗證器（verifier），也不像 Thoppilan et al.（2022）要蒐集額外人類標註訓練 re-ranker。它完全無監督、對預訓練模型開箱即用、不需額外標註、不需任何訓練、輔助模型或微調。它也不同於典型的模型集成（訓練多個模型再聚合輸出），而更像是架在單一語言模型之上的「自我集成（self-ensemble）」。

作者在四個不同規模的模型上評估：公開的 UL2-20B 與 GPT-3-175B，以及兩個稠密的 decoder-only 模型 LaMDA-137B 與 PaLM-540B。所有模型、所有任務上，自我一致性都以顯著幅度勝過思維鏈提示；配 PaLM-540B 或 GPT-3 時在算術推理上取得當時新的 SOTA（GSM8K +17.9%、SVAMP +11.0%、AQuA +12.2%），常識推理如 StrategyQA +6.4%、ARC-challenge +3.9%。另外還顯示：在「加上思維鏈反而比標準提示更差」的 NLP 任務上，自我一致性能穩健地把表現拉回並超越；它也顯著優於 sample-and-rank、束搜尋與集成類方法，且對取樣策略與不完美提示都很穩健。

2. 在多樣推理路徑上的自我一致性

人性的一個顯著面向是「人各有想法」。在需要慎思的任務上，攻克問題的方式很可能不只一種；作者主張這個過程可以透過從語言模型解碼器取樣來模擬。模型可能對同一道數學題產生數個都抵達正確答案的合理回應（圖 1 的輸出 1 與 3）；由於模型並非完美推理者，也可能產生錯誤路徑或在某步出錯（輸出 2），但這類錯誤解比較不會湊巧收斂到同一個答案。核心假設即：正確的推理過程即使彼此多樣，在最終答案上的一致程度仍高於錯誤的推理過程。

方法細節：先用一組人工撰寫的思維鏈範例提示模型；接著從解碼器取樣一組候選輸出，形成多樣的候選推理路徑（相容於 temperature 取樣、top-k 取樣、nucleus 取樣等多數取樣演算法）；最後把推理路徑邊際化掉，選出生成答案中最一致者。

形式上，設生成的答案 \(a_i\) 來自固定答案集合 \(\mathbb{A}\)，\(i=1,\dots,m\) 索引解碼器取樣出的 \(m\) 個候選輸出。自我一致性引入一個額外的潛變數 \(r_i\)，即第 \(i\) 個輸出中代表推理路徑的 token 序列，並把 \((r_i, a_i)\) 的生成耦合為 \(r_i \rightarrow a_i\)——也就是說，生成推理路徑 \(r_i\) 是可選的，只是用來抵達最終答案 \(a_i\)。取樣多組 \((r_i, a_i)\) 之後，對 \(r_i\) 做邊際化，等同對 \(a_i\) 取多數決：\(\arg\max_a \sum_{i=1}^{m} \mathbb{1}(a_i = a)\)。（答案解析器依任務而定：算術取「The answer is」之後的第一段數字，常識取其後的完整字串。）

聚合策略比較（表 1，PaLM-540B）：除了多數決，也可用 \(P(r_i, a_i \mid \text{prompt}, \text{question})\) 對每條路徑加權；該機率可取未正規化值，或依輸出長度正規化（式 1，即對每個 token 的對數機率取平均後取指數）。結果為——貪婪解碼 GSM8K 56.5 / MultiArith 94.7 / AQuA 35.8 / SVAMP 79.0 / CSQA 79.0 / ARC-c 85.2；未加權和（多數決）74.4 / 99.3 / 48.3 / 86.6 / 80.7 / 88.7；正規化加權和 74.1 / 99.3 / 48.0 / 86.8 / 80.7 / 88.7（幾乎相同）；未正規化加權和 59.9 / 92.2 / 38.2 / 76.2 / 76.2 / 83.5；加權平均則慘跌至 22.1 / 59.7 / 15.7 / 40.5 / 52.1 / 51.7。

作者細看模型輸出機率後發現，各條 \((r_i, a_i)\) 的正規化條件機率彼此相當接近——語言模型認為這些生成「差不多同樣可能」。論文在此明確註記：這也意味著語言模型校準不佳，無法妥善分辨正確解與錯誤解，這正解釋了為何先前工作需要另外訓練 re-ranker 來評判解的品質。

自我一致性探索了「開放式文本生成」與「固定答案的最佳文本生成」之間一塊有趣的空間。推理任務通常有固定答案，所以研究者一般考慮貪婪解碼；但本文發現，即使目標答案固定，在推理過程中引入多樣性仍極為有益。需注意，自我一致性只能用於最終答案來自固定答案集合的問題；原則上若能定義好「多份生成之間是否一致（同意或矛盾）」的度量，也可推廣到開放式生成。
