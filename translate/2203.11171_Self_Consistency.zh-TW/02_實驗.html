3. 實驗

3.1 實驗設定

任務與資料集：算術推理採 Math Word Problem Repository（AddSub、MultiArith、ASDiv）、AQUA-RAT、GSM8K、SVAMP；常識推理採 CommonsenseQA、StrategyQA、ARC（easy/challenge）；符號推理採 last letter concatenation（輸入「Elon Musk」輸出「nk」）與 Coinflip。

語言模型：UL2-20B（開源 encoder-decoder，混合去噪器訓練）、GPT-3-175B（用 Codex 系列的 code-davinci-001 與 code-davinci-002 兩個公開引擎以利重現）、LaMDA-137B、PaLM-540B。所有實驗皆為少樣本設定，不做任何訓練或微調，並沿用 Wei et al.（2022）的相同提示（算術用同一組 8 個人工範例；常識任務每個用 4–7 個範例）。

取樣方案：UL2-20B 與 LaMDA-137B 用 T=0.5 並截斷至 top-k（k=40）；PaLM-540B 用 T=0.7, k=40；GPT-3 用 T=0.7 且不做 top-k 截斷。

3.2 主要結果

結果為 10 次跑的平均，每次獨立取樣 40 條輸出；基線是搭配貪婪解碼的思維鏈提示（CoT-prompting）。

算術推理（表 2）：四個模型全面顯著提升，且模型越大增益越顯著——UL2-20B 為 +3%～6%，LaMDA-137B 與 GPT-3 則為 +9%～23%。已達高準確率的大模型仍有可觀增益：AQuA 與 GSM8K 上 +12%～18%，SVAMP 與 ASDiv 上 +7%～11%。代表性數字：PaLM-540B 的 GSM8K 由 56.5 → 74.4（+17.9）、AQuA 35.8 → 48.3（+12.5）、ASDiv 74.0 → 81.9（+7.9）、SVAMP 79.0 → 86.6（+7.6）、MultiArith 94.7 → 99.3；GPT-3 code-davinci-002 的 GSM8K 60.1 → 78.0（+17.9）、SVAMP 75.8 → 86.8（+11.0）、AQuA 39.8 → 52.0（+12.2）、MultiArith 96.2 → 100.0、ASDiv 80.1 → 87.8；LaMDA-137B 的 MultiArith 51.8 → 75.7（+23.9）。幾乎所有任務都刷新 SOTA——儘管自我一致性是無監督且任務無關的，仍勝過需要任務專屬訓練、或用數千筆樣本微調（如 GSM8K）的既有方法。

常識與符號推理（表 3）：六項中五項取得 SOTA。GPT-3 code-davinci-002：CSQA 79.0 → 81.5、StrategyQA 73.4 → 79.8（+6.4）、ARC-e 94.0 → 96.0、ARC-c 83.6 → 87.5（+3.9）、Letter(4) 70.4 → 73.4、Coinflip(4) 99.0 → 99.5。PaLM-540B：StrategyQA 75.3 → 81.6（+6.3）、ARC-c 85.2 → 88.7、Letter(4) 65.8 → 70.8、Coinflip(4) 88.2 → 91.2。符號推理刻意採**分佈外（OOD）**設定：提示中給 2 字母／2 次擲幣的例子，測試卻用 4 字母／4 次（因為 PaLM-540B 與 GPT-3 在分佈內已可達完美準確率）；在此更困難的設定下，只要模型夠大，自我一致性的增益仍相當顯著。

圖 2 顯示取樣路徑數（1、5、10、20、40）與準確率的關係：取樣越多路徑表現持續越好，凸顯推理路徑多樣性的重要。表 4 給出自我一致性修復貪婪解碼錯誤的實例：GSM8K 題目中貪婪解算成 60 − 20 = 40 而漏掉第二個停點，兩條取樣路徑則都正確算出 60 − 20 − 15 = 25；StrategyQA 題目中貪婪解直接斷言「喬治亞州的 Albany 是美國人口最多的 Albany」，取樣路徑則指出紐約州 Albany 人口更多而答否。

3.3 當思維鏈反而有害時，自我一致性能救回

Ye & Durrett（2022）指出思維鏈提示有時比標準提示更差。作者在數個常見 NLP 任務上檢驗自我一致性能否補上落差，包括閉書問答（BoolQ、HotpotQA）與自然語言推論（e-SNLI、ANLI、RTE）。

結果（表 5，PaLM-540B；標準提示 / CoT 提示 / 自我一致性）：ANLI R1 69.1 / 68.8 / 78.5，R2 55.8 / 58.9 / 64.5，R3 55.8 / 60.6 / 63.4；e-SNLI 85.8 / 81.0 / 88.4；RTE 84.8 / 79.1 / 86.3；BoolQ 71.3 / 74.2 / 78.4；HotpotQA（EM/F1）27.1/36.8 / 28.9/39.8 / 33.8/44.6。可見 ANLI-R1、e-SNLI、RTE 上加入思維鏈確實比標準提示更差，但自我一致性能穩健地提升並超越標準提示，使它成為在少樣本情境中「安全地加上理由（rationale）」的可靠方式。

3.4 與其他既有方法的比較

對比 sample-and-rank：常見做法是取樣多條序列後依各序列的對數機率排序取第一名。在 GPT-3 code-davinci-001 上取樣同樣數量的序列比較（圖 3），sample-and-rank 雖隨取樣數增加而改善，但增益遠小於自我一致性。

對比束搜尋（表 6，UL2-20B）：在相同的束寬／路徑數下，自我一致性顯著勝出。AQuA 上束搜尋（取最佳束）隨束寬 1→40 由 23.6 一路掉到 10.2；「以束搜尋解碼各路徑的自我一致性」為 23.6 → 24.2；「以取樣解碼的自我一致性」則由 19.7 升至 26.9。MultiArith 亦然（束搜尋 10.7→10.5；取樣式自我一致性 9.5→14.7）。原因是束搜尋輸出的多樣性較低，而多樣性正是自我一致性表現的關鍵。

對比集成類方法（表 7，LaMDA-137B）：考慮兩種集成——(1) 提示順序排列（把範例隨機排列 40 次以緩解模型對順序的敏感）、(2) 多組提示（人工寫 3 組不同提示），兩者都對貪婪解碼的答案取多數決。結果：GSM8K CoT 17.1 / 3 組提示集成 18.6 / 40 次排列集成 19.2 / 自我一致性（40 條路徑）27.7；MultiArith 51.8 / 57.1 / 60.9 / 75.7；SVAMP 38.9 / 42.1 / 42.7 / 53.3；ARC-e 75.3 / 76.6 / 76.9 / 79.3；ARC-c 55.1 / 57.0 / 57.0 / 59.8。既有集成法的增益小得多。此外，自我一致性不同於典型的模型集成（訓練多個模型再聚合），而更像單一模型上的「自我集成」。

3.5 額外研究

對取樣策略與規模的穩健性：在 PaLM-540B 上變動 temperature 的 \(T\)、top-k 的 \(k\)、nucleus 的 \(p\)（圖 4 左），自我一致性都穩健有效；圖 4 右顯示在 LaMDA-137B 系列的各種規模上都能穩健提升，只是小模型增益較低（如算術能力要到一定規模才湧現）。

對不完美提示的穩健性：人工撰寫提示時難免出錯。作者把提示推理鏈中的數字全換成亂數（僅保留最終答案），例如「已有 7 輛車，又來 6 輛，現在有 7 + 6 = 5 輛」。表 8（LaMDA-137B, GSM8K）顯示：正確思維鏈提示 17.1；瑕疵提示降為 14.9，加上自我一致性（40 條路徑）回升到 23.4。

一致度作為不確定性估計：作者另發現，一致度（同意最終聚合答案的解碼比例）與準確率高度相關（圖 5，GSM8K）。這意味著可以用自我一致性提供模型對其生成解的不確定性估計——換言之，低一致度即可視為模型信心低的指標；自我一致性因此賦予模型某種「知道自己何時不知道」的能力。

非自然語言推理路徑與零樣本 CoT：把中間推理改成方程式（如把整句改寫成「3 + 2 = 5」），自我一致性仍能提升（表 8「Prompt with equations」5.0 → 6.5），但增益較小，因為方程式短得多、解碼過程能產生多樣性的空間較少。搭配零樣本思維鏈（Kojima et al., 2022）也有效且提升顯著：PaLM-540B 上 GSM8K 由 43.0 → 69.2（+26.2）。
