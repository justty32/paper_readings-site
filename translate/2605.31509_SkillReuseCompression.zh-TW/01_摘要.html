摘要

以強化學習（reinforcement learning, RL）訓練的大型語言模型（LLM）智能體，常學到脆弱、任務專屬的捷徑。我們提出假設：當智能體的成功軌跡具結構可壓縮性（structurally compressible）——能被分解成一小組可重用的抽象樣式時——它們泛化得更好。為將此形式化，我們提出 ReuseRL，把智能體 RL 奠基於最小描述長度（Minimum Description Length, MDL）原理。ReuseRL 從成功軌跡抽出一部共享技能字典（skill dictionary），並用一個**分段成本（segmentation cost）**擴充 RL 目標，明確懲罰那些編碼效率低落的特異行為。我們為此壓縮懲罰證明了一個 PAC-Bayes 泛化界。在 ALFWorld、TextWorld-Cooking 與 Countdown-Stepwise 上，ReuseRL 相較 vanilla GRPO 與強力的回合長度基線，在分佈內（in-distribution）與分佈外（out-of-distribution）成功率都有提升。（程式碼與資料將於發表時以開源授權釋出。）

1. 引言

LLM 智能體在複雜互動任務上表現亮眼——從具身家務推理（ALFWorld）、文字遊戲（TextWorld）到符號推理（Countdown）——靠的是把自然語言推理與環境互動結合。RL 已成為訓練這類智能體的核心範式，其中多輪版本的 GRPO 推動了長程決策的許多近期進展。

然而一個持續的難題是：RL 訓練常固化脆弱的行為捷徑，此失敗模式有時稱為 reasoning collapse（推理塌縮）——長時間最佳化放大了被記憶的動作樣式，犧牲了可遷移的推理。作者不宣稱此失敗只有單一成因，而是孤立出一個可形式化、可介入的結構因素：只獎勵任務成功，會容許能滿足訓練任務、卻無法組合成可重用技能的特異、一次性解法樣式。關鍵在於：緊湊、重複的解法樣式對泛化是有益的，因此難處不在於策略形成捷徑，而在於它也形成特異捷徑。近期研究以老師蒸餾（SkillRL）、反思迴圈（ERL）或外部記憶（Reflexion 等）增補可重用結構來對抗此問題，但究竟是所學行為的哪個共享結構性質帶來增益，仍不清楚。

作者論證：既有能改善智能體 RL 的方法之所以有效，是因為它們隱式地鼓勵了可重用結構的形成。在 RL 與資訊理論中，這種可重用結構與資料壓縮及 MDL 原理緊密相關。此連結指向一個更廣的猜想：成功且可泛化的行為，正是那些容許緊湊、可重用分解的行為。作者把此性質形式化為成功軌跡的結構可壓縮性：把成功行為表示成抽象技能序列後，它由一小組可重用樣式組合出來的程度。此觀點自然地把層次式 RL 的時間抽象（options 把行為壓成可重用子程序）與 MDL 原理接起來。雖然 BPE 式動作 tokenization 與 MDL 導引的技能發現已開始把行為抽象視為壓縮，但沒有人把此壓縮直接整合進 RL 訓練訊號、作為對 LLM 智能體的逐軌跡懲罰，因此壓縮—泛化假設在此設定下仍未經檢驗。

貢獻：(1) 形式化「結構可壓縮性是 RL 訓練 LLM 智能體推理泛化關鍵驅力」的假設；(2) 提出 ReuseRL——線上以貪婪 BPE 式合併從成功軌跡抽出共享技能字典、並用所得分段成本擴充逐軌跡 GRPO 訊號的極簡框架；(3) 以 EM 式交替最佳化把框架奠基於 MDL，證明純回合長度懲罰是退化的固定碼分段成本（命題 1）、建立 PAC-Bayes 泛化界（定理 3），並統一詮釋 SkillRL 與 ERL 為隱式、部分的 MDL 最小化者；(4) 在三個 benchmark 上勝過 vanilla GRPO 與純回合長度基線，驗證核心前提：成功軌跡不該只是短，而該在可重用技能字典下可壓縮。作者刻意在自足的 RL 迴圈中隔離此效果，略去依賴輔助監督的 SkillRL / ERL，以嚴格驗證 MDL 原理的獨立影響。

圖 1 要旨：ReuseRL 區分「可重用的壓縮」與「單純的短」。每個彩色方塊是一個 ALFWorld 原子技能。Vanilla GRPO 只優化任務成功，會產生含重複或浪費步驟的長軌跡；純回合長度懲罰是只含單元素的退化碼，對所有步驟（含必要的搜索）一律懲罰，使智能體探索不足而到不了目標；ReuseRL 從成功軌跡學一部多技能字典，用該字典下的分段成本作為軌跡級懲罰，讓可重用子程序保持便宜、特異浪費保持昂貴。

2. 相關工作

2.1 文法式與 MDL 導引的層次抽象：技能發現可框架成序列壓縮，層次抽象產出可重用子程序。奠基於 MDL 原理的方法學會緊湊技能碼本，在字典大小與資料描述品質間權衡。在 RL 中，BPE 式合併頻繁動作樣式把此想法延伸為時間上延展的巨集動作；PRISE 用壓縮式抽象改善樣本效率；SkillVLA 在具身設定用可重用技能達成組合式任務多樣性；狀態抽象的 PAC 結果進一步表明壓縮表徵能保留近似最優行為。ReuseRL 承襲此線，但把 MDL 目標線上應用、作為對成功行為的逐軌跡 RL 訊號，而非離線建構可重用技能的準則。

2.2 技能鞏固與經驗增強推理：LLM 智能體日益透過環境互動建立技能。訓練期，ERL 與 SkillRL 把環境回饋蒸餾成行為修正；RAGEN、DYSTIL 靠密集回饋自我改進，另一些靠檢索過往經驗。但若不加節制，累積自產軌跡會觸發 reasoning collapse，放大記憶捷徑。這正促成把可重用行為結構的顯式壓縮當作正則化子——而這正是 ReuseRL 所加，且不依賴老師蒸餾、檢索或其他輔助模組。

2.3 資訊理論式策略壓縮：近期工作用資訊理論目標約束 LLM 推理軌跡，如自適應懲罰原始推理長度，或用語言模型先驗下的 surprisal 度量 token 成本。關鍵在於這些方法在 token 或長度層級塑形推理；相較之下，ReuseRL 在行為層級運作，壓縮的是成功技能序列的結構而非表面長度。
