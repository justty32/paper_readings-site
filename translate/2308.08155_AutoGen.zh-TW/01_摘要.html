摘要

AutoGen 是一個開源框架，讓開發者透過多個能彼此對話以完成任務的代理（agent）來建構 LLM 應用。AutoGen 的代理是可客製（customizable）、可對話（conversable） 的，並能以組合 LLM、人類輸入、工具 的各種模式運作。使用 AutoGen，開發者能彈性定義代理的互動行為；自然語言與程式碼皆可用來編排不同應用所需的彈性對話模式。AutoGen 作為一個通用框架，可建構各種複雜度與各種 LLM 能力等級的多樣應用。實證研究顯示其在數學、程式、問答、作業研究、線上決策、娛樂等領域的眾多範例應用上皆有效。

（圖 1）AutoGen 用多代理對話賦能多樣的 LLM 應用：代理可基於 LLM、工具、人類或其組合；代理彼此對話解題（可含人類在迴路中）；框架支援彈性的對話模式。

1. 引言

LLM 正成為打造「會推理、會用工具、能適應新觀察」之強大代理的關鍵積木。隨著可受益於 LLM 的任務擴張且複雜度上升，一個直觀的擴展途徑是讓多個代理協作。既有工作顯示多代理能促進發散思考（Liang 等）、提升事實性與推理（Du 等）、提供驗證（Wu 等）。由此引出核心問題：如何以多代理途徑，促成跨越廣泛領域與複雜度的 LLM 應用開發？

作者的洞見是用多代理對話（multi-agent conversation）來達成，其可行性有三個理由：(1) 對話最佳化的 LLM（如 GPT-4）能吸收回饋，故代理可透過彼此或與人的對話（提供／尋求推理、觀察、批評、驗證）來協作；(2) 單一 LLM 配合正確 prompt 與推理設定能展現廣泛能力，不同配置的代理對話能以模組化、互補的方式組合這些能力；(3) LLM 擅長把複雜任務拆成子任務後求解，多代理對話能直觀地實現這種切分與整合。

要打造這樣一個「泛用抽象＋有效實作」的框架，須解決兩個關鍵問題：(1) 如何設計能幹、可重用、可客製、能有效協作的個別代理？(2) 如何提供一個直觀、統一的介面容納廣泛的對話模式？（不同複雜度的應用需要不同代理集合、不同對話模式——單／多輪、不同人類介入模式、靜態 vs 動態對話；開發者還可能偏好用自然語言或程式碼來編排。）作者提出 AutoGen，一個基於兩個新概念的通用多代理對話框架：

(1) 可客製、可對話的代理：以泛用設計讓代理能運用 LLM、人類輸入、工具或其組合；開發者藉由挑選與配置一組內建能力，就能快速建立不同角色的代理（寫碼、執行碼、接入人類回饋、驗證輸出等）。每個代理都是可對話的——能接收、反應、回應訊息；配置得當時可自主進行多輪對話，或在特定回合徵求人類輸入，兼顧人類能動性與自動化。（§2.1）

(2) 對話式程式設計（conversation programming）：AutoGen 的根本洞見是把複雜的 LLM 應用工作流統一簡化為多代理對話。此範式分兩步：定義一組具特定能力與角色的可對話代理；再以**「對話為中心的計算與控制」**編排代理間的互動行為。兩步皆可用自然語言與程式語言的融合來完成。（§2.2）

此外，AutoGen 提供一系列用上述兩概念打造的多代理應用；在 benchmark 上評估並對新應用做前導研究，結果顯示 AutoGen 能在許多任務上達到出色表現、開啟使用 LLM 的創新方式，同時降低開發負擔。（§3、附錄 D）
