Program Synthesis via Test-Time Transduction

Seoul National University（ECE 系 + IPAI）

摘要

我們提出轉導式程式合成（transductive program synthesis）——一種在合成時顯式利用測試輸入的程式合成新表述。既有程式合成法（無論基於自然語言描述或輸入-輸出範例）通常都想從訓練範例泛化，但常苦於魯棒性，尤其在「訓練範例有限、測試輸入含各種邊界案例」的真實情境。為此，我們提出一個新框架：把合成視為在「由程式輸出定義的有限假設類」上做主動學習，藉此提升魯棒性。我們證明此法在準確率與效率上都顯著改進程式合成。程式碼開源於 github.com/klee972/SYNTRA。

1. 引言

從少數範例合成的程式，套到測試輸入時可能缺乏魯棒性，尤其當測試輸入含邊界案例（相對訓練範例 atypical、或暴露程式邏輯的角落 bug）。為此，我們引入轉導式程式合成：一種在合成時顯式利用可得測試輸入來降低不確定性、產出更魯棒程式的方法。

如圖例：給訓練範例（第 1、2 列），歸納式合成器產一個滿足它們的程式；然而該程式對第 4 列的測試輸入（一個邊界案例）產出錯誤輸出。轉導式合成則利用測試輸入避開此失誤。

我們的貢獻：(1) 把轉導式程式合成形式化為新任務——輸入為程式規格 + N 個測試輸入，目標是合成對這些測試輸入產正確輸出的程式；(2) 提出 **SYNTRA（Synthesis-by-TRAnsduction）**通用框架，藉 transduction 模型利用測試輸入，顯著提升程式在邊界案例上的魯棒性；(3) 用 LLM 實例化框架，在 4 個資料集上評估，任務準確率最高提升 196%。

2. 相關工作

  • 歸納式程式合成（inductive program synthesis）：本工作與之密切相關（從輸入-輸出範例歸納程式）。
  • 我們的工作藉「利用可得測試輸入 + LLM 的轉導預測能力」來在這類設定中提升魯棒性。

3. 轉導式程式合成與 SYNTRA 框架

3.1 問題定義

在轉導式程式合成中，先合成程式 f、再套到測試輸入來預測輸出。我們期望 f 對給定測試輸入產正確輸出；首要關切不是 f 的整體正確性或通用性，而是它在這批特定測試集上的準確率。

3.2 Synthesis-by-Transduction（SYNTRA）

  • 上述假設類只在訓練輸入-輸出對上被驗證，故須挑一個能對「測試輸入中可能出現的多樣案例」穩健泛化的假設。
  • 轉導預測 + 假設淘汰：用一個 transduction 模型觀察某測試輸入與各候選程式對它的輸出，挑一個輸出當偽標籤；與此偽標籤不一致的假設被從當前假設類淘汰。迭代重複「輸入查詢選擇 → 轉導預測 → 假設淘汰」直到只剩一個假設。
  • greedy maximin 查詢選擇：每次轉導預測都要呼叫 LLM，成本高。為省呼叫，提一個 greedy maximin 演算法：對每個輸入，先考慮 transduction 模型的最壞情況預測（淘汰最少假設者，即圖 2 的「min」欄），再選 min 值最大的輸入（最壞情況下能淘汰最多假設者）。平手時，選「候選輸出集總長最短」的輸入——減少下一步傳給 transduction 模型的輸入長度，降算力與推理負擔。類似查詢選擇機制在主動學習文獻廣用；在無額外資訊下，要勝過此類貪婪演算法常被證為困難。

4. 以 LLM 實例化

  • 程式合成模型：產生候選程式（建假設類）。
  • 轉導模型：用 LLM 實作，借其推理能力與世界知識產高準確偽標籤。對選定測試輸入，觀察各程式輸出當候選，選一個當偽標籤。

5. 實驗

  • 四個基準：
    • Playgol：字串轉換的歸納程式設計資料集（源於 spreadsheet 自動化如 FlashFill/Smart Fill 的脈絡）。每任務 5 對範例；為模擬含認知不確定性的真實條件，只用 1 對當訓練範例、其餘 4 對當測試輸入。
    • MBPP+：從自然語言描述生成 Python。比 MBPP 提供更多更多樣的測試案例，特別適合「假設多測試輸入、潛在邊界案例」的本框架。每任務至少 52 對，用 1 對當訓練、5–50 對當測試。
    • 1D-ARC：視覺推理基準（ARC 家族的一維簡化版）。
    • MiniGrid 上的程式化世界建模。
  • 主要結果：SYNTRA顯著勝過純歸納或純轉導方法；任務準確率最高提升 196%。
  • 效率：依 maximin 準則選測試輸入，用遠少的 LLM 呼叫達到與隨機選輸入相當的準確率（把「超出下界的額外呼叫」腰斬）。

結論

把程式合成從「純歸納」推進到「轉導式」——在合成時利用測試輸入，並把問題框成「在程式輸出定義的有限假設類上做主動學習」。SYNTRA 用 LLM 當轉導偽標籤器迭代淘汰假設、以 greedy maximin 控制成本，在 4 個多領域基準上同時提升準確率（最高 +196%）與效率。
