摘要

方程發現旨在從資料自動化發現「數學方程」形式的科學模型，技術上靠 SR 演算法實現。SR 的方程發現效能沿兩個維度量度：測試資料上的預測準確度，與回復已知真值公式的能力。標準迴歸通常以域內測試資料（隨機切分）量準確度——這對「域內插值」合理，但對真正的模型發現與泛化可能是誤導性代理。明顯的替代是量域外準確度，但取得有挑戰性的域外測試資料並非易事。因此我們聚焦方程回復來評 SR 演算法：能良好回復已知真值式者，是發現未知方程的好候選。既有 SR 基準雖含方程回復任務，但公開真值式數量少，且少強調演算法在維度/取樣量/取樣分佈/取樣域變化下的穩健性——而這對想為自然現象建模的實務者至關重要（資料幾乎必有噪聲、來自多樣的域/分佈/樣本量）。為補此缺口，我們提出 ERBench（方程回復基準）。

關鍵詞：方程發現、自動化科學發現、AI4Science。

1. 引言

科學方法的根本驅力，是發展能對世界做出大膽、可否證預測的模型。如 Popper 所言：理論的科學價值不在被驗證，而在能被嚴格實證反駁的能力；模型熬過嚴苛實驗（尤其在新奇的域外情境）時，我們對它的信心才增長。相對地，僅事後擬合既有資料的模型只有回溯力，缺真正科學進步所需的解釋潛能。

但 Popper 的理想並非所有建模的首要目標。工程與應用科學常要的是「定義良好域內的高預測準確度」——目標是可靠插值而非大膽外推。多項式迴歸、神經網路、高斯過程在此表現優異，但常被當「黑箱」、域外即失效（圖 1）。相對地，科學建模的雄心是泛化與解釋：發現不只能預測、還能洞察底層機制、能外推、能做可否證預測的模型。

方程發現的目標是支援科學家做出新發現——藉搜尋簡約的符號式來揭示支配系統的基本原理，產出本質上可泛化、可解釋、可否證的模型。但把這哲學理想轉為計算程序並不簡單。

衡量域外泛化的強指標，就是從訓練資料回復已知真值式的能力。方程回復可視為方程發現的類比，差別在此設定下真值已知。我們提出 ERBench——評 SR 演算法於方程回復任務的框架，實作 common task framework（共同任務框架）的理念：一組與研究者共商定義的公開任務與準則，加上保留的祕密評測任務供週期性公開評比。ERBench 的任務是回復已知真值式，準則是高回復率。貢獻：

  • 泛化（Generalization）：ML 通常以未見資料的預測準確度量泛化；但對 SR，我們提出更嚴、更有意義的標準——回復生成資料的真值符號式。能做到者已泛化到系統底層定律之外。可靠重現已知定律的演算法，是發現新定律的可信工具。故我們的基準優先採「與真值符號等價」的指標，而非僅靠預測誤差。
  • 穩健性（Robustness）：提供不同大小/分佈/域的訓練集，評估方程發現演算法的能力與限制。
  • 資料集（Dataset）：公開訓練集彙集跨領域真值式 + 大型合成式集（難度遞增）；祕密測試集由參數化、可重現程序生成，確保公平、可靠，並最小化題目落入預訓練語料的機率（對公平評 LLM 等現代方法至關重要）。
  • 排行榜（Leaderboard）：常設競賽，易接入、易維護，隨時呈現當前 SOTA 真貌。

2. 相關工作

  • SR 基準演進：Udrescu & Tegmark（2020）的 Feynman dataset（119 條物理式）→ La Cava 等（2021）擴為 SRBench（更廣的 SR 演算法）。但評測集公開後，新演算法無法公平比較；GECCO'22/'23 的競賽部分緩解此問題。後續延伸：SRDS（對齊真實物理的常數/取樣域）、LLM-SRBench（用新穎/改編式緩解 LLM 資料洩漏）、SRBench++（專家評可解釋性）、PySR 的 EmpiricalBench（科學家從噪聲資料發現過的真實物理問題）。ERBench 把這些理念系統化為「大型多樣公開式集 + 跨樣本量/域/分佈嚴格評測的祕密集」。
  • 與 AI-scientist 環境的區隔：Science-Gym、PhysGym 等評估代理跑完整科學工作流（假設生成→實驗→分析）。ERBench 刻意隔離方程發現於主動資料採集與實驗設計之外——提供靜態但全面的測試台，做核心「從給定資料回復真值式」能力的細粒度評估，與前者互補。

3. 方程發現的現狀（演算法分類學）

SR 的首要目標是找最小化預測誤差（如 MSE）的符號模型，與古典迴歸類似，但關鍵差別是 SR 同時搜尋函數結構與參數。方程發現則進一步追求回復底層生成式本身，強調簡約與符號等價而非僅預測準確。

把 SR 分五類，並由各類弱點導出基準的設計原則（▶）：

  1. 傳統迴歸的延伸（稀疏迴歸／稀疏迴歸網路）：只能回復「由基函數／網路架構給定的假設類」內的式子。▶ 公平基準應提供多樣假設類的式子，驗證跨結構偏置的穩健性。
  2. 枚舉式搜尋（如 AIFeynman，靠對稱性等統計性質砍搜尋空間）：若真值式表示小，必被回復且不依賴取樣域；但隨複雜度上升回復率劣化（圖 3 左）。▶ 應標定可靠回復的「表示複雜度邊界」（運算子數、維度）。
  3. 取樣式搜尋（GP／貝氏／RL）：靠「對資料的數值接近度」更新分佈 → 回復率依賴取樣域（圖 3 右）。
  4. 預訓練式（NeSymReS、E2E、SymFormer、TF4SR…）：成敗繫於預訓練分佈。
  5. 混合式（uDSR 用 transformer、EvoNUDGE 用 GNN 產候選）。

▶ SR 日益嵌入更大的方程發現系統，需要全面的診斷工具辨識各組件的能力與限制。

4. 方程回復基準

  • 回復任務的形式定義：給真值式生成的資料，找出與其符號等價的式子；含寬鬆評測指標（如 Jaccard 指數量部分符號相似度）。
  • 設計原則：依第 3 節導出，提供跨「複雜度、維度、取樣量、域、分佈」的細粒度量化分析，及跨科學領域/函數類的質性分析。
  • 基準組件：
    • 公開開發集：跨領域真值式 + 合成式集 SynEq（附錄 A.3 詳述取樣；在 ℝⁿ 找式子有效的大盒域，避開除零/負數開根取對數，採 Kamienny 等的多樣取樣分佈）。
    • 祕密評測集：參數化可重現生成；以三層置換（題序洗牌、變數序、重取樣）確保每次請求是等難度但跨請求不洩漏資訊。
  • 方程回復挑戰：使用者請求題目→提交結果→評測。

5. 實驗

  • 設定：演算法含搜尋式（PySR 多族群演化、Operon、gplearn）、取樣式（DSR）、預訓練式（E2E transformer）、及 Linear baseline。在祕密測試集做首次標準化直接比較。
  • 結果：
    • 嚴格符號回復：基準對多數方法極難——6 個中 5 個（含 E2E、Operon）回復率近 0;PySR 成功回復 ~30%，確立其精確符號發現的 SOTA 地位。
    • Jaccard 指數（部分符號相似度）：PySR 以 0.5 領先；次佳 DSR 0.28 竟與簡單 Linear baseline 0.25 相當——揭示複雜演算法常產生「含許多錯誤子式的龐大式」，因 Jaccard 懲罰非重疊子式的聯集，緊湊的 Linear baseline 反得高分。凸顯 SOTA 既找不到真值、也維持不了簡約性。
    • 診斷分析（對冠軍 PySR 跑 Feynman 子集）：1–3 運算子近完美回復；隨運算子數上升急遽劣化，>13 運算子掉到近 0。
