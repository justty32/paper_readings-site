論文／訪談原始來源

AgentSpec: Understanding Embodied Agent Scaffolds Through Controlled Composition 重點摘要

一句話

AgentSpec 用固定的型別介面拆開 perception、memory、reasoning、reflection、action 與可選 learning，讓研究者能在同一閉迴路裡替換模組；實驗顯示 agent 表現取決於模組彼此是否吃得懂對方的輸出，而不是把各自最強的零件湊在一起就會最好。

問題與方法

  • 問題：現有 agent scaffold 常把 prompt、記憶、推理、反思與控制邏輯綁成完整系統。換掉一個模組往往得重寫其餘管線，因此很難分辨提升來自單一元件，還是元件互動。
  • 受控組合：每一步先把原始 observation 正規化為統一 state；memory 從歷史取回情境；reasoning 產生候選決策；reflection 在執行前批判或改寫；action adapter 再轉成環境可接受的動作。環境回饋寫回記憶，也可交給 RL 更新。關鍵是每個邊界都有 typed intermediate object，而不是只宣稱程式碼模組化。
  • 設計空間：reasoning 可替換 CoT、ReAct、搜尋或 multi-agent 方法；memory 可換成原始軌跡、摘要、檢索或多粒度 MemoryBank；reflection 可在 step 或 trajectory 層工作；learning 則能比較裸 policy 訓練與帶 scaffold 情境的訓練。
  • 評估方式：DeliveryBench 檢查長期資源規劃，ALFRED 檢查家務操作與任務狀態，MiniGrid 隔離符號導航與部分可觀測性，RoboTHOR 則加入真實感較高的視覺導航。作者不只看任務分數，也比較 token 與每步思考時間。

作者報告的結果

在 DeliveryBench、GPT-5 mini 上，把 ReAct 的 Base memory 換成 MemoryBank，平均每小時 profit 從 8.54 升到 30.67；Plan-and-Solve 的相同替換則由 6.18 升到 26.78。這說明記憶收益取決於下游 reasoner 能否利用其抽象層級（作者自報）。

學習實驗顯示，GRPO 的裸 Base policy 從 -3.07 提高到 5.80，但事後接上結構化記憶不保證再進步。相較之下，會在訓練中摘要軌跡的 SUPO 搭配 ReAct 與 DynamicCheatsheet 得到 8.27，高於同 scaffold 下 GRPO 的 5.02；作者將差異歸因於訓練時已接觸結構化歷史，因而較能適應部署期 scaffold（作者自報）。

質化與跨環境分析的共同趨勢是：多粒度 MemoryBank 對不同 reasoner 較穩健；reflection 對弱組合的修正幅度較大，對強組合仍有較小且一致的幫助；較高 token 或延遲並不自動換來較高 profit（作者自報）。

局限

研究只覆蓋代表性的 embodied 與 decision-making 任務，未證明結論可直接轉移到網頁操作、軟體工程或開放式人機互動。各模組只測代表實作，沒有窮盡 prompt、retrieval、update policy 與 context budget。受算力限制，並非所有 model、module 與 environment 組合都有大規模測試或重複試驗，個別結果可能受抽樣變異影響；token 效率、延遲、記憶成長與錯誤沿軌跡傳播也仍缺更細的診斷。

對 ai_core 的價值／接點

AgentSpec 替 ai_core 的「模組可替換」補上一個常被漏掉的條件：介面型別一致只是最低門檻，表示資料能送進去，不表示接收端知道怎麼用。記憶在推論期突然加入，可能對已用另一種 context 分布訓練的 policy 形成分布偏移；同理，ai_core 若把新憑證、摘要或工具結果接到既有決策器，應測量組合後的邊際效果，而不能沿用各模組單測分數。這篇也支持把 scaffold 視為需共同最佳化的整體：准入測試除了元件規格，還要有相鄰介面契約與常見組合的回歸集，才能避免「零件都合格，整機卻退步」。
