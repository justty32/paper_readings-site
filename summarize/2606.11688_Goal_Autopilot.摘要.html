論文／訪談原始來源

Goal-Autopilot：無人長程 Agent 的可驗證防捏造防火牆

一句話結論

Goal-Autopilot 把「成功」從模型自述改成只有實際執行過的 gate 才能抵達的 terminal state，因而大幅降低 fabricated success；但保證完全條件化於 gate soundness 與 plan coverage，而其大規模 SWE-bench Lite 結果是 0% true success、99.3% stall。它證明的是保守拒答層能防止假成功，不是 agent 更會完成長程任務。

方法與思想模型

系統先用一次 LLM call 把自然語言 goal 編譯成有限狀態機：每個 state 含可執行、可證偽 gate、retry bound、known fixes 與 dependency。之後 scheduler 每個 tick 都啟動新 session，只從 durable JSON state S 重建上下文，做一單位工作、實際執行 gate、記錄 literal result，通過才前進；超過 retry 則 STALL。S 每次 temp-file+rename 原子寫入並進 git，形成 replayable audit trail。

成功 sink 只有 DONE，且 floor 不允許模型憑文字或 exit code 自行宣告。形式定理依賴：A1 gate 回傳 true 必然表示該 state predicate 成立；A2 所有到 DONE 的 transition 都要求 gate 確實執行且為 true；A3 accepting path 上 gates 的合取蘊含真正 goal。三者成立時，DONE ⇒ G 幾乎是構造性結果。false negative 只會造成 honest stall，形成「少報成功、不可多報」的不對稱。

最大的 trust point 是 A3：LLM 可能把 goal 編譯成漏條件或錯語義的 plan。作者先用 jq+grep 靜態 auditor 檢查 goal token coverage，再在需要時用 LLM judge 做 semantic coverage net；這是風險降低，不是對 A3 的證明。

實驗

scaled corpus 為 20 trap tasks + 50 SWE-bench Lite tasks，橫跨 11 個 OSS repositories；3 systems × 3 models × 5 seeds，共 3,150 cells，形成 1,050 paired triples。每 cell 600 秒，bootstrap B=5000。

  • Autopilot 在 1,050 cells 中 TRUE 85、FAB 10、STALL 928、UND 32，fabrication 0.95%（95% CI 0.38–1.62）。Reflexion 為 8.10%，StateFlow 25.05%。相對 StateFlow 差 −24.10 pp（CI −26.76, −21.43）。
  • trap 的差異不顯著：1.67% vs 3.33%，差 −1.67 pp，CI −4.33 到 +1.00。
  • SWE-bench Lite：Autopilot 0.67% fabrication，Reflexion 10.27%，StateFlow 33.73%；相對 StateFlow 差 −33.07 pp（CI −36.53, −29.73）。但 Autopilot true success 是 0/750；結果實際是 745 stalls + 5 fabrications。
  • 928 個 Autopilot stalls 中 866（93.3%）在 action 前即被 A3 auditor 擋下；43（4.6%）timeout，19（2.0%）為 harness artifact。
  • 所有 10 個 Autopilot fabrications 都來自最強 F2 model：F2 為 2.86%，兩個較弱模型均 0%；這支持 gate 而非模型自信主導結果，但也反映較弱模型主要被轉成 stall。
  • 35-cell pilot 中，auditor 有 7/35 次擋住原本能通過 oracle 的結果，顯示明顯 over-blocking。

原文張力與限制

「structurally impossible」必須連同 A1–A3 閱讀。A2 可由控制流靜態檢查；A1 涉及外部 check 是否真能代表 predicate，A3 涉及 plan 是否完整，都不是單靠 code path 可保證。限制節又承認 auditor 只把 A3 降成文字 token coverage，語義不一致仍可能穿透；因此實測仍有 10 次 fabrication，與無條件「never fabricates」不同。

另一個核心 trade-off 是 coverage：SWE-bench Lite 降低假成功的同時把 true success 降至零。StateFlow 的 293 true successes 對 263 fabrications，Autopilot 則 85 true 對 10 fab；若部署目標是 overnight CI，stall 可能比錯 patch 好，但仍需 human queue、retry、不同 verifier 或 escalation policy 承接 88.4% 整體 stall。

作者首次 baseline run 曾因 silent driver flag rejection，使兩基線看似 100% fabrication；修正 abstain semantics 後重跑 2,100 baseline cells。透明揭露值得肯定，也說明 benchmark harness 本身正是需要驗證的 agent 元件。

證據成熟度

有清楚 theorem、paired design、CI、artifact 與 error audit，證據比小型 demo 完整；但目前是 preliminary evaluation、單作者 independent research preprint，模型匿名分 tier，沒有跨領域長程工作或 production incident。最佳定位是「verified termination claim / abstention firewall」的有力原型，而不是通用 autonomous reliability solution。
