論文／訪談原始來源

《邁向可解釋臨床決策評分的符號迴歸（Brush）》重點摘要

一句話概括

Brush（Aldeia 博士論文 2512.01682 中的同名 SR 函式庫）：把決策樹式的「分支（split）操作」與非線性常數優化結合進符號迴歸——讓「規則式邏輯」無縫融入 SR/分類模型。應用於臨床風險評分（CART、MEWS），達高準確 + 可解釋（巢狀 if 規則），且模型比決策樹/隨機森林/其他 SR 更小。SRBench 上達 Pareto 最優。

解決什麼問題

  • 醫療決策常用「風險方程 + 規則」的演算法（評分系統如 CART triage）；傳統 SR 只搜尋連續函數形式與參數，難建模這種規則式決策。
  • 純數學式需數學素養 → 臨床上不如決策樹受青睞；但 SR 能產資料驅動、可解釋模型 → 有望做資料驅動臨床風險評分。
  • 現有 SR 靠局部參數優化，但無法納入 split 操作（split 參數難用現有優化法優化）。

核心：Brush 的 split 節點

  • split 節點 3 分支：一個實值條件子樹 + true/false 兩子樹（皆為 Brush 樹）；條件與可學閾值比較決定資料流。
  • 最優閾值最小化兩側目標變異數和（一維聚類）；此 split 遮罩資料集使下游運算只作用於子集 → 子樹更精確、參數優化更快。
  • 與非線性優化（Levenberg-Marquardt）相容（既有 SR 缺此）。兩型：greedy split（單特徵 + 閾值，似決策樹）、flexible split（演化生子表達式，只優化閾值）。
  • 三步優化：先優化條件子樹 → 找最小變異數閾值 → 固定條件擬合其餘。
  • GP 框架：ε-lexicase 選擇 + NSGA-II 存活，多目標（MSE + 線性複雜度）；後處理用不精確簡化（2512.01682 的 LSH 法）壓縮。
  • 分類模式：在表達式樹根固定一個 logistic regression 節點。

實驗

  • SRBench：Pareto 最優、表達式顯著更小；超過半數 run 達 R²>… 即使高噪聲。
  • 臨床（MIMIC-IV-ED，Beth Israel）：學 triage 評分（MAP、CART、簡化 MEWS）的迴歸 + 二元分類（高風險惡化）；類別不平衡 → 用 AUPRC；特徵集刻意含 ~多個變數（挑戰特徵選擇）。對手：決策樹（DT）、隨機森林（RF）、L2-logistic、PS-Tree、FEAT。
  • 結果：Brush 競爭力相當或更優，模型小得多;split 節點顯著提升分類 AUPRC（CART/MEWS deterioration 移除 split 後 AUPRC 顯著降，p<1e-4）→ 益處不只可解釋、也含分類效能；範例模型是巢狀 if 規則（resprate≥21→高風險；否則看 dbp/heartrate/age…），可解釋。

對讀者的價值

  • 是 2512.01682（Aldeia 博士論文）的Brush 框架實際應用論文——同一組人（de França、La Cava）；聚焦「把規則/split 帶進 SR」這個 SR 長年缺口。
  • 與 2505.14510 BACON（分級邏輯可解釋決策）、2502.01806 NsPC 同屬「可解釋臨床/決策 AI」，但 Brush 獨特在 「split 節點 + 非線性優化相容」（決策樹的規則 + SR 的方程一體）。
  • 最值得記：split 節點（可學閾值最小化變異數 + 遮罩資料子集 + 三步優化） 讓 SR 學「規則 + 方程」混合模型；split 不只增可解釋也增分類效能;ε-lexicase + NSGA-II + 不精確簡化的 GP 配方。
  • 與 2502.09100 等「可解釋醫療決策」需求呼應（美國 FDA 臨床決策支援軟體指引要可解釋）。
  • 定位：方法 + 臨床應用論文；適合做 可解釋臨床評分、規則式 SR、決策樹+SR 混合 的人；Brush 有開源（C++ + Python）。
