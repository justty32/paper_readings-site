論文／訪談原始來源

《Beyond Semantic Equivalence：邏輯圖用於 LLM 不確定性量化》重點摘要

一句話概括

Logical Graph Uncertainty (LGU)：在語意等價類之上再建構兩層圖——Implication Graph (ImG)（含藴含邊的 DAG，把機率質量沿著「1920s → 20世紀初」這類藴含鏈匯聚到邏輯最大假設「根」上，算出 IGE）與 Incompatible Graph (InG)（在根之間記錄互斥關係，求出 InS），最終 LGU = (1+InS) × IGE——一個無超參、O(n²) 的閉形式不確定性分數，在四個 QA 基準上 AUROC 比 Semantic Entropy 高出達 +7.1%，且 ECE 校正大幅改善。核心洞見：SE 把「形式多樣但邏輯相容」的正確答案當成高不確定性來懲罰（因為分到不同語意簇），LGU 則透過藴含鏈正確辨識：模型的答案若在邏輯樹上收斂到同一個根，不確定性應該低；唯有根之間密集互斥時，才真正代表不可靠。

核心貢獻

  1. Implication Graph (ImG) 建構：以 NLI 模型判斷答案間的藴含關係，形成 DAG（Theorem 2.3 證明），沿藴含鏈將機率質量推向「根」（邏輯最大假設），正規化後得 IGE。這解決了 SE「語意不相等就分開計數」導致雙重計數的問題。
  2. Incompatible Graph (InG) + InS：在 ImG 的根之上再判定互斥關係（例如「發生於法國大革命」vs「發生於越戰期間」不可能同時為真），用圖密度指標（邊密度／平均度／Estrada 指數）量化衝突強度。預設選用邊密度（值 ∈[0,1]，跨查詢可比）。
  3. LGU = (1+InS) × IGE：將不確定性從「語意簇的分佈熵」重新定義為「邏輯最大假設的分佈熵 × 互斥密度懲罰」——改變的是熵所度量的隨機變數本身，而非熵泛函（Theorem 2.6 給出極值刻畫）。
  4. 大規模驗證：8 個 LLM 骨幹（7B–32B）、4 個 QA 基準（TriviaQA、SQuAD、BioASQ、NQ），LGU 在所有模型／資料集上平均排名最佳；NQ 上 AUROC 0.752 / AUARC 0.533；Falcon-7b-SQuAD 上 ECE 0.071（SE 為 0.206）。

對讀者的價值（與 ai_core 的接點）

  • ai_core §3.4 憑證准入的核心升級：現有 UQ 方法（如 SE）把「結構不同但邏輯等價」的答案視為獨立的語意簇，造成不確定性被系統性高估——這直接導致憑證准入閾值過嚴：本來品質沒問題的輸出，只因為 LLM 用不同說法表達了同一事實，就被誤判為不可靠、無謂拒絕或升級。LGU 的關鍵貢獻是用邏輯圖取代語意等價類作為 UQ 的底層假設空間：ImG 把「模型表達多樣但邏輯收斂」正確歸類為低不確定性；InG 則只在根假設互斥時才拉高不確定性——這正是憑證准入需要的判準：「多樣是好事（代表沒有過擬合到單一表層形式）vs 真衝突才是警訊」。LGU 的無超參特性對憑證閾值設定尤其重要：InS ∈ [0,1] 是一個可跨查詢比較的歸一化強度，IGE 的上界由 ImG 結構決定——不需要手調魔數即可在不同任務間有一致的閾值語義。
  • 對 §3.3 成本梯度／級聯路由的影響：當便宜節點的輸出看起來「多樣」（實際上是藴含相容）時，SE 會錯誤地觸發升級到貴模型；LGU 修正了這個誤報源，讓級聯路由的升級決策更精準——省下的不只是推論成本，還有因誤升級製造出的不必要的「再次確認」延遲。
  • 方法定位：理論＋圖論保證＋大規模實證，無需訓練／超參調整，開源。適合關心不確定性估計、幻覺檢測、憑證式准入的讀者。本論文直接改進了 SE 所忽略的邏輯結構維度，對 ai_core 的「穩定度 % 門檻」提供了比 SE 更可靠的不確定性訊號來源。
