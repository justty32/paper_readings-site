論文／訪談原始來源

《Hypernetworks That Evolve Themselves：自我參照圖超網路》重點摘要

一句話概括

Self-Referential Graph HyperNetworks（自我參照 GHN）：把「變異與遺傳的機器」內嵌進神經網路本身，讓網路無需外部優化器就能自我演化——結合超網路 + 隨機參數生成 + 圖表示，每個 GHN 既給「自己的拷貝」生成帶可學習隨機變異的參數更新（隨機 hypernetwork），又給策略網路生成權重來評估自身適應度（確定性 hypernetwork）；且突變率本身是可被選擇的遺傳特質（node-specific mutation rate）。在帶環境切換的新 RL benchmark（CartPole-Switch、LunarLander-Switch）上幾代內就近乎完美恢復；在 Ant-v5 演化出協調步態，並自主降低種群變異以集中於有希望的解。核心論點：可演化性（evolvability）本身可從神經自我參照中湧現。

解決什麼問題

大多數 neuroevolution 把「演化機器」放在被優化的神經基質之外——一個與種群分離的演算法負責對個體施加突變。但演化生物學的教訓是：突變的速率與結構很重要（低變異加速利用但易早熟收斂、高變異助探索但易失去既有適應度），而自適應突變率作為個體的可遺傳特質在開放式系統（適應度地景隨時間劇變）中尤其關鍵。因此需要把「產生變異的機制」收進神經基質內，讓 evolvability 也受選擇。

核心方法

  • 承襲脈絡：HyperNetworks（小網路生大網路權重，類基因型-表現型映射）→ Graph HyperNetworks（GHN，直接在計算圖上用 GNN 處理拓撲、給任意未見架構生參數）→ 自我參照系（Neural Network Quine 預測自身權重但會「不育」、recursively fertile 自複製、Irie 的 SRWM 自參照權重矩陣、SeRANN 自複製 ANN）。本文與這些不同：對「自己的拷貝」改參數，演化迴圈中從不含梯度更新。
  • 隨機自參照 hypernetwork：兩項改造滿足「能生足夠多參數更新自己」+「含隨機變異」——(1) 最終輸出層用固定隨機基底（永不改變→避開「需要生比自身更多參數的層」的循環悖論）;(2) GNN 的 node 表示不直接送輸出層，而是先生一個均值固定為 0 的多元高斯的標準差參數，採樣後再送輸出層 → 同一 GHN 對同一架構能生不同候選權重。
  • 可調突變率（核心巧思）：每個 node embedding 過一個 M 個 sigmoid 輸出的線性層，取 max 當該 node 的突變率去縮放隨機 hypernetwork 輸出；再永遠加一點小噪聲（即使突變率全 0 仍有微變異、可重新打開突變）。M=5。直覺：種群都差不多差時增大變異（探索）、少數遠勝其餘時降低變異（集中資源）——全自主、無外部排程。
  • 演化：parent 先精確拷貝 → 過自己的隨機 hypernetwork 生一組參數加到拷貝上 → 即產出自身變體；確定性 hypernetwork 給 policy 網路生參數、跑環境得分即 GHN 的 fitness;top 個體當 parents，各產 N=2 後代。

結果

  • CartPole-Switch / LunarLander-Switch（演化中途反轉控制器輸出、之後再轉回）：對比 OpenES、CMA-ES、GA、以及自適應突變率法 GESMR、SAMR——只有自我參照 GHN 在兩次切換後都一致恢復近滿分（OpenES 第一次切換後就再也回不來、GESMR 雖製造巨大變異仍失敗）。
  • Ant-v5（地景固定）：單調改善，常卡在 ~1000 的局部最優（機器人站著不動避免摔落罰分）；突破後種群變異急降;1000 代內未達 ~4000 滿分，但穩定 >2000 → 已能運動。
  • 湧現現象：環境變化後種群多樣性上升、找到高適應度 niche 後下降 → 突變幅度的湧現式控制（呼應「evolvability 是可選擇特質」假說）。

局限

  • 「在個體內放可學習突變生成模組」計算昂貴——生成參數更新遠比從分布抽樣貴。
  • 尺寸隨目標網路快速增大：確定性 hypernetwork 尺寸由 target policy 最大 node 參數需求決定，隨機網路尺寸又由 GHN 內最大 node 需求決定 → 大目標網路使參數生成更慢。
  • 超參未經廣泛搜尋（preliminary 找到即用）;Ant-v5 未達滿分。

對讀者的價值
