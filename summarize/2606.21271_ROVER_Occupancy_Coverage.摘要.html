論文／訪談原始來源

《ROVER：以占用測度覆蓋最大化做免獎勵預訓練》重點摘要

一句話概括

多數內在獎勵探索（novelty/RND/skill-diversity）靠會隨資料漂移的非平穩代理目標，常「預訓練時發現很多狀態、最終策略卻把折扣占用集中在一小塊」，且多數方法仍假設下游 reward 能離線 relabel（多任務/meta/continual 的 reward-free 場景不成立）；ROVER（Reward-free pretraining via Occupancy coVERage maximization） 把免獎勵預訓練形式化為 occupancy coverage（占用覆蓋）——學一個「折扣狀態占用 d^π 廣布於可達狀態空間」的平穩策略，作法是把占用測度嵌入 RKHS、最小化其自相似度（平方 Hilbert 範數）J(π)=‖μ_{d^π}‖²（等價於最大化 order-2 Rényi 熵、tabular 下等價 MMD 匹配均勻分布），用算子化（resolvent world model）閉式估占用、繞開密度/熵估計，再加一個虛擬 "sink"（吸收）狀態把資料未支撐的區域路由到受控吸收態、防止「擴張-崩塌」週期性振盪。在 tabular 與像素稀疏導航任務上，比標準免獎勵 baseline（RND/SMM/APT/MAXENT/CIC）更均勻的聚合覆蓋、更快達全覆蓋、給下游更強的初始化。

解決什麼問題

稀疏獎勵下「訓練起點的行為」對下游學習至關重要。免獎勵預訓練讓 agent 在 reward 指定前先互動，可透過資料/表徵/世界模型/策略預條件下游問題。但兩個痛點：

  1. 多數遷移假設下游 reward 可離線評估（relabel 存下的 transition）——這在多任務、meta、continual 稀疏獎勵中不成立（有意義回饋只在 agent 真的抵達任務目標時線上出現）。
  2. 覆蓋型目標常被耦合到「移動的輔助物」（predictor、密度估計、最近鄰幾何、skill discriminator），其非平穩性使策略短暫發現新區卻不保留在最終折扣占用裡——SMM/RND 的振盪、APT/MAXENT 的「資料收集多樣但最終策略不均衡覆蓋」皆此病。

核心方法

  • 目標（target-free 自相似度）：用 kernel mean embedding 把占用測度 d^π 嵌入 RKHS，最小化 J(π)=‖μ_{d^π}‖²_ℋ = ∬k(x,y)dᵖⁱ(dx)dᵖⁱ(dy)。Prop.1 證 tabular（Dirac 核）下 argmin J(π) = argmin MMD²(d^π, uniform)——不必知道均勻目標 u 也能恢復均勻覆蓋；J(π) 即 order-2 多樣性的倒數、log(1/J) 是 order-2 Rényi（碰撞）熵；學到表徵空間則促進「表徵幾何下的均勻」。
  • 算子化估計（ROVER）：用 MDP 的算子/Koopman 表述，把折扣占用寫成 resolvent 形式 d^π=(1−γ)(Id−γTP_π)⁻¹ν₀；學一個轉移算子（conditional mean embedding，kernel ridge regression 閉式 T̂_n=Φ^⊤(K+λId)⁻¹Ψ），即可閉式微分 J(π)。表徵 ϕ 用 InfoNCE 對比學習從 transition 學（非預設）。策略更新用 Policy Mirror Descent（保證每步 π 仍是合法分布；歷史壓進累積係數向量）。
  • Sink-state 增廣（關鍵穩定子）：T̂_n 對資料外的 (x,a) 預測 ≈0，被 RKHS 範數誤當「低成本延續」→ 造成擴張-崩塌振盪。引入虛擬吸收態 s_{Sε}，把「未被訓練輸入解釋的殘差質量」路由到 sink（shifted ridge，Prop.3/4 給閉式 sandwich 結構），對「把占用放到未探索區」給明確成本，平衡「擴張到未見區 vs 保留已覆蓋區」。

結果（tabular + 像素稀疏導航：Two-Rooms / Multi-Rooms / Maze / Middle-Room）

  • 聚合覆蓋更均勻 + 不遺忘：baseline 雖在訓練中訪問不同區，策略快照常一次只集中一區（Fig.2/7）；ROVER 最終策略廣覆蓋——這正是其目標核心性質。
  • 樣本效率：在 Multi-Rooms / Maze（state 與 pixel 兩種觀察），ROVER 從零達「全狀態覆蓋」遠快於 baseline（Fig.3）。
  • 下游初始化更強：用 ROVER 預訓練初始化 DDPG/SAC，在 bottleneck 環境顯著勝所有 baseline 與 from-scratch（Fig.8/9/10）；離線 RL（CQL）下 ROVER 一致最強、是唯一在最難 Multi-Room（目標 Room5）成功者（Tab.2）；offline DDPG 下 CIC 在最遠目標略強（因 DDPG 偏好同質覆蓋）。
  • sink-state 消融（Fig.1）：無 sink → 用零記憶更新時策略在前幾房間振盪；有 sink → 擴張同時保留連通覆蓋。

局限

  • 刻意限定離散動作 + 簡單環境（作者明言：為隔離分析覆蓋目標，非主張可完全擴展的探索演算法）。
  • 連續動作、高維真實任務、長 horizon 尚未驗證；resolvent/算子估計與核 ridge 在大狀態空間的可擴展性是開放問題。
  • 預訓練有前期開銷（雖可攤提到多下游任務 T/|S|）；下游表現與離線演算法（CQL vs DDPG）對「資料分布形狀」的偏好交互（ROVER 偏起點與軌跡前綴的密度，利於 CQL 的 start-to-goal 鏈、未必利於偏好同質覆蓋的 DDPG）。

對讀者的價值

  • 本批 D 類探索/免獎勵預訓練的「形式乾淨」一篇：把「探索＝覆蓋」用 RKHS 自相似度最小化做成 target-free 目標（接 MEPOL/MaxEnt/APT/SMM 的最大熵覆蓋族，但不需手選狀態度量、不需均勻目標、不靠移動代理物），對「prediction-error novelty 的非平穩振盪」（與 2601.10349 SuS、2507.08210 curiosity-vs-competence 處理的同一病灶）給的是「平穩占用目標 + sink 穩定」這條結構性解法。
  • 最值得記：「最終折扣占用是否均衡」≠「訓練中是否發現很多狀態」——這是評估探索的關鍵分野；以及 sink-state 把『資料外預測 0』改成『可控吸收成本』 來治擴張-崩塌的技巧（與 occupancy 的 resolvent/算子閉式微分一起，是方法亮點）。
  • 與「下游 reward 不可 relabel」的 reward-free 遷移定位（multi-task/meta/continual）契合——這條約束本身值得做這類研究的人記住。
