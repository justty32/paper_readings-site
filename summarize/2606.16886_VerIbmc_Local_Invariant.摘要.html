論文／訪談原始來源

《神經符號軟體驗證：VerIbmc——本地 LLM 強化符號迴圈不變量合成》重點摘要

一句話概括

VerIbmc：一條神經符號迴圈不變量合成管線，把確定性符號不變量列舉＋本地可部署開源權重 LLM（7B–120B）＋ESBMC 驗證器配在一起——「只在必要時升級」三階段（Phase 0 直接驗 → Phase 1 符號列舉原子、零 LLM 呼叫 → Phase 2 由 ESBMC 結構化回饋驅動的 LLM 精修迴圈），在 499 題基準上單一最佳組態（GPT-OSS-120B）解 431 題（86.4%），全程僅靠單機本地、無雲端 API，與昂貴 frontier 雲端工具有競爭力，主打隱私保護、能源高效的工業部署。

解決什麼問題

迴圈不變量合成是形式軟體驗證的核心瓶頸。近期 LLM 神經符號工具求解率亮眼，但依賴專有、昂貴的雲端 API——對「原始碼不能離開組織」的隱私敏感工業部署是門檻，且有成本、可復現性問題。VerIbmc 證明：本地開源權重模型＋符號推理＋ESBMC，就能在不靠 frontier 專有模型下有效做不變量合成。

核心方法（三階段「只在必要時升級」）

  • Phase 0：ESBMC 直接驗未標註程式，若 trivially safe/unsafe 就退出（解 114 題、22.8%）。
  • Phase 1 符號不變量合成（零 LLM）：確定性列舉原子候選 vi⋈vj 或 vi⋈c（⋈∈{<,≤,=,≠,≥,>}），對 |V| 活變數、|C| 常數最多產 6(|V|²+|V|·|C|) 個；ESBMC 判每個原子的歸納性。光是符號合取就解 75 題（15%）零 LLM 呼叫。
  • Phase 2 LLM 精修迴圈：Phase 0 回 unknown 時，反覆「以迴圈原始碼＋當前原子庫（可證 𝒫／可否證 𝒟／未知 𝒰 三庫）＋few-shot 提示 LLM → ESBMC 驗 → 失敗候選拆成子公式、把歸納原子濾進 𝒫 → 測合取 ⋀𝒫 是否整程式驗過」；解析錯誤不罰、續跑。
  • CoT vs ToT 兩種 prompt 策略：ToT 探四種推導風格（歸納含/不含解釋、Hoare 邏輯三元組、Horn 子句編碼），先用 score(s)=(0.6|𝒫ₛ|−0.3|𝒟ₛ|+0.1|𝒰ₛ|)/|聯集| 評分、取 top-2 精修至 R=10 輪、每 6 輪重排。

結果（含數字）

  • 5 模型：GPT-OSS-120B/20B、Qwen2.5-32B/7B、Llama-3.1-8B；5 基準族 520 題（去 21 不可避溢位後 499 有效）：C2I 133、L4I-SVC 99、L4I-SY 84、SVC 154、NL 50；硬體 4× RTX A6000（48GB）、ESBMC v8.2、每題 600s。
  • RQ1 有效性：最佳組態 GPT-OSS-120B（Basic）解 431/499（86.4%）；GPT-OSS-20B 424、Qwen2.5-32B 382、Qwen2.5-7B 352、Llama-3.1-8B 342。Basic（帶符號先驗）全面勝 LLM-Only，對弱模型優勢最大（Llama 307→342，+35）。
  • RQ2 對比 SOTA：完勝傳統符號（CPA-Checker 282、2ls 194、ESBMC-Kind 145）與神經（Code2Inv 210）；在四共享套件上 VerIbmc 346–348（聯集）對 LaM4Inv 338、Clause2Inv 356、LORIS 351；在 SV-COMP 可比子集（43 題）VerIbmc（本地）36/43，逼近 LORIS 39/43、勝 Clause2Inv/LaM4Inv 各 30/43。
  • RQ3 ToT 影響：ToT 多解 49 個 CoT 未解的 （模型，題） 對，但聚合多為負（GPT-OSS-120B 431→421、Llama 342→285），開銷至多 1.40× wall-clock——model-dependent，弱模型反受傷。
  • RQ4 各階段貢獻：Phase 0 114（22.8%）、Phase 1 符號 75（15.0%）、Phase 2 需 LLM 248（49.7%）、永遠未解 62（12.4%）。Phase 1 對弱模型淨增（Llama +36、Qwen-7B +22；GPT-OSS-120B +0，自己就能導同樣原子）。
  • 收斂：65.1% 的 LLM 解在第 1 輪、85.1% 在 5 輪內、88% 在 10 輪內（最多 171 輪）。20 組態間 Jaccard 中位數 0.73；模型身份對變異的貢獻是策略選擇的 3–7×。

局限

  • 整數語意：管線在 ℤ 上推理而非 C 的定寬整數（排除 21 個不可避溢位題）。
  • 非確定性：用 best-of-three / pass@k 協定回報。
  • 基準代表性：限迴圈密集程式；架構雖語言無關但無其他語言實證。
  • 前端限制：與 Clause2Inv/LaM4Inv 的比較受其解析限制（僅單迴圈純量整數程式）。

對讀者的價值

  • 本主題 B 中**「把神經符號形式驗證帶下雲端、用本地開源權重模型」這條務實工程路線的代表**——與 2606.00669（NeuroLog，LLM 事實＋Datalog＋SMT）、2602.18095（Logitext）、2604.27960（LLM＋ASP）對讀，補上「隱私/成本/可復現」這個常被忽略的部署維度。
