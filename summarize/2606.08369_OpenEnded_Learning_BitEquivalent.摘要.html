論文／訪談原始來源

《開放式學習的資訊論定義》重點摘要

一句話概括

開放式學習（open-ended learning）一直缺乏嚴格定義，本文提出一個資訊論定義：引入新概念 bit-equivalent（位元當量） B_ρ＝「達到期望獎勵 ρ 所需的最少環境資訊量（θ 與所選動作 A 的互資訊下確界）」，並把環境定義為開放式（open-ended）＝存在某 agent 能讓平均 bit-equivalent 隨時間「線性成長」B̄_T(π)=Ω(T)；據此證明幾乎所有經典 bandit（有限臂、有限維線性、Gaussian process、甚至無窮臂 i.i.d.）都不是開放式的（即使獎勵無界、動作集無限也不夠），再構造一個確實開放式的環境——無窮維線性-高斯 bandit（"insatiable linear bandit" 永不饜足線性 bandit），並證明一個 Truncated Thompson Sampling（TTS，截斷式湯普森抽樣，逐步擴大「學習目標」維度）能達成開放式學習且此線性率是最優的。

解決什麼問題

近年大量工作（POET、self-improving agents、自動科學發現）追求「能在開放式環境中持續擴展能力」的 AI，但**「開放式」一直沒有融貫定義，也沒有「agent 該如何探索開放式環境」的理論**。先前形式化嘗試（Sigaud et al. 2024、Hughes et al. 2024）以觀察者視角的「novelty（新奇）＋ learnability（可學習）」定義開放式，但作者指出：novelty + learnability 並不能保證 agent 真的透過互動提升能力——一個持續產生新奇且可學習產物的 agent，未必獲得能改善表現的有用資訊。本文要給「什麼環境才算開放式」一個量化、可證明的答案。

核心方法（理論，bandit 設定）

  • bit-equivalent（Def. 1）：期望獎勵 ρ 的位元當量 B_ρ = inf_{A: E[r̄_θ(A)]≥ρ} I(θ;A)——達到該獎勵水準平均所需的「關於環境參數 θ 的資訊量」（以 nat 計）。重點不是「能拿多少獎勵」，而是「要多少有用資訊才拿得到」。
  • 開放式定義（Def. 3）：環境是開放式的 ⟺ 存在 agent π 使平均 bit-equivalent 線性成長 B̄_T(π)=Ω(T)；agent「達成開放式學習」＝實現此線性率。
  • 資訊增益是上界但非充分（Lemma 4）：B̄_T(π) ≤ 資訊增益 γ_T(π)=I(θ;H_T)。故「資訊增益次線性」⇒非開放式（排除有限臂高斯、有限維線性、GP bandit）；但反之不成立——有限臂非高斯噪聲或無窮臂可有「線性甚至無窮資訊增益卻仍非開放式」（資訊不轉化為持續獎勵成長，B̄_T≤log|A| 或 ≤log T 有界）。
  • 構造開放式環境：insatiable linear bandit——動作是有限支撐的無窮維 0/1 向量、θ_i ~ N(−1,1) 獨立、獎勵 ⟨θ,a⟩＋高斯噪聲；其核特徵值不可加總，違反 GP 的譜尾條件，故允許線性資訊增益。
  • 演算法：標準 Thompson Sampling 在此失效（最優動作 sup 為無窮、無有效動作；任何固定截斷 FT 的 B̄_T≤M·log2 有界）。TTS 改為追求「一序列遞增複雜度的學習目標」χ^m=θ_{1:m}（只學前 m 維），用隨時間成長的截斷層級 m_t——既避開完整 TS 的無效性、又突破固定截斷的有界性。

結果

  • Theorem 5–9：有限維線性、有限臂（高斯）、GP bandit 資訊增益 O(d log T)=o(T)，非開放式；有限臂非高斯／無窮臂 i.i.d. 雖資訊增益可無窮，但 B̄_T 仍 ≤log|A| 或 ≤log T，仍非開放式（Table 1 彙整）。結論：無界獎勵與無限動作集都不是開放式的充分條件。
  • Theorem 14（TTS 成功）：insatiable linear bandit 中存在截斷排程使 B̄_T(π_TTS)=Ω(T)，達成開放式學習。
  • Theorem 15（最優性）：任何 agent B̄_T(π)=O(T)，故 TTS 的線性率是最優匹配上界。
  • 變體 insatiable logistic bandit（二元有界獎勵）也是開放式的 → 開放式不需要無界獎勵。

局限

  • 定義與全部結果只適用 bandit（無狀態）設定；延伸到有狀態、非平穩環境是關鍵下一步（作者明列）。
  • TTS 需人為輸入「學習目標序列」（截斷排程） 作為超參，缺乏無需刻意調參的自動設計；GP-UCB 型 agent 或可達成但留待未來。
  • 無窮臂去掉 i.i.d. 假設的情形只給猜想未證。屬純理論（無實驗），實際 deep RL 落地仍遠。

對讀者的價值

  • 本批 D 類中唯一從「形式化定義」切入開放式學習的一篇——把「open-endedness」從工程口號變成可證明的量化準則（bit-equivalent 線性成長），與工程派的 2606.20858（演化發現發育型獎勵排程）、2606.25178（Transfer-Aware 課程）形成「理論地基 vs 實作方法」互補；其 insatiable linear bandit 是「開放式環境」的最小可證明範例。
  • 最值得記的反直覺結論：「無界獎勵＋無限動作」≠ 開放式；真正的關鍵是「持續改善表現是否必須持續取得新的有用資訊」。這把 novelty/learnability 的觀察者視角，換成「資訊→能力」的 agent 視角。
  • 方法層面記住 TTS「逐步擴大學習目標維度」 的配方——呼應課程學習「由簡到難」的精神，但對象是「該學環境的哪一部分」而非「訓練什麼任務」；與 satisficing TS、rate-distortion 學習目標一脈。
