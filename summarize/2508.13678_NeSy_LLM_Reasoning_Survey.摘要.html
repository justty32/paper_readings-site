《神經符號 AI：邁向提升大型語言模型的推理能力》重點摘要

一句話概括

南大 LAMDA 出品的神經符號（NeSy）× LLM 推理綜述：以三大視角——Symbolic→LLM（符號生成資料、LLM 模仿，解決推理資料稀缺）、LLM→Symbolic（符號求解器／程式／工具／搜尋輔助，解決推理函數錯誤）、LLM⊗Symbolic（端到端符號化推理：符號格式化推理、可微符號模組、符號回授）——把「用符號方法補強 LLM 推理」的近期工作分類整理，並指出多模態推理、進階混合架構、理論理解三大開放方向；附 GitHub 資源庫 Awesome-LLM-Reasoning-with-NeSy。

解決什麼問題

LLM 雖在多任務表現亮眼，但複雜推理仍是根本瓶頸——許多研究指出 LLM 只是複製訓練資料中的推理步驟、並非真正推理。如何提升 LLM 推理被視為通往 AGI 的關鍵里程碑。NeSy（結合符號 AI 擅長的複雜推理 + 神經網路擅長的大數據學習，對齊 Kahneman 雙系統理論）是特別有前景的一條路。本文系統梳理「NeSy 如何補強 LLM 推理」。

核心方法（綜述的分類框架）

先形式化推理任務（給定問題與背景知識，經一連串中間推理步驟得答案），再從三大視角組織文獻：

  • Symbolic→LLM（符號助神經）：解決推理資料稀缺。
    • Symbolic Generation, LLM Imitation：用符號引擎自動生成高品質帶推理路徑的資料，LLM 模仿學習。
    • LLM Formalize, Symbolic Augment：LLM 把問題形式化，再用符號方法擴增。
  • LLM→Symbolic（神經助符號）：解決推理函數錯誤（LLM 推理步驟不可靠）。
    • 符號求解器輔助、程式輔助（Program-Aided）、工具輔助（Tool-Aided）、搜尋增強（Search Augmented）——把難算的推理外包給可靠符號元件。
  • LLM⊗Symbolic（混合，端到端推理）：
    • 符號格式化推理（Symbolic Formatted Reasoning）、可微符號模組（Differential Symbolic Module）、符號回授（Symbolic Feedback）。

結果

  • 本文為綜述／立場文（IJCAI Survey Track 風格），無單一實驗數字；貢獻在於清晰的三視角分類法與配套的代表性方法歸位。
  • 一致觀察：NeSy 方法在推理任務上「展現優越表現」，因為把符號元件的可靠推理與 LLM 的泛化學習結合；對齊雙系統理論（System 1 神經直覺 / System 2 符號審慎）。
  • 持續維護的 GitHub 資源庫（Awesome-LLM-Reasoning-with-NeSy）收錄相關論文與資源。

局限

  • 領域發展極快、論文量龐大，無法窮盡覆蓋；作者明言聚焦「關鍵想法與技術路徑」而非全覆蓋。
  • 偏 LLM 推理切面，對傳統 NeSy（如 DeepProbLog 類機率邏輯、感知-推理整合）著墨相對少。
  • 三開放方向（多模態推理、進階混合架構、理論理解）多為展望，缺深入路線圖。

對讀者的價值

  • 本批 A 類綜述中最聚焦「NeSy × LLM 推理」的一篇——與 2502.09100（LLM 邏輯推理綜述）、2505.20313（NeSy 中的推理）互補；三視角分類法（Symbolic→LLM / LLM→Symbolic / LLM⊗Symbolic）是好用的速查框架。
  • 最值得記：「資料稀缺 → 符號生成資料」「函數錯誤 → 符號求解器/程式/工具/搜尋外包」「端到端 → 可微符號模組 + 符號回授」 三條主線；以及把 NeSy 明確錨定在雙系統理論上的論述。
  • 與 2507.09751（健全完備的 NeSy LLM）、2407.10162（ChatLogic）等具體方法可作「綜述—個案」對照閱讀。
  • 定位：分類導向的領域綜述 + 開源資源庫；適合要快速建立「LLM 推理 × 符號」全景、找代表性方法切入點的人。
