論文／訪談原始來源

《SkillSmith：自進化智能體系統的技能–工具共演化》重點摘要

一句話概括

SkillSmith：一個技能–工具聯合共演化框架，引入 Lotka-Volterra 生態動力學追蹤技能間的互補/衝突交互矩陣，以原子 bundle（同時修改技能＋工具）打破「固定工具層」瓶頸，並以**反模式記憶（anti-pattern memory）**防止已知失敗被重複提出。在 OfficeQA、SealQA、WildClawBench 上一致優於僅演化技能的強 baseline，增益隨模型規模（9B→397B）與任務複雜度單調放大。

解決什麼問題

既有技能演化系統（EvoSkill、SkillClaw、Trace2Skill）有三重局限：(1) 工具層被視為固定——由缺失/脆弱/錯誤規格工具造成的失敗迫使系統在技能層過度補償，使技能膨脹且易出錯；(2) 技能效用被獨立評估——假設每個技能的價值彼此獨立，但現實中多技能被同時檢索、組合並應用，技能間會互相干擾；(3) 失敗經驗幾乎不被保留——失敗軌跡在反思時被消費一次即丟棄，只保留成功產物，導致重複診斷已知錯誤、甚至重新生成已被退役的技能。

核心方法

  • 原子 bundle 技能–工具共演化：每次迭代從失敗軌跡生成一個原子級提案 bundle，聯合更新技能與工具。工具演化受限於五種型別化的生命週期操作——WRAP（包裝）、EDIT（編輯）、COMPOSE（組合）、SPLIT（拆分）、RETIRE（退役）——確保受控的工具演化而不爆搜尋空間。原子性保證互相依賴的技能與工具更新同時生效。
  • 協同感知技能生態動力學：以 Lotka-Volterra 競爭–互利方程式為靈感，從執行日誌估計技能交互矩陣 β̂ij（正值＝互補、負值＝衝突）。動態效用更新 uᵢ^{(t+1)} = uᵢ^{(t)} + ε * ûᵢ * uᵢ * (1 − Σⱼ wᵢⱼ * uⱼ / K)，引入承載容量 K 與競爭/互利權重 wᵢⱼ。檢索評分融合語意相關性＋動態效用＋交互相容性＋執行成本。生態壓力訊號指導 mutation 優先級、merge 相容性檢查，以及連續 Tret 輪低效用技能的自動退役。
  • 實例級 Pareto 管理：Pareto 前沿 G 在訓練實例粒度而非總分上維護——一個系統狀態不被淘汰若且唯若它在至少一個訓練實例上是唯一最佳的。合併算子取兩分歧 lineage 各自改動的技能，並對新組合的技能對做生態衝突旗標。
  • 反模式記憶 Ft：結構化儲存失敗簽名 p、因果歸因 a、補救措施 c。雙重作用：(1) 診斷加速——新失敗發生時檢索相似歷史模式，將開放式根本原因分析轉為確認/拒絕已知假設；(2) 提案否決——生成的 bundle 若與已知反模式相似度 > θveto 即被擋下，必須重新修改成不重複已知錯誤的形式。退役技能不直接刪除，而是轉成墓誌銘（epitaph）存入 Ft，防止未來重創等價技能。

結果

  • OfficeQA（246 題，跨文檔表格定位＋多步數值推理）：Qwen3.5-397B 上 80.1%（+18.3% vs Base Agent）；9B→397B 的增益從 +2.8% 單調增至 +18.3%。
  • SealQA（111 題，噪音搜尋環境）：397B 上 49.5%（+18.9% vs Base Agent）。
  • WildClawBench（15–50 步多模態多工具環境）：SkillSmith 持續改進至 Day 6，技能僅演化 baseline 在 Day 2–4 就平台化；工具密集型類別的優勢最大（−6.8% 在僅技能消融）。
  • 消融：鎖定工具層造成最大效能降（WCB −6.8%）；取消生態治理使庫膨脹至 28 組件、檢索精度下降；取消反模式記憶使退化率從 2.1% 三倍增至 7.6%；FreeTool（無型別限制的自由工具生成）雖能修補部分工具，但工具錯誤率激增 4.6×（14.7%）、退化率 8.9%。
  • 長期穩定性（100 輪、兩次環境擾動）：SkillSmith 在工具層崩塌後可重構受損工具並更新依賴技能，恢復至接近 70%，而僅技能 baseline 平台在 30%。

重要洞見

  • 「工具演化不應是自由程式產生」：僅五種型別化生命週期操作 + 原子 bundle 約束，將搜尋分支因子從未約束程式生成的 O(|V|ᴸ) 降到多項式級別（定理 A.2），同時保留共演化能力。
  • 「生態動力學作為治理層」：Lotka-Volterra 更新使技能效用不僅依賴自身表現，也依賴當前族群——自動淘汰冗餘/衝突技能、鼓勵互補組合。
  • 「反模式記憶 = 負向經驗複利」：系統不僅累積「什麼有效」，也累積「什麼應避免」——反模式命中率從 0% 升至 ~35%，使反射 LLM 呼叫在演化後半減少 ~31%。
  • 「聯合最佳化嚴格優於僅技能」：定理 A.1 證明，當存在正測量的硬任務子集需要工具層不具備的能力 c* ∉ span(T₀) 時，聯合最佳化的全域最優嚴格大於僅技能最佳化的理論上界（J*_joint > J*_skill），性能間隙 = ε·PH > 0。

局限

  • 依賴骨幹 LLM 的反思品質（低品質反思產生的不良 bundle 會浪費預算）。
  • 生態模型冷啟動：技能交互矩陣在共現資料稀疏時噪聲大（需要 nmin 累積）。
  • 評估僅限於 QA/搜尋/多工具協調場景，尚未觸及嵌入式或多人代理。

對讀者的價值

  • ai_core「固化引擎」的直接實例：Lotka-Volterra 生態效用模型追蹤技能–工具對偶互動（互補 vs 衝突），並自動觸發退休、拆分或組合——這是 §3.6 固化引擎概念在技能庫層面的可操作機制（哪些技能該固化為確定性工具？哪些該退役？不再是啟發式猜測，而是從執行日誌估計的交互矩陣驅動）。
  • 與 2606.26327 EVOM（LLM 設計代理 + 低保真 PPO 演化 RL 架構）、2606.27243 NOVA（驗證感知多代理 harness + 架構梯度）並讀：三者都是「LLM 代理 + 演化迴圈 + 約束式搜尋」，但 SkillSmith 更聚焦技能與工具的共生關係與生態治理自動化，且以定理證明（A.1–A.2）支撐設計決策——值得做「固化引擎」的人理解其分析框架。
