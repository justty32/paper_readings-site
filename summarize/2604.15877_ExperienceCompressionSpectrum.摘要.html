論文閱讀總覽論文索引深掘綜述訪談

作者：Xing Zhang, Guanghui Wang, Yanwei Cui, Wei Qiu, Ziyuan Li, Bing Zhu, Peiyang He

日期：2026-06

arXiv：2604.15877

論文／訪談原始來源

《經驗壓縮光譜：統一 LLM 代理中的記憶、技能與規則》重點摘要

一句話概括

Experience Compression Spectrum（經驗壓縮光譜）：把代理的「記憶（memory）／技能（skill）／規則（rule）」重新定義為同一條壓縮軸上不同壓縮率的三個點（情節記憶 5–20×、程序技能 50–500×、宣告式規則 1,000×+），主張記憶抽取與技能發現本質是同一種操作——把互動軌跡壓縮成可重用知識，只是粒度不同；用此鏡頭映射 20+ 個系統，揭露每個系統都固定在單一預設壓縮層、沒有任何系統支援自適應跨層壓縮，作者稱此缺口為「missing diagonal（缺失的對角線）」。

解決什麼問題

代理走向長程、多會話部署後累積的經驗會壓垮 context window 與檢索預算，效率化管理成為第一線可擴展性瓶頸。兩個社群（agent memory 與 agent skill）都在解同一問題卻幾乎不互引：對 22 篇主要論文的 1,136 條參考文獻做引用分析，跨社群引用率不到 1%（記憶引技能 0.7%＝4/566；技能引記憶 1.2%＝7/570）。這種割裂反映的是概念鴻溝，限制了可擴展代理系統的設計。本文屬框架/立場論文（scaffold 層，不含訓練時方法如 RLHF、Constitutional AI）。

核心方法

  • 四層形式化（Def 2.1 互動軌跡＝狀態/動作/觀察/回饋序列；Def 2.2 壓縮函數 C_L: 軌跡→知識）：
    • L0 原始軌跡：1:1，幾乎不可重用；L1 情節記憶（「發生了什麼」，鍵值/時間戳事件）5–20×；L2 程序技能（「某類情境該怎麼做」，routine/程式片段/工作流模板）50–500×；L3 宣告式規則（「什麼原則支配決策」，自然語言原則/約束）1,000×+。
  • 三組系統性 trade-off：泛化性↔具體性；壓縮率↔資訊保留；取得成本↔維護成本（L1 便宜取得但規模化維護昂貴＝每天上千條會在數週內耗盡檢索預算；L3 難誘導但緊湊低維護）→ 向上壓縮不只是「想要」而是規模化部署的「必須」。光譜描述的是輸出空間而非固定流水線順序（可 L0 直達 L3，或多層並存）。
  • 映射既有系統（表 2）：10 個系統聚在 L1、8 個在 L2、L3 幾乎空白；ExpeL/AutoAgent 跨 L1–L2 但仍是「固定兩檔」非連續光譜。「missing diagonal」＝沒有系統能：①為軌跡自適應選層、②證據累積時向上升層（多記憶→一技能→一規則）、③規則過抽象時向下降層。

結果

  • 這是概念/立場論文，無自做實驗；結論靠彙整他人 benchmark（表 1）：higher compression → 更好下游表現方向一致——SkillRL 的 L2 技能較 L1 軌跡檢索在 ALFWorld +68.5pp；Trace2Skill L2 較人寫技能 +21.5pp、較無技能 +42.1pp、跨模型 35B→122B +57.7pp；EvoSkill 跨任務 +5.3%。
  • 保真度才是關鍵：SkillsBench 顯示 curated 技能 +16.2pp 但 LLM 自生技能 +0.0pp——「光有壓縮層不夠，壓縮過程的保真度決定產物是有用還是只是緊湊的雜訊」。
  • L3 初步證據：RuleShaping 研究 25,000+ 條規則，發現負向約束（護欄）+7–14pp 而正向指令反傷；Cui et al.（本團隊）示範同一批經驗「有無治理迴路」決定它是低於 zero-shot 還是提升表現。

局限

  • 框架屬概念性、未經實證驗證；四離散層是簡化抽象（實務壓縮可能連續，如 EvolveR 跨 L2/L3）。
  • 為 2026 Q1 快照，領域變動極快；聚焦文字代理（多模態為未來）；提出 4 條可證偽預測（如 L1+L2 多層存應勝單層、transferability–specificity 曲線凹形、L2 為甜蜜點）但尚待實驗確認。

對讀者的價值

  • 直接回應本庫 [../deep/aicore_reliable_function_landscape.md] 所點出的「何時該固化」缺口：本文把「memory/skill/rule」排成單一壓縮軸，並用「missing diagonal」精準命名 ai_core §3.6 固化引擎最硬的兩個未決問題——「壓到哪一層」與「何時升級」。它提供一個現成詞彙：把 LLM 反覆處理的案例從 L1 情節，經 k 次相似後升為 L2 技能，跨域再現後結晶為 L3 規則；若規則在新情境失敗則降級回 L1 重新蒐證。
  • 對 ai_core「資產工廠 vs 資產消費者」與「逐步剃除 LLM 依賴」而言，本光譜給出量化的「剃除梯度」：向上壓縮＝儲存/檢索開銷 100–1,000× 下降、單決策 compute 下降，正是把「貴稀有智能」的一次性抽取轉化為「便宜高頻」可重用資產的軸線。作者提的三原則（層無關壓縮核心／雙向升降級／持續生命週期治理＋閒時鞏固）可直接對照 ai_core 固化引擎的設計骨架；其「負向護欄勝於正向指令」呼應治理＝拒絕為預設。歸 I 類。
  • 值得警惕：本文自己強調「保真度＞壓縮層」（自生技能 +0.0pp）——提醒 ai_core 固化不是把 LLM 輸出存起來就好，抽取品質與生命週期治理（drift、退役）才是成敗根源。
