論文／訪談原始來源

SIRI-Bench: Challenging VLMs’ Spatial Intelligence through Complex Reasoning Tasks 重點摘要

一句話

SIRI-Bench 把立體幾何題的關鍵條件藏進可環視的三維場景影片，只把輔助條件與問題留在文字中，藉此測量 VLM 能否先從視覺取回尺寸、形狀與空間關係，再完成多步數學推理。

基準與生成方法

  • 問題：既有空間智能基準多停在辨識、距離估計或二維圖形推理，難以分辨模型是真能把三維視覺資訊帶進複雜推理，還是只靠文字線索與既有題型作答。
  • 題目改寫：每道立體幾何題被拆成示意圖、幾何類型、主要條件、輔助條件與最終問題五部分。示意圖改成影片；幾何類型、尺寸、平行與垂直等主要條件移出文字，改由三維物件呈現；難以可靠視覺化的輔助條件與最終問題仍保留文字。頂點字母另換成場景中的彩色點，避免命名慣例洩漏立體類型。
  • 自動場景引擎：幾何類型辨識 agent 先判斷主體，數學專家 agent 求出足以唯一決定物件的條件，再把尺寸正規化；程式碼專家 agent 產生 Blender bpy 腳本。後續 agent 刪除應由影片讀出的文字條件、把符號答案轉為數值，並按長度、面積或體積修正縮放後答案。
  • 資料與評量：SIRI-Bench 含 891 組影片、問題與答案；影片長 3 秒、16 fps、解析度 1200×900，題目涵蓋九種常見立體（作者自報）。評量採預測數值相對真值的百分比誤差，目的在同一指標中同時反映空間估計與後續計算錯誤。

作者報告的結果

作者評測多個開放與封閉 VLM，並加入取得完整文字幾何條件的同系 LLM 作為控制組。最佳影片輸入模型 Doubao-1.5-pro 仍有 50％預測的相對誤差超過 100％；開放模型中表現最佳的 Qwen2.5-VL-72B 有 50％預測誤差低於 100％，但僅 10％低於 60％（作者自報）。這不是單純靠擴大參數就消失的問題，InternVL 不同尺寸模型的誤差分布近似。

最有辨識力的實驗是文字與影片控制比較。同系模型在誤差低於 20％的樣本比例上，影片輸入的 12.4％、8.3％、7.4％，分別升至文字輸入的 49.5％、18.4％、27.4％（作者自報）。Doubao-1.5-pro 的文字版本約有 50％預測低於 20％誤差，超過 70％低於 80％誤差（作者自報）。結果支持作者的主要判斷：高階數學推理並非唯一瓶頸，從影片可靠取回空間條件本身就已大量失敗。

小型人類比較也顯示同一差距。受試者在隨機抽取的七題中，超過 30％答案落在 20％誤差內，若放寬到 60％誤差則約能解出 70％；四個受測 VLM 都未達到前者（作者自報）。錯誤按難度與題型拆分後沒有明顯集中，顯示失敗不是只卡在少數困難類別。

結論與局限

論文的結論是，當關鍵幾何條件必須從三維影片取得時，現有 VLM 的複雜推理能力會被空間感知瓶頸拖垮。SIRI-Bench 的貢獻不只是一張排行榜，更是用文字控制組把「看不懂」與「算不出」部分拆開。

（本檔補註，非作者自陳）原文沒有作者自陳的 Limitations 小節（文中 12 處 limitation 講的都是被評測 VLM 的不足），以下為本檔判斷。資料只涵蓋立體幾何、採固定渲染設定，距離真實世界的遮擋、材質與互動仍有落差；891 題（作者自報）規模適中，生成引擎雖可擴充，擴充後的可靠性仍需重新驗證。人類比較只抽七題，不能當作穩健的人類基準。相對誤差把感知與計算壓成單一結果，能顯示端到端失敗，卻不能直接定位是哪一個中間條件先讀錯。

對 ai_core 的價值／接點

這篇最值得 ai_core 借用的是控制變因式診斷。同一道題只改變空間條件的載體，文字版與影片版的差距便成為感知轉譯層的失真證據；對意圖翻譯或多模態 agent 而言，也應保留一條「結構化真值輸入」的控制路徑，否則端到端失敗時只能猜是感知、規劃還是執行出錯。

自動場景引擎則提醒另一件事：多 agent 合成資料不等於資料自動可信。幾何求解、程式碼生成、條件刪除、索引替換與答案縮放各有自己的不變量；ai_core 若把自然語言規則固化成可執行任務，也需要逐階段留下可驗證的中間產物，讓「條件是否真的藏進環境」與「答案是否隨變換正確更新」能分開驗收。
