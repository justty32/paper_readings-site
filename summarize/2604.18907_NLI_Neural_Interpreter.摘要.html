《NLI：Neural Language Interpreter》重點摘要

一句話概括

NLI（Neural Language Interpreter）架起符號與神經程式合成之間的橋：同時學一個離散、類符號的語言（inductor 把輸入輸出對歸納成離散 token 程式）與一個可微的解釋器（interpreter 以遞迴神經程式執行該 token 序列），再用梯度式搜尋在潛在程式空間中優化程式。在 compositional generalization（組合泛化）任務上，NLI 勝過既有神經法、與符號法competitive：在所有基線與非搜尋變體 OOD 準確率近 0% 之處，NLI 梯度搜尋在 Shift-L（長度外推）達 99%、Comp-I（概念組合）達 91%、Shift-P（從複雜程式「反編譯」出原語）達 100%。消融證實「離散序列潛在程式 + 離散解釋器 + 遞迴執行」三者是泛化的關鍵。

解決什麼問題

神經程式合成靈活但組合泛化差（OOD 時崩潰）；符號法泛化強但不靈活、難端到端可微。如何兼得「符號的組合強度」與「神經的靈活性」？關鍵挑戰：在 programming-by-example（只看輸入輸出對）下，做到系統性泛化——長度外推、組合未見過的概念、從複雜程式拆出原語。

核心方法

  • Inductor（離散程式表徵學習，§3.2）：把輸入輸出對編碼成離散 token 序列（類符號程式）；離散性靠 Gumbel-Softmax 等實現。
  • Interpreter（遞迴神經程式執行，§3.3）：一個可微解釋器逐步執行 token 程式——每層（執行步）條件於恰好一個 token，採嚴格遞迴/序列流（這正是其長度泛化的設計來源，致謝 François Chollet 啟發此遞迴架構）。
  • 訓練目標（§3.1）：重建損失 L_rec（解釋器執行程式須重現目標輸出）+ 編碼器正則化損失。
  • 搜尋神經程式（§3.4）：三種推論策略——Base Inference（直接取編碼器輸出）、Prior Search（從編碼器抽樣）、以及主力 Gradient Search（在潛在空間以梯度優化程式）。test-time 梯度搜尋是泛化的關鍵啟用者。

結果

  • 自訂組合泛化套件（固定長度 20，三 split）：所有模型 ID 近完美；OOD 上所有基線（ICL、TTT、LPN、離散 LPN）與 NLI 非搜尋變體近 0%。NLI Gradient Search：Shift-L 99%（從小位移外推到大位移）、Comp-I 91%（合成如複合程式）、Shift-P 100%（只訓練於複雜程式後「反編譯」出原語）。
  • 學到的程式碼展現原語的系統性重用：單次左移恆用 token 231、兩步移恆用 token 476，較大程式由這些積木組合而成；OOD 的八次位移也表示為這些原語的混合——泛化來自重用而非記憶。
  • 消融：移除遞迴執行、或移除 inductor/interpreter 任一的離散性，OOD 準確率崩到近 0%；移除 skip token 降至中等（模型能自學 skip 但專用 token 利更快更穩訓練）；編碼器損失的益處視組合類型而定（對 Shift-P 這種「需表徵原語以組更短程式」有用，對長度外推無影響）。
  • DeepCoder benchmark（組合版）（§4.5）：在擴大原語數與程式複雜度的設定下亦驗證。

局限

  • test-time 潛在搜尋計算成本高是主要瓶頸（雖對過擬合異常穩健、即使受限預算也robust）；擴展到更難問題需更高效推論（作者點名演化/局部搜尋為有望方向）。
  • 問題變難時程式長度與詞彙增大，可能梯度消失/爆炸（實驗未見但大規模或需架構改動）。
  • 當前解釋器表達力受限：每層只條件於一個 token，無法做帶參原語（如 add(k)），執行嚴格序列、無條件分支。

對讀者的價值

  • 本批 G 類**「可微/梯度式程式合成」的代表**——與離散搜尋型的 GP（2501.17168 EvoGP、2504.10253 TinyverseGP）、ARC 的程式歸納（2411.17708 GridCoder、2411.08706 LPN）對照，NLI 走「學一個離散語言 + 可微解釋器 + 潛在空間梯度搜尋」的混合路線，試圖端到端可微地獲得組合泛化。
  • 最值得記：「inductor 出離散 token 程式、interpreter 遞迴可微執行、test-time gradient search 啟用 OOD 泛化」 三件套；以及「離散性 + 遞迴執行是泛化命脈」這個被消融強力支持的結論（拿掉就崩 0%）。
  • 與 2411.08706（LPN，潛在程式網路/潛在搜尋）直接對比且勝出；與 François Chollet 的 ARC/組合泛化議程（1911.01547）一脈相承。
