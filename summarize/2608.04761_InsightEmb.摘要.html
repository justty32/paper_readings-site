論文／訪談原始來源

《InsightEmb》重點摘要

一句話

InsightEmb 學的不是「題目和技能字面像不像」，而是 agent 當前狀態正在卡哪個 action-intent bottleneck，因而該取回哪條抽象規則。

方法

作者把 observation、goal、history 的具體情境與抽象 insight 間的落差稱為 abstraction gap。模型只用公開數學推理資料做兩階段 contrastive 訓練：situation-to-insight 對齊題目／部分 CoT 與啟發式規則；situation-to-experience 讓需要相同進展結構的軌跡靠近。推論時，將目前 agent state 嵌入並動態檢索 insight。

結果與注意版本

原文在 ALFWorld、WebShop、ScienceWorld 與靜態 SRA-Bench 報告優於比較的 reasoning embedders，且不做環境專屬訓練。這批以 v1 日期入庫，但 Fetcher 提供的 HTML/PDF 是現行 v2；文件據其正文撰寫，不把 v2 的修訂誤記為 v1 原始結果。作者也指出 lexical bottleneck 與 MedCalcBench outlier，並以 BM25 hybrid 作有限補救。
