論文／訪談原始來源

Teach the Magnitude, Not the Direction 重點摘要

一句話

CrEST 把多輪多步 agent 訓練的 credit assignment 拆成兩層：turn 級用 verifier reward 決定梯度方向（inter-turn，哪一輪對/錯），token 級用 entropy-gated self-teacher 只調幅度（intra-turn，哪個 token 該加重），因此保留 RLVR 的 verifier-bounded 上限，同時取得 dense token 訊號。

方法

  • 標準 RLVR（GRPO）把單一 trajectory reward 攤給所有 token，多輪 session 裡會把失敗輪的 token 一起獎勵。On-policy self-distillation（OPSD）給 dense 訊號，但 teacher-bounded，且無 per-token KL clip 時約 100 步內因梯度集中到少數 token 而崩潰。
  • CrEST：per-token advantage = turn-segmented GRPO advantage（inter-turn，方向）× 幅度因子 φₜ∈[1, 1+λε]（intra-turn）。φₜ 由 self-teacher（同模型但看得到 ground truth）與 student 的 log-prob 差異 Δₜ 算出，經兩道 gate：direction gate（teacher 與 verifier 方向不一致就整段歸零，這是保住 verifier-bounded 上限的關鍵）、entropy gate（用 token surprisal 的 z-score，把調幅集中在高不確定性內容 token，壓低格式 token 的權重）。
  • 形式化三性質（附錄證明）：方向保持（最終 advantage 符號恆等於 turn advantage 符號）、偏誤有界（‖Bias‖≤λε·‖∇J_GRPO‖，作者於 λ=0.3, ε=0.28 算出約 8.4%）、符號一致放大。只有 λ 需要調，其餘常數固定。

作者報告的結果與限制

作者在 BFCL V3（Qwen3-4B/8B）與 WildToolBench 上報告：CrEST 平均準確率 52.00%（4B）／50.00%（8B），優於 GRPO、MT-GRPO、EnvTuning、OPD、OPSD 全部 baseline；OPSD 在 4B 上（38.75%）甚至低於原始 GRPO（43.63%），作者稱這是 teacher-bounded 上限的直接經驗證據。訓練動態圖顯示 OPSD 前 5% token 吃掉約 77% 梯度量，GRPO 前 10% 約 31%，CrEST 前 10% 約 57%，介於兩者間。Ablation 顯示 inter-turn 與 intra-turn 兩層各自只帶來部分增益（分別 +4.25、+5.12），合併才有 +8.37；拿掉任一 gate 都掉回接近 GRPO 水準。以上均為單一訓練種子、僅在 4B／8B 兩個規模、兩個 benchmark 上的作者自報數字，未做獨立訓練重跑；entropy 作為 token 重要性的代理也承認只是啟發式。

對 ai_core 的價值／接點

CrEST 的「verifier 決方向、teacher 只調幅度」原則，對 ai_core 的 commit-time authority／副作用結算是可直接借用的分工模式：任何已驗證但稀疏的訊號（如 outcome verifier、hard contract check）應該保留對梯度或決策方向的否決權，任何密集但未驗證的訊號（heuristic reward、self-critique、cost 代理）只能拿來調幅度，不能翻轉方向——這正是防止「密集訊號劫持稀疏但可信訊號」的具體工程手法。turn-segmented advantage（同一 trajectory 內失敗輪不牽連成功輪）也對應 ai_core 若要做多步驟任務的逐步結算而非整段算總帳，可作為信用分配設計的參考基準。
