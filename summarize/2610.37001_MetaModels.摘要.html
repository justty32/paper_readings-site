論文／訪談原始來源

Meta Models: Models that Model Learning 重點摘要

一句話概括

作者將歷史神經網路訓練紀錄視為數值表格，用凍結的 TabPFN 從配置及訓練進度預測損失、比較配置與更新預測；在所測條件中表現有競爭力，但仍依賴相關歷史紀錄，尚未證明部署後能節省訓練計算。

問題與方法

作者所稱 meta-model 是對其他模型學習行為作預測的模型：給定歷史訓練配置、進度與觀察結果，查詢新配置在某一進度的損失。重複查詢可形成曲線，對候選配置排序可協助選擇實驗；換成其他目標也可預測下游分數或參數與梯度統計。這些是同一個預測函式的不同查詢，不表示已有不依賴資料的通用學習定律。（§1）

TabPFN 把訓練紀錄作為表格脈絡、待測配置作為查詢；預訓練骨幹權重不因新任務更新，但各任務仍需有標籤的歷史紀錄、任務特定特徵與目標處理。損失預測使用依各資料集擬合的 Chinchilla scaling-law 偏移，預測殘差後再加回。文中的零樣本指不作任務專用權重微調，並非沒有標記脈絡；推論變體依分布內（ID）誤差選擇，分布外（OOD）則包括更大模型。（§2、附錄 B.2.1）

作者自報：離線預測與決策

  • 配置排序：Delphi-HP 在 24 個「模型寬度、batch、token 預算」組合中每次保留一組，從其他 23 組預測該組內的最終 Paloma 損失排序；損失截斷至 6.0。平均 Spearman 相關為 TabPFN 0.967、XGBoost 0.875。候選選擇另以原始損失計算；23 個合格組的平均超額損失為 0.0038 對 0.0254 nats。（§2.1、附錄 B.1）
  • 曲線與下游：曲線查詢不給目標 run 的已觀察損失；在 Marin OOD 的早期階段，TabPFN 的誤差高於重現的 NCPL。MoE 比較中 TabPFN 的 OOD 曲線 MAE 為 0.0326，MoE 微調 NCPL 為 0.1086，但後者介面沒有 expert 欄位，因此不是相同輸入下的骨幹比較。DataDecide 的 750M／1B 下游十項任務 macro-accuracy 預測，使用相同歷史 checkpoint 脈絡，TabPFN OOD MAE 為 1.62、XGBoost 3.40 個百分點；1B 結果仍有低估偏差，目標為最後可用評估，未必是訓練完成結果。（§2.2～2.3、附錄 A.3、附錄 B.5）
  • 接收目標 run 早期結果：七個 Delphi 大規模 run 中，把前 20% 的目標曲線加入歷史脈絡，平均剩餘曲線 MAE 從 0.05787 降至 0.02537 nats，相對下降 56.2%；只有 4／7 個 run 各自改善，因此平均改善不是逐例保證。（§2.4、附錄 B.7、表 7）
  • 離線實驗選擇：StepLaw 的重播讓三種共用 TabPFN 骨幹的策略從相同兩次隨機評估開始，第五次總評估時，12 個 OOD 條件的平均最佳已找到相對 regret，歷史資料、加初始結果但不更新、持續加入觀察分別為 0.13981%、0.04733%、0.03937%。這是已測結果的離線重播，包含兩次初始評估，不能證明實際訓練節省。（附錄 B.8、表 8）

KAN 提供可檢視的座標

兩個小型 KAN 從 StepLaw 訓練組的低損失 run 學出依模型大小與 token 預算變化的學習率、batch 參考值，將配置相對參考值的對數差加入原特徵。它們不讀待測 run 結果，TabPFN 權重也維持凍結。模型大小的 KAN 邊被限制為對數空間線性，因此尺度外推包含人為指定的冪律先驗；學出的關係是此資料的擬合結果，不是普遍定律。（§3、附錄 C.1）

在 StepLaw 較大模型 OOD，作者報告預設 TabPFN 的最終損失／曲線 MAE 為 0.02273 / 0.03666，KAN 路徑為 0.01608 / 0.03093 nats；平均選擇 regret 為 0.4271% → 0.0838%。預設路徑合併 Marin 與 StepLaw 脈絡，KAN 路徑只用 StepLaw；作者另報相同 StepLaw 脈絡的控制，OOD 的三項平均指標亦改善。ID 的配對區間包含零，無法據此判定改善。（§3、附錄 C.1、表 9）

前瞻預測：Marin Hero Run

作者在 2026-08-25 10:38 UTC 以版本控制凍結 V0，使用四個較小 run 的 77 個 checkpoint 與 Hero Run 已完成至 3.84% 的五個評估，預測未來 dropless Paloma macro loss；預註冊在此指版本控制時間戳，並非獨立註冊平台。凍結早於下一次評估，但完整評分規則直到最初兩個後續結果到達後才定案，故不能稱整個評估方案事先登記。（§4、附錄 D.1）

公開 run 於 9 月 24 日被標記中斷；作者評分 14 個後續 checkpoint，最後只到原定訓練的 14.61%。V0 MAE 為 0.0216，標稱 90% 區間涵蓋 14/14；官方 scaling law 為 0.0576，只用較小 run 的 TabPFN 為 0.0788。官方 law 未取得 Hero 前綴，故這不是同資訊量模型比較，也未隔離前綴以外的 ladder 貢獻；14 個同一 run 的點全落區間也不足以建立一般校準。最終完成時預測 2.031、區間 [1.850, 2.455] 尚未驗證。（§4、附錄 D.1）

限制

作者指出，未見資料配方等新機制、辨識不可靠外推，以及在計入試跑、搜尋和適配成本的同預算前瞻實驗中證實更佳決策，仍是未解問題。DataDecide 的配方轉移只測脈絡已有的配方，並非新配方；不同資料集損失定義不同，誤差應在同一資料集內比較。推論時間比較亦不包含基礎模型預訓練成本。（§5、§2.2、附錄 A.4）
