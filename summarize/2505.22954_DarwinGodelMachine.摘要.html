論文／訪談原始來源

《達爾文·哥德爾機（DGM）：自我改進代理的開放式進化》重點摘要

一句話概括

DGM（Darwin Gödel Machine）：一個會改寫自己原始碼的編碼代理——用「經驗驗證取代形式證明」（在 coding benchmark 上實測修改是否變好）＋「達爾文式開放式探索」（維護一座不斷成長的代理檔案庫 archive，從中取樣親代→自我修改→分支出新代理），自動把編碼能力從 SWE-bench 20.0%→50.0%、Polyglot 14.2%→30.7%，且改進可跨模型/跨 benchmark/跨語言遷移，全程在沙箱中進行。

解決什麼問題

今日 AI 系統受困於人類設計的固定架構，無法自主、持續地改進自己；推進 AI 仍重度依賴人工。Schmidhuber 的哥德爾機理論上可「可證明有益地」自我修改，但實務上幾乎無法形式化證明某項修改淨有益。如何讓 AI 在不斷變強解題的同時，無止境地自我改進？

核心方法

  • 放鬆哥德爾機的要求：不要求形式證明，改用經驗證據——在 coding benchmark 上實測新版本是否更好（呼應生物演化：突變不事先驗證，而是產生、試煉、再被天擇）。
  • 自指自我改進：DGM 本身就是一個由 frozen 預訓練 FM 驅動、能讀寫執行程式碼的編碼代理（用 Turing-complete 的 Python）。自我改進＝一項編碼任務＝修改自己的程式庫（工具、prompt、workflow）。關鍵假設：coding benchmark 表現↑ ⟹ 自我修改能力↑。
  • 族群式開放式探索（取自 open-endedness 研究）：從單一初始代理起，建一座累積所有已生成代理的 archive。每輪親代選擇約正比於表現分數、反比於其「具編輯功能子代數」→偏好高分但被探索不足的譜系（兼顧 exploitation 與 exploration），且所有代理保有非零選中機率。親代讀自己的評測日誌→提出下一個要實作的功能→把它當問題敘述執行→改自己程式庫產生新代理。只有能編譯且保留改碼能力者才入庫（其餘丟棄）。
  • 暫存石（stepping stones）：保留「有趣但次優」的解，可能在很久之後才促成突破 → 有別於只沿最佳解爬山的 hill-climbing。
  • 實驗設定：80 次迭代；自我修改階段用 Claude 3.5 Sonnet (New)；評測階段 SWE-bench 用 Claude 3.5 Sonnet (New)、Polyglot 用 o3-mini；分階段評測（10→50→200 題）省算力。

結果

  • SWE-bench Verified：20.0%→50.0%；Polyglot：14.2%→30.7%（全集）。最佳代理媲美已核可的開源 SoTA（SWE-bench）、大幅超越 Aider（Polyglot）。
  • 自動發現的改進：更細粒度的編輯工具（按行檢視、按字串替換）、長上下文管理、多次嘗試 + 用另一 FM 評選最佳解、考慮先前嘗試等 workflow。
  • 兩個組件都不可或缺：DGM 勝過「無自我改進」（=ADAS，早期有效但很快停滯）與「無開放式探索」（只改最新版，一次壞修改就難回頭）兩個 baseline。
  • 遷移性：SWE-bench 上的最佳代理換 FM 仍有效（Claude 3.7 Sonnet：base 19%→DGM 59.5%；o3-mini：23%→33%）；跨 benchmark（SWE→Polyglot 28.9%、Polyglot→SWE 24.5%）與跨語言（Python→其他語言）均保持增益 → 非過擬合。

局限

  • 算力昂貴：單次 SWE-bench run 約 2 週、API 成本高；尚不及閉源 SoTA。
  • 受限於底層 FM 能力（本版未改寫訓練腳本/重訓 FM，留作未來）；目前開放式探索流程本身固定、DGM 不可改。
  • 只專注 coding 領域；以 benchmark 為唯一目標可能放大未被量度的失準（misalignment）、產生越來越難解讀的內部邏輯——故全程沙箱、限時、可追溯譜系、人類監督。

對讀者的價值

  • 本批 D 類「自我進化代理」代表——與同批 2406.18532（符號學習/語言梯度優化 prompt+工具+pipeline）路線不同：DGM 走演化/開放式檔案庫 + 自指改碼，2406.18532 走連結主義類比的反向傳播。兩者都把「代理自我優化」當核心，但 DGM 強調演化探索與暫存石、後者強調整體聯合優化。
  • 最值得記：「經驗驗證取代形式證明」（哥德爾機的務實化）、archive + 親代選擇的開放式探索能跳出欺騙性的局部低谷（圖 3 的兩次 dip 後反超）、自我改進＝改碼任務這個自指閉環、以及改進可跨模型/任務遷移證明非過擬合。
