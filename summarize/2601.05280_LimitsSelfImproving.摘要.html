論文／訪談原始來源

《論 LLM 中自我改進的限制（為何 AGI 仍遙遠）》重點摘要

一句話概括

把 LLM/生成式 AI 的遞迴自我訓練形式化為離散時間動力系統並數學證明：當外部接地（exogenous）訊號比例 αₜ→0（強版奇點/AGI 假設所要求的「自主」狀態），系統必然走向退化不動點——兩種失效模式：(1) 熵衰減（Entropy Decay）（有限取樣致多樣性單調流失）與 (2) 方差放大（Variance Amplification）（失去接地致分布隨機漫步漂移）；這是 KL 類目標下分布學習的架構性不變量。出路：以演算法機率＋程式合成的神經符號整合（CTM/BDM/AID），辨識生成機制而非僅相關性，跳脫只學分布的束縛。

解決什麼問題

奇點假設的核心是遞迴自我改進（AI 改自身→正回饋→智能爆炸）。許多人認為「擴大模型 + 用自生資料訓練」就能觸發。本文直接反駁：訓練於自生資料正是自我毀滅之路——即經驗上已知的模型崩潰（model collapse / 遞迴詛咒）。貢獻是把經驗觀察升級為收斂的形式化證明，並界定其適用範疇（何時必崩、何時不崩）。

核心方法

  • 形式化（定義 1–2）：真分布 P_data；模型在第 t 代為分布 Pₜ；訓練分布為外生與內生的凸組合 P_train = αₜ·P_data + (1−αₜ)·Pₜ；更新算子 = 最小化 KL（等價最大化對數似然）。
  • Theorem 2（純自指 α=0）：熵衰減——有限取樣下高維分布的尾部「統計上不可見」，被指派零機率；熵序列為上鞅，由鞅收斂定理幾乎必然收斂到極小熵（mode collapse）。Corollary 3：由資料處理不等式（DPI），自指迴圈無法增加與 P_data 的互資訊（資訊論意義上封閉，不可能長智能）。
  • Theorem 4（αₜ→0）：方差放大與均值漂移——均值更新成 AR(1) 過程，αₜ→0 時自迴歸係數→1，失去「拉回 P_data」的回復力，退化成隨機漫步，中心因累積隨機誤差漂離真分布。
  • Theorem 5（範疇條件）：若 αₜ 持續有下界（αₜ≥α*>0），無限容量下反而收斂到 P_data；崩潰僅發生於 αₜ→0 的自主狀態。Remark 6：RL+verifier（如 AlphaZero）只在「完美、形式可執行環境」才免疫；若 verifier 是學來的（RLHF reward model）會同樣崩潰，若是靜態 proxy 則遭 Goodhart 定律利用→語意崩潰。多模型集成（Theorem 8）只是延緩，終究收斂到「共識退化分布」。
  • Kant 哲學框架：當前 GenAI 是分析引擎（analytic，重組/內插既有資料），無法產生綜合知識（synthetic，真正新穎的定律/真理）；奇點需要綜合知識生成能力，現範式缺。
  • 出路＝演算法整合：用 Coding Theorem Method（CTM）/BDM/Algorithmic Information Dynamics（AID） 近似演算法機率與 Kolmogorov 複雜度。一步更新拆成三算子組合 U = 統計擬合 ∘ 符號投影 ∘ 因果校正。**符號錨（symbolic anchor）**把連續漂移離散化（程式不能微量漂移，需跳到下一個有效程式，形成位能障壁）；生成式蘊涵讓最小程式重新導出含尾部的整個分布（恢復熵）；由編碼定理，投影到低複雜度程式空間 → 強收縮因子（Proposition 10：以萬有先驗條件化可「跳脫 DPI」恢復隱藏資訊）。

結果（關鍵命題/數字）

  • 不可能性結果是「有條件」而非普世：僅適用 αₜ→0 的閉迴路密度匹配 + KL 類目標。
  • KL 的普世性：cross-entropy = KL、MSE（高斯下）、BCE/logistic、categorical CE、focal/label smoothing、GAN 的 JS divergence 皆屬 KL/f-divergence 家族 → 證明廣泛適用於所有現行 transformer/生成模型訓練。
  • 收縮層級：統計更新只在分布空間收縮（受 DPI 限、無法恢復機制）＜符號更新（投影到低複雜度子空間，更激進）＜因果更新（程式空間直接淘汰不相容機制，最強），由 κ_sym、κ_causal=κ_id·(1−c) 等收縮因子量化。

局限

  • 純理論：無實機實驗，依賴無限容量理想化、KL 目標、可計算簡單機制等假設。
  • CTM/BDM 根植不可計算量（Kolmogorov 複雜度），只能近似；對非演算法簡單的真實世界其錨定效力存疑。
  • 「持續外部接地（αₜ≥α*）即不崩」——故對主張「LLM 仍要人類資料」者，本文反而支持其穩定性；爭點全在「自主性」假設是否成立。
