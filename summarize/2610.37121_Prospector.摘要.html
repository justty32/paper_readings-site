論文／訪談原始來源

Prospector: learning a compact graph traversal policy for scientific reasoning 重點摘要

一句話概括

Prospector 將小型語言模型訓練成逐步走訪文獻知識圖的策略，每一步依工具回傳的邊決定接下來讀什麼，最後附上所見證據。作者報告其在圖生成的問答上可轉移至其他領域，但圖內一致與原始文獻的科學真實性是不同問題。

方法與評估標準

模型只透過三個工具讀圖：find 查節點名稱、expand 讀取節點鄰邊、connect 查已定位節點間的短路徑。每回合最多 20 次工具呼叫、400 條已見邊；最終答案附圖邊。成功判準要求答案屬於題目的答案集合，且引用的每條邊都曾由工具返回、答案出現在引用邊中。這個集合檢查不驗證引用邊是否連成完整路徑，也不驗證圖的抽取正確性、原文上下文或每一步是否足以支持科學結論。（PDF 第 5、11 頁，§3.2、§6.3）

資料集先從圖中抽取不重複節點的路徑，再由教師模型依路徑寫題，答案集合由全圖依該關係序列求出。半導體圖有 195 個保留測試題；另三圖分別有 210、228、223 題。3,971 個訓練題與測試題不共用 gold path，但這不代表節點、文獻或抽取模式完全隔離。圖本身由生成式系統從文獻抽取；三個跨領域圖也採同一抽取管線。（PDF 第 10～11 頁，§6.1～6.2）

以 Qwen3.5-4B 為底座，作者使用 rank-16 LoRA，先在教師示範上監督微調，再進行完整軌跡 GRPO、以成功軌跡重新監督微調，最後從策略自身的關鍵決策狀態做 GRPO。獎勵依圖中答案與引用 gate 給分；答錯時可得部分 gold-path 邊召回獎勵。另訓練 verifier 從多個候選的問題、答案及所引邊評分，與單次策略推論應分開計算。（PDF 第 6～7、12 頁，§3.3、§6.5）

作者自報結果

半導體圖 195 題上，Prospector-4B 單次 greedy 的 gated success 為 0.839±0.015；同樣可使用三工具的 gpt-6-astra 為 0.877，claude-opus-5.5 為 0.846。對八個現成模型，閉卷分數介於 0.154～0.226；先以題目實體選定子圖雖有幫助，仍低於相同模型使用工具的分數，例如 gpt-6-astra 0.477 → 0.877。不同模型的推理設定採各供應者預設，這是所測基準與介面下的比較。（PDF 第 4～5 頁，§3.1）

對每題取樣 32 條軌跡時，195 題中 192 題的候選池至少含一個正確且通過 gate 的答案；訓練 verifier 選出候選的成功率為 0.913，同池多數決為 0.856。候選池的上限、verifier 選擇及單次 greedy 是不同計算預算，不能將 0.913 當成單次策略的結果。（PDF 第 7 頁，§3.3）

凍結後轉移到三個未作策略訓練的圖，Prospector-4B 的 gated success 分別為生物啟發材料 0.803±0.017、PFAS 0.766±0.022、材料性質 0.809±0.011；同工具 gpt-6-astra 分別為 0.857 / 0.846 / 0.865。± 為三次運行的變動；轉移是跨圖與領域，但題目仍按相同的圖路徑生成與 gate 協定。（PDF 第 7 頁，表 1）

工具消融中，移除 connect 的成功率 0.838 與全工具 0.841 接近；移除 expand 降至 0.398。移除工具也改變模型可見工具清單並拒絕其呼叫，所以這是完整系統介面改變下的結果。（PDF 第 5～6 頁，§3.2）

成本與限制

作者以單次 episode、無並行量測 Prospector-4B 在 H200 的速度為每分鐘 10.7 題，MacBook M4 Pro 離線 1.2 題；成本估算則另用租用 GH200 每小時 2.29 美元、並行處理基準 episode，單次推論約每千題 0.57 美元，與供應者公布的 API token 價格比較。速度與成本使用不同併發設定，後者也不能直接當作含模型訓練、圖建立及維護的完整系統成本；32 次候選及 verifier 的成本與單次推論不同。（PDF 第 8 頁，§3.5、圖 5）

作者以線性探針從下一回合生成前的隱狀態預測跟隨、回退或回答，並在部分圖上測試沿方向加向量改變行為；這提供所測模型狀態與行動的關聯及介入證據，不能直接證明其具有可獨立驗證的一般科學理解。（PDF 第 8～9、13 頁，§3.6、§6.6）

作者指出開放式假設生成缺少此處由圖計算的答案集合，仍需額外評估新穎性、機制合理性與實驗價值。私有部署可減少把問題與圖送至外部服務，但前提是模型、圖與工具實際均在受控本機執行；本研究的自動圖抽取及圖內 gate 本身不能保證原始文獻無誤。（PDF 第 9～10 頁，§4）
