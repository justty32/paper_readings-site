論文／訪談原始來源

《ESAA：LLM 軟體工程自主 Agent 的事件溯源架構》重點摘要

一句話概括

ESAA 把 LLM 降為「結構化意圖發射器」：agent 只能輸出符合 JSON Schema 的 agent.result／issue.report，deterministic orchestrator 才能驗證、寫檔、append events、投影 roadmap.json，再以 canonical JSON＋SHA-256 replay 驗證物化狀態。

核心架構

權威 artifacts 是 AGENT_CONTRACT.yaml、append-only activity.jsonl 與由純 projection 產生的 roadmap.json。Output contract 帶 correlation/task/attempt IDs、actor、action、idempotency key 與 patch proposals；path boundary 限定 .roadmap/、src/。Orchestrator 依序 validation、output.rejected、apply effect、append event、reproject、esaa verify。

Event sourcing 與 CQRS 分離 command 與 read model；canonical key sorting／string normalization 排除序列化差異，projection hash 偵測 log 與物化 view 的 divergence。Multi-agent 透過 claim／promote／complete／phase gates 協調，而非共享可任意改寫的 memory。

案例結果

  • Landing page：9 tasks、49 events、三種模型工具組合，output.rejected=0、verify_status=ok。
  • Clinical dashboard：50 tasks、15 phases、7 components、4 個 heterogeneous agents；15 小時產生 86 events。實際完成 31/50 tasks、8/15 phases，所有 30 個 completion records 有 positive acceptance；verify_status=ok (partial)。
  • Overhead：JSON envelope／preamble 每 invocation 約 200–500 tokens；schema＋persistence 每 event 低於一秒；86-event log 約 15KB。

關鍵矛盾與限制

  • 摘要稱兩案例皆以 run.status=success 結束，並稱 clinical case 有「50 tasks、86 events、8 phases」；正文明確說只完成 31/50、8/15，Table 2 標 verify ok (partial)。Replay 正確只證明已記錄狀態一致，不等於專案完成。
  • output.rejected=0 可能表示 contract 有效，也可能是樣本太少／agent 已被 prompt 約束；沒有 unconstrained baseline，不能量化「降低 parsing failure」。
  • n=2、temperature 0、沒有 SWE-bench、human quality 或 failure injection；無法推論 enterprise scalability。
  • Append-only log 將 concurrent events 序列化，但沒有測同檔 conflict resolution、transactional outbox、crash between effect and event，或 side-effect unknown。

證據成熟度：有可檢查 artifacts 的 architecture demonstration；效果與 scalability 證據低。

對 FreePy 的價值

ESAA 與 FreePy 的 event journal、deterministic reducer、idempotency key、projection hash 高度一致。它最值得當最小 vertical slice；同時也清楚暴露下一步：必須把 intent-before-effect、crash injection、effect receipt、lease／attempt fencing 與 partial-goal semantics 補齊，不能把 hash replay 當完整 transaction guarantee。
