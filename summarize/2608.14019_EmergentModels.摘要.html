Emergent Models: Intelligence from Tiny Substrates 重點摘要

一句話

Emergent Models（EM）把建模重新定義成「在極小、固定規則的動力系統上搜尋初始條件」而非「學一個輸入輸出映射」：固定規則＋interface 在 latent space 迭代不定步數，訓練只用演化搜尋改初始狀態（program），理論上可證某些 EM 具 latent universality（規則與 interface 全固定，只換 program 就能實現任意 partial computable function）。

方法：generalised automaton + interface + program-as-search-space

核心構件是一個五／六元組 M=(S,f,H,E,D,⊕)：狀態空間 S（可離散可連續、可有限可無界）、局部轉移規則 f（每步稱 microstep，作用到 halting 為止）、halting 判斷 H、編碼器 E 與解碼器 D 構成的 interface、把初始 program p 與編碼輸入 E(x) 合併的算子 ⊕。推論流程是 s0=p⊕E(x) → 迭代 f 至 halting → D(s_T) 解碼輸出。訓練時把可訓練參數分成 soft parameters（program p，latent、可隨推論改變）與 hard parameters（f／H／interface 中可訓練部分，訓練後在推論期固定）。latent universality（Theorem 1）證明：存在某個 EM，規則與 interface 全固定，僅靠改變有限支撐的 program p 就能對任意 partial computable function g:{0,1}⇀{0,1} 實現 Φ_p=g；配合 Searchability Lemma（Lemma 1），因為合格 program 是有限字串，枚舉／隨機取樣／有限次編輯理論上終能命中。這是對 UTM「固定轉移函數＋固定編碼方案即可跑任意程式」的重述，而非新的可計算性結果。訓練上，EM 高度遞迴、非凸、常是離散的，梯度法不可行，作者一律用世代制族群演化演算法（GA，含 island 遷移／tournament／elitism／crossover／mutation），適應度只看解碼輸出的誤差或 reward，中間 microstep 軌跡完全不受督導；控制任務中沿用「Lamarckian-style state inheritance」：親代被選中時只對 hard parameters 做 crossover/mutation，最終 latent 狀態直接複製給子代。

作者報告的實驗與資料限制

以下皆為作者自報數字（原文 §3）。EM43（1D、4 值、radius-1 CA，程式碼區 Lp=10＋60 條 LUT＝70 參數＝140 bits，訓練域 x∈[0,30]，外推測試域 [30,1000]）：x+1、2x、x mod 4、round(x/3)、x·(1+x mod 2) 五個單輸入任務全部 100% 訓練／100% 測試準確率（8 或 2 個獨立 run 平均），包括週期函數 x mod 4（FFNN 無法全域表示）；雙輸入乘法 a·b（Lp=50，110 參數）在可用算力預算內未收斂，訓練與測試準確率皆差。GoL-EM 算術：固定 Game of Life 規則，只訓練 glider 位置當 program，x±k 一類任務（x-2、x-1、x+1、x+2、x+5，18 格 program、2 個 glider、4 萬次評估）全部 100%/100%；條件式任務（偶數 x+1／奇數 x-1，26 格、3 glider、100 萬次評估）僅 60%/50%，且隨機搜尋與 GA 效果幾乎相同，顯示搜尋地景弱結構化。GoL-EM CartPole（無 state retention，反應式控制）代表性 run：族群平均 return 171.36，最佳 controller 訓練 return 417.20，20 個新 episode 評測 316.90±121.52（隨機基線約 20-25，滿分 500），非 halting 率 54.5%。CEM1D（連續值 1D 格、L=19、內部 T=30 microstep、僅訓練局部係數 a_l,a_c,a_r）：訓練 return 737.32±104.63，1000 個新 rollout 評測 734.93±107.00（滿分 800），但長 rollout 中 cart 位置仍會漂出邊界，顯示未學好位置資訊整合。Meta-Life-Food：CEM2D（35 個 hard params、128 個 soft params，8×8 格）訓練/評測 return 155/133，mRNN baseline（117 hard、12 soft，d=6，僅 T=1 無迭代）150/146，接近打平。Meta-Life-Adapt（線上依 reward 切換 food/poison 策略）：CEM2D meta-score 0.714（reaction-window 0.780、after-reaction 0.699），mRNN 0.822（0.913、0.796），mRNN 約高 15%，兩者皆遠高於隨機基線 0，顯示都能線上調適，但 CEM2D 訓練世代數更多（510 vs 260）收斂更慢。作者明確自陳限制：所有測試的 substrate-interface 組合都未被證明具 latent universality（僅是抽象存在性定理）；EM43 乘法失敗原因無法歸因（算力、超參、interface 或表達力）；GoL 搜尋地景近乎無結構、genotype-to-phenotype 映射脆弱；CEM1D／CEM2D 仍不如 mRNN 穩健；CartPole 與 Meta-Life 環境本身可能被近線性策略解掉，不足以檢驗 EM 相對傳統神經控制器的真實優劣；論文定位為「foundational」，不主張與成熟方法競爭。

對 ai_core 專案的價值／接點

這篇的路線是「參數極小＋演化搜尋＋固定規則迭代」換取全域泛化與精確外推，和 open-ended evolution／符號回歸系走的是同一條軸線：不是擬合資料，而是搜尋能生成資料的規則本身，這對 ai_core 的成本梯度分析有直接參照價值——論文提出的 q=N_params/T̄（參數量對平均時間深度之比）可當成一個具體度量：低 q（小參數、長迭代）偏向壓縮式、規則化解，高 q（大參數、單次前向）偏向記憶式解，換算到 ai_core 語境即是「該把預算花在擴大表示（權重）還是拉長計算（推論步數／重試／迭代精煉）」的量化取捨依據，而不是憑直覺選模型大小。EM43 的「geometric grokking」現象（成功案例中泛化不是藏在不透明權重裡，而是顯現為穩定可讀的時空幾何模式）對驗證器設計有啟發：若某個生成/推理過程真的內化了規則而非記憶答案，其中間軌跡應該呈現出跨規模不變的可解釋結構，這提供了一種「是否真泛化」的間接檢查點，而不只看最終輸出對錯。此外，作者刻意把 hard parameters（規則／interface，訓練後固定）與 soft parameters（program，latent、隨推論可變）分離，並用 Lamarckian inheritance 讓有利的 latent 狀態可跨世代繼承——這和「固化引擎」要解決的問題結構相似：哪些狀態該固化成不變的「硬體」、哪些該留在可塑的運行時記憶裡，可以借鏡其 hard/soft 二分與繼承協定作為固化邊界的設計參考。
