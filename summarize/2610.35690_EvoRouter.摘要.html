論文／訪談原始來源

EvoRouter：從執行經驗學習多代理路由

一句話概括

EvoRouter 為每個任務選模型、技能、子任務與多代理協作配置，透過執行結果訓練路由策略。作者讓專家定期整理有條件的路由經驗，再以特權教師蒸餾學生自身生成的規劃軌跡，並以成功率和成本訓練；所報收益屬特定基準、可用資源池與近似 FLOPs 成本口徑。（§1）

路由與訓練流程

路由器先讀任務和資源描述，產生協作模式、互動輪數與代理列表；每個代理包含模型、技能與子任務。確定性執行器解析計畫並啟動代理，路由器再根據回傳結果產生最終答案；任務驗證器評估答案是否正確。（§3.2、§4.1）

  1. 監督初始化：以凍結的強模型擔任 bootstrap router，收集有效格式且答案正確的示範；以此微調學生，並固定初始化後的策略作正則化參考。（§4.2）
  2. 成本感知強化學習：每題採樣一組軌跡，以驗證成功的 0／1 回饋減去相對任務預算的對數成本懲罰，再做組內相對優勢更新。加權成本懲罰設上限，使成功軌跡獎勵保持正值，失敗軌跡不為正；KL 正則項約束策略偏移。（§4.3）
  3. 洞察與 on-policy 蒸餾：訓練時的專家比較跨任務的配置、結果及成本，歸納適用條件、收緊衝突規則並合併冗餘洞察。凍結教師在學生生成的規劃前綴上額外讀取洞察、配置、執行結果及是否成功，給學生 token 層級的分布監督。學生更新後產生新軌跡，供下一輪洞察整理；部署時不提供這些特權回饋。（§4.4）

研究的先導比較顯示，不同任務對模型和協作方式的需求不同，增加代理或互動輪數未必持續改善表現，同一模型組合在不同協作模式下也可能改變相對排名。這些是作者所測配置上的觀察，不是每次擴張皆無益的定律。（§3.1）

實驗與結果

評估涵蓋五個訓練領域的 19 個資料集，以及未見過的程式生成與邏輯推理兩個領域。作者自建領域內資料集共 12,800 題，分為 10,500／1,000／1,300 訓練、開發與測試題；領域外使用 175 題 LiveCodeBench 與 200 題 BBH-LD。模型池含五個工作模型，協作模式包括單代理、反思、串鏈、全連接與辯論；不同路由基線在可適用處取得相同資源說明。（§5.1、附錄 A）

EvoRouter-4B 的領域內平均比 RCR-Router 高 7.23 個百分點，作者報告工作代理的平均 MAS 成本降低 50.95%，至約 15.28k 相對成本單位。將路由器呼叫也計入後，其總推論成本為 18.94k，較 RCR-Router 低 39.2%；兩個降幅分母與計入範圍不同，不能互換。領域內五個能力類別並非每類都第一，例如 RCR-Router 的 commonsense 為 90.38%，高於 EvoRouter-4B 的 88.46%。（§5.2，表 2、圖 5）

成本是依模型啟用參數量與輸入、輸出 token 估算的相對 FLOPs 代理值；作者忽略注意力交互等項，以最小工作模型每 token 的矩陣運算量為單位。這不是實測延遲、電費或 API 價格，也不包含訓練時專家、教師和收集軌跡的總成本。（附錄 B）

消融與泛化

作者自報，4B 完整系統的領域內正確率為 68.69%；移除洞察為 64.54%，移除 OPD 為 63.23%，只保留 SFT（移除 RL 與 OPD）為 59.77%。領域外相應為 74.67%、70.93%、69.87%、63.20%。這些對照支持各訓練元件在本設定下有貢獻，但成本未對每項消融都同步下降，例如去除洞察的領域外成本略低於完整系統。（§5.3，表 3）

作者另固定已訓練路由器，同時替換模型、協作模式及技能池；在該替換設定下，4B 相對 MasRouter 的領域內／外正確率各高 3.85／7.47 個百分點，工作代理成本分別低 6.7%／18.5%。三個資源池一起替換，無法單靠此結果拆出每一種替換對表現的作用。（§5.4、附錄 A.1）

代價與限制

  • 三個學生基底分別為 Qwen3-4B、Qwen3-8B、Llama-3.1-8B；作者用 2,000 筆過濾示範做兩輪 SFT，後續每題取 16 條 rollout。Qwen／Llama 分別以 Qwen3-32B／Llama-3.1-70B 作教師，DeepSeek-V4-Pro 作洞察專家及 bootstrap router。作者列出八張 A100 80GB 作實驗設備，但所引推論節省不能直接抵銷這些訓練與蒸餾成本。（附錄 A.3）
  • 沒有原生模型選擇的基線固定使用 GLM-5；多模態任務中不支援影像的模型只收到影像不可見的佔位文字。無效配置會被拒絕並記錯；這些實作選擇與可用資源共同界定比較。（附錄 A.1、A.4）
  • 作者將本方法定位於雲端代理服務，尚未處理異質邊緣設備和代理間通訊開銷。本檔補註，非作者自陳：有限測試集與有限次洞察更新支持所報實驗結果，不能證明自我改進必然無限持續，或在其他價格與資源配置下仍有同樣成本優勢。（§6）
