論文／訪談原始來源

《利用可微符號表達式進行高效率的符號策略學習（ESPL）》重點摘要

一句話概括

ESPL（Efficient Symbolic Policy Learning）：用可微符號表達式把 RL 策略表為緊湊符號式，從零端到端梯度學習——免預訓練神經網路、免額外 agent。比 SOTA 符號策略法 DSP 少數千倍環境互動；並擴展到元強化學習（meta-RL）——提出 Contextual Symbolic Policy（CSP） 為未見任務生成符號策略，兼具更高泛化、效率與可解釋潛力。

解決什麼問題

  • DRL 策略（神經網路）參數龐大、巢狀非線性運算多 → 難理解、難在資源受限下部署。
  • 符號策略（變數/常數/運算子組成的符號式）簡潔、低複雜、可解釋、易部署；但既有法：GP 式限簡單任務且需 world model、表現降；DSP（RNN agent + RL 生符號策略）資料效率低（比傳統 RL 多數百倍環境互動）、多維動作需預訓練 NN 當錨模型、複雜到難用於 meta-RL。

方法

  • **符號網路（symbolic network）**＝全套候選符號策略——激活函數＝各種符號運算子、參數＝符號式的常數。
  • 路徑選擇器（path selector）：自適應遮罩不相關連接 → 從符號網路選出緊湊符號形式。
  • 所有模組可微 → 策略表為可微符號表達式 → 可off-policy 梯度下降直接訓練（無需額外 agent）→ 大幅提效。
  • 擴展 meta-RL → CSP（Contextual Symbolic Policy）：結合 ESPL 與 context-based meta-RL（建於 PEARL）——路徑選擇器依 context 變數決定符號形式、參數生成器依 context 生成常數 → 給少量軌跡即為未見任務生成符號策略。

結果

  • 8 個連續控制任務：表現與 NN 策略及既有符號策略相當或更高;比 DSP 少數千倍環境互動（大幅提升符號策略學習的資料效率）。
  • meta-RL（CSP）：比神經網路策略泛化更高、效率更高、有可解釋潛力。

對讀者的價值

  • 本批 C 類最後一篇，也是**「符號 × RL × meta-learning」橋樑**——連接 C（符號迴歸）與 D（meta-learning/演化 RL）；與 2503.06879（Actor-Critic SR 策略）、2509.15929（MCTS）同觸及 RL，但 ESPL 獨特在**「可微符號網路 + 路徑選擇器」端到端學符號策略**（非生成式/搜尋式）。
  • 最值得記：「符號網路（運算子當激活、參數當常數）+ 路徑選擇器（遮罩選緊湊式）→ 全可微 → off-policy 梯度訓練」 的範式（把符號策略學習變成可微優化，免預訓練/額外 agent）；以及 CSP（context 決定符號形式 + 常數）為未見任務生符號策略。
  • 與 2311.02104 對應 D 類的 meta-RL（2101.03958 演化 RL 演算法等）精神相通（學跨任務共享結構）。
