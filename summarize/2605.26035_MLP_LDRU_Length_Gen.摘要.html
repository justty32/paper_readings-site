論文／訪談原始來源

《以對數深度遞迴單元達成長度泛化》重點摘要

一句話概括

MLP-LDRU：一種「對數深度遞迴單元（Log-Depth Recurrent Unit）」——用一個帶閘控、初始化偏向「近似結合律＋單位元」的二元算子，在平衡二元樹上做平行歸約（parallel reduction）來逼近遞迴，把整條序列以均勻 O(log n) 計算深度壓成單一嵌入；藉此同時避開 RNN 的位置偏差與 Transformer 的固定深度限制，在 21 個正規語言任務上18 個達 100% 分佈外（OOD）準確率、其餘 3 個 ≥99.9%，勝過可比的遞迴與注意力模型。

解決什麼問題

長度泛化（推廣到比訓練更長的序列）是神經網路長期難題。正規語言（regular language）是常用試驗場——因可在任意長度精確驗證標籤、直連自動機理論。既有兩派各有短板：RNN 提供長度自適應計算但較早 token 經更多遞迴步 → 位置偏差／長程記憶問題；Transformer 套固定層數、不隨長度變，OOD 長度泛化不可靠。理論已知（Ladner-Fischer 1980、Blelloch 1990）：有了結合律算子，平行歸約可給遞迴一個對數深度實作，但這類「算子層級的約束」尚未被充分探索。

核心方法

  • LDRU 類：把 token 嵌入透過一個二元算子 ⊙_θ 在平衡樹上組合；歸約得對每個 token 均勻的 O(log n) 計算深度，緩解 RNN 的位置偏差，又能平行算卻表現得像沿序列的遞迴。動機＝正規語言的幺半群（monoid）視角：串接對應一個結合性乘積，若學到的算子近似結合律，當歸約算子用即近似序列遞迴。
  • MLP-LDRU 的算子 ⊙_θ：核心是逐元素加總（天然結合）＋學習的閘控控制資訊流。對輸入 h_i, h_j：用 MLP 從 [h_i;h_j] 產生閘 g_i,g_j；f = V(g∘h)+b；輸出 = W_out(f_i+f_j)+b_out。V_i、V_j、W_out 全用單位矩陣初始化、偏置歸零 → 與逐元素加總一起把算子偏向近似結合。3 層 MLP、擴張因子 (1,2,1)。
  • 單位元處理：序列長為奇數時補零嵌入 0；把 0 當中性佔位元（任一輸入為 0 則輸出另一輸入＝跳過組合），免得 ⊙_θ 還要去學恆等映射，也避免 padding 偽影。每步：算子→殘差 FFN→LayerNorm，步間權重共享，並加 dropout（經驗上助泛化）。
  • 複雜度：O(n·d²) 工作量、O(log n) 深度——兼具 RNN 的線性擴張與對數時間平行；對比 RNN 的 O(n) 序列深度、Transformer 的 O(n²d+nd²)。
  • 新貢獻 — prefix languages：一類新正規任務，專門隔離「長度外推下的長程依賴處理」。

結果（OOD 準確率，訓練長度 1–40、測試 41–500）

  • 21 個正規任務：MLP-LDRU 18 個達 100%、其餘 3 個 ≥99.9%；多種子均值±標準差。
  • 全面勝過或匹敵 baseline：勝過 3 種 Transformer 變體（除 D₈、D₁₂ 對 ∼RoPE）；∼RoPE 雖在 D₁₂ 最強卻不穩定（Modular Arithmetic 僅 31.4% vs NoPE 76.0%、ALiBi 54.4%）。Gated DeltaNet（及附錄 S5、SD-SSM 兩 SSM）從未在任何任務超越 MLP-LDRU；亦勝 RegularGPT，匹敵或超越 RNN（除 D₈，差距不顯著）、LSTM、BBT-GRC。
  • 例：Even Pairs / Modular Arithmetic / Parity Check / Cycle Navigation 皆 100.0±0.0；多數 Transformer/SSM 在 Cycle Navigation、Parity 退化到 ~20–50%（接近隨機）。
  • 超出正規語言：在 ListOps（測組合外推）與多個 NLP 分類 benchmark 上表現具競爭力。剩餘失敗經分析源於訓練資料對幺半群組合覆蓋不足，而非架構限制。

局限

  • 主戰場是正規語言/合成任務；自然語言上只是「具競爭力」，非全面領先。
  • 偏向近似結合律是歸納偏置，對本質非結合的任務未必適配；少數任務（D₆/D₈/D₁₂）未達滿分。
  • 平行歸約假設可平衡樹化，對極長序列的記憶體/實作開銷需 D 節討論。

對讀者的價值

  • [[長度泛化]] 的乾淨架構解：把「結合律歸納偏置 + 對數深度平行歸約」做成可學算子，是介於 RNN 與 Transformer 之間的第三條路，與本批 2604.25800（Transformer + CoT 在標準位置編碼下長度泛化受限於 TC⁰）、2603.01959（對角 SSM 狀態追蹤極限）形成「誰能可靠長度泛化」的對照群。
  • 最值得記：幺半群/結合律視角把正規語言長度泛化講清楚；用單位矩陣初始化把算子偏向結合這個簡單可複製的技巧；以及「剩餘失敗來自資料覆蓋而非架構」的誠實診斷。
