論文／訪談原始來源

《Self-Evolving Neuro-Symbolic Skills》重點摘要

一句話

NeSy-Spatial 將空間 agent 的工具呼叫與幾何計算拆成有型別、可執行原子指令，再從成功與失敗軌跡演化出可取回的 Tool-Use 與 Geometry skills。

問題與設計

從零規劃工具序列很彈性，卻會違反前置依賴；固定 pipeline 雖安全，卻常多跑工具又難跨題。本文的 skill library 有原子 A 和高階 skill S：前者包含輸入輸出型別、前置條件、執行器與局部 verifier；後者是依賴圖。Tool-Use Skill 編排外部工具，Geometry Skill 則編排座標轉換、距離、檢查等可執行幾何步驟。

推論與演化

推論時檢索、具現並閉環執行 skill，根據中間證據決定下一步。每累積 20 條軌跡，分析器從成功及失敗萃取可支持／無效的片段，fusion 模組增補、取代或編輯 library；pruning 則依局部驗證失敗率、使用次數、閒置年齡與 tenure 刪除不可靠項，並修復依賴它們的 skill。

結果與界限

作者在 MMSI、MindCube、OmniSpatial，以 GPT-5.4 和 Gemini 2.5 Pro 評估；宣稱六個 backbone–dataset setting 中五個 Overall accuracy 最佳。另報 GPT-5.4 的平均 FTCS 94.56、Python success 95.45；數字是作者線上 prequential 評估，並非獨立驗證。系統仍依賴工具介面、verifier、初始 seed skills 和 LLM 對軌跡的分析品質。
