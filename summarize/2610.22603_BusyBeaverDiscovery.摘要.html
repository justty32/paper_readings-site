論文／訪談原始來源

Busy Beaver Discovery：用agent發現並形式驗證機器的算術加速規則

一句話概括

作者把Turing machine執行軌跡壓成有參數的tape patterns，讓Gemini寫可執行的macro-transition猜想、主動測邊界、以非形式證明迭代，再用可修改定理陳述的Lean agent證明每條規則與整個系統closure。主要成果是十一台BB(6)機器的全新、形式驗證Collatz-like accelerations；它們的blank-tape halting問題被精確轉成算術trajectory是否到達halting條件，仍未解出halting／non-halting，也未求得BB(6)。Cryptid分類暫定且待community acceptance。（§1、§6）

Busy Beaver、holdout與Cryptid的分別

BB(n,m)取n-state／m-symbol TM在blank tape上、所有會halt者的最大步數，二symbol慣寫BB(n)。Holdout僅指blank-tape halting未決。本文Definition2.1把Cryptid定為：有exact compact dynamical-system描述、但該trajectory是否到達halt仍未決的holdout；這比社群通常還要求對應數學問題「真正open且困難」更寬，因此新分類須社群接受。（§2.1–2.2）

Collatz-like指block exponents依parity／congruence選不同乘加分支，不等於已證等價於標準3x+1 conjecture。Generalized Collatz reachability不可判定也不證明任一具體BB(6)機器獨立於ZFC；作者明說接近provability frontier僅推測。加速替換多個raw steps，揭露結構，不能單憑簡單規則推論長期行為容易。（§2.2）

四階段管線與規格

1. Pattern detection：先無損壓縮，再抽象

每machine先模擬\(S=5\times10^6\)steps，記tape、head position與state。有限tape的head兩側各自從外端向head掃，保head marker及無限blank regions；以block repetition count／block length為simplicity score，優先短且重複多的block。一個lookahead比較留n或n−1個copies的當前加下一block coverage，只有後者嚴格較大才退一copy。預設compression search parameter16，因此candidate blocks最長8symbols；這個參數不是top-pattern數100。（§3.1、附錄D）

Compression展開可重建原configuration；接著移除exponent數值，以block symbols、state與head direction形成pattern family，再按包含的unique configurations數排序取top100patterns。具體到抽象兩步不同：前者無損表示、後者把多個實例歸同族。（§3.1、§4.1）

2. 可執行猜想與interactive refinement

對每pattern，從trace擷取同pattern相鄰出現的exponent-vector轉移，不是相鄰raw TM step；LLM寫Python函式預測下一組exponents。初猜可能在observed trajectory上全對仍漏分支，例如Antihydra在first exponent0、末exponent奇數時應halt，初程式卻產negative exponent。（§3.2）

LLM可指定synthetic exponents直接初始化該pattern，測即使尚不知是否blank-reachable的boundary cases；工具跑到重返target pattern、halt或每transition128000steps上限，最多5refinement turns。末尾改寫為piecewise math，可能再代數合成多步加速。**所有已記錄的初始及synthetic transitions預測100%**才進證明，這是有限資料filter，不能代替全參數proof。（§3.3–3.4、§4.1）

3. Informal proving：同模型三個角色

逐case rule追蹤抽象tape，Proof Generator寫step-by-step proof；Correctness與Format Evaluators各給0／.5／1及feedback。只有兩者皆1才接受，最多4iterations／rule；同Gemini3.1Pro扮三role，並非三個獨立模型投票或kernel guarantee。（§3.4、§4.1）

4. Lean formal proving：允許修命題，固定機器與起點

沿BusyLean定義／lemmas，給agent初始equivalence、closure與halting／non-halting theorem statements及informal proofs作scaffold。初始命題不是不可更動的ground truth：Problem Setter可補parameter bounds、加缺失boundary rules；Planner拆lemmas協調，Writer證明，Critic審formalization／proof，四persona在shared workspace round-robin。Compiler／Writer／Critic feedback可回Setter，simulation也可再查規則。（§3.5）

改動僅限rules，Lean machine definition與start configuration固定；start從blank tape直接simulation核對。有效系統須每rule對固定machine證明，且start與每rule output要麼halt、要麼match某rule input，構成closed system。不得靠false hypotheses把命題變空；成功條件為Critic確認所有必要theorems編譯、無sorry及unauthorized axioms，否則到72h限時失敗。本文核心環境為Gemini3.1Pro與Lean4.28.1。初始化含halting statements不表示最終已解Cryptid halting；主要證成的是acceleration及closure。（§3.5、§4.1）

新規則的具體例子：有closed description仍未解halt

附錄A.9的machine為1RB1RC_1LC1LC_1RE0LD_1LB1RF_---1RA_0RD1RD。先以兩family \(C_0,C_1\)描述，再以\(C_0(a,b,c)=C(2a,b,c)\)、\(C_1(a,b,c)=C(2a+1,b,c)\)合併成

\[C(a,b,c)=0^\infty1^{a+2}\mathrm{E}{>}1^{2b+2}01^{2c+2}0^\infty.\]

Blank tape經100raw steps到\(C(5,2,0)\)。七條simplified rules中包括\(C(a,b+1,c+1)\to C(a+6,b,c)\)與\(C(a,0,0)\to Halt\)，另依首參數parity及其他零邊界分支。這些例子僅節選，完整系統在原附錄；「存在halt branch」不等於這個start trajectory必會走到該branch。其他新systems也保留parity、下界或有限parameter集合，如A.11的\(d\in\{3,6\}\)，不可省掉條件後當普遍規則。（A.9、A.11）

Rediscovery到底新增什麼

附錄B按和社群rules的關係分：Exact2（up to renaming等，新增formal closure proof）；Equivalent reformulated8（同dynamics、family／acceleration level改寫，社群higher-level exponential formulations未證）；Different decomposition3（partial／conditional community system或不同加速層）；Undetermined2（Discord rules未能reproduce）。Correspondences是direct simulation核對，不等同所有equivalence皆另外Lean證成。BMO1原rules已在Lean證過，故主文「先前未形式驗證」概述不可套到每台；有些成果是替代proof／decomposition。（附錄B，表3、表1）

意義與作者限制

價值是把empirical code synthesis接到可修正規格的formal closure，不只讓LLM給看似合理的數學敘述；synthetic counterexample queries能查blank trajectory未露出的case。Grey-box exploration不直接靠TM source code推猜，作者說原理可延伸Python／C++等Turing-complete語言；本文未提供那些domain的實驗。（§1、§3；最後一句為本檔補註，非作者自陳）

作者承認現在仍不是完全open-ended：只找人類已研究的Collatz-like functions；未展示自主發明全新open-problem類型。Busy Beaver可不斷生題，不保證每題的廣泛數學重要性，也不保證研究這些Cryptids能解標準Collatz。十一新reduction是形式化結構發現的進展，不能寫成跨越不可計算性、解決ZFC獨立性或證出BB(6)。（§6；最後一項界線為本檔補註，非作者自陳）
