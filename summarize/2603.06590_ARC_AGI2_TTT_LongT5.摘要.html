論文／訪談原始來源

《ARC-AGI-2 技術報告：LongT5 + 測試時訓練 + 對稱多視角》重點摘要

一句話概括

一支 Kaggle 隊伍的完整解法報告（非官方 benchmark 報告）：把 ARC 視為序列建模，用僅 125 token 的緊湊任務編碼 + 改造的 LongT5 編碼器-解碼器（200M 參數），靠四根支柱——①對稱性/遍歷/細胞自動機資料增強②測試時訓練（TTT）+ 輕量 LoRA逐題專化③對稱感知的解碼與評分（聚合多增強視角的似然＝「多視角推理」）④符號先驗過濾——在 ARC-AGI-2 半私有評測集達 27%。報告最珍貴處是一張清楚的增量歸因表：從 llama 1B 的 3.75% 一路加技術到 27.08%，每招貢獻幾個百分點都列出來。

解決什麼問題

ARC 要求從極少範例推出符號規則、且像素級全對才算對（一個 token 錯整題零分）。如何在 Kaggle 嚴格的執行時間/算力預算內，用一個小神經模型逼近人類級泛化？

核心方法（四支柱 + 流水線）

  • 緊湊編碼：每個任務序列化成僅 125 token（多示範對串接時最長約 10,000 token），用 LongT5（transient global attention）做高效長上下文處理 + 整合 FlashAttention 加速。
  • 注入先驗 / 資料增強：
    • 符號過濾：顏色一致性、網格尺寸一致性、包含性過濾，砍掉不合理候選。
    • 對稱增強：群對稱（旋轉/反射/轉置）。
    • 遍歷先驗：把網格序列化成「逐行（RbR）」與「蛇形（zig-zag）」兩種遍歷，當作表示層增強。
    • 細胞自動機擾動：用可局部反演的 CA 生成增強樣本（含「共軛技巧」）。
  • 三階段增強分工：TTT 用 AE、候選生成用 AEIDR、評分用 AEI。
  • 測試時訓練（TTT）：對每個未見任務，用該任務示範對的增強資料做 LoRA（r=8、35 epoch、lr=8e-4）微調，加上任務專屬外部記憶做跨任務檢索，局部專化又不災難性遺忘。
  • 離線訓練技巧：課程學習、UL2 遮罩去噪多任務訓練（「training to understand」）、以及grokking（延長訓練到泛化突現）。
  • 對稱感知評分：對候選在多種對稱條件視角下做前向，聚合似然算每像素信心分；ARC 取分數最高的 2 個候選作答。

結果（增量歸因，半私有/Kaggle）

  • 最終：200M LongT5 → 半私有評測集 27%（受算力約束下具競爭力）。
  • 增量歷程（同隊自報）：llama3.1 1B 3.75% → 調參 5.00% → 換 LongT5 7.08% → 跑全資料集 12.08% → 加 grokking 19.86% → 加 2-遍歷 25.00% → 加多任務 UL2 27.08%。
  • 單招絕對增益：遍歷 +6.14%、grokking +5.14%、UL2 多任務 +2.08%、HPC 優化（架構換 + FlashAttention 等）使 5%→12.08%（+7.08%）。
  • 解碼：beam search 優於 BFS/DFS（後者即便閾值降到 1% 仍低約 0.5–1%）；真解有時以僅 0.1% 機率出現於某個剛性變換。
  • 相關工作對比表：2024 ARC Prize 第二名 fine-tune Mistral-NeMo-Minitron-8B 達 hidden 56.5%；第三名 Qwen2.5-0.5B 達 40%（單獨 LLM 33%）。

局限

  • 半私有集 27% 仍遠低於人類；ARC-AGI-2 需多重組合規則，純神經序列模型仍吃力。
  • BARC 大資料集因雜訊高、含缺乏人類可解邏輯的任務而被排除——顯示對資料品質極敏感。
  • 因 Kaggle 測試集未公開，論文所有數字是在自製 177 個人工任務上計算（非官方私有集）。
  • TTT 每題需即時 LoRA 微調，計算成本高、需大量 HPC 工程才塞進時間預算。

對讀者的價值

  • 本批 E 類中最完整的「TTT + 神經序列模型」工程實戰範本——把編碼、增強、TTT/LoRA、grokking、UL2、對稱評分、beam vs BFS/DFS 全部攤開講，含真實的增量歸因，極適合想復刻或改進 ARC 神經解法的人。
  • 與 2601.10904（2025 報告，把 TTT 列為冠軍主路）互為總綱與實作；與 2411.07279（TTT 少樣本理論）、2505.07859（Product of Experts、多視角評分）、2411.08706 LPN、2411.02272（歸納 vs 轉導）同屬「神經 ARC」家族；與 2512.06104 CompressARC、2511.14761 VARC 形成「TTT 預訓練大模型 vs 零預訓練小模型」對照。
  • 最值得記：「多視角推理」＝同一候選在多種對稱/遍歷視角下聚合似然；grokking 與 UL2 去噪是被低估的離線增益來源；beam search 比 BFS/DFS 更能撈到低機率真解；以及「每招貢獻幾個百分點」這種誠實的工程歸因。
