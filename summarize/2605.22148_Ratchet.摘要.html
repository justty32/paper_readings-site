作者：Xing Zhang, Yanwei Cui, Guanghui Wang, Ziyuan Li, Wei Qiu, Bing Zhu, Peiyang He（AWS Generative AI Innovation Center, HSBC）

日期：2026-05，智能體技能庫生命週期管理

論文／訪談原始來源

《Ratchet：自演化 LLM 智能體的最小衛生食譜》重點摘要

一句話概括

Ratchet 是一個單智能體迴圈，讓凍結的 LLM 自行撰寫、檢索、策展、退役自然語言技能，用四項衛生機制（outcome-driven retirement、bounded active-cap、meta-skill authoring prior、pattern canonicalisation）把自演化技能庫的瓶頸從「作者品質」轉移到「圖書館員（生命週期管理）」。在 MBPP+ hard-100 上，pass@1 從 0.258 提升到晚窗口滾動平均 0.584（+0.328），而無技能控制組僅 +0.002；同一配方轉移到 SWE-bench Verified 的 agentic solver 亦獲 +0.22 峰值提升。八項消融實驗揭示：退休機制與 meta-skill 作者先驗是承重組件，顯式去重在此規模被 meta-skill 取代。

解決什麼問題

SkillsBench（2026）的關鍵發現：LLM 自產技能對無技能基線的增益是 +0.0pp，而人類策展技能達 +16.2pp——瓶頸不是技能作者（LLM），而是圖書館員（生命週期管理：版本控制、衝突檢測、廢棄）。既有系統（Voyager、ExpeL、AutoManual 等）的技能庫無節制成長，導致庫漂移（library drift）——有效品質因未受控的膨脹、冗餘或不成熟修剪而退化。Ratchet 證明：只要修好圖書館員，同一個凍結作者就能產出有用的自演化技能庫。

核心方法

  • 四項衛生機制：
    1. Outcome-driven retirement（結果驅動退役）：每個技能累積足夠證據（Nmin ≥ 100 次試驗）後，若貢獻分數 ĉ(s) = （成功 − 失敗）/試驗次數 ≤ −τ（τ = 0.10），則退役。不是啟發式規則，而是實證結果驅動。
    2. Bounded active-cap（受限活躍容量）：ACTIVE 技能上限 C = 50，迫使技能競爭 Router 的短名單，避免檢索品質隨庫增大而退化。
    3. Meta-skill authoring prior（後設技能作者先驗）：一個 Markdown 文件（含 schema lock + ## Do / ## Don't 風格指引），約束 Synthesizer 產出風格一致的技能，隱含去重。
    4. Pattern canonicalisation（模式正規化）：union-find 合併餘弦相似度 ≥ 0.85 的 Critic 模式標籤，使同一個 bug 的兩種失敗描述產出一個技能而非兩個。
  • 單一凍結 LLM 扮演五個角色：Router（選 0 或 1 個技能注入 Solver）、Solver（LLM + 技能 → 程式碼）、Grader（評分 pass/fail）、Critic（對失敗 capsule 產出 verdict: HELPED/HURT/NEUTRAL/INAPPLICABLE + 模式標籤）、Synthesizer（從失敗群集產出新技能）、Curator（依貢獻分數退役技能）。
  • 資料模型：Skill（YAML，含 intent、guidance、狀態旗標、embedding）、Meta-Skill（Markdown，每評估套件一個）、Capsule（每 （任務， 技能， 嘗試） 三元組的 pass/fail 記錄）、Verdict（Critic 對失敗 capsule 的歸因標籤）。全部附加寫入不會刪除，退役只改狀態旗標。
  • 非發散保證（Proposition 1）：證明有界 active-cap C 與退休門檻 τ 足以防止期望效能跌破無技能下限超過有限邊際 τ + ε + Cδ；無界 C 與無 τ 的系統（如 Voyager）沒有此有限類比。

關鍵發現/數據

  • MBPP+ hard-100（100 輪，3 種子，Claude Opus 4.7）：Default 配置的滾動增益 +0.328 ± 0.018（baseline 0.258 → 峰值 0.658 ± 0.042）；無技能控制組（A1）+0.002 ± 0.005。
  • SWE-bench Verified hard-150（20 輪，agentic Claude Code）：峰值 +0.22 lift（0.65 → 0.87），驗證配方可轉移到多步驟工具使用型智能體。
  • 八項消融（A1–A8）：
    • 承重組件：移除 meta-skill（A3）剩 +0.187（−0.141）；嚴苛退休（A4, Nmin=20, τ=0.0）掉到 −0.019，比無技能更差——驗證證據地板不可或缺。
    • 非必要組件：移除正規化（A5）+0.374、移除 cover-guard（A6）+0.363——在此規模 meta-skill 的作者先驗已足夠隱含去重，顯式過濾器的誤殺代價超過過濾收益。
    • 邊際增益：加倍容量（A7, C=100）+0.317（變異更大）、meta-synth 刷新（A8）+0.372（但 wall-time +55%）。
  • 技能庫動態：Default 產 ∼152 技能，89 被退休，50 維持 ACTIVE；Router 在 ∼73% 的 eval 任務中注入技能。

局限

  • 放大器非發現者：權重凍結，Ratchet 重定向既有能力但無法教導真正新知識；pass@k 預期不變。
  • 範圍：SWE-bench 僅 20 輪（初步）；單模型單供應商；Critic 雜訊可固化為持久技能（用閉合標籤集緩解但缺校準）；退休測量相關性非因果。

對讀者的價值（ai_core 接點）

  • 直接對應 （內部參照） 的 §3.6 固化引擎：Ratchet 的 outcome-driven retirement + bounded active-cap 正是 §3.6 需要的「退役/收斂」機制——既有文獻（Voyager、ExpeL、AutoSkill）都只做技能新增，不做實證淘汰。Proposition 1 的非發散保證為固化引擎提供了形式化基礎：只要有限容量與有限證據門檻，期望效能就不會發散。八項消融清楚畫出「哪些是承重的、哪些在此規模可省略」，是 §3.6 實作優先級的直接依據。
  • 與 2605.24050（Skill Shadowing，不退休的代價）成對閱讀：Ratchet 證明「退休必要」，Skill Shadowing 證明「不退休累積什麼代價」。
  • 貢獻分數 ĉ(s) = （成功−失敗）/試驗 是 §3.4 憑證准入在「技能級別」的直接實例——每技能帶實證記錄，退役決策可審計。
  • 定位：自演化智能體基礎設施論文 + 完整消融 + 形式化保證 + 可復現附錄，適合做智能體技能庫、終身學習、LLM 自我改進系統的人。
