作者：Sudhanva Kulkarni（Tanglin Trust School, Singapore）

日期：2025-01；H 類 Kolmogorov-Arnold Networks（KAN）

arXiv：2501.17896

論文／訪談原始來源

《可解釋機器學習：KAN 於翼型升力預測》重點摘要

一句話概括

把新提出、內建可解釋性的 Kolmogorov-Arnold Network（KAN） 與五個常用監督式 ML 模型一起套到航太工程的翼型升力係數 C_L 預測問題上：KAN 在測試集達 R²=96.17% 為最佳（勝基線 ANN 與 MLP），再透過剪枝（pruning）+ 符號化（symbolification） 把模型化為一條「C_L 對輸入變數」的封閉形式方程，且擷取出的可解釋資訊與已知的升力物理一致，展示 KAN 輔助科學探索的潛力。

解決什麼問題

資料科學已成科學探索的「第四範式」，但多數 ML 模型是黑箱，難以從資料生成新知識。既有 XAI（如 LIME、SHAP）多只解釋個別預測而非整個模型，難以追溯模型每一階段學習的因果。本文用 KAN（內嵌 XAI）示範一個既準確又可全程解釋的模型，並驗證其解釋是否符合物理。

核心方法

  • KAN 原理：基於 Kolmogorov-Arnold 表示定理（任何多變數複雜函數可分解為較簡單函數之和）。結構似 MLP，但三點關鍵不同：
    1. 激活函數在邊（edges）上（為 B-spline 曲線），節點只做求和（MLP 反之：激活在節點、權重在邊）。
    2. 激活函數可學習（學 B-spline 參數）而非固定（sigmoid/ReLU），更靈活。
    3. 因而 KAN 可解釋，本身即一種 XAI 工具。
  • 翼型表示：用 CST（Class Shape Transformation） 參數——以 Bernstein 多項式表示翼型幾何；僅 8 個 CST 係數即可涵蓋對稱/非對稱/有彎度/反曲等多種翼型。
  • 資料：取自 Agarwal et al.，約 2900 個翼型（UIUC + Airfoil Tools 資料庫）的 8 個 CST 係數，及低雷諾數（10⁵）、攻角 −4°～+8° 下的 C_L 與 C_D。特徵＝8 CST 係數 + 攻角，預測 C_L。去重後 30,439 樣本，75%:25% 切分（訓練 22,829 / 測試 7,610）。
  • 對比模型：線性迴歸（LR）、決策樹（DTR）、隨機森林（RFR）、AdaBoost（ABR）、MLP，及基線 ANN。
  • KAN 解釋流程：選架構（層數、寬度 w、grid size g、樣條階數 k）→ 稀疏化與剪枝（保留重要度 > 75 百分位的節點/邊）→ 符號化（把擬合的激活函數換成函數庫中 R² 最佳的已知數學函數）→ 得封閉形式方程。

結果

  • 測試集 R²：KAN 96.17%（最佳） > MLP 96.00% > 基線 ANN 95.66% > ABR 95.35% > RFR 95.07% > LR 94.13% > DTR 93.91%。（LR 雖簡單卻勝 DTR）。
  • 剪枝威力：全連接 KAN 有 19 節點、90 邊；剪枝後僅保留 25%（11 節點、10 邊），測試 R² 仍達 95.60%，接近基線 ANN。
  • 可解釋產出：符號化得 C_L 對 CST 係數與攻角的封閉方程（式 1），呈現複雜非線性關係——與「翼型任一截面形狀改變即影響整個流場與 C_L」的先驗物理一致。特徵重要度（Figure 3）顯示幾何與攻角主導，且攻角不論形狀皆顯著影響 C_L，符合空氣動力學常識。
  • 封閉方程的價值：可對主導輸入變數求導估敏感度、量化輸入不確定性對輸出的影響、用於求最佳翼型形狀。

局限

  • 僅建模 C_L;C_D、C_L/C_D 比未做。
  • 資料僅限低雷諾數（10⁵）；其他雷諾數範圍待探。
  • 屬「示範性」研究（單一作者、高中生 + 導師），方程細節與圖以圖片呈現（文字版未含完整係數）。

對讀者的價值

  • 本批 H 類 KAN 的入門級實證——以具體航太工程案例展示 KAN「準確 + 可解釋」雙重賣點，及 剪枝→符號化→封閉方程 的完整可解釋工作流。
  • 最值得記：KAN 把激活函數搬到邊上並設為可學習 B-spline，使其能被符號化成方程；以及「剪枝後僅 25% 網路仍保 95.6% R²」展現的稀疏可解釋性。
  • 與符號迴歸路線（如 2502.03367 SyMANTIC）目標相近（找可解釋符號式），但 KAN 是從神經網路結構直接萃取而非搜尋方程空間；適合做可解釋 ML、KAN 應用、工程代理模型（surrogate）的人。
