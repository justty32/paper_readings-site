論文／訪談原始來源

《Reflexion：具語言強化學習的語言智能體》重點摘要

一句話概括

Reflexion（言語式強化）：不更新任何權重，而是把環境／評估器給的二元或純量失敗訊號放大成一段自然語言反思（verbal reflection），存進情節式記憶緩衝（episodic memory），下一次嘗試時把這些反思當額外脈絡讀回給 LLM，使智能體在少數幾次 trial-and-error 內從過去失敗中學會改進；反思等同一種「語意梯度（semantic gradient）」，在 HumanEval 上以 91% pass@1 超越 GPT-4 的 80%。

解決什麼問題

以 LLM 為核心的自主智能體（ReAct、Toolformer、WebGPT 等）過去只能靠 in-context 範例學習；要讓它們從試誤中學，傳統強化學習需要大量樣本與昂貴的權重微調，對動輒數千億參數的 LLM 不切實際。核心難點是信用分派（credit assignment）——要能判斷模型「在哪裡錯了」並生成一段可執行的改進建議。Reflexion 主張用語言而非梯度來做這件事。

核心方法

  • 三模組架構：Actor（LLM，依狀態生成文字/動作，內含 memory；可用 CoT 或 ReAct 當生成器）／Evaluator（對軌跡打分：推理用 exact-match、決策用啟發式、程式用自寫單元測試或 LLM 自評）／Self-Reflection（LLM，把「稀疏純量獎勵＋軌跡＋記憶」放大成具體的口語反思）。
  • 迴圈（Algorithm 1）：Actor 產生軌跡 → Evaluator 打分 → Self-Reflection 生成反思 sr_t → 附加進長期記憶 mem → 重置環境重試，直到通過或達最大次數。
  • 兩層記憶：短期＝當前軌跡；長期＝歷次反思文字，滑動窗口上限 Ω（通常 1–3 條）以符合脈絡長度限制。
  • 接地的自我評估：程式任務用 CoT 自生單元測試套件（經 AST 過濾、最多 6 條），因此仍符合 pass@1 資格；不依賴隱藏測試集。
  • 相對傳統 RL 的優勢：輕量免微調、回饋更細緻可解釋、記憶明確、對未來動作給出具體提示。

結果

  • HumanEval Python：91.0% pass@1（前 SOTA GPT-4 為 80.1%）；HumanEval Rust 68 vs 60、MBPP Rust 75.4 vs 70.9、LeetcodeHard PY 15.0 vs 7.5。唯一落後：MBPP Python 77.1 < 80.1（歸因於內部測試 16.3% 的偽陽性率，遠高於 HumanEval 的 1.4%）。
  • AlfWorld 決策：ReAct+Reflexion 在 12 次連續試驗內解出 134 題中的 130 題，較強基線絕對 +22%；ReAct-only 在第 6–7 試就停滯（幻覺率 22%）。
  • HotPotQA 推理：較基線 +20%；消融顯示「自我反思」較「僅情節記憶」再多帶來 +8% 絕對增益（證明 refinement-only 不如 reflection-guided）。
  • 提出 LeetcodeHardGym（40 題 hard、19 種語言，題目均在 GPT-4 預訓練截止後發布）。

局限

  • 本質是用自然語言做策略最佳化，仍可能卡在非最優局部極小；記憶只是有上限的滑動窗口（作者建議未來改用向量資料庫/SQL）。
  • 高度依賴 LLM 自評能力（弱模型如 starchat-beta 無改善——自我修正是強模型的湧現能力），且無成功的形式保證。
  • 程式 TDD 面對非確定性/不純函式/硬體相依/並行行為時難以指定正確輸入輸出映射；WebShop 這類需高度探索多樣性的任務失敗。

對讀者的價值

  • 對 ai_core §3.4「外部接地訊號驅動改進」：Reflexion 是「把（編譯器/單元測試/環境）的確定性失敗訊號當作接地信號、驅動 LLM 節點下一輪改進」的乾淨範例——Evaluator 是確定性/可驗證節點，LLM 只負責把訊號翻成改進方向，正合「多數確定性節點＋少數 LLM」的計算圖直覺。
  • 對 ai_core §3.6「經驗記憶雛形／固化引擎」：episodic memory buffer 是「把反覆處理的失敗案例結晶下來、下次讀回」的最初階雛形。但要點在於對照：Reflexion 只把經驗固化成易失的自然語言反思（Ω=1–3 的滑動窗口，跨題不保留），距離 ai_core 想要的「把案例結晶成確定性程式碼/抽象庫」的固化引擎仍有本質差距——它示範了「外部訊號→反思→記憶→重讀」的迴圈值得做，也暴露了「反思停在自然語言、不沉澱為程式資產」是為何無法真正剃除 LLM 依賴的原因。
  • 跨主題 5（程式自我除錯：自生測試＋反思修碼）與 7（反思迴圈）。與已入庫 CRITIC（用外部工具接地做單輪批評-修正）、Self-Refine（無外部接地、無持久記憶的單次自我精修）對照：Reflexion 的差異化＝外部接地評估＋跨試驗持久情節記憶二者兼具。歸 I 類。
