論文／訪談原始來源

《基於強化學習的符號迴歸在負荷建模的應用》重點摘要

一句話概括

SR 應用於電力系統動態負荷建模：用 Actor-Critic 強化學習 驅動符號迴歸——Actor 機率式選運算子、Critic 用損失評估表達式樹，配 risk-seeking 策略梯度（優化頂端表現非平均）與 候選池 + 梯度下降微調。產出緊湊可解釋的數學式，比 ANN/ZIP/多項式迴歸在多數故障場景下 RMSE 更低、兼顧準確、效率、可解釋。

解決什麼問題

  • 再生能源滲透、需求多變、電網控制演化 → 準確高效的負荷建模關鍵卻困難。傳統固定形式參數模型與**資料驅動（ANN/LSTM）**難平衡準確、計算效率、可解釋；ANN 可解釋性低、無顯式數學關係。
  • 負荷建模：給擾動量測 x（電壓/頻率變化）與功率響應 y，找 f 使 y≈f(x)。PMU 等高解析量測提供豐富資料。

方法

  • 可訓練表達式樹：固定/受控深度、預定運算子集 → 降複雜度保可解釋。二元樹，逐層交替 unary/binary 運算子（unary 如 ReLU/sigmoid，binary 如 +/×，皆從運算子庫選）。
  • Actor 網路：對樹各節點機率式選運算子;Critic：用損失函數評估表達式樹。
  • risk-seeking 策略梯度：標準策略梯度優化平均，但 SR 等任務在乎最佳樣本（頂端表現）→ 用 risk-seeking（類 DSR，只優化頂 ε 分位數）平衡探索-利用。
  • 候選池機制：存訓練中最佳表達式 → 先策略梯度粗優化、再梯度下降微調參數 → 選損失最小者為結果。降計算開銷、平衡準確與簡單。

實驗

  • 案例：PMU 資料，bus fault + line fault 兩故障場景，三種負荷型（CI 恆阻抗、IM 感應馬達、PV 光伏）；預測電壓 V、有功 P、無功 Q。
  • risk-seeking vs 標準策略比較（Table I，不同 ε 分位數）。
  • 對比 ANN / ZIP / 多項式迴歸（Table III）：所提模型多數情況 RMSE 最低（如 line fault PV 負荷電壓 RMSE 降至 0.040 勝全部基線；Q 達 0.023）。ANN 偶有相當但跨場景不一致；ZIP/多項式落後（捕捉不到負荷的非線性）。
  • 故障場景評估：V/P/Q 預測與真值高度吻合（含暫態）;IM 負荷在暫態的 P/Q 偏差略大（待優化）。

對讀者的價值
