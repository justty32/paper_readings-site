AGEL-Comp 論文摘要

arXiv: 2604.26522 標題: AGEL-Comp: A Neuro-Symbolic Framework for Compositional Generalization in Interactive Agents 作者: Mahnoor Shahid, Hannes Rothe (Universität Duisburg-Essen) 類別: I （方向五：LLM-based agents / neuro-symbolic）

研究問題

LLM-based agent 在互動環境中系統性地無法達成組合泛化（compositional generalization）——即從已知基本元素組合成新概念的能力。此「組合性危機」源於 LLM 的知識缺乏經驗基礎（grounding），無法形成對世界的結構化、因果性的理解。當前 SOTA LLM 在開放式互動環境中表現脆落，依賴統計模式匹配而非系統性推理。

核心貢獻：AGEL-Comp 架構

AGEL-Comp（Action-Grounded Experiential Learning for Compositionality）是一種神經符號 AI agent 架構，融合三大創新：

1. 動態因果程式圖（Causal Program Graph, CPG）

一種有向超圖（directed hypergraph）作為世界模型 W = (V, E)：

  • 節點 V：grounded predicates（如 is_harmful(X)）或概念（如 fire）
  • 超邊 E：Horn clauses 作為子程式，超邊從多個輸入節點（子句 body）指向單一輸出節點（子句 head），建模邏輯/因果依賴關係

此模組化結構支援階層規劃與目標化模型修正。此即 ai_core §1 可優化計算圖的具體實例：CPG 不是靜態結構，而是可被 ILP 動態擴展、可被 NTP 驗證的計算圖，其節點與超邊隨互動經驗而增量成長。

2. 歸納邏輯程式設計（ILP）引擎

從稀疏經驗反饋中合成新的、可泛化的 Horn clauses，提供形式化的符號知識 grounding 機制。學習過程分兩階段：

  • 階段一：因果歸因（MCS 演算法） — 透過 Minimal Contrastive Search 在 episodic memory 中尋找「最小對比」經驗（相同動作、不同結果），隔離出單一因果前提
  • 階段二：抽象歸納（MIL） — 透過 Meta-Interpretive Learning 將具體因果假設泛化為可重用的 Horn clause，整合進 CPG

3. 混合推理核心

  • LLM 作為規劃器：從目標 G 與知覺 Pt 生成候選子目標集合
  • NTP 作為驗證器：對每個子目標進行端到端可微反向鏈接（backward chaining），返回 proof score σ 與 proof path π，確保計劃的邏輯一致性

NTP 透過兩階段訓練：先以基礎邏輯規則 bootstrap，再對 ILP 歸納的新規則進行持續微調（continual fine-tuning）。

學習機制：演繹-溯因循環

AGEL-Comp 的運作基於 deduction-abduction 循環：

  1. 演繹（deduction）：LLM 提出計畫 → NTP 以 CPG 驗證 → 執行
  2. 溯因（abduction）：預測錯誤發生時 → MCS 隔離因果 → MIL 歸納新規則 → 更新 CPG → NTP 微調

此循環使 agent 能從與環境互動中持續建構可解釋、結構化、具組合性的世界理解。

實驗

環境：Retro Quest

基於 Unity + ML-Agents 的 top-down 2D RPG，設計 10-quest curriculum 測試組合泛化（含 ambiguous/stochastic 場景）。

對比配置

  • MLLM-Agent（ReAct-style baseline）
  • AGEL-Comp Full System
  • AGEL-Comp w/o NTP（有 ILP、無驗證）
  • AGEL-Comp w/o ILP（有 NTP、靜態世界模型）

四種 LLM backbone：GPT-4o、Gemini Pro 2.5、LLaVA 1.6、DeepSeek-VL。

關鍵結果

指標 AGEL-Comp Baseline
Quest Success Rate 100%（所有 backbone） 63.33%-86.67%
First-Try Success 60.0% 3.3%（差 18 倍）
Sample Efficiency (Gemini) 23.27 159.30（6.8× 改善）
Hard/Very Hard 任務 維持 100% 降至 0%

消融研究核心洞察

  • w/o ILP：驗證器無法修正世界模型，表現與 baseline 幾乎相同（76.7%），在困難任務上完全崩潰
  • w/o NTP：能學習但缺乏驗證，First-Try 成功率從 60% 驟降至 22.5%
  • 結論：ILP 學習器與 NTP 驗證器是共生（symbiotic）的，缺一不可

關鍵洞見

  1. 純 LLM agent 的組合泛化失敗根源在於知識缺乏 grounding——統計相關性無法取代因果結構
  2. 符號學習（ILP）與符號推理（NTP）互為必要：前者的世界模型需要後者驗證，後者的驗證能力依賴前者提供準確的模型
  3. 從少量樣本中學習的能力來自 ILP 的強歸納偏誤；MCS 的「最小對比」策略確保了因果歸因的可靠性
  4. 雖然單次 NTP 驗證計算成本高，但總體迭代次數大幅減少（5-10×），整體效率反而更高
