論文／訪談原始來源

Rule-Based Languages for Neurosymbolic AI 重點摘要

一句話概括

這篇綜述把規則式神經符號語言拆成語意、表達力、神經整合與評估機制四條軸，主張先辨認任務需要的推理及不確定性，再選語言與求值方法；provenance semiring 是重要共同基礎，但尚未統一所有語意與能力。

解決什麼問題

同樣標榜「神經加邏輯」的系統，可能採用不同的真值、機率、否定、遞迴與近似方法，不能只以是否有規則來比較。本文聚焦明確暴露規則層的 Datalog 及擴充、ASP、Prolog 式機率程式，以及學習這些規則的 ILP；純次符號模型如 GNN 不在核心範圍。作者也介紹以邏輯正則化訓練的鄰近設計，藉此說明它們與執行時保留可檢視規則層的差別。（§1、§3.3）

作者自報整理超過 50 個系統、方法與應用，多數來自近六年，依主要研究社群分為 DB／PL、核心 ML／AI、視覺與機器人四領域。這是作者策展的 corpus 與代表性摘要，不是本文重跑各系統後得到的效能排行榜。（§4、表 3）

語意邊界：可微不等於機率，否定也不是同一種運算

作者以不含 function symbols、有限事實庫的 Datalog 為起點：正向規則的 immediate-consequence operator 單調，bottom-up 反覆套用可到 least fixpoint。其多項式保證指的是 Datalog 核心的 data complexity，不能連同機率推論或任意擴充一起套用。

加入 negation as failure 後，一般不再單調。分層否定給 perfect-model 語意，well-founded semantics 容許 unknown，stable-model semantics 則支撐 ASP 的非單調推理。作者特別指出，圖中的部分內含關係是語法關係；well-founded／stable 是替代語意，不能把整幅圖讀成推論成本也依序可比。

ProbLog 的 distribution semantics 對機率事實的選擇形成可能世界，query probability 由相容世界的權重相加。LTN／LNN 等 fuzzy 系統則在鬆弛真值上以 t-norm 組合，沒有同樣的可能世界分布。soft unification 以 embedding 相似度替代符號相等，但若把成對相似機率當獨立事實，可能不具遞移性；本文轉述 equivalence semantics 以相等關係上的分布處理這個問題。（§2、§3.1～3.2）

Provenance semiring 的共通性與限度

正向關係查詢可在交換半環上求值：同一輸出的替代推導用加法合併，每條推導的輸入標註用乘法組合。遞迴可能產生無限多推導，本文依既有理論要求相應連續性條件，例如 omega-continuity，使總和定義良好。改換代數可重用求值引擎，但這不等於任意語意都能直接換一個半環解決。

特別是，多條證明可能共用事實，不能把它們當獨立事件直接相加相乘就得到可能世界機率；精確機率仍需對 Boolean provenance 做 weighted model counting。時間算子、embedding equivalence 與 FFI 也尚未由同一半環語言自然涵蓋。DeepLog 的多語意整合是在代數電路這個編譯層，作者沒有將它當成已完成的統一來源語言。（§2、§3.1、§5.2、§6）

結果

決策矩陣與跨領域觀察

本文的主要產出是分類、文獻整合與配置矩陣，沒有新增統一條件下的 benchmark 比賽。作者認為 corpus 以 AI 系統為主，DB／PL 提供許多理論基礎，視覺與機器人的代表數較少。對六個反覆出現的情境，表 4 強調的能力如下；這些配置判斷依該綜述所整理的系統與應用而來。（作者自報，§4～5、表 3～4）

訓練與部署可以採不同語意

作者將訓練與部署表示分為機率分布（P）、Boolean／MAP（B）及連續鬆弛（R）。P→P 保留答案分布及修正低信心感知的空間；P→B 只在部署斷言 MAP 事實，較便宜但失去不確定性。R→B 的 differentiable ILP 在訓練時鬆弛規則、部署時抽出符號規則。R→R 則全程使用鬆弛值；其分數不能直接解讀為可能世界機率。固定規則不在梯度路徑上的 B→B 系統，與由 abducted proofs 編譯出可微 loss 的設計也不同。（§5.1、圖 6）

精確度與 GPU 加速是不同選擇

綜述指出，精確 WMC 一般為 #P-hard；雖然在已編譯好的 d-DNNF 電路上計數可線性求值，編譯電路本身可能隨 ground program 的 treewidth 指數增大。top-k provenance 限制推導集合，換取有偏近似；sampling、amortized inference 與 abduction 搜尋則處理不同的推論或學習訊號問題。

GPU 求值不會自動把近似變精確。作者區分 Lobster 把 Datalog 編譯成 GPU kernels、DOLPHIN 保留 CPU 符號層並向量化機率與梯度計算，以及 KLay 對已編譯精確電路做 GPU 平行化。選型時要同時看「算的是什麼」與「在哪裡算」。（§3.4、圖 5）

局限

作者明載的邊界與未解問題：沒有單一 dialect 覆蓋所有情境。來源語言層的 Boolean／probabilistic／fuzzy／embedding 統一、兼顧 Datalog 與 ASP 語意的可微引擎、近似推論可計算的誤差界，以及神經符號程式驗證都尚待解決。LLM 產生規則的靜態分析與修復，以及模型作關係時的幻覺、非決定性與成本語意，也列為研究問題。（§5.2、§6）

作者另強調，滿足符號限制不代表學得概念具有預期意義，reasoning shortcuts 仍會破壞泛化與校準。端到端可靠性需要同時處理規則及 concept grounding，不能僅由可檢查規則推出整體保證。（§5.2、§6）

對讀者的價值・接點

本檔補註，非作者自陳：設計規則式 NeSy 系統時，可先問是否需要非單調推理、遞迴、聚合、時間與開放詞彙，再決定訓練及部署是否保留不確定性，最後選近似機制與硬體。這個順序可避免把「可微」「可解釋」「可驗證」當成彼此自動成立的性質。
