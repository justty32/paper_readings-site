論文／訪談原始來源

KAFlow：以低秩生成元學習可蒸餾的物理算子

一句話概括

KAFlow把physical field的generator拆成translation-invariant spectral multiplier、少量position×frequency separable terms及gauge-fixed KAN非線性，再用FFT與Lawson／Strang flow演化；從univariate functions自動選sparse supports、refit closed forms。在KANO synthetic operators上降低unseen-family loss並恢復係數，在quantum與非局部PDE上提高rollout準確度。這裡「exact」主要指離散低秩quantization與特定線性流，不是所有learned nonlinear dynamics都零誤差。（§2–3、Text S1）

低秩的是什麼：linear symbol與generator的範圍

在periodic uniform grid上，Kohn–Nirenberg quantization以symbol \(p(x,\xi)\)作用輸入。Proposition1對finite-order linear variable-coefficient operator \(\mathcal G=\sum_{k=0}^Kc_k(x)\partial^{\alpha_k}\)及任意translation-invariant multiplier \(\mathcal M(\xi)\)，其symbol

\[p(x,\xi)=1\cdot\mathcal M(\xi)+\sum_{k=0}^Kc_k(x)(i\xi)^{\alpha_k}\]

是\(K+2\)outer products之和，separation rank≤\(K+2\)，不隨resolution增加。這不是任意nonlinear／variable-order operator都exact finite rank的定理。KANO三synthetic benchmarks的線性symbol及quantum Hamiltonian linear part均rank2；\(f^3\)等pointwise nonlinearity另表示。Official KANO checkpoints的learned symbols亦有\(\sigma_3/\sigma_1\le3.5\times10^{-6}\)。（§2.4、Text S1）

Generator低秩不保propagator低秩：transport \(u_t=c(x)u_x\)的rank1 generator，其flow composition symbol為\(e^{i\xi(\varphi_{\Delta t}(x)-x)}\)。作者測\(\varphi(x)=x+\varepsilon\sin x\)，benchmark grid上tol\(10^{-4}\)的numerical ranks為11／16／20，對應\(\varepsilon=.1/.2/.3\)。故學generator、交integrator演化，可避免static network直接學較高秩propagator。（§2.6）

Exact低秩quantization與成本

對\(p=\ell(\xi)+\sum_{r=1}^Ra_r(x)m_r(\xi)\)，有離散恆等式

\[\operatorname{Op}_m(p)u=\mathcal F_m^{-1}[\ell\mathcal F_mu]+\sum_{r=1}^Ra_r(x)\,\mathcal F_m^{-1}[m_r\mathcal F_mu].\]

Position factor在inverse FFT後乘，符合Kohn–Nirenberg ordering。這是給定separable symbol的exact application，不是把arbitrary dense symbol任選小R仍保exact。d維成本\(O((R+1)m^d\log m^d)\)、symbol evaluations \(O((R+1)m^d)\)；general dense symbol為\(O(m^{2d})\)，KANO reference materialize triple phase tensor則\(O(m^{3d})\)。不要把reference implementation額外成本當所有dense quantization不可改善的下界。（§2.5，Proposition2、Text S1）

KAFlow架構與gauge allocation

\[\mathcal G_\theta u=\operatorname{Op}_m(\ell)u+\sum_{r=1}^Ra_r(x)\operatorname{Op}_m(m_r)u+\Phi^{nl}(u,\operatorname{Op}_m(\mu)u,x).\]

直接作用physical field，無latent lifting／projection；static task輸出\(\mathcal G_\theta u\)，dynamic task輸出integrated flow。Spectral functions是dictionary-augmented KAN edges：半頻譜上complex coefficients乘\(|\xi|^p\)，\(p\in\{0,.5,1,1.5,\ldots,4\}\)，再加B-spline residual；residual按training energy spectrum加權penalty，弱約束頻段受更大懲罰。Position functions用linear＋splines；nonlinearity以univariate sums及product terms表示。（§2.7、Text S2）

Gauge固定：\(a_r\) zero mean，constant coefficients放\(\ell\)；再

\[\Phi^{nl}(z,x)=\Phi(z,x)-\Phi(0,x)-\nabla_z\Phi(0,x)\cdot z,\]

去掉非線性module的constant／linear-in-z部分，讓position-dependent linear terms歸symbol。作者的unique place是這個架構分工；不把它擴成從任何部分觀測都唯一辨識真實physical law，或任意低秩factorization全無縮放／混合等價。（§2.7；最後一句為本檔補註，非作者自陳）

Exact integration需要哪些前提

一般dynamics用fourth-order Lawson integrating-factor RK與2/3dealiasing，將diagonal stiff linear part \(e^{\Delta t\ell}\)精確處理。TextS1明確：只有\(\mathcal N\equiv0\)時完整一步回exact linear flow，該線性部分無time-discretization error／step-size restriction；有nonlinearity仍是數值RK，不能保任意步長全系統精確或穩定。（§2.7、Text S1）

Quantum用\(H=T(\xi)+v(x)+\kappa_1\rho+\kappa_2\rho^2\)、\(\rho=|\psi|^2\)，Strang split的potential／kinetic exponential factors對real \(V,T\)皆unitary，故任意parameters保norm；不等於noncommuting split沒有time error。Kinetic用非負softplus coefficients、monotone、\(T(0)=0\)固定global-phase gauge。這些是physics與架構約束，不是模型從零無prior發現unitarity。（§2.7、Text S1/S2；split-error及prior界線為本檔補註，非作者自陳）

自動symbolic distillation仍有候選library

Position-dependent part回歸到centered monomials \((x^n-\langle x^n\rangle)(i\xi)^p\)，spectral part用上述power dictionary，nonlinearity用\(f^2,f^3,ff_x,f^2f_x,ff_{xx},f_x^2,xf^2,xf^3\)。沿BIC path及各size best-subset選supports，丟condition number>\(10^3\)者；每candidate以closed form重訓，再選training-family held-out loss≤best的1.1倍中最小support，dense model也可保留，最後double-precision L-BFGS refit。（§2.8）

「無人工指定symbolic template」指不用人看edge後為每task指定最終equation，不等於沒有power／monomial／product library或模型prior；Whitham最終即保dense spline。Quantum DW另用learned potential polynomial fit，NLSE用distillation加Kerr profile-likelihood refinement。（§2.8、Text S2、§3.5）

Synthetic operators：unseen families與precision floor

三task為\(G_1f=x^2f-f_{xx}\)、\(G_2f=xf_x+f_{xx}\)、\(G_3f=f^3+xf_x+f_{xx}\)，128points。GroupA有2000training＋400held-out pairs，GroupB400test pairs，分別是不同input families；selection用A held-out，不用B。R2／J1，三initializations先Adam1000iterations取A validation最佳後續訓及L-BFGS；報六random seeds，不把restart3與seed6當同分母。（§2.9–2.10、Text S2）

Variable-order與五種evolution equations

\(G_4f=\operatorname{Op}(|\xi|^{1+.5\sin x})f\)，order .5–1.5、benchmark numerical rank4／tol\(10^{-4}\)；同A/B分法，outputs用double precision full-grid quantization。R4 KAFlow unseen loss\(.293\times10^{-2}\)，R2$.886\times10^{-2}$、FNO\(4.44\times10^{-2}\)、KANO-MLP\(5.06\times10^{-2}\)；「15倍」對FNO、「17倍」對MLP。Published additive-real-part KANO configuration無法表示此symbol，B loss\(206\times10^{-2}\)，不能把它與MLP混為單一KANO comparator。456params對FNO566k約.08%。（§3.4、表5）

五PDE為Burgers、fractional Burgers、Benjamin–Ono、KdV、Whitham；128points、256training trajectories內末32validation，另64test，每條100steps。Initial Fourier modes1–4；data solver20Lawson substeps，KAFlow4substeps／observation、R0／2nonlocal features，以rollout curriculum訓練；FNO同validation與curriculum調參。KdV／Whitham僅在架構設計期間held out，仍有各自training data。Sparse baselines PDE-FIND／WeakSINDy用local polynomial library與validation-selected thresholds。（§2.9、Text S2）

KAFlow100step test losses依序\(.00429/.00488/.00290/.0161/.103\)，FNO\(.0130/.0159/.00312/.0198/.442\)；不是每題orders-of-magnitude勝。302params對FNO287k–550k。KAFlow一般六seeds，但BO／KdV只報五個收斂者的mean±SD，FNO三seeds。Sparse regression在local Burgers成功，fractional／nonlocal項超出指定library時失敗；Whitham PDE-FIND diverged。（§3.5、表6）

Burgers／fractional／BO／KdV可選出closed-form linear symbols，coefficient errors .02%–.6%；Whitham保spline、resolved band relative error.25%，ground truth在表6為\(-i\sqrt{\xi\tanh\xi}\)。係數／symbols取lowest-validation model，不是全部seeds平均，也沒有在未受data約束頻段保準確。（§3.5、§2.10）

實測成本與適用界線

128points、batch64 forward＋backward CPU training step：KANO10.1ms、KAFlow8.5ms。表7另測Intel Xeon Silver4510／8threads、batch16 forward含symbol evaluation；m1024時KAFlow5.2ms，對作者\(O(m^2)\) KANO implementation3596ms，約690倍；official KANO在1024是未列結果，不能說690倍是同解析度training speedup或直接對official實測。其optimized KANO和official outputs relative difference\(6.8\times10^{-6}\)。（§3.6、表7）

作者未來方向是2D／3D，本文實驗為1D periodic grids；resolution-independent rank／parameters不自動保證跨resolution與任意boundary條件泛化。Low-rank class、chosen dictionary、energy-supported frequency band及observational identifiability都是需保留的範圍。KANO benchmarks的多數baseline沿原報告，作者以official checkpoints重現FNO／KANO／KANO-symbolic；本次自訓baselines三seeds，不把全部視為同一重訓協議。新data generators／models／code作者稱upon reasonable request，非本文附完整公開可執行包。（§2.10、§4、Data Availability；泛化界線為本檔補註，非作者自陳）
