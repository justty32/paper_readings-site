日期：2026-03，神經符號（主題 B：LLM 寫「會推理的程式」/ 形式驗證工具自動生成）

arXiv：2603.06931

論文／訪談原始來源

《LLM2SMT：用零人類手寫程式碼造出一個 SMT 求解器》重點摘要

一句話概括

LLM2SMT：一個案例研究——讓一個 LLM 編碼 agent（Claude Code，Sonnet 4.6）在零人類手寫程式碼下，從一句「實作 Nieuwenhuis–Oliveras 同餘閉包演算法」的最小描述出發，造出一個完整的 DPLL(T) 式 QF_UF SMT 求解器（含前處理、對 UNSAT 實例輸出 Lean 證明）；問的不是「LLM 能不能推理」，而是「LLM 能不能寫出『本身會推理』的軟體」——結果在 SMT-LIB QF_UF 基準上求解 7,468 個實例，逼近 z3（7,500）與 cvc5（7,494）。

解決什麼問題

「LLM 能否推理 / 能否寫軟體」已被廣泛辯論，但「LLM 能否寫出自身會推理的軟體」幾無探討。SMT 求解器是「會推理的程式」的標竿（邏輯原理 + 精細演算法 + 正確性要求高）。本文以此為試金石，檢驗 LLM agent 在適當鷹架下能否獨力產出有競爭力、且其判決可被形式認證的求解器。

核心方法

  • 開發流程：用 Claude Code（Sonnet 4.6）生成全部實作，從引用 Nieuwenhuis–Oliveras 同餘閉包的最小描述起步。開發者透過 維護說明 加永久指令（如求解器跑要設 timeout）；agent 在拿到失敗測例時自主除錯；LLM 自己生成 fuzzing 與 delta-debugging 工具來省 token；用 git 歷史＋回歸測試支援迭代。具體範例比抽象描述更能引導修正。
  • DPLL(T) 架構（QF_UF）：lazy SMT；理論原子變成布林變數交給標準 SAT。CaDiCaL SAT 求解器透過 IPASIR-UP 介面產候選賦值，再由理論專屬檢查驗證（QF_UF＝無量詞等式＋未解釋函式）。
  • 同餘閉包：Nieuwenhuis–Oliveras 演算法偵測不一致的項等式；含公式 hash-consing；處理 SMT2 中布林「既是命題又是項」的雙重性（一開始導致假 UNSAT）。
  • Lean 證明輸出：不建低階證明，而依賴 Lean 自動化——grind tactic 驗理論引理、bv_decide 處理命題片段；SMT 型別/常數變成 Lean 公理、理論引理變成獨立定理。初期把上千個假設塞進單一定理導致 Lean 解析失敗，須拆分。

結果（含數字）

  • SMT-LIB QF_UF 非增量基準、180 秒 timeout、並行：
求解器 求解實例數 獲勝數
z3 7,500 7,491
cvc5 7,494 7,308
llm2smt 7,468 6,486
llm2smt-no-prepro 7,355 6,150
  • 反直覺：關閉理論傳播（theory propagation）反而更好（7,478 vs 7,468）——在這批基準上傳播帶來開銷卻無補償。
  • 證明認證：285 個認證成功、2,244 因 grind 能力不足失敗、1,314 timeout、240 超 Lean heartbeat、86 stack overflow；未發現任何錯誤證明。

局限

  • 完整證明認證仍超出當前能力（僅 285/~4000+ 成功）；agent 在「理論引理 vs 最終證明」的區分上掙扎最久，須人工給正確 Lean 證明範例。
  • 只覆蓋單一理論（QF_UF）。
  • 「Jagged Intelligence」：agent 能做複雜推理卻在瑣事翻車（一開始不把 t=t 化簡為 true）；無 timeout 的程序會默默累積。
  • 仍需開發者提供標準工具（fuzzing、delta-debugging）、明確資源上限與謹慎的輸入規格。

對讀者的價值

  • 本主題 B 中**「LLM 不只用符號工具、而是親手造出符號工具」的奇點式案例**——與 2606.00669（NeuroLog，LLM 當事實抽取器接 Z3）、2602.18095（Logitext 把 LLM 當 SMT theory）形成對照：這裡 LLM 是求解器本身的作者。
  • 與 2606.08728（AI4Math 綜述）、2604.26311（DreamProver）、2606.19315（Diffusion Proof）對讀，補足「LLM 與形式證明/求解器」光譜的另一端——程式合成出可被 Lean 認證的求解器。
  • 最值得記：零人類手寫程式碼即逼近 z3/cvc5（7,468 vs 7,500）；以及那組誠實的工程教訓——具體範例 > 抽象描述、agent 自帶 fuzz/delta-debug、「Jagged Intelligence」與「證明認證仍是硬骨頭」。
