論文／訪談原始來源

Can Test-Time Memory Evolution Outperform Test-Time Training for Scientific Discovery? 重點摘要

一句話概括

Test-Time Memory Evolution（TTME）把搜尋中可執行候選的成敗與改進整理成外部記憶，供固定權重的語言模型產生後續候選。作者在兩種既有發現框架、五項數學構造任務中，報告最佳結果優於原論文的 test-time training（TTT）結果；這是特定搜尋設定下的比較，不足以證明記憶一般優於權重更新。

方法

兩個框架都從候選檔案庫選父程式、生成修改、執行並由任務驗證器評分，目標是在預算內找最高品質的有效構造。TTT 用搜尋結果做線上強化學習更新權重；TTME 保留框架的父代選擇、檔案庫更新和驗證器，以外部記憶取代線上權重更新。同一個固定權重模型既生成候選，也執行記憶整理、策略選擇和適配。（§3.1、§4.1）

兩份記憶每兩個搜尋步驟更新：Guideline Memory 從有效結果及執行失敗萃取適用條件與操作建議，合併重複項並淘汰過期項，最多保留 24 條；Strategy Memory 只從有效且比父程式更好的修改提煉算法想法，按策略家族整理及保留來源案例。兩者初始為空。（§3.2～3.3、附錄 C）

每個父程式的一半候選直接根據父程式與指南生成，另一半先選擇可用策略、依父程式改寫成指示後生成；若沒有合適策略則提出新想法。策略跨搜尋分支重用，但其是否有效仍由執行與任務驗證器判定。（§3.4）

實驗與作者自報結果

五項任務為 Erdős 最小重疊、三個自卷積不等式 AC1～AC3，以及 29 階 ±1 矩陣的最大行列式。AC1、AC3、Erdős 數值越低越好，AC2、Hadamard 越高越好；Hadamard 驗證器以精確整數算行列式。這些是具特定驗證器的數學構造任務，不能直接推廣到無自動驗證器的開放科學發現。（§4.1、附錄 A）

TTT-Discover 使用 Qwen3-8B 與 gpt-oss-120b，在 AC1、AC2、Erdős 搜尋 50 步；例如 Qwen3-8B 的 TTT 與 TTME 最佳值依序為 AC1 1.50525 → 1.504329、AC2 0.9472 → 0.949248、Erdős 0.380932 → 0.380927。ThetaEvolve 使用 Distill-Qwen3-8B 搜尋 65 步，TTT 與 TTME 的 AC2、AC3、Hadamard 分別為 0.9469 → 0.948148、1.4930 → 1.464224、0.5764 → 0.579938。（§4.2、表 1～2）

TTT 數值取自原論文，並非本文重跑；作者稱保留原框架主要設定，但附錄列出例如 gpt-oss-120b 的原 TTT 以 Tinker 服務、本文固定權重實驗以 vLLM 服務。TTT-Discover 每次主要候選 25,600 個，ThetaEvolve 33,280 個；TTME 的記憶整理、策略選擇與適配是額外模型呼叫，因此相同主要候選數不等於相同總推論量。ThetaEvolve 本文固定權重實驗表列單一 seed 3407，而原設定列三個 seed；表格沒有提供結果不確定度，差距不宜解讀為穩健性保證。（§4.1、附錄 B）

成本表僅比較 TTT-Discover 的 Qwen3-8B 三項任務，計入候選生成、記憶相關模型呼叫及適用的 RL 訓練，但執行時間不含候選評估。相較 TTT，作者報告 TTME 時間減少 47.7%～58.4%、計算量減少 82.8%～84.6%；例如 AC1 分別為 11.76 → 5.36 小時、29.47 → 4.53 EFLOPs。這些比例不代表包含驗證器與所有環境成本的端到端節省，也不能直接套用於其他模型或框架。（§4.2、表 3）

消融與解讀

Qwen3-8B、TTT-Discover 的 AC2 與 Erdős 消融中，TTME 單獨使用優於同時使用 TTME 和 TTT；後者由更新過的模型同時生成候選與操作記憶。gpt-oss-120b 上移除任一記憶組件，三項任務的最佳分數均低於完整 TTME。這些結果支持所測配置的兩種記憶，但沒有證明其他 TTT 設計或任務必然如此。（§4.3、表 4～5）

作者另以能編譯並獲評分定義程式有效，報告 TTT 和 TTME 的平均有效率都高於沒有兩者的搜尋；TTME 在所測 AC1、AC2 中，較常選到把父代想法與其他祖系以外已探索想法結合的候選作後續父代。這是搜尋軌跡的觀察，無法單獨證明記憶造成了每項性能差異。（§4.4）
