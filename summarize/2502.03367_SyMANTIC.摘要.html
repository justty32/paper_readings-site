論文／訪談原始來源

《SyMANTIC：高效符號迴歸，發現可解釋簡約模型》重點摘要

一句話概括

SyMANTIC（Symbolic Modeling with Adaptive iNtelligent feaTure expansIon and Compressed sensing）：一個高效的 SR——靠互資訊特徵選擇 + 自適應特徵擴展 + 遞迴 L0 稀疏迴歸，從 10⁴–10¹⁰+ 候選中高效找低維描述子；用資訊論複雜度量度產近似 Pareto 最優方程集；PyTorch + GPU 開源。在 benchmark 上回復 >95% 真值方程（次佳僅 ~50%）、訓練最快，從 5 個時間點學混沌 Lorenz 系統（勝 SINDy），電池材料性質預測勝 SR + 傳統 ML。

解決什麼問題

SR 的四大痛點：計算成本高、隨輸入維度擴展性差、對噪聲脆弱、無法平衡準確與複雜度。

核心方法

  • C²-SISSO（Complexity-Constrained Sure Independence Screening with Sparsifying Operator）：建於 SISSO（從海量候選找最優低維描述子的壓縮感知法，原為材料性質建模）之上，在稀疏迴歸前先限制特徵複雜度。
  • 三大組件：
    1. 互資訊（MI）特徵預篩：處理高維（特徵 >~10–20）；對 x↔y 強非線性關係穩健；按 MI 排序選最相關主特徵。
    2. 自適應特徵擴展：用 x 與使用者定義運算子集遞迴 L 層建特徵空間（指數成長，故需 MI 預篩控制）。
    3. 遞迴 L0 稀疏迴歸（壓縮感知視角的懲罰式 SR）。
  • 資訊論複雜度量度：計入「唯一輸入/運算子的數量與頻率」→ 產近似 Pareto 最優方程集（非單一最準式）。
  • 自動超參搜尋：序貫測試多組超參，每輪用 C²-SISSO 新結果更新 Pareto 前沿（達 RMSE 閾值或試完所有超參即停）。
  • 開源 PyTorch（易裝、GPU 加速、易平行）。

結果

  • benchmark：回復 >95% 真值方程（次佳僅略過 50%）;訓練時間最短。
  • 混沌 Lorenz 系統：從僅 5 個時間點的狀態導數量測學支配方程，勝廣用的 SINDy（含更多資料/不同噪聲下亦然）。
  • 電池材料性質預測（可持續電池材料）：即使有限訓練資料，學到比現有 SR 與傳統 ML 更準、更可泛化的模型。

局限

  • 只探索到最大深度（GP 可探更深表達式；但 GP 測很多低品質式效率低）→ 未來可混合 SyMANTIC 的針對性搜尋 + GP 的更深探索。
  • 假設 MSE 損失（可擴展但未處理離群/非高斯噪聲）。

對讀者的價值

  • 本批 C 類的**「稀疏迴歸/壓縮感知 SR」代表**——與 GP（2512.01682）、transformer（2505.21879 SFR）、MCTS（2509.15929）等路線不同，走 SISSO/壓縮感知 + 特徵擴展 路線，主打高效 + 高維 + 抗噪 + 小資料。
  • 最值得記：「MI 預篩 + 特徵擴展 + L0 稀疏迴歸 + C²-SISSO 限複雜度」 的高效配方；資訊論複雜度（計入頻率非僅數量）;自動超參搜尋逐步改善 Pareto；以及驚人的小資料結果（5 點學 Lorenz）。
  • 與 2506.19537 SR降維、2505.21879 SFR 皆攻「高維/降維」；與 SINDy（動態系統）正面對比。
  • 定位：完整方法論文 + 多領域實證（化工/材料背景，開源 Python 套件）；適合做 高效 SR、材料/化工性質建模、動態系統辨識、小資料 SR 的人。
