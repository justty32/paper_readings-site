論文／訪談原始來源

《可分解神經符號迴歸（SeTGAP）》重點摘要

一句話概括

SeTGAP（Symbolic Regression using Transformers + Genetic Algorithms + genetic Programming）：一個事後可解釋的可分解 SR——把訓練好的「不透明（opaque）」迴歸模型（NN）蒸餾成可解釋的多變數數學式。關鍵思路：先用 Multi-Set Transformer 為每個變數各自找一條單變數符號骨架（skeleton），再用 GP 級聯逐變數合併、保留原骨架結構，把高維符號搜尋轉成「有引導的增量操作」。結果在所有受控問題上一致回復正確函數結構（對手 ≤7/13），外推泛化更好（甚至勝它所蒸餾的 NN）。

解決什麼問題

  • 多數 SR 只最小化預測誤差、不抽支配方程 → 過複雜/不準。神經 SR（transformer）同時處理所有變數 → 常抓不到「每個變數 ↔ 響應」的函數形式。
  • 大資料直接 SR 計算昂貴 → 用高效不透明模型當代理蒸餾數學式。

方法（SeTGAP，圖 1）

  1. Multi-Set Transformer 生多條單變數符號骨架：刻畫每個自變數如何影響不透明模型的響應（骨架＝結構但常數待定）。
  2. GA 選擇：濾掉低品質骨架、保留最具資訊者。
  3. GP 級聯合併（cascade）：一次納入一個變數增量合併骨架，產生候選骨架組合池、選最合適者，確保合併式與原結構對齊。
  4. GA 係數優化：對最終多變數式擬合數值常數。
  • 核心假設：若所有變數的單變數函數形式都已正確辨識，則「尊重這些預辨識結構」的搜尋空間中必存在與系統底層函數等價的多變數式 → 把高維符號搜尋轉成一系列有引導的增量操作。骨架當結構約束 → 即使噪聲/低變數敏感度也不會像別人選「數值接近但錯誤」的運算子。

結果

  • 受控問題（13 個、各 10 次迭代）：SeTGAP 全部正確回復函數形式；對手（2 個 GP、3 個神經 SR、1 個混合）任何一次迭代都 ≤7/13；有些只抓到最具影響力變數的形式。
  • 外推 MSE 更低或相當：純優化域內 MSE 的方法傾向過擬合、缺外推所需的結構彈性；SeTGAP 的分解法學到更真的函數形式 → 外推泛化更佳，甚至勝過它所蒸餾的不透明 NN（同樣訓練資料下 NN 外推誤差顯著更高）→ 凸顯 SeTGAP 兼為迴歸法與可解釋工具。
  • Feynman 資料集：高符號回復率 + 有競爭力的預測表現。
  • 噪聲穩健：Multi-Set Transformer 用小噪聲訓練 + 迴歸 NN 平滑響應 → 抗擾。
  • 局限：Feynman 方程多為線性/加性可分（對分解法較不挑戰）;變數範圍太窄會妨礙辨識真函數形式；指數項小常數誤差會放大外推誤差；有時正確辨識單變數形式但噪聲妨礙變數間關係偵測。

對讀者的價值

  • 本批 C 類的**「神經符號 SR」代表**——名字就是 NeSy（transformer + GA + GP）；與 2502.01806（NsPC 蒸餾規則）、2505.14510 BACON 同屬「把不透明模型轉成可解釋符號」，但 SeTGAP 走 「分變數骨架 → 級聯合併」 的獨特分解路線。
  • 最值得記的核心思想：「分而治之」——先解各變數的單變數形式（避免多變數同時搜尋的組合爆炸與局部極小），再用骨架當結構約束增量合併；以及「結構正確比域內 MSE 低更重要」（外推、可解釋皆受益）的論點。
  • 與 2512.15920 特刊總綱呼應：強調「結構正確 vs 純擬合」、外推泛化。
  • 定位：完整方法論文 + 大量實驗（受控問題 + Feynman/SRBench++）；適合做 可解釋 SR、模型蒸餾/事後解釋、神經符號迴歸 的人。
