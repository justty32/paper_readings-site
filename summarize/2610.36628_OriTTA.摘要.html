論文／訪談原始來源

OriTTA：從固定分類器幾何取得單樣本適應目標

一句話概括

OriTTA不從當前test batch估類別幾何，而在串流開始前以source linear head與每類一張合成anchor，固定投影子空間、重新選定的原點及class ideal points；online只對幾何可靠的特徵施angular／radial losses，以class-indexed memory維持未出現類別，並在記憶預測集中時reset。作者在四backbones×兩protocols×兩stream orders共16組的batch-size-1實驗，皆取得15種corruptions平均accuracy最高；這是特定synthetic corruption評估，非逐種corruption皆勝或任意shift保證。（§1、§4–5）

固定frame如何從source model建成

Linear logits為\(\ell_c(z)=w_c^\top z+b_c\)。先扣除classifier row／bias均值，再normalize：

\[v_c=\frac{w_c-\bar w}{\|w_c-\bar w\|},\qquad \beta_c=\frac{b_c-\bar b}{\|w_c-\bar w\|}.\]

\(v_c^\top z+\beta_c=0\)表示class logit等於所有logits平均的hyperplane，不是任意兩類的pairwise boundary。所有\(v_c\)組成\(V\)。扣共同分量不改class comparisons；投影\(P=V^+V\)再去掉classifier看不到的方向。（§3.1，式1–6）

每類anchor從random pixels對frozen source model最小化class CE；實作另加\(10^{-3}\mathrm{TV}(x)\)，Adam lr.1、1000iterations／cosine decay並clamp合法pixels。無source images、test data或統計prior；anchor只須feature可用，不要求外觀真實。其feature centroid為\(\bar z^a\)，新的原點

\[\omega=(V^\top V+\lambda I)^{-1}(\lambda\bar z^a-V^\top\beta),\qquad\lambda=K/100\]

最小化\(\|Vz+\beta\|^2+\lambda\|z-\bar z^a\|^2\)，兼顧接近各hyperplanes與anchor centroid。常數在IN-RN50選定後跨setting共用；learning rate仍按normalization type設定，不能說整個實驗完全無任何選參。（§3.1、A.2/A.4）

在\(\mathcal I=\omega+\operatorname{rowspan}(V)\)以\(\tilde z=\omega+P(z-\omega)\)運算；投影保留每個logit difference、argmax與softmax probabilities。四模型\(r=\min(K-1,D)\)，IN-RN50為999/2048、IN-ViT為768/768；後者\(P=I\)無方向可去。每類ideal point為\(\mu_c=\omega+sv_c\)，\(s=\operatorname{med}_c\|P(z_c^a-\omega)\|\)。Frame與anchors一經建立不再更新。（§3.1、表8）

Reliable gate與兩個單樣本loss

令\(u=\tilde z-\omega\)、\(t_c=u^\top v_c\)、\(d_{\perp,c}=\sqrt{\|u\|^2-t_c^2}\)。對predicted class \(c\)，先要求\(t_c>.5\)且\(d_{\perp,c}<.11\sqrt r\,t_c\)的cone，再要求距\(\mu_c\)不超過該類已入cone樣本距離的running .2-quantile。每類前20個cone samples全放行，再以其第四小距離初始化；後續按是否通過乘\(1-.8\eta\)或\(1+.2\eta\)、\(\eta=.02\)，該類未出現時tracker不動。這是online per-class quantile，不是讀到未來全test set再挑最接近20%。（§3.1、A.5）

僅gate通過者計

\[L_{ang}=-\log\frac{\exp(-d_{\perp,c}/\sqrt s)}{\sum_j\exp(-d_{\perp,j}/\sqrt s)},\qquad L_{rad}=\frac1r\max(0,\|u\|-(s+\delta))^2,\]

\(\delta=\frac13\operatorname{med}_i\min_{j\ne i}\|\mu_i-\mu_j\|\)。前者以negative axis distances替classifier logits做CE；後者只壓過大radius，非把所有樣本向內拉，也非單獨保證靠近正確類別。更新共享normalization affine parameters會同時影響未計loss的輸入。（§3.2）

Memory、對齊與reset互補

Bank每個predicted class slot存一張input，初始是anchor；online以update前predictive entropy<\(0.4\ln K\)准入，保留最近符合的input，同batch同類則取最近ideal point者。幾何gate不控制bank准入，因\(K=1000\)時太少樣本能填滿bank。因此「per-sample losses不需classifier softmax confidence」不等於整個算法不用confidence；bank仍可能收進confidently mislabeled input。（§3.3、A.6）

每\(\lceil30/B\rceil\)steps按round-robin取\(\min(20,K)\)slots，以current backbone重新encode，將projected features拉向原slot label的固定\(\mu_c\)；不重新pseudo-label bank後再對齊。\(L_{align}=\frac1{|\mathcal S|}\sum_{c\in\mathcal S}\|\operatorname{proj}_{\mathcal I}f_\theta(m_c)-\mu_c\|^2/r\)，總loss為\(L_{ang}+L_{align}+2L_{rad}\)。（§3.3–3.4）

每\(\lceil200/B\rceil\)steps無gradient重分類全bank，計\(\sigma=\max_j|\{c:\hat y(m_c)=j\}|/K\)。當\(\sigma>.25\)且距初始化／上次reset至少1000frames，恢復source affine parameters、重建optimizer丟Adam moments、bank重seed anchors並清quantiles及warm-up。它量測bank predictions合併程度，不是ground-truth accuracy或bank標籤汙染率的直接估計；不直接以incoming class frequencies觸發。（§3.4、A.6/B）

評估設計與baseline邊界

C10用WRN-28-10／BatchNorm，C100用AugMix WRN-40-2／BatchNorm，ImageNet用ResNet-50／GroupNorm與ViT-B/16／LayerNorm。僅適應norm affine，ViT最後classifier前LayerNorm亦freeze；classifier、conv／attention weights皆freeze。Adam lr為LayerNorm \(2.5\times10^{-4}\)、BN/GN再除8。BatchNorm保source running statistics。（§4.1、A.1）

每dataset的15corruptions取severity5，CIFAR每corruption10000圖、ImageNet50000圖；主實驗batch1、一圖一update。Episodic在corruption邊界回source，continual跨15種不作邊界reset，但OriTTA自身collapse reset仍啟用。Shuffled與class-blocked兩order皆每seed重排，後者重排class順序與class內順序；同seed各method byte-identical stream，10seeds2021–2030，報accuracy均值及跨seed SD。16組不是16datasets。（§4.1、A.8）

六baseline為TENT、EATA、SAR、DeYO、ReCAP、SaTeen，採官方batch1設定；本文EATA實為無Fisher regularizer的ETA variant。CIFAR ReCAP variance prior另從clean CIFAR training features取得並calibrate scale。Continual沿released wrapper重建方式，SAR／ReCAP recovery reference為當前corruption起點權重，已可能退化；OriTTA collapse reset回真正source。這些差異是理解結果的必要條件，非只有loss一項不同。（A.10）

100seed穩定性與detector移植

另在IN-RN50、episodic／shuffled的zoom、elastic、fog，各跑100seeds2001–2100，共300runs。表2 collapse rate定義為fog accuracy<5%的seed比例：DeYO66%、ReCAP33%、SaTeen62%、TENT100%，EATA／SAR／OriTTA皆0%；不能說只有OriTTA從不collapse。OriTTA三corruptions accuracy為46.5±.2／49.7±.3／59.0±.2，作者並報同300runs無collapse；此處失敗率定義與online bank \(\sigma\) reset threshold不同。（表2、§4.2）

把bank detector／source reset換入SAR但保loss、filter、optimizer的SAR+RT，在IN-RN50 continual／class-blocked由21.57→38.51，mean resets約9025→3；OriTTA41.98／4.6resets，RDumb固定64000images回source為28.64／11resets。這不是只換一個threshold：reference state也從corruption起點改回source。OriTTA episodic ImageNet／C100不觸發，但C10 class-blocked仍4/10runs觸發、平均.5次；「從不reset」不適用全庫設定。（表7、附錄C）

消融、成本與限制

IN-RN50移除projection：episodic／shuffled49.59→47.02；C100 class-blocked把origin改0並重算幾何61.69→59.73。Prototype進own cone比例C100 .47→.99，C10仍0→0；frame各項不是所有backbone等量受益。（§4.3，表5–6）

IN-RN50 episodic／class-blocked full48.98，拿掉angular／radial／alignment後35.05／47.94／48.19。長block下alignment更重要：C10每class1000images，拿掉後68.96→60.94，resets .5→37.1／run；反覆回source不是良好穩定性。另同設定SGD50.93反高於Adam48.98，但平均SD .32高於.10；作者為穩定性、跨scale與batch-size規則仍選Adam，不說Adam每項最好。（D.1–D.3，表15–18）

Batch-size ablation在IN-RN50 episodic、B1–64；以各方法published lr規則，OriTTA均值領先、shuffled變動<.8points、class-blocked<.5。OriTTA schedules以frames定義、steps取ceiling，lr隨\(\sqrt B\)；不將此擴成任意batch／domain穩定。（A.7、D.4）

單RTX PRO6000 Blackwell96GB上，IN-RN50 episodic／shuffled全15corruptions5.4h；SAR12h、ReCAP6h、SaTeen7h，但TENT2.8h、EATA4.5h、DeYO3.5h更快；不含一次性anchor synthesis。Bank需存K張input，另每30frames對齊最多20張、每200framesprobe全K張，並非免費的single-sample update。（A.11，表12）

作者限制：\(K-1\ge D\)時projection無作用、小K時recenter作用弱且cone過窄；假定linear head的centered rows近equiangular，long-tailed training未必成立；僅synthetic corruptions，ImageNet-R／Sketch等natural shifts尚未驗。VLM prompt adaptation不在範圍。未來可回最近healthy state而非source、重校小row-space cone、延伸dense prediction。（§5、附錄B）
