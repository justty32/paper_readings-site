論文／訪談原始來源

《感知不確定性下推理的神經符號框架》重點摘要

一句話概括

一個把不確定性從感知顯式傳播到規劃的 NeSy 框架：Transformer 感知前端 + GNN 關係推理 從視覺觀察抽出帶校準信心分數的機率符號狀態，再交給一個不確定性感知的符號規劃器——信心低時主動做資訊蒐集動作（look_closer / push_obstacle）。以桌面機器人操作為具體應用，符號預測 F1=0.68、操作成功率平均 90.7%，比最強 POMDP 基線高 10–14 分且規劃只需 10–15 ms（POMDP 需 100+ ms）。

解決什麼問題

  • 連續感知訊號 ↔ 離散符號推理的橋接，在不確定下尤難。傳統法要嘛假設完美感知（不切實際）、要嘛純感知層運作（缺可解釋與泛化）。
  • 既有 NeSy（NS-CL、Neural-Symbolic VQA）假設確定性符號狀態（感知＝觀察到謂詞的二元映射）→ 無法量化/傳播不確定性、不會在不確定時主動蒐集資訊。
  • POMDP 雖原則性處理不確定，但 (1) 直接在高維觀察空間（RGB）推理 → 信念狀態指數複雜、100+ ms;(2) 缺符號抽象——對原始像素推理而非語意關係（On/LeftOf/Clear）→ 無可解釋計畫、難注入領域知識。
  • 三大不確定來源：感測噪聲、模型偏差、部分可觀察性。

方法

  • 神經符號翻譯器（連續觀察 → 機率符號狀態）：
    • ResNet-18 骨幹抽視覺特徵 + 可學物件查詢 + 8 頭多頭自注意力（動態處理 3–10 個物件）+ 物件偵測頭（bbox + objectness）。
    • GNN 關係推理：場景當全連接圖，18 維邊特徵（2D 空間/bbox/尺寸比/3D 位姿等幾何描述子）做訊息傳遞，輸出每個有序物件對的關係機率。
    • 混合 Transformer-GNN：Transformer 給全域脈絡與自適應物件選擇、GNN 經訊息傳遞施加幾何約束 → 在接觸密集關係（On: F1=0.52）上勝純 Transformer/GNN。
  • 自適應、關係專屬閾值：On=0.5、LeftOf/CloseTo/Clear=0.3（不同關係預測特性不同）→ 比固定閾值提升 143%（F1 0.68 vs 0.28）。
  • 不確定性感知符號規劃器：PDDL 領域 + A* 搜尋（只用信心 >τ 的謂詞）；信心低於校準閾值時自動觸發資訊蒐集動作，依場景複雜度提升成功率 4.7–10.0%。
  • 閉迴路執行：感知→機率符號→自適應閾值+空間驗證→規劃；不確定則 re-observe/probe 更新觀察迴圈。

理論貢獻

  1. 校準-收斂連結（Theorem 3）：規劃收斂保證顯式依賴校準品質 ECE——校準差（高 ECE）會使收斂界失效，需更多資訊蒐集步。首次量化「感知品質 ↔ 規劃保證」。
  2. 相依感知不確定性建模（MRF）：用馬可夫隨機場建謂詞相依（互斥、蘊含、相關），比獨立假設給更緊的界（操作場景關係強耦合時更準）。
  3. 最優閾值選擇（Theorem 6）：推導平衡成功率與規劃效率的最優規劃信心閾值解析式（非 ad-hoc 調參）。
  • 另含 Theorem 1（獨立情況不確定性傳播，乘積律基線）、Theorem 4（A* 最優性）、Theorem 5（時間複雜度）。

實驗

  • 資料：10,047 個 PyBullet + YCB 物件合成場景（3–10 物件，RGB 224×224，關係 On/LeftOf/CloseTo/Touching/Clear）。
  • 符號預測：整體 F1=0.68。
  • 操作任務（各 50 trials）：Simple Stack 94% / Deep Stack 90% / Clear+Stack 88% = 平均 90.7%，比最強 POMDP 基線（DESPOT/POMCP）高 10–14 分，規劃 10–15 ms（POMDP 100+ ms）。
  • 理論驗證：不確定性下降符合預測律；收斂界緊（理論 17% 內）；最優閾值與實測吻合 → 理論可預測而非抽象。
  • 消融：自適應閾值、資訊蒐集、各組件貢獻皆正向。

局限

  • 模擬-現實落差（sim-to-real）；資訊蒐集動作在模擬中簡化（真機需考慮感測器擺位、動作安全/可逆、即時性）；假設 Theorem 3 的不確定下降率 r 為常數（真實可能隨進度/狀態/動作型變化）。
