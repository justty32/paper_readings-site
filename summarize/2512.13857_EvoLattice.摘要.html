《EvoLattice》重點摘要

一句話概括

EvoLattice 把「LLM 引導的程式/智能體演化」從單候選、覆寫式突變（FunSearch / AlphaEvolve 那種，每次只留一個候選、改動具破壞性）改造成單一有向無環圖（DAG）內含整個族群：每個節點存多個並存替代方案（alternatives），圖中每條合法路徑就是一個可執行候選，於是用不複製結構換得指數級組合搜尋空間。它對「每個替代方案出現的所有路徑」逐一評分，產生替代方案層級的統計（均值/變異/最佳貢獻）作為密集回饋餵給 LLM 做突變/重組/剪枝；再用確定性自我修復保證無環與依賴一致（不靠 LLM 守規則）。在零訓練 NAS 代理發現任務上，Spearman ρ 達 0.15–0.16，勝過所有固定零樣本代理與 LLM 單路徑演化法（次佳 ShinkaEvolve-style ≈0.12），且變異更低、收斂更快；動態自然呈現 MAP-Elites 式品質-多樣性。

解決什麼問題

現有 LLM 驅動演化（FunSearch、AlphaEvolve、ShinkaEvolve、Darwin Gödel Machine）共享同一表徵瓶頸：演化物件是單一龐然候選，突變即覆寫——丟棄有用變體、易破壞結構、無法保留多個競爭策略、無法把不同個體的部分成功融合、無法累積可重用微算子庫。LLM 只看到「整個候選的純量分數」，缺乏對可重用子組件的信用分配（credit assignment）。

核心方法

  • EvoLattice 表徵：DAG，節點＝功能組件（數值算子/符號子程式/智能體子策略），每節點存一組 alternatives（程式演化時是 lambda，智能體演化時是 prompt 片段/工具描述）；邊＝資料依賴；指定 output 為根。每條從依賴到 output 的合法路徑＝一個可執行候選，全部路徑構成隱式編碼於單一結構的候選家族。
  • 組合式評估 + memoization：枚舉（或抽樣）所有路徑執行；用含 lambda 原始碼的防碰撞簽章做全域子路徑快取，重用重疊上游子圖 → 運行時與單路徑法相當卻擷取更多資訊。
  • 替代方案層級統計：對每個 alternative，蒐集所有含它的路徑分數 → 算均值效應、變異、最佳貢獻；另對當前最佳路徑注入小高斯擾動量測節點重要性。這些統計直接呈給 LLM。
  • LLM 突變（用 gpt-oss-120b，假設生成 temp=0.5、突變 temp=0.0）：先自動生成「任務感知假設」嵌入 prompt，附結構 diff；LLM 做局部組合式編輯（刪弱替代/在既有節點增替代/增節點/調依賴），不重寫整個程式。
  • 確定性自我修復：每次突變後強制無環、移除懸空依賴、剪空節點、保證可達性 → 把結構正確性的責任移離 LLM。
  • 單調擴張：候選空間只在效能支持下才縮（targeted 刪除），壞突變只影響局部，強路徑恆存。

結果

  • NAS-Bench-Suite-Zero（Medium）：EvoLattice Spearman ρ=0.15–0.16（CI ±0.04），勝固定代理（Spectral 0.06、ZeroLM 0.09、LPZero 0.10）與 LLM 單路徑演化（FunSearch 0.09、AlphaEvolve-diff 0.11、ShinkaEvolve 0.12）。
  • 更低變異、更快穩定：best-so-far 單調上升且呈離散跳躍（非破壞性突變保留強路徑、不回退）；改善稀疏而爆發式；可執行路徑數快速成長但 memoization 使運行時不爆。
  • 不只重發現：發現的最佳代理結構近似 ZeroLM，但加入穩定化變換（層級向量化、top-k 聚合、變異係數可靠度建模、非線性閘控、低權重熵 tie-breaker），在 FP16/取樣損失/異質架構等真實噪聲下修復脆弱代理；移除這些穩定化組件則效能崩回 naïve ZeroLM。
  • 額外在「零訓練優化器更新規則發現」上驗證泛化（附錄 D）。

局限

  • 可擴展壓力：路徑數組合爆炸，即便 memoization，節點/替代增多後評估成本仍高；最優路徑抽樣/重要度抽樣/代理建模理論待補。
  • 結構膨脹：長期運行累積過多替代方案；剪枝又與探索拉扯，需自適應圖正則化/稀疏化策略。

對讀者的價值

  • 本批 G 類**「LLM × 演化式程式發現」的代表性新表徵**——與 2505.22954（Darwin Gödel Machine 自改寫智能體）、2506.23408（LLM 夢見離散演算法）同屬「LLM 當演化算子」陣營，但 EvoLattice 的賣點是把品質-多樣性（MAP-Elites）內建進單一 DAG 表徵，而非外部 archive。
  • 最值得記：「一個節點存多個並存替代方案、每條路徑＝一個候選、用 memoization 撐住組合爆炸、用替代層級統計做信用分配、用確定性修復卸下 LLM 守規則負擔」 這套組合拳；以及它讓程式演化與智能體（多智能體）演化統一在同一框架。
  • 與經典 GP（2501.17168 EvoGP、2504.10253 TinyverseGP）對照：EvoLattice 把「族群」從個體間挪到單一個體的內部結構，是對 modular GP / QD 的有趣重構。
  • 適合做 LLM 程式合成、神經架構搜尋零樣本代理、品質-多樣性、多智能體系統演化 的人。
