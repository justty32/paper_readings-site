對讀者的價值

  • 定位：主題 9（治理／棄權-委派）的關鍵一步——把「拒絕為預設」變成可訓練的端到端目標。 ai_core §3.4 的治理直覺是「拒絕為預設＋憑證准入」；SelectiveNet 把這個直覺從「事後加閾值」升級為「訓練時就把 g(x)≥0.5 這個准入憑證跟 f 一起學」，而 coverage c 本身就是一個可直接調的治理旋鈕——調高 c 犧牲風險換覆蓋、調低 c 犧牲覆蓋換風險，對映 ai_core 想要的「穩定度 % 門檻」可以是訓練時的目標而非事後拍板的閾值。
  • 與庫中既有棄權/委派系列的定位對比：
    • 1705.08500 Selective Classification（同作者群前作）：f 是事後給定、不與 g 聯合訓練，κ_f（信心函數）只需能排序即可，換取統計上界的可證明性。SelectiveNet 正是承接該文「最難的開放問題——同時訓練 f 與 g」而來，用端到端訓練換取更好的 risk-coverage 曲線，但代價是失去 1705.08500 的機率保證（覆蓋率違反需靠額外校準/Hoeffding bound 補回）。
    • 1711.06664 Learning to Defer：棄權不是終點，關鍵在「棄權後交給誰」——s 學的是「這一例上模型與下游決策者誰的損失較低」。SelectiveNet 完全沒有下游決策者的概念，g=0 只輸出「don't know」，是 Learning to Defer 框架中「委讓對象損失恆定」的退化特例。
    • 2405.01563 Conformal Abstention：用取樣一致性當信心分數、以 conformal prediction 給棄答門檻分佈無關的統計上界，是黑箱、免訓練、事後校準式棄權；SelectiveNet 則是白箱、需要重新訓練整個網路的棄權，兩者是「事後統計保證」vs「訓練時聯合最佳化」的兩極。
    • 2504.19254 UQ Scorers 與 2506.09669 Query-Level Uncertainty：兩篇都在為黑箱/可存取 logits 的模型找信心分數的來源（集成多種 UQ 訊號、或生成前的 internal confidence）。SelectiveNet 的 g(x) 本質上就是「可學習出來的信心分數」，但它要求可微、可端到端訓練的網路架構才能學出來——這正是它套用到 LLM 節點時的落差所在。
  • 對 LLM 場景的落差（也是本庫跨篇結論的根源之一）：SelectiveNet 的核心優勢（g 與 f 共用表徵、聯合最佳化）建立在「整個網路可微、可重訓」之上。面對黑箱 LLM 節點（API 呼叫、無法拿到梯度、甚至無法拿到 logits），SelectiveNet 的架構完全無法直接套用，只能退化成「外掛在 LLM 輸出後面的 gate」——也就是 1705.08500／2405.01563／2504.19254／2506.09669 這條事後信心分數路線。換言之，「可靠、可微的品質分數」仍是級聯（§3.3）與治理（§3.4）共同缺乏的那塊拼圖：SelectiveNet 示範了「有此分數時聯合最佳化能贏多少」，卻無法回答「黑箱 LLM 節點上這個分數該從哪裡來」。
