論文／訪談原始來源

Agent2World: Learning to Generate Symbolic World Models via Adaptive Multi-Agent Feedback 重點摘要

一句話

用「深度研究者—開發者—測試團隊」三個角色的多智能體迴圈，把生成符號世界模型（PDDL 或可執行程式碼）從一次性生成變成靠執行回饋反覆修正的過程，同時把這個推論期互動軌跡直接收成訓練資料，拿去監督微調同一顆模型。

三階段架構與訓練範式

  • Stage I 知識合成:Deep Researcher agent 用網路搜尋補齊描述裡缺的常識知識，輸出補完後的中介表示，解決 LLM 本身常識不足或描述本身不完整的問題。
  • Stage II 世界模型生成:Model Developer agent 帶著沙箱程式碼執行工具，把補完後的描述實作成 PDDL 或可執行程式碼，執行失敗就在同一輪內反覆除錯。
  • Stage III 評估驅動精修:Unit Tester 針對描述裡的謂詞、動作、不變量自動產生 Pytest 風格單元測試；Simulation Tester 用 ReAct 迴圈實際跑軌跡，抓出「目標不可達」「前置條件缺失」「狀態更新不一致」這類只有互動執行才會暴露的行為級錯誤。兩者產生的診斷回饋送回 Model Developer，直到通過檢查或達收斂上限。
  • 訓練範式：把 Model Developer 與 Testing Team 的互動形式化成一個 MDP——狀態是世界模型描述加測試診斷，動作是新實作或修補，獎勵聚合單元測試通過率與模擬表現。再用 verifier-guided rejection sampling 篩選軌跡：只有最終模型「可在沙箱成功執行」且「通過 Testing Team 的測試與模擬檢查」才保留，聚合成 1526 條涵蓋四種世界模型類型的訓練軌跡，用於監督微調 Llama-3.1-8b。

作者報告的結果

三個 benchmark（Text2World 的 PDDL 生成、CWMB 的 MuJoCo 風格可執行程式碼、ByteSized32 的推理密集文字遊戲）上，Agent2World_Multi 在 gpt-4.1-mini 與 Llama-3.1-8b-instruct 兩種底層模型都取得作者自報的最佳成績。Text2World 上可執行率達 93.1%，比對照的 Text2World_EC=3 高 14.9 個百分點，F1_avg 達 75.4（作者自報）。CWMB 上整體正規化回報 R 達 0.4811，比先前最佳的 GIF-MCTS 高 0.132（作者自報）。SFT 後的 Llama-3.1-8b 相對訓練前平均相對提升 30.95%（作者自報，摘要語）,Text2World 可執行率從 27.7% 升到 44.6%(+16.9)。消融顯示拿掉 Unit Tester 對 CWMB 離散動作空間影響最大（正確率降 0.3008、R 降 0.4470，作者自報）。

對 ai_core 的價值／接點

這篇最直接可借的是驗證器守門的訓練資料引擎設計：Testing Team 不是單純的離線驗證，而是動態依當前模型犯的錯誤合成測試案例，再用「能否在沙箱執行 + 能否通過合成測試/模擬」這個二元 verifier 篩選要不要保留整條互動軌跡進訓練集——這正對應 ai_core §3.4 治理原則裡「憑證准入」該長的樣子：准入門檻不是靜態規則清單，而是可執行、可重新合成的動態檢查。對固化引擎（§5）的啟發是，推論期的多輪修正互動本身就是可直接轉成訓練軌跡的副產品，不必另外設計資料蒐集流程；但這個機制的可信度完全繫於 Testing Team 本身的測試覆蓋——若合成測試有系統性盲區（測不到某類行為維度），被留下的訓練軌跡會把這個盲區一併蒸餾進模型裡。對 ai_core 而言，「軌跡通過 verifier」不能直接等同品質保證，固化前仍需獨立檢查 verifier 本身的覆蓋率。
