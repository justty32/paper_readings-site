論文／訪談原始來源

《透過元學習提高訓練 KAN 的記憶體效率（MetaKAN）》重點摘要

一句話概括

MetaKAN：不直接最佳化 KAN 的海量激活函數參數，而是用一個更小的「元學習器（meta-learner）」生成這些權重——靠「可學習提示（learnable prompt）當每個激活函數的識別符 + 一個兩層 MLP 元學習器學共享的權重生成規則」，端到端可微訓練，只用 KAN 1/3 到 1/9 的可訓練參數就達到相當甚至更好的效能，把 KAN 與 MLP 的訓練成本差距大幅縮小；且模型無關（model-agnostic），可套用到 FastKAN/ConvKAN/WavKAN 等變體。

解決什麼問題

KAN 把固定激活函數換成邊上可學習的 spline 激活函數，更靈活可解釋；但每個激活函數都帶可學習係數 → 參數量約為同結構 MLP 的 G+k+3 倍（G=grid 數、k=spline 階），記憶體效率差、訓練成本高、難擴展到大資料/複雜任務。這正是原 KAN 論文點名的痛點。

核心方法

  • 關鍵觀察：KAN 把高維函數分解成逐維的單變量函數，而這些單變量函數同屬一個共享函數類 Ω、共用同一套「參數設定規則」。於是 KAN 的權重學習可視為多任務學習：每個激活函數是一個迴歸任務，由「任務資訊 c」對應到「該激活函數的 spline 係數」。
  • MetaKAN 框架（圖 1）：把 KAN 每個激活函數的權重改由 w = h(c; θ) 生成——
    1. 可學習提示 c（prompt）：每個激活函數的唯一識別符（類比 LLM 的 prompt）。
    2. 元學習器 h（兩層 MLP）：學「識別符 → spline 係數」的共享生成規則。 原本龐大的激活函數參數 → 壓縮成「提示 + 小元學習器」的參數。提示與元學習器同時用梯度下降更新（Algorithm 1）。
  • 擴展到深層 KAN（Algorithm 2/3）：不同層的任務分布會「漂移」，單一共享元學習器難擬合 → 把層分群成 K 個 cluster（依輸入/輸出通道相近分組），每群配一個專屬元學習器，在表達力與記憶體間取平衡。
  • 模型無關：同框架可生 MetaFastKAN、MetaWavKAN、MetaConvKAN 等。
  • 記憶體效率條件：元學習器是固定成本，當「省下的 spline 參數」> 此固定成本才划算 → 網路越大越深、grid 越大越有利；極小 KAN 反而可能略增參數。總參數量近似等於同結構 MLP。

結果（含數字）

  • Feynman 符號迴歸（表 2，16–17 條方程）：grid=5 時 11/17 條 MSE 更低、參數減 21–47%;grid 較大時 13/16 條更優、平均省 18% 參數。I.12.5 方程 MSE 有一個數量級提升（30 參數 vs KAN 57）。
  • 卷積架構（表 3，MNIST/CIFAR-10/CIFAR-100）：4 層 MetaKANConv 在 CIFAR-10 達 45.86%、參數減 89%（392K vs 3.49M），且高出 baseline 6.03 個百分點；MetaFastKANConv 在 CIFAR-100 達 34.81%（vs 28.84%）僅用 12% 參數；8 層 MetaFastKANConv 在 CIFAR-10 達 81.53%、參數減 78%。
  • 記憶體（圖 4）：網路越大、grid 越大，MetaKAN 峰值 GPU 記憶體節省越顯著。
  • 提示語義（圖 10）：相似激活函數的學到提示更相似（熱圖暗區），佐證提示確實能識別激活函數。

局限

  • 極小 KAN（總激活數很少）時，元學習器固定成本反而使參數略多於 KAN。
  • 元學習器隱藏維度需配合 grid 大小挑選（grid 小要用很小的隱藏維才省）。
  • MetaKAN 與 KAN 本身在影像分類 benchmark 仍可能弱於既有基線（作者於 Impact Statement 自承）。

對讀者的價值

  • 本批 H 類（KAN） 中走「HyperNetwork / meta-learning 生成權重」路線的代表，與 2501.17411（GA-KAN，用演化計算搜尋稀疏架構減參）對照：兩者都治 KAN 參數爆炸，GA-KAN 砍結構、MetaKAN 砍權重表示冗餘。
  • 最值得記：「KAN 激活函數＝共享函數類的多任務」 這個重構視角，以及由此導出的「prompt（識別符）+ 小 meta-learner（共享規則）」配方；深層用分群多元學習器；參數量可壓到接近 MLP。
  • 與 HyperNetwork 的差別：不靠啟發式整層共享，而是顯式建模 KAN 的權重生成規則。
