《Macaron-V1》重點摘要

一句話

Macaron-V1 是把 frozen base、每回合只選一個 specialist LoRA、可版本化 harness 與 recursive self-improvement 基礎設施一起設計的 agent-model family；它提出持續學習的架構，但尚未證明跨世代累積增益。

系統

  • Venti 以 744B GLM-5.2 base 加 Chat、Agent、Coding、GenUI 四個 1B LoRA；Tall 則在 Qwen3.6-35B-A3B 上採相同四類。
  • L0 以 24-token constrained decode，每個 user turn 選一個 adapter；target adapter 以自己的 conversation view 作答，再輸出最多 192 token 的 server-side summary。工具結果會黏在原 adapter，transaction 失敗可 rollback。
  • Model–Harness co-design 包含 component-native UI4A、可執行 REPL agent、Harness Context Protocol；MindForge／MinT／LongStraw 支撐版本化訓練、長 context 與 sparse-base serving。

證據與重要保留

作者在 6,448 筆 routing trace 報 Venti 99.12% routing accuracy，但 trace 來自 LoRA 訓練資料，僅是實作診斷。多 benchmark 表內有內部評測與外部 public 值，不能跨列平均或視為同協定排行；作者自己列出 component attribution、長期 RSI、不同團隊 adapter composition、資料治理與安全測試均未證明。Venti 在自家 ChatBench/LivingBench 報 58.3/64.0，UI4A-Bench 87.8，皆應按其 protocol 解讀。
