論文／訪談原始來源

《改進符號迴歸的蒙特卡羅樹搜尋》重點摘要

一句話概括

改進 MCTS 用於 SR 的兩大創新：(1) 極值老虎機（extreme bandit）分配策略——專為「找全域最優表達式（而非平均獎勵）」設計，多項式獎勵衰減假設下有有限時間保證;(2) 演化啟發的「狀態跳躍（state-jumping）」動作（變異、交叉）——非局部跳到搜尋空間有望區，並重塑獎勵地形（加速且穩定收斂）。在 ground-truth 與黑箱資料集上回復率與 SOTA 相當、且在準確-複雜度 Pareto 前沿佔優位。

解決什麼問題

  • SR 是 NP-hard 組合優化（搜尋樹結構 + 參數）。GP 主流但常產過複雜公式、對超參敏感;RL/MCTS 把 SR 當序列決策，但傳統 bandit 策略 + 逐符號建構限制表現。
  • SR 與傳統 RL 兩處不同：(1) 目標是找全域最優狀態（最高獎勵）而非最大化期望累積獎勵；(2) 動作空間可設計成彈性狀態跳躍，繞過逐步轉移。

兩大創新

  1. 極值老虎機分配策略（UCB-extreme）：類比 UCB 但UCB 最小化平均 regret，SR 要單一最佳結果 → 用 extreme-bandit 設定；多項式獎勵衰減假設下有最優性保證。但對尾衰減率參數敏感、需仔細調、複雜目標式上常掙扎。
  2. 演化啟發的狀態跳躍動作（變異 + 交叉）：把 GP 的非局部轉移嵌進 MCTS → 跳到有望區。重塑獎勵地形：加入前 Nguyen-4 的獎勵尾衰減（Beta 分布 β 參數）落在某區間，加入後β 降到 <2 → 更快更穩收斂（其餘 Nguyen 案例 β 也移到 [2,4]）。

結果

  • 基本 benchmark（Nguyen/Nguyen C/Jin/Livermore，200 萬評估預算、100 次平均）回復率：
    • Nguyen 93.25%（vs NGGP 92.33、GEGL 86、DSR 83.58、PySR 74.41）;
    • Nguyen C 100%、Jin 100%（vs DSR 70.33、PySR 72.17）;
    • Livermore 71.41%（vs NGGP 71.09、GEGL 56.36、DSR 30.41）。
    • 與 SOTA（DSR/GEGL/NGGP/PySR）相當或更優。
  • SRBench 黑箱（122 任務，對比 21 個基線）：測試準確第 2（僅次 Operon）但模型簡單得多；在準確-複雜度 Pareto 前沿位列頂尖（與 Operon、GP-COMEA、DSR 並列）。

對讀者的價值

  • 本批 C 類的**「MCTS/RL-based SR」代表**——與 2511.05849 EGG-SR（MCTS/DRL 嵌等價）、2503.06879（Actor-Critic SR）同脈，但本文獨特在**(1) 極值老虎機（找全域最優而非平均）+ (2) 把 GP 的變異/交叉當 MCTS 狀態跳躍動作**（混合 RL+GP）。
  • 最值得記的兩個洞見：「SR 要全域最優 → 該用 extreme bandit 而非標準 UCB」;「狀態跳躍（mutation/crossover）重塑獎勵地形（降尾衰減 β）→ 加速收斂」；以及「MCTS+演化動作」的混合範式。
  • 與 2512.10849（貝氏 SR 的 risk-seeking）皆關注「找最佳而非平均」的搜尋目標。
  • 定位：方法論文 + 理論保證 + benchmark（PKU，有開源）；適合做 MCTS/RL-based SR、組合優化、extreme bandit 的人。
