作者：Yaniv Leviathan, Matan Kalman, Yossi Matias（Google Research）

日期：2022-11

arXiv：2211.17192

論文／訪談原始來源

《透過推測式解碼加速 Transformer 推論》重點摘要

一句話概括

Speculative Decoding（推測式解碼）：用一個便宜的近似模型 Mq 平行猜出接下來的 γ 個 token，再讓貴的目標模型 Mp 一次前向就把這 γ+1 個位置全部平行驗證；搭配新提出的 speculative sampling（推測式抽樣） 的 accept/reject 規則，保證系統輸出分佈與「單獨跑 Mp」完全相同（無損）。不改架構、不重訓、不改輸出，即插即用地在 T5-XXL 上取得 2X–3X 的實測加速。

解決什麼問題

大型自迴歸模型（如大 Transformer）推論慢：解碼 K 個 token 需要 K 次串行的模型前向。既有加速法（蒸餾、稀疏化、量化、自適應計算 / early-exit 等）多半要改架構、改訓練流程、重訓模型，且不保證輸出不變。作者的兩個關鍵觀察是：(1) 困難的語言建模任務裡常夾雜可被小模型良好近似的簡單子步驟；(2) 大模型推論常不是卡在算力，而是卡在記憶體頻寬與通訊——因此還有餘裕的算力可拿來換平行度。於是他們把處理器的 speculative execution（推測執行，如分支預測） 推廣到「隨機（stochastic）」情境。

核心方法

  • 三步驟（Algorithm 1，::SpeculativeDecodingStep）：
    1. 用便宜的 Mq 自迴歸地猜 γ 個 token（x₁…x_γ）。
    2. 用貴的 Mp 平行計算這 γ+1 個前綴位置的分佈 p₁…p_{γ+1}（一次前向驗證）。
    3. 逐一以 accept/reject 判定：token 若 q(x) ≤ p(x) 直接接受，否則以機率 1−p(x)/q(x) 拒絕；第一個被拒處從調整後分佈 p′(x)=norm(max(0, p(x)−q(x))) 重抽一個修正 token，全接受則額外多送一個。
  • 無損保證：附錄 A.1 證明對任意 p、q，如此抽出的 token 恰好服從 p(x)，故輸出分佈精確等同單獨跑 Mp。最壞情況每次至少產出 1 個 token（不會比標準自迴歸慢），最好一次產出 γ+1 個。
  • 接受率 α 與加速：定義單一 token 的接受率 β，α=E(β)=1−E(D_LK(p,q))（D_LK 為 p、q 的一種散度）。i.i.d. 假設下每次迭代期望產出 (1−α^{γ+1})/(1−α) 個 token。若近似模型成本係數 c（Mq 對 Mp 的單次成本比），總 walltime 改善因子為 (1−α^{γ+1}) / [(1−α)(γc+1)]（Theorem 3.8）。α 越高、c 越小加速越大；c 幾乎為 0 時上界趨近 1/(1−α)。
  • 代價：以「增加算術運算量」換「降低延遲」——平行跑 γ+1 份 Mp，被拒的猜測即浪費算力；故需有餘裕算力（記憶體頻寬是瓶頸時最划算）。近似模型可任選（不影響無損性）：實驗多用小兩個數量級的現成 Transformer，也試過連 unigram/bigram 這類零成本模型。

結果

  • 實測加速：在單張 TPU-v4、batch=1 下，相對於成熟的 T5X 實作，T5-XXL（11B）取得 2X–3X 開箱即用的延遲改善，且輸出完全不變。翻譯任務加速 2.6X（temp=1）/ 3.4X（temp=0），摘要任務 2.3X（temp=1）/ 3.1X（temp=0）。argmax（temp=0）比標準抽樣加速更高。
  • 模型與 α：Mp=T5-XXL、Mq=T5-small（77M）在 c 與 α 間取得最佳平衡、加速最高。經驗上「小兩個數量級」的近似模型 α 落在 0.5–0.9；分佈越尖銳 α 越高。連 bigram（EnDe 翻譯）都有 α≈0.2、對應 1.25X 加速。
  • 另有第三方在 Chinchilla 70B 上獨立復現，得到相近的 2X–2.5X 改善。
  • 附錄 A.5 lenience（寬容度）：若願意放寬「完全等同」，Mp=T5-XXL、Mq=T5-small 時，寬容值 1/0.5/0.3/0.1 可把加速推到 2.5X/3.1X/3.6X/5X（此時不再是嚴格無損）。

局限

  • 以算力換延遲：需有可用的額外算力；若無餘裕算力（非記憶體頻寬瓶頸）則不划算，反因浪費被拒運算而不利。
  • 論文只在文字模態、且只為 T5 完整實作了加速（其他模型只量測 α）；影像等其他模態、與 beam search 的相容性（附錄 A.4 僅初步）留待未來。
  • 固定的 γ 與固定近似模型並非最優：動態調 γ（理論上限再多約 60% 改善）、客製化 / 蒸餾 / 分層近似模型都留作 future work。

對讀者的價值

  • 與 ai_core 的核心接點（§3.3 per-request 成本梯度）：ai_core 的信念是「先讓笨模型做、沒通過驗證再升級給聰明模型」。Speculative Decoding 正是這條梯度在解碼（token）尺度的無損化身——便宜的 Mq 先猜、貴的 Mp 驗證，而且保證輸出等同單跑 Mp。
  • 最該記住的啟示：它以最乾淨的方式證明了「驗證比生成便宜、且可保正確性」——Mp 對 γ+1 個位置只需一次平行前向即可驗證一串猜測，成本遠低於逐 token 串行生成；且 accept/reject 的機率等價把「便宜端先跑」做成零品質損失。這正呼應 ai_core「確定性驗證器把關、便宜端先跑」的設計信念。差別在尺度與保證形式：本文是 token 層、機率等價的無損；ai_core 是任務層、以任務驗證器把關（未必機率等價，而是任務層可接受）。
  • 尺度對照：可與 2305.05176 FrugalGPT（任務層的 LLM cascade——便宜模型先答、不夠好再升級）並置理解：兩者同屬「便宜先跑 / 貴的把關」的成本梯度，一個在 token 解碼尺度且無損，一個在整體任務尺度。（FrugalGPT 內容不在本文萃取範圍，僅作尺度對照，不轉述其細節。）
