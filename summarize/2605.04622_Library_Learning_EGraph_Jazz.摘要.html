論文／訪談原始來源

《Library learning with e-graphs on jazz harmony》重點摘要

一句話概括

把「爵士和聲的樂句模式發現」直接形式化為程式合成中的庫學習：給定一批和弦進行，模型用 DSL（和聲關係作 primitive）枚舉每首曲子的所有推導（parse），再聯合地學一套可重用的和聲抽象（library）並用它重寫（refactor）所有推導；關鍵工程貢獻是把演繹式 parsing 與 e-graph 上的庫學習（babble 演算法）整合在 egglog 裡——用 e-graph 緊湊表示指數多的等價推導、用 anti-unification 在 e-class 間找最小一般化模板、用 MDL 成本集分析選最優庫，藉此避開「先窮舉所有 parse 再壓縮」會爆炸的 Catalan 數量級組合。三曲概念驗證上，聯合學習把總推導大小由 87 壓到 27（正規化壓縮率 1.5，優於逐曲學習的 1.16），且學出的抽象（ii-V-I、降五度進行等）與爵士理論及專家標註（JHTB）大致相符。

解決什麼問題

音樂模式發現（MPD）的兩難：模式要夠抽象才能涵蓋非精確重複，又要夠有分析意義才能解釋結構——太抽象則匹配氾濫多為瑣碎假陽性，太具體則脆弱抓不到「家族相似」變奏。作者主張「好模式 = 能在許多解釋中重用、能降低語料整體描述長度的抽象」，因此不該用頻率或表面相似度定義，而該用壓縮效用。傳統上「從表面推結構化推導」屬於 parsing（假設固定文法）、「從一堆程式抽共用子程序」屬於 library learning（假設已有程式語料），兩者被當成獨立問題；但若要直接從和弦表面學模式，可用的抽象決定推導空間、而抽象是否有用又取決於它如何參與各曲推導，兩問題互相依賴、必須聯合求解。

核心方法

  • DSL：採 Rohrmeier(2020) 爵士和聲文法，但把產生規則重新詮釋為和聲關係（如 Descending5th/V-I 是斷言兩和弦滿足音程與性質約束的邏輯謂詞），每個 primitive 以 egglog 邏輯規則編碼。
  • Parsing 階段：在 egglog 內以兩條推論規則跑到飽和，實作 CYK 式動態規劃；所有合法推導以等價類（e-class）緊湊合併，結果類似 Shared Packed Parse Forest（指數多推導壓在一張圖）。再用 root-connectedness 由上而下傳播，濾掉不參與任何完整 parse 的局部片段。
  • Anti-unification 階段：仿 babble，把經典的樹 anti-unification（求兩程式的最小一般化 least general generalization）擴展到在 e-class 之間計算；以動態規劃、交錯計算 e-node 與 e-class 的 anti-unifier，避免重複傳播；CanCoOccur 確保只在能共同參與完整 parse 的推導間抽象。
  • 壓縮（refactor）階段：候選模板加進 e-graph 當改寫規則、做 equality saturation，把重複結構替換成附參數的高階組合子（Template 程式，方括號表結構組合、尖括號路由引數）。
  • 成本集分析（cost set）：每個 e-node/e-class 配一組 (library 子集, 使用成本) 對，自底向上交叉組合、以 beam search 剪枝，實例化 MDL 目標 L* = argmin (cost(L) + cost(D|L))——抽象只在「編碼節省 > 自身複雜度」時被採用。

結果

  • 概念驗證限三首低歧義曲（Red Clay 長 13、Valse Hot 15、Sunny 17；庫上限 15、beam 寬 5）——因 egglog 實作尚未能撐大規模聯合推論。
  • 壓縮：聯合學習把三曲總推導由文法基線 87 降到 27，計入庫儲存成本後正規化壓縮率 1.5；逐曲學習雖總推導 28 略小，但庫儲存成本大很多（47 vs 31），壓縮率僅 1.16——聯合學習偏好「跨曲可重用」的抽象。
  • 質性：學出的抽象與爵士理論相符——f0 屬-主進行、f1 降五度、f2 具體 ii-V-I（被用 4 次）；也有左分支傾向的「不完整構成」抽象（如 f3「缺左側屬和弦的主和弦」，呼應範疇文法的方向性函數應用）。f9 正確以 VI-V 關係解析 Sunny 的 III-VI-ii-V-i（避開小調語境下不成立的應用屬和弦鏈），與 JHTB 專家標註一致。

局限

  • 僅三曲概念驗證；egglog 實作未對高歧義曲做大規模聯合推論優化。
  • 壓縮最優未必音樂上合理（Red Clay 開頭主和弦被指派非常規深層結構角色），可能是小語料效應，需更大更多樣資料集驗證。

對讀者的價值

  • 本批 G 類中**「庫學習 × e-graph × MDL」的乾淨範例**——直接把 DreamCoder/babble 的「壓縮即發現可重用抽象」搬到非程式碼領域（音樂），凸顯庫學習是一種領域通用的歸納偏置。與 2603.25975（wake-sleep 重新發現 Schank 事件 primitive）同屬「以壓縮壓力自動發現 primitive」一脈，但本文用 e-graph + anti-unification 而非 wake-sleep。
  • 最值得記：「parsing 與 library learning 互相依賴、應在 e-graph 上聯合求解」，以及「用 e-graph + cost set 把『先窮舉再壓縮』的 Catalan 級爆炸（C_{k-1}^N）剪到可行」這個工程關鍵。
  • 與 2606.07704 FunctionEvolve、2602.00929 TheoryCoder2 等「學可重用抽象/函式」工作互補；對研究 DreamCoder/Stitch/babble 系庫學習、e-graph/equality saturation、grammar induction、計算音樂認知 的人很有參考價值。
