論文／訪談原始來源

SkillForge: Compositional Skill Synthesis with Verification-in-the-Loop for Generating Formally Verified Dafny Programs 重點摘要

一句話

SkillForge 把自然語言到 verified Dafny program 的工作拆成六個各有明確 contract 的 atomic skill，再讓 harness 依 verifier error category 決定性地路由修復；在有完美 oracle 且錯誤可分類的領域，這種 bounded、可觀測的 skill orchestration 比 open-ended agent exploration 更準也更省。

問題與方法

寫出能通過 formal verification 的 Dafny code，同時要求 implementation、precondition、postcondition、loop invariant 與 termination annotation 彼此一致。one-shot generation 失敗後無從補救；naive repair 把不同錯誤都塞回同一個 prompt；agentic system 又得在有限且可分類的 error space 中花額外 reasoning 選 action。SkillForge 因而把問題改寫成 harness engineering。

skill library 包含 INFERSPEC、SYNTHBODY、GENINVARIANT、DIAGNOSEERROR、REPAIRCODE 與 STRENGTHENSPEC。每個 skill 都是 s=(P,T,C)，由 prompt template、tool binding 與 decidable success criterion 組成。INFERSPEC 先把自然語言轉成 type 與 contract scaffold，SYNTHBODY 在禁止修改 specification 的條件下生成 body；若 verification 失敗，DIAGNOSEERROR 以 regex 加 LLM fallback 分成 invariant_missing、spec_gap、body_error 或 type_error，再固定路由到相應 repair skill。

harness 保存目前 program、errors、diagnosis 與 history，支援 progress tracking 與 rollback。它以 hard iteration budget 保證終止；若 candidate 沒變，便用較高 temperature 重生；若 error count 連續惡化，便回復目前最佳版本。soundness 保證是條件式的：harness 只在 Dafny verifier 回傳成功時交付 program，因此 H(x)=d* != empty => Verify(d*)=true，不表示每個 verified program 都與使用者原意等價。作者另以 reference implementation 建立 Dafny lemma，分開檢查 precondition、postcondition 與 behavioral equivalence。

作者報告的實驗與結果

benchmark 含 178 個作者人工撰寫 natural-language description 的 Dafny pair，來源為 official tutorial、DafnyBench 與 open-source verification project，並分成 simple、medium、hard 3 種難度（作者自報）。主要 backend 是 GPT-5.5，Dafny 與 Z3 作為 oracle，所有 iterative method 的最大 action budget 為 5 次（作者自報）。

SkillForge 的 verification rate 為 91.6%，equivalence rate 為 86.5%；最強 baseline Proof2Silicon 的 verification rate 為 85.4%，差 6.2 個百分點（作者自報）。成功案例平均 1.8 次 iteration，71.3% 在初次嘗試即通過；83.1% 在 2 次內通過（作者自報）。hard subset 上，SkillForge 為 77.8%，最強 agentic baseline 為 66.7%（作者自報）。

ablation 顯示移除 iterative loop 使 verification rate 下降 20.3 個百分點；把 structured diagnosis 換成 random route 下降 11.8 個百分點；移除 GENINVARIANT 整體下降 7.9 個百分點，在 hard subset 更下降 22.2 個百分點（作者自報）。這支持兩個不同結論：verification-in-the-loop 是最大總體來源，而 category-conditioned routing 是 SkillForge 超過一般 agent repair 的關鍵。

成本方面，SkillForge 平均每題使用 4.6K token、2.8 次 verifier call 與 14.2 秒；相較 ReAct-Verify 少 48% token，相較 MCTS-Repair 少 68% token（作者自報）。後者平均需要 8.6 次 verifier call，顯示定向修復避免了 tree search 的大量旁支（作者自報）。

結論與局限

作者的結論是，當外部 oracle 完美、錯誤輸出可穩定分類時，atomic skill 加 deterministic routing 能提供比通用 agent 更透明、可測且有界的控制面。不過 verification 與 semantic equivalence 並不相同，兩者相差 5.1 個百分點，證明「通過 proof」仍可能偏離 reference semantics（作者自報）。

作者自陳的局限包括：benchmark 只有 178 個 example（作者自報）；skill library 為 Dafny-specific，搬到 Lean 4 或 Coq 需要重做 implementation；主要實驗依賴 GPT-5.5 與 Claude Opus-4.7，尚未測 open-source model；GENINVARIANT 成功率最低，為 64.7%，複雜 quantified loop 仍是主要 failure mode（作者自報）；skill template 由人工撰寫；agentic baseline 是依 published methodology 改寫到 Dafny，implementation difference 可能影響 absolute number。

對讀者的價值／ai_core 接點

對 ai_core，這篇提供一個非常具體的 orchestration 原則：如果 environment 已給出有限且可判定的 error taxonomy，next-action selection 就不必再交給自由形式 reasoning。可以把 diagnosis 當 routing key，把 skill contract 當准入證書，把 retry budget、stagnation detection 與 rollback 放在 deterministic harness。它也提醒固化流程要保留兩道門：第一道問 artifact 是否通過 formal checker，第二道問它是否仍符合原始意圖；只有第一道，會把 verification success 誤當成 semantic correctness。
