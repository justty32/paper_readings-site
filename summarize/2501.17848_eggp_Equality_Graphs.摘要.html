論文／訪談原始來源

《利用等式圖改進符號迴歸的遺傳編程（eggp）》重點摘要

一句話概括

eggp（e-graph genetic programming）：把編譯器優化用的等式飽和／等式圖（e-graph）接進 GP，記錄整個搜尋史的所有已訪表達式（含其等價形式），並改造子樹交叉與變異，讓運算子只生成「未曾訪問過」的表達式——這個極簡修改就把一個 minimalist GP 提升到能與 SOTA（PySR、Operon）競爭、且模型更小更可靠、不顯著增加計算成本。

解決什麼問題

GP 做 SR 時反覆重訪語意等價的表達式（同一式子的無窮多種參數化／語法變體）。重評等價式浪費算力、又不立即帶來更好解。Kronberger 2024b 量測發現 GP 搜尋中只有約一小部分表達式是唯一的（大量重複）。傳統認為冗餘有助於探索（等價式同精度、保留遺傳多樣性），但過去沒有高效驗證等價的手段，這假設無法被驗證。簡化啟發式也常不足。

核心方法

  • 等式飽和（equality saturation）+ e-graph：源自編譯器優化的「相位排序問題」。給定表達式（DAG）與一組等價改寫規則，平行反覆套規則，把所有等價程式緊湊存進 e-graph。e-graph 由 e-node（含一個符號）與 e-class（一組等價 e-node 群）組成；同一 e-class 不管走哪個 e-node 都導出等價式。可同時存多個表達式（保留各根 e-class id 清單），自底向上插入時若子結構已存在就回傳既有 id → 緊湊存集合，並能高效用 pattern matching 查「某式或其等價形是否已存在」。
  • eggp 的關鍵改動：
    1. 插入新表達式後執行單步等式飽和，合併等價式（注意：單步不保證插入所有等價形，但多迭代會讓 e-graph 指數膨脹；實驗顯示單步已足夠改善）。
    2. e-graph 交叉：選定第一父代的交叉點後，把第二父代可選的子樹限制在「替換後會生成未訪問表達式」的子集；若該集為空或不交叉則回傳原父代。
    3. e-graph 變異：生成新子樹後檢查是否已在 e-graph；若是，把子樹根節點換成另一個「能生成未訪問式」的同 arity 符號；該集為空則回傳原式。
  • 單／多目標版：eggp_so（用後代取代族群）與 eggp_mo（保留 Pareto front + 次層 front + 隨機補滿，兼顧探索與利用；等價於對全搜尋史抽 NSGA-II Pareto front）。維護按 fitness 與 size 排序的表達式資料庫；插入時等式飽和自動消除冗餘參數。九個超參。Haskell + srtree 函式庫實作（開源）。

結果

  • 在 reduced SRBench（12 題，10×10-fold CV）與 9 個真實資料集（化學/摩擦/NASA 電池/Nikuradse 等）對比 tinyGP、Operon、PySR（皆限單核）。
  • eggp_mo 平均排名最佳（SRBench：以 R² 中位數與 AUC 計，eggp_mo 第一、Operon 次之）；統計檢定（Wilcoxon）可拒絕「PySR/tinyGP 不劣於 eggp」的虛無假設，與 Operon 多半無顯著差異。
  • eggp 一致回傳更小的模型（等式飽和簡化 + 消除冗餘參數）。
  • 可靠性高：在多個資料集上幾乎每次執行都達到相同 R²，而對手有時得分較低或失敗。
  • 執行時間：eggp 與 tinyGP 相近（用 e-graph 不顯著增加 runtime）；比 PySR 快，但比最快的 Operon 慢約數倍。

局限

  • 超參用預設值，未細調；PySR/Operon 經仔細調參或可達相近結果。
  • 單步等式飽和只是折衷（多步會讓 e-graph 指數爆炸）；步數影響留待未來。
  • 對較大表達式改善有限（亮點集中在「小而準」的模型）。
  • 僅改了子樹交叉/變異兩個運算子（為與 tinyGP 公平對比），未上 island model、專用變異等 SOTA 技巧。

對讀者的價值

  • 本批 G 類（遺傳編程／程式合成）的「e-graph 賦能 GP」代表——把程式語言／編譯器的等式飽和技術跨界帶進演化式 SR，核心洞見：用 e-graph 記錄搜尋史、用 pattern matching 強制產生 novelty。
  • 最值得記：**「插入即飽和合併等價式 → 運算子只取會產生未訪問式的子樹/符號」**的配方；多目標版抽全史 Pareto front；以及 e-graph 帶來的衍生能力（存檔/續跑、跨搜尋合併歷史、查「具備某組性質」的表達式、整合先驗）。
  • 與同批 G 類 2411.05820 EvoNUDGE 對照：兩者都把圖 + 語意等價帶進 GP，但本篇用 e-graph 做**「避免重訪／鼓勵新穎」、EvoNUDGE 用 GNN 做「正向導引播種」**；與 2502.03367 SyMANTIC、2509.15929 MCTS-SR 等非 GP 路線形成對比。
