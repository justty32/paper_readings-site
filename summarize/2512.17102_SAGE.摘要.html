論文／訪談原始來源

《SAGE：基於技能庫的強化學習自進化代理》重點摘要

一句話概括

SAGE（Skill Augmented GRPO for self-Evolution）：將 GRPO 擴展為循序任務滾動（Sequential Rollout）與技能積分獎勵（Skill-integrated Reward），讓代理在相似任務鏈中逐步積累可用技能庫，並以額外獎勵訊號濾除噪音技能建議、限制庫擴張只收高收益程序性知識（對應 §3.6 固化引擎方向）。AppWorld 上 SGC 提升 8.9%、token 減少 59%、步驟減少 26%。

解決什麼問題

既有技能庫代理依賴 prompt engineering 產生與使用技能，受限於基礎模型指令遵循能力，無法穩定自我改進。純 RL（GRPO）只考慮單任務的 outcome reward，不獎勵技能生成品質與跨任務重用——技能庫代理需要多任務才能暴露技能價值，但既有 RL 框架無法向過往任務傳遞後續利用訊號。

核心方法

  • 技能庫代理（§3.1）：整合 DynaSaur 的統一格式——代理每次與 API 環境互動時先定義可執行函式（技能）再呼叫執行，而非直接呼叫多個 API。技能可被生成、使用、更新、儲存四種操作。
  • Sequential Rollout（§3.2.2）：每組 rollout 不再是單一任務，而是同場景的任務鏈（兩任務）。任務 1 產生的技能累積到庫中供任務 2 使用，使技能生成品質訊號能從後續成功回傳。
  • Skill-integrated Reward（§3.2.3）：R₁ = r₁ + 1[r₁=1] × 1[r₂=1] × 1_skill(q²|q¹)；R₂ = r₂ + 1[r₂=1] × 1_skill(q²|q¹)。即任務 1 成功完成且其技能被任務 2 成功使用時給予額外 +1；任務 2 成功且使用了任務 1 的技能時也+1。無程式碼就終止的回合罰 -1.0。
  • SAGE 目標函數（§3.2.4）：將原始 GRPO 的期望從單任務改為任務鏈 (q¹,q²)∼Q，每組 rollout τᵢ 包含循序處理兩任務的軌跡，其中 o²ᵢ 來自不同技能庫 M²ᵢ（不像原始 GRPO 來自相同 query）。
  • 訓練流程：Qwen2.5-32B-Instruct → Claude 3.5 Sonnet 產專家軌跡做 SFT 初始化 → SAGE RL（4×H100 8-GPU 節點、full-parameter、嚴格 on-policy、無 KL penalty）。
  • 一般化（附錄 B）：支援 K 任務鏈，技能生成獎勵來自「後續任一任務成功使用」的最大值，技能使用獎勵來自「成功使用先前任一技能」。

結果（AppWorld）

方法 TGC ↑ SGC ↑ Avg. Steps ↓ Avg. Tokens ↓
GRPO（無技能庫） 69.2% 51.8% 16.4 3,613
技能庫代理（prompt only） 30.7% 19.6% 13.4 2,988
+ SFT 55.2% 41.7% 11.4 1,340
+ SAGE 72.0% 60.7% 12.1 1,475

技能使用分析：SAGE 的 Skill Usage Rate 與 Success Skill Usage Rate 皆顯著高於 SFT 與 Base Model，但技能庫規模控制得比 Base Model 精簡（生成少但成功率高）。

消融

  • 無技能評估：SAGE 無技能庫時 SGC 從 60.7% 降至 54.8%，證實技能庫貢獻約 +5.9pp SGC。
  • 獎勵設計：Skill-integrated > Chain-based > Outcome-based（TGC: 72.0 > 67.9 > 69.8; SGC: 60.7 > 56.6 > 55.4）。
  • RL 初始化：Base Model 直訓 RL 僅 40.7% TGC/SGC 25.6%；SFT 初始化 72.0%/60.7% 最優，證實專家軌跡對技能庫格式學習的必要性。
  • 檢索方法：Query N-gram 接近 Same Scenario 理想性能（TGC 72.0% vs 72.0%），證明任務文字結構相似性足以約束技能庫範圍。
  • 長任務鏈：三任務鏈不如二任務鏈（TGC 70.6% vs 72.0%），因獎勵不對稱（任務一獨攬生成獎勵、後續只拿使用獎勵）與梯度變異增大。

ai_core 接點

SAGE 是 §3.6 固化引擎方向最直接的 RL 實作：Skill-integrated Reward 的 1_skill(q²|q¹) 指標牌正是「高收益程序性知識」的篩選器——只有後續任務實際成功使用的技能才獲得額外獎勵訊號，等效於自動濾除噪音技能、限制庫擴張只收高產出技能。Sequential Rollout 使技能價值在多任務鏈中得到自然驗證，對應 ai_core 的「技能必須經過使用證明才准入庫」原則。缺失：尚無技能退役/收斂機制（技能只增不減），且受訓後部署中無 critic 閘門做即時准入否決。
