論文／訪談原始來源

《立場：邏輯健全性不是用 LLM 做神經符號事實查核的可靠判準》重點摘要

一句話概括

一篇立場論文：主張在事實查核中，「把 LLM 當語意剖析器將自然語言翻成 FOL、再用符號求解器驗證『邏輯健全』」這類神經符號管線結構性地會漏掉誤導性陳述——因為人類接受的推論常系統性偏離形式邏輯，導致「邏輯上健全」的結論反而誤導人；故反過來提議：把 LLM 的類人推論傾向當成「特徵」而非「bug」，用它來偵測形式組件產出的、可能誤導人的結論。

解決什麼問題

當前範式：用形式邏輯約束 / 驗證 LLM 輸出以緩解幻覺、偏誤、邏輯不一致（LLM 把宣稱翻成 FOL 公式，對已驗證知識庫檢查是否「可從真前提有效推導」＝邏輯健全 → 即視為被支持）。核心盲點：邏輯健全 ≠ 不誤導。「誤導」指字面為真、但隱含意義為假或無依據的內容；而人類往往接受形式上無效、卻直覺可接受的推論。

核心論證

  • 人類推論系統性偏離形式邏輯（援引認知科學 / 語用學：心智模型論、Gricean 準則、conjunction buttressing、conditional perfection）。
  • 典型案例表（表 1）：對單一已驗證真前提 S1「法國關稅將漲 10%」套用合法邏輯運算，得出邏輯健全但誤導的結論：
邏輯運算 推導結論（誤導） 人類實際推論 認知 / 語用基礎
析取引入（A ⊢ A∨B） S2：「關稅將漲 10% 或 100%」 「有可能漲 100%」（S1 無此依據） 人把析取讀成「預設可能性的合取」
合取引入 S3：「漲 10%，且漲 10%」 「漲 10% 連續兩次」 Gricean 量準則 + conjunction buttressing（時序）
實質蘊含（正悖論） S4：「若利率不降，則漲 10%」 S4-I：「若利率降，則不漲 10%」 conditional perfection（把條件句讀成雙條件）
模態 B、T 公理 S6：「可能漲 10%」 「可能不漲 10%」 從「可能」推出不確定（Gricean 質準則）
  • 三大蘊含：(a) LLM 反而有潛力建模人類推論、偵測形式系統認不出的誤導；(b) LLM 推理研究應把類人傾向不只當 bug、也當 feature（預測人會接受卻形式無效的推論）；(c) 若要 LLM 有效建模人類推理，不該訓練 / 優化它嚴格遵循形式邏輯（會壓抑必要的語用敏感度）。
  • 駁替代觀點：加輔助判準 X 會誤殺合法的類人推論；「惡意者不用複合句」站不住（自動系統可學會生成規避邏輯過濾器的合法複合宣稱）；「把推導 trace 攤給人看」也不成（多數用戶不會審、且委派回 LLM 又繞回原問題）。

結果

非實驗論文；貢獻為概念框架 + 反例類型學（表 1），挑戰「邏輯健全＝可信」的神經符號事實查核假設。

局限

  • 立場 / 論證性質，無實證量化「誤導漏檢率」。
  • 提議「用 LLM 類人傾向偵測誤導」本身亦依賴 LLM，可靠性待驗。

對讀者的價值

  • 本批主題 B 中罕見的「批判 / 反方」聲音——與多數主張「符號求解器提供健全性保證」的 NeSy+LLM 工作（2507.09751 Sound-Complete NeSy LLM、2602.18095 Logitext SMT、2407.10162 ChatLogic）形成張力，提醒：形式健全性 ≠ 對人的可信度。
  • 最值得記：「邏輯健全的結論可系統性地誤導人」這條反直覺主張及其認知 / 語用根據（析取→可能性、合取→時序、條件→雙條件）；以及「把 LLM 類人推論當 feature 來查核形式組件」的角色反轉。
  • 與 LLM 推理綜述（2502.09100）、NeSy 推理綜述（2508.13678）並讀，可平衡「形式化萬靈」的樂觀；對做事實查核 / 錯誤資訊偵測 / NeSy 驗證管線的人是重要警示。
