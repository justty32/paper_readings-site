論文／訪談原始來源

人類如何邊探索、邊說出對陌生世界的理解

一句話概括

這份資料集將 ARC-AGI-3 的操作、環境回饋與人類同步口述對齊，再標註機制理解、行動目的及錯誤修正，讓研究者能追問「為什麼做這一步」，而不只比較通關分數。（§1、§3）

解決什麼問題

相同操作可能是在試驗、執行計畫或堅持錯誤理解，只有動作紀錄無法區分。ARC-AGI-3 要求玩家在沒有自然語言任務指示下，同時發現環境機制與目標；作者以同步放聲思考補上這段認知過程。既有 ARC 解題、行為及口述資料未同時涵蓋此種陌生互動環境的規則與目標發現。（§1–2）

核心方法

作者自報從 Prolific 取得 64 位參與者在 25 個公開遊戲中的 144 條成功軌跡，含 136,876 次環境動作及同步語音；另收集相同遊戲的 250 條公開 LLM 軌跡，其中 100 條為直接配置、150 條使用 harness。這不是所有指派嘗試或練習的全集。正式遊戲每場上限 60 分鐘，說明中的 20 分鐘只是預估；參與者預設受派三場，未必留下三條成功紀錄。（作者自報，§3.2、附錄 A）

世界模型以條件式狀態更新機制表示。兩位作者共同檢視程式、畫面與回放，建立 320 個主要、34 個補充機制；以插入遊戲程式的監測器定位「客觀觸發」，另從口述／公開推理與行為證據判斷「首次正確認知」。偶然觸發、一般移動或通關本身不足以證明理解。GPT-5.6 Sol 協助監測程式、認知及行動目的標註；人工抽查觸發 30/30、認知 97/100、行動目的 30/30 正確，這些是抽查結果。（作者自報，§3.3、附錄 B）

行動區分追求目標、蒐集資訊與兩者兼具；資訊行動再區分無既有假說的探索、假說檢驗與追查意外。錯誤則區分已接受但錯誤的機制信念、未達明確目標的計畫，以及輸入偏離意圖的執行錯誤；暫時假說與「不知道」不直接算錯誤信念。修正必須對應同一信念、計畫或輸入。（§3.3.2–3.3.3、附錄 B.4）

結果

作者自報人類 57/1,425 個觸發與認知皆可定位的機制實例，在首次觸發前已被認知（4.0%）；各 LLM 配置也有此現象。熟悉事物的類比出現在 37/144 條人類軌跡及 26/119 條成功 LLM 軌跡。定性表徵是知道粗略運作方式、但尚未說明全部條件、時序或量值；出現在人類 72/144（50.0%）與成功 LLM 的 17/119（14.3%）。此處 LLM 分母限 Vista、Schema、OPINE-World，非全部收集軌跡。（作者自報，§4.1–4.2、附錄 D）

在含資訊目的的動作中，人類無既有假說探索占 40.6%、假說檢驗占 49.2%；成功 LLM 相應為 10.7%、49.0%。LLM 的複合資訊情境另占 35.5%，因此不能只靠上述兩項概括所有資訊蒐集。作者將差異描述為人類較常先試未知情境、兩組均常檢驗假說。（作者自報，§4.3）

人類已接受的錯誤機制結論有 15 次，其中 11 次觀察到修正；失敗計畫 1,002 次、916 次後續恢復；執行偏差 136 次、134 次修正。成功 LLM+harness 的錯誤機制結論為 593 次、451 次修正。作者提醒，LLM 的公開推理、程式及筆記較常明示可檢驗主張，人類未必把每次理解變化說出口，故不能把事件數直接當成內在認知錯誤率。（作者自報，§4.4）

局限

作者自陳：人類與 Vista 軌跡以成功通關選取；不同系統的模型、推論預算與可見推理未受控制，跨系統比較是描述性的，不能估計加入 harness 的因果效應。缺乏公開認知證據不表示內部沒有理解；認知早於觸發也不單獨證明記憶或預訓練接觸。（附錄 D.1–D.2）

作者自報首次認知相對首次觸發的平均動作差為人類 90.8、harness LLM 24.4，但只納入兩種標註都存在的機制。全部主要機制已有理解證據後，到通關的平均動作數為人類 95.1、harness LLM 49.2，亦限合資格已完成關卡；人類僅 228/1,057 關符合。缺證據者不當零計算，這些區間不是互斥認知階段、統一反應延遲，也不完整隔離規劃活動。（作者自報，§5、附錄 D.2，表3–4）

本檔補註，非作者自陳：這份資料適合提出與檢查探索策略假說；若要判斷某種認知策略是否造成通關改善，仍須另設控制比較，不能把此處成功選樣的描述差異當成效果量。

對讀者的價值・接點

作者建議下一代 benchmark 挑戰熟悉先驗，加入反常識或湧現機制、隱藏狀態、隨機與延遲結果，要求累積證據及任務相關抽象；規劃則需構造子目標，並試驗已知局部機制組合後的整體效果。（§5–6）

對世界模型與 agent 研究，本檔補註的價值是把「環境確實發生什麼」「可觀察到何種理解」「為何採取行動」分開記錄，避免以成功動作代替理解證據（本檔補註，非作者自陳；依據附錄 B.2–B.4）。資料集入口：ARC3 Human Think-Aloud。
