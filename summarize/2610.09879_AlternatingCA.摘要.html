論文／訪談原始來源

三種交替的簡單規則如何模擬 Rule 110

一句話概括

作者將三個單獨運行時呈簡單行為、左右鏡像對稱的初等細胞自動機規則按空間週期排列；在指定的三格編碼與同步相位下，每三步精確模擬 Rule 110 的一步，因此繼承其通用計算構造。隨機初態與噪聲結果則是另外的模擬觀察，並非對所有初態或持續受噪計算的通用性保證。（§2–4）

構造：對稱局部規則，非對稱排列

一維二元格點按位置 i mod 3 固定使用規則 36、37、5，三者各自的局部更新對左右互換對稱。將邏輯 0 編為三格 100，邏輯 1 編為 000，以相同分組起點排列整個 Rule 110 初始狀態；在無噪、同步更新及該編碼相位下，三次混合規則更新後所得有效區塊對應 Rule 110 一次更新。作者逐局部輸入列出對應表，因而在這種編碼下以三倍空間、三倍時間模擬既有 Rule 110 構造。（§2，圖 2）

局部規則無法分辨左與右，整體的方向性來自 36→37→5 的空間排序。作者指出，兩種鏡像對稱規則若以週期二重複，其反射與原序列只差平移，無法以相同方式提供方向性；文中也列出兩規則較長週期的非對稱排列可能。這是對特定排列與對稱性構造的討論，不是所有非均勻自動機的最小通用性定理。（§2）

Rule 110 的通用計算性是所引用既有結果；本文提供的是固定編碼下對它的模擬。三格編碼及相位對齊是精確對應前提，不能將任意亂碼起始或有噪聲演化直接視為一個正確計算。（§2）

隨機初態：多數鎖定，仍有未鎖定情形

作者在週期邊界的有限格點上模擬隨機初始狀態，自報當格點長度 N≥256 時約 91–100% 的執行會鎖定到可模擬 Rule 110 的共同相位；約 0–9% 視大小而未鎖定。鎖定的執行其時間約按 N² 成長，但作者指出部分被記為受困的執行，尤其較大系統，可能只是模擬時間不足的長暫態。原文未在主文給出足以將此比例當作所有初態保證的完整抽樣細節。（§3，圖 3）

局部區域可各自以相差一拍的相位模擬 Rule 110；相鄰區域之間形成 domain wall。作者觀察到不同方向的壁可能相遇並湮滅，也可能受相位和排列影響而持續移動、未互相接近。這解釋模擬中為何可形成單一相位，也可能留有持久不同步區域。（§3）

噪聲模型與限制

噪聲實驗讓每個 bit 每一步以機率 ε 隨機翻轉，觀察錯誤造成的 domain wall 密度。作者以近似生成／碰撞速率方程得到穩態密度 n* = √(6pε/v)：p 是翻轉後形成壁對的機率，v 是壁漂移速度的代表值。作者依模擬估計 p≈0.23、左右速度約 0.219／0.236 格塊每步，以其平均 v=0.2275 對照觀察到的平方根尺度。（§4，式 1–2、圖 4）

此方程是低噪聲下的近似描述。作者指出，噪聲大時相鄰壁互相干擾、獨立近似失效；長時間接近穩態也比方程預測慢。作者由 n*L<1 推得長度 L 格塊上期望壁數小於一的粗略條件 ε<0.16/L²；這不是保證每次執行完全無錯，也不是可容錯通用計算的證明。（§4–5）

解讀邊界

  • 作者指出三規則排列的描述資訊量在所用比較方式下比單獨 Rule 110 更多，因而此例將規則資訊分配到不同位置，而非證明更少資訊即可得到同樣計算。（§5）
  • 生物系統與物理中的對稱性破缺是作者提出的類比及潛在方向；本文的三規則不可逆，沒有實作或驗證真實生物或量子物理系統。（§5）
  • 本檔補註，非作者自陳：有限尺寸模擬支持其觀察範圍內的自同步及噪聲尺度，仍需區分精確編碼的無噪模擬、隨機初態能否鎖定、以及噪聲下計算輸出是否可靠。
