論文／訪談原始來源

《NOVA：工業推薦系統架構演進的「驗證感知」智能體 Harness》重點摘要

一句話概括

NOVA：騰訊的分級（level-aware）多代理 harness，把工業廣告推薦模型的架構演進自動化。核心是**「架構梯度（architecture gradient）」——一個受 SGD 啟發、非可微的更新訊號，把「前一次修改 + 驗證診斷 + 離線指標變化 + 軌跡記憶」聚合成「下一步該怎麼改架構」的方向；搭配靜默失敗感知（silent-failure-aware）多階段驗證級聯**（結構語義→本地可執行→離線有效→線上影響），在昂貴訓練前就攔掉「能跑但架構語義錯」的候選，並把失敗模式記成**禁區方向（forbidden directions）**回饋給搜尋；再以 L1–L4 任務分級 + AutoRun/Copilot 把高風險任務路由給人類監督。線上 A/B：選中的 L3 候選在三個 pCVR 目標上 GMV +1.25%/+1.70%/+2.02%、預測偏差降 58.8%/66.7%/37.3%，一個「論文到生產」週期人工時間縮短 13 倍以上。

解決什麼問題

工業推薦模型靠架構演進（RankMixer、TokenMixer-Large、MixFormer…）持續取得品質與商業增益，但開發極依賴專家、難規模化。既有自動化不足：AutoML 只調超參（學習率、隱層大小、嵌入維度），而有效增益常需跨模組拓撲變更;通用 LLM coding agent 只優化「能跑的程式」，但能跑 ≠ 合法的推薦架構——候選可能通過本地測試卻造成靜默失敗（silent failure）（如錯誤移除序列遮罩、self-attention 退化成 MLP、改壞 logit 融合路徑），悄悄拉低 AUC/校準/商業指標。

核心方法

  • 架構狀態：每個候選 A_t=(G_t, φ_t, F_t)——模型圖、結構超參、特徵配置。初始 A_0 取自生產程式庫 C；論文來源 P 與靜態知識庫 KB 提供架構先驗與歷史「有效/無效方向」證據；搜尋受 budget B（輪數、token、GPU 時、wall-clock）限制。搜尋單位＝對模型拓撲/特徵路由/互動模組/結構超參的可行修改（須滿足形狀相容、dtype 一致、特徵依賴、訓練穩定、線上推論相容等硬約束）。
  • 架構梯度 g_t = Grad(e_{t−1}, V_t, ΔJ_t, H_t)：因 A_t 離散且受約束、無標準梯度，改用此結構化更新訊號（類比 SGD，非數學梯度）。聚合前次修改 e_{t−1}、驗證診斷 V_t、離線目標變化 ΔJ_t（用 AUC）、歷史軌跡 H_t（修改/失敗/診斷/指標）。
  • 靜默失敗感知驗證級聯（漸進、由輕到重）：① 結構語義閘（在訓練前，依 skill specification 檢查遮罩方向/特徵路由/logit 融合是否符合意圖架構——不只看能否執行）→ ② 本地可執行性 → ③ 離線評估（AUC） → ④ 線上驗證。失敗候選記入軌跡記憶 H 並轉成可重用的禁區方向，使驗證從「事後過濾器」變成「搜尋訊號的一部分」（verification as gradient denoising）。
  • Skill specification：語義閘由 skill 規格驅動（歷史種子規則 + 累積禁區模式 + LLM 輔助檢查），未覆蓋情形不過度自信拒絕、留給離線/線上評估；一個任務改進的規格可被後續相似架構/失敗模式的任務重用。
  • L1–L4 分級 + AutoRun/Copilot：level 控制修改範圍，mode 由 skill 規格覆蓋度決定（已覆蓋→AutoRun 自動跑；未覆蓋或高風險→Copilot 要人類確認）。L1/L2 多 AutoRun、L4 多 Copilot。
  • 實作：主代理（Main Agent）編排專門子代理，跑七階段工作流（初始化→…→線上實驗評估），底層記驗證診斷與指標回饋轉成下一輪架構梯度。

結果（生產廣告系統，服務逾 10 億用戶；對比人類專家迴圈、AutoML、通用 coding agent）

  • 有效通過率（EPR）最高：L2 ScaleUp 54.5%、L3 Literature-to-Production 60.0%（L3 LPR 86.7%）;EPR 超過人類專家迴圈兩倍、大幅勝 coding-agent baseline。
  • 降低靜默失敗（相對 coding-agent baseline）。
  • 效率：一個「論文到生產」週期的人工參與時間縮短 13 倍以上（節省集中在工程師時間、非 GPU 吞吐）。
  • 線上 A/B：選中 L3 候選三個 pCVR 目標 GMV +1.25%/+1.70%/+2.02%，pCVR 偏差降 58.8%/66.7%/37.3%。
  • 消融：移除論文復現、方案設計、多候選生成、品質評估、或架構梯度回饋各會掉效，證明各組件不可或缺。

局限

  • 能力邊界：語義閘只在 skill 規格覆蓋範圍內可靠，未覆蓋/高風險須 Copilot 人類介入（非全自主）；規格累積有冷啟動成本。
  • 高度綁定推薦系統/廣告領域（搜尋單位、驗證規格都是領域特定）；離線只用 AUC 當代理目標。

對讀者的價值

  • 「智能體架構」主題的工業落地標竿：把 LLM 多代理、演化式架構搜尋、與生產級驗證/風險治理縫成一個可審計的 harness；最值得記的三招——「架構梯度」聚合多源回饋當非可微更新方向、「驗證即梯度去噪」把失敗變禁區方向、L1–L4 + AutoRun/Copilot 把自動化程度對齊任務風險。
  • 與 2606.26327 EVOM（LLM 設計代理 + 低保真 PPO 演化 RL 架構）對讀：兩者都「LLM 當架構設計算子 + 演化迴圈」，但 NOVA 更重生產約束、靜默失敗防護、人機分級；與 2510.25445 智能體 AI 綜述、2508.00604 可組合 OS 核心、2406.18532 Agent Symbolic Learning 並讀，看「智能體 + 自我改進」在真實系統如何被治理。
