論文／訪談原始來源

《SSR：符號-神經軟邏輯推理——以協同演化邁向穩健可驗證思維鏈》重點摘要

一句話概括

SSR（Symbolic-Neural Soft-Logic Reasoning）：一個把 LLM 與 SMT 求解器整合的神經符號框架——LLM 先把自然語言題目抽象成受限 SMT 相容的符號程式（facts＋queries），求解器做可驗證推理；關鍵創新是鬆弛「嚴格邏輯決定論」為信賴度加權的軟邏輯（容忍翻譯錯誤／缺前提／不確定知識），並以雙系統定向檢索處理「軟邏輯歧義」（解器找出能讓答案唯一的賦值 → LLM 驗證該賦值是否有題目/常識支撐），最後從已驗證的邏輯程式自動生成「人類般、可驗證」的前向/後向演繹思維鏈（可當訓練資料）；在 BigBench、ProofWriter、FOLIO 上一致勝過既有推理框架。

解決什麼問題

CoT 推理根本受限於神經生成的機率本質：思維鏈可能不忠實（事後合理化）、確認偏誤、幻覺（捏造/錯誤推論/誤用規則）。把 LLM 接 SMT 求解器（神經符號）雖能提準確率，但仍有三大頑疾：

  1. 自動形式化本身會幻覺（遺漏、結構錯誤）;
  2. 自然語言的歧義/脈絡依賴 ↔ 形式邏輯的嚴格語義 衝突 → 脆弱或不可滿足的式子；
  3. 把核心推理完全外包給求解器，質疑這是否真增強了 LLM 的內在推理（還是只是繞過它）。

作者主張：這些限制源於「把符號推理當成嚴格決定論，對不確定與不完美形式化零容忍」。

核心方法

  • 2.1 硬邏輯推理（理想設定）：LLM 產出 facts（已知約束 Φ＝⋀φᵢ）＋ queries Q。謂詞分 Numeric Sort（有限可枚舉值，如 Age(Bob)=16）與 Boolean Sort（真值，如 Happy(Anne)），用受限 SMT 相容語法。Boolean query 檢查 Φ∧qᵢ 與 Φ∧¬qᵢ（只一個 sat → 回該真值；都 sat → Unknown）;Numeric query 枚舉候選賦值。求解器強制全域一致、避免幻覺；但 LLM 邏輯一旦有雜訊/過約束就脆弱。
  • 2.2 軟邏輯鬆弛：先做語法層過濾——明顯壞掉的式子（自然語言碎片、無效謂詞、亂碼）替換成 BoolVal(True) 佔位防 parser 崩潰；若佔位太多或 query 被替換則退回傳統 CoT。其餘每條 φ 給信賴度權重 w(φ)＝exp(−H(φ))，H 為 LLM 輸出的長度正規化熵（由 token logit 機率算，與內在不確定負相關、不受句長影響）。若 Φ 不可滿足，搜尋「總信賴權重最大的可滿足子集」；若無候選 sat，對每個候選找最大權重可滿足子集、選之。把「全有全無失敗」換成「信賴度加權的約束選擇」，仍以 SMT 可滿足性為有效性判準。
  • 2.3 雙系統定向檢索（解軟邏輯歧義）：多候選仍 sat 時，解器先找出「哪個謂詞賦值 a=value 能讓答案唯一」（Φ∧(a=value)∧(qᵢ=qᵢⱼ)），再由 LLM 驗證該賦值是否被題目陳述或常識支撐——解器與 LLM 互動式協同。
  • 2.4 人類般 CoT 自動生成：SMT 解出可驗證答案但無人類可讀軌跡；SSR 把已驗證的邏輯程式正規化成 properties（Predicate(Object)／¬Predicate(Object)）與 rules（蘊含），再以前向／後向演繹構造解釋——根植於符號推理，而非 LLM 隨機生成，可當訓練/評估資料（支援 AI for Math）。

結果

  • 在 BigBench、ProofWriter、FOLIO 多模型多基準上，SSR 在最終答案準確率與推理鏈品質上一致勝過既有推理框架；跨資料集泛化良好（FOLIO 上提升尤明顯）。
  • 同時報告總推論時間對比。

局限

  • 失敗主要來自基於檢索的前向/後向推理程序的限制（複雜題上檢索不到決定性條件）。
  • 仍依賴 LLM 的自動形式化品質；軟邏輯雖容忍噪聲但無法無中生有缺失的前提。
