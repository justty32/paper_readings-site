《TheoryCoder-2》重點摘要

一句話概括

TheoryCoder-2 把「theory-based RL（TBRL）」最大的依賴——人工手寫抽象——自動化掉：用 LLM 的 in-context learning，從經驗合成可重用的 PDDL 抽象運算子（高層）＋ Python 謂詞分類器與轉移函數（低層 grounding），整合進階層規劃，並跨環境累積/成長一個抽象庫。在 Labyrinth/Maze/Sokoban、BabyAI、Minihack 等多環境上，它比「LLM+古典規劃域構造」「推理式規劃」「WorldCoder 等程式合成智能體」樣本效率顯著更高，能解基線解不了的複雜任務，且只需最少人工 prompt（不像原 TheoryCoder 須為每個新域手寫抽象）。

解決什麼問題

人類能形成抽象並用以高效階層規劃、快速跨任務泛化；但 SOTA LLM 智能體與深度 RL 仍難企及。最先進的 TBRL 系統 TheoryCoder 雖靠抽象取得遠勝深度 RL/LLM 的樣本效率，卻重度依賴人工提供的抽象、迴避了「抽象學習」這個真正難題——進新域得先由人想出相關抽象再寫程式碼，否則只能近乎隨機動作去建低階世界模型，喪失抽象帶來的效率與遷移性。

核心方法（TheoryCoder-2 = TBRL + 自動抽象學習）

  • 學習抽象（§3.1）：原 TheoryCoder 靠手寫 PDDL（定義抽象運算子與謂詞），TheoryCoder-2 改用 LLM in-context learning 自行合成 PDDL 檔。唯一須人工的輸入是初始 prompt——對環境最終目標的自然語言描述 + 幾個與實際環境無關的極簡示例（如 eat：前提 not eaten、效果 eaten），作為「抽象該長怎樣、粒度多粗」的模板（讓 LLM 不至於太細或太粗）。
  • grounding：每環境內，零樣本學到運算子後，再像原 TheoryCoder 學一個 Python 世界模型；額外學 Python 謂詞分類器（作用於原始狀態、回傳布林）來把謂詞語意 ground 到該環境（原本這些由人連同 PDDL 一起給）。
  • 重用與成長庫（§3.2）：用一連串「episodes」（每 episode 含一或多個按相似度分組、按難度排序的環境）；從每 episode 第二個環境起，嘗試重用先前學到的抽象並按需擴充，逐步累積抽象庫。也做打亂課程順序的消融。
  • 階層規劃：用 PDDL 運算子做高層規劃 + 低層 Python 轉移模型做低層規劃（BFS）；骨幹用 GPT-4o。

結果

  • 簡單環境（Labyrinth/Maze/Sokoban）：TheoryCoder-2 學到關鍵抽象（如「移動到某位置」運算子）並在 Maze、Sokoban 兩新環境重用；效率上僅次於最樸素的 LLM+簡單規劃基線，但勝過 LLM+P 與 WorldCoder 兩個進階 LLM 智能體（所有系統都能解這些簡單題）。
  • 較難環境（BabyAI、Minihack）：TheoryCoder-2 能解基線失敗的複雜任務，樣本效率（以 token 成本衡量）顯著更高。
  • 抽象跨環境可遷移、即時 grounding、無需領域適配；對比 Oracle（手寫抽象）顯示學到的抽象品質可用。
  • 消融：去掉可執行抽象與 Python 世界模型（TC-P，退化為 CoT）、去掉課程學習（TC-C，每 episode 從零）皆掉效能，證實各組件必要。

局限

  • 仍需最少人工——初始 prompt 與極簡示例對「抽象粒度」很關鍵（LLM 全自主時難拿捏粗細）。
  • 抽象 grounding 與謂詞分類器以 Python 程式表達，受 LLM 合成正確性限制。
  • 評估環境多為網格/VGDL 類；對更高維連續域的可擴展性未驗證。

對讀者的價值

  • 本批 G 類**「程式合成智能體 + 抽象/庫學習」的代表**——把 DreamCoder 式「學可重用抽象」的精神，落到世界模型 + 階層規劃的 RL 智能體，並用 PDDL 運算子 + Python grounding 這個 neuro-symbolic 組合表達抽象。
  • 最值得記：「LLM 合成 PDDL 抽象（高層）+ Python 謂詞分類器/轉移函數（低層 grounding）+ 跨 episode 重用成長庫」 的三層結構；以及「只需極簡 prompt 模板控制抽象粒度」的工程訣竅。
  • 與 2604.26311（DreamProver 學引理庫）、2512.13857（EvoLattice 累積微算子）同主題（累積可重用抽象），但場景是互動式 RL/規劃；與 1911.01547（智能的度量、ARC 強調抽象與泛化）理念呼應。
  • 適合做 theory-based RL、世界模型程式合成、PDDL/階層規劃、LLM 智能體抽象學習 的人。
