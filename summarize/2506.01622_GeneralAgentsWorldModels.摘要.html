General agents need world models 重點摘要

一句話

任何 agent 只要對「一組足夠多樣的多步驟目標導向任務」滿足有界失敗率（regret bound），其 policy 本身就唯一決定（誤差有界內）環境的 transition function；換句話說，能泛化到多步驟目標任務，就必然已經學到一個世界模型，而且 agent 表現越好、能處理的目標序列越長，重建出的模型精度就越高。

設定與定理

環境設為 controlled Markov process（cMP：無 reward 的 MDP，需 irreducible、stationary、有限維、至少兩個動作）。目標用線性時序邏輯（LTL）表達，只取 Now／Next／Eventually 三種算子，可組成有先後順序的 sequential goal（深度＝子目標數）與並聯的 composite goal。agent 定義成 goal-conditioned policy π(history, goal)→action，不假設理性公理。bounded goal-conditioned agent（Def. 5）由兩個參數刻畫：失敗率 δ（相對最優 agent 的成功機率下界）與最大目標深度 D（此界只保證在深度 ≤D 的目標上成立）。世界模型則定義為對 transition function 的任意有界誤差近似。

Theorem 1（主定理）：對滿足上述 bounded 假設的 agent，可以只用 π 本身（不需要激活值、不需要架構資訊）重建出誤差有界的 transition function 估計，誤差隨 δ 增大而變大、隨 D 增大而下降（確切的縮放指數見原文，本檔不逐字引）。證明是構造一族「二選一」複合目標——agent 先採取某動作，接著嘗試某轉移最多 k 次或最少 k 次——agent 選哪一邊，洩露了該轉移機率相對二項分布中位數的位置，由此可逐步逼近真實機率。

Theorem 2：若只要求 agent 對 depth-1（myopic，只看下一步）目標最優，則其 policy 對 transition function 不能提供任何非平凡界限。因此世界模型只在「多步驟、需要協調子目標」的能力下才是必要的，對純反射式 agent 不成立。

實驗（作者自報）

環境為隨機生成的 20 states、5 actions 稀疏 cMP（每個 state-action 至多 5 個非零轉移）。用 model-based agent，以隨機策略採樣長度 N 的軌跡訓練其內部模型，N 從 500 掃到 10000；再用簡化版演算法（Algorithm 2，只用 policy 作輸入）反推 transition function，對每個 agent 掃過不同最大目標深度 D，量測平均 regret 與平均模型誤差。Table 1 顯示：N=500、D=10 時平均誤差 0.171±0.007；沿 N 與 D 兩個方向都單調下降，到 N=10000 時誤差自 D=200 起就壓在 0.031±0.002 不再改善。作者以最小平方迴歸估目標深度對誤差的縮放，自報與 Theorem 1 的最壞情況界一致。作者也刻意讓 agent 在部分子目標上 worst-case regret 達到最大（違反 Def. 5 的逐目標假設），發現只要平均 regret 低，演算法仍能準確還原 transition function——顯示結果對假設違反有一定穩健性。

對 ai_core 的價值／接點

這篇論文把「能力蘊含模型」證成定理，對 ai_core §5 的固化引擎有直接的正當性支持：如果某段「模糊意圖→結構化意圖→確定性程式碼」的映射真的能跨足夠廣的任務、達到夠低的失敗率，背後就必然編碼了一個關於使用者意圖空間如何運作的隱含模型，不需要另外要求開發者顯式交出一份模型文件來審查。這給 §3.4 憑證准入治理一個可操作的思路：用一組刻意設計的「二選一子目標」任務（像 Algorithm 1/2 那樣，先做某動作，再看它面對多次重複嘗試時選擇偏向哪一邊）當作准入測試，從候選版本的選擇模式反推它對意圖空間的隱含掌握精度，而不必要求它把模型攤開來給人看。§3.2 的成本梯度也能借上這套形式化直覺：論文的誤差界同時隨 δ 與 D 變化，意味著「多花成本讓系統對更長 horizon 的任務失敗率更低」在數學上等價於「逼它學一個更精確的模型」，兩者不是分開的投資，而是同一件事的兩種度量。但 Theorem 2 也是一個提醒：如果 ai_core 某一層只做單步、立即反應的決策（不涉及多步驟固化鏈），就不能援引這篇論文去論證它一定有隱含世界模型——真正該被要求交出模型憑證的，是那些橫跨多輪、多模組的複合任務鏈路。
