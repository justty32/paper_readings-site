論文／訪談原始來源

TaxoSAE：把分類階層放進稀疏自編碼器

核心問題

一般 SAE 的特徵未必與已知分類階層相連：讀到下位概念時，上位概念可能沒有相應啟動，編輯也難指定影響的層級。TaxoSAE 以每個階層一個 SAE 的堆疊，加上依已知 is-a 關係建立的對齊損失，使讀出與干預能分別落在末端、中間與頂層概念。它是以分類法監督的表示學習，is-a 是軟訓練目標，不是推論時硬性保證；結果應按實際測試與資料限制理解。（§1–4、§2；硬性保證界線為本檔補註）

堆疊和訓練

研究設定是每個節點最多一個上位詞的有向無環分類圖；L1 為末端、L2 為中間、L3 為頂層。事實 QA 三元組含實體、關係與值；Bio 的分類元素是關係、互補元素是人名，Animal 分類元素是動物、互補元素是屬性。底座模型凍結後，SAE1 讀取指定層最後 prompt token 的 hidden state；後一 SAE 讀前一層重建，各層為該層節點配置 taxonomic slots，另配置互補元素 slots 和 10,000 個自由 slots。（§3–4.1、附錄 A）

末端 taxonomic slot 直接以末端標籤訓練；上層將下層各節點的 softmax 機率按已知父子邊加總，以最大父節點作目標。另有互補元素對齊、重建、稀疏、稅分類與互補／自由 slots 的去相關，以及答案 value loss；雙線性 value head 使用分類與互補兩組 slots，非末端節點繼承後代的答案集合。訓練 100 epochs 重建／稀疏，再從該 checkpoint 訓練 500 epochs 全損失。（§4.1–4.2、附錄 K）

「只用末端問題訓練」指 TaxoSAE 的訓練資料，並非底座不曾見過階層：GPT-2 small 先分資料集微調於末端事實 QA、hypernymy QA 和文字描述，後者明示末端到上位及中間到頂層關係；沒有非末端事實 QA。故未見上位事實問題的測試不等於沒有階層知識監督。（§5.2、附錄 K）

測試設定與對照

Bio 有 18／6／3 個末端／中間／頂層節點、20 個合成人物；Animal 有 18／6／2 個節點、20 個屬性，兩者各 360 個末端事實。Bio 的末端關係取自 Freebase，上層由作者構造；Animal 是 ConceptNet 英文 IsA 子集。主實驗使用分別微調的 GPT-2 small，Bio 第 6 層、Animal 第 9 層以末端讀出與 swap 選定；Bio 另測 Qwen2.5-0.5B 第 12 層。（§5、附錄 A、附錄 B）

Random 與 DiffMean 使用相同的三層無監督 SAE 字典；DiffMean 用標籤做事後特徵選擇。Hybrid 直接共用 TaxoSAE 的末端 SAE，上兩層用無監督 SAE；因此其末端 swap 答案必與 TaxoSAE 相同。附錄另比較把所有層概念綁定於同一 SAE 的 flat AlignSAE。各系統只用每概念一個特徵，swap 在各自最佳強度比較。（§5.1、附錄 G、附錄 J）

讀出：概念和問題層級不能混

Lq→Lr 表示以 Lq 問題在 Lr 讀取概念或其上位詞。Bio 的 TaxoSAE 對末端問題在 L1／L2／L3 皆 100%；中間問題的 L2→L2、L2→L3 為 69.8%／92.0%，頂層問題 L3→L3 為 87.8%。Animal 分別為 84.3%／86.9%／90.3%、47.9%／86.6%、50.6%；最後 50.6% 接近兩頂層節點的機率基準。Bio L2→L3 的 92.0% 比最強 baseline 60.7% 高 31.3 points，並不表示每個上層問題都達此差距。（表1、附錄 L）

作者報中間及頂層概念的有效特徵數 EffFeat 為 1.0–1.7、最強特徵佔比 Top1C 為 89–100%；這兩項以訓練問題的平均正向 activation 計算，不能直接解釋為每一個新問題僅一個 slot 被啟動。（§5.3、§6.1；個別問題界線為本檔補註）

未見概念測試各有 24 個新動物／關係、每個 100 個問題，皆無末端 slot 綁定，仍在既有六個中間節點和頂層分類；不是發現新類別或自行建立分類法。Animal 的 L2／L3 正確率 63.9%／76.1%，DiffMean 為 26.0%／56.8%；Bio 為 91.4%／94.8%，最強 baseline 分別 75.9%／69.8%。Animal 未見問題 72.5% 的最高 L1 分數低於已訓練概念第五百分位；18-way L1 沒有 none 選項，仍常被迫選已有節點。（附錄 C、表7）

控制：答案成功率與上位詞讀出分開

末端 swap 把來源 slot 設零、目標 slot 設指定強度；Strict 檢查同互補元素的目標答案。中間 swap 限來源與目標來自不同頂層節點，target-only coverage 檢查前 |U| 個 beam 候選是否涵蓋目標獨有答案。Bio 在各系統最佳強度下，TaxoSAE 末端 Strict 84.7%，DiffMean 81.8%，Hybrid 同為 84.7%；中間 coverage 41.8%，最佳 baseline Hybrid 16.3%，差 25.5 points。編輯後上位詞讀出與答案指標分開報告，不能把 93.2–100% 的上位詞讀出寫成 swap 答案全部成功。（§5.3、表2、附錄 H）

Bio swap 只替換最後 prompt token 的重建，Animal swap 使用保留重建誤差的形式，作用於每個 prompt 位置；兩資料集干預不完全相同。停用測試選最小 β 使該概念自身 exact match ≤5%，兩資料集自身 0–2%、其他概念 91–100%；exact match 是 teacher forcing 下每個答案 token 最可能，不能等同自由生成全程無副作用。（附錄 H、§6.2；自由生成界線為本檔補註）

Flat AlignSAE 的 Bio 末端 swap 5.5% 對堆疊 84.7%，中間 swap 18.3% 對 41.8%；兩者末端問題在各層讀出均完美，但 flat 編輯後目標上位詞讀出為零。此對照支持在其設定下堆疊有助跨層控制，並非證明任何分類法都需要此架構。（附錄 G、表12；外推界線為本檔補註）

消融與限制

Bio 移除 taxonomic alignment 時讀出及 swap 近隨機；移除其他損失的影響不均，去掉 taxonomic–free 正交反而改善部分 concentration，卻令中間 swap 41.8%→24.2%。Qwen Bio 單 seed、未調第 12 層的末端／中間 swap 是 60.5%／13.7%，比 GPT-2 主實驗低，層掃描顯示更深層可提升控制。（§6.3、附錄 F、附錄 B）

作者明列所有實驗為英文、兩個三層分類法各最多 18 個末端節點。底座是特別微調的小模型，事實和分類結構受控；對大型通用模型、其他語言、多父節點或非 is-a 邏輯不宜直接外推。（Limitations、§3；外推界線為本檔補註）
