《KAN-SR：Kolmogorov-Arnold 網路引導的符號迴歸框架》重點摘要

一句話概括

用 Kolmogorov-Arnold 網路（KAN）做符號迴歸：KAN 的「可學單變數函數」天然適合 SR。KAN-SR 走分而治之——可微訓練 KAN + AI Feynman 式符號簡化（對稱性、可分離性）把複雜問題拆成子問題（常可用單層 KAN 直接擬合）；擬合後把網路拆成模組化代數組件、用非線性最小平方匹配到符號函數庫 → 抽出緊湊表達式而不靠暴力枚舉。在 SRSD-Feynman 上勝基線（尤含無關變數時），並經 neural CDE 延伸到生物製程動態建模。

解決什麼問題

  • SR 同時推結構與參數、可解釋。GP 法彈性但樣本低效、計算貴、難擴展；神經符號系統多靠離散符號表示難端到端訓練。
  • KAN（Kolmogorov-Arnold 表示定理啟發）：用可學單變數函數取代「固定激活 + 線性權重」→ 更具表達力且可解釋 → 天然適合 SR 的符號抽取。

方法（7 步工作流，可選/可配置）

  1. 前處理（正規化/縮放）;
  2. 暴力搜尋（對簡單乘法式窮舉擬合 + BFGS，誤差低於閾值即接受）;
  3. 單層 KAN + 單 unit（summation 或 multiplication unit 的最小架構符號近似）;
  4. 單層 KAN + 多 unit;
  5. 簡化 + 子問題分解（辨識結構簡化/可分離組件 → 對子問題遞迴重啟）;
  6. 輸出變換（log/exp 等簡化函數形式後重搜）;
  7. 深層 KAN 擬合（巢狀迴圈：對各深度探索增加的寬度，前面失敗才用）。
  • 找到符號匹配即提早返回；否則逐步進入更具表達力階段。
  • Fast-KAN（用徑向基函數取代 B-spline 提速）+ RSWAF 激活函數;Jax 實作。加法 + 乘法 KAN 層組合可表廣泛表達式。
  • 符號抽取：用領域知情的單變數函數庫 + 非線性最小平方，把 KAN 拆成代數組件匹配閉式。

結果

  • SRSD-Feynman benchmark：解出率（solution rate）勝所研究的基線，含無關變數時提升尤顯著（歸功於分而治之 + 簡化管線發現更簡單子問題）。
  • 生物製程動態建模（in-silico）：結合 neural CDE → 回復可解釋的動力學速率方程。

局限

  • 優越表現只在「單層表示 + 簡化 + 單變數庫足以擬合」時才得到。把 SR（大型非凸混合整數非線性規劃）拆兩層、用固定 unit 數 + 有限單變數庫限縮搜尋空間 → 可能找局部解;若最優解在約束空間外則常失敗（不像 GP 演化探索）。更大更深 KAN 可緩解但會「擴散」、難抽符號、超參暴增。需完整資訊（閉式，關鍵變數不缺）；雖善處理高斯噪聲，但資訊不全會妨礙發現好方程。
  • neural CDE 是兩步法（乾淨做法是把 SR 直接整合進 neural CDE，但超出範圍）。

對讀者的價值

  • 本批的**「KAN × SR」橋樑**——連接 C 類（SR）與 H 類（KAN，2501.17896 等）；與 2511.04124 SeTGAP、2506.19537 降維同走「分而治之 + 簡化降維」攻 SR，但用 KAN 的可學單變數函數當骨幹。
  • 最值得記：KAN 的可學單變數函數天然契合 SR 符號抽取（拆成模組代數組件匹配函數庫）;AI Feynman 式對稱/可分離簡化 + 單層 KAN 子問題擬合 的分而治之；以及誠實的局限（限縮空間 → 局部解、最優在外則失敗）。
  • 與 2505.21879 SFR（網路動力學）、SINDy 皆觸及動態系統方程辨識（KAN-SR 用 neural CDE）。
  • 定位：方法論文 + SRSD benchmark + 生物製程案例（ETH 化工背景，Jax 實作）；適合做 KAN-based SR、動態系統方程辨識、化工/生工建模 的人。
