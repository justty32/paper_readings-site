論文／訪談原始來源

《面向 ARC-AGI 的高效神經引導程式誘導》重點摘要

一句話概括

系統比較三種「神經引導程式誘導」範式——學網格空間 (LGS)、學程式空間 (LPS)、學變換空間 (LTS)——並提出代表 LPS 的 GridCoder：用 VLM （視覺語言模型） 自回歸輸出 DSL token 序列的機率，再做機率枚舉搜尋找正確程式；靠條件獨立假設（把機率攤平成「位置×類別」而非樹，只需呼叫神經網路幾次）大幅提速；在 ARC-AGI 評估集 DSL 可解子集（29 題）達 79.3%（勝 MCTS+VLM 的 69%、純 VLM 的 13.8%），但結構性 (compositional) 泛化極差——10 個刻意 OOD 任務只解出 1 個 (10%)，作者提出尚未實作的 LTS（加回執行引導反饋）作為解方，proxy 實驗顯示可達 80%。

解決什麼問題

ARC-AGI 是開放世界域，隱藏測試集刻意與公開任務「質性不同」，深度學習的分布外 (OOD) 泛化在此失效。本文在程式合成設定下（假設 DSL 含足夠原語），系統研究「如何用搜尋高效擴展神經網路超出訓練分布的能力」，並要求測試集在組合結構上對訓練集 OOD（否則純神經網路即可解）。

核心方法

  • 三範式：
    • LGS（學網格空間）：對比學習一個「在特定 DSL 下兩網格的相似度」嵌入，當作 A* 式啟發式做執行引導搜尋。限定純網格到網格 DSL（Version 1）。
    • LPS（學程式空間）= GridCoder（選定方案）：訓練 VLM 輸出 token 機率序列 → 解讀為程式空間的機率分布 → 枚舉並按聯合機率排序、逐一驗證。非執行引導。
    • LTS（學變換空間，提案未實作）：把程式中間狀態回饋進每步解碼，結合 LPS 效率與 LGS 執行引導。
  • 搜尋演算法：概念近 DreamCoder / Heap Search，但機率不來自 n-gram，而來自 transformer 自回歸 token 序列。條件獨立假設：機率只依 token 位置、不依先前選擇（如貝氏網路簡化），故只需幾次推論 + 少量 bootstrapping（6 次不同範例對/起始 token 取均值）注入熵。
  • VLM 架構：雙 CNN（輸入/輸出網格）橋接為編碼器 + 單層 transformer 解碼器，452M 參數；輸出 token 序列自底向上、左到右建語法樹（特殊 token：<EOS>、<New Level>、<Identity>）。
  • DSL 與資料：三版 DSL（74→89→98 原語，逐步加物件偵測/過濾）；程序化「meta-pattern」任務生成器（split-merge、tiling、物件等），V1 約 5M 樣本，課程式微調。

結果

  • ARC 評估全集 15 分鐘預算：GridCoder 5.75%（DSL V3 達 8.25%）；可解 29 題子集 79.3%（5 分鐘亦 79.3%）。對比：MCTS+VLM 69%、Pixelwise sim 44.8%、Learned sim 37.9%、VLM-only 13.8%。
  • 條件獨立有益：GridCoder 79.3% > GridCoder cond.（不做假設）75.9%，且 5 分鐘預算差距更大。
  • DSL 擴展性佳：V1→V3 無遺忘、每原語平均解題時間不增反略降（0.064→0.057 秒/原語）→ 次線性擴展。
  • 結構泛化失敗：10 個 OAD 手作任務 GridCoder 只解 1（10%）；模擬執行引導的 LTS proxy 解 8（80%）。

局限

  • DSL 不完整（主要限制）；函數式 DSL 不如關係式 DSL 可做部分驗證；6 種物件偵測原語仍常失敗（擬改用物件分割神經網路）。
  • 程式語法低效（4 拼貼 vs 5 拼貼差 5 token、子樹須重複）。
  • LTS 僅 proxy 模擬未真訓練；GridCoder 只能提出訓練見過的程式結構（機率硬卡在 0/1），加訓也無法解決結構泛化。

對讀者的價值

  • 本批 E 類 ARC-AGI 代表之一，與 2411.08706 LPN（搜尋潛在程式空間）正好是同期姊妹路線——都在「神經 + 搜尋」解 ARC，但本文走離散 DSL token 枚舉、LPN 走連續潛在空間梯度搜尋。
  • 最值得記：「VLM 自回歸機率 + 條件獨立攤平 + 機率枚舉」高效搜尋配方；以及核心洞見——搜尋能補的是「網格層 OOD（高熵）」，補不了「程式結構 OOD（低熵卡死在 0/1）」，故執行引導 (LTS) 才是真正泛化解方。
  • 與 2411.02272（結合歸納+傳導）、2411.07279（測試時訓練）同屬 ARC 程式合成軌；對做 DSL 程式合成、神經引導搜尋、ARC 泛化分析的人有參考價值。誠實的 proof-of-concept 論文（坦承尚不具競爭力）。
