What Is a Skill Worth? Structure-Aware Shapley Valuation of Agent Skills 重點摘要

一句話

SkillSV 不把 skill 的段落當獨立 token：它先編譯 dependency 與文件 hierarchy，只對有效反事實 skill 算 Shapley 式信用，並拆開內容價值與 context 佔用成本。

為何平面 ablation 不夠

一個 rule、example、script 或 heuristic 可能引用其他單元、依賴標題上下文、或由 frontmatter 觸發。隨意刪除會留下 undefined symbol、壞連結或無標題表格，量到的是「agent 面對壞文件的韌性」而非被刪內容的價值。LOO 同樣會把依賴斷裂誤歸因於某單元。

SkillSV

  • compiler 將 skill 轉為 units N、dependency D、hierarchy H。Markdown 的頂層 list item 是 unit，縮排列入父項；標題是 rendering scaffold；輔助 script／reference 是 resource unit。
  • 只評估對 D downward-closed 的 coalition，且 insertion order 必須讓每個 prefix 有效並符合 H 的同層連續性。作者明確把採樣分布 μ 視為 estimand 的一部分，非假裝得到唯一的標準 Shapley 值。
  • ρ_del 真刪內容，量淨效果；ρ_pad 以長度中性的 placeholder 補位，量固定文件足跡下的內容效果。兩者差異是 context occupancy cost；有內容價值但佔位代價大的單元應壓縮而非刪除。
  • 用同一個 task window 比較一條 prefix chain 的相鄰 coalition，讓 task 難度在 paired difference 中抵消；固定 rollout budget 下，一個 order 給每一 unit 一個 marginal sample，並可用 noise gate 截斷已飽和尾端。

作者報告與限制

作者在 LiveMath、OfficeQA、SpreadsheetBench、ALFWorld 的四種已驗證任務上，報告其方法能保留 aggregate skill lift、找回 interaction，並導引安全 pruning／compression。實驗採固定 GPT-5.5 snapshot、K=12 orders、window b=8，兩種 rendering 的完整 audit 僅在 OfficeQA；結果均為作者報告。依賴抽取與 placeholder 中立性是核心假設，且成本仍會隨 skill 與 rollout 評估劇增。
