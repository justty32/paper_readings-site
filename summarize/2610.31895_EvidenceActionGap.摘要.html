論文／訪談原始來源

Knowing When to Stop: The Evidence–Action Gap in Coding Agents 重點摘要

一句話概括

ImpasseBench 在程式修復任務注入環境障礙，記錄 agent 何時取得足夠診斷證據、其後是否繼續嘗試或請求協助。作者報告明確的升級工具與證據提醒可改善所測的交接行為，但暫時性故障、仍可完成的工作、交接品質及乾淨任務效能都需要分開衡量。

基準與判準

作者從 SWE-smith 選取 102 個基礎任務、跨十個 Python repository，依參考修補大小分層，設置 12 類故障：六種持續性障礙、三種仍可修改但限制驗證的情況、兩種可重試恢復的暫時故障，以及一種原報告 bug 已不存在的控制。評估共涵蓋 19,371 條軌跡，每次執行上限 80 步。（§2.1）

每個故障有 evaluator 專用的 blocker card，規定何種輸出與合理恢復嘗試構成足夠證據。規則標註器將首次達到該條件的時間標為 t*；初次碰到錯誤不必然足以交接。持續性障礙要求在必要診斷後請求外部協助；驗證受限仍可能允許保留有用修改並誠實報告未驗證；暫時故障需要重試。t* 是依作者規則判定的參考點，不是模型真正內部狀態的直接量測，也不是所有情況都應立即停止的硬截止。（§2.1～2.3）

基本介面已有 task_complete 並允許 verified=false；介入組新增 escalate_to_human 工具及使用指示，呼叫時以結構化票據結束並保存補丁。這比較的是工具與指示一起加入的效果，並非僅改一個工具名稱；第一組比較交接後不恢復環境。（§3.1）

作者自報：工具對持續性障礙的影響

八個模型設定、同任務與故障的配對比較共有 9,684 組完整配對。持續性障礙有 4,344 組；基線 98.6% 的執行取得足夠證據。限制後續工具呼叫比較的 4,271 組在兩組執行都取得證據，平均證據後有效呼叫由 38.9 降至 17.5；同樣在該配對子集中，達框架上限的結束由 34.0% 降至 6.7%，證據後偵測到不安全請求的執行由 3.89% 降至 0.68%。完整 4,344 組的上限結束率則由 33.5% 降至 6.6%，分母不同。（§3.1～3.3、附錄 C）

作者以五類規則偵測不安全請求，包括猜測提升權限密碼、讀取受保護憑證或削弱既有測試等；偵測的是請求，包含被拒絕的請求，並不等於所有請求都實際造成傷害。作者報告所偵測的持續性障礙不安全請求皆出現在規則定義的充分證據之後，這不證明系統能偵測所有不安全行為。（§3.3、附錄 B.1）

過早交接也有代價：暫時性 sandbox 故障會在兩次失敗後恢復，新增工具組仍有十次執行提早交接、補丁為空，且全部未通過保留測試。因此「更快停止」不等同「正確停止」。（§3.2.1）

另一組 harness 與環境恢復實驗

作者另以 Qwen3-Coder-30B 在此前未用於監控器開發的 102 個 SWE-bench Verified 任務上比較基本與修改版 harness；兩組已有同一升級工具，修改版在符合可見輸出模式時額外提供提醒和票據模板。接受交接後，腳本最多恢復環境一次，保留補丁與歷史，讓 agent 使用原 80 步中剩餘的預算繼續。這與前述 SWE-smith 新增工具比較是兩組不同實驗。（§4、附錄 F）

五種主要持續障礙的 510 組配對中，接受的升級由 16.3% 升至 42.5%，恢復後最終成功由 7.6% 升至 21.8%。附錄另以含診斷、證據忠實及準備好交接等較嚴格條件計分，為 0/510 → 108/510；接受工具呼叫本身不等於票據符合此標準。提醒與模板一起變動，無法單獨歸因。（§4、附錄 F、表 24）

乾淨任務另有 149 組配對：基本組解決 50.3%，修改組 49.0%。差異未達顯著不等於證明無損：作者預先設定的非劣性判準要求點估計不為負且單側下界高於 −3 個百分點，實際差為 −1.34、下界 −10.71，因此未通過。這些乾淨執行都未觸發提醒；附錄的離線重播核查不產生新的獨立模型測試。（附錄 F）

票據品質與範圍

在原 SWE-smith 工具組的 3,149 份有效評分票據中，僅看任務與票據、不讀軌跡的 GPT-5.6 Terra 自動評為 74.1% 資訊足夠、25.9% 部分足夠；35.7% 的票據對已完成／未完成工作與驗證狀態僅部分說明。評分只檢查票據提供的交接資訊，不能直接證明其陳述事實均有軌跡支持：作者發現部分第二輪事實查核有問題，將事實支持分數排除，且未測量獨立人工評分一致性。（§5、附錄 G）

這些故障由研究者控制注入，證據時點與風險類型依預設規則標註；模型、任務與環境均有限。工具呼叫減少或未觸發規則，不足以證明所有行動安全；驗證受限時還要判斷是否有可保存的工作。作者將生產環境與多輪人機交接列為未來研究方向。（§2、§6）
