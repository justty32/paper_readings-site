論文／訪談原始來源

《EGG-SR：透過等式圖將符號等價性嵌入符號迴歸》重點摘要

一句話概括

把「符號等價性」嵌入現代符號迴歸（SR）的統一框架：許多語法不同的表達式其實是同一函數（如 log(2x)=log2+logx），既有 SR 把它們當不同輸出 → 冗餘探索、學習慢。EGG-SR 用 等式圖（e-graph） 緊湊表示等價表達式，並嵌入三類 SR 方法——MCTS、深度強化學習（DRL）、LLM——分別經 (1) 剪枝等價子樹、(2) 聚合等價序列的獎勵、(3) 豐富回饋 prompt 來加速學習。理論上收緊 MCTS 的 regret 界、降低 DRL 梯度估計的變異數；實驗上一致在相同時限內找到更準的表達式。

解決什麼問題

  • SR 搜尋空間隨資料維度指數成長（NP-hard）;符號等價是縮空間的有望但未充分探索方向。
  • 等價變體數隨表達式長度指數成長 → 顯式維護不可擴展。e-graph 解：只儲存共享子表達式一次，緊湊編碼等價集（用於程式優化、表達式簡化、去重）。但缺「讓多種 SR 演算法與 e-graph 互動加速學習」的統一框架。

核心：Egg 模組

  • 把 e-graph 擴展到文法式符號表達式（稱 Egg，純 Python 實作）。e-graph 由 e-class（等價類） 組成，每類含多個 e-node（等價子表達式）;e-node 編碼數學運算、指向子 e-class。
  • 給 SR 預測的產生式規則序列 → Egg 建 e-graph → 用改寫規則（rewrite rules，編碼已知數學恆等式）飽和（saturate） → 隨機遊走取樣取回一批等價序列。
  • 與既有用法不同：不是用 e-graph 找「最簡形式（Occam）」，而是刻意暴露 SR 演算法一批等價變體做「等價感知學習」。

三種嵌入

  1. Egg-MCTS：反向傳播時把獎勵/訪問次數分享給所有等價路徑（靈感自 transposition table，但 SR 中節點只在符號等價下相同，雜湊表不直接適用 → 用 Egg 辨識等價路徑）。剪枝等價子樹的冗餘探索。Theorem 3.1：更緊的 regret 界（有效分支因子變小，更快聚焦近最優區）。
  2. Egg-DRL：在策略梯度中聚合等價序列的獎勵（同獎勵的等價序列機率加總）。Theorem 3.2：無偏 + 嚴格降低梯度變異數（同獎勵分組減組內變異）→ 更穩定高效。
  3. Egg-LLM：把生成的 Python 函數解析成符號表達式 → e-graph 抽等價式 → 豐富回饋 prompt（讓 LLM 看到更多功能等價式）改善後續預測。

實驗

  • 在三角函數資料集（含大量等價變體）上：Egg-MCTS/Egg-DRL 一致找到更低 NMSE 的表達式（無噪與有噪設定皆然）。
  • Egg-MCTS 維持更廣更深的搜尋樹（探索更大更多元空間）。歸功於涵蓋豐富三角恆等式的改寫規則。
  • 與知識引導法（AI-Feynman 的組合性/對稱、物理單位約束）正交——是新的知識引導維度。

對讀者的價值

  • 與 2512.01682（Aldeia 論文用 LSH/equality graph 做簡化/去重）、2511.05849、G 類 2501.17848（equality graph 改進 GP）同屬「e-graph/等價性用於 SR」一脈，但本文獨特在把等價性嵌入「學習目標」（MCTS regret、DRL 梯度變異數）而非只做簡化/去重，且統一涵蓋 MCTS/DRL/LLM 三類。
  • 最值得記：「符號等價」是縮 SR 搜尋空間的免費午餐——同函數的不同寫法應共享統計；e-graph 緊湊表示 + 改寫規則飽和 + 取樣等價序列 的配方；以及兩個乾淨的理論保證（regret 界、梯度變異數）。
  • 與 2502.09100 等「LLM 推理」呼應：Egg-LLM 用等價式豐富 prompt。
