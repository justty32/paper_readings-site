論文／訪談原始來源

《Diffusion-Proof：超越自迴歸生成的形式定理證明配方》重點摘要

一句話概括

Diffusion-Proof：（作者稱）首個把擴散式 LLM（dLLM）用於形式定理證明 的訓練＋推理框架——以兩個協同的 7B 模型 dLLM-Prover-7B（寫整段證明）＋ dLLM-Corrector-7B（局部填補式修正）運作；靠 dLLM 的長程一致性與雙向感知 克服自迴歸（AR）模型「下一 token 預測導致長序列誤差累積、無法做填補式修正」的天生缺陷。在同資料集下相對顯著勝過 AR 基線——ProofNet-Test +1.61%、MiniF2F-Test +6.14%（pass@32），並解出一道連更強的 DeepSeek-Prover-V2-7B 都解不出的 IMO 題；承諾開源全部代碼/模型/資料。

解決什麼問題

用 AR LLM 做形式定理證明（Lean 等）雖有進展，但 AR 有天生缺陷：

  • 下一 token 預測：長程一致性差、長序列上誤差複合累積 → 次優表現；
  • AR 無法做填補式（in-filling）證明修正——一旦中間出錯只能從頭重來或繼續向後寫。

擴散 LLM（dLLM）把生成重構成「多 token 區塊的迭代去噪」，天生具長程一致性與雙向感知，已在程式碼任務展現潛力，但用於形式推理幾乎未被探索。

核心方法

  • dLLM 預備知識：AR 模型左到右建模 ℙ(xᵢ｜x[0:i−1]);dLLM 引入時間步 t∈[0,1]，以機率 t 獨立遮罩 token 成 x⁽ᵗ⁾，模型 ℙ(x⁽⁰⁾｜x⁽ᵗ⁾) 迭代從噪聲還原原 token（訓練目標＝對被遮罩位置的還原損失）。
  • 資料：蒐集 550 萬筆既有定理證明資料，清洗篩選出 30 萬筆 SFT 資料。
  • dLLM-Prover-7B：以該 SFT 資料微調 Fast-dLLM-V2-7B，強化「整段證明書寫」能力。
  • dLLM-Corrector-7B：提出新穎的 Large Block Correction 訓練法，讓模型用「大擴散區塊生成」做形式證明的局部填補式修正，利用雙向資訊感知。
  • 推理流程：Prover 先據定理陳述產出證明 → 若初版錯但證明骨架正確，則用 Corrector 以大區塊生成在局部精修該證明（而非整段重寫）。

結果

  • 同資料集下，相對顯著勝過 AR LLM 基線：ProofNet-Test +1.61%、MiniF2F-Test +6.14%（皆 pass@32）。
  • 解出一道 IMO 題，連更先進的 DeepSeek-Prover-V2-7B 都解不出。
  • 含驗證損失研究、修正過程消融、與 AR 基線及 DeepSeek-Prover-V2 的案例對比。
  • 評估遵循標準 pass@32；不允許 Long CoT 思考（Diffusion-Proof 與基線皆不支援長脈絡），以公平比較架構本身的優劣（而非追 SOTA）。

局限

  • 主要目的是驗證 dLLM 相對 AR 的架構優勢，而非取得 SOTA；絕對數值仍受 7B 規模與不允許 Long CoT 限制。
  • 修正只在「骨架正確、僅局部錯」時有效；骨架根本錯時仍需重生。

對讀者的價值

  • 本批 B 類「形式定理證明 ／ 可驗證數學推理」中罕見以「生成架構（擴散 vs 自迴歸）」切入 的工作——洞見是「dLLM 的雙向感知天生支援填補式證明修正」，這正是 AR 做不到的。
  • 最值得記：Prover＋Corrector 雙模型協同;Large Block Correction 局部填補式修正訓練法；以及「只在骨架正確時局部修」的推理策略。
  • 與本工作區 2604.26311 DreamProver、2606.24124 VeryTrace（驗證 LLM 推理）、2605.25618 SSR、2606.08728 AI4Math 綜述同屬形式化/可驗證推理群；與 DeepSeek-Prover-V2 直接對比。對做 Lean/形式證明、或好奇「擴散 LLM 能否勝自迴歸於結構化推理」的人很有參考價值。
