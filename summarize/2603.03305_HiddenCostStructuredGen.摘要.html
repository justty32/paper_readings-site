The Hidden Cost of Structured Generation in LLMs: Draft-Conditioned Constrained Decoding

arXiv: 2603.03305 | 會議: ICML 2026
作者: Avinash Reddy, Thayne T. Walker, James S. Ide, Amrit Singh Bedi (UCF + Lockheed Martin AI Center)

1. 問題與動機

LLM 逐漸被部署為軟體管線的組件，必須產生機器可解析的輸出（JSON、API 呼叫、SQL）。單一語法錯誤就使輸出不可用，因此「受約束生成（constrained decoding, CD）」透過 token 級遮罩與重正規化來強制有效性。然而，CD 並非無成本：當模型分配給合法 token 的機率質量很低（低「可行質量」），重正規化會大幅扭曲原始分佈，產生語意正確性下降——輸出格式完美但答案錯誤。

2. 核心機制：KL 投影稅（Projection Tax）→ 對接 ai_core §3.3 成本梯度

2.1 可行質量（Feasible Mass）與每步失真

對於前綴 \(h_t\)，合法 token 集 \(A(h_t)\)，可行質量定義為 \(\alpha(h_t) = \sum_{a \in A(h_t)} \pi_\theta(a \mid h_t)\)。受約束解碼的每步分佈為：

\[q(z_t \mid h_t) = \frac{\pi_\theta(z_t \mid h_t) \cdot \mathbb{I}[z_t \in A(h_t)]}{\alpha(h_t)}\]

每步 KL 失真精確等於 \(\log\frac{1}{\alpha(h_t)}\)。當 \(\alpha(h_t) \ll 1\)，每一步都引入大幅度扭曲。

2.2 累積投影稅（對接 ai_core §3.3 成本梯度）

解碼到長度 \(T\) 的總 KL 失真為累積和：

\[\text{KL}(\rho_q \mid\mid \rho_\theta) = \mathbb{E}_{z \sim \rho_q}\left[\sum_{t=1}^T \log\frac{1}{\alpha(h_t)}\right]\]

這是結構化生成的隱藏成本：當 schema 強制低熵 token（括號、引號、欄位名），模型對這些 token 的機率極低，每一步都交「投影稅」。多次累積後，解碼系統性地偏離正確語意軌跡。這就是 ai_core §3.3 所描述的成本梯度——每一步受約束推論的邊際累積成本。

2.3 軌跡偏差（Trajectory Bias）

即使最終序列滿足約束，重正規化按 \(\prod_t 1/\alpha(h_t)\) 重新加權序列分佈，使解碼偏好「容易投影」而非「全域正確」的路徑。

3. DCCD：草稿條件受約束解碼（對接 ai_core §5 受約束填碼）

3.1 核心洞察

可行質量 \(\alpha(h_t)\) 是上下文相關的。若先提供語意規劃 \(d\)（草稿），使 schema 相容的後續 token 變得高度可能，則 \(\alpha(h_t; d) \gg \alpha(h_t)\)，投影稅大幅降低。

3.2 演算法（兩階段，免訓練推論）

階段 1（草稿生成）：無約束生成 \(y \sim p_{\text{draft}}(\cdot \mid x)\)，捕捉語意規劃。

階段 2（草稿條件受約束解碼）：以 \((x, y)\) 為條件，使用 CD 產生最終結構化輸出：

\[\tilde{q}(z_t \mid \tilde{h}_t) = \frac{p_2(z_t \mid \tilde{h}_t) \cdot \mathbb{I}[z_t \in A(x, z_{<t})]}{\tilde{\alpha}(\tilde{h}_t)}\]

其中 \(\tilde{h}_t = (x, y, z_{<t})\)。硬約束只施於階段 2，因此結構保證完整保留。多草稿變體（K>1）使用累積 log-可行質量做延遲選擇，支援測試時擴展。

3.3 DCCD 作為「推理-格式化」解耦

DCCD 明確分離推理與格式化。兩模型可不同（草稿模型 + 投影模型），因階段 2 主要做結構實現而非開放推理，可採用更小模型，提升參數效率。這直接對接 ai_core §5 的受約束填碼策略——先解耦語意，再套用結構約束。

5. 分析要點

  • 草稿品質為上限：階段 1 正確時，階段 2 保留率 72.9-83.6%；錯誤草稿極少被修正（0.2-3.3%）
  • 可行質量與正確性相關：Pearson r = 0.71（累積 log-可行質量 vs 結構化正確率）
  • 非可驗證任務亦有效：TL;DR 摘要 DCCD win rate ~80%（品質/忠實度/覆蓋率）
  • 思考型生成對比：DCCD 優於 thinking+CD at answer stage（62.6 vs 51.2），因即使在回答階段套用 CD 仍引入足夠投影稅

6. 總結與 ai_core 對接

DCCD ai_core 對應
成本模型 累積投影稅 = Σ log(1/α) §3.3 成本梯度（每一步受約束推論的邊際成本）
解方策略 草稿條件降低可行質量缺口 §5 受約束填碼（先解耦語意，再結構化）
參數效率 小模型組合超越大模型 符合 §5 的效率論述

一句話：硬約束生成不是免費的——它按步收取「投影稅」。DCCD 先讓模型自由思考，再繳稅，使稅基（可行質量）最大化，稅率最小化。
