論文／訪談原始來源

《ConfidenceBench：大型語言模型的信心校準評估基準》重點摘要

一句話概括

ConfidenceBench：200 題私有選擇題、四類別（空間推理／高精度數學／文字查找／不可知）的口語化信心校準基準，以 Brier score（proper scoring rule） 為主要指標，評估 15 個前沿 LLM（三輪重複）。核心發現：準確度最高 ≠ 校準最佳——Claude Opus 4.6 校準最佳（Brier 0.103）、Gemini 3.1 Pro Preview 準確度最高（82.7%）但校準第三；推理量與模型規模獨立貢獻校準品質；五個模型劣於校準隨機基線（0.1875）。人類測試者 Brier 0.105（第三名），校準與準確度是正交的可靠性維度。

解決什麼問題

LLM 部署中流暢但錯誤的答案極其昂貴，但既有基準（MMLU、BIG-Bench）只測準確度、不測「模型知不知道自己可能錯」。信心校準（模型表達的機率是否反映真實正確率）是安全部署的前置條件（用於路由、棄權、人類審查），而口語化校準（verbalized confidence）是唯一對 closed/open-source 通用的方法（不需 logits/權重/重複採樣）。既有校準基準多僅測棄權、或混用 ECE（受分箱影響），缺乏用 proper scoring rule 直接比較前沿模型的緊湊基準。

核心方法

  • 問題集：200 題四選一，手寫、私有、未源於任何既有資料集，防訓練污染。四類別隔離不同知識失敗模式：空間推理（多步心智模擬）、高精度數學（取整誤差→似是而非錯誤答案）、文字查找（經典文本具體詞彙檢索，錯誤選項皆貌似合理）、不可知（無法憑既有知識推斷、需接觸真實物件的問題，如某日某街角的報亭顏色）。
  • 信心誘出：每題附加 prompt 要求輸出 JSON {answer: A–D, probability: 0–100}（25=隨機猜測基線）。無法解析的回覆與明確拒答者視為 25% 信心並隨機選答案（避免排除拒答造成選擇性偏差）。
  • 評估指標：Brier score B̄ = (1/n)Σ(pᵢ−yᵢ)²（越低越好，proper scoring rule——誠實回報機率的唯一最小化期望）；校準間隙 G（無平方→過度/不足信心呈帶符號量）；ECE（10 等寬分箱）與 smECE（核平滑可靠性圖）為輔助指標。校準隨機基線（均勻猜測 p=0.25）為 0.1875。
  • 實驗設定：15 模型（GPT-5 High/Standard/Low/Mini/Nano、Claude Opus 4.6/4.5/4.1、Claude Sonnet 4.6/4.5/4、Gemini 3.1 Pro Preview/Flash-Lite、Gemini 2.5 Pro/Flash），溫度 1.0，三輪獨立跑，共約 9,000 次 API 呼叫。人類基線：一名外部志願者，每題一分鐘、可用網路、相同格式回答。

結果

模型 Brier ↓ 準確度 ↑ ECE ↓
Claude Opus 4.6 0.103 ± 0.006 76.0% 0.069
Gemini 3.1 Pro Preview 0.103 ± 0.012 82.7% 0.086
Human Tester 0.105 70.5% 0.053
GPT-5 Standard 0.117 76.6% 0.067
GPT-5 High 0.121 75.8% 0.076
Gemini 3.1 Flash-Lite 0.367 55.3% 0.344
  • 準確度≠校準：Gemini 3.1 Pro 準確度最高但校準排第三；Claude Opus 4.6 校準最佳但準確度非第一。兩者正交。
  • 推理量×規模獨立貢獻：GPT-5 家族內推理量越高校準越好（Standard 0.117 > Low 0.141）；同代大模型校準一致優於小模型（Opus > Sonnet、Pro > Flash）。
  • 新≠好：Gemini 3.1 Flash-Lite 為全研究最差校準（0.367），劣於 2.5 代多個模型。
  • 不可知題是主要失校準源：模型認出自己不懂而降為 25%，但實際猜對率遠高於 1/4，呈不足信心——優於過度信心，但仍是不準確的機率。
  • 信心分佈：Claude Opus 4.6 在正確/錯誤回應間呈清晰單調分隔；Gemini 3.1 Flash-Lite 呈雙峰（25% 或 80–100%）。

局限

  • 口語化信心可能部分反映指令遵循/提示框架，而非底層知識狀態的不確定性。
  • 200 題英語多選、領域與格式有限，不推廣至長文本生成、多輪對話、其他語言/文化。
  • 私有題集限制個別題目的獨立審計。

對讀者的價值

  • 「品質分數」主題（§3.4 選型）的校準視角：Brier score 作為 proper scoring rule 直接獎勵誠實機率報告，是品質分數從「自簽憑證」走向「經過校準驗證的信心出口」的關鍵方法。
  • 口語化校準是唯一對 closed/open-source 通用的黑箱方法——對任何需要「棄權/路由/人類審查」的代理系統都是必備知識。
