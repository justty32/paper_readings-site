論文／訪談原始來源

《CRWM：為自動化技能生成做零樣本 Reward 設計》重點摘要

一句話概括

CRWM（Causal Reward World Model）：現有 LLM 自動化 reward 設計（ARD，如 Eureka）是相關性驅動——靠對每個任務反覆跑環境 feedback 精煉 reward，慢且易被「語意合理但因果虛假」的 reward 元件帶偏；CRWM 改用離線多任務互動資料預訓練一個因果世界模型，顯式建模「候選 reward 元件 ↔ 任務目標物理變數」的因果拓撲骨架，推論時把它當任務無關的因果先驗約束 LLM 生成 reward，達成 zero-shot（ESI=0，零次環境 feedback 迭代） 的 reward 設計，在連續控制 benchmark 上匹敵或勝過需多輪迭代的 SOTA，並跨未見任務與不同機器人形態強泛化。

解決什麼問題

LLM 帶起的 ARD（給任務描述 → LLM 生成候選 reward 元件 → 環境 feedback 迭代精煉）減輕了人手 reward 工程，但全靠 trial-and-error：LLM 挑出「與任務相關」的元件，卻可能是虛假相關。例如 ShadowHandLiftUnderarm（雙手舉鍋），LLM 把「瞬時舉升速度 velocity」當 reward——語意上跟「lifting」相關，但在連續物理互動中是高頻、因果模糊的訊號，引入嚴重梯度噪聲導致 Optimization Collapse;ShadowHandScissors，LLM 用 scissors_open 當 reward，agent 就鑽漏洞讓剪刀微開不停累積 reward 而不達真目標。LLM 在因果歸因與反事實推理上的弱點，使迭代式 ARD 難以一致地改善。

核心方法

  • CRWM 離線預訓練因果世界模型：在多任務互動資料上學「候選 reward 元件」與「任務目標物理變數」之間的因果拓撲關係，建出穩健可詮釋的因果骨架（causal skeleton）。
  • coarse-to-fine 策略 + Joint Optimization Module：先抽粗粒度結構先驗（Causal Foundation Model 給 structural prior），再用 micro-level 軌跡精煉。模組含兩件：
    • Explicit Mechanism Decoupling（EMD）：顯式解耦各因果機制（消融顯示移除 EMD 表現明顯不穩）。
    • Confidence-Aware Soft Fusion：依信心軟融合粗結構先驗與細軌跡證據。
  • Causal-ARD 推論：LLM 把 CRWM 當任務無關的因果先驗約束 reward 生成 → 單次 zero-shot 產出可執行 reward 函數，不需 feedback-driven 精煉（ESI=0）。
  • 評估指標：Success Rate（SR）+ **Evolutionary Search Iterations（ESI）**＝初始生成後的 feedback 精煉輪數（CRWM=0）。所有 LLM 方法用同一 foundation model（DeepSeek-v3）以隔離架構增益。

結果（Dexterity 套件 + ManiSkill2）

  • zero-shot 對比：CRWM（ESI=0）在未見任務上匹敵 SOTA 迭代法，勝過 Eureka（需 4 ESI）並匹敵 URDP（需 1–4 ESI）；無引導的 ZS-LLM baseline 在動態/長視界任務明顯較差 → 大幅降低取得新技能的設計延遲。
  • 跨形態/跨環境（ManiSkill2，不同機器人形態+物理）：zero-shot SR PickCube 0.64、OpenCabinetDoor 0.89、TurnFaucet 0.80;Eureka 要多達 6 ESI 才達近似且更不一致 → CRWM 捕捉到可遷移的因果結構。
  • 消融：移除 prior（CRWM w/o Prior）全面變差 → 純離線 transition 不足以穩定估結構；移除 EMD 表現明顯不穩。
  • Sim-to-Real：用 CASBOT W1 移動操作臂 + Offline Trajectory Evaluation（人遙操軌跡餵進生成的 reward 評估對齊）避開 sim-to-real 動力學落差。

局限

  • 仍依賴離線多任務互動資料預訓練 CRWM（資料覆蓋決定因果骨架品質）。
  • 因果先驗在「候選 reward 元件 ↔ 物理變數」層級；對全新類型的任務目標變數，先驗外推有界（論文 Limitations 章另述）。
  • sim-to-real 用 offline trajectory evaluation 規避真機部署，未做大規模真機 RL 閉環。

對讀者的價值

  • 本批 D 類**「自動發現 reward × 因果先驗」代表——與 2601.21847 READY（演化發現 reward / MetaBBO）形成對照：READY 用演化搜尋發現 reward，CRWM 用因果世界模型先驗**一次生成 reward；都瞄準「自動化技能生成的 reward 設計」這個自我改進瓶頸。
  • 與 Eureka（LLM 演化 reward）的關係最關鍵：CRWM 把 Eureka 的「多輪 feedback 迭代」壓成「ESI=0 單次因果約束生成」——這是「相關性驅動 → 因果驅動」的範式轉移。最值得記：「離線預訓練因果骨架 → 當任務無關先驗約束 LLM」 的配方，與 「語意合理但因果虛假的 reward 元件導致 Optimization Collapse / reward hacking」 這組失敗診斷。
  • 與 2606.16489 BRICKS-WM 都用「world model」但目的正交：BRICKS-WM 建動力學世界模型供規劃/重用，CRWM 建reward 因果世界模型供 reward 設計。
