作者：Shunyu Yao, Jeffrey Zhao, Dian Yu, Nan Du, Izhak Shafran, Karthik Narasimhan, Yuan Cao（Princeton University & Google Brain）

日期：2022-10（ICLR 2023）

arXiv：2210.03629

論文／訪談原始來源

《ReAct：在語言模型中協同推理與行動（Synergizing Reasoning and Acting in Language Models）》重點摘要

一句話概括

ReAct（Reason + Act）：把代理的行動空間擴充為「環境行動 ∪ 語言空間」，讓 LLM 以 few-shot prompting 交錯生成推理軌跡（thought）與任務行動（action）——推理引導、追蹤、修正行動計畫並處理例外（reason to act），行動則從外部環境（如 Wikipedia API）取回觀察餵入推理（act to reason）；在 HotpotQA/Fever 上因外部知識接地而大幅壓低 CoT 的幻覺，在 ALFWorld/WebShop 上僅用 1–2 個範例就以絕對 34%/10% 成功率輾壓模仿學習與強化學習基線。

解決什麼問題

LLM 的「推理」（CoT）與「行動」（行動計畫生成）此前被當成兩個獨立課題研究。CoT 是靜態黑箱——只靠內部表徵生成思路、不與外部世界接地，導致事實幻覺（hallucination）與推理過程的錯誤傳播；而行動生成類工作（SayCan、WebGPT 等）用 LM 產生領域行動，卻不做抽象的高階推理、不維護工作記憶。兩者如何協同、協同是否帶來系統性增益，此前無人研究。

核心方法

  • 形式化：代理在時刻 t 依 π(a_t|c_t) 行動、c_t 為觀察-行動歷史；ReAct 把行動空間擴充為 Â = A ∪ L（L＝語言空間）。語言空間中的行動即 thought——不影響環境、無觀察回饋，僅對當前脈絡 c_t 推理、把有用資訊組合進 c_{t+1}，支撐後續推理或行動。
  • thought 型態多樣：分解目標訂計畫、注入任務相關常識、從觀察抽取重點、追蹤進度並轉換子目標、處理例外並調整計畫。
  • 密／疏兩種節奏：推理為主的任務（QA/事實查核）採 thought-action-observation 步嚴格交替（dense）；行動多的決策任務（ALFWorld/WebShop）讓 LM 自行決定 thought 稀疏出現的位置（sparse）。
  • 知識任務工具：極簡 Wikipedia API——search[entity]／lookup[string]／finish[answer]，刻意弱於神經檢索器，逼模型靠顯式語言推理來檢索。
  • 內外知識互補：ReAct→CoT-SC（ReAct 限步數內未答則退回 CoT-SC）與 CoT-SC→ReAct（多數答案票數 < n/2、內部知識不可信時改用 ReAct）。
  • 微調（bootstrap）：仿 STaR 用 ReAct 自產的 3,000 條正確軌跡微調 PaLM-8B/62B。

結果

  • HotpotQA/Fever（PaLM-540B prompting）：ReAct 一致優於 Act（27.4 vs 25.7 EM；60.9 vs 58.9），證明推理引導行動的價值；Fever 上勝 CoT（60.9 vs 56.3）、HotpotQA 上略遜 CoT（27.4 vs 29.4）。組合法最佳：ReAct→CoT-SC 35.1 EM、CoT-SC→ReAct 64.6 Acc，且僅用 3–5 個樣本就追上 21 樣本的 CoT-SC。
  • 幻覺人工分析（各 50 條軌跡）：CoT 成功案例中 14% 為「幻覺出的假陽性」（ReAct 6%）；CoT 失敗主因 56% 是幻覺，ReAct 為 0%——外部知識庫接地讓軌跡更事實導向、可信。代價：交錯結構約束降低推理彈性，ReAct 推理錯誤率較高（47% vs 16%），且 23% 失敗來自無資訊的搜尋結果拖垮推理。
  • ALFWorld：ReAct 最佳 prompt 成功率 71%，vs Act 45%、BUTLER（10^5 專家軌跡模仿學習）37%；最差的 ReAct trial（48%）仍勝兩者最佳。對 Inner Monologue 式稠密外部回饋消融（ReAct-IM 53%）也顯著佔優——證明自由形式的內部推理 ≠ 覆述環境回饋。
  • WebShop：一/二-shot ReAct 成功率 40.0%，勝 Act 30.1% 與用一萬多條指令訓練的 IL+RL 28.7%（絕對 +10%）。
  • 微調：3,000 條自產軌跡微調後 ReAct 成四法最佳——微調 PaLM-8B ReAct 勝所有 62B prompting、62B 勝所有 540B prompting；微調 Standard/CoT 反而在教模型背（可能幻覺的）事實，微調 ReAct/Act 教的是「如何取用外部資訊」這一更可泛化的技能。
  • 附帶收益：軌跡人類可讀、可診斷（能分辨知識來自內部或外部）；人類編輯一兩條 thought 即可即時矯正代理行為（Fig. 5）。

局限

  • prompting 版與領域監督式 SoTA 差距仍大（HotpotQA 35.1 vs 67.5）；複雜任務需更多示範，易超出 in-context 長度上限。
  • 特有失敗模式：重複迴圈——反覆生成先前 thought/action 跳不出來（疑為貪婪解碼所致）。
  • 檢索品質是命門：無資訊搜尋佔錯誤 23%，推理被帶偏後難以恢復（事實性 vs 彈性的取捨）。
  • 主實驗基於未公開的 PaLM-540B（附錄以 GPT-3 複現且更佳：HotpotQA 30.8、ALFWorld 78.4）。

對讀者的價值

  • agent 基石論文，ai_core 執行迴圈的原型：thought→action→observation 迴圈正是 ai_core §1「符號神經網路計算圖」中 LLM 節點與確定性工具節點交替執行的最早清晰形態——thought 是 LLM 節點輸出，action 由確定性 API（search/lookup/finish）執行，observation 是確定性節點回填給 LLM 的邊。行動空間擴充 Â = A ∪ L 的形式化，等於在計算圖上宣告「語言節點只改脈絡、不碰環境」，是把 LLM 呼叫包成可靠函數時劃分純函數節點 vs 有副作用節點的先聲。
  • 接地訊號效益的早期實證：幻覺 56%→0% 這組數字是「外部確定性資訊源可矯正 LLM 內部知識」的最早量化證據之一，直接支撐 ai_core 用檢索/工具節點替 LLM 節點供給事實的設計；而「微調 ReAct 教技能、微調 CoT 教背誦」的發現，對 §3.6 固化引擎是重要提醒——該結晶成確定性程式碼的是「取用資訊的程序」而非「資訊本身」。
  • 對 §3.3 成本梯度亦有暗示：ReAct↔CoT-SC 互為 fallback 的啟發式（步數上限、多數票信心閾值）就是最原始的級聯路由——便宜的內部推理不夠可信才升級到帶工具的貴路徑（或反之），與 FrugalGPT 的評分-路由結構同構。thought 可被人工編輯即改變後續行為，也預示了 ai_core 治理面「在圖的中間節點設檢查/否決點」的可行性。
