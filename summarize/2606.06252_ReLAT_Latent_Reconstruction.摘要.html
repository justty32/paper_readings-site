日期：2026-06

arXiv：2606.06252

論文／訪談原始來源

《ReLAT：用問題重建閉合潛在推理迴圈》重點摘要

一句話概括

潛在推理（把中間推理從自然語言搬進潛在/快取表示以省 token、避開離散瓶頸）有個盲點：中間狀態不可檢視，沒人知道它是否還保有原問題的約束——這叫「開環」。ReLAT（Reconstruction-Guided Latent Reasoning At Test Time）用一個簡單原則閉合迴圈：若潛在狀態忠實代表了問題，就應該能從它重建出原問題；於是構造一個可微的「問題→潛在思考→問題」循環，在生答案前以「問題重建損失」做自監督測試時訓練（只更 LoRA），把不透明的潛在計算錨定回問題規格。在 Qwen3-8B 上把 AIME 2024 從 56.7% 提到 73.3%（較最強開環潛在基線 +16.6 分）。

解決什麼問題

近期把推理搬進潛在/KV-cache 表示（LatentMAS、Cache-to-Cache、ThoughtComm 等）以提效率，但代價是失去文字推理的可檢視性：潛在狀態一旦生成就被當作可靠中間態往下傳，語意漂移無從偵測、會沿推理鏈傳播。既有測試時訓練目標（熵最小化、perplexity、一致性正則）只管信心/一致/脈絡適應，不檢查潛在思考是否還保有原問題約束。如何給出一個自監督、可微的「輸入錨定忠實度訊號」？

核心方法

  • 核心觀察：問題本身就是檢驗忠實度的天然參照——潛在狀態裡「有風險的資訊」正是這道問題表達的約束集。若能從潛在狀態重建問題 → 約束還在；若不能 → 已丟失任務相關資訊（無論它看起來多自信/內部一致）。
  • 可微循環：構造 Question \(\to\) Latent Thought \(\to\) Question 循環。為讓離散 token 選擇可微，用連續鬆弛：把每個潛在思考向量表示為「模型詞彙分布下的期望 token 嵌入」（soft embedding），保持從重建損失到潛在思考生成的可微路徑。潛在思考序列長度固定 \(K=16\)。
  • 測試時訓練（ReLAT）：單一 backbone（凍結）+ 臨時 LoRA \(\phi\)。流程：生潛在思考 \(\mathcal{E}_\phi(Q)\) → 要同一模型從中重建原問題 → 算重建損失（帶 loss mask 只選原問題 token、排除模板/padding）→ 只更 LoRA（AdamW，\(N=16\) 步，lr \(1\!-\!5\times10^{-5}\)）。重建問題只用來定義損失、不用來生答案；每個測試實例後 LoRA 重置，保證實例級獨立。
  • 定位：重建是「適應訊號」而非「解題替代」；是必要但非充分的結構錨——把開環潛在推理轉成閉環的忠實度檢查過程。

結果

  • Qwen3-8B AIME 2024：56.7% → 73.3%，較最強開環潛在基線（LatentMAS）+16.6 分。
  • 跨數學推理（AIME 2024/2025）、知識 QA（GPQA-Diamond、MedQA）、程式生成（MBPP+），在 Qwen3-4B/8B/14B 與 DeepSeek-R1-Distill-Qwen-7B 上，ReLAT 一致勝過：單模型推理、文字級協作（TextMAS）、開環潛在協作（LatentMAS）、以及其他測試時訓練目標。
  • 消融（附錄）：直接重建式 TTT 基線不如 ReLAT 的可微潛在循環。

局限

  • 重建忠實度是必要非充分——能重建問題不保證推理正確，只過濾/校正明顯失真的潛在狀態。
  • 每個測試實例需 16 步 LoRA 更新 + 重置，增加推理時計算（雖凍結 backbone）；長生成（AIME 設 20,000 token）使開銷更顯著。
  • 連續鬆弛（soft embedding）是對真實離散潛在推理的近似；\(K=16\) 等超參需調。

對讀者的價值

  • 點出潛在推理／latent CoT 這條熱門路線的結構性風險（開環、不可驗證），並給出一個優雅、自監督、可微的補救——對任何在做 Coconut 式連續思考、KV-cache 通訊、latent multi-agent 的人很有啟發。
  • 與本批構成「測試時適應三路」對照：2604.19295 TEMPO 更策略權重（RL）、2509.04439 ArcMemo 更外部記憶（不動權重）、本篇 ReLAT 更潛在狀態忠實度（LoRA + 重建）。與 2603.06590/2411.07279 的 ARC 式逐題 LoRA TTT 同屬「測試時微調」家族但目標不同（這裡是錨定輸入而非擬合範例）。
  • 最值得記：「忠實的潛在狀態應能重建出原問題」是個可直接落地的自監督訊號；把開環潛在推理改成閉環只需一個可微的 Q→Z→Q 循環；以及「重建是必要非充分的結構錨」這個誠實的定位。
