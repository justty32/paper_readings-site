論文／訪談原始來源

PolicyHarness：介面改變會同時移動任務上限與模型失配

核心主張

Harness包含prompts、tools與control logic，決定模型看到什麼、output怎麼decode成具參數operation、operation如何執行。相同weights經不同encoder／decoder，可有不同semantic policy。論文在KL-regularized control下，把部署return寫成\(J=C-M\)：\(C\)是該harness／objective的最優regularized return，\(M\)是policy沿自己trajectories偏離最優決策的損失。固定harness訓練只動\(M\)；換harness可同時動\(C,M\)，故固定checkpoint比較不等單獨測harness潛力。（§1–2、§5）

「policy暗中是harness」精確指：在訓練介面下達最優的policy log odds，可識別該harness的相對action scores。不是weights含harness的程式、tool machinery，亦不能由behavior唯一復原reward、reference或dynamics。有限post-training checkpoint只是實測逐漸接近其target，不能直接套「已最優」。（§3.1、附錄C）

Semantic abstraction與理論條件

Interface \(\mathcal I=(c,d,e)\)分encoder、semantic decoder與固定executor；semantic policy是所有decode成同一完整operation/arguments的token sequences機率和。State需含task、history／sufficient summary、tools、budget、controller memory；retry、verification、summary等若再次呼叫evaluated model，都是新decision epoch，不能藏進與policy無關的transition。Invalid output須定義failure／recovery action，不能丟掉重正規化。（§2、附錄B.2）

定理用finite states/actions、bounded rewards、\(0\le\gamma<1\)、\(\tau>0\)、available actions上full-support reference；跨interface固定initial distribution、reward units、discount、regularization及state/action alignment。Log-score/readout另需actual policy在queried actions為正；固定interface的gap identity容許0policy probabilities，以\(0\log0=0\)。Reference是control problem的一部分，每interface訓練中固定；自然地把frozen reference model經新prompt推到semantic space時，reference本身也可能改，target不一定不動。（附錄B.1）

Token-level training只有在同action fiber內reward、transition及discount相同，並保reference conditional realization時，sequence KL的chain rule才把optimization精確降成semantic KL。Autoregressive token KL要對應同含termination的sequence measure；token-dependent reward、length discount或中途新model decisions需擴state／決策模型。不能把任意token SFT/RL自動當已解semantic-control最優。（附錄B.3；最後一句為本檔補註，非作者自陳）

可識別的是相對scores，不是mechanism

最優\(F^*=Q^*+\tau\log\pi^{ref}\)，\(\Pi^*=softmax(F^*/\tau)\)。同state全部actions加相同常數不改behavior，所以只識別\([F^*]\)；達最優時\(\tau\log[\Pi(a|s)/\Pi(b|s)]=F^*(s,a)-F^*(s,b)\)。不同reference、reward甚至transition可產同score class；reward常數平移亦可改absolute return卻不改decision。（§3.1、附錄C.3）

實際readout為\(\widehat F_{\theta,I}=\tau P_\perp\log\Pi_{\theta,I}\)。對aligned states/actions，部署score error分為target shift、source training residual、readout drift的向量和；它們可抵銷，不能將各norm或各loss任意相加。等價最優decision只設target shift為0，不保frozen model readout不變。（§4.1）

Return loss的精確方向與adaptation門檻

\[M(\theta,I)=\frac{\tau}{1-\gamma}\mathbb E_{s\sim d_I^{\Pi_{\theta,I}}}\mathrm{KL}(\Pi_{\theta,I}(\cdot|s)\|\Pi_I^*(\cdot|s)),\qquad J_I=C_I-M(\theta,I).\]

KL方向是actual→optimal，occupancy亦是actual policy在該部署interface的discounted occupancy，不是uniform states或optimal visitation。局部loss是\(D_\Phi(F^*,\widehat F)\)，\(\Phi=\tau\log\sum\exp(F/\tau)\)；Bregman兩參數不可顛倒。Ceiling依harness及objective，不是raw task success天花板；有成本／discount／KL時\(J\)與success是不同量。（Proposition5.1、§5.2、附錄D.1–D.2）

Frozen swap的\(\Delta J=\Delta C-\Delta M\)。若原本有害，adapted source \(\theta_1\)要超原source pair，充要條件為

\[M(\theta_1,I_2)<T=C_2-J(\theta_0,I_1)=\Delta C+M(\theta_0,I_1).\]

\(T\le0\)時因\(M\ge0\)，目標harness再怎麼適應也無法超source pair。這個recovery、同adapted checkpoint對兩harness的ranking、及相同budget下勝過source-harness continuation，是三種比較，不能互換；ranking reversal可只因source-interface performance下降。（Corollary5.2、附錄D.6）

Score-error upper bound \(M\le\varepsilon_d^2/[4\tau(1-\gamma)]\)用actual occupancy與positive probabilities；若此真upper bound低於\(T\)才保recovery。Lower bound另需沿actual／optimal scores interpolation全程uniform \(p_{min}>0\)；無此overlap不能有獨立於機率的正quadratic lower constant。Output correspondence界readout drift亦需semantic-action fibers保持的bijection及finite token log-sensitivity。（§6.1、附錄D.4、附錄E）

受控MiniWoB：完整單token action menu

三families：click-checkboxes、synonym版soft-checkboxes、ascending-numbers；編成checked finite acyclic task graphs，reward binary exact completion、zero explicit costs、每episode10actor decisions、\(\gamma=.95,\tau=.1\)。H0一native action；H1額外ordered two-click batches，只算一decision／discount；H2automatic gate；H3optional program verification；H4frozen2B reviewer；H5只改instructions。H5雖同execution，frozen reference讀不同input，故regularized optimum另解，不把reference效應混稱新增物理能力。（附錄F.1、表4）

每family480train、96calibration、24train probe、192test；共1440train／288calibration／72probe／576test，probe是training subset，其餘public contents disjoint。每action及arguments對一case-sensitive single-token code，對完整menu next-token logits以temperature1正規化，故semantic distribution精確可讀；這不同於部署coding的open actions。（表5、F.1 Readout）

Coding harness：teacher proxy只支持有限排序

Frozen Qwen3.5-9B、五native harnesses，Terminal-Bench Lite39tasks各三independent runs，accuracy是三次single-run rates mean±sample SD，timeouts/failures留分母。Model thinking on、temperature.6、32768output／65536context、50top-level decisions及task time limit；summary／subagent／retry亦計decision。（附錄F.7）

Proxy只用三probe tasks，各target/teacher原有每task三trajectories，僅full probes的complete trajectories入估計：teacher Pi7/9、其他9/9；target Pi7、DeepAgents6、DeepSeek8、Terminus／mini9/9。每recorded state重送context、只sample不執行tools；target128／teacher64samples，13common categories各pseudocount.5。Categories合併不同arguments/effects，非嚴格同semantic-action fiber；opaque／invalid保留，不是把難解析的output丟掉。（F.7 Probes／Categories）

F.8另解的exact study與結論邊界

F.8用off-the-shelf9B／無adapter、thinking off／one-token menu、同576MiniWoB tasks，reference設同frozen actor，finite-horizon10decisions、\(\gamma=1,\tau=.1\)。這是與post-training不同objective／reference的新control problems；backward/forward精確算\(C,J,M\)，residual≤\(7.22\times10^{-16}\)，每task/harness另256rollouts。由reference=self使\(J\)等success，\(C-M\)完整排序六harness；單\(-M\)雖也選H3卻錯排H1／H0，單\(C\)選H0。不能把此finite-horizon例當直接違反前面discounted定理的\(\gamma<1\)條件。（附錄F.8；最後一句為本檔補註，非作者自陳）

作者建議同時報ceiling、frozen return，跨多checkpoint看harness，並檢presentation對choices的影響。受控finite-menu結果和open coding proxy支持這個診斷方向；它們不保任何「更高ceiling」候選都能在任意有限訓練budget獲勝，更不以behavior唯一反推harness machinery。（§7、附錄B–F；後一範圍界線為本檔補註，非作者自陳）
