《物理科學中的符號迴歸特刊導論》重點摘要

一句話概括

Royal Society「物理科學中的符號迴歸」特刊導論（源自 2025 年 4 月倫敦會議）——是整個 C 類（符號迴歸）的總綱地圖：界定 SR、對比傳統迴歸、盤點三大用途（科學發現 / 經驗建模 / 模擬器 emulator）、方法學考量（搜尋空間、運算子、複雜度控制、特徵選擇、AI 整合）、挑戰（擴展性、抗噪、過擬合、計算複雜度）與新方向（對稱性/守恆律等先驗約束 + LLM 協同）。

SR 是什麼

  • SR 從資料中發掘底層數學表達式 f（y=f(x)），不像傳統迴歸對預設結構擬合參數；探索算術/三角/指數/對數等運算子組合構造候選方程。
  • 輸出是顯式公式（人類可解釋、捕捉內在結構 → 外推泛化更好）。
  • 歷史：Lenat AM、BACON、ABACUS、LAGRANGE → GP（Koza 1992，現代 PySR/PyOperon）→ AI Feynman、AI Descartes → 深度/RL 的 EQL、uDSR → 近期 transformer/基礎模型端到端。

三大用途

  1. 科學發現（物理定律）：最雄心——從實驗/觀測資料抽基本定律或新描述方程。靠簡約原則（Occam 剃刀）+ 複雜度懲罰/簡單性先驗（緊湊方程更可能是真關係而非過擬合）。湧現現象領域最富礦（天文物理、凝態、工程）——不一定推翻基本定律，而是發現特定脈絡下支配湧現行為的數學形式，連接微觀↔宏觀。
  2. 經驗建模：擬合緊湊準確模型（未必是物理定律）；比非參數/過參數深度模型更具洞見、易用；外推穩健（若捕捉到真功能形式）—— MDL（最小描述長度）與簡單性先驗關鍵。但外推仍須謹慎。
  3. 模擬器/代理模型（emulation）：把昂貴的第一性原理模擬（量子力學、流體、廣義相對論）用快速準確的數學近似取代；顯式公式 → 揭示輸出對輸入的敏感度（主導物理效應）、可嵌入資源受限硬體（線上控制）—— 勝神經網路 emulator 之處在簡潔可移植。

方法學考量

  • 策略性問題選擇：當「期望存在簡潔可解釋關係」時 SR 最有益；純求準確/變數多時深度網路更合適（但需更多資料）。SR 可用小資料，但噪聲/不足資料 → 虛假或過複雜方程、過擬合。
  • 高複雜系統：需特徵工程、降維;GP 經演化選擇壓力做隱式特徵選擇（從高維自動找低維方程的相關變數）。擴展性是限制 → 自動辨識函數/階層模組結構以求更壓縮描述。
  • 搜尋空間設計（運算子/基函數，由領域知識引導）是成敗關鍵：太窄錯失方程、太大不可解或過擬合。

新方向（前沿）

  • 納入先驗科學知識（縮搜尋空間、增物理合理性）：對稱性（平移/旋轉/宇稱）、守恆律（能量/動量/質量）、漸近行為/邊界條件、部分理論模型（用 SR 補缺失項）、量綱齊次性。
  • LLM/基礎模型協同：假設生成（建議相關變數/函數形式/物理原理）、解釋（把複雜公式譯成直覺自然語言）、程式生成、橋接資料與背景知識（形式化約束、整合進模擬框架）。

會議速寫（特刊內容地圖）

  • 方法：Desmond 的窮舉式 SR + 描述長度排序、Guimerá 的Bayesian Machine Scientist（貝氏模型選擇≈統計物理）、Cornelio 的 AI-Descartes/AI-Hilbert（納入公理與形式證明）、Bomarito 的 GP 後驗取樣、Burlacu 的 Zobrist hashing 去重、Olivetti de Franca 的 equality graphs、Russeil 的多資料集→通用定律。
  • 套件：Cranmer 的 PySR、Kutz 的 SHRED（潛空間稀疏迴歸）、La Cava 的 BRUSH（多目標 SR + 醫療可解釋）。
  • 應用：Bartlett 的大尺度結構功率譜解析 emulator（勝神經網路）、Yasin 的弱透鏡 ESR、Kabliman 的金屬合金材料性質、Abel 的超出標準模型物理 emulator、Constantin 的物理定律「類 Zipf 律」統計性質。

挑戰與展望

  • 高維擴展難（表達式空間隨輸入暴增）、抗噪/離群/系統誤差、計算限制；數學正確但物理無意義的風險（需領域知識）;MSE 不足以評 SR（好內插≠合理外推/物理合理）→ 需可解釋/簡單/穩健，MDL 做複雜度控制；不確定性如何傳進符號表達式（需信賴評估、辨識可信 regime）;SR 形式上 NP-hard;階層/混合建模（全域結構共享、局部參數變化）是延展途徑。

對讀者的價值

  • 本批 C 類（符號迴歸 21 篇）多源自此特刊 → 這篇是先讀的總綱：給 SR 的定義、用途三分法、方法學詞彙（搜尋空間/運算子/複雜度/MDL）、前沿（物理約束 + LLM）、與後續各篇的對應（ESR、Bayesian Machine Scientist、PySR、equality graphs、emulator…皆有專篇）。
  • 與本批 NeSy 主軸的接點：SR 是「符號 + 子符號 + 神經混合 AI 特別有用的首選場景」（原文語），且與 2502.09100 等「LLM + 符號」呼應（LLM 當 SR 的假設生成器/解釋器）。
  • 最值得記：SR 三用途（發現/建模/emulator）、簡約=MDL、搜尋空間由領域知識引導、物理先驗（對稱/守恆/量綱）縮空間、MSE 不夠用。
  • 定位：特刊導論/綜述（無新方法/實驗），是建立 SR 領域地貌的最佳入口。
