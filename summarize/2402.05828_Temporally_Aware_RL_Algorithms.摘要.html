論文／訪談原始來源

《發現具時間感知能力的強化學習演算法》重點摘要

一句話概括

給 meta-learned 的 RL 目標函數加上「訓練壽命」條件（已用步數 n／總訓練步數 N），讓發現出的演算法能在 agent 訓練過程中動態改變自己的損失函數；並發現只有用演化策略（ES）才學得到這種動態更新，meta-gradient 因目標短視（myopic）會失敗。據此提出 TA-LPG / TA-LPO，在未見的訓練時程與環境上全面勝過非時間感知的 LPG/LPO 與 PPO。

解決什麼問題

近期 meta-learning 已能自動發現以代理目標函數（surrogate objective）參數化的新 RL 演算法。但要勝過人工設計，參數化既要夠表達力（能表示新的學習原則、而非只復現舊的）又要能泛化到 meta-train 分佈之外。問題是：現有方法發現的目標函數（如多數常用 RL 目標）不考慮「訓練時程（training horizon）」——還剩多少訓練步數。但人類會依時程改變學習策略（學生臨近考試會改讀書法）。忽略最佳化時程，顯著限制了被發現演算法的表達潛力。

核心方法

  • 壽命條件化（lifetime conditioning）：把 agent 當前壽命 n/N（n＝已互動步數、N＝總訓練時程）餵進學到的目標函數。
    • TA-LPG：在 LPG（Learned Policy Gradient，LSTM 逆序處理轉移、輸出 bootstrap 向量與策略目標）的輸入加上 n/N 與 log(N)。
    • TA-LPO：在 LPO（Learned Policy Optimization，以神經網路參數化 Mirror Learning 的 drift 函數、PPO 是其特例）的 drift 函數輸入加上 (n/N)·x_{p,A}，刻意保持結構以滿足 drift 函數的理論條件（單調改善保證）。
  • meta-最佳化的關鍵抉擇：meta-gradient 須對截斷視窗做 BPTT、記憶體受限、目標短視；ES（演化策略）可對整個 agent 壽命做最佳化、適應度＝訓練結束的最終回報，無額外記憶體成本。
  • 多任務 ES 的適配——antithetic task sampling：對偶取樣的每一對候選 x±σϵ 在同一個隨機抽到的任務上評估，再對該對適應度做 rank transformation（等於選表現較佳者），跨任務正規化、穩定訓練。

關鍵結果

  • 適應可變時程：在 held-out Grid-World 上，TA-LPG 在所有時程上最終回報都高於 LPG——短時程上於「sparse」任務只用 LPG 1/8 的步數就達最高表現；長時程上於「dense」任務在 LPG 已停滯後仍持續進步。展現「犧牲訓練中期表現以換取更佳最終回報」的探索/利用權衡。
  • OOD 泛化：TA-LPO 雖只在 MinAtar 的 Space Invaders 單一環境 meta-train，卻在 MinAtar 與 Brax（連續控制）兩個測試套件上顯著勝過 LPO 與 PPO，且對差異極大的超參（10M 步/rollout 128 vs 50M 步/rollout 5）穩健。常在訓練末期才超越 PPO，暗示 lifetime awareness 可緩解 RL 常見的「過早收斂」失敗模式。
  • meta-gradient 失敗：以 meta-gradient 訓練的 TA-LPG 在所有時程上回報更低、且更新範數對時程無一致適應；ES 版才學到動態適應。佐證「截斷式 meta-最佳化不足以發現長視（long-sighted）演算法」。
  • 學到的動態母題（analysis）：TA-LPO 從訓練初期的樂觀（optimism）＋最大化熵，轉為訓練末期的悲觀（pessimism）＋最小化熵；並實作了「非對稱 rollback 排程」（比 clipping 更激進、對極端比率反轉梯度）與隨時程調整的更新/熵退火排程，有效平衡探索與利用。

局限

  • LPG 路線難取得強（理論）穩健性保證，不利可靠部署；LPO 路線 meta-learn 的空間受限較多、表達力可能較弱。

對讀者的價值

  • 本批 D 類（meta-learning / 演化 RL） 重要的「表達力 × meta-最佳化方法」對照研究：核心洞見是**「想發現非短視的動態演算法，meta-最佳化方法（ES vs meta-gradient）比參數化本身更關鍵」**。
  • 最值得記：壽命條件化 n/N、ES 才能學到動態目標、antithetic task sampling、樂觀→悲觀的時間排程。
  • 與 2101.03958（演化符號損失計算圖）對照：本文不演化符號圖，而是為既有 neural meta-RL 損失（LPG/LPO）加時間輸入並改用 ES；未來方向是再加 optimizer 統計、架構、任務資訊，最終走向純 in-context 的黑箱 meta-learning。
