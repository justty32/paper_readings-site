作者：Quan Long（河北大學）, Bin Wang, Bing Xue, Mengjie Zhang

日期：2025-01，KAN 架構搜尋（H 類）

arXiv：2501.17411

論文／訪談原始來源

《基於遺傳演算法的 KAN 在分類任務中的自動最佳化（GA-KAN）》重點摘要

一句話概括

GA-KAN：首個用演化計算（遺傳演算法）自動最佳化 KAN 架構的方法——把「神經元連接 + grid 值 + 網路深度」編碼進染色體，配合退化機制（degradation）+ 零遮罩（zero mask）解碼出不同深度的稀疏 KAN，全程零人工介入；在 5 個 UCI 分類資料集上勝傳統 ML 與手工 KAN（Iris/Wine/WDBC 達 100%、Raisin 90%、Rice 95.14%），且參數量大幅下降（如 WDBC 1560 vs 手工 KAN 27328），並能對 Wine/Iris 抽出可解釋的符號公式。

解決什麼問題

KAN（Kolmogorov-Arnold Networks，2024）以「邊上可學習激活函數、節點只做求和」取代 MLP，理論上更可解釋。但手工設計 KAN 結構費時費力：原版靠剪枝（pruning）縮小網路，需設懲罰因子（如 λ₁、λ₂）、跨資料集調參、依賴專家知識，且剪枝限制了層數、無法動態調整深度。GA-KAN 要把這整套結構搜尋自動化。

核心方法

  • 編碼策略（Encoding）：對每層相鄰神經元間的連接用 0/1 編碼（1=有連接，0=無）；另加 6 bits 編碼 grid 值（範圍 1–64）、2 bits 編碼網路深度（depth−1，可表 1–4 層）。染色體長度固定（式 5），由搜尋空間決定（最大深度、每隱藏層最大神經元數）。
  • 解碼（Decoding）＝退化機制 + 零遮罩：某層全為 0 即「退化」掉該層（深度−1）；但隨機讓整層全 0 機率極低，故用零遮罩主動把某層所有 bits 設 0，配合直接編碼的深度位，讓固定長度染色體能解碼成不同深度的 KAN，維持族群多樣性。
  • 適應度評估（Algorithm 2）：解碼成 KAN → 用 LBFGS（同原 KAN 設定）訓練固定步數 → 取訓練過程中最小驗證損失為適應度；無效結構（input 到 output 無通路）給 +∞ 適應度直接淘汰。
  • 交叉與突變：交叉只發生在兩親代同層同位置的神經元（grid/depth 用單點交叉）；突變翻轉任意 bit（0↔1），維持多樣性、防早熟。
  • 可解釋性三面向：feature importance（feature_score 層級反傳）、feature selection（編碼天然做特徵子集選擇，wrapper 式）、symbolic formulae（auto_symbolic 自動抽公式 + 選用的人工精修）。

結果（含數字）

  • 參數設定：最大深度 4、每隱藏層最多 5 神經元、grid 1–64；交叉率 0.9、突變率 0.5、族群 100、世代 20、LBFGS、20 epochs。KAN 版本固定 0.2.1。
  • 兩個 toy 資料集（原 KAN 論文的符號公式 exp(sin(πx)+y²) 等）：GA-KAN 自動找到對應結構，無需手調剪枝參數。
  • 五個 UCI 分類資料集：Iris 100%、Wine 100%、WDBC 100%（AUC 1.0）、Raisin 90.00%（勝 SVM+GA 的 87.67%）、Rice 95.14%（AUC 0.985），全面勝傳統 ML 與兩種手工 KAN baseline。
  • 參數量大降（Table V）：Iris 156（vs 882/1360）、Wine 390（vs 6912/2340）、WDBC 1560（vs 27328/4410）。
  • 可解釋：Iris 抽出 3 條類別分數公式（width 特徵最關鍵，含 sin 非線性項）;Wine 公式為線性、Color_intensity 主導，並自動剔除 Nonflavanoid_phenols 特徵。

局限

  • 因 KAN 訓練本身慢（約 MLP 的 10×）＋ NAS 評估成本高，只在相對小規模、低維、類別均衡的資料集驗證。
  • 符號公式抽取有時自動結果不佳，需選用的人工精修。
  • 未做迴歸等其他任務；未探資源受限硬體部署與大規模擴展。

對讀者的價值

  • 本批 H 類（KAN） 中走「演化計算 × NAS × KAN」路線的代表，與 2506.07549（MetaKAN，走 meta-learning 壓參數）形成對照：兩者都攻 KAN 參數爆炸，但 GA-KAN 用架構搜尋找稀疏結構，MetaKAN 用meta-learner 生成權重。
  • 最值得記：「連接/grid/深度三者一起編碼進染色體」+「退化機制 + 零遮罩動態調深度」 的編解碼設計；以及 KAN 天生可解釋 → GA 同時做特徵選擇 + 符號公式。
