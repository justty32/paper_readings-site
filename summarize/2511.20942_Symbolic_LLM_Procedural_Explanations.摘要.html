《透過受限生成改進程序技能解釋：符號-LLM 混合架構》重點摘要

一句話概括

AI 教育場景的符號-LLM 混合：教程序技能時，LLM 的解釋常流暢但淺薄，缺了老師期望的結構邏輯——因果（步驟依狀態）、目的（步驟服務目標）、分解（問題拆子目標）。本文用 TMK（Task-Method-Knowledge）符號模型當「主動鷹架」約束 LLM 生成：TMK 層定義可推理空間（有限狀態機 + 目標階層 + 守衛條件），LLM 層在此結構界內合成解釋。系統 Ivy 顯示符號約束一致提升「how/why」解釋的結構品質，分解維度提升最大。

解決什麼問題

  • Ivy（2025 春部署於研究生 AI 課）回答程序技能問題，流暢但缺結構：causality（步驟如何依狀態）、teleology（步驟為何服務總目標）、decomposition（問題如何拆子目標）。
  • 技能遷移（有意義學習的標竿）需理解「為何/如何」程序有效，非表層流暢 → 提升解釋的推理結構是教學價值的核心。
  • 既有 TMK-Basic 只捕捉目標 + 機制，未顯式編碼因果轉移、目標階層、形式分解 → 引導出的答案流暢但泛泛。

核心設計

  • TMK-Structured（本文）把三種推理結構顯式化：因果轉移（有限狀態機 FSM）、目的連結（目標階層）、階層分解（目標抽象）。
  • 受限生成架構：分離符號控制（TMK 層：FSM/目標階層/安全條件/轉移）與生成解釋（LLM 層：詮釋 TMK、生成解釋）。LLM 在 TMK 結構界內生成 → 措辭靈活但邏輯不漂移（TMK 定義合法的移動與理由空間）。
  • 範例「守衛與囚犯（Guards and Prisoners）」：ReturnGuardMechanism 是一等模組——typed I/O、明確 start/success/failure 狀態、各狀態標為 operation 或 subgoal;轉移由因果守衛（如 safe(S_i)&&safe(S_i+1)）把關，守衛失敗則路由到 Failure。
  • 四階段管線（Algorithm 1，用 GPT-4o-mini）：
    1. 問題範圍分類：把學生問題與 TMK 的 Goal/Mechanism/Concept 頂層名稱做嵌入比對；超閾值則進 TMK 推理，否則交無約束的 RAG-GPT;
    2. 結構化知識檢索：取 top-k TMK 條目（父 Goal、Mechanism FSM、Concept 如 safe(config)），how 型問題優先 Mechanism;
    3. 受限合成：LLM 須 (i) 只敘述 Mechanism 守衛指定的轉移（因果）、(ii) 把每步連到父目標與成功狀態（目的）、(iii) 每狀態點名所呼叫的 operation/subgoal（分解）;
    4. 連貫性優化：壓成 5–7 句、保留關鍵守衛與目標達成標記。

評估

  • 設定：20 個程序技能問題（4 技能 × 5），4 系統（Standard GPT、RAG-GPT、Ivy+TMK-Basic、Ivy+TMK-Structured，全用 GPT-4o-mini）→ 80 輸出。三維度（causal/teleological/compositional）× 0–2 評分表；專家 + 獨立標註者，共 560 份評估。
  • 正確性：TMK-Basic 與 TMK-Structured 皆 0.65 完全正確 vs RAG-GPT 0.35、Standard GPT 0.15 → 結構約束降失敗率、提高事實正確上限。
  • 推理結構（僅正確答案的均值，0–2）：TMK-Structured 每維最高（causal 1.6 / teleological 1.333 / compositional 1.5）> TMK-Basic（1.5/1.167/1.3）> RAG-GPT（1.4/1.083/0.7）> Standard GPT（0.7/0.917/0.6）。
    • 最大差距在分解：TMK-Structured 1.5 vs Basic 1.3（+0.2）、RAG 0.7（+0.8）、GPT 0.6（+0.9）——正是 TMK 設計要鷹架的多步階層推理。
  • 新手/專家一致性：TMK-Structured 最高（teleology F1=0.843、decomposition F1=0.752、causality F1=0.765）→ 專家認為該有的結構，TMK 約束輸出能讓新手可靠辨認。
  • 教師對齊（專家評分 vs 其 DimensionExpected 期望）：TMK-Structured 領先（causal F1=0.909、teleology F1=0.917、decomposition F1=0.900）。

結論與局限

  • TMK 當主動鷹架（非僅檢索脈絡）→ 同時更可靠（正確性高、失敗少）與更具教學結構（專家均值高、新手辨認強），分解增益最大。
  • 局限：資料集小（每系統 20 題）、每技能僅一位專家評正確性（無評分者間信度）、評的是解釋品質非學習成效（遷移/學生表現超出範圍）。
  • 未來：用 human-in-the-loop 自動從教綱/逐字稿/範例建構 TMK-Structured、自動推導 DimensionExpected、用單元測試 + 反例引導精煉；真課重新部署研究學習成效。

對讀者的價值

  • 本批中最偏「AI 教育應用」的 NeSy，與 2407.101622501.14540 的「結構約束 LLM 生成」同脈，但這裡的符號結構是教學用的 TMK（FSM + 目標階層）、目的是教學對齊而非邏輯正確性。
  • 關鍵思想：把符號表示當「主動生成約束（active scaffold）」而非靜態脈絡（對比 RAG 的「相關文字」）——給 LLM「技能的操作語意」而非「相關文字」。與 grammar-constrained decoding（CRANE）等同精神，但用於程序技能教學。
  • 與 2502.01806（NsPC 把規則嵌回模型）都關心「可解釋 + 符號結構提升可靠性」，但本篇在生成端用 FSM 約束。
  • 最值得記：三維度評估框架（因果/目的/分解 × 0–2） 是評「解釋結構品質」的可操作 rubric;四階段受限生成管線是把符號 KB 接到 LLM 的具體配方。定位是部署系統 + 系統級評估（非學習成效、規模小）。
