論文／訪談原始來源

MLE-World：預測機器學習程式的執行回饋

核心問題

研究 agent 可以逐次產生程式並據訓練結果修正，但每個候選都真實訓練與評估會消耗時間。MLE-World 以 Qwen3.5-4B 微調模型，根據程式碼、套件版本、資料概覽和時限預測例外、終端輸出、validation metric 與提交旗標，用廉價預測協助探索；最終提交仍以真實 validation 選擇、隱藏測試評分。它模擬完整程式一次執行的回饋，而非重現訓練、保證結果或預測測試分數。（§1、§4、§6；保證界線為本檔補註）

模型、信心與搜尋

AIDE 以 Draft、Debug、Improve 在程式樹中探索；實際執行回報訓練紀錄、錯誤 trace 與驗證分數。世界模型輸入包含完整程式、執行環境、AIDE 的檔案樹／CSV 維度與欄位示例、時限；輸出依序是 82 類例外標籤（含 null）、預測 log、metric、submission flag。模型在 497,056 條歷史執行上全參數監督微調（視覺塔凍結），失敗案例亦保留。（§3–4、附錄 B）

首個輸出 token 的 82 類機率重新正規化後，最大機率 p_max 是對最可能例外類別的信心，1−p_max 為不確定性；p_clean 是 null 類機率。五分位資料顯示 p_max 越高，各欄位吻合率越高，但這不是經證明校準的全文正確機率或錯誤率保證。UCB 在預測正常、可提交且 metric 有限的候選池中加不確定性獎勵，作者稱之為經驗探索 proxy，非正式 confidence bound；greedy 解碼該池內 null 最可能，因此不確定性亦為 1−p_clean。（§4–5.1、§6.3）

五種策略用預測回饋探索：Best-of-N 按預測 metric 選、Sequential 使用前一預測結果修訂、Pairwise 用 LLM 比較候選及預測 log、Fusion 合成新程式、UCB 在分數上加探索項。選中後 confidence gate 對低於門檻或缺信心者真跑；新的最佳預測 validation 分數也必須真跑以取得可驗證提交。預測 timeout 不跑，故「只跑低信心」有重要例外；此策略可能錯過被誤判 timeout 的程式。（§5、附錄 M；最後為本檔補註）

同任務新程式的預測評估

主試驗選 MLE-bench Lite 22 題中的 17 題，排除 5 題難有進展者。1,700 個留出程式是每題 100 個、平衡 agent 階段與快慢執行；任務與微調共享。抽樣前排除偵測到 exact／near duplicate 的程式；MinHash／LSH 機率式搜尋仍可能漏掉相似程式或跨題語意重疊，因此不是新任務泛化測試。（§6、附錄 E）

回饋、校準與限制

固定狀態診斷先取 153 個狀態，Sequential／Fusion 三個未完成狀態從所有相關比較排除，表3 共 150；Fusion 用相同四候選，code-only 14.0 與預測 log 20.6 percentile，增加 6.55±2.87 points。Pairwise 和 Sequential 的預測 log 提升未確立，方法的 model calls 及額外合成不同；局部真實回饋未顯著更好不等同兩種回饋等效。（表3、附錄 P）

獨立八小時 BoN 對照中，隨機 gate 與 confidence gate 分別用 5.54／4.49 小時 real execution、均值 47.37／47.21 percentile，後者少約 19% 執行時間；每組 51 trials、seeds 不同，paired task 差 −0.15±2.32 points，未確立品質差異。這不保證每個策略、門檻或真實成本皆相同。（附錄 N）

作者另測三個微調排除任務各 100 程式，terminal judged match 53.3% 對 DeepSeek 42.1%；失敗案例占多數，尤其不足以證明成功訓練結果或 timeout 的泛化。主設定依賴約 50 萬既有執行紀錄，baseline agent 未測能否利用同樣 corpus；模型預測錯誤可能誤導搜尋、missed timeout 仍耗完整執行。正式部署或跨任務家族需獨立再驗。（§7、附錄 R）
