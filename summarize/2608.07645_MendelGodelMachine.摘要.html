論文／訪談原始來源

《Mendel Gödel Machine》重點摘要

一句話

MGM 認為自我改寫 coding agent 不應只從單次失敗學習，而要拿檔案庫中的跨任務表現與跨譜系對照當編輯證據。

核心方法

  • clonal mutation：一般做法，以一個 agent 在一項任務的軌跡改寫自己。
  • reaction-norm mutation：同時看同一 agent 在多項任務的軌跡。跨環境反覆出現的失敗較可能是 agent 的結構缺陷，而非單題偶然。
  • cross-lineage hybridization：對同一任務，拿另一譜系的 agent 與其軌跡作參照，讓改寫可受控地借入不同設計的優點。
  • 作者在加性 fitness landscape 假設下分析，並以代理模擬說明比較式突變較快、更好收斂；實作則維護版本譜系、軌跡與評估檔案。

證據與限制

論文報告在 SWE-bench 與 Polyglot 上，MGM 的效能、效率與泛化改善皆較單軌跡基線一致；但改善依賴 archive 中任務、軌跡和評估本身可信且可比較。理論結論只在加性適應度模型內成立，真實程式改寫的表徵交互作用未必符合它。

對讀者的價值

這篇把 agent archive 從「挑下一個 parent 的排行榜」改成「診斷改哪裡的資料集」。工程上需注意對照組、任務覆蓋與 lineage provenance；否則跨任務聚合會把不相容的失敗混成一條錯誤規則。
