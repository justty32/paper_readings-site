論文／訪談原始來源

《ArcMemo：抽象推理組合的終身 LLM 記憶》重點摘要

一句話概括

ArcMemo（Abstract Reasoning Composition Memory）主張：與其把「整題的查詢/回答對」存進記憶，不如把解題軌跡蒸餾成概念級的可重用、模組化、用自然語言寫的抽象（如 ARC 中拆出的單個變換原語），未來查詢時選擇性檢索相關概念注入 prompt，達成不更新權重的測試時持續學習；在 ARC-AGI-1 上把官方分數從 55.17 提到 59.33（相對 +7.5%），是唯一在「所有推理計算規模下都勝過無記憶基線」的記憶設計，且評測時動態更新記憶比固定記憶更好——形成一種自我提升。

解決什麼問題

人類解複合推理問題會「在先前洞見上累積、抽象模式、在新情境組合」。LLM 的外部記憶多是實例級（存原問題脈絡緊耦合的查詢/回答對或摘要），難跨題重用、且記憶一大就讓解題模型得自己從一堆過往經驗裡撈相關點子。如何讓記憶更通用、模組化、可組合？

核心方法

  • 概念級記憶：存「抽象（脫離原脈絡、對更大未來問題集有用）+ 模組化（直接促進與其他想法重組）」的概念，而非整條複合規則。例：把規則 A,B,C,D,E 各自獨立存成模組概念，而非把 A 與 B,C 耦合存死。
  • 兩種記憶格式：
    • OE（Open-Ended，開放式）：把解題軌跡反思成「情境→建議」式的自然語言 playbook，產生交錯的觀察+思考後驗推導；冗餘留給選擇與解題階段處理。
    • PS（Program-Synthesis 式）：先把解轉成偽代碼以突出高階操作（避免把低階實作細節錯記成概念），再從偽代碼抽概念，含參數列表、相關性提示（relevance cue）、型別註解、實作筆記，鼓勵重用/修訂既有概念以壓縮總長度。
  • 記憶寫入（Concept Abstraction）：寫入時帶壓縮版既有記憶於 context，鼓勵更新而非重複；全程以 few-shot 示範 + 範例豐富模板 scaffold。
  • 記憶讀取（Concept Selection）：只取最相關子集——OE 用「把抽象域輸入解析成不同抽象層級的問題描述」做匹配（把空間豐富輸入轉成自然語言）；PS 用 System-2 式推理導向選擇（概念附 relevance cue 與型別註解說明何時相關、如何拼接）。
  • 持續概念學習（Continual）：評測時動態更新記憶，前一輪 pass 觸發的記憶更新可能讓後一輪 pass 解出新題。

結果

  • ARC-AGI-1：官方分數 55.17 → 59.33（相對 +7.5% vs 強無記憶基線），且是唯一在所有推理計算規模下都勝過基線的記憶設計。
  • 抽象 vs 實例級：抽象概念是最一致的設計（實例級因與原脈絡耦合而難重用）。
  • 持續更新 > 固定：評測時持續更新記憶帶來隨推理規模（重試次數）湧現的分數提升——前一輪的記憶更新使後一輪解出新題，呈自我提升。
  • 選擇機制有效：為特定問題選記憶子集既提升表現又降 token 成本，顯示「選擇」操作本身就有價值（不只是為了讓記憶能持續長大）。

局限

  • 評測限於 ARC-AGI（雖是壓測組合泛化與抽象推理的天然 testbed，但仍單一基準）。
  • 概念抽象/選擇高度依賴底層 LLM 的反思與檢索品質，且需精心的 few-shot scaffold 與模板工程。
  • PS 格式需偽代碼前處理才能避免記成低階細節；OE 與 PS 在不同任務各有長短，需依域選格式。

對讀者的價值

  • 提供一條與「逐題 LoRA TTT」不同的測試時適應路線：用自然語言概念記憶 + 選擇性檢索，不動權重就持續學習——對 ARC 式抽象推理特別契合（簡單像素操作組合成廣大任務空間）。
  • 與本批對讀極有價值：2603.06590 / 2605.01154 是「測試時微調權重」、本篇是「測試時累積記憶」；2606.06252 ReLAT 是「測試時優化潛在狀態」；三者代表測試時適應的三條路（權重 / 記憶 / 潛在表示）。與 1911.01547（智能＝技能獲取效率）呼應「組合既有概念」的人類式解法。
  • 最值得記：「概念級（模組+抽象）記憶比實例級記憶更可重用」；「選擇性檢索」本身就帶來增益並省 token；以及「測試時持續更新記憶 ⇒ 跨重試的自我提升」這條不靠梯度的 self-improvement 路徑。
