論文／訪談原始來源

《SELFDOUBT：以 Hedge-to-Verify Ratio 做推理 LLM 的不確定性量化》重點摘要

一句話概括

SELFDOUBT：從推理軌跡直接提取行為信號（hedge 詞如"perhaps"/"maybe"，vs verify 詞如"check"/"verify"）的單次推理不確定性框架。核心信號 HVR（Hedge-to-Verify Ratio）= hedge 標記數 / （verify 標記數 + 1），零額外推論成本。HVR = 0 的軌跡正確率 96.1%（25.4% 覆蓋率），形成零成本高精度信心閘。完整 SELFDOUBT score（HVR + verbalized confidence 的 z-score 融合）在 AUROC 上顯著擊敗 10 倍成本的語義熵（p=0.001），AURAC 持平。兩階段部署級聯達成 71% 覆蓋率下 89.7% 準確度的選擇性預測。

解決什麼問題

推理 LLM 不確定性量化陷入兩難：採樣式方法（語義熵、語義體積、幾何不確定性）需 N 次前向傳播（10–20 倍推論成本），對推理模型尤其昂貴；單次替代方案各有取捨——口語化信心在困難任務失校準、軌跡長度僅在中難度任務有效、探針方法需隱藏狀態、logit 方法需 token 機率而商用推理 API 不揭露。核心挑戰：商用 API 無 logits/無中間機率、無法多次採樣——亟需純文字、單次、無訓練的不確定性信號。

核心方法

  • 兩階段標記詞典建構（離線，每模型一次，90 條無標註軌跡）：Stage 1——多 LLM 共識投票生成 hedge/verify 種子詞，經 bge-m3 嵌入迭代語意連貫性過濾，保留 top-10 排名種子；Stage 2——從無標註軌跡提取 1–3-gram，依 cosine 距離對 hedge/verify centroid 的 margin Δ(g) 分類，建構模型特定的 hedge 詞典 H 與 verify 詞典 V。
  • HVR（Hedge-to-Verify Ratio）：HVR(T) = h(T) / (v(T) + 1)，以 word-boundary regex 對 H/V 匹配計數。分母 +1 避免無 verify 標記時除以零。HVR 越大表示不確定性越高。HVR = 0 為零膨脹分佈——無 hedge 標記的軌跡自動落於零。
  • Verbalized Confidence：提示模型輸出"Confidence: [0-100]%"，解析為 V ∈ [0,1]。
  • SELFDOUBT Score（§3.4 品質分數）：s_SD(T) = z_r(-HVR(T)) + z_r(V)，z-score 標準化使兩通道可通約，融合互補失敗模式——HVR 捕捉推理行為中的不確定性、口語化信心捕捉模型自我報告的不確定性。
  • 部署級聯（§3.3 cheap gate）：Tier 1（HVR = 0 gate，零成本 regex）→ 直接接受；Tier 2（校準 z-sum，τ=0 自然對稱預設）→ 接受 s ≥ τ 者、其餘推遲。僅需每模型 4 個標量（μ_hvr, σ_hvr, μ_v, σ_v）。

  • HVR = 0 gate：21 輪合併 96.1% 精確度（1330/1384），經標註雜訊校正後 99.4%（Wilson 95% CI: [98.9%, 99.7%]）。54 件原始不一致經手動審計後僅 8 件為真正模型錯誤（0.58%）。
  • vs 語義熵：SELFDOUBT AUROC 顯著優於 SE（p=0.001），AURAC 無顯著差異（p=0.069），以十分之一推論成本達成同等選擇性預測品質。
  • 模型規模依賴：GPT-4B → 120B，SELFDOUBT 呈最清晰的單調趨勢；Gemini 2.5 Flash 為唯一異常值——壓縮思維摘要僅產出 0.9% 零 hedge 軌跡，HVR 近乎常數。
  • 跨軌跡格式一致性：原始推理軌跡模式下 SELFDOUBT 顯著擊敗 TL+VB（AUROC p=0.026, AURAC p=0.039）；思維摘要模式下具競爭力但未達顯著。
  • 部署級聯：Tier 1 接受 25.2% 查詢（96.3% 精確度）;Tier 1+2（τ=0）達成 70.7% 覆蓋率 89.7% 精確度，較無推遲基線提升 9.2 百分點。校準損失僅 0.48 pp AURAC（oracle → 90-trace calibration）。

局限

  • HVR = 0 覆蓋率高度依賴模型（Gemini 0.9% → Claude 53.3%），稀疏 trace 模型受益有限。
  • HVR 定義於表面形式 hedge/verify 詞彙，對抑制 hedge 語言或非實質性檢查的提示/風格偏移未測試。
  • 不分解不確定性來源（epistemic vs aleatoric），僅產出單一排序分數。
  • 僅多選題格式驗證，未測試自由文字生成（開放式 QA、程式碼生成、逐步評分數學）。

對讀者的價值

  • 「品質分數」主題（§3.4）的直接方法：SELFDOUBT score 的 z-score 融合設計示範了如何將行為不確定性信號與自我報告信心結合成單一排序分數——無需訓練、無需內部機率、僅需 regex + 算術。
  • 「cheap gate」主題（§3.3）的示範案例：HVR = 0 gate 是零成本高精度接受規則——僅需 regex 匹配、無需分數計算——不確定性越低越準確的信號在推理軌跡中具高度通用性。
