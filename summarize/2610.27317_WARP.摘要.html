論文／訪談原始來源

WARP 重點摘要

一句話概括

WARP 將「找出 PDE 係數」放進真正部署的頻譜 Galerkin 求解器：從觀測狀態重新起跑多步積分，對預測軌跡誤差反向微分，讓學到的係數必須在自己的狀態上持續運作。它同時輸出可解釋 PDE 係數與自主求解器，但主要實驗已知正確方程項，並非從任意大候選庫自動發現未知方程，也沒有全域穩定性保證。

貢獻與已有方法的邊界

弱形式將空間導數移到已知測試函數，降低直接微分噪音的困難；單步導數殘差小，卻不保證積分後仍有正確耗散、能量或吸引子。WARP 結合弱空間投影與 solver-in-the-loop 係數訓練，讓每次訓練及部署使用相同有限維動力系統。（§1）

作者明確承認：以觀測為錨點的多步 rollout、學習可部署求解器、弱形式結合 rollout，本身已有直接前例，包括 rollout operator inference、RK／Unrolled-SINDy 與可微流體 closure。本文特點是將未知量限制為有名稱的物理空間微分算子之共享係數，以同組正交 Fourier 函數表示狀態及測試 PDE；並在完全相同 modal library 上控制比較導數擬合與多步訓練。右側沒有神經網路，不是學任意 reduced polynomial operator arrays。（§2）

從 PDE 到實際學習的 modal ODE

週期域上的候選方程為

\[\partial_tu=\sum_{\ell=1}^{P}\xi_\ell\mathcal D_\ell(u).\]

以實正交 Fourier 基底保留各軸 \(|m_j|\le M\)，每場 \(K=(2M+1)^s\) 個基底，總狀態維度 \(d=N_fK\)。對同組基底取弱形式、分部積分後，得到

\[\dot q_i=F_i(q;\xi)=\sum_\ell\xi_\ell A_{i\ell}(q).\]

所有保留模態共享物理算子係數；不同場方程的係數除非候選庫明確綁定，仍分開學。基底導數解析計算，非線性乘積用 \(2/3\) dealiasing，再投影回保留頻帶。保留頻帶不必對非線性乘法封閉。（§3.1–3.2）

band-closed 不等於已解析所有物理尺度：大多數合成資料直接由同一有限維 Galerkin 系統生成，沒有獨立演化的捨棄模態回饋；獨立高解析 DNS 投影則仍受到未保留尺度影響，不屬 band-closed。（§3.1）

FD 控制組與 WARP 訓練

FD 與 WARP 共用基底、modal 觀測及 \(A(q)\)。FD 在觀測狀態計算候選庫，用中央時間差分作應變數，以最小平方估係數。主要實驗已提供恰好正確的算子支撐集，估全部係數、不做稀疏選項；兩者差異是單步導數擬合與多步積分目標，不能據此分離弱空間投影本身的效益。（§3.3、3.6、§5）

WARP 每次由帶噪觀測 \(q_{\rm data}(t_j)\) 錨定初始狀態，以候選係數積分到非零時間偏移 \(i\)，最小化

\[\mathcal L(\xi)=\frac1Z\sum_{j\in\mathcal B}\sum_{i\in\mathcal I}w_i\|\hat q_{j,i}(\xi)-q_{\rm data}(t_{j+i})\|_2^2,\]

其中 \(Z\) 是選定目標觀測的平方範數總和，選好軌跡、錨點及偏移後固定。求解器每個 stage 都在自己預測的狀態重算 \(A(q)\)，不是一路餵入真值。依基準採雙向、僅向前或較短反向 horizon；HW 為向前50、向後5個快照間隔，MHD 為向前200。MHD 的場振幅不同，殘差再用每場 inverse-rms 權重。（§3.7、表 1）

訓練用 JAX odeint 的自適應 Dormand–Prince、adjoint sensitivity 取係數梯度，從 FD 初值以 L-BFGS 最佳化；非有限 rollout 給固定 \(10^6\) loss。主要正確候選庫不加正則；通常 full-batch、至多500次迭代、梯度容忍值 \(10^{-10}\)。部署後只需係數及初始狀態，不再供應未來觀測。避免時間差分不代表無偏：帶噪錨點、目標與候選庫仍有 errors-in-variables 偏差。（§3.7、§4.1、§2）

實驗口徑與 held-out 評估

八個系統有九種配置，因 HW 另做獨立 DNS 投影。每次擬合只用一條觀測訓練軌跡；三種 seed 42／123／456 改變的是同軌跡的獨立加性 Gaussian 觀測噪音，不是三條不同乾淨訓練軌跡。每場噪音標準差為該場乾淨軌跡標準差的 \(\eta\) 倍，圖中選用 \(\eta\in\{0,0.01,0.02,0.05,0.10,0.20\}\) 的子集。係數誤差 \(E_\xi=\|\xi-\xi^*\|_2\)，通常報三噪音 seed 平均與一標準差。（§3.4、3.8、§4.1）

確定性前四基準以五個新的乾淨初始狀態測試，同一狀態分別交真方程與學得方程，不含初始觀測噪音；通常低頻振幅擾動 \(\pm40\%\) 並改相位。湍流則測五個未用於訓練的初始狀態，spin-up 後比較能量、通量與頻譜，避免以必然失去逐點相關的軌跡誤差判斷吸引子品質。Kolmogorov／HW／mHW 分別丟棄500／150／\(40\gamma_{\max}^{-1}\)，再平均200／150／\(80\gamma_{\max}^{-1}\) 時間。真係數從相同初始狀態積分，提供有限取樣散布基準。（§3.8）

逐點湍流圖多從訓練窗的帶噪首幀起跑；真係數同樣從該帶噪首幀重啟的灰線，隔離初始擾動的混沌放大。不能把 WARP 與這條灰線接近解讀成永遠精確預測乾淨軌跡。（§4.6–4.7）

作者自報結果與例外

系統／配置 主要結果及界線
Burgers 高噪音係數優勢約一個數量級；但低噪音 \(0.01\le\eta\le0.05\) 時 FD 新初始狀態預測較好，與 WARP 黏性低估有關。
KdV 係數誤差改善1–2個數量級；非零噪音的新初始狀態 rollout 誤差改善1–3個數量級。這是觀測趨勢，不是一般尺度定律。
二維 ZK 噪音提高時係數優勢增至約一個數量級，乾淨共同初始狀態下積分預測也改善。
衰減二維 Navier–Stokes 係數優勢約1至近2個數量級；最高噪音 FD 對流係數低估約一半，WARP 在1%內。
Kolmogorov 湍流 WARP 在新初始狀態統計上至 \(\eta=0.1\) 仍落在真模型散布內，FD 能量及耗散漂移。零噪音 FD 仍受取樣時間差分截斷偏差。
band-closed HW \(c_1=1\) 噪音下係數改善1–2個數量級；最高噪音 WARP 能量誤差可能大於 FD，通量與頻譜仍較好。
未封閉 HW DNS 投影 \(512^2\) 獨立資料投影至 \(M=12,16,21\)，WARP 係數誤差皆小於 FD；零噪音偏移隨頻帶擴大降低，仍不等於恢復精確閉合方程。
mHW \(10\%\) 噪音係數改善約1–2個數量級；但低係數誤差不保證各統計更好，近轉移閾值的偏移可改變 regime，渦流區通量及能量也可能不及 FD。
Orszag–Tang MHD 保住對流與 Lorentz 係數，低噪音事件誤差僅數%；\(20\%\) 噪音升至量級一，電流片事件已無法解析。

來源：§4.2–4.10、B.2。各基準的離散化、樣本間距、訓練窗及 horizon 不同，不能把改善倍數直接當通用縮放規律。

MHD 以耗散峰時間及整段最大電流作事件指標，兩者不一定同時發生。通常五個新狀態用 \(\pm10\%\) 振幅擾動保留同類電流片事件，另以 \(\pm40\%\) 振幅及新相位作壓力測試；事件圖用 seed42 擬合。主 \(M=21\) 生成器峰電流比 \(128^2\) 參考低4%，屬頻帶解析度限制。FD 在最高噪音看似較小的電流誤差，是事件已丟失後的退化現象，非預測正確。（§4.10）

DNS、候選庫與長期穩定性

獨立 HW DNS 使用有限差分、Arakawa bracket 等不同離散化；被捨棄尺度仍交換能量，既有算子庫未含 subgrid closure。零噪音係數誤差稱 closure-induced offset，也含離散化差異，不是已證明的估計誤差下界；係數可能吸收未解析尺度，不應全部當原連續 PDE 的物理真值。（§4.8）

附錄 F 對 Kolmogorov 擴成33欄、無稀疏懲罰的候選庫，含5欄真項，所有欄先投影為零均值。WARP 在各噪音恢復真係數至數%內，偽項約比 FD 小一個數量級，但10%噪音時最大的偽項已與黏性係數一樣大；不能說完全選掉錯項。兩者10%模型從新狀態部署都保持有界，WARP 重現能量預算，FD 動力學太慢且吸引子錯誤；有界只是這些擬合結果的觀察，非任意候選係數的保證。（附錄 F）

附錄 E 將10%噪音模型部署時間延長為原 held-out 的兩倍，測 MHD、HW、Kolmogorov。WARP 均穩定且接近參考，但 MHD 因耗散高估而衰減過快；FD 三者也都數值有界，可能出現錯誤能量增長或落到錯吸引子，並非一律爆炸。因此 rollout loss 在實驗上排除許多不良係數，沒有證明一般穩定性。（附錄 E）

作者明示限制

主要設定是週期域、平滑場、已知正確算子項；更大或錯置候選庫需額外稀疏／穩定選擇，非週期邊界需適當基底，實驗噪音、缺失場與 shock 尚未測試。mHW 截斷模型僅再現定性轉移，轉移位置仍有量化偏移；DNS 未學 closure，MHD 峰值受有限頻帶限制。沒有同資料的 strong-form 控制組，不能單獨宣稱弱投影防止 blow-up。作者提出局部有限元素基底、項目選擇與更大 modal 系統的 FFT 實作作後續方向。（§5–6）
