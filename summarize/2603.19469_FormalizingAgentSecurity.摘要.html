論文／訪談原始來源

《形式化 LLM Agent 安全的框架》重點摘要

一句話概括

安全不是 action 的內在屬性，而是 action 與 execution context 的關係；本文以 task alignment、action alignment、source authorization、data isolation 四個 properties，加上五個理想 oracle，將 prompt injection、task drift、confused deputy、capability misuse、memory poisoning 等 87 篇文獻中的攻擊映射成 contextual authorization violations。

形式框架

Time-step context 包含 user prompt、目前 trajectory、persistent memory、environment state、authenticated sources 與 source permission graph。五個 oracle 回答：prompt 允許什麼 objective、trajectory／action 是否服務該 objective、哪些 inputs 實際導致 action、這些 inputs 從哪些 sources 來。

四個 properties：

  1. Task alignment：初始 objective 在允許集合內，整條 trajectory 沒漂移到別的目標。
  2. Action alignment：每一個 action 都服務授權 objective；整體仍在做菜，不代表偷開麥克風是必要動作。
  3. Source authorization：造成 action 的 instruction 來自 authenticated／delegated source。
  4. Data isolation：tool arguments 的資訊來源到 destination 的 flow 在 permission graph 中獲准。

它們必須聯合判斷。例如外部 recipe 的「350°F 烘烤」雖來自未 authenticated source，若使用者授權「照此 recipe」且 action aligned，可合法；外部文字指定付款方法則可能在 task/action aligned 時仍違反 source authorization。

攻擊／防禦重整

Indirect prompt injection 被定義為未授權 source 造成且不服務 user objective 的 action；direct injection 主要違反較高權限 objective 的 task alignment。Jailbreak、task drift、capability misuse、cross-context leakage、malicious tool、memory poisoning 各映射到不同 properties。

防禦則分成改善 oracle approximation，或直接做 property checks。Prompt delimiter、training、policy、sandbox、tool filter、runtime monitor 都只覆蓋部分需求。作者引用 AgentDojo：PI detector／tool filter 相對無防禦將 targeted ASR 降 86%／88%，delimiter／repeat prompt 至多 28%；但 PI detector 同時使 benign utility 69.0%→41.5%。這是既有研究數據，不是本文新實驗。

限制與成熟度

  • 五個 oracle 是 ideal specification，不是可運行演算法；instruction causal attribution、semantic objective judgment 與 neural information flow 都未解。
  • 框架只處理同步單 agent、單 authenticated user；未形式化多 agent delegation、multi-principal authority composition。
  • 聚焦 confidentiality／integrity，不處理 availability／resource exhaustion，也假設 authentication／access control 已存在。
  • 沒完整處理 individually benign actions 合成的危險、dynamic actors 與 TOCTOU。
  • 四 properties 是對 87 篇既有 attacks 的 systematization，作者明說不能證明 sufficiency／axiomatic completeness。
  • 本文沒有新實驗、資料或軟體；證據是概念一致性與文獻映射。

證據成熟度：高價值的 conceptual specification；低度的實作與 empirical validation。

對 FreePy 的價值

四 properties 可直接成為 Decision／Verifier 的分層 contract；尤其 source permission graph 能對應 capability graph，trajectory／action alignment 對應 Goal postcondition 與 Step admission。但 FreePy 必須把 oracle 分成 mechanical、probabilistic、authoritative evidence，不能假定理想 oracle 存在；多 agent delegation 與 TOCTOU 正是它可補足的研究缺口。
