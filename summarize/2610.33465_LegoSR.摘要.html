論文／訪談原始來源

LegoSR: A Unified Framework for Self-improving Agent-Guided Scientific Discovery 重點摘要

一句話概括

LegoSR 統一七種符號迴歸與微分方程發現工具的資料、方程表示及評估，讓 LLM agent 根據求解器知識與實驗紀錄調整搜尋。作者在合成或數值產生的基準上報告，加入這些指引的 agent 在雜訊微分方程任務優於同工具與預算的通用 agent，並接近多求解器聯集。

平台與 agent

平台整合 PySINDy、DLGA-PDE、SGA-PDE、PySR、DISCOVER、LLM4ED 與 EqGPT，保留各自的原生搜尋方式，再將候選轉換成共用 Equation IR。共享模組處理導數估計、係數擬合及評估，記錄設定、候選和軌跡，支援恢復或從既有實驗分支；共同評估會重新擬合候選係數、計算正規化殘差，適用時再向前積分比較動態。（§2.1～2.2）

Sketch 是部分已知的方程：可固定某一項及係數、只錨定項而擬合係數，或保留受限的未知孔洞。例如已知 Burgers 方程的對流項時，可保留 u_t = −u u_x + R，讓求解器找 R。共同介面讓不同求解器使用同樣先驗，並不保證先驗正確。（§2.2）

Agent 以 LLM 控制器讀取求解器卡片、資料診斷及經驗，決定導數估計、求解器及參數、Sketch 與候選檢驗。單次任務的 discovery tree 保存候選、結果及決策理由；跨任務的 experience library 由提交結果在探索迴圈外與參考方程比對、評分後整理經驗。後續任務可檢索其他方程家族的經驗，作者稱之為自我改進；這是改變可檢索指引，並未報告更新 LLM 權重或證明能力必然單調增長。探索時參考方程不可見。（§3.1～3.2）

評估與比較

作者測試 134 個代數符號迴歸問題、19 個系統的 40 個 ODE 目標及 17 個 PDE 問題；對訓練資料加 0%、1%、5% 的獨立高斯噪聲，測試資料保持無噪聲。代數題對目標值加噪，ODE／PDE 則在導數估計之前對軌跡／場加噪。（§4.1.1～4.1.2）

覆蓋率定義為每題多次運行中至少一次達到各任務復原標準。代數題採 SRBench 的符號條件，允許與真式相差常數或相差非零常數倍，並要求測試 R² > 0.5；ODE 可用符號匹配或指定數值容忍條件；PDE 要求正確項集合且所有係數相對誤差不超過 5%，提交係數在評分時不再重新擬合。三類標準不同，不宜將覆蓋率直接當成完全一致的逐係數精確率。（§4.1.2）

兩種 agent 使用相同 DeepSeek-V4.1-Flash-1017、工具和資源上限，每題各獨立跑三次；通用 agent 沒有求解器卡、工作流程指引及經驗庫。UNION 是七個專家調整求解器各跑三個 seed 的成功題聯集，即每題 21 次執行，不是單一求解器或與 agent 相同執行數的對照。所有方法使用同一題的同一份帶噪資料。（§4.1.3）

兩個案例

KdV 的 1% 噪聲案例，agent 先經 PySINDy、SGA-PDE，後者找到正確兩項但係數偏低；使用神經 surrogate 估計導數的 DLGA-PDE 最終取得 u_t = −0.9947 u u_x − 0.002488 u_xxx，對照真式係數 −1 與 −0.0025，前向積分相對 L² 誤差由中間式的 28.9% 降至 1.8%。通用 agent 的最佳式積分誤差為 23.8%。這是具體案例軌跡，而非所有 KdV 資料都能取得的保證。（§5.2）

Chafee–Infante 的 10% 噪聲案例，agent 從先前失敗搜尋留下的 surrogate 整理項、以 Sketch 留孔並測試刪項，再以弱形式回歸擬合係數；作者報告最大係數誤差由 19% 降至 2.3%。25% 噪聲時，研究者直接提供兩個已知項的 Sketch，弱形式擬合另修正三次項噪聲偏差，最大係數誤差由 31% 降至 3.8%。後者包含人工先驗，不是全自動從零發現。（§5.3）

限制

作者將擴展到真實實驗資料、其他求解器與更廣泛的經驗重用列為未來工作。現有基準以已知參考方程評分，不能直接證明面對未知機制、量測偏差或錯誤先驗時仍能找出物理真相。跨任務經驗建立時使用評分結果；雖然同方程家族經驗在測試時被排除，這並不等同完全沒有跨題知識或評分回饋。（§3.2、§7）
