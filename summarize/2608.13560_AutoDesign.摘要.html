AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design 重點摘要

一句話

AutoDesign 把「論文轉海報」這類多模態長程設計任務框成 meta-harness 優化：內層 design harness（designer＋critic 反覆生成修訂）不變，外層 meta-harness 用 rollout–evaluation–update proposal–acceptance gate 四階段，每輪只准動一個 harness 元件，且更新要同時在 train 集進步、dev 集不退步才被接受，藉此避免過擬合單一任務集。

方法

Design harness 拆成 Context/Memory、Tools/Specifications、Execution Runtime、Orchestration、Evaluation/Feedback 五個功能元件；meta-harness optimizer 由一個 coding agent 扮演 planner（分析軌跡與分數、派子代理檢查、彙整成失敗模式與更新計畫）與 code editor（實作變更）兩角色，每輪只准修改五元件之一，讓效果可歸因到單一介入。Acceptance gate 要求候選更新同時滿足 J_train 進步且 J_dev 不退步才晉升，dev 集分數只用於守門，從不餵給 optimizer，避免 harness 對訓練任務過擬合。可選 human-in-the-loop：人可對 planner 給自然語言方向性指引，或在發現 evaluator 系統性偏誤時介入修正 evaluator（evaluator 本身在自動優化期間固定不動）。

作者報告的實驗與資料限制

作者建了 PosterBench（100 篇論文、5 個學門、7 維 rubric：Faithfulness／Coverage／Density／Visual Evidence／Layout／Readability／Aesthetics，加權加總後再套多個嚴重度上限 ceiling）評測論文轉海報系統。作者報告：AutoDesign（DesignHarness＋Claude Code＋Claude 4.8）拿到 78.32 分，同組態下勝過商用系統 Claude Design 的 70.87（+7.45）與 OpenDesign 的 69.45（+8.87）；在七組不同 coding agent／模型配置上固定模型只加裝 DesignHarness，PosterBench 平均分從 54.99 升到 67.39（+12.4%），個別配置增益 5.01～19.56 分不等，最大增益是 DeepSeek V4 Pro＋Claude Code 的 +19.56。成本—表現 Pareto 前沿顯示 Doubao Seed 2.1 Pro 以 GPT-5.5 兩成七的成本拿到其 88% 分數。系統盲測人類評測（11 位志願審稿人、936 次配對判斷）中 AutoDesign 的 Bradley–Terry 勝率估計最高，64.0%（95% 區間 55.2–77.8%），且 PosterBench 分數差距越大（≥20 分）人類與 benchmark 判斷一致率越高（51.9%→74.4%）。全自動長程迴圈跑一份海報耗時約 40 分鐘、253 次工具呼叫、11 輪編輯、成本低於 $3；7 天演化累積 224 個子代理、至少 123 次遞迴迭代、54 次被接受的 harness 更新。以上均為作者自報數字。作者明講的侷限：PosterBench 只正式評測論文轉海報，投影片／網頁／會議影片輸出仍是 pilot、未經正式評測器驗證；outer loop 每輪只維護單一 active harness，不做多變體樹搜尋；evaluator 若要能自適應演化，需要凍結參照任務、對抗探針與定期人審錨定，否則優化可能 reward-hack 一個會移動的評測目標。

對 ai_core 專案的價值／接點

這篇對自我改進迴圈最直接的貢獻是「acceptance gate」設計：train 進步且 dev 不退步才接受更新，且 dev 分數從不洩漏給 optimizer——這是防止 harness／skill 級別自我改進退化成過擬合單一任務批次的具體機制，比單純「有進步就採用」更穩健，值得 ai_core 固化引擎在決定是否寫入新技能/prompt 更新時直接借用。「每輪只准動一個元件」的限制也直接對應固化引擎的可歸因性問題（HELIX 論文裡因同時改多元件而無法做單一 atom 歸因的限制，這篇正好給出解法）。對驗證器設計的警示：作者明確指出 evaluator 若要跟著系統一起演化，必須用凍結參照任務、對抗探針與人審維持錨定，否則會被 reward-hack——這對 ai_core 若打算讓驗證器本身也自我改進，是必須內建的防線。成本-表現 Pareto 資料則具體示範了「用 harness 補足弱模型」的成本梯度：便宜模型加對的 harness 可以逼近貴模型原生表現的九成，是低成本自我改進路線的量化參照。
