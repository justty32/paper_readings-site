論文／訪談原始來源

《符號迴歸的當前挑戰：最佳化、選擇、模型簡化與基準測試》重點摘要

一句話概括

一本博士論文（Aldeia，指導者是 SR 名家 de França 與 La Cava）：不提全新 SR 方法，而是改進影響預測準確度與模型複雜度的關鍵子程序，分四支柱攻克 SR（基於遺傳程式設計 GP）的長年挑戰——參數最佳化、親代選擇、模型簡化、基準測試——並全部實作進多目標演化 SR 函式庫 Brush，在真實/合成問題上達準確度-簡單度的 Pareto 最優。

四大貢獻

1. 參數最佳化（線性 + 非線性）

  • 把非線性參數加進 Interaction-Transformation（IT）表示、實作於 ITEA；評估四種「線性+非線性」組合啟發式。非線性用 Levenberg-Marquardt（LM）、線性用 OLS（普通最小平方）。
  • LM+OLS 組合預測最佳（代價是表達式較大）;限制 interaction 變數數 → 提升可解釋且不損準確。
  • 要點：有線性分解時永遠用 OLS（閉式解）；混合情況用「局部 LM + 全域 OLS」（LM 只作用於樹的孤立部分）;盡量避免 ERC（隨機常數）（降彈性與可解釋）。純非線性最佳化會過參數化、計算貴。

2. 親代選擇（ε-lexicase 的變異數法）

  • 提出 Minimum Variance Threshold（MVT） 當 ε-lexicase 的閾值準則（靈感來自決策樹切分），實作於 FEAT（原用 MAD 中位數絕對偏差的半動態閾值）。
  • 與原 FEAT 相當、在合成資料集（SRBench）上明顯改善；真實任務表現保留但需更多評估。MVT 能看到「近精英」之外的個體（MAD 只優先近精英）→ 改善但成本較高。
  • 要點：ε-lexicase 應用動態/半動態閾值；即使沒 MVT，ε-lexicase 仍勝其他選擇法；親代選擇雖間接但對模型品質影響大。

3. 模型簡化（LSH 不精確簡化）

  • 提出不精確簡化（inexact simplification）：用**記憶化（memoization）+ 局部敏感雜湊（LSH，SimHash）**近似語意、辨識等價子樹 → **自動學「純資料驅動的替換規則」**降複雜度，開銷小。
  • 比不簡化中位數降誤差，可整合進任何 SR 框架。要點：至少對最終模型總是要簡化（提升可解釋與泛化）；不精確簡化輕量、常有益、無益時也不傷；資料驅動簡化能揭示問題特定等價；簡化減 bloat 同時保持或提升準確。
  • 局限：不精確規則會微改函數行為（精確科學發現場景不宜）。

4. 基準測試（SRBench 重評）

  • 對大規模 SR benchmark SRBench 提改進協定並重跑，評估當前 SR 全景、把本論文貢獻定位其中。
  • 發現：參數最佳化是最佳演算法的共同點（多為 GP-based）;GP-based SR 即使在 transformer 趨勢下仍有競爭力；超參調校難 → 需 parameterless（免調參）體驗;SR 提升準確但常過擬合噪聲——產出小而準的模型卻抓不到底層真方程（真科學發現仍需進步）;no free lunch（無演算法一致稱霸）。

Brush 框架（貢獻載體）

所有貢獻實作進 Brush（高效 C++ template + Python bindings 的多目標演化 SR 函式庫，含 island model）。應用於醫療（治療抗性高血壓的可計算表型、臨床評分建模）；支援鎖定表達式部分做部分擬合 → 跨醫療站點模型遷移。

對讀者的價值

  • 本批 C 類（SR）中**最系統、最「實作導向」**的一本——是 SR 演算法工程的四支柱地圖（最佳化/選擇/簡化/benchmark），對應 2512.15920（特刊總綱）提到的方法學考量的深入版。
  • 最值得記的可操作要點：(1) 有線性分解就用 OLS 閉式解 + 局部 LM、(2) ε-lexicase 用動態閾值（MVT 看更廣）、(3) 最終模型總要簡化、LSH 不精確簡化輕量有效、(4) 參數最佳化是高效 SR 的共同關鍵、GP 仍勝 transformer、SR 會過擬合噪聲抓不到真方程。
  • 與後續 C 類各篇的接點：equality graphs/saturation（2511.05849 EGG-SR）、benchmark（2508.14481 快速 SR benchmark）、MCTS（2509.15929）等都在此論文的「未來工作」或 related 中提及。
  • 與本批 NeSy 主軸接點：SR/GP 是可解釋符號模型的演化式發現，與「可解釋 AI」（2505.14510 BACON）同目標但走演化路線。
  • 定位：博士論文（綜述背景 + 四章原創 + benchmark），無單一驚人結果但工程細節扎實；適合做 SR/GP 演算法、參數最佳化、lexicase 選擇、表達式簡化、SR benchmark 的人當參考手冊。
