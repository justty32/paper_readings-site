論文／訪談原始來源

SymbolicLM: Training Language Models as Symbolic Regressors 重點摘要

一句話概括

SymbolicLM 用合成的數值觀測、符號公式與物理量綱資訊後訓練語言模型，再以數值回饋修訂候選公式。作者報告在自建和外部基準的成績，但原文把同一準確率指標同時描述為數值容忍度與精確符號還原，解讀時須保留這個歧義。

問題與方法

符號迴歸的輸入是觀測點 (x_i, y_i)，目標是找出能解釋資料的解析式。作者認為，通用語言模型往往需依賴外部搜尋與數值最佳化，純數值殘差也難直接指出結構錯在哪裡；本文同時訓練模型與設計推論期修訂流程。（§1～2）

  • 合成資料 PhysSymbArena：作者報告約 16 萬條公式、18 億 token。公式以隨機運算樹產生，對輸入取樣並計算輸出，再從 SymPy 的 127 種物理量中為變數與輸出指派同領域的語意和量綱。運算樹自底向上檢查 SI 量綱，不合規的指派會捨棄重取。這些是符合量綱規則的合成描述，不能直接視為實測物理定律。（§3、附錄 A.5）
  • 監督微調：將數值觀測與物理描述放入提示，模型輸出前序表示的公式，使用 token 交叉熵訓練。這階段把數值到符號表達式的映射直接放進模型。（§4.1～4.2）
  • 強化微調：以 GRPO 從每個提示取樣一組候選，在組內正規化回饋。可解析與量綱一致是門檻，未通過則總獎勵歸零；通過後再加權符號結構相似、骨架等同與數值擬合三項。結構相似度比較運算子、函式、變數、常數數量、序列及複雜度；骨架比較將係數以共同佔位符處理，因此不等同於所有常數皆正確。數值項使用截為非負的 R²。（§4.3）
  • 推論期 SymbolicSGA：這仍是外部修訂流程。它用資料上的數值適配度排序，保留前五個候選；利用分支提示對最佳式修改變數或子項，或產生不同於較差候選的新式並重用高分子式。作者改用任務提示控制探索／利用，而非原 SGA 的溫度分支。（§4.4）

作者自報結果

原文的 Acc_τ 在 §5.1 定義為測試點最大相對誤差是否落在容忍度 τ 內的指標；表中也報 R² 與 NMSE。以下保留表格標籤，不能直接把 Acc_τ 宣稱為符號精確匹配率。（§5.1、式 2）

Qwen3-8B 0.0179 0.9821 0.0119
SymbolicLM，SFT 0.7581 0.2496 0.4375
SymbolicLM，SFT + RL 0.7626 0.2451 0.4648
SymbolicLM + SymbolicSGA 0.9056 0.1061 0.5508
PySR 0.8652 0.1348 0.5059

表 2 所列完整方法的 Acc_τ 比 SFT 高 0.1133，即 11.33 個百分點；推論期修訂與 SFT、RL 是不同階段，不能將整體增益全部歸給模型內部能力。此表中的完整方法 R²、NMSE 也須按原表保留，勿自行假定兩者相加恆等於 1。（§5.2、表 2）

外部基準表 3 中，SymbolicLM + SymbolicSGA 在 SRBench-Feynman 的 R² / NMSE / Acc_τ 為 0.9569 / 0.0430 / 0.6470；PySR 為 0.9548 / 0.0451 / 0.6386，SNIP 的 R² 為 0.9683。在 LLM-SRBench-Transform，完整方法的三項值為 0.9481 / 0.0519 / 0.4144，PySR 為 0.9390 / 0.0610 / 0.3423。這些是作者報告的特定基準結果，並非所有指標皆勝所有基線。（§5.3、表 3）

附錄物理資訊消融報告，加入物理描述前後 R² 為 0.7678 → 0.7582，ACC 為 0.4297 → 0.4375；依原表方向，數值擬合沒有同步改善。附錄另比較同模型與資料條件下的 SGA 和 SymbolicSGA；其 ACC 為 0.6218 → 0.6471，但附錄用 ACC 而主文表 3 用 Acc_τ，且同名完整方法在表 3 的值為 0.6470，報告未解釋這個小差異。（附錄 A.3～A.4、表 1～2）

解讀邊界

  • 指標不一致：作者在 §5.2 將表 2 的 Acc_τ 稱作精確符號還原，但 §5.1 的數學定義是數值容忍度。緒論另稱 SRBench-Feynman 的精確骨架準確率為 57.98%，表 3 完整方法的 Acc_τ 卻為 0.6470；原文未交代兩者關係。本摘要不把它們當作同一數字。（§1、§5.1～5.3）
  • 可重現資訊有限：主文與附錄說明資料生成與方法，但未清楚交代訓練／測試切分細節、容忍度 τ 的具體值及完整模型訓練設定。作者的重現聲明稱已提供充分細節；本檔觀察與該聲明分開。（§5.1、重現聲明）
  • 本檔補註，非作者自陳：量綱一致是必要的物理檢查之一，無法單獨證明公式反映真實機制。合成資料和有限外部基準成績也不能直接證明對有噪聲的實測資料、未知物理領域或任意計算預算均有效。
