論文／訪談原始來源

《RENEW》重點摘要

一句話概括

RENEW 不只叫 offline RL 避開不確定區，而是請人比較兩段 imagined rollout 哪段 dynamics 較合理，直接用偏好微調世界模型，並把有限標註集中到 ensemble disagreement 高、最容易被 planner 鑽漏洞的區域。

方法

Dynamics Learning from Human Feedback（DLHF）沿用 Bradley–Terry preference loss，但把一般 RLHF 的 reward model 換成 dynamics model 對整段軌跡的 log-likelihood。標註問題必須是「哪段較符合物理／動力學」，不是「哪段較快達成目標」；後者可能偏好穿牆捷徑，反而獎勵 exploitation。

RENEW 假設只有預訓練模型與可用起始狀態，沒有原始離線資料作訓練訊號。每輪先估 epistemic uncertainty，從高不確定 state-action／segment 比例較高的分布取樣 imagined pair，取得偏好後以 DLHF loss 更新模型，再重算 uncertainty。本文使用 ensemble disagreement；方法宣稱可換其他估計器。

原文實驗結果

作者先用 synthetic oracle 表明偏好可從頭學小型 dynamics，但要約 1M preference labels 才達到約 1K supervised transitions 的 error 水準。100K label 的離散環境比較中，RENEW 在 Sliding Tile 3×3 的 final L1 error 為 0.207，naive DLHF 為 0.419；Sokoban 上 naive 反而讓預訓練模型變差，RENEW 改善。

在預訓練 Maze、固定 1,600 preference labels 下，RENEW 的 transition accuracy 在 5×5、10×10、15×15、20×20 分別為 96.5%、97.2%、94.4%、94.9%，作者報告皆高於 naive finetuning。它同時降低 prediction error 與 uncertainty；這是修復「模型可被利用區」的代理指標，非已證明下游 policy 不可 exploitation。

可帶走的設計

把 unknown 轉為標註與測試優先序，而非只當懲罰項。偏好資料要記錄是針對 dynamics realism 還是任務偏好，否則一樣的 pair 可導向相反更新。保留舊模型在低不確定區的正確性也要驗收，因為均勻 imagined rollout finetune 可能把原來正確的 transition 覆寫掉。

局限

所有偏好由可見 ground truth 的 synthetic oracle 產生，並非帶噪真人；環境是小型 grid world 與低維連續控制。作者尚未連結較低 error 到形式化的 unexploitable 保證或實際 offline RL return。完整原文逐節精要見下檔。
