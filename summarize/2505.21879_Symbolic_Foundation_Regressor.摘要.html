論文／訪談原始來源

《複雜網路上的符號基礎迴歸器（SFR）》重點摘要

一句話概括

首個專為「複雜網路」設計的預訓練符號迴歸基礎模型 SFR：能處理「大量相互關聯變數」的時空資料（如全球流行病跨 200+ 國家），高效重建支配方程。用 ~20 億條合成網路方程預訓練一個 set-to-sequence 雙分支 transformer，單次前向傳播即出方程。網路動力學重建只需 1.2 分鐘（比搜尋/學習法快 >3 倍），真實全球疫情傳播律 <0.5 分鐘，準確度與效率俱佳。

解決什麼問題

  • 科學現象常源於眾多相互關聯變數的協同演化（全球疫情 200+ 國、細到個人則上億變數）；傳統 SR 只處理低維獨立變數。
  • 複雜網路上的 SR：y_i = f(x_i, {x_j : j∈鄰居})——輸入含節點自身狀態 + 鄰居狀態；傳統 SR 是其特例（單節點無鄰居）。挑戰：網路拓撲多樣 + 高維變數 → 方程空間巨大。

兩大關鍵思想

  1. 經局部取樣解耦拓撲：把觀測樣本建模為三元組（中央節點 x_i + 其直連鄰居 {x_j} + 輸出 y_i）；取樣不同中央節點 → 與全域拓撲尺度/類型解耦，聚焦局部區域（利於現實的不完整觀測 + 異質傳播方程）。
  2. 物理先驗簡化方程：把方程分解為 self 部分 f_self(x_i) + interaction 部分 Σ A_ij·f_int(x_i,x_j)（self 描述個別節點演化、interaction 描述鄰居交互）→ 學固定的 1 元 f_self + 2 元 f_int，而非直接推可變的 n 元 f → 降維（破維度詛咒）。此分解的可行性/普遍性已被確認。

SFR 流程

  • 造方程語料 + 合成資料：隨機生成表達式樹（葉＝常數/變數、內部＝運算子；規則：避免巢狀三角/指數、interaction 至少一項）→ ~20 億條有效網路方程；取樣多種拓撲（grid/random/power-law/small-world/community）；從域空間（標準常態）取輸入模擬輸出。
  • set-to-sequence 雙分支模型：Set Transformer 資料表示模型（把觀測集映到表示空間）+ 兩個 transformer 分支解碼器（self 分支 + interaction 分支，自迴歸生 f_self 與 f_int 的前綴表達式序列）;cross-entropy 預訓練。
  • 下游應用：單次前向傳播出方程；scaling 變換（把真實資料轉成模型期望分布、處理分布偏移）;BFGS 優化常數；constrained beam search 可納入專家/LLM 領域知識（與 LLM 整合的介面）。

結果

  • 非網路 SR：在 R² 與準確度上顯著勝 PySR、SINDy、NeSymRes、E2E（尤嚴格指標）。
  • 網路動力學（6 場景：Gene 基因調控/Heat 熱擴散/Epi 疫情/Bio 生化/LV Lotka-Volterra/Mutu 互利）：全指標勝 GNN+GP（搜尋）與 TPSINDy（學習），不論拓撲/線性非線性；1.2 分鐘重建（>3 倍快）。
  • 真實全球疫情：<0.5 分鐘發現更直觀的交互傳播律、最佳資料擬合。
  • 少資料即可：正常方程 40+ 個（節點數×時間步）測試點、複雜方程 60+ → 適合稀疏資料現實。
