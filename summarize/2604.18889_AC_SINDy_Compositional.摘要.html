論文／訪談原始來源

《AC-SINDy：以算術電路做組合式非線性動力稀疏辨識》重點摘要

一句話概括

AC-SINDy 把標準 SINDy「枚舉龐大候選基底庫」這個會隨狀態維度組合爆炸（多項式階 p、維度 d 時庫大小 O(p·d^p)）的瓶頸，換成「算術電路（arithmetic circuit）」結構化表式——以線性函數的組合 + 乘性交互動態建構非線性特徵，把函數寫成 f(x)=Σ_k ψ_k(x)、ψ_k(x)=∏_{j∈S_k}(w_{k,j}ᵀx)（一堆「因式化項」之和、可跨交互共享結構），參數量降到 O(p·d)（活躍交互 m=O(d) 時整體 O(p·d²)）而非組合增長。線性層＝求和節點、乘性層＝乘積節點，剪枝＝刪計算圖的邊（直接動結構而非選係數）。配上特徵正規化（解決尺度不可辨識）、重要性剪枝 Δ_i≈|w_i·∂ℒ/∂w_i|、多步一致性濾波。在 2D 非線性系統、Lorenz、含驅動 Lorenz 上回復出正確結構與近似係數（如 2D 噪聲 σ=0.05 仍抓到主導線性/雙線性項）。

解決什麼問題

標準 SINDy 須預先枚舉龐大候選基底庫，庫大小隨狀態維度 d、多項式階 p 達 O(p·d^p)——即使底層動力其實只有稀疏、低階交互，高維系統仍計算上不可承受。AC-SINDy 改為假設動力可由低複雜度的組合式表式承載（而非「在固定基底中稀疏」），用算術電路隱式表達假設類，繞開顯式庫枚舉。

核心方法

  • 架構：(1) 遮罩線性層——對增廣輸入特徵做線性變換（含偏置與低階項）；(2) 交互層——特徵以乘性組合 x^{(ℓ+1)}k = ∏{j∈𝒢_k} h^{(ℓ)}_j，{𝒢_k} 把特徵分群。
  • 函數類：f(x)=Σ_k ψ_k(x)，ψ_k(x)=∏_{j∈S_k}(w_{k,j}ᵀx)——因式化項之和，跨交互共享結構（非各自獨立的單項式）。
  • 算術電路詮釋：線性層↔求和節點、乘性層↔乘積節點；剪枝＝移除計算圖的邊，直接操控模型結構而非係數選擇。
  • 參數效率：組合式項只需 O(p·d) 參數（vs 顯式庫 O(p·d^p)）；活躍交互 m=O(d) 時整體 O(p·d²)。
  • 特徵正規化（關鍵）：組合模型有尺度不可辨識（特徵尺度可在層間任意重分配不改輸出）→ h̃_i(x)=h_i(x)/(stopgrad(σ_i)+ε)（σ_i 為訓練標準差），保住「係數大小 ↔ 函數重要性」的對應。
  • 重要性剪枝：以 Δ_i≈|w_i·∂ℒ/∂w_i| 估參數重要性（兼顧大小與對 loss 的影響）；迭代剪掉最低重要性參數再精修。
  • 多步一致性與濾波：把濾波與動力辨識分離——要求單一學得函數對「隨時間反覆組合」封閉；編碼器 ℰ 由觀測估潛態 S_t、動力 f_θ 演化 S_{t+k}=Φ^{(k)}θ(S_t)；多步監督 Σ{k=1}^K ‖x̂_{t+k}−x_{t+k}‖² 防止把未來資訊塞進編碼的平凡解。

結果（測試系統）

  • 2D 非線性：真 ẏ=−2x−0.1y−0.5xy−0.025y²；回復 ẏ≈−1.93x−0.11y−0.50xy−0.029y²——係數準、結構正確。
  • Lorenz（σ,ρ,β=10,28,8/3）：正確抓到主導交互 x(ρ−z)、xy；ż≈0.25x²+0.49xy+...−7.18（出現些微虛假項、係數有偏差）。
  • 含驅動 Lorenz：第一式加 0.1sin(x)。
  • 抗噪（2D，高斯 σ=0.05）：ẋ≈−0.08x+0.55y、ẏ≈0.04x²−0.57xy−2.14x——顯著噪聲下仍抓到主導線性/雙線性項、回復平滑的底層動力近似。
  • 預測品質：Lorenz 軌跡上準確捕捉各態動力與全域相空間結構，混沌長期預測如預期發散。

局限

  • 屬「組合式因式化表式於系統辨識」的初步研究；未來才會探索高維與更複雜動力。
  • Lorenz 回復出現虛假項與係數偏差，不保證精確係數回復（但保住定性動力結構）。
  • 實驗只到低維（2D/3D）。

對讀者的價值

  • 本批 C 類涵蓋 SINDy／動力系統發現支線 的代表——多數 SR 工作做代數式回歸，本篇攻**「動力方程式發現」且直擊 SINDy 的庫枚舉組合爆炸**，方向獨特。
  • 最值得記：用算術電路（求和/乘積節點）取代顯式基底庫 → 參數 O(p·d) 而非 O(p·d^p)；剪枝＝刪計算圖邊；組合模型的尺度不可辨識需特徵正規化；以及重要性剪枝 |w·∂ℒ/∂w| 與多步一致性濾波。
  • 與 2502.03367 SyMANTIC（遞迴稀疏迴歸 + 互資訊特徵選擇做精簡建模）對讀：兩篇都在攻「庫/特徵爆炸」，一個用互資訊篩特徵、一個用算術電路繞開枚舉。亦與本批代數式 SR（2606.07915 EditSR、2605.23272 SAGE-Fit）互補——同為「發現可解釋式子」但對象是 ODE/動力而非靜態函數。
