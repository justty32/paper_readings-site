論文／訪談原始來源

預測器比模型自己更懂它，額外價值從哪裡來？

一句話概括

本文以模型對所選答案的機率為基準，證明額外正確性預測優勢可經重新校準等量轉成答案 log loss 的改善；在合成與參數計數假設下，這個優勢受模型距同容量最佳值的差距與新增容量所限，並延伸到等升級率的雙模型 cascade。（§3–4）

問題與核心定義

預測「模型會不會答對」常被用於 routing，但要先問學得的 predictor 比模型自己的 confidence 多提供多少資訊。令 f 是答案機率分布，選最大機率答案，Z 表示此答案是否正確；self-confidence 為該答案的機率，不是模型口頭聲稱的信心。L_Y 衡量 gold answer 的 log loss，L_Z 衡量二元正確性的 log loss，額外可預測性為 E = L_Z(f) - L_Z(g,f)。（§3.1）

主要理論

等量轉移：將原先所選答案的機率改成 predictor 的正確機率，剩餘質量依其他答案原比例分配。正確／錯誤機率以外的 alternative loss 不變，因此 L_Y(C_g(f)) = L_Y(f) - E。需有限答案 loss、predictor full support，並在定義中要求原先未選答案的總質量非零。這是 log loss 的恆等式，不是 accuracy 同量提升，也不是訓練原模型權重的演算法。（命題1、§3.2；附錄 A.1；末句為本檔補註，非作者自陳）

次佳差距與容量：假設固定任務分布上每個參數預算均有可達的最低答案 loss L_Y*(P)，模型類容許組合模型與 predictor。所有參數含凍結權重均計入，共享只算一次，固定算術不另加參數；故 P 參數模型與 Q 參數 predictor 合成後至多用 P+Q。定理1給出 E <= delta_P(f) + L_Y*(P) - L_Y*(P+Q)。只有超過容量增益的額外可預測性才證明模型在自身預算下次佳；不是只要 predictor 有用就證明原模型差。（§3.3，假設1、定理1）

上界不是必然趨勢：若 loss floor 凸、容量效益遞減，小 predictor 的容量修正可進一步縮小；但次佳差距下降不必使最大 E 下降。附錄以保持所選答案和 confidence、僅改善錯誤時 alternative 分布的構造證明兩者可分離。（附錄 A.3–A.4）

雙模型 cascade 的條件

先執行弱模型，再由 router 決定哪些題升級給強模型；與 confidence routing 比較時，兩者升級比例 rho 相同。若 u 是兩種升級決策的差，cascade accuracy 優勢等於「額外捕捉的弱模型錯誤」減「額外遇到的強模型錯誤」。能多抓弱模型錯誤的 router 可轉成對 confidence logit 的有效校正，定理2由此限制弱錯誤捕捉增益。（§4.1–4.2）

令 Delta = delta_P1(f1) + L_Y*(P1) - L_Y*(P1+Q+2)，其上界為 sqrt(min(rho,1-rho) * Delta)。額外兩個參數是升級率與校正強度。只有當 learned router 額外遇到的強模型錯誤非負時，同一上界才直接約束完整 cascade accuracy 優勢；若 router 更會避開強模型錯誤，還有另一來源的收益。（定理2、推論2；附錄 A.5–A.7）

實驗設計與結果

作者自報評估八家族的16個 base／instruction-tuned release，規模7–12B；任務為 WinoGrande、CommonsenseQA、GSM8K、MMLU-Pro。前兩者以正規化選項 likelihood 建分布，後兩者以每題128個生成樣本估答案頻率，再以最高機率答案及其機率評估。生成題的 confidence 需多次取樣，不能直接當作單次生成免費得到的訊號。（作者自報，§3.4.1、附錄 B.2；末句為本檔補註，非作者自陳）

每個模型／任務／微調階段分別訓練 Qwen3-Embedding-4B predictor，讀題目、答案、分布，生成題另給以多數答案結尾的抽樣推理軌跡。用 development 的85%訓練、15%選 checkpoint／seed。微調後 development accuracy 未改善者剔除，留下依任務16／16／14／13對，共59對；因此結果是改善子集，不涵蓋所有微調結果。empirical suboptimality 是相對留存群組最佳觀察答案 loss 的差，不是已量得理論 floor。（作者自報，§3.4.1、附錄 B.1、B.3–B.4）

作者自報上述四任務中，empirical suboptimality 與 E 的 Pearson 相關依序0.98／0.98／0.93／0.65。微調後59對的答案 loss 都下降，E 在55對下降。Llama-3.1-8B 的 CommonsenseQA 軌跡中，E 由0.107降至0.004 nats。這是觀察趨勢，不是定理保證逐模型都下降。（作者自報，§3.4.2，圖1–3）

結論與局限

作者明示：理論只給上界，不能推出每次降低答案 loss 都縮小 predictor 優勢；完整 cascade 優勢還依賴強模型錯誤，後續需研究不執行強模型時如何預測升級收益。self-confidence 不可取得時，predictor 僅恢復此訊號也可能有用；可預測價值另來自次佳差距及新增容量。（§5）

作者在附錄說明相關檢定假設觀察值獨立，未調整多重比較；小型 predictor 的跨模型相關也不一致，不能把主4B結果泛化成任意 predictor 的定律。（附錄 C.1、C.3）

對讀者的價值・接點

（本檔補註，非作者自陳）設計 agent routing 時，先建立能取得的 confidence 與校準基準，分開評 correctness log loss、題目排序、固定升級率 accuracy 及實際成本。正斜率 Platt 校準可降 loss 卻不改排序，所以「更會估機率」不等於「更會挑題升級」；也不能由本文推論多模型 routing 普遍無用。（依據§4.3、§5）
