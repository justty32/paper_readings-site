FluxDisco: Symbolic Regression for Stoichiometric Dynamical Systems via Monte Carlo Graph Search 重點摘要

一句話

FluxDisco 把化學、生物與物理中已知的化學計量結構當成硬約束，不直接猜整組 ODE，而是用 Monte Carlo Graph Search 聯合搜尋未知 flux expression，藉由狀態合併重用等價數學式的評價結果，並以 ODE 積分後的軌跡誤差和式子簡約度共同導引搜尋。

問題與方法架構

  • 問題：黑箱動力學模型可以預測，卻不給可解釋方程；一般 symbolic regression 又常分開擬合各個狀態導數，可能違反質量守恆等已知物理結構。對可寫成 x_dot(t)=S v(x(t)) 的系統，化學計量矩陣 S 往往已知，真正未知的是 flux vector v。FluxDisco 因此把目標改為在 S 約束下聯合發現全部 flux。
  • 圖上的符號搜尋：每個狀態同時包含所有待發現 flux 的完整或部分式子，action 則用 context-free grammar 把待展開 token 替換成變數、常數或運算子。不同操作順序可能得到同一式子，因此作者使用圖而非樹，讓同一數學狀態能有多個 parent，並將回饋傳給所有 ancestor。
  • 條件展開與狀態合併：只有當節點還沒有 child 時才展開，並先對 child 做 rollout 以避免冷啟動。為了控制高 branching factor，每次只展開各 flux 最右側的待完成 token，並以最大 expression depth 強制簡約。新狀態在加入 graph 前會先做 constant folding 與詞彙排序，把加法、乘法常數等重複表示歸並成同一 ID。
  • 選擇與 rollout：一般 MCGS 偏好平均回饋高的節點，但 equation discovery 的目標是找到單一最佳函式形式。FluxDisco 因此讓 local reward 不低於該狀態曾採到的最高 reward，防止好式子因其他差 rollout 而過早被軟剪枝。對部分式子進行隨機完成，則為無法直接評分的中間節點提供密集回饋。
  • 回饋與常數優化：完成候選式後，先用已知 S 組成 ODE，在常數優化的每次迭代中實際解 ODE，以整段軌跡與觀測資料的誤差導引參數。Reward 同時包含 MSE 的指數適合度與式子複雜度懲罰。這比先對噪聲軌跡做 finite differencing 更慢，但避免導數估計放大噪聲或因平滑而扭曲真實動力學。
  • 不確定性處理：原始 Binary KL 信心區間在龐大搜尋空間中收縮太慢，容易退化成幾乎均勻的搜尋。作者以 Thompson sampling 的 Beta posterior 作為啟發式 credible interval，讓少量已採樣 reward 能更快區分節點，代價是 true mean 落在區間外的風險較高。

作者報告的結果

作者以 standard、squared 與 square-root SIR、Lotka–Volterra、stable 與 unstable Brusselator，以及 Fairen–Velarde 的模擬軌跡測試方法，並比較 SPL、SINDy、PySR、ProGED 與 ODEFormer。預設搜尋的最大 flux expression depth 為 6，進行 100 個 episode（作者自報）。除了加入化學計量矩陣的正式版，也測試以 identity matrix 取代 S 的 no-stoichiometry ablation。

FluxDisco 在所有被測系統與噪聲條件下，最大軌跡重建誤差仍低於 2%（作者自報），且是唯一未在某些實驗高於 NMSE 100% 平均值預測 baseline 的方法（作者自報）。不施加化學計量的版本在數值誤差、耦合項識別與效率上都顯著較差（作者自報），支持「先用已知物理結構限縮搜尋空間」的主張。

符號恢復的結果比軌跡擬合更嚴格。FluxDisco 在多數系統對耦合項的識別率較高，但 Fairen–Velarde 的真實函式沒有被任何比較方法恢復（作者自報）。FluxDisco 雖可找到能擬合其軌跡的式子，卻不等於恢復真實機制。此外，正式版與 ablation 的 runtime 都比其他方法高數個數量級（作者自報）；作者認為 equation discovery 通常是離線任務，因此準確性可補償這項代價。

結論與局限

論文證明，當化學計量矩陣可靠時，與其放任 symbolic regression 分開猜每條 ODE，不如把先驗結構直接編進表示與搜尋，把問題縮小成聯合 flux discovery。圖狀態合併、domain-aware grammar 與軌跡級 reward 再共同解決等價式重複、巨大組合空間與噪聲導數估計問題。

作者明列三項主要局限。第一，聯合 flux 估計隨系統維度與式子複雜度增加而快速失去擴充性，因為同一 graph node 必須同時生成整組正確 flux。第二，方法把化學計量當硬約束，一旦 S 指定錯誤，flux 估計也會錯；未來可改成同時估計化學計量與 flux、並對偏離先驗結構施加懲罰的軟約束。第三，現行方法假設系統狀態可完全觀測，還不能直接處理真實物理系統中的 latent state。

對 ai_core 的價值／接點

FluxDisco 對 ai_core 的啟發是「把強先驗寫進搜尋空間，不只寫進最後的評分器」。若一項任務已有可信的接口、依賴圖、守恆條件或狀態轉移結構，生成器不應先產生任意解再由 verifier 淘汰；應讓只有結構上合法的候選能被表示。這同時縮小搜尋與保證基本正確性。

狀態合併也對程式合成有用。同一部分程式或工作流可由不同編輯歷史到達；若搜尋系統只依語法樹路徑記憶價值，就會重複學習等價狀態。ai_core 可借用「canonicalization＋transposition table＋多 parent 傳播」，讓對某個中間結構學到的成敗訊號能被所有等價產生路徑重用。
