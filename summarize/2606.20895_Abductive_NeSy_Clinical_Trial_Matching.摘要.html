論文／訪談原始來源

《αNeSy-CTM：以 LLM 溯因推理 + 邏輯驗證做臨床試驗配對的神經符號框架》重點摘要

一句話概括

αNeSy-CTM：把臨床試驗配對（CTM，判病人是否符合試驗資格）框成約束滿足/SMT 問題——用 **LLM 自動形式化（autoformalize）**把病人檔與資格條件翻成 SMT-LIB 約束，交給 Z3 求解器做確定性可滿足性檢查；關鍵創新是加一道 **LLM 溯因推理（abduction）**階段，從含糊/不完整臨床文字補上隱含但有依據的事實（如「能獨立行走」⇒ 低 ECOG 狀態），讓形式化更完整可靠。在 TREC 2021–2023 上比純 LLM baseline 最高 +30% 相對提升（TREC 2023 準確率 75.71% vs zero-shot 58.17%），抗擾動只掉 2%（非溯因版掉 8.5%），且與 CoT 高度互補（互救 18%/12%）。

解決什麼問題

LLM 能讀懂臨床敘述變體，但無法做嚴格資格條件所需的確定性驗證（數值門檻、時間窗、巢狀邏輯依賴），且缺可審計的推理軌跡 → 高風險臨床場景不可信。純符號/規則系統雖嚴謹，但面對病歷的片段化、不完整、含糊就脆斷。CTM（人工比對病歷 vs 資格條件）是試驗招募的瓶頸、易出錯。

核心方法

  • 問題形式化：對每個病人–試驗對，定義變數空間 V（年齡、既往治療、診斷、時間指標等，有型別域：整數/實數/布林，在背景理論 𝒯（線性算術）下評估）。資格條件 L=φ(T)（符號約束集）、病人事實 F=ψ(P)。資格 y=1 ⟺ F∪L 在 𝒯 下可滿足（無矛盾）。
  • NeSy-CTM（基線神經符號版）三階段：
    1. 自動形式化：LLM 把資格條件譯成 SMT-LIB 約束（如 assert (>= Age 18)）、從病歷抽事實（assert (= Age 52)）。
    2. 符號驗證：Z3 檢查 F vs L，回 sat（合格）/ unsat（不合格）。
    3. 自我修正迴圈：Z3 報語法/型別錯 → LLM 收錯誤回饋迭代修正（工具增強推理）。
  • αNeSy-CTM（溯因擴展）：基線在資訊不全時會高估資格（L 的變數與 F 不匹配→欠定→Z3 誤判 sat）。加一道溯因推理：LLM 生成一組保守的、文本支持的推斷事實 I（匹配縮寫、治療史、疾病狀態指標），合併成 F∪I∪L 再交 Z3。例：病歷「能獨立行走、自行採買、生活無需協助」+ 試驗要 ECOG≥3 → 溯因補 ECOG=0/1 → Z3 才能可靠判定不合格。

結果（TREC 2021–2023，三個 LLM 骨幹：gpt-oss-120b / olmo-3-32b / qwen3-vl-32b;Z3 v4.12.2）

  • TREC 2023（最難、半結構化問卷、證據最碎）：αNeSy-CTM 平均準確率 75.71%，遠超 zero-shot 58.17%；最高達 +30% 相對提升。
  • 準確-特異度權衡：神經符號法把過度敏感（高 Sens 低 Spec）的 LLM 推向平衡準確；更嚴的邏輯邊界大幅降假陽性（如 gpt-oss-120b NeSy-CTM Spec 達 82–90% vs zero-shot 51–56%）。
  • 形式驗證在最難、欠定資料集增益最大；平衡分類使其成為人機協作篩選更可靠的過濾器。
  • 抗擾動：αNeSy-CTM 在受控證據擾動下只掉 2%，非溯因 NeSy-CTM 掉 8.5% → 溯因提升穩健性。
  • 互補性：αNeSy-CTM 救回 CoT 失敗的 18%，CoT 救回 αNeSy-CTM 失敗的 12% → 暗示混合路由策略潛力。

局限

  • 仍依賴 LLM 自動形式化的正確性（型別/語法錯需自我修正迴圈兜底）；溯因可能引入過度推斷（論文強調「保守、僅文本支持」）。
  • 計算複雜度較高（多階段 + Z3 求解 + 迭代）；只測二元資格預測。

對讀者的價值

  • **「神經符號應用」**的標竿案例：把 LLM（語言/世界知識）+ SMT 求解器（確定性邏輯）+ 溯因推理（補不完整證據）三件套接到高風險醫療任務，主打可審計、可驗證的臨床 AI。
