作者：Yewei Liu, Xiyuan Wang, Muhan Zhang（北京大學人工智慧研究院）

日期：2025-06，網路剪枝／元學習方法

arXiv：2506.12041

論文／訪談原始來源

《透過圖元網路進行元剪枝：一個通用的網路剪枝元學習框架》重點摘要

一句話概括

MetaPruning：把元學習的「元網路（metanetwork）」概念首次引入剪枝——先在「神經網路↔圖」之間建雙射對應，再用一個圖神經網路（GNN）當元網路，學會把「難剪」的網路就地改寫權重成「易剪」的網路；訓練好後剪枝只需「過一次元網路前饋 + 標準微調」，不必每次剪枝都重訓，且能在不同資料集／架構間自然遷移，在 CNN 與 Transformer 多個任務上達 SOTA。

解決什麼問題

既有剪枝兩條路都有缺陷：(1)固定手工準則（norm/magnitude/saliency）粗糙、表達力受限；(2)learning to prune（用 NN／RL 學剪枝）每次剪一個網路都要專門訓練、缺乏通用性，多半只能「學一次剪一個特定網路」。如何讓「學到的剪枝策略」可重用、可遷移、通用於各種網路與各種剪枝方式？

核心方法

  • 第二條路線思路：不改剪枝準則，而是把網路變得更好剪（繼承稀疏正則化剪枝精神，特別參考 DepGraph）。
  • 網路↔圖雙射：神經元／卷積通道→節點；連接（FC／卷積／殘差）→邊；節點特徵＝BatchNorm 參數（weight/bias/running mean/var，含前一層與 skip）；邊特徵＝連接權重（線性／殘差視為 kernel size=1 的卷積，攤平成向量）。可逆轉換回網路。
  • 元網路（GNN）：基於 message passing + PNA 架構；節點與邊特徵編碼→多層訊息傳遞（含 EdgeInvertor 設計：前半維學無向不變特徵、後半維學隨方向等變的有向資訊）→解碼；殘差係數很小（學 delta 權重而非完全重寫）。
  • 元訓練（meta-training）：取「data model」當原始網路→轉圖→過元網路→轉回新網路，算兩種損失：準確度損失（交叉熵，避免破壞有效部分）＋稀疏度損失（group norm 為基的正則項，促稀疏好剪），反傳更新元網路。
  • 剪枝管線：初始剪枝（把易剪網路先剪成難剪，去掉低品質參數）→過元網路→剪枝→微調。
  • 關鍵性質：元網路是相對極小的 GNN、每個參數只看局部鄰域→必須學通用策略→剪枝模型與訓練 data model 完全不同也照樣好、對 data model 數量（1/2/8）不敏感、無過擬合、可跨資料集與架構遷移。

結果（含數字）

  • ResNet56/CIFAR10：剪 65.6% FLOPs，準確率 93.51%→93.64%（+0.13%，不降反升）。
  • VGG19/CIFAR100：剪 88.83% FLOPs，Top-1 -3.90%。
  • ResNet50/ImageNet：剪 57.2% FLOPs，Top-1 僅 -0.01%、Top-5 -0.33%。
  • 彈性：準則高度可換（不同 NORMALIZE／alpha 甚至 naive 無正規化都穩）；支援結構化、非結構化、N:M 稀疏剪枝。
  • 遷移：metanetwork 可在 CIFAR10/100/SVHN 之間、ResNet56↔ResNet110 之間遷移，皆優於不用元網路。
  • 成本：元網路不隨被剪網路規模擴張；與 DepGraph 對比，攤提後時間更省（一次元訓練可剪無數網路）。A100 80G 足以元訓練 ResNet50/ViT，微調用 RTX 4090 即可。

局限

  • 元訓練前期成本（範例 357 分鐘）須一次性付出，雖可攤提但單次剪一個網路不划算。
  • 前饋過元網路瞬間 VRAM 峰值高。
  • 通用性目前達「階段（3）」（可剪相似架構／資料集的一群網路），尚未達「階段（4）」（剪任意網路）——需在更多網路／資料集上預訓練才有望。

對讀者的價值

  • 本批 D 類的**「元學習×圖神經網路用於模型壓縮」代表**——與傳統「準則式剪枝」正交，走「用 NN 改寫 NN 權重」路線。
  • 最值得記：**「網路↔圖雙射 + GNN 元網路 + 局部訊息傳遞學通用權重改寫」的配方；「學一次、剪無數、可遷移」**打破 learning-to-prune 每次重訓的痛點；EdgeInvertor、小殘差係數學 delta 等實作細節。
