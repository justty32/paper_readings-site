論文／訪談原始來源

《健全且完整的神經符號推理：以 LLM 接地的解釋》重點摘要

一句話概括

LLM 知識廣但邏輯不一致。本文不靠 prompting、也不靠外部 solver，而是把 LLM 直接當成「超協調邏輯（paraconsistent logic）AC」的解釋函數（interpretation function），並用快取機制證明此「LLM 接地的解釋」仍保持健全性與完整性（sound & complete）——矛盾被局部化、不會引發邏輯爆炸。

核心問題與創新

  • LLM 是不可靠知識庫（不一致、不完整），如何在形式推理中善用其參數知識？
  • 既有三類做法：(a) prompt 式（LLM 自己用自然語言推理）、(b) solver 式（LLM 產形式語句交外部推理器）、(c) 預訓練/微調學證明。本文提出第四類 (d) 解釋式（interpretation-based）：LLM 評審直接充當解釋函數。
  • 用**廣義真值（generalized truth values）**＝（驗證， 反駁） 的有序對，取代二元判斷，植根於 Belnap 四值語意（能處理不完整/不一致資訊的「Belnap 電腦」）。

邏輯選擇：Angell 的分析包含邏輯 AC

  • 同時具超協調性 paraconsistency（容忍矛盾不爆炸）與超完備性 paracompleteness（拒絕排中律），適合模糊/不完整資訊。
  • 真值用 weak Kleene 三值 {𝔱 真， 𝔢 未定義， 𝔣 假}，廣義真值是 𝒱₃×𝒱₃。

雙邊事實性評估（Bilateral Factuality Evaluation，Section 3）

哲學原則 bilateralism：理解一個命題需同時掌握「斷言」與「否認」條件。流程：

  1. 把原子公式 φ 語句化（verbalization）;
  2. 對 LLM 問兩次：一次「能否驗證？」一次「能否反駁？」;
  3. 映成 weak Kleene 真值；
  4. 組成有序對 ⟨u,v⟩。
  • Def 3.4 雙邊評估 ζ：u=𝔱 若輸出含 "VERIFIED"、u=𝔣 若 "CANNOT VERIFY"、否則 𝔢;v 同理用反駁 token。
  • Def 3.5 快取函數 ζ_c：一旦某原子被評估，重複呼叫回傳快取值 → 保證 tableau 推理所需的穩定賦值。
  • 例：「美洲於 1492 年被發現」→ 驗證「歐洲探索脈絡下準確但不完整」=cannot verify；反駁「歐洲視角下不矛盾」=cannot refute → ⟨𝔣,𝔣⟩（知識不完整）。

形式保證（Section 4，本文核心）

  • Def 4.1 LLM 接地的 AC 解釋：每個關係 \(R^\mathcal{I}(c_1,...,c_n)=\zeta_c(R(c_1,...,c_n))\)，雙邊評估函數直接算謂詞真值。
  • Lemma 4.2 穩定性：ℐ(φ) 良定義且首次計算後恆定（靠快取）。
  • Lemma 4.4 / 4.6 雙向映射：任一 LLM 接地解釋 ↔ 標準 AC 解釋語意等價（標準解釋只需預填快取）。
  • Theorem 4.8 保持健全性：Γ⊢ φ ⟹ 對所有 LLM 接地解釋 Γ⊧ φ。
  • Theorem 4.10 保持完整性：對所有 LLM 接地解釋 Γ⊧ φ ⟹ Γ⊢ φ。
  • 含意：即使用不確定、會犯錯的 LLM 當解釋函數，底層形式系統的邏輯保證依然成立（靠快取 + 等價引理）。

實驗（Section 5）

  • 資料：由短答事實性基準 GPQA 與 SimpleQA 各 N=400 構造。
  • 指標：Macro-F1（在不棄權時）、Coverage（非棄權比例）、執行時間/token。
  • 六個 LLM 評審：旗艦（Llama 4 Maverick、GPT-4o、Claude 3.5 Sonnet）＋蒸餾（Llama 4 Scout、GPT-4o Mini、Claude 3.5 Haiku）；三種 prompt（direct / zero-shot CoT / few-shot CoT）。基線：單邊評估（只給 𝔱 或 𝔣）。

關鍵結果

資料集 模型 雙邊 F1 覆蓋率 單邊 F1 覆蓋率
GPQA 旗艦 0.699 0.589 0.633 1.000
SimpleQA 旗艦 0.736 0.584 0.657 1.000
  • 雙邊評估 F1 顯著勝單邊（+~6 個百分點，p<0.01），代價是覆蓋率降（在不一致/不確定時觸發棄權）。
  • 旗艦明顯勝蒸餾；雙邊評估約 2× 時間與 token。
  • 不一致 ⟨𝔱,𝔱⟩（30%）比不完整 ⟨𝔣,𝔣⟩（11%）更常見（p<0.05）；且未出現 𝔢（未定義）。

概念驗證 + 局限

  • PoC tableau 推理器：應用於用藥安全知識庫（228 斷言 + 712 推論）→ 偵測 92 個 gluts（醫療顯著錯誤，如鴉片類被推為非成癮、β-阻斷劑被推為氣喘安全），同時系統仍可滿足——證明矛盾被局部化、不爆炸。
  • 局限：複雜度依需評估的原子數，最壞指數級；每原子需 2k 次 API 呼叫（k-sample 多數投票）；尚缺完整端到端推理器（只實作了解釋函數）。未來：把 AC 翻譯成古典描述邏輯（SROIQ）以接 Pellet 等既有工具。

對讀者的價值

  • 一條讓 LLM「合法」進入形式邏輯的路線：把 LLM 當解釋函數而非推理器，用超協調邏輯吸收其矛盾，並有定理保證健全完整。
  • 與 2507.11127（推理=積分式）、2507.08216（接地 BC_{w,d}）同屬 NeSy 形式化前沿，但獨特在用 LLM 充當 grounding 並容忍矛盾。
