The LLM Proposes, the Executive Disposes 重點摘要

一句話

本文把 LLM 降為提交 typed proposal 的角色，讓 deterministic Executive 擁有 belief、驗證預先登記的 prediction 與 run validity；貢獻是量測 goal drift 的儀器，不是 ARC 解題器。

核心設計

  • Observer、Surveyor、Actuator 只能透過封閉詞彙提案；Executive 的 differ、matcher、validator、compiler、renderer 與 evaluator 決定所有 state transition。
  • claim 必須先寫入 prediction log，之後由程式將預測和 observation diff 比對才可進入 belief；「LLM 說完成」不是事件。
  • referent 從命名文字，經由 observation anchor、action receipt，最終到被測試規則引用的 characterized 層級；所有 store append-only，status 由資料計算而非覆寫。
  • run gate 對 organ write error、render token ceiling、salted-canary echo 設門檻；失效 run 不得做 attribution。shadow reference 在每個 ablation cell 都編譯完整系統本會採用的 plan，但不可 render／執行，令刪掉 commitment 後 drift 指標仍有定義。

兩種 drift

binding drift 是意圖與指涉物都在，但長距離／低 salient context 使目標－referent 的連結丟失；修復為 code-owned join。commitment drift 是後續 context 根本遺失意圖；修復為由程式執行的外部 agenda／commitment store。兩者不應用一個總分混為一談。

作者報告的結果，含重要負結果

作者報告：在一個遊戲、每 cell 三個 seed 的有效 run 中，移除 commitment store 令 goal-abandonment 從 0.00 變 1.00，而 binding error 維持 0.00；A0 的三個 seed 中有一個沒有可用 feedstock，該 drift 指標為 undefined，非零；最多一 run 有 394 個 shadow reference beats。移除 join 也未令 per-beat binding drift 上升，作者解釋為 bind 已被 Executive 的幾何／receipt 邏輯結構性吸收，殘差移到 hypothesis formation。

更重要的是，52 個通過 gate 的 ARC-AGI-3 run 全部零 level completion、零分。作者把此預先登記為效能主張的結構性否決，因此本文不能作為 ARC-AGI-3 解題有效性的證據。

採用邊界

這套設計可借鑑為「提案、狀態變更、驗收」三權分立與可重播紀錄；但因果 dissociation 仍只在有限遊戲／seed 上完成，封閉詞彙與形式 micro-world 的假設也限制外推。
