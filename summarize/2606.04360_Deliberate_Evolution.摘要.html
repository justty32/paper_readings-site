論文／訪談原始來源

《Deliberate Evolution：以代理式推理達成樣本高效的 LLM 符號迴歸》重點摘要

一句話概括

Deliberate Evolution（DE）：一個把「提議式子」與「控制搜尋」解耦的代理式 SR 框架——洞察是現有 LLM-SR 太樣本低效（每題常需 10³ 候選），病根在「用單一純量分數（MSE）同時逼 LLM 推斷怎麼改、為何錯、過去學到什麼」。DE 給 LLM 提議補三種顯式訊號：方向（adaptive operators 決定 refine/mutate/crossover/regenerate）、診斷（tool-augmented：殘差/資料統計/量綱一致性把純量誤差轉成局部結構證據）、記憶（reflective memory 累積成功母題與失敗教訓）。在 LLM-SRBench 上，只用標準取樣預算的 40%，平均 NMSE 在 Llama3.1-8B 降 55%、Qwen3-4B 降 37%，且一致勝過 LLMDirect/LLM-SR/LASR/SGA。

解決什麼問題

現有 LLM 演化式 SR樣本低效：把候選提議與搜尋引導混為一談，只給親代式 + 一個 MSE 純量，卻要 LLM 一次推斷三件事——怎麼改（方向）、為何失敗（診斷）、前次教訓（記憶）。缺這三訊號 → 搜尋在無效編輯間漂移、無法瞄準錯誤的結構源頭、反覆重蹈失敗，大量評估浪費在「貌似合理但無資訊」的候選上。

核心方法

核心原則：解耦「提議什麼式子」與「搜尋如何演進」。 LLM 當有彈性的骨架提議者，三個顯式模組操控搜尋：

  • Adaptive operators（自適應運算子／方向）：依當前搜尋狀態與停滯行為，顯式選擇 refine（精修簡化）／mutate（功能變異）／crossover（重用有望子式）／regenerate（更廣探索），而非讓 LLM 從純量瞎猜該做哪種符號移動。
  • Tool-augmented proposal（工具增強提議／診斷）：以分析工具診斷當前失配——分析資料統計、殘差樣式、量綱一致性，把純量誤差轉成局部化的結構回饋（揭示是缺週期性？變數交互錯？量綱無效？漸近行為錯？）。
  • Reflective memory（反思記憶／歷史）：彙總成功母題、失敗編輯、停滯軌跡，使未來提議重用有望結構、避免冗餘探索；達成「軌跡級」經驗累積。
  • 三者合力把 SR 從「純量驅動的試誤生成」轉為「有顯式意圖、局部證據、累積經驗的引導式科學搜尋」。維持演化框架（族群、島嶼、選擇-變異-評估）。

結果

  • LLM-SRBench（LSR-Transform 與 LSR-Synth，橫跨物理/材料/化學/生物）+ Llama3.1-8B-Instruct 與 Qwen3-4B-Instruct：
    • 只用標準取樣預算的 40%，平均 NMSE 降 55%（Llama3.1-8B）、37%（Qwen3-4B）；一致勝 LLMDirect、LLM-SR、LASR、SGA。
    • 進一步在域外泛化、噪聲觀測、真實應力-應變量測與消融上，證明「深思引導」改善擬合準確度、穩健性、樣本效率。
  • 圖示：在更少評估次數下達更低誤差（樣本效率曲線明顯左移/下移）。

局限

  • 倚賴 LLM 的數學先驗；以中小型開源骨幹（4B/8B）為主，極大規模未測。
  • 工具診斷（量綱一致性等）需任務脈絡（變數單位等）。
  • 評測集中於 LLM-SRBench 派生集。

對讀者的價值

  • 本批 C 類的**「LLM 代理式 + 樣本效率」代表**——與 2606.07704 FunctionEvolve（同攻 LLM-SRBench、同強調「別讓 LLM 對著純量瞎猜」）為姊妹路線：FunctionEvolve 攻結構顯式化，DE 攻提議/控制解耦 + 樣本效率，兩者互補。
  • 最值得記：「conflate proposal with guidance」是 LLM-SR 樣本低效的病根;方向/診斷/記憶三訊號的拆解；殘差/量綱當診斷工具把純量誤差變局部結構證據；以及亮眼的 40% 預算 + NMSE 降 55%。
  • 與 2606.09276 ERBench 對讀：DE 在 LLM-SRBench 刷高效率，ERBench 提醒祕密集才見真章；與 2502.03367 SyMANTIC（無 LLM 的高效路線）對照「效率」的兩種達法。
