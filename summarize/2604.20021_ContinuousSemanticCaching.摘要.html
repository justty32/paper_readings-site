論文／訪談原始來源

《Continuous Semantic Caching for Low-Cost LLM Serving》重點摘要

一句話概括

連續語意快取 + kernel ridge regression 不確定性量化：以動態 𝜖-net 離散化將無限連續查詢空間分割為 Voronoi 區域，結合 KRR 泛化部分成本回饋到語意鄰域，在離線/線上兩種設定下給出嚴謹的次線性 regret 理論保證，實驗上比離散方法降 regret 達 72.41%。

核心貢獻

  • 問題創新：首篇將語意快取從「已知有限離散查詢集」擴展到「未知連續嵌入空間」——現實中 LLM 查詢無限多樣，無法預先枚舉。這是從 multi-armed bandit 到 kernelized bandit 的根本轉變。
  • 𝜖-net 離散化 + Voronoi 分區：以覆蓋半徑 𝜖 將連續空間切為有限區域，每個區域最多快取一個代表查詢，將 NP-hard 連續最佳化轉化為離散近似問題，並給出離散化誤差界（𝐿𝑔𝜖）。
  • 離線演算法 CUCB-SC-Cont：KRR 估計查詢成本函數 𝑐(𝑥) 及其後驗變異數，悲觀上界驅動 Reverse Greedy 快取選擇；給出次優性 gap 的三項分解（到達估計誤差 + 成本估計誤差 + 離散化誤差），並匯出最優 𝜖∗。
  • 線上自適應演算法 CLCB-SC-LS-Cont：動態構建 𝜖-net、階段式低切換門檻、KRR 樂觀 LCB 驅動探索；在連續空間上達成 Õ(√𝑇) sublinear regret 並控制快取切換次數（即使新語意群集在執行中動態出現）。
  • 實驗驗證：合成資料集與 NQ+TriviaQA 真實查詢流上，離線次優性 gap 對比 CUCB-SC 改善最高 73.32%（少量資料時最顯著）；線上 regret 對比 CLCB-SC-LS 降 72.41%（合成）與 43.14%（真實），runtime 仍具競爭力。

對讀者的價值（ai_core 接點）

  • 本文直接對應 ai_core §3.3 成本梯度的「零成本終點」：語意快取時不呼叫 LLM（成本 = 0），僅付出 mismatch cost 𝜙(𝑑(𝑥, M))。這是成本梯度從「貴模型→便宜模型→蒸餾→程式碼」後的終極形態。
  • KRR 的後驗變異數 𝜎² 可作為 ai_core §3.4 憑證/信心信號——當快取命中之查詢的 KRR 不確定性低於門檻，可安全跳過驗證層（等同確定性快取）；不確定性高時觸發 §3.4 的驗證流程。這呼應 backlog 中的 2602.13165（驗證式語意快取）。
  • 低切換成本的設計思路（動態階段門檻、僅在新語意區域出現時才更新快取）對應 ai_core 固化引擎 §3.6：不是每次都重新固化，而是只在「足夠新的行為模式」出現時觸發重新固化——運作哲學一致。
  • 連續查詢空間的泛化方法（從觀察到的查詢推論未觀察到的鄰近查詢成本）可作為 ai_core 意圖空間的泛化機制：當一個意圖（intent）被評估過成本，鄰近意圖的成本可以推斷而不需每次從頭評估。
