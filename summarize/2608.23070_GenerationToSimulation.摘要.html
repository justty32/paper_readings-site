日期：2026-08-24（v1，cs.AI）

論文／訪談原始來源

From Generation to Simulation: How Far Are World Models from Being True Simulators? 重點摘要

一句話

這篇 survey 不再用影像品質或架構類型衡量 world model，而拿傳統 simulator 的能力當外部尺；結論是目前模型已能在特定場景替代部分互動與控制功能，卻仍缺可驗證物理、可查詢的結構化 state feedback、長時程可重現性與真正面向下游決策的評估。

問題與分析方法

生成式 world model 已能產生逼真、可受 action 或語言控制的長影片，因此常被描述成下一代 simulator。但 simulator 不只要「看起來像世界」；它還要讓外部程式精確施加 action、逐步取得 state、重播相同條件、檢查物理量，並用 ground truth 評估 agent。若只按 latent dynamics、video diffusion 或 JEPA 分類，很容易把生成技術的進步誤認成模擬能力已齊全。

作者以 physics engines、game engines 與 reinforcement-learning environments 共同提供的介面為基準，建立八個 capability dimensions：asset construction、physics engine、interaction、controllability、stability、state feedback、diversity 與 evaluation metrics。這是一把獨立於模型路線的尺，可以把 latent dynamics、autoregressive video、diffusion、JEPA、explicit 3D／4D 與 occupancy methods 投影到同一張能力圖上。

文獻收集結合 Google Scholar、arXiv、DBLP 與 Crossref，另沿代表 survey 與 milestone papers 的引用網路擴充。納入標準要求方法接受 action 或其他 conditional input，並向前 rollout 出未來 observation 或 state，能服務 interaction、control 或 planning。最終 corpus 含 200 篇工作，涵蓋 2018 年至 2026 年中；作者逐篇標記技術路線、主要能力貢獻與 state interface，並另外稽核 implementation papers（作者自報）。

能力比較的核心發現

Interaction 與 controllability 是目前最接近功能替代的部分。Autoregressive 與 diffusion 路線已能讓使用者以鍵鼠、camera pose、語言或 latent action 操控生成環境；latent-dynamics 與 JEPA 則把 rollout 放進緊湊 representation，利於 policy learning 與 planning。但這些成功多在受限遊戲、駕駛或機器人場景，action interface 的語意、精度與閉迴路一致性仍不統一。

Physics 是第一個結構缺口。傳統引擎每步執行明確 solver，能檢查碰撞、接觸、守恆與參數；生成模型主要從資料學 visual plausibility，物體消失、幾何漂移與相同行動產生不同後果仍可能發生。Differentiable physics、顯式 3D state 與物理條件生成提供融合方向，卻尚未兼得開放域彈性與逐步形式保證。

Stability 的問題也不只影片能生成多久。長 rollout 是否不漂移是一項能力；控制亂數後能否重播、是否提供 tolerance bands 與 repeat-run variance 是另一項。現有研究對這兩者缺少跨架構共用 protocol，使 A／B testing、regression testing 與安全分析很難判斷差異來自模型更新還是 sampling noise。

最被忽略的是 state feedback。完整 audit 中，只有 6／163 篇 implementation papers 提供可在 runtime 查詢具名 entity state 或 physical parameters 的介面（作者自報）。即使放寬到 RGB 之外的 depth、semantics、LiDAR、normals 或 occupancy 等 sensor-level output，也只有 45／163 篇明確提供（作者自報）。從像素再跑 perception model 可能實用，但不等於 simulator 直接回傳 object pose、mass、friction、collision 或 reward；兩者在資訊損失、校準與可稽核性上不同。

結論與研究路線

作者的總判斷是：在受限條件下，world model 可以替代 simulator 的部分功能；嚴格來說仍差關鍵一步。各路線的優勢互補，但沒有單一路線同時提供逼真生成、形式物理、精確 action、持久 state、可讀 feedback、可重現 rollout 與面向下游的 ground-truth evaluation。

論文據此提出六個方向。Formalized physics 把 differentiable solver 與生成模型結合；unified action interface 橋接精確但狹窄的 explicit control、可讀但模糊的語言，以及泛化強但不透明的 latent action；first-class state feedback 要讓 entity 與 physical fields 成為原生輸出；long-horizon stability 同時處理 drift 與可重播性；downstream-utility evaluation 改看在 world model 內訓練的 policy 回到真實環境後是否成功；cross-route fusion 則組合 diffusion 的視覺、latent dynamics 的控制、JEPA 的效率與 explicit geometry 的一致性。

局限

這份 evidence map 量到的是研究注意力與論文中有沒有主要貢獻，不能直接當成某能力已達到的成熟度分數。State-interface audit 也受公開資訊限制；論文沒寫不一定代表系統內部完全沒有，只能列為 absent 或 unresolved。搜尋有固定截止日，快速變動的技術報告與沒有正式 paper 的工業系統難以完整納入。

分類仍包含人工判斷。每篇只標少數主要能力，跨 route 的複合系統可能被壓縮；不同領域對 stability、physics correctness 與 closed-loop success 的測量也尚未一致，因此 corpus-level counts 更適合找結構空白，不適合排模型名次。Survey 主要關注會生成 future observations 或 explicit state 的 generative route，直接輸出 action 或 value 的 policy route 只在比較所需時納入，結論不能無條件擴到所有「world model」用法。

對讀者的價值／ai_core 接點

這篇替 ai_core 提供一張比「模型準不準」更可操作的驗收表。若一個 world model 要成為 agent 的執行環境，至少應分別檢查 action 介面、state feedback、物理／規則約束、重播一致性、長期 drift 與下游 policy utility。把這些能力拆開，可避免一段視覺漂亮的 rollout 因單項表現好，就被誤升格為可驗證 simulator。

最重要的接點是 first-class state feedback。ai_core 若只接收畫面或自然語言敘述，每次決策前都得重新推斷世界結構，誤差會在 perception、memory 與 planning 之間累積。更穩健的介面應直接回傳有版本、可查詢、可驗證的 entity fields，並把 sensor estimates 與 runtime ground truth 分欄保存。這也讓憑證准入有具體標的：不是認證影片合理，而是認證某些 state variables 在指定 rollout horizon 與 tolerance 下可供下游可靠使用。
