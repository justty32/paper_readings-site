論文／訪談原始來源

PostDiag：替符號迴歸候選式診斷失敗方式

問題與介面

符號迴歸求解器以不同方式搜尋方程式，卻常用單一誤差分數排名候選；分數本身難以指出哪個局部行為不符。PostDiag 將診斷核心與搜尋分開，輸入求解器給出的式子骨架和觀測資料，輸出風險座標、局部證據與修訂骨架。它不自行產生初始候選，也不讀求解歷程；整合仍需各求解器的 adapter。（§1、§3.1、附錄 F）

局部特徵與兩軸風險

訓練資料先分成係數擬合集與診斷用 audit 集。輸入正規化後，以最遠點取樣選錨點，再在 audit 集以 k 近鄰構造可重疊局部區塊。每塊的 PFP 指紋包含平均值 level、局部最小平方斜率向量 trend、扣除局部仿射近似後的均方根殘差 roughness；比較預測與觀測的指紋，保留位置與三種差異。（§3.1–3.2）

表達風險 Bias 是各區塊擬合式與觀測指紋差異的加權平均；穩定風險 Var 則將同一骨架在擬合集多次 bootstrap 重擬，觀察各 audit 區塊上的指紋變動。這些是行為診斷指標，並非真實結構的直接判定。風險平面用低／高 Bias 與 Var 分別對應保留或微修、修補、簡化、重寫；局部證據指出哪裡和哪種特徵有差異。（§3.3）

介入與接受條件

低成本 NMSE gate 排除誤差極低與極高的候選，將中間候選交給診斷。LLM 編輯器依風險狀態及證據提議骨架；新式子在擬合集重新擬係數，只有 audit 誤差下降才接受，否則保留原式。論文指出 GP adapter 將接受式放回族群，LLM 求解器則透過各自介面取得修訂與診斷；附錄 F 的 LaSR 概念抽象及 SR-Scientist 工具介面顯示整合細節依求解器而異。（§3.4、附錄 F）

實驗設計與成本

LSR-Synth 有 129 個任務，涵蓋物理 44、材料 25、化學 36、生物 24；每題 5,000 點，訓練 4,000、ID 測試 500、OOD 測試 500。OOD 為時間或溫度較大的區間；兩個測試集只在搜尋結束後評估，不用於診斷或接受修訂。預設訓練資料再分 75% 擬合與 25% audit；64 個區塊、每塊 64 近鄰，三個特徵權重 0.4／0.4／0.2，穩定性用 3 次 bootstrap 重擬，兩個閾值由少量保留任務的初步實驗設定。（§4.1、附錄 A）

主表比較五個 LLM 求解器及 PySR、gplearn，各配對固定基礎搜尋預算與種子，統計三 seeds。PostDiag 的額外診斷、重擬與 LLM 介入不從基礎搜尋預算扣除，但計入端到端 wall-clock；因此這是相同原生搜尋預算比較，不是相同總計算量比較。主表 LLM backbone 與 GP 的 PostDiag 編輯器使用 Qwen3.5-27B。（§4.1、附錄 D）

結果與界線

作者自報主表 ID 整體 \(Acc_{0.01}\)：LLM-SR 22.0%→31.0%、SR-Scientist 25.6%→35.7%、PySR 23.8%→28.7%；每題平均時間依序為 167.5→191.7、648.0→702.2、8.8→10.5 秒。\(Acc_{0.01}\) 要求測試點最大相對誤差不超過 1%；時間是含兩種方法全部開銷的每題平均，不能稱加上診斷後 wall-clock 一定更快。（表1、§4.1）

同一 27B 設定的 OOD 整體 \(Acc_{0.01}\)：LLM-SR 21.2%→28.9%，SR-Scientist 24.8%→33.6%；gplearn 與增強版均為 0%。符號等價評分在去掉擬合常數後，以模型十次判斷及人工處理非一致案例，gplearn 仍為 0%，Direct LLM 27B 維持 1.55%；數值精度提升不等於皆恢復正確符號結構。（附錄 E、表2、附錄 G、表4）

作者以人工構造四種骨架與資料配對檢查診斷，欠擬合與錯配在穩定性邊界有重疊；消融比較顯示完整版本在四個測試求解器的所報指標最佳。評估僅限 LLM 與 GP 類求解器，缺少接受修訂介面的強化學習等方法可能需要較大調整；作者也將降低診斷與介入成本列為後續方向。（§4.3–4.4、§5）
