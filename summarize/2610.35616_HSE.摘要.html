論文／訪談原始來源

Hierarchical Skill Evolution for Coding Agents 重點摘要

來源註記：同一 arXiv v1 摘要頁 題名末尾是單數 Coding Agent，其作者 metadata 將 Shiyang Zhang Yuhua Zhou、Baian Chen Weiyi Shang 各接成一名；HTML 全文 題名為複數 Coding Agents，並將兩對姓名分列。兩頁 ID、版本及摘要方法內容一致；本檔沿用全文的題名和分列方式，不判定哪個欄位正確。

一句話概括

HSE 將程式 agent 的任務軌跡先按任務、再按 repository、最後跨 repository 彙整為程序與復原技能，並用外部 writer／evaluator 管理技能演化；作者報告凍結技能可轉移到所測基準，另以目標基準自身軌跡更新技能得到更高分，但後者不是未接觸目標任務的泛化測試。

方法

編碼模型保持凍結，輸出軌跡與外部技能分開。訓練時，L1 以重現、定位、編輯、驗證及復原五階段整理可見工具互動，並接收任務驗證器結果；跨輪次由失敗轉成功或成功轉失敗分別形成較強的正、負證據，沒有配對結果的首輪視為弱證據。（§4.1）

L2 在同一 repository 彙整重複訊號，形成具觸發條件、證據門檻、行動、驗證與停止條件的候選。L3 將跨 repository 支持的成功程序去除特定識別資訊，形成可轉移程序技能；另一分支將反覆出現的失敗訊號轉成復原技能。外部 writer 撰寫候選，evaluator 根據支持與風險決定接受、修訂或拒絕。（§4.2～4.3）

訓練期間，writer 規則與 evaluator 的證據權重依後續結果和晉級回饋更新，evaluator 的決策門檻固定；驗證失敗則保留先前接受的演化狀態。訓練取自 SWE-Gym 500 題，其中 474 題屬十個訓練 repository，26 題來自獨立的 bokeh 驗證 repository。靜態測試只把凍結技能送給 agent；目標基準適應則使用目標任務軌跡更新技能庫，writer／evaluator 規則保持固定。（§4.4～4.6、附錄 E.1）

作者自報結果

靜態技能由 SWE-Gym 演化出的 10 個技能組成，其中 8 個程序技能、2 個復原技能；靜態測試不使用目標基準軌跡。SWE-bench Verified 有 500 題，DeepSWE 有 113 題；解決率為通過各基準驗證器的比例。表列 GLM-5.2 三次完整運行的平均及樣本標準差，非三次中至少一次成功的 pass@3。（§5.1、附錄 E.2）

基準／harness 無技能 靜態 HSE 差距（百分點）
SWE-bench Verified／Pi 73.5±1.10% 75.4±0.20% +1.9
SWE-bench Verified／Claude Code 76.1±1.30% 80.6±0.20% +4.5
DeepSWE／Pi 43.1±2.23% 48.7±0.88% +5.6
DeepSWE／Claude Code 44.8±3.11% 52.5±0.51% +7.7

作者亦在 Pi 上將同一技能包用於 GPT-5.5、Opus 4.8；前者在兩基準分別由 82.6 → 85.4%、67.2 → 73.5%，後者由 88.6 → 90.2%、59.3 → 61.1%。跨模型結果只在 Pi 測試，不能推定同樣結果適用所有 harness。（§5.4、表 6）

目標任務適應與靜態轉移不同

作者進行固定八輪適應：每輪完整執行目標基準任務，使用其軌跡更新技能庫，再在同一完整目標任務集合上評估；目標任務的 benchmark verifier 結果只用於報告解決率，不提供給 writer／evaluator 作候選評估回饋。SWE-bench Verified／Pi 從靜態 75.4% 至第八輪 90.1%，DeepSWE／Pi 從 48.7% 至 71.7%。這是接觸目標題目軌跡後的同集合適應結果，不能與未接觸目標軌跡的靜態分數作同等泛化聲稱；未提供 verifier 回饋也不代表未見任務內容或軌跡。（§5.2、表 2、附錄 E.2）

消融與成本

靜態技能組移除程序或復原技能，各設定的解決率均降低。DeepSWE／Pi 中，完整 HSE 48.7%，去除程序技能 45.1%、去除復原技能 43.4%。另一消融把軌跡跨 repository 隨機打亂，以相同軌跡與證據預算破壞原本的階層彙整；固定初始 writer／evaluator 則測試整組控制器更新機制，不能分別識別 writer 與 evaluator 更新的獨立效果。（§5.3、表 3～4）

成本以每題一條軌跡的文字字數估算，不是 token 或實際費用。HSE 注入技能平均約 0.5K 字，SWESkillsBench 約 1.5K 字；含反覆歷史的總字數下，HSE 在四個設定均高於無技能。較小初始技能包因此不代表相對無技能的總上下文成本更低。（附錄 A、表 7）

作者列出兩基準、兩個 harness、三種模型的範圍限制；僅三次運行的平均與標準差也不能單獨建立小差距的統計顯著性。技能是否適用於新任務仍依賴當前程式與測試證據，不能從歷史軌跡直接複製修補。（§6、附錄 C.9）
