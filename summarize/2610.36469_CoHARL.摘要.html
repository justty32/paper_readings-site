論文／訪談原始來源

CoHARL: Co-Evolving Agent Policies and Executable Harnesses with Reinforcement Learning 重點摘要

一句話概括

CoHARL 同時以強化學習更新共享 agent 策略，並根據執行軌跡修改一組可執行 harness；不同 harness 收集的經驗共同訓練策略。作者在軟體工程和終端任務中報告提升，但實驗使用單次訓練，搜尋與驗證的額外成本亦未完全匹配。

方法與評估邊界

Harness 管理提示、動作解析、工具回傳與 episode 控制。CoHARL 讓較強的 proposer 參考目前策略的成功與失敗軌跡、先前嘗試及歷史準確率—生成 token 成本紀錄，修改 harness 程式；候選經領域專屬檢查與試用後，在訓練步驟邊界加入池中。排程器依任務難度調整的經驗分數分配 rollout，並給新版本強制試用與最低使用保護。所謂下信心界是啟發式懲罰，並非校準的統計信賴區間；歷史 archive 的分數也不會隨當前策略更新而自動刷新。（§3.2）

每組相同任務及 harness 的 rollout 使用組內相對獎勵來更新同一個策略；只有模型生成 token 進入 loss，工具觀察作為上下文。SWE 訓練獎勵包含測試正確率、部分須提交才計算的過程獎勵和長度懲罰，篩選群組另用 test_score；不同 harness 的篩選分數可能含過程獎勵，因此保留群組不一定含完全解題的 episode。評估則要求 fail-to-pass 全通過且 pass-to-pass 持續通過，並非用 LLM judge。（§3.1～3.4、附錄 C.1）

理論分析指出：在同任務、同 harness 組內，若 \(K\) 個二元結果條件獨立且成功率為 \(p\)，獎勵不全相同的機率是 \(1-p^K-(1-p)^K\)；低成功率時近似 \(Kp\)，但超過一半後成功率增加可能減少對比。這只是說明組內學習訊號的條件式直覺，並非收斂速度保證，也不能直接套用 SWE 的複合篩選分數。（§3.3、附錄 A）

作者自報結果

在 SWE-rebench，作者使用 2026 年前任務訓練、2026 年 3 月後的 110 題評估，以每題三次嘗試的平均解題率（avg@3）比較：初始 Qwen3.5-35B-A3B 與 SWE-mini 為 17.3%，固定策略的 Meta-Harness 重現為 21.2%，固定 harness 的 Plain GRPO 為 20.3%，CoHARL 為 27.6%。訓練採 rank-32 LoRA，主實驗 150 步、每步目標 48 rollout，最多八個 harness；proposer 為 Claude Opus 4.7。（§4.1～4.2、表 1）

不再適配地將 SWE-rebench 訓練結果用於 SWE-bench Verified 500 題、每題一次時，CoHARL 得 59.8%，Meta-Harness 52.0%，Plain GRPO 49.8%，初始配置 44.2%。這是跨資料集評估，但作者指出預訓練污染仍可能存在。Terminal-Bench 2.0 使用另行訓練的 agent，CoHARL 36.8%、harness-only 33.7%、初始 26.6%；每題先對回傳 episode 平均，沒有回傳的題記零，並非從 SWE 零樣本轉移。（§4.2、表 2～3；附錄 E）

另做獨立的 30 步訓練預算對照，在相同 110 題各嘗試一次：完整 CoHARL 28/110（25.5%），固定 harness 22/110（20.0%），先搜尋再固定 harness 做 RL 25/110（22.7%），單一 harness 交替修訂與 RL 21/110（19.1%）。移除 archive 或軌跡的版本各為 20.0%、20.9%。這些是單次訓練的結果，無信賴區間；相同訓練步數與 rollout 預算不等於搜尋和總運算匹配：完整方法及部分對照搜尋 8 次，單一 harness 7 次，固定 harness 不搜尋。（§4.3、表 4；附錄 C.1）

成本與完整性限制

150 步 SWE 主實驗中，CoHARL 與僅 RL 的訓練 episode 數相差不到 1%，harness 驗證約增加 10% 開銷，proposer 推論另計；作者未提供完整總計算成本比較。另一次 30 步消融不能直接套用這些成本比例。（附錄 C.1）

為減少修改 harness 洩露隱藏測試，初始 harness 禁用注入並設 gate 檢查提案。主實驗中檢視的五個已接受版本未發現隱藏測試存取；另一次固定策略搜尋中，六個試圖恢復存取的提案均被拒絕。作者指出程式檢視不能排除其他資訊通道，六次拒絕也不能估計一般攻擊成功率；訓練仍使用標量任務獎勵。（附錄 B）

作者另指出反覆驗證可能使 harness 選擇過擬合，固定動作格式限制可探索的修改，且未分開測量 proposer 品質或在共同 harness 下的策略提升。有限訓練次數及未完全匹配的搜尋成本，使結果應視為所測設定的證據，而非普遍因果結論。（附錄 E）
