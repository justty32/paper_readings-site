論文／訪談原始來源

《以共形棄答緩解 LLM 幻覺（Mitigating LLM Hallucinations via Conformal Abstention）》重點摘要

一句話概括

Conformal Abstention（共形棄答）：用 LLM 自評（self-evaluation）多次取樣回應之間的一致性作為信心分數，再以共形預測 / 風險控制（conformal prediction / risk control）校準一個棄答門檻 λ，讓「不確定就說『我不知道』」這件事帶有分佈無關（distribution-free）、對幻覺率（錯誤率）的嚴格統計上界 R(λ)≤α；純靠 prompting、不需微調，只要一個很小的校準集即可保證上界成立。

解決什麼問題

LLM 會自信地生成看似合理卻錯誤的幻覺，而直接用回應序列的（log-）機率當信心度會隨輸出長度變差、與正確性脫鉤。既有以「取樣回應一致性」偵測幻覺的工作面臨兩個未解問題：(i) 如何判斷兩個回應對某問題是否等價；(ii) 一致性低到什麼程度才算幻覺——且這些方法多只報 AUC 類指標，不給「該如何實際選定棄答策略」的可操作準則，更無統計保證。本文同時解掉這兩點。

核心方法

  • 問題形式化：以 score-based 棄答策略 a_λ(X)=1[g(X)<λ]（分數低於 λ 就棄答，否則輸出預設回應 f(X)）；風險 R(λ)=E[(1-a_λ)(1-m)]（未棄答又答錯才計損失），在 R(λ)≤α 下最小化棄答率 T(λ)，等價於找滿足上界的最小 λ*。
  • 信心分數 g（三種）：對查詢生成 k 個回應，用 LLM 自我 prompting（conditioned on 問題 X） 評相似度——**match count（m.c.）**＝與參考回應相似的其他回應數；**expected match count（e.m.c.）**＝一次 prompt 問「有幾個相符」並用計數 token 的 log-prob 取期望（更細緻但非黑箱）；並取 greedy（零溫度）回應當參考、再抽 k−1 個高溫樣本的 greedy 版以省 O(k²) 成本。
  • 校準 λ（核心保證）：以 Conformal Risk Control（CRC, Angelopoulos et al. 2024） 取 λ̂ₙ = inf{λ : n/(n+1)·Lₙ(λ)+1/(n+1) ≤ α}，保證 E[R(λ̂ₙ)]≤α；證明 CRC ≡ 對 Hoeffding UCB 的 RCPS（Bates et al. 2021），但用 O(1/n) padding 而非信賴區間法的保守 O(1/√n)。另給高機率版：RCPS 三種 UCB（Empirical Bernstein、Hoeffding-Bentkus、Bernoulli-KL）與 CRC 的 Markov 放大（P(R≤e·α)≥1−δ）。
  • 第二貢獻：校準 match 函數 m：自動評測需判斷兩回應是否等價；用共形預測選相似度門檻 β̂，保證代理損失 L₂ 為真實錯誤數 C 的近似上界（E[C]≤E[L₂]+α）——作者稱這是文獻首見、可獨立使用。

結果

  • 模型與資料：用 Gemini Pro；Temporal Sequences（BIG-bench，含長答案，4000 題）與 TriviaQA（短答案，1000 題）；δ=0.05。
  • 長答案（Temporal Sequences，α=0.05/0.1）：match count / expected match count 在相同風險下棄答率顯著低於 log-probability 基線——證實 log-prob 分數對長輸出不可靠；CRC 與 RCPS 差異極小。
  • 短答案（TriviaQA，α=0.1/0.2）：log-prob 與 m.c./e.m.c. 表現相當（各有互勝）——故 match-count 類方法長短皆宜、為較穩健之選。
  • 校準有效性：未校準的 Baseline 在小校準集時會違反風險上界，而 CRC/RCPS 守得住；Empirical Bernstein 因非為 Bernoulli 特化而較差。match 函數校準：TriviaQA 用 recall 門檻 0.5（100 樣本 0 錯），Temporal Sequences 用 LLM 自評 1–10 分門檻 β̂=7（100 樣本 4 錯）。

局限

  • 保證依賴校準集與測試點可交換（exchangeable / i.i.d.）——分佈偏移下上界失效；跨領域（out-of-domain）未處理。
  • 上界是對「棄答後」殘餘幻覺率的保證，偵測不到 LLM「完全確信卻錯」的情形（自一致性無法揭露）。
  • m.c. 原生需 O(k²) 次額外推論；e.m.c. 需存取 log-prob（非純黑箱）。
  • match 函數與棄答策略均需人工標註的小校準集；且保證多為期望值版，高機率版更保守（棄答率上升）。

對讀者的價值

  • 直擊 ai_core §3.4「治理＝拒絕為預設＋憑證准入」：本篇把「拒絕（棄答）為預設」升級為帶分佈無關統計上界的准入門檻——R(λ̂)≤α 正好可當一張可驗證的治理憑證，讓「這個 LLM 節點的殘餘幻覺率 ≤ α（信心 1−δ）」成為讓輸出通過的量化准入條件，而非靠拍腦袋的 confidence threshold。
  • 與已入庫 1705.08500 選擇性分類（風險上限下的棄權）同源、更進一步給共形版分佈無關保證；與 backlog 的 2402.10978 conformal factuality（在事實層級做共形校準）成一條「用共形預測給 LLM 可靠性硬保證」的線——歸 I 類。
  • 對「把 LLM 呼叫包成可靠函數」的北極星：本篇示範了如何在函數邊界上釘一個統計 SLA（棄答率 vs 保證錯誤率的可調 trade-off），是把不可靠 LLM 節點納入確定性計算圖時的准入閘門範本；且純 prompting、小校準集、不動模型，落地成本低。
