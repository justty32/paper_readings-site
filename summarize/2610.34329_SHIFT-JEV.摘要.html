論文／訪談原始來源

SHIFT-JEV：分布轉移下的棄權與持續適應

核心問題與結論

把 LLM 作為選項決策模型時，分布、標籤比例、新類別或候選選項可能改變；高信心不代表答對。本文在 LLM-as-Jev 的選項機率介面上加上監測、風險控制棄權與有回退的持續適應。實驗發現，校準資料和風險分數影響棄權效果，漂移路由幫助有限；重播與依嚴重度調整的錨定是小模型持續學習收益的主要來源，gain gate 則避免無用更新。以下數字均為作者自報，並非本工作區重現。（§1、§6）

方法：監測、棄權與更新

決策介面列出編號選項，對 identifier suffix 用 prefix-free trie 評分，以 ID validation 擬合溫度；樹形 attention mask 打包評分。LoRA 微調採樹狀交叉熵與 KL anchors。監測訊號包含熵、最大機率、前二名差距與選項數、合法 token 機率質量，以及旋轉選項後的分布與答案一致性；旋轉須額外評分，因此只用於 0.6B。state-only embedding 的 k-NN 距離不受選項變更影響，並供路由與串流偵測；CUSUM、KS 與預測標籤直方圖的卡方測試偵測不同轉移。（§3.2–3.3、附錄 A）

棄權的 logistic risk model 使用不確定性、格式及一致性，ID 與 SciQ／Emotion 代理轉移校準資料的第一半用來擬合模型與提名門檻，第二半固定順序檢驗。Clopper–Pearson 單側上界低於目標風險 α 才通過，遇首個失敗即停；無門檻通過則全部棄權。已知 regime 擁有自己的參考池與門檻；未知輸入或警報後採 ID 與代理門檻中較嚴者。漂移距離用於路由，不進風險分數。（§3.4）

論文命題的範圍是同一 regime 的校準資料與新測試點可交換，且模型和候選門檻只依第一半選定：此時以至少 1−δ 的機率，該 regime 答覆項目的母體錯誤率不超過 α。δ=0.1；這不是保證每個有限測試集、未知轉移或警報後實際錯誤率必然達標。未知轉移只報實測違規。保守 fallback 也不自動帶來未知分布的有效性。（§3.4、附錄 B；未知轉移界線依原文及本檔補註）

新 regime 有標記資料後，模組 C 以漂移與準確率檢定衡量嚴重度；訓練新資料與舊 regime 重播，對前一模型做局部蒸餾及 KL 錨定。嚴重度越高，KL anchor 權重指數下降而蒸餾權重上升。半程探測在未驗證轉移且新模型勝數不超敗數時提早停止；半程與全程候選各須對 80 個新 regime 留出樣本的配對正確性做單側 sign test，p<0.10，且舊 regime 驗證準確率下降不超過 5 個百分點；選新舊準確率平均最佳的合格候選，否則回退。無論是否更新都納入新 regime 參考池與重新認證門檻。（§3.5、附錄 B）

作者的 false acceptance 界限是單個無益候選至多 0.10；兩候選的聯合上界是 0.20，不能把單候選數字當整輪保證。舊資料保留亦是有限驗證集合上容許至多 5 個百分點下降，不等於所有舊資料都不退化。（附錄 B；後句為本檔補註，非作者自陳）

設計與分母

ID 有 AG News、SST-2、BoolQ、ARC-Challenge，SciQ 與 Emotion 僅作代理校準。十個測試轉移涵蓋三 domain、兩 AG News 類別先驗、CLINC150 新類別及四種候選變化；移除正解改變任務，故每個回答都錯。棄權主表以九個轉移環境 × 三 seeds＝27 個 environment–seed 測試／α；共享測試項使違規數僅描述性統計。Qwen3-0.6B 與 Qwen3-4B-Instruct-2507 三 seeds，Phi-4-mini 只凍結評估；串流、擾動與適應後可靠性等分析用 seed 1。四階段依序 Banking77、無轉移對照、Twitter-Fin、CLINC-OOS；各階段 300 訓練、260 留出（80 gate、20 buffer validation、160 認證）。（§4、表2、表6）

校準、棄權和監測結果

Frozen 0.6B 的 ID 準確率 73.3%，Banking77／Twitter-Fin 分別 18.4%／27.6%；4B 為 91.1%、55.4%／60.2%。微調加溫度縮放後，九轉移平均 ECE：0.6B 由 0.289 降至 0.087，4B 由 0.182 降至 0.078。這是底層 B2 加溫度的 B3 效果，不是棄權監測層改變預測。（§5.2、表5）

α=0.10 時，同 pooled LTT 下不確定性分數 B4 在 0.6B／4B 分別 5／3 次超標，最大機率分數為 15／5 次；split-conformal LAC 為 14／9 次，但它控制的是預測集合邊際覆蓋率，並非選擇性錯誤率。B5 分別答覆 33.3%／60.1% 轉移輸入，實測風險 5.2%／6.2%，違規 4／6 次。不同 coverage 下不能只拿違規次數當唯一指標。（§5.3、表6–7）

α=0.05 時 B5 多數 run 無可認證門檻；六個 Qwen run 中五個連 ID 也全部棄權，其零違規不代表有用的自動化。固定序列首項失敗會停止，作者報有一 run 後續候選原可通過。漂移路由對違規數改變很小；事後分析將 ID／代理門檻較嚴者套用所有輸入，α=0.10 時 0.6B／4B 為 3／2 次違規，但降低部分 coverage，須另行驗證，不是原 B5 設計。（§5.3、§6.2）

seed 1 的串流試驗中，滿嚴重度類別先驗轉移在預測標籤卡方測試的偵測率為 95%／99%（0.6B／4B）；信心與 embedding 訊號為 0–1%。但同一卡方測試在新鮮無轉移串流誤報 6%／10%，高於校準目標 5%。警報後切保守門檻也非總是改善：0.6B CLINC 違規串流由 20% 升至 38%，coverage 約 14% 降至 5%。（§5.4、表10–11）

持續適應與局限

四階段最終平均準確率，0.6B 的 Shift-Jev 為 70.48±0.88%，LwF 68.10%、replay 66.67%，其餘 fine-tuning、EWC、Seq-FT+KL 約 66.3–66.7%；三 seeds 均勝各 baseline。共享 1,600 個獨立測試項、每項先跨 seed 平均後的 item-level sign test 支持差異；只有三 seeds 的 seed-level 配對檢定不顯著。拿掉 replay 降 4.81±2.22 points，拿掉 gate 降 1.23±2.18 points、僅兩個 seed 較佳；故不應把收益全部歸給 gate。（§5.5、表12）

4B 的 gate 在全部三 seeds 拒絕 Twitter-Fin 更新，80 項上 2.5–7.5 points 的候選增益未達 p<0.10；最終平均 79.86±1.10%，低於 baseline 0.42–1.36 points，1,200 獨立項的差異不顯著。適應後 seed 1 再認證在 CLINC 得到 0.6B／4B coverage 44.5%／67.0%、風險 4.5%／3.5%；Banking77 全棄權，Twitter-Fin coverage 1.2%／7.3% 而風險 40%／27.3%，0.6B ID 風險 11.6%，顯示小型再校準仍脆弱。（§5.5、表13–15）

作者指出模型只到 4B、兩模型家族，先驗與候選轉移是合成的；4B checkpoint 與基礎論文不同，訓練混合也刻意排除測試轉移。設計曾依同一 benchmark 的早期結果修正，路由分析為事後分析；Phi-4-mini 額外訊號提高實測風險。更大留出與校準集、自然轉移及更多模型仍待驗證。（§6.2）
