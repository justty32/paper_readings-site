論文／訪談原始來源

《SMCEvolve：以序貫蒙地卡羅演化做有原則的科學發現》重點摘要

一句話概括

SMCEvolve 把 LLM 驅動的程式演化（AlphaEvolve/ShinkaEvolve 那一類）重構為「從獎勵傾斜目標分布 p(x|q) ∝ p₀(x|q)·exp(βR(x)) 取樣」的序貫蒙地卡羅（SMC）問題*——讓「父代選擇、突變、停止」三件原本各自手工設計的事，全部由單一溫度參數 βₜ 沿一條探索→利用連續譜統一導出，並給出首個程式演化的有限樣本收斂保證（定理 3.1）。三機制：(1) 自適應父代重採樣（依橋接分布重要性權重，早期近均勻探索、後期集中高獎勵）、(2) 帶接受的突變混合（四種 LLM 突變核 + Metropolis–Hastings 接受/拒絕 + Thompson 採樣挑核）、(3) 自動收斂控制（以有效樣本數 ESS 二分排程溫度、λₜ=1 時自動終止，免預設迭代數）。在數學/演算法/符號迴歸/AutoResearch 四域上以更少 LLM 呼叫達到等於或優於基線（如 Circle Packing N=21 達 0.9993 reward、192 次呼叫，勝 ShinkaEvolve 0.9514）。

解決什麼問題

LLM 驅動程式演化框架（AlphaEvolve、ShinkaEvolve）缺原則性理論基礎與收斂保證：(1) 父代選擇/突變/族群管理皆孤立手工設計、非由連貫原理導出；(2) 無收斂保證——系統分不清族群已收斂到高獎勵區還是只是停滯，被迫預設迭代數；(3) 資源利用低效，變異大、浪費算力。核心問題：能否把 LLM 程式演化奠基於嚴謹的機率框架？

核心方法（三機制）

  • 核心洞見：把程式搜尋視為對獎勵傾斜目標 p*(x|q) ∝ p₀(x|q)·exp(βR(x)) 取樣——把 LLM 先驗向高獎勵程式重新加權，平衡探索與貼合先驗。
  • 機制 1 — 自適應父代重採樣：父代依當前橋接分布的重要性權重重採樣，權重 Wₜ ∝ exp((βₜ−βₜ₋₁)·R)，早期 βₜ 小→近均勻（探索）、後期→集中高獎勵父代（利用）。對比既有系統全程固定選擇規則。
  • 機制 2 — 帶接受的突變混合：四種互補 LLM 突變核（M¹ 局部編輯+同儕啟發、M² 純局部編輯、M³ 全重寫+同儕啟發、M⁴ 純全重寫）；以 Metropolis–Hastings 接受機率 αₜ(x,x')=min{1, exp(βₜ(R(x')−R(x)))} 接受/拒絕；以 Thompson 採樣依近期成功率自適應挑核；每步多提案（K 次）助充分混合。
  • 機制 3 — 自動收斂控制：以有效樣本數 ESS 二分排程溫度（找 λₜ 使 ESS(λ)=κN），免預設總迭代 T；λₜ=1 時自動終止。
  • 理論（定理 3.1）：給出達到目標逼近誤差的有限樣本複雜度界 ℬ=Õ((ε⁻²∨κ⁻¹)/(1−ρ)·β·ΔR)，其中 ℬ=總 LLM 呼叫數、ε 誤差容差、κ 橋接規則性、ρ 突變核混合率、β·ΔR 獎勵強度——以高機率（≥3/4）逼近目標分布所需預算由問題難度與核性質明確參數化。

結果（四域）

  • 數學發現（10 題）：Circle Packing N=21 達 0.9993（vs ShinkaEvolve 0.9514），用 192 次呼叫（基線預算 200）。
  • 演算法效率（8 題）：convolve2d_full_fill 11.6× 加速（vs ShinkaEvolve 1.27×）；fft_cmplx_scipy 9.23×（vs 1.1×）；用 288–480 次（基線 500）。
  • 符號迴歸（16 題）：跨生物物理、化學反應、材料科學，普遍持平或勝過基線；平均 256–384 次（基線 400）。
  • AutoResearch（TinyStories 上 GPT 預訓練）：最高最終 reward，且在遠少於固定預算的呼叫數即自動終止。
  • 消融（Circle Packing）：均勻採樣 0.9514、貪婪 0.9760、自適應混合 0.9993；單核上限 0.9929、Thompson 混合 0.9993；廣度×深度 N=8,K=2（0.9993）勝 N=4,K=4（0.9379）與 N=16,K=1（0.9379）。效能提升伴隨算力降低，違反典型探索-利用權衡。

局限

  • 橋接規則性假設：ESS 二分是針對此條件的有限樣本機制，正式理論刻畫仍開放。
  • 僅獎勵的 MH 近似：黑箱 LLM API 無法算完整 MH 比值，採以獎勵為基的代理。
  • 有限樣本複雜度界可再收緊。
  • 框架聚焦單目標獎勵最大化，多目標/無獎勵情境未探索。

對讀者的價值

  • 本批 C 類的**「把 SR/程式發現奠基於機率取樣理論」代表**——與 2512.10849 Bayesian SR via SMC 同用 SMC，但 SMCEvolve 把 SMC 套到LLM 驅動的程式演化（不只 SR，還含演算法/AutoResearch），且首次給程式演化收斂保證。
  • 最值得記：程式搜尋＝對獎勵傾斜分布 SMC 取樣這個重構；單一溫度 βₜ 統一導出父代選擇/突變/停止；ESS 二分自動決定迭代數、免預設；以及「效能升、算力降」的反直覺結果。
  • 與 2606.07704 FunctionEvolve、2606.04360 Deliberate Evolution 等「演化式發現」對讀：別人多手工設計演化算子，本篇用 SMC 理論把它們統一並給保證。亦與 2604.17402（GP-SR 泛化界限）對讀：兩篇都在給 SR/演化「理論保證」，一個談泛化、一個談搜尋收斂。
  • 定位：方法 + 理論 + 多域實證；適合做 LLM 程式演化、SMC/重要性採樣、自動科學發現、SR 搜尋的人。
