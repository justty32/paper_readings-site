0. ai_core 的北極星，一句話重述

ai_core（（內部參照））主張把系統建成一張符號神經網路計算圖：多數節點是確定性程式，少數節點是 LLM；貴稀有智能是「資產工廠」、便宜高頻智能是「資產消費者」；治理原則是拒絕為預設＋憑證准入；第一目標是程式碼助手（上層結構化抽取生資產、下層受約束填碼）；最硬的未決問題是固化引擎——把 LLM 反覆處理的案例結晶成確定性程式碼／抽象庫。

把這張藍圖拆成六個問句，正好對應本批文獻的六大簇：

1. §1 計算圖怎麼被優化——從「比喻」到「可運行的反向傳播」

ai_core 說系統「像」符號神經網路計算圖。本簇文獻把這個比喻一路推到可運行的優化演算法，構成一條清楚的演進線：

  • 源頭・把多次 LLM 呼叫看成一個東西：2207.10342 Language Model Cascades 把「思維鏈、工具使用、多輪自評」統一成機率程式——這是「調用鏈＝計算圖」比喻最早的形式化，但它只談推理，不談優化。
  • 第一次讓圖可編譯、可自我改進：2310.03714 DSPy 把 prompt 從手寫字串抽象成 signature/module，用 teleprompter「編譯」出示範與指令——計算圖第一次有了「編譯器」。
  • 把節點與邊都變成參數：2402.16823 GPTSwarm 明確把 agent 系統寫成圖（node＝操作、edge＝資訊流），同時優化 node 級 prompt 與 edge 級拓撲（用 REINFORCE 學連線分佈），且能自動剪除無用／對抗 agent——這幾乎是 ai_core §1 的逐字對映，連「拓撲層治理」都做到了。
  • 把「梯度」講清楚：2406.16218 Trace 提出 OPTO 形式化，把整個 workflow 的執行 trace（含 console 錯誤、自然語言回饋）當廣義梯度，用單次 LLM 呼叫的 OptoPrime 更新異質參數（prompt／程式碼／超參）；2406.07496 TextGrad 則給出 PyTorch 式 API（Variable/backward/step），讓自然語言反饋沿圖反傳，通用到 prompt、程式碼、分子、放療劑量。
  • 連結主義類比的極致：已入庫的 2406.18532 Agent Symbolic Learning 把 prompt＋工具＋pipeline 全當「權重」，用自然語言模擬 loss／gradient／optimizer 做整體聯合優化——與 Trace／TextGrad 幾乎同構，差別只在它更強調「語言損失」可無監督。

對 ai_core 的落點：§1 不缺形式化了——OPTO（Trace）是目前最乾淨的「計算圖優化」數學框架，TextGrad 是最順手的工程樣板，GPTSwarm 補上「拓撲也是參數」。但要提防一個共同前提：這些框架的節點目前多半仍是 LLM，優化的是「怎麼問 LLM」；ai_core 的野心相反——是要讓節點逐漸變成確定性程式。所以這簇是「§1 的優化層」現成可用，真正的差異化仍在 §3.6 固化。

2. §2 / §3.3 貴便宜怎麼分工與換擋——成本梯度的三種尺度

ai_core 的「資產工廠 vs 資產消費者」與「成本梯度」在文獻裡分裂成三個尺度，彼此正交、可疊加：

關鍵洞見來自 2006.07512 FrugalML 與其後身 2305.05176 FrugalGPT 的落差：FrugalML 在「輸出是有限標籤集＋有信心分數」時，能證明最優策略 2-稀疏並解到帶保證的最優；一旦搬到 LLM（輸出是整個自然語言空間、無現成品質分數），FrugalGPT 只能退回啟發式 scorer，最優性保證就丟了。這正劃出 ai_core §3.4 的核心工程問題：「憑證／穩定度%」這個品質分數要從哪裡可靠地生出來——沒有它，成本梯度就只是啟發式。2310.12963 AutoMix 給了一個答案：讓小模型自我驗證（few-shot 蘊涵式、取樣一致比例當信心）再用 POMDP 決定升級，且把 POMDP 離線解成 <1ms 查表（本身就是一次小型固化）；2406.18665 RouteLLM 給另一個答案：用人類偏好資料離線學一個路由器。

2.2 token 尺度：推測解碼（同一次生成內部的成本梯度）

同一條「猜便宜、驗可靠」的梯度，可以下沉到單次解碼步：

  • 1811.03115 Blockwise Parallel Decoding（2018）是源頭——輔助頭並行猜 k 步、主模型一次前向驗證取最長吻合前綴，輸出等同貪婪解碼。
  • 2211.17192 推測解碼把 draft 換成獨立小模型＋拒絕抽樣，保住原分佈。
  • 2401.10774 Medusa 讓草稿頭長回主幹上（免獨立模型）、tree attention 一次驗證多候選。
  • 2401.15077 EAGLE 把外推搬到 feature 尺度、用錯位 token 消不確定性，做到幾乎免費且可證明無損。

對 ai_core 的落點：token 尺度是「便宜端能做到多便宜」的極限案例，且全都無損——它示範了「昂貴確定性驗證＋便宜推測生成」正是「多數確定性節點＋少數 LLM」在最小尺度上的化身。ai_core 的驗收契約可借鑑其「驗證器一次性檢查整批草稿」的批次結構。

2.3 生命週期尺度：把貴智能一次性沉澱成便宜資產

最徹底的成本梯度是部署期完全不用 LLM：

  • 2305.02301 Distilling Step-by-Step 抽 LLM 的 rationale 當多任務監督訓小模型，770M 勝 540B 且測試期零 LLM——「資產工廠→資產消費者」最乾淨的一次性蒸餾。關鍵設計「理據當輸出而非輸入」正是脫離 LLM 的開關。
  • 2305.17126 LATM 是同一分工的線上版：貴模型造一次性工具、便宜模型高頻使用。
  • prompt 本身也是可離線煉的資產：2211.01910 APE、2309.03409 OPRO 把「寫指令」當黑箱優化，一次煉好、之後廉價復用。
