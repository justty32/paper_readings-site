6.1 修正一：品質分數不再是缺口，是選型問題（且 gate 本身要夠便宜）

初版說「可靠品質分數是 §2.1 成本梯度與 §3.4 治理的同一個 missing piece」。這句話仍對，但它現在有了完整的方法光譜——分三條互斥的技術路線，按你能不能碰到模型內部與願不願意多次取樣來選：

graph TD
    Q{"要一個品質/信心分數"} --> B["只有 API（黑箱）"]
    Q --> W["拿得到隱藏狀態（白箱）"]
    B --> B1["多次取樣比一致性<br/>語意熵 [[2302.09664]]<br/>SelfCheckGPT [[2303.08896]]<br/>成對相似度 [[2506.00245]]"]
    B --> B2["問模型自己<br/>P(True)/P(IK) [[2207.05221]]"]
    W --> W1["內部表徵<br/>INSIDE [[2402.03744]]"]
    W --> W2["把貴分數壓成便宜探針<br/>SEP [[2406.15927]]"]
    B1 -.成本 N 倍.-> C["再決定粒度與保證強度"]
    B2 -.自簽憑證風險.-> C
    W1 --> C
    W2 --> C
    C --> G1["粒度：逐主張 [[2410.13246]]"]
    C --> G2["從分數升級為證書<br/>PAC/FDR-E [[2307.09254]]<br/>conformal [[2402.10978]]"]

四個對 ai_core 直接可用的判斷：

  1. 黑箱路線（一致性）最通用但成本是 N 倍取樣。2302.09664 語意熵的關鍵是先用 NLI 把答案聚成語意等價類再算熵（不是 token 熵）；2506.00245 進一步指出「硬分群」對邊界樣本脆弱，改用連續的成對相似度，並證明語意熵是其特例。2303.08896 SelfCheckGPT 則完全不需 token 機率，最適合套在外部 API 型 LLM 節點上——ai_core 若用第三方模型當節點，這是唯一能用的一類。
  2. 模型自評（P(True)/P(IK)）便宜，但它是自己簽自己的憑證。2207.05221 證明自評確實有訊號、且隨模型變大更準，但這與 2401.10020 Self-Rewarding 暴露的污染風險是同一件事的兩面。結論：自評只配當便宜預篩 gate，不能當准入憑證的最終依據。
  3. 「gate 必須比它省下的更便宜」現在有解。2406.15927 SEP 把要 10 次取樣的語意熵壓成單次生成隱狀態上的線性探針，推論成本近乎零；2311.08692 Zooter 在路由端做同一件事——把「跑完所有候選再用 reward model 排序」壓成 86M 只看 query 的路由器。這兩篇是同一個母題的兩個實例，值得當作 ai_core 的通用設計手法：任何昂貴判斷都應該問一句「能不能蒸餾成單次前向」。
  4. 分數可以升級成證書。2307.09254 用文字蘊涵取代精確比對定義 FDR-E，讓棄權門檻帶 PAC 保證 P(FDR-E≤ε)≥1−δ；2402.10978 提供第三選項——不拒答而是降級輸出（逐步剔除不可靠子主張，換取 1−α 的事實性保證，FActScore 30%→80%）。對 ai_core 的意義：憑證上的「穩定度%」不必只是一個浮點數，可以是有統計保證的證書；而治理動作也不必是二元的放行/拒絕，放行／降級／拒絕三選一更實用。
  5. 粒度不能停在整段。2410.13246 證明整段校準良好不蘊含逐項校準良好——長輸出裡對錯混雜，整段一個分數在實務上不可用。逐 atomic claim 校準正好接上 §5 的上層結構化抽取：先拆成可逐項驗證的資產，再逐項准入。

選型導航另見 2412.12767 黑箱校準綜述（信心估計→校準→量測三層分類），可當方法目錄。

FARM 為白箱路線補上一個具身例子：只讀凍結世界模型的內部預測狀態，用小型 readout 產生逐步因果風險，支持「昂貴表徵可蒸餾成常駐便宜 gate」；但它在完全未見任務上不一定勝基線，且尚未把分數接到任何介入策略。因此 §6.1 的選型表還要把「偵測是否可轉移」與「觸發後是否真能降低失敗」分成兩次驗收（本檔補註，非作者自陳）2609.11445。
