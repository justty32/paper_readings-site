10. §8.1 三個缺口的結案判定與下一批方向

§8.1（2026-07-22）點名三個缺口並據此開了五個搜尋方向。本節逐條結案。

§8.1 缺口 判定 依據
1. 技能庫／抽象庫的退役與收斂機制 ✅ 結案 五條機制互異、原則收斂的路徑：閾值式 2605.22148／健康診斷式 2605.13716／合約違反式 2605.10990／生態動力學式 2606.01314／策展式 2605.294402604.03964；綜述 2607.10113 給出生命週期形式化，2605.24050 給出不退役的量化代價

三個最該記住的新結論：

  1. 「編譯」不是單一形態，§1 與 §3.6 已合流。原本的線性順序（先優化圖、之後才固化節點）被推翻——整張圖可以一次編譯掉，產物可以是程式碼、權重、配置集或邏輯圖，各有不同的重編譯成本與可稽核性。
  2. 便宜端的極限比想像中低很多。token 尺度的推測解碼光譜顯示便宜端可以一路退到檢索資料庫與 N-gram 統計（2311.082522308.04623），這是 §3.6 固化引擎在毫秒尺度上的預演——「用確定性資產取代神經網路」在每個時間尺度上都成立。
  3. UQ 沒有領域通用解。2604.22985 在工具呼叫上反轉了「多樣本一致性優於單樣本」、2605.28500 顯示 NLI 聚類在程式碼上直接失效——每個節點類型都要自己定義「什麼算等價」，這是 §6.1 三分光譜之上多出來的一層選型。
  4. 每一種「更可靠」的機制都要自己被審計。約束器可能不完整（§6.3）、可能是攻擊面（2606.11817）；技能庫可能宣稱重用但實際重用趨近於零（2410.20274）；快取可能與壓縮互相拆台（2607.15516）。共同教訓是憑證必須被驗證是否真的兌現，不能以「機制存在」代替「機制有效」。

2026-09 補證：審計要涵蓋檢查器、資料代理、准入覆蓋與輸入鏈

Where the Verifier Fails 直接拆開「有 verifier」與「verifier 可靠」：同一輸入在四個實作的自我驗證率相差 41.3 個百分點，同一函式庫兩種設定也有 49.9% 的判決不一致（作者自報）。這不是否定可執行檢查，而是要求憑證保存 verifier identity、version、抽取設定與 runtime，並用 metamorphic tests 分開量測 coverage、false negative 與 false positive（本檔補註，非作者自陳）2609.01354。

R2S-Eval 對代理評估給出同樣的層化正證：先驗證校準模擬器能否保留真機策略排名，再以人類偏好與位置反轉測試 VLM judge，最後才聚合 pairwise 排名。它支持的是相對策略結論，不是 real 與 sim 的行為等價，故「代理已校準」也必須寫清楚證書保護的命題範圍（本檔補註，非作者自陳）2609.03276。

Update Admission 揭露准入審計的另一個盲點：永遠不放行的 gate 可以讓「已接受更新的違規率」完美，同時完全凍結學習。因此憑證還要記 defer、證據預算、risk–coverage 與 missed opportunity（本檔補註，非作者自陳）；本文的具體數字來自合成的一步模型，應視為負向單元測試，而不是已驗證的機器人學習配方2609.10873。

語音管線則證明單一模組通過驗收仍不足。乾淨文字上的拒絕與 planner 測試，不能保證 ASR 變形後的組合鏈仍安全；近音替換會保留危險意圖卻改寫拒絕邊界。前置正規化因此應保留候選轉錄、錯誤類型與不確定性，並沿「轉錄、風險判斷、計畫可執行性、任務結果」分層驗收（本檔補註，非作者自陳）。由於實驗以文字生成與規則插入模擬錯誤，真實音訊部署風險仍待實測2608.28518。

Invalidation Contracts 最後把「憑證會過期」落成版本協議：version stamp、row-level diff、dependency vector 與 rule fingerprint 決定 artifact validity，planner 是否採用有效建議則另算 compliance。這補上 10.3 第一項「再固化觸發條件」的一部分（本檔補註，非作者自陳），但證據來自兩個手寫 API domain，尚不能把精準失效直接外推到大型生產 schema2609.00243。

10.3 下一批該找什麼

§8.1 的三個方向已結案兩個半，新的開放問題換成：

  1. 再固化的觸發條件——編譯產物會過期，但「什麼訊號代表該重編譯了」無人給機制。關鍵字：workflow drift detection、recompilation trigger、compiled-artifact staleness。
  2. 省錢手段的組合效應——2607.15516 只證明快取×壓縮會互斥，但路由×快取×推測解碼×TTS 預算的四方交互無人系統性量測。關鍵字：inference optimization interaction、compound cost model。
  3. 固化產物的消費端適配——2607.11346 顯示同一套確定性執行期對強弱模型效果相反。關鍵字：capability-gated tooling、agent scaffolding transfer。
  4. 約束機制的安全閘——2606.11817 證明安全憑證是模態綁定的，但除了蜜罐碼之外沒有通用作法。關鍵字：constrained decoding safety、modality-bound alignment。
  5. 多輪 agent 軌跡的不確定性量化——2602.05073 證明既有 UQ 方法搬到 agent 軌跡上幾近隨機（AUROC 0.47–0.69），而 ai_core 的節點多半就是多輪的。關鍵字：trajectory-level uncertainty、agentic UQ、step-level abstention。
