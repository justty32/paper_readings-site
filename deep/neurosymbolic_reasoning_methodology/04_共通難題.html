5. 共通難題

把 40+ 篇的「限制」欄交叉比對，浮現五個跨論文反覆出現的硬骨頭：

  1. 接地脆弱 / 推理捷徑：最深的結構性問題。2510.14538 證明它是必然、不可能用架構消除；2604.23377 證明最小修復 NP-hard；連 LLM 也逃不掉（2602.18095）。
  2. 符號推理的可擴展性：精確推論在理論上就極難（2502.03274 NP^PP-complete），涉圖神經/遞迴相依時知識編譯失效（2509.07665），可微邏輯閘難規模化（2506.04912）。符號工作負載甚至主宰算力（2401.01040）。
  3. 符號基底是新攻擊面：2606.17223 首次系統揭示——KG 投毒、單公理本體編輯可低成本高隱蔽地破壞，且符號層會「自發放大」誤差（75.8% 符號翻轉自發產生）。「換取可信」的假設本身脆弱。
  4. 缺統一定義與可信評估：定義到 2507.11127 才有積分式統一；後設認知僅佔 5%（2501.05435）；benchmark 飽和/污染/報告錯配（2606.08728）；評估標準化仍是公認缺口。
  5. 健全 ≠ 可信：2604.04177 的釜底抽薪質疑——形式健全的結論可能系統性誤導人；多數系統其實自承無形式保證。

7. 給實作者的決策捷徑

  • 要可審計、容忍延遲、任務部分可形式化 → LLM+符號驗證器（2501.14540 2606.20895 2602.18095），記得加自我修正迴圈（2604.27960）。
  • 要端到端學習 + 抗噪 + 訓練分布內保證 → 緊耦合可微損失（2509.00834 2411.08463）；要精確機率推理選 2412.07331。
  • 想用現成符號軟體又要學神經前端 → EM 解耦（2606.14463）。
  • 手上有 KG / 結構化知識 → KG⇄LLM 協同（2506.09566），但慎防本體被投毒（2606.17223）。
  • 任何弱監督感知+符號推理系統 → 先跑一遍 RS 診斷（2604.23377 ASP 驗證器、2510.14538 緩解選型表），別等概念全錯了才發現標籤準確率騙了你。
  • 要可上硬體 / 極致可解釋 → 可微邏輯閘（2506.04912）或結構即解釋的 BACON（2505.14510）。
