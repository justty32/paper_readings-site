0. 一句話總綱

在程式碼領域，神經符號的共同配方是：讓 LLM 負責「提案」（從自然語言／原始碼抽取結構、生成候選程式或事實），讓一個零相依、確定性的符號驗證器（SMT／Datalog／型別／執行／CAS）負責「把關」；幻覺與不可靠被工程化地關進「召回遺漏」而非「自信而錯」，整條管線因此可審計、可撤照、可累積。

這正是 ai_core 北極星的另一種講法——LLM 退縮到「意圖翻譯＋模糊前沿」兩個介面，其餘固化成可被機械驗證的確定性程式碼。本批 20 篇論文，等於把這條路線在程式碼／軟體工程上已經跑通的各個落點攤開來看。
