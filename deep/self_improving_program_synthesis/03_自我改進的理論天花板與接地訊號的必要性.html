3. 自我改進的理論天花板與接地訊號的必要性

§1-2 都在講「怎麼自我改進」，本節講 2601.05280 的反命題：在什麼條件下，自我改進注定失敗。 這是本批最硬核的理論，也是把前兩節串起來的「為什麼」。

3.1 崩潰定理：兩種失效模式

2601.05280 把 LLM 的遞迴自我訓練形式化為離散時間動力系統。設真分布 P_data、第 t 代模型分布 Pₜ，訓練分布是外生與內生的凸組合：

P_train = αₜ · P_data + (1 − αₜ) · Pₜ

其中 αₜ = 外部接地（exogenous）訊號的比例。更新算子 = 最小化 KL 散度（等價最大化對數似然）。核心定理：

定理 條件 結論
Thm 2 熵衰減 純自指 α=0 有限取樣下分布尾部「統計上不可見」被指派零機率；熵序列是上鞅，幾乎必然收斂到極小熵 → mode collapse
Cor 3 資訊封閉 α=0 由資料處理不等式（DPI），自指迴圈無法增加與 P_data 的互資訊 → 資訊論意義上封閉，不可能長出新智能
Thm 4 方差放大 αₜ→0 均值更新退化成 AR(1) 過程，自迴歸係數→1，失去「拉回 P_data」的回復力 → 隨機漫步漂移
Thm 5 範疇條件 αₜ ≥ α* > 0 無限容量下反而收斂到 P_data；崩潰只發生在 αₜ→0 的「自主」狀態

這個結果是「有條件」而非普世——這點極重要，常被誤讀。它說的不是「自我改進不可能」，而是「沒有持續外部接地的純自指自我改進不可能」。KL 的普世性（cross-entropy、MSE、BCE、GAN 的 JS divergence 都屬 KL/f-divergence 家族）讓這結論涵蓋幾乎所有現行生成模型訓練目標。

3.2 接地訊號為什麼是必要的——與前兩節的對照

把 2601.05280 的 αₜ 當作一把尺，回頭量本批每個自我改進系統，會發現能持續改進的，都有一個 αₜ > 0 的接地來源；能崩潰的警訊，也都對應到接地失效：

系統 它的「外部接地訊號」是什麼 對應 2601.05280 的判讀
SOAR 2507.14172 程式執行結果（hindsight relabeling 的「對它自己產生的輸出必然正確」是真值錨） 程式執行 = 形式可執行環境 → 接近「免疫」的 verifier
DGM 2505.22954 coding benchmark 實測跑分 經驗驗證 = 外部接地；但 benchmark 是靜態 proxy → Goodhart 風險（DGM 自己也警告「放大未被量度的失準」）
BARC 歸納 2411.02272 範例過濾（f(x_train)=y_train 才採用） 執行相符 = 乾淨接地
TTT 2411.07279 範例導出的留一法損失 範例是外生的人類標註 → α>0
Poker ILP 2507.16405 偵測矛盾（同假設不能既接受正例又接受其生成的負例） 邏輯一致性 = 形式接地，且準確率隨例子數單調遞增（與 Thm 5「α 有下界即收斂」同調）

2601.05280 點名的「verifier 種類決定生死」尤其切中要害：

  • 完美、形式可執行的環境（如 AlphaZero、程式執行、Prolog 推理）→ 免疫崩潰。這正是程式合成在自我改進迴圈裡如此珍貴的根本原因：程式可執行，於是接地訊號是「真的對不對」而非「看起來像不像」。
  • 學來的 verifier（RLHF reward model）→ 同樣會崩潰。
  • 靜態 proxy verifier → 被 Goodhart 定律利用、語意崩潰。DGM 用 benchmark 跑分當訊號，正落在這個風險帶——這也是它強調沙箱、限時、可追溯譜系、人類監督的深層原因。

HarnessLens 2608.27311 把這個風險帶再切細一層：它不讓所有候選共用固定或隨機任務批次，而是依修改欲影響的行為挑選相關任務，以現行與候選 harness 的配對軌跡比較行為，最後只接受改善可歸因於修改且未觀察到回歸的候選。作者的消融顯示，固定批次或只看總指標的 gate 都弱於完整方法；這直接佐證本節對靜態 proxy 的警告，也把「外部分數」收窄成「有辨識力、可歸因、涵蓋回歸面的行為證據」。

這不是把 benchmark verifier 變成完美接地，而是限縮「只要有外部分數就有足夠接地」的粗糙版本。HarnessLens 仍只在有限模型家族、harness 與公開 benchmark 上驗證2608.27311，且「未觀察到回歸」受所選任務覆蓋限制；它填補的是如何改善弱接地，而非證明 Goodhart 風險已消失（本檔補註，非作者自陳）。

2609.01354 則反過來修正本節「形式可執行環境的 verifier 近乎免疫」這個過強讀法：四種 verifier 實作的字串抽取、正規化與容差設定會系統性改變二元 verdict，連可證等價的答案也可能被拒，語義已改變的答案也可能被接受。因此，程式可執行只提供建造強接地的條件，不自動構成可靠憑證；verifier 的身分、設定、coverage 與 accuracy 也必須成為接地鏈的一部分（本檔補註，非作者自陳）。

3.3 出路：符號錨與「跳脫 DPI」

2601.05280 開的藥方是神經符號整合：用 Coding Theorem Method（CTM）/ BDM / Algorithmic Information Dynamics（AID）近似演算法機率與 Kolmogorov 複雜度，把一步更新拆成 U = 統計擬合 ∘ 符號投影 ∘ 因果校正。關鍵機制：

  • 符號錨（symbolic anchor）：程式不能微量漂移——要改就得跳到「下一個有效程式」，形成位能障壁，把 Thm 4 的連續隨機漫步離散化、擋住漂移。
  • 生成式蘊涵：最小程式能重新導出含尾部的整個分布 → 恢復被熵衰減吃掉的尾部。
  • 跳脫 DPI（Prop 10）：以萬有先驗條件化，可在程式空間恢復統計空間裡丟失的隱藏資訊——這是 Cor 3「自指不增互資訊」的唯一合法出口。

收縮力的層級：統計更新（僅在分布空間收縮、受 DPI 限）< 符號更新（投影到低複雜度子空間）< 因果更新（程式空間直接淘汰不相容機制，最強）。

這把 §1 的光譜反過來照亮了：為什麼越往下（程式級→因果/演算法級）威力越大？因為越往下越靠近「辨識生成機制」而非「擬合相關性」，而只有前者能跳脫 KL/DPI 的束縛。2601.05280 與 2503.16048 在此奇妙共振——後者也說 meta-learning 真正灌進去的是「機制」（計數器電路）而非「先驗」（簡約偏置），同樣是「機制 > 相關」的主張，只是一個從資訊論、一個從認知科學的形式語言實驗。

3.4 哲學註腳：分析 vs 綜合

2601.05280 借康德框架收尾：現行 GenAI 是分析引擎（analytic，重組/內插既有資料），無法產生綜合知識（synthetic，真正新穎的定律）。奇點需要綜合知識生成能力。把這句話接到 ARC：ARC 的「結構 OOD 測試集」本質就是在考綜合能力——能不能造出訓練分布裡沒有的新組合。GridCoder 2411.17708 的「程式結構 OOD 補不了」與 LPN 2411.08706 的「組合泛化不穩健」，正是分析引擎在綜合任務上的具體碰壁。
