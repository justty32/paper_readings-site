2609.04518 是這個 OOD 瓶頸在 coding agent 上的直接反例：控制軌跡、獎勵與更新預算後，跨 harness 的信用分組確實讓 advantage 帶上 harness 身分，卻沒有在訓練時未見的 harness 上形成可檢出的額外解題能力。它打臉了「多介面訓練自然產生可攜能力」的假設，也填上本節原先缺少的介面層遷移檢驗：來源 harness 的增益只能先算配置適應，尚待在未見 harness 上實測後，才可視為通用改進（本檔補註，非作者自陳）。

4.3 有前景的方向

  1. 執行引導 + 搜尋↔學習的全閉環（融合 GridCoder-LTS 構想 2411.17708 × SOAR 閉環 2507.14172）。GridCoder 已論證執行引導是結構泛化的解方（proxy 10%→80%）但未實作；SOAR 已證搜尋軌跡回灌能抬高 scaling 曲線。把「每步執行回饋」接進「搜尋產物回灌微調」的閉環，是當前最值得做、且兩篇都指向同一處的空白。

  2. 以程式執行為「完美 verifier」錨定自我改進（2601.05280 的理論 × 程式合成的實作）。理論已證「形式可執行環境的 verifier 才免疫崩潰」；程式合成天然提供這種 verifier。把 DGM 2505.22954 那種「benchmark 跑分」的弱接地，換成「程式級可執行單元測試」的強接地，可能同時提升可持續性與抗 Goodhart。

  3. 連續潛在 ⊕ 離散符號的混合表示（LPN 2411.08706 自陳的未來工作）。LPN 的連續搜尋省算但組合泛化不穩；離散 DSL 組合泛化強但枚舉爆炸。在潛在空間做粗搜、再投影到離散程式做精修與驗證（呼應 2601.05280 的「符號錨把連續漂移離散化」），可能兩得其利。

  4. 自動化「背景理論 / DSL」的生成——把最後的人工依賴也納入自我改進。Poker 2507.16405 的 SONF、GridCoder 2411.17708 的 DSL 目前仍手工。若能讓系統像 DGM 改自己碼一樣演化自己的 DSL/metarules，就把「程式級」與「架構級」自我改進真正打通。

  5. 以「機制覆蓋率」而非「資料量」設計改進課程（2503.16048 的啟示）。既然 meta-learning 灌入的是機制、且「單一夠複雜的語言抵 5000 種」，那自我改進的訓練資料設計應該瞄準「覆蓋目標機制（Chomsky 階層 / 電路複雜度）」而非「堆量」。這對 SOAR/BARC 的合成資料生成管線（目前靠量與多樣性）是一條更省、更有原則的路。

  6. 演算法級自我改進的「可解釋產出」回哺（2101.03958 × 2507.17668）。演化 RL 能產出人類可讀、且對應到 CQL/M-DQN 的閉式損失；2507.17668 指出「有好暖啟動時 LLM 提案最佳」。讓 LLM agent 把演化發現的符號損失當暖啟動、再迭代，是「演算法級」與「LLM 自我改進」的交叉點。

5. 給讀者的一頁速記

  • 自我改進有四層：權重（TTT/微調）→ 程式（合成/ILP/GP）→ 架構（DGM 改自身碼）→ 演算法（演化 RL 損失）。越深威力越大、驗證越難、越貴。強系統都在跨層閉環（SOAR = 程式級⊕權重級；BARC+TTT = 程式級⊕權重級）。
  • ARC 沒有銀彈：歸納（可驗證、擅組合）⊕ 轉導（擅知覺）強互補；離散 DSL（可解釋、擅組合、會爆炸）↔ 連續潛在（省算、組合不穩）；SOTA = 神經+程式合成+TTT 三元組（缺一掉一截）。
  • 結構 OOD 是公敵：搜尋只能補「網格層高熵 OOD」，補不了「程式結構低熵 OOD」；唯一已知解方是執行引導（GridCoder-LTS proxy 10%→80%）。
  • 自我改進有理論天花板（2601.05280）：純自指（外部接地 αₜ→0）必崩——熵衰減 + 方差放大，且 DPI 保證自指不增互資訊。但這是有條件的：只要接地 αₜ≥α*>0 就收斂到真分布。程式合成之所以珍貴，正因它提供「程式可執行」這種完美 verifier，是免疫崩潰的接地來源。
  • 機制 > 相關：2503.16048（meta-learning 灌的是神經機制非貝氏先驗）與 2601.05280（要辨識生成機制非擬合分布）從兩個學科得出同一主張——這也解釋了為何「往程式/因果層走」才有真正的泛化。
  • 共通瓶頸：接地品質、架構容量、多樣性可持續性、算力遞減、結構泛化、符號難擴展、殘餘手工依賴。
  • 最該做的方向：執行引導⊕搜尋學習全閉環、以程式執行當強 verifier 錨定改進、連續⊕離散混合表示、自動演化 DSL/背景理論、以機制覆蓋率設計課程。
