3. 主軸二：可學習性 / 可抽取性（能否學出、能否抽出）

表達力只說「解存在於權重空間」，不保證「梯度訓練到得了」，也不保證「事後能把離散結構抽回來」。這條軸把論文分成三種姿態：

3.2 表達力 ≠ 可學習性：本批最重要的裂縫

  • 2603.01959 的核心發現不是表達力，而是落差：2 層 AUSSM 理論上能表達 S₃／A₄（皆長度 2 次正規列），實際梯度訓練卻失敗；但 2 層 negative Mamba 的 C₂×C₄ 增量卻學得到。「解在權重空間存在，標準訓練到不了」——用近解初始化探針證明該解落在損失景觀的吸引盆地內，只是隨機初始化跳不進去。

  • 2412.01417 在 ECA 上量到平行版本：Transformer 能跨 Boolean 函數泛化（規則抽象 acc 0.96），但多步規劃急遽崩潰，且深度直接決定可規劃步數（2 層 1 步、10 層 4 步）——即使把規則明給（RO-S）仍崩，瓶頸在「中間狀態的隱表徵傳播」而非缺規則。

  • 教訓：設計新架構時，「能不能模擬」只是入場券，「梯度走不走得到」才是真關卡。GraphFSA 的 Diff-FSA、PD-SSM 的 surrogate 梯度、AFA 的三階段課程＋sigmoid 鬆弛，全都是在補「可學習性」這一課的工程技巧。

3.3 可抽取性：把黑箱拆回離散自動機

  • 天然準離散：2601.10918 的關鍵觀察是 RNN 隱狀態軌跡本身就自組織成準離散模式，無需訓練時強加狀態機約束，事後分群即可抽出 FST（比古典 OSTIA 最多高 87%）。
  • 無損雙向：2604.01228 最強——LG-TS-FFN 與 AFA 結構同構，可從權重門檻化無損抽回 δ 與邏輯型別（非近似編碼）。
  • 退化解現象：2506.17333 AutomataGPT 反推規則矩陣時，a_appRM（套用準確）恆高於 a_RM（精確匹配）——模型常找到不同卻管用的等效規則，「對訓練集越陌生的規則反而越會被創造性解出」。
  • 一個誠實的警告：2605.08150 指出手工建構的可解釋性不遷移到梯度訓練出的網路（神經元會被置換／縮放）。這給「抽取」一條紅線：抽得出 ≠ 訓練網路天生長這樣。

4. 工程主旋律：「連續鬆弛訓練 → 離散結晶」

這是本批反覆出現、最具可移植性的範式。它讓你兩頭通吃：訓練期享受可微（梯度好走、樣本效率高），推論期享受離散（確定性、可上硬體、可審計、外推穩定）。

階段 做什麼 為何要
鬆弛（relax） 把離散運算換成連續可微版本：AND→a·b、OR→a+b−ab（2506.04912）；hardmax→softmax surrogate（2509.22284）；硬布林→機率分佈（2602.03486、2412.07331）；單一下一態→機率自動機（2408.11042） 讓梯度能穿過離散決策
結晶（crystallize） 推論時每個閘取最可能運算 / 離散化轉移矩陣 / 抽出決策表：DiffLogic CA 結晶成確定電路、Diff-FSA 離散化抽轉移矩陣、PD-SSM 逐列 hardmax 得到確定、稀疏、可部署的離散物件

代表案例與其賣點：

  • DiffLogic CA（2506.04912）：訓練時連續邏輯閘、推論時結晶成確定電路——5 個閘畫棋盤、336 個閘做生命遊戲，可直接映射 FPGA/ASIC 做奈秒推論，且免設計的容錯／自癒。這是「結晶」範式最漂亮的展示。
  • DeepDFA（2602.03486）：DFA＝PFA 特例 → 3D 轉移矩陣矩陣乘＝可微前向；半監督符號落地（落地函數從資料＋邏輯學得），且首度把時序知識注入延伸到互動式 RL（Neural Reward Machine）。
  • AFA 門控（2604.01228）：sigmoid 鬆弛 + 三階段課程學習，訓完門檻化抽回符號 AFA，100% 完美還原。
  • GraphFSA / Diff-FSA（2408.11042）：機率自動機鬆弛 + final-state loss + random iteration offset 兩個穩定性技巧，訓完離散化——離散狀態帶來迭代穩定外推（訓小圖測大圖、多跑步數不崩，基線會崩）。

共同代價：2506.04912 明言訓練有顯著數值不穩、需大量超參調校；2509.22284 P 矩陣生成比純對角慢約 7×；鬆弛—結晶之間的 gap 永遠是調參戰場。這條範式好用，但不免費。
