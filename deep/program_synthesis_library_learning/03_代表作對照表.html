論文 核心思想 優點 缺點 / 局限
2604.26311 DreamProver wake-sleep 演化可遷移引理庫；語意分群→抽引理→去重→LRU 直面「引理不被重用」痛點；冷門域達 SOTA；緊湊庫>龐大庫被消融強證 引理庫領域特定；分解限單層；仰賴 LLM 抽象品質
2603.25975 Schank-primitive wake-sleep + MDL 檢驗「概念 primitive 是否存在」 把認知科學老問題量化（4%、100% vs 81%）；specialization≈Huffman 的優雅類比 須先結構化成 before/after 三元組；beam search 非完備
2605.04622 e-graph 爵士庫學習 parsing 與 library learning 在 e-graph 上聯合求解 用 cost-set 把 Catalan 級爆炸剪到可行；學出模式符合爵士理論 僅三曲概念驗證；egglog 未對大規模優化
2602.00929 TheoryCoder-2 LLM 合成 PDDL 抽象（高層）+ Python grounding（低層）+ 跨 episode 成長庫 把 TBRL 對人工抽象的依賴自動化；抽象跨環境可遷移；樣本效率高 仍需極簡 prompt 控粒度；受 LLM 合成正確性限制；多為網格域
2605.08399 CoCoDA 程式碼原生技能 DAG，同物件解「庫成長 vs 上下文預算」 typed 級聯檢索成本次線性；8B 匹敵 32B；policy-library 共演化理論保證 依賴固定 teacher 抽取 composite；限六基準/Qwen3 家族
2509.04439 ArcMemo 概念級（非實例級）自然語言記憶 + 選擇性檢索；不更新權重 給轉導路線補可重用抽象；測試時持續更新→跨重試自我提升 限 ARC-AGI 單基準；高度依賴 LLM 反思與 scaffold

2604.13290 Presynthesis 把昂貴的 FTA 建構/可達性分析移到離線，線上只做快速 slicing 首次兌現「更細抽象→更快合成」；SQL 比 SOTA 多解 15%、中位 90× 加速 離線產物耗記憶體（設想做服務）；抽象語意仍須人工設計
2507.16405 Poker 自監督 ILP：偵測矛盾自造負例 + SONF 最大泛化背景理論 免除「客製背景理論」+「手選負例」兩大負擔；準確率隨例子數單調遞增（有定理） SONF 仍須人工導出；實驗限文法學習
2606.24245 AutoSpec ILP 當 CEGIS 迴圈的「謂詞提名器」演化 LLM agent 安全規則 ILP 把規則編輯指數空間剪成短清單（F1 比啟發式 CEGIS 高 4.8×）；規則可審計 仰賴人工標註軌跡；謂詞庫須事先設計；不保證全域最優

3.3 LLM 演化（FunSearch 譜系）

論文 核心思想 優點 缺點 / 局限
2512.13857 EvoLattice 單一 DAG 內含整個族群（每節點多並存替代方案）；MAP-Elites 內建 不複製結構換指數搜尋空間；替代層級統計做信用分配；確定性自我修復卸下 LLM 守規則 路徑數組合爆炸（即便 memoization）；長期結構膨脹
2606.26173 AlgoEvolve bi-level：內迴圈 LLM 突變策略碼，外迴圈演化 prompt genome 元演化自動發現搜尋啟發式、修復「零交易/局部最優」失效；設計時合成、部署零延遲 結果選擇性（菁英 prompt）；複雜度天花板現語法邊界
2605.15308 SMCEvolve 把程式演化重構為對獎勵傾斜分布的 SMC 取樣 單一溫度 βₜ 統一導出選親/突變/停止；首個程式演化收斂保證；效能升+算力降 橋接規則性假設；黑箱 LLM 只能用獎勵代理 MH；單目標
2606.07704 FunctionEvolve 讓 LLM 看見 AST 結構；選親/突變/擬合三環共用結構 點出「對結構盲」是 LLM-SR 病灶；SA@50 達基線 4.5×；附帶基準共線性稽核 倚賴任務脈絡；強骨幹依賴大型 LLM
2606.04360 Deliberate Evolution 解耦「提議式子」與「控制搜尋」；補方向/診斷/記憶三訊號 40% 預算 NMSE 降 55%；殘差/量綱當診斷把純量誤差變局部證據 倚賴 LLM 數學先驗；中小骨幹為主；限 LLM-SRBench 派生集
2609.17590 Evolutionary Ensemble Search council 分工提案、orchestrator 派發實驗；parent-relative operator credit 與三層記憶跨輪保留經驗 相較 Deliberate Evolution 把記憶當搜尋訊號，EES 另以可比 measurement contract 要求每個 child 重跑並留下 lineage 與 artifact identity（本檔補註，非作者自陳） 19／22 是評分可見的開發 ledger（作者自報），無凍結盲測與元件邊際消融，不能證成完整 council／memory stack 的泛化

3.4 神經引導合成 + GP 基礎設施

論文 核心思想 優點 / 缺點
2411.17708 GridCoder VLM 出 DSL token 機率 → 條件獨立攤平的機率枚舉 優：把枚舉成本壓下（79.3%>75.9%）。缺：搜尋補不了「程式結構 OOD」，須執行引導（LTS 未實作）
2411.08706 LPN 連續潛在程式 z + 梯度上升搜尋，繞過手工 DSL 優：測試時搜尋內建可微架構、省算。缺：組合泛化不穩健
2604.18907 NLI 離散 token 語言 + 可微解釋器 + 潛在梯度搜尋 優：組合泛化 OOD 99%/91%/100%，泛化來自重用。缺：test-time 搜尋貴；每層只條件於一 token、無分支
2509.17393 SYNTRA 轉導式：LLM 偽標籤淘汰歸納假設 + greedy maximin 省呼叫 優：準確率最高+196%、省 LLM 呼叫。缺：須測試輸入可得；偽標籤受 LLM 限
2606.10237 Minimalist GP 用 Chomsky 極簡程式的 MERGE 推導取代演化搜尋 優：對抗 bloat、精確緊湊（多數題 30/30 命中）。缺：極簡程式理論不成熟；高度依賴原子詞庫選擇
2504.10253 TinyverseGP GP 跨表示×跨域統一基準框架 優：破解 GP 碎片化、共同庫+tiny 模組。缺：起步原型、無大規模實證
2501.17168 EvoGP 樹型 GP 整條流程搬上 GPU、群級並行 優：峰值>10¹¹ GPops/s、比 GPU 版快 304×。缺：須預設最大樹節點數；NaN padding 浪費
2506.23408 LLM 夢見離散演算法 Prolog 一階邏輯 + 安全工具約束 LLM 規劃（拼接而非自由生成） 優：事實=知識圖譜、規則=路徑、否定=證明系統；對治幻覺。缺：缺量化對照；超大資料庫不可行
2507.14172 SOAR 離散 Python 搜尋軌跡（hindsight relabel）回灌微調生成器 優：搜尋↔學習閉環抬高 scaling 曲線。缺：解多樣性下降、輪次遞減（詳見 self_improving doc）
