B1. Transformer 預訓練（基礎模型）— 把 SR 變成「翻譯」任務

在數十億條合成「資料 ↔ 方程」語料上預訓練 set-to-sequence transformer，推論時單次前向就吐出方程，速度碾壓搜尋式。代表 NeSymRes、E2E。

論文 核心思想 優點 缺點
2505.21879 SFR 複雜網路基礎回歸器 首個複雜網路 SR 基礎模型：①局部三元組取樣解耦全域拓撲；②self/interaction 物理分解（學固定 1元 f_self + 2元 f_int 破維度詛咒）；~20億方程預訓練 極快（網路動力學 1.2 分鐘 >3×、疫情 <0.5 分鐘）；非網路 SR 勝 PySR/SINDy/E2E；少資料即可 需巨量合成語料；分解假設限制方程形式
2509.19849 預訓練 SR 泛化分析（批判） 系統檢驗 transformer SR 泛化：建 IPD/WIPD/OOPD 三域評測 揭露關鍵盲點：模型不是學「可組合構件」，而是「點雲統計↔符號結構」的記憶式模式匹配器 —

Transformer 派總評：速度是殺手鐧，但 2509.19849 的診斷是當頭棒喝——OOD 即崩，回復率從域內到域外斷崖式下跌。實務決策：資料在訓練分布域內才用，否則回頭用搜尋式。這是本領域最重要的「冷水」結論之一。

B2. KAN / 可微符號網路 — 學連續函數再符號化萃取

Kolmogorov-Arnold Network 把可學的單變數函數放在邊上，天然契合「逐變數抽符號」。路徑是「先擬合神經網路 → 剪枝 → 把每條邊的激活函數符號化成已知函數」。

論文 核心思想 優點 缺點
2509.10089 KAN-SR 7 步工作流：暴搜 → 單/多 unit 單層 KAN → 對稱性/可分離性簡化拆子問題 → 輸出變換 → 深層 KAN；擬合後拆模組用非線性最小平方匹配領域函數庫（Fast-KAN+RSWAF, Jax） 含無關變數時解出率尤勝基線、避免暴力枚舉、可延伸 neural CDE 動態建模 僅在「單層+簡化+單變數庫足夠」時強；固定 unit + 有限庫易落局部解
2501.17896 KAN 翼型升力 KAN 預測 C_L（R²=96%）後剪枝+符號化得封閉方程，與已知升力物理一致 準確+全程可解釋；剪枝後僅 25% 網路仍 95.6% R²；方程可求導估敏感度 單一輸出、低雷諾數、示範性質
2506.07549 MetaKAN 用小型元學習器（HyperNetwork）生成 KAN 海量激活參數，1/3–1/9 參數達同效；模型無關 大幅減參、網路越深越有利；部分 Feynman 任務 MSE 反更優 極小 KAN 時固定成本反增參

KAN 派總評：可解釋性內建、與 AI Feynman 式分而治之天然契合；但搜尋空間受固定結構 + 函數庫約束，探索力不如 GP，「最優解在約束外則失敗」。

B3. 神經符號可分解 — 分而治之 + 結構約束

用神經網路先學出「結構骨架」，把高維符號搜尋拆成有引導的低維增量操作。介於學習式與搜尋式之間。

論文 核心思想 優點 缺點
2511.04124 SeTGAP 可分解神經符號迴歸 分而治之：Multi-Set Transformer 為每變數各找單變數骨架 → GA 過濾 → GP 級聯逐變數合併並保留骨架結構 13 受控問題全部正確回復結構（對手≤7/13）；外推甚至勝它蒸餾的 NN Feynman 多為加性可分（對分解法不夠挑戰）；指數項小常數誤差放大外推

可分解派總評：把「結構正確 > 域內 MSE 低」的價值觀做到極致；軟肋是其分解假設與多數 benchmark 的可分結構「相互捧場」，真實難題上的優勢待驗。
