3.1 準確 vs 複雜度的 Pareto（幾乎全篇都碰）

SR 的根本張力。共識是 MSE 單目標不足以評 SR（2512.15920）——它選不出簡約且物理合理的式。各派的回應：GP 用 ε-lexicase + NSGA-II 維護 Pareto 前沿（2512.01682/2512.07961）；SISSO 用資訊論複雜度（2502.03367）；MvSR 用 AIC/BIC/MDL（2509.10500）。2509.21780 EIC 進一步主張：傳統「越簡單越好」會選到緊湊卻數值病態（災難性抵消）的式，需加「結構穩定性」第三維。

3.2 Ground-truth 結構回復（≠ 域內低 MSE）

科學發現場景真正要的是回復出正確結構，而非擬合誤差低。痛點有二：

  • 判定難：2508.14481 指出既有基準過度要求唯一公式形式、只靠 SymPy 判定常失敗；改用「可接受表達式清單（函數等價）」。
  • 回復 ≠ MSE：2511.04124 明言「結構正確比域內 MSE 低更重要」；2512.01682 重評發現 SR 常過擬合噪聲、抓不到真方程。

3.3 泛化 / OOD 外推

  • 最重要的冷水：2509.19849 證明 transformer 預訓練 SR 是「記憶式模式匹配」，OOD 即崩。
  • 正面教材：結構正確的式天然會外推——2511.08784 的標度律、2511.04124 的可分解式都外推勝固定結構擬合；2512.04204 跨 CHIME catalog 穩定。

3.4 可解釋落地

SR 的賣點，但有陷阱：保護運算（protected operations）會損害可解釋（2504.05756）；臨床場景偏好決策樹式規則，純方程不夠（2512.07961 補 split 節點）；玻璃盒非線性勝 LIME/SHAP 事後解釋（2504.05756）。

3.5 量綱 / 物理先驗

把領域知識注入搜尋的主要管道：Buckingham-π 量綱齊次（2512.04204）、守恆/對稱/邊界條件（2512.15920）、self+interaction 物理分解破維度詛咒（2505.21879）、已知極限約束（2412.08143 的 von Weizsäcker/Thomas-Fermi）。Φ-SO/PhySO 是把物理單位硬約束進搜尋的代表工具（2509.10500）。

基準層的方法學進展（不是新 solver，是評測本身）：

  • 2508.14481 FastSRB：可接受表達式清單 + early termination，把「回復判定」從「唯一形式」鬆綁為「函數等價（運算子數 ≤ 參考式 1.2 倍）」，同時省 40–60% 算力。
  • 2509.21780 EIC：提出 ground-truth-free 的結構穩定性評估維度，與 108 位人類專家偏好 70% 一致。
  • 2509.19849：提出 IPD/WIPD/OOPD 域內外取樣協定，專測泛化（而非單看域內回復率）。

現況評語：SRBench/Feynman 仍是事實標準，但三大公認缺陷已被點名——①偏物理且可分結構偏多（利好分解/SISSO 派，未必反映真實難度）；②回復判定脆弱（FastSRB 在修）；③只測域內、不測 OOD（2509.19849 在補）。「快速 + 公平 + 測泛化」的下一代 benchmark 仍是開放問題。

5. 研究空白與有前景方向

  1. 搜尋式與學習式的混血（最熱）。已見端倪：2509.15929 把 GP 變異/交叉當 MCTS 跳躍；2511.04124 用 transformer 出骨架再 GP 合併；2511.08784/2505.21879 用 LLM 生模板/beam 約束。前景：transformer 暖啟動 + GP/MCTS 精煉，兼得速度與泛化。

  2. 正交增強層的可組合化。e-graph（2511.05849/2501.17848）、降維（2506.19537）、物理先驗（2512.04204）、評估準則（2509.21780）目前各自為政。前景：一條 pipeline 同時掛降維前處理 + e-graph 去重 + 量綱約束 + EIC 結構過濾——四者互相正交，理論上可疊加增益，但尚無人系統整合。

  3. 真正的 OOD 組合泛化。2509.19849 的診斷指出 transformer 學的是記憶而非構件組合。前景：怎麼讓模型學「可組合的數學構件」而非「點雲快照」？是把 SR 從擬合工具升級為發現工具的關鍵門檻。

  4. 不確定性量化（UQ）的普及。目前只有貝氏派（2512.10849）與少數工具（PySR/PhySO）原生提供形式+參數雙重 UQ。前景：科學發現須知道「這條式有多可信、哪裡該補資料」，UQ 應成標配而非奢侈品。

  5. 下一代 benchmark。需同時做到公平回復判定（2508.14481）、測 OOD（2509.19849）、納結構穩定性（2509.21780）、且包含真正難（深巢狀、非可分）的問題——現有基準的可分結構偏多會系統性高估分解/SISSO 派。

  6. LLM 進場的雙面刃。LLM 可生模板、讀等價回饋（2511.05849）、做特徵選擇（2512.04204）；但其預訓練語料可能污染ground-truth 回復評測（記住了 Feynman 公式），如何隔離記憶污染是 LLM-SR 評測的新坑。

  7. 領域特化的「方法改造」模板。2412.08143 把 SR 庫從「學函數」改造成「學泛函」、2505.21879 改造成「學網路動力學」——這種把通用 SR 引擎針對問題結構做手術的範式（而非直接套用）在物理各子領域有大量未開發空間。
