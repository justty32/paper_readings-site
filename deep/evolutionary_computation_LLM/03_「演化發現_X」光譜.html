3.1 ① 損失 / 更新規則——奠基與表達力之爭

2101.03958（Evolving RL Algorithms, Co-Reyes 2021）是整條線的奠基作：把「設計 RL 演算法」形式化成 meta-learning，外層用正規化演化在「計算 RL 損失函數的型別化 DAG」空間搜尋，內層用該損失訓練 agent。產出可被人讀懂的閉式損失：

  • DQNReg L = 0.1·Q(s,a) + δ²——極簡卻能從非影像簡單環境 meta-train，泛化到 Atari 勝 DQN/DDQN/PPO。
  • 分析顯示它透過壓低 Q 值高估獲益，結構上對應到後來人工提出的 CQL、M-DQN——「演化出來的東西可被人讀懂並對應到研究者正手動探索的方向」是它最大的可解釋性賣點。

三項工程加速值得記：功能等價檢查（對隨機輸入雜湊輸出，等價就複用分數）、早期關卡（先在 CartPole 跑，低於閾值即終止）、從 DQN 自舉（比從零學收斂快、最終表現 +40%）。

2402.05828（Temporally-Aware）的核心洞見是「meta-優化方法 > 參數化本身」：給 meta-learned 目標函數加「訓練壽命」條件 n/N，讓演算法在訓練中動態改變自己的損失。關鍵發現——只有 ES 學得到這種動態更新，meta-gradient 因目標短視（截斷 BPTT）會失敗。學到的動態母題：訓練初期樂觀+最大化熵 → 末期悲觀+最小化熵。這對整條光譜是警示：想發現非短視的演算法，外層用 ES（適應度＝整個壽命的最終回報）比 meta-gradient 關鍵。

2603.28416（LLM 演化發現 update rule）把搜尋空間從「受限參數化/符號 loss」拉到「完整可執行訓練邏輯」，並用 LLM 解決「盲目變異多半無效」。最反直覺的自發現象：刻意禁用 actor-critic/TD/bootstrap，演化竟自發收斂到「世界模型 + 規劃蒸餾」這類 model-based 結構——暗示 RL 演算法空間中 model-based 是一個強吸引子。代價極高：每代約 30 小時、每候選 25 個完整訓練 run。

對照三者：2101.03958 走符號計算圖（產可分析閉式損失）；2402.05828 走神經參數化 + 加時間輸入 + ES（不演化符號圖）；2603.28416 走完整可執行程式 + LLM 算子。這正是 §0 軸二「算子是誰」在同一個「發現 loss」任務上的三個切片。

3.2 ② 獎勵——函數本身 vs 時間排程

  • 2601.21847 READY 發現的是 MetaBBO（用 RL meta-learn 黑箱優化器設計策略）的 reward 函數本身，填補「自動獎勵設計 × MetaBBO」此前無人碰的交叉。三大設計：多任務 niche（一個 run 同時替三個 MetaBBO 找獎勵且互相加速）、五個 reflection-based 程式級算子、rejection sampling 強制每個入種群個體都支配人類 baseline。最反直覺：零樣本跨 MetaBBO 獎勵遷移（為某 MetaBBO 設計的獎勵能直接 boost 未見的 MetaBBO，暗示存在通用良好獎勵結構）。

  • 2606.20858 發育型獎勵排程發現的是獎勵的時變權重排程（被忽略的「動機如何隨訓練時間演進」這條軸）。複合獎勵 r(t) = r_task + λ[α(t)·agency + β(t)·novelty + γ(t)·reactivity]，三分量時變權重 θ∈ℝ¹⁵ 由 EA（CMA-ES/xNES/DE/L-SHADE）外層演化、PPO 內層訓練。最反直覺：讓演化無先驗地排發育順序，結果 novelty 自發成為早期主導訊號，推翻 agency→novelty→reactivity 的生物直覺——「計算上的最優可能異於生物上的最優」。

注意 2402.05828 與 2606.20858 的共鳴：兩者都發現「時間排程」是被忽略的軸——前者讓 loss 隨壽命變、後者讓 reward 權重隨訓練變，且都得用 ES/EA 外層才能優化整個壽命的最終表現。

3.3 ③ 架構——把 NAS 引進被忽視的 actor-critic

2606.26327 EVOM 把長期被當成「固定實作繼承自前人」的 actor-critic 架構，做成雙層最佳化：外層 LLM 演化「架構程式」種群（開放拓撲但受 PolicyNet/ValueNet 介面約束），內層低保真 PPO（100k 步）給便宜 fitness。守衛：編譯失敗/非有限/崩潰 → 罰 −1000。在 MuJoCo 上演化出含殘差 + LayerNorm/SiLU 的架構，大幅勝手工 PPO（Ant 4652 vs 2517）。兩個演化工程觀察：mutation/crossover 互補（mixed 最佳）、種群增大不單調獲益（更大候選池更依賴 noisy 低預算訊號）。

3.4 ④ 演算法本身——元學習「決定誰存活」的規則

光譜頂端是「發現演算法本身」。2502.02190 LQD（已在 §2.2 詳述）發現的是 QD 演算法的局部競爭規則——這是純度最高的「演算法即被發現對象」：它不發現某個 loss 或 reward，而是發現「這個演算法用什麼規則決定誰跟誰競爭、誰存活」。2505.20881 MoH 則發現組合優化的優化器本身（見 §1.3）。兩者一個用 ES-based Meta-BBO、一個用 LLM，恰好標出軸二的兩端。
