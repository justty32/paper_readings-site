空間接地到長程控制

空間智慧不能停在「看出物件在哪裡」。具身 Agent 還要知道缺少哪個視角、把多模態證據保存成什麼狀態、如何將程序步驟重新接地為公制命令，以及證據不足時何時改看、重規劃或停手。本章沿著「取證 → 表徵 → 程序 → 控制」檢查這條鏈，並比較端到端 VLA 與顯式結構在長程任務中的可靠性、能耗與失敗邊界。

一、會看不等於看見，會定位也不等於會控制

SIRI-Bench 把立體幾何的主要條件藏進環視影片後，同系模型明顯落後於取得完整文字條件的版本。2506.14512 這把問題指向視覺到幾何條件的轉譯，但固定渲染資料並未覆蓋真實接觸與遮擋。（本檔補註，非作者自陳）

VA-Bench 要求模型從 RGB 示範抽程序、自主選視角，再把新場景目標重定位為公制命令。2609.19554 最佳模型的目標定位達 100.0%，最佳三輪端到端 macro-average 卻只有 53.93 ± 3.17 個百分點，均為作者自報。2609.19554 長程組合條件沒有模型完成嚴格 episode，亦為作者自報。2609.19554 診斷高分不能代替物理終局驗證。（本檔補註，非作者自陳）一般故障攔截與恢復見故障治理綜述。

主動視角可視為控制前的資訊動作。（本檔補註，非作者自陳）VA-Bench 的主動相機條件優於被動多視角條件，但作者未把增益唯一歸因於視角選擇。2609.19554 MindJourney 用影片世界模型展開候選視角；真實場景的深層搜尋反而退化，作者歸因於生成品質隨分布偏移下降。2507.12508 實際觀察與生成觀察不應共用證據資格；想像視角若直接填補公制座標，可靠性尚待實測。（本檔補註，非作者自陳）

Spatial Language Model 把點、線、面保留為幾何向量，避免先把座標文字化，但尚未驗證動態立體場景與接觸。2606.04381 GAF 的 dynamic Gaussians 同時表達目前場景、未來場景與候選動作，再由 diffusion 修正遮擋與接觸殘差；它缺少任務語意。2506.14135 兩者不宜混成單一「空間 latent」；觀察來源、幾何信念、預測運動與任務謂詞應分開保存。（本檔補註，非作者自陳）

VLA-Touch 在規劃層把觸覺轉成物性描述，在控制層保留連續觸覺力修正 action chunk。2507.17294 芒果硬度任務中，完整語言描述成功率為 60%，連續 classifier 輸出為 75%，均為作者自報。2507.17294 高階介面可讀物性摘要，低階控制仍應保留原始數值或分布。（本檔補註，非作者自陳）

二、規劃表徵應切在可覆核的介面，不切在共同隱狀態

VLA-OS 固定骨幹與 action head，比較直接動作、單模型整合規劃與雙模型階層規劃。2506.17561 視覺 token 與短期影像 foresight 通常優於長篇語言推理；深度耦合的顯式規劃會累積錯誤，階層式 policy 則能用原始觀測修正規劃，但成本較高。2506.17561 顯式輸出應是可覆核的建議，而非另一段更長的隱狀態。（本檔補註，非作者自陳）

Skill-3D 先判斷所需幾何證據，再依場景、失敗教訓與成本檢索工具工作流；只有產生且用到有效證據的呼叫才算有效。2606.07436 規劃表徵因此還應包含適用條件、證據與備援；即時機器人的效益尚待實測。（本檔補註，非作者自陳）

neuro-symbolic procedural VLA 用任務圖管順序，以事件記憶保存轉移，再讓 saliency 指示當前步驟該看哪裡。2609.05369 其實驗只驗證熟悉設定的目的地選擇，完整程序尚未端到端驗收。2609.05369 較穩妥的切分是程序圖管合法步驟、空間證據管物件綁定、低階 policy 管連續動作；跨場景優勢尚待實測。（本檔補註，非作者自陳）

規劃到控制的交接物應包含 subgoal、物件綁定、座標系、成功謂詞、證據來源與有效期限；控制器另保留原始觀測。（本檔補註，非作者自陳）它是否優於特定端到端模型，仍尚待按任務長度與硬體預算實測。（本檔補註，非作者自陳）

三、顯式結構贏在長程規則，輸在初始狀態與幾何落地

河內塔式操作中，神經符號模型以 PDDL 規劃配合學習式控制。2602.19260 三塊任務成功率為 95% 對端到端 VLA 的 34%，未見四塊為 78% 對 0%，均為作者自報。2602.19260 VLA 微調能耗為 68.5 MJ，神經符號方法為 0.85 MJ，亦為作者自報。2602.19260 這是單一窄域與不同資料形態下的結果，不能外推成符號方法全面勝出；它只否定端到端規模會自然產生長程可靠性的假設。（本檔補註，非作者自陳）

Neurosymbolic Embodied Agents 先以多視角或互動證據建立符號初始狀態，再於 token 層排除不可行動作。2608.16794 殘餘失敗主要集中於狀態獲取，一旦狀態正確，受約束規劃高度可靠，為作者自報。2608.16794 規劃器證明的是相對於符號狀態可執行，不是該狀態忠於物理世界。（本檔補註，非作者自陳）

SymPlan 先以符號執行器檢查目標與前置條件，再只對穩定通過的題目施加長度壓力；它不處理多視角初始謂詞，也不是低階控制策略。2606.31260 所以「plan right, then plan tight」之前還有「ground right」，省 token 不能補救錯的物件綁定。（本檔補註，非作者自陳）

PDDL-ART 從示範、任務與動作名稱產生 PDDL，再檢查語法、可行性、初始狀態、計畫語意與執行期謂詞。2608.17146 但謂詞仍由 VLM 判斷，修正也可能破壞已驗證部分。2608.17146 自動生成降低建模成本，沒有消除 perception-to-predicate 的可信度問題。（本檔補註，非作者自陳）

GAVEL 讓 LLM 管語意程序，圖世界模型管前置條件、效果、安全恢復與未知位置分布；規則可推出的缺步直接修正，其餘才退回 LLM。2609.19315 完整分布加線上重排比只取最大後驗位置少走約 5.4%，為作者自報。2609.19315 圖模型沒有幾何可達性與碰撞限制，符號成功不能直接等同實機成功。2609.19315 將程序圖、動態幾何與觸覺控制接成一條管線，整合誤差與即時成本尚待實測。（本檔補註，非作者自陳）

四、不確定性要保留型別，fallback 才知道該退到哪裡

SymboUQ 分開可符號化比例與可判定比例。2608.00417 parser 能接受宣稱，不表示稽核器能從 grounded 前提得到蘊含或矛盾；unknown 與 not-evaluable 也不算通過。2608.00417 控制交接應把缺少 ontology、缺少觀察、前提矛盾與幾何方差過大保留成不同狀態，而非單一低信心。（本檔補註，非作者自陳）

不確定性往下游傳遞時，至少要保留四種型別及其來源。（本檔補註，非作者自陳）

  • 證據未知：物件未見、視角不足或工具沒有管轄權時，先做有預期資訊收益的觀察或換證據工作流；想像視角只能排觀察優先序，不能冒充實測。（本檔補註，非作者自陳）
  • 符號矛盾或不可判定：前置條件衝突時停止該計畫，回到可信脈絡重建物件綁定與謂詞；若稽核器不支援該關係，升級到工具或人工，不把 unknown 當成 false。（本檔補註，非作者自陳）
  • 公制估計有界但不精確：把座標分布、遮擋與校準資訊傳給局部控制器，限制速度與作用域，再以新觀察重新估計；GAF 式幾何初稿加學習式殘差修正可作候選，但校準門檻尚待實測。（本檔補註，非作者自陳）
  • 接觸後偏差：保留高頻連續觸覺給控制器做局部修正，把低頻物性摘要交給規劃器判斷是否換 subgoal；若兩層判斷衝突，停止 action chunk 並重新取證，而非讓語言描述覆寫原始力訊號。（本檔補註，非作者自陳）

每個 fallback 應回到能修正該錯誤的層。（本檔補註，非作者自陳）GAVEL 對未知位置保留分布，VLA-Touch 讓接觸訊號分別進入規劃與控制時間尺度。2609.193152507.17294 閾值與近似風險見可靠函數綜述；重試、回滾與副作用則交由前述故障治理。

端到端 VLA 能吸收難以列舉的感測規律，顯式程序能約束順序與前置條件；任一方獨占全鏈，都會把自己的弱點變成下游唯一真相。（本檔補註，非作者自陳）較務實的設計是神經模組提出帶來源與分布的候選，符號層裁定程序合法性，控制器保留原始感測並在越界時 fallback；其跨層可靠性、能耗與 sim-to-real 優勢仍尚待實測。（本檔補註，非作者自陳）
