安全、更新准入與研究空白

具身 Agent 的安全不能用「最後有沒有完成」或「過程有沒有被記成違規」單獨回答。本章把安全推理、輸入失真、更新准入、模組介面與執行加速放在同一條證據鏈上，追問系統究竟是安全地前進，還是靠拒絕、停滯與未被量測的風險換得漂亮數字。最後收束為四個可驗證的研究缺口。

安全推理與任務成功互相拉扯

IS-Bench 把主要任務成功率、任務完成且安全條件全數滿足的成功率，以及已觸發風險的處理率分開量測，並區分必須在風險動作前成立的 pre-caution 與動作後恢復的 post-caution。安全 CoT 讓全模型平均風險處理率增加 9.3 個百分點，主要任務成功率卻平均下降 9.4 個百分點；這些數字均為作者自報。2506.16402 這組結果不支持「多想一步自然更安全」的簡單敘事，而是顯示現有 agent 可能把計算、探索或行動預算花在避險上，最後既少犯錯也少完成任務。（本檔補註，非作者自陳）

問題還早於控制器。HEAL 以場景與任務不一致的受控改寫測試目標翻譯，發現模型可能辨識出缺件，卻仍生成不可接地的符號目標；即使不再提不存在的物件，也可能擅自改做另一個可行但不等價的任務。其證據止於 LTL 目標，沒有執行到物理動作。2506.15065 因此，「沒有捏造物件」不能代替「忠於使用者意圖」，而「拒絕不了」與「拒絕錯了」也應分開計分。（本檔補註，非作者自陳）

語音入口又把這個矛盾往前推了一層。Robots Mishear Us 的文字層 ASR 擾動顯示，近音替換可保留危險語意並提高有害指令穿過拒絕邊界的機會；嚴重雜訊條件的接受率升高，但可執行危險方案沒有同步增加，數值均為作者自報。正常任務的規劃成功率也會因同類錯誤下降。2608.28518 這項實驗模擬的是轉錄文字，不是真實麥克風經 ASR 產生的錯誤，所以尚待實測不同口音、聲學環境與辨識模型是否維持相同風險排序。

三篇工作咬合後，安全測試至少要保留四個互不替代的結果：是否正確理解意圖、是否察覺風險、是否產生可執行方案、是否安全完成任務。（本檔補註，非作者自陳）高風險動作前的條件檢查與失敗治理，可沿用既有的故障治理綜述；本章不重述其攔截、路由與補償機制。

零違規與持續學習的停滯假象

Update Admission 指出，更新關卡若只統計已准入更新的違規率，永遠拒絕便能取得零記錄違規。共同候選流實驗中，成對二項關卡隨證據預算增加而接受更多更新，未觀察到契約違規；範圍型 Hoeffding 關卡在兩個預算下都沒有接受更新，這些結果均為作者自報。迴路診斷的 fresh paired 關卡雖維持作者自報的零契約違規，仍錯失 60.4％ 的可學輪次，最終成功率為 59.6％。2609.10873 所以准入器的輸出不該只有 pass 與 fail，還要有 defer、證據成本、可學機會覆蓋率與停滯時間；否則安全數字無法分辨克制和癱瘓。（本檔補註，非作者自陳）

Provably Safe Sim-to-Real Transfer 提供另一種「安全地繼續學」的形式。它維護可能失配的轉移集合，在未認證區域使用真實資料，已認證區域重用模擬器，並以已知具有嚴格安全餘裕的基線策略混合候選探索策略。其理論保證依賴 tabular CMDP、已知安全基線，以及失配與不失配轉移之間可分離的間隙。小型 gridworld 中，方法的 unsafe iterations 為作者自報的 0.0％，但真實樣本仍多於不受限方法。2609.01418 這不是「零違規而且免費」，而是用基線餘裕與較多互動購買可證安全的進展。（本檔補註，非作者自陳）

兩條路的共同難題是何時已有足夠證據放行。VLA calibration 研究顯示，prompt ensemble 在作者測試的 36 組模型、資料與指標組合中都降低校準誤差，動作維度間的 ECE 最多相差 5 倍；這些數字均為作者自報。該研究只在 LIBERO 與 OpenVLA 系列驗證，而且信心貼近群體成功率不等於能辨識個別失敗。2507.17383 把校準分數接到更新 gate 時，應另驗證它能否排序候選、其機率值是否可信，以及 gate 對錯失機會的敏感度；三者不能由一個 ECE 代答。（本檔補註，非作者自陳）

可靠的准入契約因而必須同時計量傷害與進展：放行後的物理安全、保留舊能力、新能力增益、拒絕或延後造成的機會損失，以及取得獨立證據的成本。（本檔補註，非作者自陳）契約如何成為可組合的可靠函數，可接續可靠函數綜述；本章只保留具身部署特有的證據問題。

型別接得上，不代表物理效果等價

AgentSpec 以 typed intermediate object 串接 perception、memory、reasoning、reflection、action 與可選 learning，使模組能在同一流程中受控替換。實驗顯示，結構化記憶的收益取決於下游 reasoner 是否能利用其抽象；訓練時未見過該 scaffold 的 policy，也不保證部署時接上記憶就會進步。2606.14674 型別介面解決的是「資料能否送達」，不是「接收端是否理解其語意」；更新准入的最小單位因此應是模組與相鄰介面的組合，而非孤立元件。（本檔補註，非作者自陳）

Spec-VLA 顯示相同問題也出現在解碼器與物理動作之間。它讓小型 draft model 先提出 action token，再由原 VLA 平行驗證，並以離散 bin 距離取代 token 完全相等。作者自報的整體加速為 1.22× 至 1.42×；較容易的任務可放寬門檻而不降低成功率，LIBERO-Long 在門檻超過 5 後則明顯惡化。研究只在模擬器驗證，bin 接近也未被證明等同於碰撞邊界附近的物理效果接近。2507.22424 推測解碼的可靠性契約不能只寫接受距離，還要綁定任務 horizon、動作維度、狀態區域與失敗後果，這些條件尚待真機實測。（本檔補註，非作者自陳）

Weights or Skills 將機器人學習分為把能力固化進權重的 VLA，與可檢視、修改及組合的 code-as-policy 技能，並指出跨形體可攜性、技能來源、第三方驗證、前置條件與效果詞彙仍缺公認標準。綜述也指出，同時整合 feedback、memory 與 search 的系統仍少，這是作者的定性盤點，不是跨 benchmark 排名。2608.01851 兩派真正的交會點不是選權重或技能，而是都需要可審計的准入物件：權重更新要攜帶資料、回歸與校準證據；技能要攜帶來源、前置條件、效果、平台假設與撤回條件。（本檔補註，非作者自陳）

Embodied Reliability Agenda 進一步主張，測試、組合式驗證與 runtime assurance 應共享神經符號表示，並讓部署時的假設違反回流到規格、情境與 fallback；但該文是研究議程，沒有整合系統或量化實驗。2606.03593 這為權重與技能提供共同語言，卻還沒有證明共享表示能避免語意在介面間流失。（本檔補註，非作者自陳）

四個需要真機證據的研究缺口

第一個缺口是跨平台、跨月的記憶與恢復基準。AgentSpec 的受控組合尚未量測長期記憶成長、磨耗與錯誤沿軌跡傳播；Update Admission 的診斷則是合成的一步純量模型，沒有接觸幾何或實體安全危害。2606.146742609.10873 新基準應讓同一組記憶與技能在不同形體、場域與月份重播，記錄寫入正確性、退役時機、恢復成功率、重複傷害、人工介入與能力保持，並公開硬體與軟體版本漂移；這套設計尚待實測。（本檔補註，非作者自陳）

第二個缺口是 detection→routing→recovery→audit 的因果消融。現有社群議程要求測試、驗證與執行期保證互通，卻未提供量化整合實驗。2606.03593 應固定失敗注入與初始狀態，逐一移除偵測器、路由器、恢復策略及稽核證據，再以重播檢查哪一段真正降低傷害、哪一段只增加停止率；此設計尚待實測。（本檔補註，非作者自陳）具體的反事實歸因、效果語意與補償分類交由故障治理綜述處理。

第三個缺口是同時涵蓋排序、物理安全與校準的 sim-to-real 標準。現有可證方法限於帶安全基線與可分離失配假設的 tabular CMDP，VLA 校準證據又來自模擬成功標籤；兩者尚未在同一真機流程相遇。2609.014182507.17383 標準應同時報告模擬器能否排序候選、實機互動是否違反時序安全條件、預測風險是否校準、取得保證用了多少真實樣本，以及保守 gate 錯失多少合格更新；此標準尚待實測。（本檔補註，非作者自陳）

第四個缺口是把不確定性送到公制控制，而不是停在文字、token 或任務級分數。HEAL 尚未執行其符號目標，語音安全研究尚未從真實音訊產生轉錄，Spec-VLA 也未在真機證明 token 距離對應物理效果距離。2506.150652608.285182507.22424 有前景的實驗應保留感知、語音、目標翻譯、動作維度與動力學模型各自的不確定性，觀察它們如何改變速度、接觸力、安全距離、fallback 與人工接管；此方向尚待實測。（本檔補註，非作者自陳）若這些訊號無法改變公制控制或更新決策，校準再漂亮也仍只是旁觀量測。（本檔補註，非作者自陳）
