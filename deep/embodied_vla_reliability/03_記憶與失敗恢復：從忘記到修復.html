記憶與失敗恢復：從忘記到修復

具身 agent 會「看過」某物，不代表它記得物體後來被移到哪裡；它曾「做過」某動作，也不代表物理後條件已成立（本檔補註，非作者自陳）。本章把記憶視為受驗證約束的狀態轉移，再沿著「偵測→路由→恢復→重驗」追問：何時可重試，何時必須重置，又有哪些錯誤會永遠躲在抽樣之外（本檔補註，非作者自陳）。

一、歷史量不等於可行動的記憶

FindingDory 把記憶測試拆成高層的歷史目標選擇與低層的實際導航。2506.15635 模型即使辨認出物件，也可能選到不可達或不夠近的歷史視點；增加未過濾影格並未穩定改善表現。2506.15635 TemporalFlow-VLA 從另一端得到相同警示：直接提供多幀，不保證模型學到時序與物理變化。2608.26821 它以機器人表面的 temporal flow 監督雙時間尺度 token，強迫歷史壓縮後仍保留「剛才實際怎麼動」。2608.26821 兩者的咬合點不是「少看幾幀」，而是歷史的取捨要由下游行動所需的證據決定（本檔補註，非作者自陳）。

MEMOBench 再把「記得」拆成 Storage、Update 與 Compression，用模擬器 predicate 檢查過程 checkpoint，並以 prefix completion 阻止 agent 因為偶然達到後段狀態就冒領前序進度。2609.07047 這個分解說明看過、存入、修訂與壓縮是四次不同的失敗機會；終局成敗只能證明整條管線的結果，無法反推哪一步已經可靠（本檔補註，非作者自陳）。

Mimir 因此把世界記憶與任務記憶分開：前者保留實體、位置、狀態與觀測證據，後者維護目標順序、進度、手部狀態與失敗紀錄；找不到證據支持的接地候選時回傳空值，不猜一個動作。2608.04933 但結構化不會自動帶來組合可靠性（本檔補註，非作者自陳）。AgentSpec 的受控組合顯示，記憶模組與 reasoner 的抽象層級是否相容，會改變模組組合後的效果；訓練時未看過某種結構化歷史的 policy，部署時外接記憶也不保證受益。2606.14674

二、動作事件不等於物理成就

AGM 把夾爪開合視為「現在應該查證」的觸發器，不是「已抓取或已放置」的成功證明。2608.29537 物體隨夾爪連貫上移，或釋放後指定語意關係成立，進度才准寫入；失敗則依可恢復性保留當前步驟或回滾。2608.29537 這種寫入協定正面回答了「做過為何不是完成」：動作是命令通道的事件，成就則是世界狀態通過後條件的證據（本檔補註，非作者自陳）。

EXPTEACH 也不把所有實機軌跡直接升格為長期記憶。2507.16713 動作、回饋與修正先留在短期記憶，任務成功後才把經驗摘要入庫；新任務又只取回相似經驗，而不是把整庫塞入 context。2507.16713 MeCo 對軌跡快取再加入另一道門：相似性足夠才重用歷史軌跡，中途失敗時從當前狀態續規劃，快取則以使用頻率與冗餘檢查決定保留。2601.20577 前者強調「什麼可寫入」，後者強調「什麼可重用」；兩道關卡不能合併，因為曾經成功的軌跡在新位姿下仍可能不適用（本檔補註，非作者自陳）。

WALL-E 將真實軌跡與 LLM 世界模型的預測差異歸納成 action rules、knowledge graph 與 scene graph，再轉為能否決模型預測的 code rules，並以診斷集覆蓋率修剪衝突或冗餘規則。2504.15785 這與記憶准入是同一個問題的兩面：經驗不只要有成功標籤，還要證明它能修正哪類已知錯誤，並在新證據出現後可退役（本檔補註，非作者自陳）。至於執行效果、授權與目標完成的一般性區分，可參見故障治理綜述，本章只保留具身記憶的物理證據問題。

三、偵測到恢復之間還有一個路由問題

FARM 從凍結世界模型的內部預測狀態讀取逐步失敗分數，再用至當下的最高分累積因果軌跡風險。2609.11445 它明確把繼續、求援、恢復或重置留給獨立的介入策略，且未見任務的零樣本轉移較弱。2609.11445 因此風險 readout 只是路由的輸入，不是「應該重試」的答案（本檔補註，非作者自陳）。

FLARE 提供一個可操作的分界。2608.26645 環境仍在原任務可恢復範圍內，只有機器人姿態偏離時，主策略 Retry；環境前提已遭破壞時，切換到物件中心的 Reset 專家。2608.26645 人類指定 Reset 路由優於線上 MLLM 路由，這是作者自報結果，也直接暴露「會恢復」與「知道何時切換」並非同一能力（本檔補註，非作者自陳）。2608.26645

Onto-EV-WM 把模糊失敗分數轉成含型別、參數與來源的失敗謂詞，再依謂詞將修正提案送往相容機制；路由只代表介面相容，提案還得通過原生任務 predicate 才能接受。2608.13901 這使恢復管線有三個不可對換的契約：風險訊號要能提前量到錯誤，失敗類型要能支持選路，執行後要用世界狀態重驗（本檔補註，非作者自陳）。任一契約尚未開始實體跨任務校準，就應標示為尚待實測。

若失敗謂詞指向陳舊的物件隸屬、空間關係或前置條件，路由對象就不應是動作 policy，而是世界圖、scene graph 或其約束規則（本檔補註，非作者自陳）。圖修復更正的是後續接地與規劃所讀取的世界狀態，修復後仍必須重做原生後條件驗證（本檔補註，非作者自陳）。

IRR 提案重用 VLA 視覺編碼器與成功示範終點，以特徵距離產生任務獎勵，但作者尚未報告該獎勵造成的策略改善，並保留獨立稽核作為真正成功判定。2609.17115 這與 FARM 共用底層表徵的效率優勢相似，也共用一個治理風險：偵測或獎勵若與生成策略同源，就可能一起忽略同一種 near miss（本檔補註，非作者自陳）。共用表徵可作便宜的常駐訊號，不應直接升格為獨立成就證明（本檔補註，非作者自陳）。

四、恢復要換策略，驗證還要追著策略走

恢復不是單一個 replan 按鈕（本檔補註，非作者自陳）。RoboMonkey 在每個狀態產生多個動作候選，再用合成偏好資料訓練的驗證器選出與專家動作較近者。2506.17811 這證明推論期增加提案與篩選可改善動作選擇，但 RMSE 偏好代理的是模仿相似度，不是長期任務價值。2506.17811 若失敗來自策略慣性，重新抽同一類候選只會重演（本檔補註，非作者自陳）。Quality-Diversity 規劃工作改為依行為差異保留 policy archive，偵測到持續停滯後回滾 checkpoint，再換成行為不同的 policy。2608.08523 前者在當下候選內選優，後者在多種策略間換軌；只有先判斷錯誤是單步偏差還是策略模式錯誤，才知道要加大抽樣還是離開原分布（本檔補註，非作者自陳）。

ARCHITECT 把人類對失敗軌跡的自然語言修正對應到程式與工具呼叫，再蒸餾為可持久載入的 skill library。2607.23784 Language-Driven QD 則讓 LLM 產生成功條件、適應度與多組行為描述子，以多個 MAP-Elites 網格搜尋行為不同的成功技能。2608.30983 前者的 library 沒有顯式衝突規則，後者只在模擬中驗證。2607.237842608.30983 兩條路線都把修正從當輪 prompt 變成可重用資產，但技能的作用域、版本與物理後條件如何共同決定准入，尚待實測。

RENEW 對可被 planner 利用的世界模型錯誤選擇另一種修復：從 ensemble disagreement 高的 imagined rollout 取樣，請標註者比較哪段 dynamics 較合理，再以偏好微調世界模型。2607.14180 它的偏好來自可見真值的合成 oracle，尚未證明真人噪聲下的效果。2607.14180 這修正的是模型本身，不只是限制 planner（本檔補註，非作者自陳）。若標註只問「哪段較快達標」，反而可能獎勵穿牆之類的 exploitation。2607.14180 驗證目標必須與要修復的缺陷同義，否則「驗證後寫入」只是對錯的代理指標更有紀律地過擬合（本檔補註，非作者自陳）。

最後的限制來自抽樣驗證本身（本檔補註，非作者自陳）。在連續空間中，若重要的 reset mode 很少被驗證軌跡碰到，通過逐轉移檢查的程式世界模型仍可能漏掉整條規則，之後又被 planner 反覆利用。2608.17956 因此驗證分布要追著 planner 的查詢分布走，並主動探測模式邊界；即使如此，未覆蓋區域仍只能標成不確定，不能補寫為成功（本檔補註，非作者自陳）。關於這類覆蓋、不確定性與可靠函數的一般性關係，可參見可靠函數綜述。

落到狀態機時，最小協定應分開記錄觀測到的歷史、已嘗試的動作、已驗證的成就與已完成的恢復；每次轉移還要帶上證據來源、驗證器版本、可恢復性與未覆蓋邊界（本檔補註，非作者自陳）。偵測訊號越過門檻後，系統先根據世界前提是否仍有效選擇 retry、reset、policy 合成或圖修復，再對恢復後的原生任務謂詞重驗；路由命中、程式無錯與視覺相似都不可單獨推進持久進度（本檔補註，非作者自陳）。若重驗仍落在抽樣外，正確狀態不是成功或失敗，而是尚待實測的 unknown。
