七、權限與責任必須沿來源路徑傳播

SEAgent 把 agent、工具、RAG 與 agent 間訊息建成資訊流圖，用 ABAC mandatory policy 在 effect 前做 allow／prompt／deny。它特別處理 confused deputy：低權限 agent 傳給高權限 agent 的文字，不會因接收者較可信就自動升格。受測 InjecAgent／AgentDojo 攻擊為 0% ASR，但前提是標籤與政策已正確配置；未知政策缺口仍不在保證內。2601.11893

來源敏感性稽核又證明 prompt 裡寫 UNTRUSTED 不構成邊界。固定 proposition、位置與任務，只翻轉來源權威，競爭證據條件下有 5.4% 動作不一致；移除合法證據後，2.4% 比較呈現「原本正確、混入未授權證據後錯、移除後又正確」。這些是 stress-set rates，卻足以說明 capability decision 必須逐 argument 查 lineage，不能只問模型是否理解來源標籤。2607.20827

語音輸入還顯示 lineage 不能從文字 token 才開始。ASR 變形可讓原本有害的指令更容易穿過拒絕邊界，也會讓正常任務的規劃表現下降。 2608.28518 因此乾淨文字上的安全 gate 不能替整條「語音→轉錄→意圖→計畫」管線背書，候選轉錄與不確定性必須隨來源一起保留。（本檔補註，非作者自陳） 2608.28518

PCAA 再補上跨 runtime 的責任物件：action certificate 保存 admissibility、action identity、assumptions、approval 與 outcome closure，也誠實標示 adapter 只能 inline gate、由外部 runtime 控制，或僅 post-hoc observe。它的 proof 目前主要是 receipts、canonical manifest 與 replay check，不是形式安全證明；96 條 protected traces 又與自家 taxonomy 高度對齊，1.000 routing 成績需保守看待。可取的是 schema：observer 不得冒充 enforcement，未執行與等待核准也要有 closure evidence。2606.04104

八、交易、授權與目標完成是三種不同的 commit

Atomix 把 LLM execution 與 effect settlement 分離。transaction 先累積 tool intents，依資源 frontier 決定哪些可 buffer、哪些可 reversible-eager、哪些 irreversible effect 必須等到 commit gate；abort 時不再把 checkpoint replay 當成效果回滾。在 SMTP sink 實驗中，Atomix、TCC 與 Mutex+WAL 都是 0/500 invalid、500/500 valid，Saga 卻在 5 種 abort source 中洩漏 4 種效果，checkpoint replay 洩漏 2 種。它最值得吸收的不是「交易」標籤，而是 per-resource ordering、effect class 與 settlement 狀態；多個不可逆 effect 的 partial commit、跨程序與 distributed exactly-once 仍未解。2602.14849

SagaLLM 代表另一條路：長交易拆成可補償步驟，保存 persistent state、validator 與 coordinator，在失敗時反向執行 compensation。概念適合不可鎖住整個世界的 agent workflow，但原文只有四個 planning failure cases，沒有 SagaLLM task success、rollback completion 或 validator accuracy；Always、Guaranteed 不是形式或定量證據。2503.11951

即使效果可正確 settlement，也不代表仍獲授權。Commit-Time Authorization 把 DOM epoch、approval token、ETag、branch marker、reservation handle 等視為 authority witness；derived state 繼承 witness，durable effect 前必須重查 freshness、causal priority、effect binding 與 eligibility，並把 check 與 commit 原子耦合。壓力測試的 invalidating rows 有 207/216 unauthorized commits，是刻意破壞 authority 的 stress rate，不是部署事故率；CommitGuard 可將配對 replay 的 unsafe effect 轉成 abort，但 live success 由 0.972 降到 0.5。2607.10487

最後，合法且正確的效果仍不等於 goal 完成。Goal-Autopilot 只允許實際 gate 通過的 FSM 抵達 DONE，把 fabricated success 由 StateFlow 的 25.05% 降到 0.95%；但 SWE-bench Lite 上 true success 是 0/750，745 次 stall。其 DONE ⇒ goal 定理條件化於 gate soundness 與 plan coverage，而 coverage auditor 擋下 928 個 stalls 中的 866 個。2606.11688 所以 production ledger 至少要分開記：

effect settled?     authority still valid?     goal mechanically verified?

三者都為真才能稱為可信完成；其中一格未知，就不能由 agent 自述補成成功。

AGM 把這項紀律落到具身進度記憶：夾爪事件只觸發查證，物體隨夾爪移動或指定關係成立後，進度才准寫入；失敗則依可恢復性保留當前步驟或回滾。 2608.29537 這為「效果已發生仍不等於目標已完成」提供正證，也把持久狀態寫入本身提升為需要成就憑證的 commit。（本檔補註，非作者自陳）但其線性單指標不支援分支與部分序，而且有界拒絕到上限後仍可能放行未驗證進度，不能讀成完全 sound 的 goal gate。 2608.29537
