思想模型：四種不能混用的 agent 觀

「agent 的思想模型」至少有四種意思。混用它們，會把軟體模組、心理理論與方便的擬人語言當成同一件事。

一、計算圖：最適合工程

GPTSwarm 把 agent 系統表示為 node＝LLM／工具／函式，edge＝資訊流；AFlow 再把條件與迴圈寫進程式碼控制流。這個模型讓成本、路由、版本、錯誤與可替換性都有明確位置。2402.168232410.10762

它不主張 agent 真的有信念，只回答「資訊經過哪些轉換後產生行動」。做編排、最佳化與除錯時，這應是底層真相。

二、BDI／POMDP：顯式信念狀態

古典 BDI 把 belief、desire、intention 分開；POMDP 則維護對不可觀測世界狀態的信念分布。Agentic AI 綜述提醒，現代 LLM agent 多半是隨機生成與 prompt 編排，不能因提示裡出現 goal、reflection、belief 就倒推它實作了 BDI。2510.25445

SToM 是少數把「對方意圖」真正外顯化的例子：先列 3–5 個可能意圖，逐輪以似然做 Bayesian update，再用信念熵決定追問資訊或採取目標行動。這比一句「猜猜對方在想什麼」更可檢查；但 likelihood 仍由 LLM 估計，且實驗只有 SOTOPIA 的 90／14 個雙人情境，不能當成一般 Theory of Mind 已解。2510.18476

三、生成認知：思想存在於互動

Enactive AI 拒絕把認知簡化成腦內世界模型，主張知覺、行動、經驗、自主性與具身條件彼此構成。RL 與它部分相容，因為 agent 從互動經驗學習；但 reward 通常仍由外部指定，身體也常只是限制，不是形成「什麼值得在意」的來源。2605.24238

這條線適合追問：一個只在收到 prompt 時醒來、沒有自我維持需求的 agent，究竟是自主主體，還是具有行動介面的服務？它提供評判語言，不直接提供可部署 runtime。

四、持久符號環境：思想結晶成可執行資產

Persistent Lisp Loop 讓 LLM 置身跨回合保存狀態的 REPL，能定義、檢查與改寫自己的函式、巨集與 DSL。它把思考從易失文字推向可執行符號資產；但目前是概念稿，沒有實作與 benchmark，任意程式執行與資源耗盡也尚未解決。2506.10021

一個較穩健的組合

四種模型可以分層，而不是選邊站：

系統真相：計算圖與事件 trace
決策狀態：顯式 belief／goal／intention
學習來源：環境互動與不確定性消減
長期結晶：通過驗證的程式、規則、技能與記憶

最危險的做法是只保留自然語言人格與反思，卻稱它具有穩定信念、自主目標和自我模型。可讀的敘事不等於可更新、可驗證的狀態。

具身長程序再補上一種跨層分工：符號任務圖管合法順序，append-only 事件記憶管進度，procedural saliency 管空間 grounding，VLA 只承接已獲准子目標的連續控制。 2609.05369 這佐證「思想」不該濃縮成單一 persona，而應拆成可驗證的程序狀態、感知對齊與動作執行。（本檔補註，非作者自陳）但目前證據只驗到局部 saliency 能修正目的地選擇，完整任務圖、記憶與人機事件管線仍待實測。 2609.05369

第五個工程層：思想是帶來源的派生狀態

上述四種 agent 觀仍少了一件事：某個 belief、摘要或計畫究竟從哪裡來，失效時哪些下游判斷要一起撤回。

HORMA 的 workspace 把 raw trajectory 留在 timestamped directory，再建立帶 source reference 的 entity、event 與 state notes；retriever 用 ls、grep、cat、select 導航，選取最少但足夠的 context。它把 construction 與 retrieval 分開，也把強模型的慢速整理與小模型的 critical-path navigation 分開。這很接近 context pager，但 select 只是選取，不代表內容已被外部驗證。2606.11680

StructMemEval 說明為何 retrieval 不足。它要求在 250–500 次更新中維持 tree、state、ledger 與 preference statistics；主集 retrieval-only overall accuracy 0.06，最佳 memory agent 0.66，count-based 最高仍只有 0.13。一筆漏記、重複或失效傳播錯誤就會污染最終狀態。記憶正確性因此需要 state-transition invariant、去重與 dependency invalidation，而不是更多 embedding top-k。2602.11243

Agent Traces to Trust 把這些關係收斂成 typed provenance graph：chronological event log 回答「發生什麼」，provenance projection 回答 Use / Generate / Derive / Support / Contradict / Invalidate / Trigger / Update。它是 taxonomy 綜述，尚未提出完整 runtime 或 full-stack benchmark；價值在指出 ToolRun argument、memory lineage、claim evidence 與 recovery action 必須能接在同一張依賴圖上。2606.04990

因此較適合 Agent Machine 的「思想模型」是：

raw event / observation                    權威歷史
        ↓ derive（保存 source、generation）
belief / note / plan / context manifest    可撤回派生狀態
        ↓ sample
LLM proposal                               機率候選
        ↓ validate + effect + evidence
committed decision                         權威狀態轉移

LLM 的文字不是隱藏在系統裡的靈魂，也不是可任意丟棄的 debug string。它是有 input manifest、模型 provenance 與 branch identity 的一次 proposal。真正可重播的是保存的 event 與 response，不是再問模型一次。

第六個工程層：intention 是 reducer 的輸入，不是內心獨白

ESAA 把模型輸出收斂成 structured intention，再由 deterministic orchestrator 驗證、套用並 append event，projection 以 reducer 從 journal 重建。這個拆法讓「agent 想做什麼」有清楚工程語意：它是尚未承諾的 proposal；真正的系統狀態是可重播 event projection。2602.23193 不過 clinical case 雖有 50 tasks／86 events，正文只完成 31/50 tasks、8/15 phases，且驗證標為 partial；它支持架構可檢查性，不支持已達成臨床級成功。

Formalizing Agent Security 再把「想做什麼」拆成四個可問的安全性質：task alignment、action alignment、source authorization、data isolation；五個 ideal oracles 分別判定 intent、step、source、scope 與 effect。它映射 87 篇工作，沒有新 runtime 或實驗，且明說 properties 沒有 completeness proof、尚未處理 multi-agent delegation。2603.19469 其價值是提醒：一個總稱為「agent 思想」的自然語言 trace，不能同時替代意圖、授權、資料流與效果證據。

更精確的資料型別是：

belief / hypothesis       可更新、帶信心與來源
goal / commitment         帶 owner、scope、deadline 與撤回規則
intention / proposal      尚未授權、尚未執行
authorized action         綁定 witness、target 與 policy version
committed effect          有 settlement 與 outcome evidence
verified completion       由 goal predicate 裁決

把這些欄位都塞進一段 persona prompt，會讓「模型說它知道／打算／完成」錯誤地升格成系統事實。

記憶壓縮不能洗白來源權限

Memory Provenance Laundering 指出一個比「記錯」更危險的 failure：外部網頁、郵件或 tool output 經 LLM consolidation 後，action trigger 仍被保留，但低信任來源被洗成「使用者歷史」或「既定流程」。PPMF 因而把 (source, trust, transformation history, risk labels) 存成平台 metadata，tool argument 必須綁回 supporting memories，權限取所有來源中的最低 trust；只有綁定 principal、target、risk class 與 scope 的平台 declassification event 才能升權。2607.29167

在論文的固定 schema 與完整標籤下，PPMF 對 synthetic、AgentDojo、HTTP effect、3,680-page BrowseSafe adaptation 與 726 traces 都得到 0 attack success；但 10% forged confirmations 時 ASR 變成 0.088±0.016，10% risk downgrade 為 0.112±0.006。這表示防線不是「模型學會辨識壞內容」，而是把 trust root 移到 observation labeling、confirmation UI、tool schema registry 與 append-only log。缺 metadata 時 fail closed 可保安全，卻把 benign success 降到 0.814。

因此記憶物件不能只存文字與 embedding。它至少要保存 immutable source identity、authority ceiling、derivation edges、generation、validity 與 declassification receipt；摘要內容再像使用者口吻，也不得自行取得使用者權限。
